This directory contains scripts used to generate manuscript-facing figures.
Keep final figure scripts here rather than scattering one-off plotting code in
the top-level `scripts/` directory.

replacement is a direction-qualified illustrative exemplar, not an unconditional representative

```bash

```

## M3A-v2.2 q_I Stim vs No-Stim Runaway Comparison GIF (E1146)

Two arms on ONE shared substrate/seed/drive/q_I carrier (same trajectory as
`plot_fig_m3a_v2_2_hG_runaway_transition_gif.py --top qI --layout subject1146`); the only
difference is that the stim arm V_th-clamps the E cells near the four central ICL contacts
(ICL4-7) during a finite window. Visual diagnostic of EXTERNAL preventive suppression --
NOT a treatment/recovery/closed-loop claim.

```
python scripts/paper_figures/plot_fig_m3a_v2_2_qI_stim_runaway_gif.py
python scripts/paper_figures/plot_fig_m3a_v2_2_qI_stim_runaway_gif.py \

```

The stim params (`_simulate_continuous(..., stim_target, stim_on, stim_off)`) only change the
spike-threshold comparison, never an rng draw, so the two arms are byte-identical until
`stim_on` (the comparison's shared baseline; pinned by `tests/test_m3a_v2_2_qI_stim_runaway.py`).
Layout = 2 rows (top no-stim / bottom stim) x [`permissivity(1-q_I)` | `2D SNN activity` |
(`q_I(mean+min)+axial g_K trace` | `SEEG readout`)]; the stim row overlays the no-stim mean q_I
as a gray dashed reference. Output
`results/paper-ready-figure/fig_m3a_v2_2_qI_stim_runaway_epilepsiae_1146/figures/`.
