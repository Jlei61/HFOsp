# 多模态传播语法审计 · 图说明

这一组图回答同一个问题：40 名患者里有 6 名被冻结的聚类结果判成"两个以上传播模式"，这些**多出来的模式到底是什么**。

配色遵循 `docs/figure_style_guide.md` §0.1：传播先后顺序一律 viridis（深紫=最早 First，黄=最晚 Last）；
模式数 K 用一条单色系紫色梯度（K=2 为灰色多数派），与 viridis 和保留给 Δr 的红蓝发散色标都不冲突。
独立 panel 文件不带左上角字母，身份由文件名标注；`multimode_grammar_complete_layout` 是带统一 a–d 字母的完整拼版。
每张图同时输出 PNG / PDF / SVG。

---

### multimode_grammar_complete_layout.png

四个 panel 的完整拼版，是这次审计的主图，按 a–d 顺序阅读。a 问"模式数跟着大脑走还是跟着电极走"，
b 问"一个模式具体长什么样"，c 问"两个模式之间差在顺序还是差在招募范围"，d 问"模式序列有没有记忆"。
四个 panel 各答一个独立问题，没有重复画同一层证据。K 的图例和顺序色标在整张图里各只出现一次。

**关注点**：a 里六个彩色点全部挤在最左侧的浅紫带内（触点数 ≤ 6），而 34 个灰点铺满 6–52 触点；b 里每一列（每个模式）
都有一个白色下三角和一个白色上三角落在不同的触点行上——模式之间换的是"谁先谁后"这一对端点。

### panel_a_modes_vs_array_size.png

横轴是这名患者真正参与传播事件的触点数（对数轴），纵轴是被冻结下来的模式数 K，每个点是一名患者。
右侧横条是 K 的人数分布（34 / 1 / 2 / 2 / 1）。右上角三行给出 K 与三个候选解释变量的 Spearman 相关。
六名 K>2 患者标了 1–6 的序号，序号与 panel b 的排列一致。

**关注点**：K 与触点数强负相关（−0.61），而与事件数（+0.12）和记录段数（+0.01）都测不出关系——
"多模式"跟着电极覆盖范围走，不跟着记录长度走。

### panel_b_mode_prototypes.png

六名 K>2 患者的模式原型热图。行是触点（用真实触点名），列是模式，颜色是该模式下这个触点的平均相对放电次序
（只统计该触点真正参与的事件，未参与的格子不进平均）。白色下三角标出该模式最先放电的触点，上三角标出最后放电的触点。

**关注点**：zhangjinhan 的五个模式，上三角沿对角线逐格下移——五个模式恰好就是"F5 最后 / F4 最后 / F6 最后 / G1 最后 / G2 最后"
这五种取值；818 的四个模式同样是"哪个触点最先"的四种取值。模式在枚举端点，而不是在表达四五种独立的传播语法。

### panel_c_order_vs_recruitment.png

每个点是一名患者体内的一对模式（共 84 对）。横轴是两个模式原型之间的秩相关（只在两边都有效参与的公共触点上计算），
越靠左表示两个模式的先后顺序越相反；纵轴是两个模式招募到的触点比例之差的绝对值。
坐标区下方的灰条给出"如果两个模式的触点顺序完全随机"时该相关系数的 95% 取值范围。

**关注点**：4 触点时随机顺序的 95% 范围铺满整条横轴，6 触点时也几乎铺满——
在这种阵列规模下，落进左侧"顺序相反"阴影区并不构成证据；纵轴上真正非零的招募差主要来自 916、zhourongxuan、zhaojinrui。

### panel_d_evenness_vs_switching.png

每个点是一名患者。横轴是模式使用的均匀程度（熵除以 log K，越靠右越接近平均使用每个模式）；
纵轴是实测的相邻事件换模式比例减去"block 内保持占比、只打乱顺序"的零假设均值。
水平实线是零假设位置，序号 1–6 与 panel a / b 一致。

**关注点**：全队列所有点都压在零线附近 ±0.07 以内，六名 K>2 患者（彩色）和 34 名 K=2 患者（灰色）混在一起，
分不开——没有任何一名患者的模式序列表现出"刚才用了 A，这次更容易继续用 A"的记忆效应。

### supp_s1_transition_matrices.png

K=4（818、916）和 K=6（zhaojinrui）三名患者的相邻事件转移矩阵。上行是实测转移概率，
下行是实测减去"block 内保持占比、只打乱顺序"的零假设期望。所有转移都只在同一段记录内部统计，
跨记录段的相邻对全部剔除。

**关注点**：下行整体接近白色，全队列最大的单格偏离是 818 第 4 个模式的自转移（+0.046，实测 0.306 对零假设 0.260）——
注意不要拿它和该模式 0.146 的全局占比比较，那个差距大部分是不同记录段成分不同造成的假象。

### supp_s2_superfamily_random_ordering_null.png

"这些模式是不是自然分成两个方向相反的大家族"的检验。对每名患者，把 K 个模式原型按所有可能的二分方式切开，
取"组内相关减组间相关"最大的那一种作为实测值（红点）；小提琴+箱线是零假设分布——保持每个模式的有效触点集合不变、
只把触点顺序随机打乱后重跑同一个最大化过程。

**关注点**：六名患者的红点全部落在零分布内部（P = 0.13–0.40）。
在随机顺序下，这个最大化过程本来就有 98.4%–100% 的抽样会给出"两个方向相反的家族"——所以这个读法本身不是证据。

# 2026-08-16 追加：selection-corrected null 与 916 招募范围端点

这一组图回答 08-15 报告留下的最大缺口（"每个模式内部的主导发放顺序，是不是固定 K 的聚类
在小格点上自己切出来的"），以及"916 的招募范围分层能不能搬到没看过的记录段上"。

配色沿用 §0.1：发放先后仍是 `First → Last` 的方向意义；模式数 K 的紫色梯度不在这组图里出现，
两个招募层用青（low-extent）/ 紫红（high-extent）区分，零假设一律用中性灰蓝，实测用暗红。
独立 panel 文件不带角标字母，`selection_null_and_extent_complete_layout` 是带 a–e 字母的完整拼版。

### f1_dominant_order_vs_selection_corrected_null.png

六名 K>2 患者各一列。纵轴是"主导发放顺序的集中度"——先算每个模式内部最常见的那一种发放顺序
占该模式事件的比例，再对 K 个模式取等权平均（等权是为了不让最大的模式独自决定这个数）。
每列两把小提琴：左边是"保住谁参与、只把先后顺序随机打乱、再用**与产出端逐字相同**的聚类重跑"
得到的零分布；右边是"连每个触点自己偏早还是偏晚的倾向也一并保住、只打掉事件内跨触点协同"
得到的零分布。红点与红虚线是实测值，下方两个 P 是各自的经验值。

**关注点**：红点相对左侧小提琴的位置就是"选择偏差之外还剩多少"。注意六个人不是一个档：
有的红点明显在小提琴之上，有的落在里面，还有的**掉到小提琴下面**——
即固定 K 的聚类在随机顺序上反而能切出比真实数据更集中的模式。

---

### f1b_null_construction_check.png

零假设的**自检**。横轴是六名患者（编号与上图一致），纵轴是"各触点平均发放次序的离散度"，
也就是"这个触点是不是总体上偏早/偏晚"这层一阶结构的强度。四根柱依次是：实测、
顺序随机化零假设、第一版"跨事件打乱再重排"零假设、以及穷举 p! 后按最大熵匹配边缘的替换版零假设。

**关注点**：顺序随机化那根应当几乎贴地（它就是要抹掉这层结构），最大熵那根应当与实测柱等高
（它就是要保住这层结构）。第一版那根**普遍高于实测柱**——它不是保住而是放大了这层结构，
所以实测落在它下面不说明任何事；这正是那一版被判为构造无效的依据。

### f2_916_extent_endpoint_train_heldout.png

左：六个触点各自的参与率；中：六个触点的平均发放先后（0=最先，1=最晚）；
右：AM 杆被招募的比例，深色横线是"同规模随机抽取"应当给出的水平。
青=低招募层，紫红=高招募层；实线=训练记录段，虚线=完全没看过的 held-out 记录段。
两层的划分只用训练段的招募比例定出，冻结后才搬到 held-out。

**关注点**：左中两图里实线与虚线几乎完全重合，说明这条阈值搬得动；中图里两条曲线
**一起单调上升**，说明两层走的是同一个方向，差别只在走多远。右图是这张图的要害：
高招募层的柱正好顶在它的随机水平线上（只有 4 个 AH 触点，招募 5 个以上必然碰到 AM 杆，
这是摆位的鸽巢效应，不是现象），而低招募层的柱远远**低于**它的随机水平线——
真正非强制的结构是"低招募的那一层主动回避 AM 杆"。
