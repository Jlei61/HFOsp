# Topic 4 rev22-DCI: frozen dual-core interictal connectivity identifiability

**Status:** specification for collaborator review; no rev22 SNN run is authorized by this document

**Parent result:** rev20-DC frozen dual-core mechanism atlas

**Scientific scope:** one patient, development-only, interictal activity only

## 1. Motivation and question

rev20 established a useful starting point. With the binary two-core Node field
`dualcore_s39` frozen, jointly increasing the expression of the previously learned E-to-E
and E-to-I redistribution patterns by 25% was the only tested one-factor candidate that
improved all three post-selection readouts on 12 new networks: held-out complete-event
distance, natural KMeans alignment to the patient's two templates, and OOD fraction.
Increasing E-to-E expression alone or increasing the fixed-topology ellipse aspect ratio
reduced distance and OOD more strongly, but also weakened or collapsed the minority mode.
No candidate reached the count-matched patient floor.

The next question is therefore not ictal fitting and not another free Node-field search:

> With the two-core Node substrate fixed, which parts of the already learned local
> connectivity redistribution are needed to reproduce the patient's complete interictal
> event distribution, including recruitment and within-event propagation timing, without
> collapsing one of the two naturally occurring event modes?

The experiment is data-driven in a restricted sense: patient interictal training events
select the expression and local fixed-topology geometry of an existing connectivity
redistribution family. It does not infer anatomical cores or biological synaptic strengths.

## 2. Frozen substrate and forbidden inputs

The following are frozen for every rev22 run:

- Node field `dualcore_s39`: centers `(1.53773425799, 1.22641798807)` and
  `(18.60661213705, 2.41771341441)` mm, 1,499 selected E neurons;
- Node mapping `delta_Vtheta_i = -h_i d_i`, with `node_gain=1` and the existing `d_i`;
- core count, centers, radius/budget, contact geometry, detector and causal-family event unit;
- realized baseline topology, delays, background spatial OU and all non-varied parameters;
- Z/M off, no ictal target, no Fig.5 criterion and no patient ictal file access;
- total incoming E-to-E and E-to-I weight for each postsynaptic target.

The formal observation remains one complete, returned, temporally isolated,
edge-supported causal family. Detector fragments cannot define event boundaries. Missing
contacts remain explicit states and are never silently removed from a distance.

## 3. Parameter semantics

Four coordinates are considered:

| Symbol | Machine meaning | Not allowed interpretation | Reference |
|---|---|---|---:|
| `g_LEE` | dose of the previously learned E-to-E coefficient row | total E-to-E synaptic strength | 0.5 |
| `g_LEI` | dose of the previously learned E-to-I coefficient row | I-to-E inhibition or total E-to-I strength | 1.0 |
| `theta_FT` | orientation used to redistribute weights over existing E-to-E edges | independently learned anatomical tract direction | 45 deg |
| `AR_FT` | aspect ratio used to redistribute weights over existing E-to-E edges | rebuilt isotropic/anisotropic topology | 2.0 |

`g_LEE` and `g_LEI` multiply learned coefficient patterns generated by
`continuous_local_e_source_flow`; they preserve every target's pathway-specific incoming
budget. The historical labels `Both` and `BOS` are derived joint-dose conditions, not extra
parameters.

`theta_FT` and `AR_FT` act through fixed-topology reweighting. The ellipse parameterization
already holds area constant:

```text
ell_parallel = ell_0 * sqrt(AR_FT)
ell_perpendicular = ell_0 / sqrt(AR_FT)
```

Because the graph was originally sampled near `theta=45 deg, AR=2`, this experiment cannot
claim to learn an unrestricted direction or range. The primary domain is restricted to the
rev20-estimable neighborhood:

```text
g_LEE    in [0.0, 1.0]
g_LEI    in [0.0, 1.5]
theta_FT in [22.5, 67.5] deg
AR_FT    in [1.0, 3.0]
```

`AR_FT=1` means an attempted isotropizing reweighting on an anisotropically sampled graph;
it is not a genuinely isotropic topology. `AR_FT=4` is excluded from the fit domain because
rev20 produced runaway in 4/4 networks. Angles outside the stated interval are excluded
because the realized graph provides inadequate support and rev20 produced non-estimable or
zero-event responses.

Changing total E-to-E strength, changing the E-to-E length scale, or rebuilding topology is
out of scope. A topology-rebuilt sensitivity would require a separate experiment because
its graph realization cannot be paired with the fixed-topology primary arm.

## 4. Locked versus free is not ablation

For model-family comparisons:

- `locked` means fixed at the reference value;
- `free` means optimized within the domain above using patient interictal training data;
- `ablated` means a learned dose is set to zero and is only a mechanism control.

The following 12 nested model families are predeclared. Bit order is
`[g_LEE, g_LEI, theta_FT, AR_FT]`, where 1 means free and 0 means locked.

| ID | Mask | Purpose |
|---|---|---|
| `M0000` | 0000 | frozen dual-core reference |
| `M1000` | 1000 | E-to-E learned-pattern dose alone |
| `M0100` | 0100 | E-to-I learned-pattern dose alone |
| `M0010` | 0010 | fixed-topology angle alone |
| `M0001` | 0001 | fixed-topology aspect ratio alone |
| `M1100` | 1100 | joint learned-dose surface |
| `M0011` | 0011 | joint fixed-topology geometry surface |
| `M1111` | 1111 | all four coordinates free |
| `M0111` | 0111 | full model with `g_LEE` locked |
| `M1011` | 1011 | full model with `g_LEI` locked |
| `M1101` | 1101 | full model with angle locked |
| `M1110` | 1110 | full model with aspect ratio locked |

The single-free families estimate main effects. `M1100` and `M0011` test the two mechanistic
pairs already implicated by rev20. The four leave-one-locked families test whether each
coordinate adds information once the others are available. Other pairwise families are
only added after rev22 if a leave-one-locked result reveals an unresolved interaction.

## 5. Formal training representation

For event `e` and fixed contact `i`, let `m_ei` indicate recruitment and `t_ei` be the onset
in milliseconds. Define:

```text
l_ei = t_ei - min_j(t_ej)                  physical relative onset in ms
u_ei = l_ei / (max_j(t_ej)-min_j(t_ej))    normalized within-event order
```

The label-free event vector contains:

```text
x_e = [m_e,
       m_e * u_e,
       m_e * clip(l_e / 180 ms, 0, 1),
       ICL and SCL recruitment fractions,
       physical first-SCL minus first-ICL lag / 180 ms,
       cross-shaft-lag validity]
```

All centering, scaling, PCA components and sliced-Wasserstein directions are learned from
patient training events only and then frozen. No A/B label enters this representation.

Three candidate training components are computed:

1. `D_cloud`: sliced-Wasserstein distance between complete patient and model event clouds;
2. `D_cover`: patient-to-model support coverage in the frozen standardized embedding,
   summarized by the q90 nearest-model-event distance over count-matched patient draws;
3. `D_lag`: shaft-balanced discrepancy of physical pairwise contact-lag distributions,
   including the states `i before j`, `j before i`, and `not jointly recruited`.

Each component has two uncertainty references:

- a patient split-block/count-matched floor;
- a within-candidate network-seed noise estimate.

The normalized excess is

```text
E_k = max(0, (D_k - patient_floor_q50_k) /
             (patient_floor_q95_k - patient_floor_q50_k + epsilon)).
```

## 6. Objective qualification before new simulation

No rev22 simulation may start until all 232 rev20 trajectories have been rescored offline.
For each component, define its empirical identifiability ratio as the between-candidate
q90-q10 range divided by the median within-candidate seed MAD. A component with ratio below
1 is not allowed to dominate the scalar objective; it remains a diagnostic endpoint.

The provisional scalar is:

```text
J_fit = max(E_cloud, E_cover) + lambda_lag * E_lag
lambda_lag = 0.25 if the D_lag identifiability ratio is at least 1, otherwise 0
```

This replaces an LSE over all components. An unresponsive physical-lag term therefore
cannot hide changes in event-cloud fit or patient-support coverage.

The objective is accepted only if all of the following zero-simulation controls behave in
the expected direction:

1. removing the patient minority cluster worsens `D_cover` and `J_fit`, even though the
   objective receives no cluster label;
2. censoring all SCL contacts worsens recruitment/coverage terms;
3. stretching physical onsets while preserving normalized order selectively worsens
   `D_lag` and the physical-onset part of `D_cloud`;
4. permuting within-shaft onset times worsens the pair-lag component;
5. on rev20 artifacts, the known aspect-3 mode-collapse control cannot outrank the balanced
   Joint-1.25 candidate on `J_fit` while appearing superior only because of majority-mode
   concentration;
6. each component's candidate ranking is reported with its four-seed uncertainty rather
   than as a single deterministic score.

Failure of item 5 means the representation still does not express the stated scientific
target. The response search must not start by changing optimizer settings to compensate.

## 7. One shared four-dimensional response design

The experiment does not run a separate CMA-ES for every model family. It uses one immutable
96-point space-filling design in the four-dimensional domain and fits one response surface.
The design contains:

- one exact reference point;
- 47 full four-dimensional maximin points;
- eight points on each of the four leave-one-locked three-dimensional planes;
- eight points on the `g_LEE x g_LEI` plane;
- eight points on the `theta_FT x AR_FT` plane.

The existing rev20 one-dimensional grids are rescored and reused as exact axis-anchor
observations for `M1000`, `M0100`, `M0010` and `M0001`; they are not rerun. The response
model retains an `observation_design=rev20_diagonal_seed` flag and their own seed-derived
noise estimates. They constrain the same mean response surface but are not counted as new
crossed-seed rev22 evidence.

A heteroskedastic Matérn-5/2 Gaussian-process response surface is fit to candidate-level
means with the observed four-seed variance. A second, nonparametric tree ensemble is a
sensitivity analysis. Conditional optima for all 12 families are proposed from the same
surface and must remain inside the sampled domain. Surrogate predictions never constitute
evidence: every proposed optimum is rerun on new seeds.

Leave-one-candidate-out prediction error, rank correlation and uncertainty calibration are
reported. If the GP and tree ensemble nominate disjoint regions, both proposals are carried
to the new-seed stage rather than choosing after viewing validation metrics.

## 8. Seed contract

Three random sources are distinct:

1. design/surrogate seed;
2. network-topology seed;
3. dynamics seed controlling OU/background and simulation stochasticity.

The current legacy `seed` creates both topology and dynamics. rev22 must add explicit
`topology_seed` and `dynamics_seed` without changing the default path. When both explicit
seeds equal the legacy seed, the substrate, events, onsets and all rev20 endpoint arrays must
be byte-identical to the archived result.

Candidate comparisons use common random numbers: every candidate receives the same crossed
seed units. Reusing simulation seeds across candidates is variance reduction, not an
optimizer restart. Space-filling design and surrogate initialization seeds are frozen
separately.

Seed stages are:

| Stage | Crossed units per candidate | Role |
|---|---:|---|
| fit | 2 topology x 2 dynamics = 4 | response surface |
| new-seed qualification | 3 x 2 = 6 | verify predicted conditional optimum |
| confirmation | 4 x 3 = 12 | final paired network-level comparison |

All 12 predeclared model-family optima proceed through qualification and confirmation unless
the worker has an engineering failure or nonfinite/runaway trajectory. There is no optional
stopping based on early metric direction.

## 9. Selection and validation separation

Only patient-training `J_fit` may choose parameter values. Before any candidate-level
validation field is loaded, freeze:

- the 96-point manifest and hashes;
- the fitted response models;
- one conditional optimum per family, plus any predeclared model-disagreement duplicate;
- all qualification and confirmation seed pairs.

After all corresponding SNN artifacts are immutable, open the following
**selection-blind validation endpoints**:

1. recording-block held-out complete-distribution distance;
2. natural model KMeans K=2 and balanced alignment to the frozen patient templates;
3. OOD fraction over all returned causal families, with unreadable events counted as OOD;
4. mode-specific recruitment, physical pairwise lag, rank profile and event-cloud spread;
5. pooled and equal-network-weighted mode proportions;
6. proportion of individual networks expressing both modes;
7. returned-event yield, unreadable fraction and runaway/nonfinite status.

Only the held-out distribution uses patient events not used to build the training target.
The KMeans alignment reference and OOD support were estimated from patient training data;
they are selection-blind in rev22, not statistically independent. Because these artifacts
have been viewed in earlier development rounds, the whole revision remains development-only.

## 10. Statistical analysis and parameter influence

The independent unit is a crossed topology-dynamics simulation unit, not an event. Report
paired differences to `M0000` and nested contrasts between `M1111` and each
leave-one-locked family. Use topology-first hierarchical bootstrap: resample topology seeds,
then dynamics seeds within topology. Event bootstrap is only a lower-level uncertainty
component and cannot replace seed-level inference.

A coordinate is called **useful within this SNN family** only when:

1. freeing it improves training `J_fit` in the predicted region;
2. the effect is reproduced on new-seed qualification and confirmation units;
3. held-out complete-distribution distance improves;
4. KMeans balanced alignment does not fall through minority-mode collapse;
5. OOD does not improve solely by suppressing yield or making events unreadable;
6. locking the coordinate back in the full model worsens at least one distributional
   endpoint without improving the others enough to dominate it;
7. the conclusion is not carried by one topology seed.

If many parameter values or model masks remain indistinguishable within uncertainty, the
coordinate is reported as non-identifiable, not ineffective.

## 11. Floor and effect-size reporting

Primary tables report raw distances, KMeans alignment, OOD and event yield. The descriptive
fraction of reducible discrepancy closed is

```text
F_closed = (D_reference - D_candidate) /
           (D_reference - patient_floor_fixed)
```

`patient_floor_fixed` is one floor computed at the reference candidate's pre-frozen median
event count and reused for every candidate. It is not recomputed at each candidate's yield.
Candidate-specific count-matched floors are reported separately as sampling diagnostics.
`F_closed` is never called variance explained and is always shown beside event yield.

## 12. Outputs and allowed conclusions

Required outputs are:

- objective-qualification report and synthetic-control figure;
- four-dimensional design manifest and seed manifest;
- response-surface diagnostics and conditional-optimum table for all 12 model families;
- paired validation atlas for distance, KMeans alignment, OOD and yield;
- Pareto plot of held-out distance versus KMeans alignment, colored by OOD;
- one Fig.4-style direct event/GIF panel and one KMeans panel for the final nondominated
  candidate, generated from the same confirmed artifacts;
- machine-readable provenance, hashes, exclusions and a Chinese `figures/README.md`.

If supported, the strongest allowed conclusion is:

> Data-driven adjustment of learned local connectivity redistribution improves interictal
> propagation kinematics beyond a frozen dual-core threshold substrate in this patient and
> SNN family.

Forbidden conclusions include biological E-to-E/E-to-I strength estimation, independent
tract-direction recovery, anatomical core identification, cohort generalization, ictal
recovery or patient-level causality.
