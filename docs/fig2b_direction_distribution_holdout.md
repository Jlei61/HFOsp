# Figure 2B 补充实验：留出方向分布损失

方案冻结日期：2026-10-22；本文件在读取新损失结果之前建立。此为作者提出的新补充分析，不声称独立预注册；旧 Figure 2B 已经查看过同一数据。正式图与作者终稿保持原版本，候选需作者目视验收。

科学问题是：同一患者的训练记录块得到两个模板后，加入三维电极几何得到的 rank trajectory 是否比仅用 channel rank sequence 更准确地表示未参与拟合记录块的方向分布？统计单位是患者，事件只用于计算该患者的损失。这里的方向是参与触点上 normalized rank 对真实三维坐标的最小二乘梯度方向，不是独立测量的物理真值，也不评价完整曲线、速度或未来发作。

## 数据与两种模型

沿用当前 all-event Figure 2B 的 26 人队列、完整通道 union、eventsBool 掩码和所有间期事件，不使用旧 5000-event/QC 子样本。奇偶记录块双向交叉拟合；两臂使用同一训练/测试划分，K=2、10 次初始化和 seed=0。rank sequence 的训练特征为 masked rank；rank trajectory 加入训练事件可估计的单位三维方向，按训练集两视图总方差匹配权重。方向不可估事件仍参与 rank 聚类。复用现有 all-event masked-view 算法，并逐患者对照已有 direction score 验证模板链一致。

两个训练簇分别产生原有 rank 模板及其三维梯度轴。为公平比较，两种方法都在同一真实坐标系读取模板轴；sequence 臂的坐标只用于公共评价读出，不参与模板发现。**本实验的 rank trajectory 指现有 rank+3D 方向增强模板，不是另行训练图中显示的流线曲线。**

## 主损失：留出方向分布负对数似然

每个训练模板轴 u_k 固定为其 rank 梯度方向。在单位球面上建立 von Mises–Fisher 分量：

`f(d | u_k, κ_k) = κ_k / [4π sinh(κ_k)] × exp(κ_k u_kᵀd)`。

κ=0 取球面均匀密度 1/(4π)。κ≥0 仅由训练簇的平均轴向余弦作最大似然估计，不重新旋转模板轴。数值上限 κ=1000，触及次数必须报告。分量权重 π_k 是训练集中可估方向事件的簇比例，因此表示方向可估事件的经验分布，不人为平衡两个模式。

冻结 `q_m(d)=Σ_k π_mk f(d|u_mk,κ_mk)` 后，主损失为 `L_m=−mean_test log q_m(d)`，单位为 nats（密度相对于 steradian），越低越好。计算混合密度时对两个分量求和，不利用测试方向选择最佳模板。每折按相同可估方向测试事件求均值，两折等权；队列对患者配对比较。由于评价实际事件分布，此处不沿用旧 score 的两簇等权权重。另报按事件数加权两折敏感性。

参考线为均匀球面 NLL=log(4π)≈2.531；另报告仅由所有训练方向拟合的单分量 vMF，以区分患者总体方向偏好与两个模板的作用。连续密度 NLL 不是概率百分比，也不应计算百分比误差下降。

## 辅助读出与有针对性的控制

- 冻结模板后仅用测试 rank 分配模式，报告事件方向与该模板轴的平均夹角误差（0° 完全一致，90° 垂直，180° 相反），以及对应条件 NLL。两种方法使用共同可分配测试事件。它们检验事件级对应，不替代主分布检验。
- 对训练集有限方向按记录块内置换，保留 rank、缺失性和全部测试数据，重新拟合空间模板；默认 20 次。密度的方向宽度在该置换训练视图上估计。该控制检验收益是否依赖 rank 与方向的配对，而不只是增加特征维度。失败次数及原因保留。
- 额外报告前半记录块训练、后半记录块测试的时间顺序敏感性，不将此内部表示检验称为未来临床预测。
- 验证球面密度归一化、均匀极限、数值稳定性、旋转/标签对称性、训练输入与测试输入隔离，以及 legacy score 复现。主统计固定为双侧患者配对 Wilcoxon；以患者 bootstrap 10000 次给中位配对改变量的 95% CI。主损失与辅助损失不按显著性择优。

支持“空间信息改善留出方向分布”的依据是 trajectory 主 NLL 在患者层面下降，并结合置换和时间顺序敏感性解释其稳定程度。若只有角度误差改善而分布 NLL 不改善，只支持模板轴更接近单事件方向；若 NLL 无改善，先检查轴定义、密度校准、模板复现和分母，不将结果归因于生物学不存在空间组织。
