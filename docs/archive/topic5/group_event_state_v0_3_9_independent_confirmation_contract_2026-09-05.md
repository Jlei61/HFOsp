# v0.3.9之后的独立确认合同

本合同固定下一阶段的证据边界，不授权自动打开已有development/sealed分区，也不把三个已见设计病例重新命名为独立验证。当前修复pilot的结果不论正负，都应按有限清单报告；不能把后续确认当成本轮无限重训的理由。

## 需要确认的命题

主要命题是：可学习的间期事件整合，是否在强背景和完整固定历史之外，提供可重复的未来预测信息，并让**同一个患者、同一seed、同一冻结checkpoint**迁移到未用于上游学习的事件传播结构。非线性转移有无额外增量单独回答；线性模型表现更好也是有效结果。冻结状态的发作前信息和事件对生理状态的反馈分别立题，不能由前一个命题自动推出。

## 人与数据的独立性

E1096/E1125/E253及参与过旧版本结果筛选的时间段均标为设计资料。确认病例先按记录覆盖、原始通道可重建、处理延迟、间期事件有效测量和发作分母登记，不查看模型收益选择患者。临床发作计数可用于可估性盘点，但不得依据风险预测结果选择上游或患者。

先盘点新病例的FIT/INNER/独立留出支持，再冻结完整病例清单与不可估原因。间期检验至少应有可覆盖多日/独立记录段的多个非重叠目标窗；具体样本量须由保留真实缺失和时间相关性的全训练流程模拟预先确定，不能把“20个窗”等经验数字当成充分功效。患者是队列结论的单位，seed是优化重复。展示每个物理窗，不用重叠anchor或seed补齐分母。

## 信息边界与测量

触点选择、refine、空间编码和所有归一化仅由训练资料确定。保留原始记录、检测、打包、细测量与背景抽样的依赖清单。跨处理段事件若缺少细mark，保留已知clock/count/participation，把细mark缺失与真实无事件分开。背景窗避让完整事件core，零事件块仍提取固定网格背景。响应分量按FIT可测支持锁定，不让一个不支持频带抹掉其他可用分量。

现有算子按整块结束发布token。若后续要研究即时IED状态更新，必须另行构建并冻结低延迟检测算子，完整验证截断原始记录到查询时刻后的输入与状态不变；不能只移动时间戳。人体pilot的近小时发布延迟不能被隐去。

## 状态与冻结任务

确认阶段先锁定F完整固定历史、L可学习线性转移和N非线性转移。相同事件写入定义、背景父预测、读出结构和优化规则；历史H=0.5/8小时，主要提前量2小时、目标宽度30分钟，0/6小时为明确登记的参照与延伸。N增加的转移容量与L32敏感性并列，不用无作用参数凑相等参数量。

学习率、步数、优化器、初始化、实际batch、训练/验证曲线、每层形状、参数变化、输入与源码hash全部落卡。非零训练步、梯度可达、转移项曲率和留出净收益分别记录。初始回退是合法拟合选择；达到预算上限意味着优化受限，不意味着生物学阴性。优化配置在任何留出结果公开前冻结，必要修复必须说明失效原因和受影响依赖，保留旧结果，不循环扩预算直到阳性。

传播主要端点是相同前两组触点与第三组大小条件下的下一触点集合对数评分。分叉层由FIT识别，不能用留出多样性造出合格层。STOP、传播时间、频带时间质心、能量、峰值、跨频带延迟、波形统计与coupling分开报告。上游只用计数/粗招募任务，count-only及recruitment-only冻结后做双向完整响应探针；raw latent与已训练任务功能读出的迁移分别评价，以独立原因反例检验“共享”的解释。

状态、完整固定历史、初始化表征、重新拟合常数和错时对照必须共用可比的读出预算与实际评分样本。对照对父基线的损害不能计入状态效应：在同一评分集上先聚合各臂损失，再以父基线封底。缺失错时配对记不可估，不把它们当成零损失。

## 发作关系

上游选择和全部状态freeze完成后才打开登记的发作结果。风险查询网格只依据查询时刻之前的记录覆盖与状态可用性生成，保留之后真实发作；严禁复用按未来纯间期目标筛过的H1查询集。先报告原始onset及8/24小时聚集敏感性分母，再报告有真实前史支持的不同发作。旧版本FIT/INNER/留出至少3/1/1次仅是风险可估性的最低门槛，不是确认级证据充分的标准。

早期ictal空间场和传播路径需要另有足够的逐触点训练、INNER和留出发作目标；风险可估不自动让空间任务可估。风险与距下次发作时间是相关结局，不当作两次独立发现。分母不足时明确NOT_ESTIMABLE；除非全训练流程正对照在预定最小效应、缺失率和簇分母下足够灵敏，否则不得称科学阴性或临床预测器。

## H3另行检验

三种生成模型都允许事件到来后更新**状态估计**：共同原因/无反馈、额外计数反馈、额外内容反馈。比较的是在控制共同状态和可测混杂后，解释未来独立观测是否仍需要反馈项；结果变量不得只用被该事件直接写入的observer。先用相同时间支持下的已知真值模拟校准假阳性、缺失和可辨识性，再考虑人类数据。观察性模型比较最多支持“需要反馈项的统计解释”；没有干预或额外识别条件，不升级为IED改变生理状态的因果证明。

## 验收与交付

一次性冻结主要端点、效果方向、最小有意义效应、比较家族和多重比较范围。先在保留真实记录缺口、事件密度、测量延迟和结局簇结构的模拟中跑完整训练—INNER选择—冻结迁移流程，再确定独立确认样本量。当前“把合成真因子直接交给读出”的窗口支持诊断只是乐观的条件灵敏度，不能替代这一步。

交付逐窗/逐发作配对分数、患者内与患者间不确定性、完整否定和不可估表、源码与输入版本审计、可再生图表及中文结论。审阅修复包可以完成，执行pilot可以完成；原始科学命题是否成立由这些独立检验决定。
