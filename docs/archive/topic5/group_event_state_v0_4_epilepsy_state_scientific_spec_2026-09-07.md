## 1. 研究定位与替代关系

**本项目以癫痫群体间期事件为观测基础，研究患者内可持续更新、具有病理预测意义的有效状态。动力学方法用于处理真实时间、记忆、噪声和观测更新；主要证据来自丰富历史的未来信息、状态对历史信息的保留、事件表达的条件变化，以及冻结状态与发作的联系。**

希望解释的现象是：同一个患者，在近期放电数量相近时，事件的参与触点、相对时序、频带和波形组织仍可能不同；这些差异是否持续，是否预示之后的病理表达，以及是否连接发作表达或易感性。

研究对象写为：

\[
p(Y_{\mathrm{future}}^{\mathrm{epilepsy}}\mid\mathcal H_t^{\mathrm{IED}},C_t)
\approx p_\theta(Y_{\mathrm{future}}^{\mathrm{epilepsy}}\mid s_t,C_t).
\]

这里的近似是待检验的任务内信息保留，不是充分统计量定理。\(\mathcal H_t\) 仅包含查询时真正可读的事件；\(C_t\) 是当时合法的背景与测量条件；\(s_t\) 是由历史持续更新的表示。我们不要求它等于真实脑状态，也不把任一潜坐标命名为兴奋性、抑制增益或吸引子距离。

v0.4 **替代 v0.3.13“下一窗口只做合成及 INNER 校准”的执行优先级**。v0.3 作为开发及方法诊断阶段归档；数值修复、有效的时间边界和已观察的反证继续有效，历史分数不改名为 v0.4 结果。新旧规定冲突时，本文件与配套工作包控制 v0.4；旧队列不能直接改版本号继续运行。

具体改变如下：

| v0.3 后期容易形成的要求 | v0.4 的规定及原因 |
|---|---|
| 校准完整后才允许开展癫痫分析 | 只阻断存在数值无效、泄漏或评分错误的依赖比较；局部有效的人体任务与针对性修复并行 |
| 两个真实 INNER 都阳性或都选非零步才可继续 | 保留两个时间段用于配方选择和稳定性诊断；不以结果阳性作研究准入条件 |
| 丰富状态、全部视图、全部时距同时过关 | 每条假设独立判读；局部支持有局部价值，也明确未支持部分 |
| 无输入长程演化、严格跨视图均为状态成立前提 | 持续观测下的跟踪是主问题；断观测预测、定向跨视图分别支持更强结论 |
| 全面恢复非线性、多尺度、时不变动力学 | 只有实际历史信息或任务差异提出具体问题时，才做对应结构比较 |
| 合成重复数、模型种类不断扩张 | 按准备声明的联系做已知阳性与无联系检查；阴性排除界限另需功效依据 |

## 2. v0.3 留下了什么证据

v0.3.12 的开发工作包可接收，核心科学闭环仍开放。丰富状态尚未稳定优于粗状态；细触点适配器普遍退回第 0 步；发作关联对病例支持与近期率匹配敏感。这些都是真实反证，不能因项目改名而略去。

同时，旧合成比较存在基线失准、初始化被计入“学习”和有限但极端的 NLL 等问题；因此旧人体非正结果不足以证明丰富事件没有状态信息。独立审阅中的消费者阳性小实验只说明特定适配器有读取已知信号的能力，不能替代完整 producer 的检验。

现有 E1125 留出段虽然跨约 66.5 小时、3 个日历日和 24 个小时层，稀疏评分仍只有 125 个一分钟数量目标、64 个非零空间/负荷包。时间跨度、实际观测曝光、目标数量和独立时间块须分开。已经反复查看的资料继续属于开发资料；以后获得新优化种子不恢复其独立确认身份。

因此本轮验收为：**接收 v0.3 开发归档；不接收已建立丰富病理状态，也不接收科学阴性；停止把完整 DSR 能力作为后续癫痫研究的门槛。**

## 3. 科学假设及其各自的证据

| 假设 | 决定性比较 | 可以支持什么 | 不能由此推出什么 |
|---|---|---|---|
| H1：持续间期预测状态 | 丰富与粗历史；持续丰富状态与充分拟合的近期历史/短记忆状态；合法未来目标 | 哪些事件信息对未来有用，持续表示保留了多少，以及实际记忆、预测时距 | 唯一脑状态、自治闭合、任意长自由运行 |
| H2a：状态与事件表达 | 同一事件前状态对细触点集合和形态的增量；随后单独做同前缀 continuation | 状态与哪些招募、时序、频带表达相联系 | 相对延迟就是因果传播；预测 STOP 就解释终止机制 |
| H2b：间期与发作联系 | 仅以间期任务训练并冻结的状态，对发作关联或早期空间表达的增量 | 在明确时间边界内，间期表示与发作共享可迁移信息 | 没有人时分母的风险预测、完整发作生成、单一标量统一所有发作属性 |
| H3：事件对后续变化的作用 | 共同驱动/历史模型与加入事件数量、内容作用的模型比较 | 观察性资料中的反馈样预测依赖 | IED 的生理因果反馈、RNN 更新等同生理作用 |
| 多尺度及非线性 | 已有信息基础上的少量记忆截断或结构对照 | 哪个端点需要更长历史或更复杂映射 | 若干真实独立慢过程、真实吸引子或全局时不变 |

H1 与 H2a 在首包一起进行。只要 producer 与评分可解释，立即冻结并接有数据支持的 H2b；不等待 H1 显著。H3 独立保留，但首包不新增反馈模型。

## 4. 输入与状态：保留癫痫特异性

主要信息单元仍是**完整群体 IED**：事件时间、参与/未参与触点、触点相对时序及同步组、频带与跨频带组织、可用波形描述。分钟包只用于计算和曝光管理，不能把 P_marks 悄悄替换成率、负荷和少数能量比。

首包复用已验证的丰富事件提取与编码接口，但列出字段覆盖表：原生波形、波形描述量、频谱摘要和事件内时序不是同一种输入。未进入模型的原生波形不能算已检验其价值。缺失频带、未参与触点、无事件和无观测分别编码。触点顺序、参与 mask 与几何依照项目合同核对。

分解为患者相对稳定的组织与时变表达：FIT 内得到的触点字典、几何和模板提供 trait；状态描述这些组织当前更容易以何种方式出现。trait 不能用待预测时段重新拟合。此分工不宣称患者网络恒定。

保留 q–f–g 原型作为工作模型：事件编码 → 根据真实经过时间推进和观测更新 → 未来表达读出。首包固定当前可用容量，不预设扩 latent、增加时间尺度或重写滤波器。如果保留概率滤波，已有均值/协方差数值正确性不能退化；但无需为全部神经生理过程建立精确后验。

状态更新的可用性按 **release time**；事件内部顺序及真实间隔按 **occurrence time**。首包固定采用当前 `infer_asof` 的查询时重放：用当前权重，从合法 episode 起点重放截至查询已发布的历史，再推进到查询时刻。首包不另实现另一套迟到观测修正。批量发布不能被解释为同时发生的生理冲击。

### 4.1 在线记忆与唯一导出合同

现有 [model.py](../../../src/topic5_group_event_state/v0312/model.py) / [engine.py](../../../src/topic5_group_event_state/v0312/engine.py) 中，在线工作记忆含推断器 GRU `c`（64 维）、生成状态 `m`（24 维）与 `P`（24×24）、事件编码及时间/缺测信息。**唯一导出对象沿用 `QueryState`：Q_t=(m_t,P_t,合法时间元数据)**。推断器 `c` 和中间事件 GRU 不导出给消费者。

| 使用方 | 固定读取方式 | 含义 |
|---|---|---|
| H1 | 从同一个 Q_t 的后验采样，经 f 推进、g 读出 | 后验预测；P 是预测不确定性的一部分 |
| H2a-A/B 的可学习状态输入 | 只读 m_t，24 维；FIT 内标准化 | 后验均值投影的消费者，不偷偷追加 c 或 P 对角线 |
| S-A | 从同一个 Q_t 经冻结 g 得到 §7 定义的功能预测量 | 固定功能坐标，不从 latent 中事后挑轴 |
| S-B | 与 H2a-A 相同的 m_t 输入、同一冻结间期触点 head | 跨测量的描述性空间对应 |
| 共同 C | 合法时钟、测量支持与确定性记录计时信息，字段表单列 | 元数据不能仅给状态臂使用 |

“同一状态”指同一 producer、同一导出函数与其固定投影；不宣称各消费者输入张量相同或 Q_t 是充分统计量。时间戳、scaler、读取分量、维度及 producer 身份写入导出表。B 系列保留自己的历史参考接口，不能冒充 Q_t。

模型状态分三类：**静态 trait；未训练或 FIT 初始化后固定、但由输入驱动的表示；学习后的表示**。选第 0 步不证明学习成功，也不自动等于静态 trait；固定随机递归表示仍可能随历史变化。是否退化为常数、消费者是否退化为截距，分别用实际状态变化和 head 权重判定，不互相替代。

## 5. 最小比较与归因

背景基线为 FIT trait + 合法时钟/测量条件，简称 C。共同字段固定包括日内 sin/cos、记录段年龄、距可用临床 reset 的时间、count/marks 发布支持年龄、可读曝光与缺失标志；时间量作 FIT 冻结的 log1p/标准化。现有 head 主要只接时钟，**G0 必须把可用确定性计时线索以相同接口给五臂和对应消费者**，不能仅在报告中声称已控制。不存在的字段标缺失，不猜测；离线才知道的临床 reset 只支持离线条件分析。H 是消费者额外的显式近期历史，不并入 C 后隐去其作用。第一包只用以下比较族，不做架构排行榜。

| 比较族 | 固定内容 | 目的 |
|---|---|---|
| B_stats / B_marks：历史参考 | 相同真实时间支持、相同目标与读出机会；分别读粗统计和丰富事件历史 | 在一种有拟合能力的参考中检验丰富输入的增量；失败不等于所有可能模型都不存在信息 |
| S_stats / S_marks：持续状态 | 同一 q–f–g 容量和训练规则，只改变合法输入 | 检验当前持续模型是否保留丰富信息 |
| S_marks-short：短历史重拟合 | 与 S_marks 相同架构，训练及评价用 G0 按支持冻结的 H_short；本次 E1125 使用 2 小时 | 检验较早历史是否有用；避免只在测试时 RESET 造成分布变化 |
| C 与冻结消费者的 C+history / C+state / C+history+state | 相同 FIT/验证支持和消费者预算 | 区分 trait、近期历史和状态的贡献；允许状态与显式历史互补 |

P_stats 保留率、曝光、粗空间等既定字段；P_marks 在这些共同字段上增加事件内容。主状态与历史参考读取从合法 episode 起点至查询时真正可读的历史；持续臂沿用 `history_hours=None`。**现有 `grad_hours=2` 是梯度计算范围，不是前向历史上限**，不能把主状态暗改为每个查询重置的两小时 embedding。冻结参数后应核对连续重放与相同历史的查询重放一致，状态不因评分分批而重置。技术缺测、临床 reset 与人工隐藏遵守各自既定规则；不能穿过不合法 gap 造历史。

历史参考可保留固定时间核，但必须报告核的覆盖与衰减，并拟合其编码/读出；它不是所有可能历史预测器的上界。冻结消费者中现有“近期历史”使用两小时，这与 producer 的完整合法历史分别登记。

### 5.1 在拟合前冻结短历史，而不是训练后解释空窗

对每个预定 query 和候选 H∈{30,120} 分钟，计算 `[t−H,t]` 与合法 episode、真实可观察区间、截至 t 已发布字段支持的交集时长，除以 H 得到 coverage。分别记录 count 与必要 marks 的支持末端及年龄、最后一条 IED 的发生年龄；**无 IED 不等于无观测**。充分曝光且零 IED是有效安静信息；部分曝光、整段未发布、count 已可读而 marks 未发布分开标记。

窗口选择只读两个 INNER 预登记主时距 query 的时间/支持元数据，不用损失、未来形态或发作效果。固定支持规则：若两个 INNER 各有至少 80% 的 query 同时满足 episode 年龄≥H、共同已发布 coverage≥0.5、支持末端年龄≤H/2，则可将 H=30 分钟作为主短臂；否则以 H=120 分钟**替换**，不增第六臂。0.5/80% 是预先写明的开发支持规则，不是生物学或显著性阈值。两小时也不足时仍报告其局限，只限制历史归因，不阻断其他比较。

因此首包 **H_short=120 分钟**；30 分钟只交付时延/可用性诊断，不再固定训练三次。INNER0 的两小时支持仍弱，不能写成“两小时资格已全面通过”。当前 packets 只有共同 block release；在没有独立字段 release 证据前，count 与 marks 都使用这个保守支持，不能臆造更早的 count 发布时间。G0 若修复了训练截止或元数据，则先重新输出此表，保持相同选择规则并在拟合前冻结。

历史效果同时报告全配对支持和预定 `memory_support`：短窗 coverage≥0.5、末端年龄≤H_short/2，且短窗以前另有至少 30 分钟合法已发布曝光；按较早/近期实际事件数列出分层。没有较早事件的安静历史也保留，但不能据此声称整合了多条较早 IED。短、长臂必须读取同一批近期可读事件与缺失信息；主差值不使用测试时 RESET 代替短历史重拟合。

### 5.2 五个固定差值及解释范围

令 R 为同一目标、同一有效分量和同一物理支持上的损失，越小越好。以下差值都以正值表示右侧更好；分别给分子、分母、置信区间，不合成一个 rich-state 总分。

| 名称 | 差值 | 直接解释 |
|---|---|---|
| 丰富历史输入增量 | R(B_stats)−R(B_marks) | 当前历史学习程序可利用的额外内容 |
| 当前状态模型的 rich 增量 | R(S_stats)−R(S_marks) | 当前状态模型对额外内容的利用 |
| 表示保留 | R(B_marks)−R(S_marks) | 相对当前富历史参考的能力保留或损失，不是对全部信息量的测定 |
| 较早历史贡献 | R(S_marks-short)−R(S_marks) | 在 memory_support 上增加较早历史的作用，含较早率/曝光/粗空间 |
| 冻结状态的条件增量 | R(C+H)−R(C+H+S) | 显式历史和共同条件以外的补充信息 |

rich 胜过 stats、长历史胜过短历史，**不自动证明较早 rich 内容有贡献**：`Y=较早率 X+近期形态 M+噪声` 就能同时产生这两个结果，较早形态可以完全无用。首包只接收两种信息各自有用。只有准备声称较早额外 marks 有作用时，下一包才做一次训练匹配比较：保留较早 count/曝光/粗空间和相同近期 rich，仅移除较早额外 marks；本轮不增加交叉矩阵。

### 5.3 正确时刻诊断

首包在 **H2a-A 的 C+H+S 条件细身份读出**做一次冻结状态替换；固定消费者、recipient 的 C/H、目标、真实条件 K/community，只将 Q 的状态槽换为同患者 FIT 中另一合法时刻的 Q（head 实际只读 m）。原时刻与替换必须在相同可匹配事件上比较，报告 `R(wrong_time)−R(correct_time)`。

供体提前至少 4 小时、日内时钟差≤2 小时、字段支持年龄差≤10 分钟、两小时曝光比例差≤0.2；记录/临床段年龄用 log1p 差≤log(2) 匹配。只从同 producer/scaler 的 FIT 合法供体中按时间距离最近确定，不看目标、发作效果或预测分数，不自动放宽匹配。报告可匹配比例、供体重用、状态—显式历史不协调与分布外距离。无供体则局部不可估。它检验时间对应，不能单独证明历史整合或因果作用，也不是全局准入门。

状态不必严格胜过富历史参考才有表示价值。可报告预测差及状态压缩成本；声称“不劣”则需事先给出可接受损失界限与相应区间，不能把差异不显著写成等效。

## 6. H1 与 H2a 的首包读出

### 6.1 H1：未来病理表达

为保留与 v0.3 的可比性，首包沿用 **W=1 分钟，h=1/5/30/120 分钟，目标区间 [t+h−W,t+h)**。主时距固定为 30 分钟；其余用于描述时距差异，不取四档最优值作为主结果。它们是未来一小段内的事件，不能写成未来 h 分钟累计事件。

科学主读出是事件组织：给定事件发生的条件形态，以及给定窗口总参与触点次数的 shaft 组成；后者当前是 Multinomial，其条件不是 IED 数量。数量和负荷同时报告。形态按 band_ratio、signed_xlag、delay_iqr 三族逐分量报告。零事件窗参与数量评分，条件形态不适用，不能填 0 或剔除整个数量目标。

**v0.4 主平均效果按物理 query—target 窗口等权**。每个事件先在同一形态族的有效标量分量内平均 NLL，再对可用形态族等权，再在该窗口内对有有效形态的事件等权；最后对有形态支持的窗口等权。所有模型使用同一原始有效 mask，不用预测值决定是否纳入。逐族结果同时输出，不能以字段更多获得更多事件权重。

设 d_bi 为上述事件级配对增量，n_b 是窗口中可评分事件数，则主读出为 `Δ_window=mean_{b:n_b>0}(mean_i d_bi)`；配套 `Δ_event=Σ_bΣ_i d_bi/Σ_b n_b`。前者代表一个有可评分事件的查询窗，后者代表一个可评分事件。两者符号不同照实解释，不择优。缺失族/标量的数量、仅部分 marks 的事件数与窗口数单列；必要时给全字段共同支持的描述性敏感性。

上述事件级分数使用 **先按每个事件/标量对预测路径边缘化，再平均损失**：`−log mean_s p(y_bik | z_s)`。它是条件边缘预测评分，不是整包联合似然。现有 `objective.view_log_probs` 先把整包事件/分量 logp 相加再混合、以有效分量总数归一；该旧分数保留为 `legacy_packet_joint_component_score`，不能直接除以事件数改名成新主分数。G0 要实现所需的逐事件/逐分量输出并与手工小例核对；无需新增模型或损失头。各种视图分别定义的混合不自动组成共享潜变量下的完整联合分布。

数量按所有有效窗口等权；空间与负荷按各自有定义窗口等权。平均效果的权重与不确定性单位分开：时间块用于处理依赖，不能改变或代替窗口/事件估计量。

首包是开发性证据包：给出各预定端点的配对差、区间和实际支持，不通过挑选最优视图给总体阳性标签。后续独立确认前，从科学问题与开发资料锁定一个主要组织端点及效应界限；多个确认端点须控制多重比较。

如果一分钟目标支持过稀，只可在读新评分前另登记较宽聚合窗及其独立评分定义，保留原端点；不能把增加的窗口宽度伪装为样本增多。首包不为新聚合似然增加一套模型。沿用的发作/发作后目标排除意味着 H1 评价的是合格间期范围内的表达；未来是否发作只能用于登记该分析范围，不能进入预测输入，也不能将这一条件分析称为所有未来时段的预测。

### 6.2 H2a-A：事件前状态与细触点集合

对每个待评事件，使用其发生前最后一个登记分钟查询 q_i 的 Q(q_i)，只读取 release≤q_i 的历史。这是现有一分钟适配器的保守接口，**不冒充恰在 t_i− 用尽全部可用信息的状态**；列出 q_i、t_i、两者间隔及发布支持年龄。主事件集合仍按既有一分钟目标选择，事件时间条件可用于已知时钟，当前事件参与、波形和最终延迟不能回流到状态。比较 C、C+history、C+state、C+history+state；H2a 主损失以事件等权，时间块用于不确定性。

当前消费者给定 K 或 community 数量时，任务名称必须写成“**给定事件规模/粗组成的细身份预测**”。这些是评分时提供的条件，不意味着事件前已知规模；不能称完整触点集合的无条件前推预测。集合 NLL 按事件汇总，触点不是独立重复。

首包固定当前 `conditional_set_lp` 的独立条件 head 语义：每个 community c 给定 K_c，`p(A_c|K_c,m,C,H)=exp(Σ_{j∈A_c}ℓ_j)/e_{K_c}(exp ℓ_c)`，其中 e_K 是 K 阶基本对称多项式；各 community 的条件 logp 相加。K_c=0 或全集是确定性项，概率为 1；全部 community 都确定的事件不算有效身份单位。小触点集枚举验证归一化。此 head 直接使用 m，**不是先从 count/shape 联合模型采样再条件化**，因此不引入虚构的后验路径权重。以后若改为共享潜变量联合条件分布，必须计算 `Σ_s p(K|z_s)p(A|K,z_s)/Σ_s p(K|z_s)`，不能沿用无条件等权路径。全宇宙 K 分数仍是单独标注的次要读出。

若细身份无增量而未来形态有增量，可支持形态状态，但不能支持细空间复用；反之亦然。读出选第 0 步须显示对应基线、权重变化及是否只剩 trait，不得把若干相同退化读出算成多项独立反证。

普通冻结迁移允许 producer 读取该视图合法的过去信息，回答表示能否复用。只有要声称其他视图包含目标视图的信息时，才追加定向删除该视图全部等价输入及 producer 损失的实验；这是更强的问题，不是普通迁移的合格前提。两种结果都不足以证明唯一共同生理原因。

### 6.3 H2a-B：同前缀 continuation

G0 即核查一个已有 continuation 消费者的接口；S_marks 首种子冻结后可与 H2a-A 独立运行，不等待其他主臂。输入分为固定事件前 Q 的 m 投影与该事件真实已见前缀；同一前缀、同一候选集合比较有/无状态，分别评价下一触点/同步组与 STOP。H2a-A 完成不能替代本项完成。

不得使用完整事件后才能算出的最终 K、归一化 rank、全事件波形、后缀统计或事件结束时间作为前缀输入。teacher-forced 一步评价与自由 continuation 分开；只能运行前者时如实报告。若现有前缀并非可观测前缀，局部标记不可运行，不阻断 H1、H2a-A 或 H2b。

## 7. H2b：同一份冻结间期状态尽早连接发作

producer 的训练、超参数和 checkpoint 仅由间期任务决定。任何发作标签、发作关联强弱和空间匹配结果都不能反向选择 producer。所有消费者使用同一版本冻结状态；消费者自身的训练边界另行记录。

**S-A 关联**沿用主窗 [−2h,−30min)、次窗 [−30min,−5min)。固定 query 时刻的功能坐标 Ψ(Q_t,C_t)：shaft softmax 概率的后验均值、每个 band_ratio 与 signed_xlag 的预测均值、IQR 零点概率及正值标准化 log-IQR 的条件预测均值。正值均值按 `(1−p0)` 对路径加权后归一；不能对混合条件分布直接平均各路径的条件均值。只用当前 Q 和合法 C，**不需要任何未来真实事件 K、参与或形态**。

各坐标减去同一 query/C、同一 MC 噪声下的 FIT 参考状态分布预测，得到状态依赖功能增量；该参考只是基准分布，不称静态脑状态。坐标中心、尺度和常量维 mask 均由 FIT 冻结。S-A 主输出是每个病例窗相对匹配控制的逐坐标有符号均值差；整体描述量是先在空间族及各形态族内平均平方标准化差，再以空间 1/2、三个可用形态族共 1/2 加权后开方。整体量天然非负，必须与逐分量方向和匹配参照一起解释，不能以“大于零”判定关联阳性，不挑最大 latent 轴。

现有 [seizure.py](../../../src/topic5_group_event_state/v0312/seizure.py) 主要输出 raw log-rate、相对 FIT 参考的 log-rate 增量及平均后验方差；它们保留为预定辅助结果，**组织功能坐标需在 G0 接入同一个冻结 readout**，不能称现有率曲线已经完成了组织状态关联。先按记录条件、时钟、字段支持年龄、曝光、记录/临床段年龄匹配，再给加入可读近期率的条件分析；统一使用 H_short 的率窗，30 分钟率仅作支持充分时的诊断。先给各自全部支持，再给共同病例和完全相同病例查询，避免支持变化冒充率混杂。病例内 query 等权，发作簇层汇总；稀少发作不制造群体显著性，伪发作仅作描述性参照。

**S-B 默认只做冻结间期空间对应**：用 EEG 起点前至少 5 分钟的最后合法分钟 query，取同一个 m/C 和可读两小时触点历史，输入在间期 FIT/验证上训练并冻结的 H2a-A head，得到触点 logits；与临床起点 0–10 秒、CAR、1–150 Hz baseline robust-z 宽带激活相比较。通过 seizure_id、EEG/clinical 起点和通道名连接，禁止把连续宽带能量代入 IED 集合似然。

源码 [spatial_transfer.py](../../../src/topic5_group_event_state/v0312/spatial_transfer.py) 当前计算全触点 Spearman。条件 K_c head 的 community 间共同截距不由条件似然识别，因此 v0.4 主指标固定为**每个 community 内、相同有效触点的 Spearman，再对合格 community 等权**；每组至少 3 个触点，预测或目标为常数则不定义。C、C+H、C+S、C+H+S 使用相同触点/组支持，给病例配对差；全触点 Spearman 仅保留作旧口径辅助，并注明跨组偏置限制。该映射使用连续目标的排序，不宣称概率预测或 EEG 起点传播。

首包不新增发作监督 head。若以后用发作标签学习连续空间映射，必须独立登记为监督迁移，按发作簇留出并重做该 fold 的 scaler；单簇只允许冻结映射或描述。监督迁移和当前冻结对应分别验收。

**S-C 风险**仅在完整可观察人时、事件标注和合法时间验证均具备时运行；报告基础率、概率校准、敏感度及报警时间。缺分母只限制风险。S-A/S-B 不能升格为风险，但可以独立支持或反驳间期—发作联系。

producer 早于待评发作冻结且输入因果可读，才有前推含义；其他情况保留回顾性标签。E1125 既有发作已经用于开发，不作为全新确认数据。

## 8. 睡眠、节律、状态持续性与更强解释

所有比较先包含必要的测量条件和时钟基线。真实可得的睡眠/觉醒、药物或记录条件可形成附加条件分析，但缺失标签不能由时钟猜造。前推输入只用查询时可读协变量及已知时钟；未来真实睡眠仅可作事后分层，不能冒充预知协变量。分别报告：IED 历史能否读出有用的未来病理表达；在已测睡眠、近期率等因素之外是否还有增量。后一个结论更强，前一个不因此失效。

持续观测条件下，每到新查询可使用此前已发布的新事件；固定起点的断观测预测则全程禁止未来更新。两类结果分开，既不让未来事件泄漏进固定起点预测，也不要求跟踪状态必须长时间脱离观测。

先按 §5.1 冻结主短臂，本次是 2 小时，与持续历史比较；30 分钟保留为可用性诊断。报告实际前向历史、可读曝光和较早/近期事件数。较早 marks、8 小时及结构问题均在首包后按具体缺口定向登记，不追加默认拟合矩阵。

非线性同样按问题触发：区分非线性观测读出与非线性状态演化。固定参数在前推时间上有用，只支持该患者、记录条件与时间范围内的预测迁移，不证明全局时不变。

H3 的事件作用模型必须面对共同驱动、观测更新、率历史、睡眠及测量变化等替代解释。没有干预或额外识别条件，最多使用“反馈样预测依赖”。H3 不决定 H1/H2 是否可以成立。

### 9.2 条件零联系与组织阳性：两种任务足够

条件零联系要求在**模型真正可读的条件**下成立：

\[
Y_{\rm future}\perp H_{\rm extra\ marks}\mid H_{\rm stats}^{\rm readable},C^{\rm readable}.
\]

保留率、曝光、延迟和合法背景中的预测性；未来目标生成直接使用这个可读条件集合，再加独立噪声。extra marks 不得通过不可读共同驱动、未来 missingness 或发布机制提供遗漏的目标信息。只在生成器隐藏 U 给定时独立不合格：若 U 同时影响 marks 和未来目标、而粗历史看不到 U，rich 的改善是合法信息，不是假阳性。零任务的预期为 B/S 的额外 marks 增量为零；它仍可以有粗历史及时间记忆。

组织阳性在相同可读粗条件和近期 rich 下，让**短窗以前的一组已发布事件内容的固定汇总**影响未来 band_ratio 或 signed_xlag；近期 marks 与该汇总独立，粗条件不能重构它。查询选择与发布调度先固定，并确保全历史看得到而 H_short 看不到这组内容。这样一个任务同时校准 rich 输入比较与较早历史比较；提供使用真实合法旧汇总的简单参考。若实际实现只注入近期形态可预测性，只能标为 rich 输入阳性，不能声称已校准长历史。

效应、时间支持、全部随机流及预期比较写入生成器合同。阳性中的标准化旧内容系数首包固定为 1、独立目标噪声标准差固定为 1，旧汇总在 FIT 标准化；零任务对应系数为 0，其他可读背景机制相同。注入如何映射到原始 band/xlag 字段须可复核。首包各 3 个独立数据实现，每个固定一个优化种子；不以这 3 个实现估计 5% 错误率或排除小效应。重复、数值修复及消费者检查的实际拟合数在工作包预算中单列。

### 9.3 训练、截止和运行接口

保留 `grad_hours=2`，不扩八小时反传。每次优化更新，用**当前参数**无梯度重建较早前缀，再对登记后段展开梯度；所有携带历史的 m/P/c、事件内记忆及历史核都遵守边界。评分完整重放。首包不长期携带旧参数产生的 hidden 跨更新使用；若未来改为近似携带，需要另登记近似和影响。截断反传涉及梯度偏差，不定义前向记忆长度。[Aicher et al., 2020](https://proceedings.mlr.press/v115/aicher20a.html)

| 接口 | 首包必须实现/核对的规则 |
|---|---|
| 训练截止 | 每个 INNER/FIT 的标签、scaler、模板、统计量都满足实际可用时间及全部原始依赖支持≤截止；当前 `train_packet` 按包结束初筛不足以单独证明 release 合法。之后发布的标签只用于事后评分，不能提前参与拟合 |
| 迟到事件 | 只采用 §4 的 occurrence 顺序 as-of 重放；观测支持末端与最后 IED 分开 |
| 多时距 | 所有预测来自同一 Q 的只读副本；可复用一条固定公共噪声轨迹的多个截点，但 h 的顺序/子集不得修改在线状态或改变已定义分布。若独立 rollout，则各自从 Q 拷贝，不从上一个终点重新加 h |
| 随机一致性 | m/P/c 的确定性重放按预定浮点容差比较；路径按物理 query、相对时间与 eval_seed 定义公共随机流。批大小、h 顺序变化不改变同一随机流结果；独立抽样只比较 MC 精度，不要求逐位相同 |
| 缓存 | 仅冻结且同权重/scaler/split/输入边界的查询可复用；更新参数后失效，不能用 stale hidden 假称当前权重完整重放 |
| reset 与共同条件 | 技术缺测、临床 reset、人工隐藏分别登记；临床时刻是否在当时可知单列。C 对照获得同等的确定性计时和支持信息 |
| 集合概率 | 独立条件 head 按 §6.2 枚举核对；跨 community 偏置与联合模型条件路径权重不能混淆 |

INNER 配方按工作包固定为首种子选一次、三个种子最终重拟合；不要求两个 INNER 都改善。报告初始、选中、末段损失、尺度和实际参数变化。选第 0 步按 §4.1 分类，不阻断独立有效任务。

NaN、时间泄漏、单位错误、无效概率或未拟合基线制造的巨额增量须修复对应比较。有限但极端 NLL 拆开均值残差与尺度/尾部失准，不剪 final score。若必须改为点预测，所有比较臂在读新 OUTER 效果前统一登记评分与选模，局部声明均值信息；不能临时按 NLL/MSE 谁阳性选择。修复已读开发资料不会恢复确认身份。每 GPU 一训练进程，复用恢复修复，不开额外大型压力测试。

## 10. 分项验收、继续与停止

验收报告分开计算有效性与科学证据；失败、不可估及未运行项目都保留，不用一个总完成率代替科学结论。

| 观察结果 | 当前解释 | 下一步 |
|---|---|---|
| 丰富参考有增量，持续状态没有 | 当前状态模型未保留可读信息，或其训练/读出不足 | 只针对已定位的信息损失改一次模型；不先扩患者或结构矩阵 |
| 持续状态有预测价值，但没有长于近期的贡献 | 有用的近期表达表示 | 保留局部价值，暂不称慢状态；核查可读历史后再决定是否研究更长记忆 |
| H1 某形态/组织端点支持，H2a 或 H2b 不支持 | 有局部间期状态，跨任务边界仍在 | 接收局部结论，查对应消费者/支持，不要求所有任务一起阳性 |
| H2b 有冻结增量，H1 主端点不支持 | 可能有任务特异信息，不能倒选 producer | 保留探索性联系，在独立发作支持上检验；不能倒推出完整 H1 |
| 状态与富历史接近、并保留长期贡献 | 可用的持续压缩表示候选 | 报告差值与成本；不劣/等效另按事前界限验证 |
| 只在 S-ID 或更新跟踪时有效 | 回顾性识别或需要新观测的跟踪信息 | 保留对应价值，不能写成固定起点的自主前推 |
| 所有合法丰富比较均无增量，区间宽或正对照能力不足 | 当前证据不足 | 停止无目标调参；根据具体信息年龄/样本限制决定一次定向补充 |
| 合格诊断和独立支持下，区间排除预定有意义增量 | 所选患者、测量、端点和效应范围内的受限阴性 | 接收限定阴性；停止该范围内的模型扩张，不推广为癫痫不存在有效状态 |

首包完成后必须回到三个问题：**丰富内容是否带来未来信息；持续状态保留了哪些信息及多长历史；同一冻结状态连接了哪些事件表达或发作现象。** 如果新增工作不能改变其中任一判断，就不列为下一阶段必须实验。

后续 v0.4 分为两类有限工作包。第一类是**独立确认**：从完整首包中锁定值得确认的具体端点、时间范围与效应界限，再按数据资格选择未用于该方案开发的患者或新时间段，完整复用 producer—消费者链。选患者不看效果；患者是推广到人群的统计单位，患者内以时间块/发作簇处理依赖。局部端点有充分理由即可进入确认，不要求所有 H1/H2 同时阳性。第二类是**解释已有发现**：一次只解决一个具体缺口，例如历史跨度、读出与演化的非线性分工，或定向跨视图；H3 另立可识别的反馈问题。两类工作都不自动扩成患者×latent×尺度×结构矩阵。

## 11. 文献如何约束这次调整

以下来源与前轮[文献审阅和设计检验](group_event_state_v0_3_12_independent_scientific_review_2026-09-07.md)共同构成依据；这次不另设方法综述任务。

- **Diamond et al., Brain, 2023**：人类 IED 的时空传播组织与致痫来源存在联系，支持认真使用事件内部结构。不能由该研究直接推出本项目每条相对延迟都是真实传播，或其组织一定具有跨事件慢状态。[原始研究](https://pubmed.ncbi.nlm.nih.gov/36729683/)
- **Fouad et al., Brain Communications, 2022**：11 名 Epilepsiae 患者的 IED 率与形态受睡眠阶段和脑区共同调制，不同脑区并非统一方向。这支持丰富观测作为状态读出，也要求将总的表达信息与睡眠条件外增量分开。[原始研究](https://academic.oup.com/braincomms/article/4/5/fcac183/6645731)
- **Baud et al., Nature Communications, 2018**：长期记录中的间期活动节律与发作发生相联系，为 H2b 提供动机；其长期时间支持与本项目短期住院记录不同，不能据此预定必须识别多日慢变量。[原始研究](https://www.nature.com/articles/s41467-017-02577-y)
- **Proix et al., Lancet Neurology, 2021**：利用长期记录进行按时间验证的发作预测，说明风险问题需要完整时间支持和专门验证；这些要求不应阻断已有支持的关联或空间表达研究。[原始研究](https://pubmed.ncbi.nlm.nih.gov/33341149/)
- **Schroeder et al., Brain Communications, 2023**：不同发作属性与不同时间过程相关，支持分开评价发作发生及表达，避免要求一个标量统一所有现象。[原始研究](https://academic.oup.com/braincomms/article/5/5/fcad205/7226358)
- **Cawley & Talbot, JMLR, 2010**：有限验证资料上的选模本身也可能过拟合；固定新配方与增加种子不恢复 E1125 的独立确认身份。[原始研究](https://jmlr.org/papers/v11/cawley10a.html)

这轮方案检查得到三条修订：完整 DSR 不是原目标的必要条件；单一 embedding 阳性也不足以说明持续状态；针对性校准应保护结论，而不成为研究癫痫问题之前的无限任务。以上是结合文献和现有审阅作出的设计判断，**不是 v0.4 实验验证结果**。
