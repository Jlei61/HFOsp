# v0.3.9 冻结迁移的固定执行定义

本页在正式迁移adapter拟合前冻结。上游每个患者、F/L/N家族、H=0.5/8h和seed分别只按joint任务2h提前量的INNER损失选择两个预设LR之一，平局取较小LR。所有这些状态均保留，不以H1阳性筛选。count-only/recruitment-only采用各患者joint H8在三个seed平均INNER损失最小的家族，之后仍由各自任务INNER选择LR；不能看传播或发作选择家族。

新触点decoder复用成熟anatomy-only tissue RNN，重新使用新测量算子的pre20%校准事件拟合。三seed按该校准段validation的next BCE + STOP BCE选择，固定之后不再改变。E1125的HR11无坐标，decoder及其空间评分限于其余8个触点；E1096为6个、E253为9个。不能把旧触点权重按位置接到新触点。

每个间期事件只配对一次：onset之前最近的有效5分钟状态anchor。当前事件的原始块尚未发布，因此它及其后缀不能先写进该状态。触点prefix是完成测量后构造的结构条件，不声称真实系统可以即时读取这个离线prefix。

主传播评分固定为：观察前两个完整tied groups后，在已知第三组大小k的条件下，预测第三组触点集合。对剩余触点所有大小为k的集合精确归一化，使用无序集合的负对数概率；不再把单触点softmax平均称为完整集合概率。严格same-prefix分叉仅由FIT识别：完全相同前两组身份与第三组大小，至少5个FIT事件且至少2种不同第三组集合。留出数据不能创造合格分叉。全体有第三组的评分和STOP另外报告，不拼成重复独立发现。

冻结decoder给出前两组后的logits。先在FIT重新拟合每触点/STOP截距，再拟合并冻结背景adapter；随后分别拟合state、完整固定历史、同初始化未学习状态、已训练任务的功能读出和常数状态残差。adapter为8单元GELU读出，输出初始为零；同维度对照采用相同初始化和抽样seed。静态/背景最多400步、LR=.003；每个状态对照最多600步、LR=.001；AdamW、weight_decay=1e-4、clip=2、batch=128，每25步INNER验证，耐心分别10/12次，初始回退合法。FIT每次均匀抽anchor，再从该anchor抽一个事件。报告按anchor先平均，再展示真实时间块，事件数不冒充独立样本数。

收益同时相对冻结背景与重新拟合常数封底；单独记录对照比其父基线差的情况。错时对照在相同prefix及组大小下选择至少2小时错开的同分区状态，并排除两者之间有发作的配对，背景保留正确时刻。缺少合格配对时记不可估。

未训练的传播延迟、频带、波形统计、触点coupling采用相同的低容量正则读出；FIT标准化和预设ridge强度0.01/0.1/1/10，INNER仅选择冻结后的读出，不能改变上游。raw latent与上游实际训练任务的功能读出分别评价；原始坐标中保留其他独立原因，不等于共同病理因子。recruitment-only另做未来负荷的冻结交叉探针，不能以联合训练的两个头替代该检验。

H2b仅在上游全部冻结后评价。先逐患者报告FIT/INNER/留出发作及簇分母，再对可估的全部登记状态做冻结风险读出；事件/风险标签不能反选上游。缺少训练或验证发作时记NOT_ESTIMABLE，不扩开已有development/sealed，也不将其解释为病理阴性。

风险分母沿用v0.3.7最低资格：FIT至少3次、INNER至少1次、SELECTION至少1次不同发作；这只是必要条件，之后还需合格的前发作覆盖和真正的风险查询集。H1的anchor曾按未来30分钟纯间期目标筛选，不能直接拿它们训练风险读出，否则会提前删去阳性。可估时必须重建只依赖查询时刻之前覆盖的风险网格，保留随后的发作标签；若原始分区发作数已低于最低门槛，则只报告分母上界和NOT_ESTIMABLE，不拟合失真的风险模型。

背景修复后，正式人体及迁移根目录更新为`/data/hfosp_group_event_state_v0_3_9_transition_transfer_background_repaired`。本页的模型、预算、端点和INNER选择规则保持不变，旧背景下的家族选择失效，不能沿用。

正式迁移前补充缺失分量规则：每个响应家族仅保留至少3个不同FIT anchor实际测得的分量，然后在这些分量完整的行上评分；报告保留的原始分量索引。E253的采样率不支持最高频带，不能因这一个频带缺失而把其余四个频带和六个可用频带对一起判为不可估。`band_centroid`是各频带的**时间质心**，不是主频；能量、峰值和跨频带时间差分别报告。

两个单视图都做对向未来探针：count-only冻结后预测未来粗招募完整向量，recruitment-only冻结后预测未来log1p(count)。招募只在非零事件的有效窗口定义，计数包含真正零事件窗口；不对招募向量先取可能抵消信息的均值。真实损失梯度审计同样按各自任务的目标可估性选取留出窗口。
