## 1. 最初的问题与现在的位置

原始 [v0.1 科学 spec](group_event_state_v0_1_scientific_spec_2026-09-01.md) 问的是：能否从完整间期群体事件序列中识别一个持续、可预测、可跨任务使用的病理网络状态。H1 要区分历史状态与最近一次事件、近期统计；H2a 要说明状态与事件表达的联系；H2b 用冻结的间期表示检验发作迁移；H3 检验事件是否对未来状态有额外作用。[v0.2 H3 合同](group_event_state_v0_2_h3_spec_plan_2026-09-01.md) 已明确 observer 更新不是生理反馈，人体模型比较最多支持 feedback-like predictive dependence。

[v0.3.11 rich-event spec](group_event_state_v0_3_11_rich_event_state_execution_spec_2026-09-06.md) 和 [v0.3.12 合同](group_event_state_v0_3_12_observable_state_validation_spec_2026-09-06.md) 把承重主线恢复为：丰富事件信息 → 有预测价值的表示 → 同一冻结表示的条件形态／细空间及发作读出。非线性和多时间尺度用于解释已存在的状态，不是先验必须获得的答案。

本轮在设计上基本回到这个方向：P_stats/P_marks、真实 release、统一查询状态、同目标评分和冻结消费者都有实际实现。把第一轮固定在 E1125、I-L-G1 是合理缩小范围。没有运行 H3 或结构矩阵也不是偷偷修改问题，只要如实标未检验。

但实际回答仍集中在“这一套延迟测量、状态模型和训练配方的前推表现不好”，距离“患者是否存在可复用状态”还有仪器鉴别力这一步。若接下来仅继续调优化器、延长日志、统计正种子，就会让校准工作逐渐替代科学问题。

## 2. 会改变科学判断的具体发现

### 2.1 合成正号里包括完全未学习的模型

独立读取原 card：realization 904 的 morphology、identity、zero 三个世界，两输入臂合计六个模型全部 `selected_updates=0`，运行 1000 步后仍选初始化。这些模型在条件形态 h=1 的 rich-minus-stats 增量约为 1e-5、1e-5、1e-6，却都计入正 realization 数。

因此“4/5 正向”“4/4 正向”不是“4 个实现成功恢复信号”。必须同时报告注册分母、数值成功、实际学习、效应超过误差／预定阈值、相对 oracle 的恢复程度。失败样本保留在可靠性分母；其缺失分数不能擅自填零或填负数。

原文件：[逐 realization 配对表](/data/hfosp_group_event_state_observable_state_validation_v0312/final_reports/synthetic_replication_pairs.csv)、[扩展训练表](/data/hfosp_group_event_state_observable_state_validation_v0312/final_reports/extension_training_audit.csv)。

### 2.2 巨大正增量可能只是对照失效

形态世界 h=1，realization 905 的 P_stats/P_marks NLL 为 1.2496/19966.2670；906 为 1104.7807/10.1361；907 为 1036.9312/1.6549。identity 902 为 7029.3350/28.5138。增量很大并不意味着胜者接近合理预测分布。

这种双向失败不能仅归于一次 CUDA 错误：大量评分是有限数值，但统计上极差。原实现的条件 Gaussian 尺度可降到 exp(-6)；过窄分布、均值漂移、读出对未见时钟相位的外推，以及路径混合估计都能放大 NLL。**这些是应分解检验的候选原因，本次没有宣称已定位唯一根因。**

下一版要让每个输入臂分别对照真分布／可读信息 oracle 和固定边际基线，分开均值误差、尺度、覆盖率和边际积分误差。不能把 NLL 裁掉再宣布修复。Proper score 衡量的是整个预测分布，分数差不能替代分布合理性检查。[Gneiting 与 Raftery, 2007](https://www.eecs.harvard.edu/cs286r/courses/fall10/papers/Gneiting07.pdf)

### 2.3 zero 有正号，不等于已证明假阳性失控

若零假设下分数差近似对称，5 个实现中至少 4 个取正的单侧概率为 0.1875；正负号本身没有定义显著性。这里 zero 中位增量很小，又混有初始化差异和训练差异，更不能把 4/5 直接读成 80% 假阳性。

所以原报告“不能做科学阴性”的决定正确，但更准确的理由是：**尚未定义并校准检出规则，灵敏度与数值／训练可靠性也没有建立。** 不是已经证明了确定的高假阳性率。下一版需固定目标效应、检出阈值、独立数据实现和 Monte Carlo 误差。[Morris 等, 2019](https://pmc.ncbi.nlm.nih.gov/articles/PMC6492164/)

### 2.4 下一轮 INNER 条件既不充分，也尚未真正阻止不合格执行

E1125 本轮 P_stats-state 两 INNER 选 150/50 步；P_marks-state 选 400/50 步；learned marked-history 选 400/50 步。它们已经满足“两 INNER 都选非零步”，但 OUTER 仍失败。rich 的 inner0 最佳组合损失为 3.2115，末次为 4.1787：两次降率后停止只能说明停止规则走完，不能把明显恶化曲线称为稳定收敛。

目前 `queue.py::make_recipe` 把两个最佳步数取中位数。400 与 50 得到 225，这个预算不是“两起点共同验证过的较好配方”。以单个优化种子产生配方，再固定给另外两个种子，也不能证明跨种子训练充分性。

更直接的实施问题：`make_recipe` 写出 `learned_state_eligible=false` 时仍返回 `status=FROZEN`；`train.py::run_cell` 的 outer 分支未检查这个资格标志。本次用两个最小 card（选中 0/100 步）实际复现了 `FROZEN + updates=50 + learned_state_eligible=false`，并静态核对执行入口没有消费此标志。

因此“下一轮资格条件已加好”应改为“资格标志已计算，强制阻断尚未闭合”。这不推翻当前 E1125 的既有分数，但必须在下次自动解锁人体 OUTER 前修复。参见 [queue.py](/home/honglab/leijiaxin/HFOsp/.worktrees/topic5-ges-v033-training-lab/src/topic5_group_event_state/v0312/queue.py:36) 和 [train.py](/home/honglab/leijiaxin/HFOsp/.worktrees/topic5-ges-v033-training-lab/src/topic5_group_event_state/v0312/train.py:290)。

### 2.5 短时距实验实际使用的是较旧的信息

E1125 S-E 共 376 个唯一查询，h=1 为 125 个一分钟计数目标，其中空间／负荷有事件目标为 64 个。66.48 小时是查询跨度，不能当作 66.48 小时连续评分曝光；5750 个形态有效分量也不是 5750 个独立时间块。

信息年龄中位 29 分钟，范围 2–59 分钟。因此 h=1 实际是在多数查询上用约半小时前的观察预测下一分钟。D-local 尚不可用，短尺度的生物信号可在这段等待中消失。

本次计算精确 OU 理想例子：若真实状态 τ=5 分钟，即使准确知道 29 分钟前的状态，对 1 分钟后状态可解释的方差比例也只有 exp[-2(29+1)/5]=6.14e-6；τ=120 分钟时为 0.6065。这个例子只是信息延迟的数学反例，不是 E1125 的时间尺度估计。

因此长跨度修复值得接受，但不能以此宣布“时间支持问题全部消除”。多日节律研究需要远长于数天的记录；已有数年 IEA 研究发现 circadian 与 multidien 调制，不能由本轮 3 个日历日排除。[Baud 等, 2018](https://www.nature.com/articles/s41467-017-02577-y)

### 2.6 发作反向不能全部归因于近期率匹配

原汇总：11 次病例标准匹配中位 +0.05856，近期率匹配保留 7 次，中位 -0.05609。

本次重新聚合原病例台账：

| 配对支持 | 标准匹配 | 加近期率匹配 |
|---|---:|---:|
| 各自可用病例 | +0.05856，8/11 正 | -0.05609，3/7 正 |
| 限制到相同 7 次发作 | +0.03472，4/7 正 | -0.05609，3/7 正 |
| 再限制到相同病例内查询 | -0.03774，3/7 正 | -0.05609，3/7 正 |

病例内查询的筛选已改变符号；加入近期率后的控制对象变化进一步改变数值。当前可以说关联不稳健，不能说“控制事件率证明此前全是混杂”，也不能说存在保护作用。风险预测仍需完整时间分母，病例关联不代替风险校准。[原病例台账](/data/hfosp_group_event_state_observable_state_validation_v0312/final_reports/seizure_case_ledger.csv)

### 2.7 触点读出的失败位置仍需分层

现有适配器从零权重、FIT 触点先验 bias 开始；选第 0 步就会忽略状态和 history，因此 S-B 四路逐病例相同有直接的计算解释。它不是四种科学模型独立趋于同一结论。

本次直接调用原 `fit_adapter`，在已知条件集合分布中给它真实有效状态：3 次独立数据实现均选非零步，测试增量 0.6109、0.5339、0.6188 nats/事件；一个选 400 步碰到此次测试上限，所以这仅证明容量和学习通路，不证明优化充分性。将状态与身份独立后，3 次均选第 0 步，增量约零。

这排除了“该适配器在任何情况下都学不动”的泛化解释；没有排除生产数据的状态表示不好、时延过长、验证分布漂移或线性读出不足。还需匹配人体支持的端到端 identity 世界和带条件 nuisance 的基线。

## 3. 文献如何改变方案

检索覆盖了事件形态／空间随状态变化、长时程发作节律、预测表示与动态可辨识性、概率评分／模拟校准、IED 促发与抑制机制。以下均为原始研究或原方法论文；未把文献结果当作本队列证据。

| 来源 | 支持什么 | 对当前方案的约束 |
|---|---|---|
| [Baud 等, 2018, Nature Communications](https://www.nature.com/articles/s41467-017-02577-y) | 长期 IEA 与发作有日内和多日调制 | 时钟覆盖不等于多日节律可辨识；率是重要强参考 |
| [Proix 等, 2021, Lancet Neurology](https://pubmed.ncbi.nlm.nih.gov/33341149/) | 用长期连续小时 IEA、按时间前推、独立队列验证风险预测 | 本轮病例分析不具备同一风险分母，不能沿用其临床解释 |
| [Kang 等, 2020, Scientific Reports](https://www.nature.com/articles/s41598-020-58612-4) | REM/NREM 下 IED 时长与空间范围可变化 | 支持丰富信息的合理性，也提出睡眠共同驱动；样本小且为头皮 EEG，不能直接搬到群体 SEEG |
| [Conrad 等, 2023, Epilepsia](https://onlinelibrary.wiley.com/doi/abs/10.1111/epi.17482) | 101 位患者睡眠／发作前后 spike rate 与定位变化 | 时钟不能替代睡眠；患者内慢状态可能部分是可测脑状态 |
| [Schroeder 等, 2023, Brain Communications](https://academic.oup.com/braincomms/article/5/5/fcad205/7226358) | 长期记录中，发作网络状态出现与持续时间受不同时间因素调制 | 发作发生、类型、空间演化与持续时间应分别检验，不强迫一维统一解释 |
| [Sani 等, 2021, PSID](https://www.nature.com/articles/s41593-020-00733-0) | 优先识别任务相关动态可以减少无关神经变化对低维表示的占用 | 仅拟合主导变异未必保留迁移信息；可借鉴低维预测子空间作诊断，不能引入发作监督后仍称零发作监督迁移 |
| [Sani 等, 2024, DPAD](https://www.nature.com/articles/s41593-024-01731-2) | 分开识别动态映射和读出映射的非线性 | 后续应比较同 q/g 的线性与非线性 f；非线性读出优势不证明潜动力学非线性 |
| [Ansari 等, 2023, NCDSSM](https://proceedings.mlr.press/v202/ansari23a.html) | 识别观测与连续动态可分开建模，需验证近似过滤 | 保留 q/f/g，但先做带真值的读入、过滤、预测分布分层诊断；Joseph 通过不等于整体概率模型正确 |
| [Gneiting 与 Raftery, 2007](https://www.eecs.harvard.edu/cs286r/courses/fall10/papers/Gneiting07.pdf) | Proper scoring rules 为预测分布评价提供依据 | NLL、尺度、覆盖、CRPS 等互相检查；不能按赢几个 seed 定义科学结果 |
| [Morris 等, 2019](https://pmc.ncbi.nlm.nih.gov/articles/PMC6492164/) | 模拟要先定义生成机制、估计对象与性能尺度，报告模拟误差 | 分开数据实现、优化随机性和预测 Monte Carlo；正号不是功效 |
| [Cawley 与 Talbot, 2010, JMLR](https://jmlr.org/papers/v11/cawley10a.html) | 验证标准本身可被过度优化，造成性能评价偏倚 | E1125 已看过的 OUTER 永远是开发资料；回到 INNER 不会让它重新独立 |
| [Barbarosie 与 Avoli, 1997, J Neurosci](https://pubmed.ncbi.nlm.nih.gov/9364076/) | 小鼠切片中 CA3 间期活动及模拟输出可抑制 entorhinal ictal activity | 不能预设 IED 一定促发作；事件来源与网络状态会改变方向 |
| [Huberfeld 等, 2011, Nature Neuroscience](https://pubmed.ncbi.nlm.nih.gov/21460834/) | 人体切片及颅内观察区分普通 interictal 与促发作前驱放电 | pre-ictal 放电不等同于所有 IED；反馈必须检验具体事件类型及条件 |

这组文献支持继续检验丰富信息，却不支持强迫所有事件、所有形态和所有发作表型共享一个主导状态，更不支持把普通滤波更新解释为塑形。

## 4. 三轮方案反证及收敛

这里的“轮”指实质不同的候选方案及判别检验；不是声称已经完成三轮人体训练。

| 候选方案 | 本次检验 | 结论与修订 |
|---|---|---|
| A：数值修复＋两个 INNER 非零后，继续原 rich-vs-stats 训练 | 既有人体所有相关 INNER 已非零；904 初始化仍可计正；不合格 recipe 可冻结 | 不足。增加绝对预测质量、资格执行门和真正的跨起点配方评价 |
| B：morphology 超过 zero，多个视图都能预测，即认为共同状态有希望 | 60 对独立慢过程反例：自身历史 MSE 改善中位 0.693；定向跨视图为 -0.00075。共享世界两者约 0.689 | 不足。自身可预测与跨视图共享分开；增加独立慢过程及已知共同 nuisance 世界 |
| C：信息增量 → 状态保留 → 定向迁移，分别设门，并把时延纳入可检出性 | 实际 adapter 在有效状态下可学；OU 延迟解析反例成立；相同发作查询重新聚合改变解释 | 采用。每个失败有归属及停止路径；人体闭环仍需后续正式执行 |

特别修订一个容易走偏的门槛：**状态不必严格打败包含全部合法历史的最强预测器，才有“状态表示价值”。** 状态本来就是历史的压缩。若以显著更紧凑、冻结可迁移的表示保留几乎全部有效信息，它仍可有科学价值；若要声称“建模优势”，才另外要求优于强历史。非劣效也需要预定容忍界限，不能用“不显著差于”代替。

同样不能要求 morphology-only 世界在 count、粗空间、identity 都阳性。该世界特意使这些变量没有相关信号；强迫多端点全赢会奖励错误仪器。原 v0.3.12 §7 已明确不设全层阳性门，下一版应保留。
