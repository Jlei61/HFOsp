## 修复如何对应原始问题

- **实际识别到了什么**：统一 infer_asof 的源时间、发布时间、查询时间、曝光、输入集合及临床 reset。P_stats/P_marks 公共参数同初始化，保留参与、时序、频带、延迟、波形和事件间隔；不通过缩短信息输入降低计算量。
- **能否向真正未来泛化**：优化种子与切分种子分开，S-ID 的隐藏数据不进 scaler／输入，S-E 的两个前推 INNER 先冻结配方，再 outer 重拟合。短提前量使用自己的合法目标，不再被 120min 资格排除。
- **学到的状态是否保留历史**：后验创新改为相对先验的残差，完整协方差校正保留。原来的绝对伪观测初始化会反复把状态拉回零，非零长梯度可能小到不可扰动核对。修复后 FIT 真实 6–8h 事件得到可核验梯度；仍需要严格历史重拟合证明预测价值。
- **能否复用到细表达／发作**：同一冻结 checkpoint 接数量、空间、形态、细身份、四条演化规则及 S-A/S-B。所有细身份参考都获得相同目标时钟；发作关联单列相同受体时钟下状态对 FIT RESET 的增量；空间迁移增加同预算拟合的历史参考。
- **能否自主可靠运行**：从第 0 步开始可选 checkpoint，完整 optimizer/sampler/scheduler 恢复；有效批量累积不改权重。任务全程持锁、依赖隔离失败、源码/数据变更拒绝静默复用、截止保存 PAUSED。

## 准入范围与保留缺口

**准入 GPU 训练／训练端评分＋CPU 冻结消费者。** 第一次正式启动后，训练再次出现异步 CUDA 索引断言；同步从同一 checkpoint 越过失败步未复现。动力学中唯一动态 `index_put` 已由固定基底收缩替代，矩阵值和梯度逐位等价；受影响的首次启动全部归档后从零重建。修复后 70 项测试、26 项全链、恢复、累积梯度及 GPU profile 重新通过。由于原错误无法同步复现，不宣称已证明唯一根因。CPU 消费者与同 checkpoint GPU 主评分仍按相同目标／噪声执行。

D-local 低延迟测量未准入，仍使用真实小时 release。S-B 现有测量是临床起点 0–10s 的空间强度，不是 EEG 起点空间或传播路径。S-A 病例关联可做，S-C 连续风险和 IED 生理反馈不可由本轮推出。

采用 event 32、recognition 64、latent 24，未盲目扩到 128。优化设置、归一化、损失权重及参数更新均可追溯；本次证明学习通路能工作，不证明所有人体任务已训练充分。固定容限平台＋两次降率仍需结合 MC 误差与曲线解释；各一次合成实现不构成人体阴性所需的功效校准。
