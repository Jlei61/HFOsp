# 追加：新输入重放与事件时钟修复

三例FIT-only新触点测量共466个原始块已完成。进一步用纯间期、完整覆盖的FIT块重新选择触点，三例均与重建算子相同；该等价性写入每份新数据。INNER阶段每例两个原始块、每块两个事件的新波形均通过强制原始样本cutoff重放，并从同块检测资产精确重放完整打包时钟。检测器沿用冻结的block-local历史GPU资产，不声称已恢复旧cusignal版本的逐位运行。

初次数据拼装还发现一个独立错误：跨200秒处理段的事件缺少stitched centroid，若删除整条事件并减去覆盖，会同时丢失已知的计数和触点参与。修复版保留这些事件的clock/count/participation/coupling，把细mark显式标为缺失；其余测量cache保持不变，数据走 `human_data_v2`。旧 `human_data` 保留用于追溯，不进入正式人体训练。

## 背景测量修复：当前正式人体输入改走平行根目录

恢复跨200秒段事件之后，旧背景窗口避让清单仍只包含保留下来的细测量事件。实际核验发现E1096/E1125/E253分别有60/215/540个2秒背景窗与已知恢复事件的core重叠；E253另有一个真正零事件的短块没有提取背景。它会混淆“背景解释”与“事件残差解释”，必须修复后重新拟合所有依赖背景的上游和迁移读出。

修复删除这些背景窗，零事件块按原固定30秒网格补出6个2秒背景窗，重新由FIT计算背景标准化。事件时钟、每个事件的输入、实际历史长度、所有anchor、目标和划分已与此前`human_data_v2`逐项精确比对，三例全部相同。事件归一化未改变；背景及其FIT归一化改变。完整核验见新根目录`input_boundary/background_repair_parity.json`。

当前正式人体根目录为 `/data/hfosp_group_event_state_v0_3_9_transition_transfer_background_repaired`。旧根目录人体拟合和其下游导出保留并标为输入修复前结果，不进入新版本汇总；模拟已知真值实验、466块事件测量和9张新触点decoder卡不受影响，按hash复用。重新执行同一108主比较、126敏感性、36单视图有限配方，家族仍只由修正输入后的INNER选定。

旧敏感性队列有一张CUDA索引异常失败卡，两GPU按原配方独立复放均成功，目前原因未定位。新训练保留原GPU随机数流，逐批核验实际FIT索引并保存批大小、索引范围和序列hash；这是一项定位与可追溯性加强，不宣称已经找到原异常根因。
