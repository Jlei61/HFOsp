## 1. 要优先回答的问题

主问题是：**在查询时实际可读的信息下，过去群体 IED 的细结构是否能改善未来条件形态与空间组织；这种收益能否由同一个冻结状态承载，并连接到该患者的发作表达？**

预先分开五层结论：

| 层 | 必要比较 | 允许的结论 |
|---|---|---|
| 输入信息 | 相同核心的 `P_marks` 对 `P_stats`，相同物理目标与切分 | 细事件信息有无增量 |
| 状态表示 | state 对近期／多尺度 marked-history、同读出常数等合格参考 | 学到的历史压缩是否有预测用途 |
| 时间组织 | 严格历史重拟合；同查询后验的 HOLD/EVOLVE/RELAX/RESET | 当前识别、历史记忆和无新观测演化各自价值 |
| 冻结迁移 | 同 checkpoint 的未训练细集合、定向跨视图、发作关联及早期空间 | 可复用表示和发作联系；不自动是统一病理机制 |
| 生理反馈 | 后续显式事件跳变模型、可辨识干预／外生扰动 | 本版只规划，不能由 observer 更新宣称已证实 |

数量保留为共同主端点和基线校准入口；首轮的完整证据链必须同时包含条件形态与细空间读出。不能靠数量阳性替代这些端点，也不能靠非线性结构比较挤掉它们。

## 2. 数据权限、发生时间与发布时刻

### 2.1 统一查询对象

所有消费者只接收一个 `QueryState`：

```
patient, producer_hash, split_id, transform_id, query_time
last_source_time, last_release_time, information_age
m_at_query, P_at_query, posterior_paths_at_query / rng_key
available_exposure, readable_event_count, reset_history, input_digest
```

`infer_asof(t)` 只同化 `release <= t` 的数据；若最后后验在源时刻 s<t，则先以 f 无观测传播至 t。源时刻与查询时刻均随导出保存。不同臂、冻结读出、校准和发作必须从同一对象出发，不能私自再次生成“当前状态”。

时间标签固定为：主目标宽度 W=1min，h∈{1,5,30,120}min 指从 query 到目标结束；目标区间是 `[t+h-W,t+h)`。因此 1min 档是下一分钟，绝不是把未来 120min 全部累加。额外窗宽必须另立端点，不混入原比较。

延迟包不是 t 时刻的新物理事件。若包乱序到达，按已发布测量的物理顺序重放到 t；优先复用已验证前缀，不能直接把历史观测当当前观测同化。无观测时跳过 q，仅传播 f；技术缺测与发作／发作后 reset 分开。

同一冻结参数下，早期输入不应受未来文件、输入变换或任意尚未发布包的值影响。训练参数本身对未来训练数据的依赖，在 S-ID 回顾性协议中另作说明。

### 2.2 保留两种可观察性，不伪造实时信息

- **D-delayed**：现有小时测量包按真实 release 可读。所有时距报告两项：从查询时刻的 h，以及最近观测年龄 + h。
- **D-local**：优先复用原始测量 producer，构建有明确有限右上下文的事件局部版本；算法阈值、触点字典、标准化只来自 FIT。事件 release 必须晚于事件结束及所需上下文，记录检测与处理耗时；整小时自适应统计不能偷偷沿用。

首轮先审计测量依赖，在一个既有开发患者、预定多个昼夜时段的片段重算，比较事件检出集合、参与、延迟、频带和波形描述量。若事件定义变化，作为新的测量版本冻结、在相同原始时间支持上分别报告，不只保留两版本“碰巧相同”的事件。缺 raw 或时延无法验证时，D-local 局部标 `NOT_AVAILABLE`，继续 D-delayed 合法链；不得把旧 release 回填成事件发生时间。

两版本比较旨在区分“信息过旧”与“事件信息不足”。D-local 失败不应自动否定 D-delayed 的较长时距问题；D-delayed 阴性也不排除低延迟可识别状态。

## 3. 先冻结切分，再随机训练

第一批使用已看过的 E1125、E253、E1096，明确称开发资料。E1125 为工程 pilot；不按本轮阳性强弱重排患者。新增患者或 sealed 需以后独立授权。

`split_seed=20260906` 独立于 `optimizer_seed=[20260906,20260907,20260908]`、`data_realization_seed`、`sampler_seed` 和 `eval_seed`。每一 seed 配对的目标 ID、INNER、FIT mask 和 scaler 必须逐项相同。

### S-E：真正向前预测

保留已授权日历范围，冻结一个 canonical outer 前推段。模型选择改为截止 outer 前的嵌套前推 INNER：至少两个有足够覆盖的滚动起点，选择目标与最终报告的多视图目标一致。每个 INNER origin 的训练、scaler 和任何预训练编码器只能使用该 origin 前的 FIT 数据。可用更新步数／正则配方在 INNER 冻结后，在外层训练期重新拟合；最终 outer 不参与修复配方或 checkpoint 选择。

记录全部真实前推日历跨度、可读曝光、昼夜覆盖和不跨发作的 episode 数。争取跨两个昼夜的支持，但不以“必须每位有两个整日”取消稀缺病例：不足者保留患者内描述，并区分时间外推与插值。分散采样改善相位覆盖，不会自动产生独立天数。

### S-ID：分散目标核心的回顾性识别

按日历日×时钟层×记录质量选择目标核心，不按状态值、事件数或发作结果选。外层核心及 INNER 隐藏块在参数拟合、scaler 和任何数据驱动编码器中完整排除。训练前缀允许穿过隐藏核心，但该段只传播先验，不能用“整条 episode 必须全部可读”把周围数小时一起删除。

以核心内固定目标包为主索引，对每个 h 构造 `query = target_end - h`；目标长度另记，不再把“核心起点 + h”当唯一查询。30 分钟核心可以承载 120 分钟前发出的预测。S-ID 可以用目标时间之后的其他 FIT 时段训练参数，所以只是回顾性跨时段识别，不是实时前推证明。

### 计权与支持集

每条评分记录有 `(patient, split, query, target_start, target_end, view)`。端点间样本量可以不同，臂间同端点必须使用同一 ID 交集；交集损失与各臂覆盖损失并列保存。可估性只由预定时空覆盖、通道和目标有效性决定，不由得分决定。

训练按物理目标包采样，或对重复 episode 的多次出现作逆频次计权；不能因为重放长历史而加重某个包。各患者分别建模报告；事件、种子和 MC 路径都不是患者数。

## 4. 架构：保留现有核心，修复可检验性

### 4.1 输入与学习目标

保留两条输入：

- `P_stats`：合法分钟 count、总负荷、粗空间组成及观测质量。
- `P_marks`：加上逐群体事件的参与身份、触点内时序、频带、跨带延迟、波形描述及真实事件间隔。复用 contact embedding 8、事件编码 32、分钟内 GRU 32、慢 recognition GRU 64。固定 latent 24；首轮不强行扩至 128。

相同组件使用独立且同名的初始化 RNG，避免多一个事件编码器改变所有公共 head 的初始化。`P_stats` 的同容量空 marks 编码器对照只在确实需要区分容量时追加；全记录置换对照停用。若用供体置换，只从当前 FIT 可读支持选同患者、相近曝光／参与规模的完整事件结构，训练和评价分别按冻结供体策略执行，绝不把 outer marks 移入 FIT。

三个目标为：区间数量、给定事件数量的粗空间组织、给定有事件的形态／传播描述。形态至少拆报相对频带能量、signed cross-band lag、delay IQR；负荷另报。形态项按每个有效分量归一，不能让高计数重复主导全部目标。原始 waveform 的完整重建与 STOP/route 不列为已覆盖。

### 4.2 q、f 与 g

继续使用先验均值／全协方差、依赖先验的伪观测创新和 Joseph 更新；噪声相对完整预测协方差参数化。`P` 表示该近似过滤器的预测不确定性，只有校准后才可讨论其可靠性，不能因矩阵正定便称真实病理不确定度。

第一家族固定 **I-L-G1**：独立稳定线性潜转移、非线性 recognition 和 readout。这仍然有能力识别非线性观测下的状态，并不是假设病理过程只能线性。C-N-G1 作为后续表达能力反证臂，只有基础测量／输入比较稳定、或 FIT 明确显示表达不足时追加；不能用 I-L 对 C-N 直接归因为非线性。

数值核沿用已验证 OU 传播及稳定残差积分。批量短步与长 gap 的同底层噪声复核只在 FIT 做。事件后验更新与 f 的生理事件驱动分离；本版不向 f 偷加 IED 输入后宣称反馈。

`g` 输出区间预测分布。count 的期望是率沿真实区间的曝光积分；conditional marks 取事件前的相应状态，不能用同化该事件后的后验重建评分。已知时钟在查询未来按真实时间推进；未来事件数、未来可读覆盖不能作为隐状态输入。实际曝光可作为评分条件／offset，条件预测与无条件覆盖预测分开命名。

### 4.3 持续状态与严格历史

主状态按冻结参数对每个合法间期 episode 持续过滤。训练时从 episode 起点在当前参数下重放前缀，必要时无梯度重建较早部分；只有显式记录的后段参与反传。冻结评价从相同 episode 起点重建，不以任意 3 小时截断替代主状态。

另设严格 `H=0.5/2/8h`：在 `query-H` 重置；只可同化发生与发布均符合该起点和 query 权限的包。按实际 release 逐查询判定可读覆盖，不按 `H<1h` 全局禁止。三档在同目标支持、相同有效批量、相同优化配方和充分拟合机会下重训；梯度可用计算重算覆盖全部指定 H。物理长度增加必然改变梯度跨度，不强行把它们都裁成同样短记忆。

24h 留作后续；只有数据覆盖、有效事件和训练可达性支持才扩展。不从三个初始化时间常数数值推断三种生理过程。

## 5. 基线与训练充分性

先交付可独立求解的基线：固定 NB 率＋离散度（曝光 offset）、时钟 NB GLM、近期率、多尺度 marked-history；空间 trait/近期空间历史；形态 FIT 分布／近期多尺度形态。依次判断剩余增量，不能因为一个神经参考塌缩就取消它应代表的科学对照。

主 marked-history 参考需保留同一已可读事件集合。先用 FIT 固定的丰富描述量及时间核作低容量参考；再以与 producer 相同事件编码器、G1 和训练机会作无递归状态参考，区分表示收益与编码器／读出容量。两种参考名称明确，不能把有损描述均值称“完整原始历史”。

常数状态臂保留同一 g、时钟与曝光条件重新拟合；不称严格固定率。所有参考必须允许回退至自己的更简单嵌套基线。差值分开给：状态对强历史、对常数的原始值，以及按预先指定参考封底的保守值；不得把对照自己的损害计作状态能力。

初始化：count head 使用 `log FIT_rate_per_hour`，离散度使用 FIT 标量 MLE；组成使用带固定平滑的 FIT 频率；形态中心／尺度使用合法 FIT。学习的残差头小非零初始化，记录残差为零的分布核对；不要让零输出投影阻断所有上游初始梯度。**第 0 步 checkpoint 必须评估并可被选中。**

优化起始配方：AdamW，公共网络 lr=1e-3、动力学与协方差参数 lr=3e-4，betas=(0.9,0.999)，eps=1e-8；weight_decay=1e-4，仅作用常规权重，不对截距／尺度／衰减施加同样惩罚。全局梯度范数裁剪 1。先由 FIT 小样本记忆实验验证学习通路，再按冻结 INNER 比较必要的 lr=3e-4 对照，不扩成随意搜索。

有效批量先设 32 个物理目标起点，按连续 episode 合并前缀；OOM 只降 microbatch 并累积，保持有效批量与实际目标权重。历史重建采用 activation checkpointing，训练路径初值 4，评价 64，近零对比用固定预算的独立 MC 复核到 256/512；目标 MC 配对标准误≤1e-3 nats/评分单位，否则标数值未分辨，不能无限采样。

每 50 步评估固定 INNER 目标及共同随机数。先预算 3200，预算端点仍改善则可到 6400；固定学习率平台不足以认定收敛。当前实施采用固定 1e-3 的共同随机数容限：连续 6 次无该幅度改善则 lr×0.3；经历两次降率，再连续 8 次无改善才记平台。尚未实现训练期间逐次估计 MC_SE；冻结后另以 4 组独立 64 路径评分估计数值误差，失败只限制可分辨性，不回头挑 checkpoint。此平台标签不能用作“已充分收敛”的证明。预算停止如实记录；不为所有臂凑同一步数而截断慢臂。每个科学比较同时展示选中步、末段趋势、各组 lr、真实更新量和初始损失。

逐层表写出输入／输出维度、参数量、初始化、归一化及更新量。若 FIT 也学不动，先查单位、梯度与损失；只有干净 FIT/INNER 都显示欠拟合且正对照支持容量瓶颈，再追加 64→128 容量臂，并给参考相同机会。扩大网络不是下一轮预设答案。

## 6. 冻结分析必须从同一 checkpoint 出发

### 6.1 当前状态与演化

先计算合法 `q_t`，再比较四条规则：

1. HOLD：从 t 起保持后验分布，未来时钟照常推进。
2. EVOLVE：从 t 起按已学 f 传播。
3. RELAX：从 t 起按 FIT/INNER 冻结的收缩规则回归，并报告剩余状态权重。
4. RESET：在 t 直接替换为 FIT 参考分布，再用同一 f 演化；完全移除当前状态信息。

加一个仅作解释的错时供体状态：同患者、相同可读覆盖／信息年龄层，供体来自合法参考池；使用受体 query 的时钟、曝光、mask 和 g。不将预测规则差异称为生理干预。

Evolve胜HOLD但不胜RESET：有用的可能是平均分布传播，当前识别尚无证据。真实 q 胜RESET但HOLD已足够：当前识别有用，额外演化未必要。只在短 h 有益：报告有效时距，不否定短时状态。

### 6.2 细触点与定向跨视图

冻结适配器显式接受 `fit_target_ids / inner_target_ids / outer_target_ids`，与 producer 的样本权限一致；history 参考通过同一个 `infer_asof` 可读集合构造。先验 trait、trait+history、trait+state 以相同正则候选和充分优化比较，零步可回退。

首轮同时输出精确 K-subset NLL，以及给定每个粗 community 参与数的细身份 NLL。K 是条件任务的真值条件，不被塞进无条件 count 预测。下一触点、同前缀分叉和 STOP 需要各自 decoder 与正对照，不由集合 NLL代替。

定向跨视图只选一项：**去掉传播时序输入及其 producer 损失后，其他事件信息能否支持冻结延迟读出**。删除 relative delay/rank/tied-lead、band centroid/cross-band lag、IQR/span 及可直接重构它们的派生量；保留事件间间隔。producer 不接触目标视图的训练标签；冻结后新适配器只用合法 FIT/INNER 的延迟标签训练，再评 outer。若相关频带/参与信息仍能预测延迟，这是功能性跨视图证据；不是病理唯一共同原因证明。

### 6.3 稀缺发作的可行设计

不要求先达到临床风险预测器样本量才允许研究发作。三个层级分别给出结果，不能互相替代。

- **S-A 关联**：每个发作簇有合法前史即可列病例轨迹。主窗 `[-2h,-30min)`，次窗 `[-30min,-5min)`；先按完整预发作、发作及发作后区间排除控制池，再匹配记录时段、真实昼夜、已可读曝光、信息年龄及可用背景。只有一个簇时不给群体显著性，仍可给相对于匹配参照的效应。多个簇按日期／簇依赖处理，不能把共用对照的符号当完全独立。
- **总关联与增量分开**：先报上述观测条件调整后的差异，再额外匹配查询时已可读的近期率／空间历史。前者消失而后者保留等各方向均如实记录。物理过去但尚未发布的计数只作标注清楚的回顾性 oracle 敏感性分析。
- **S-B 早期空间表达**：同一患者冻结状态，与 FIT trait、近期空间历史、trait+state 比较发作最初 0–10s 空间激活（0–30s 次要）；原始 ictal 测量、通道映射和起始时间必须合法。若用发作标签拟合映射，按发作留一，单次发作只允许冻结无监督映射或描述，不在该次上拟合再验证。只有空间强度测量时不称传播路径；路径需可靠先后时序。
- **S-C 风险**：仅有完整可观察人时和按时间外推的足够发作支持才拟合风险；报告基础率、时间在警报内、校准和漏报。不足只限制 S-C，不取消 S-A/S-B。

producer 仅用间期 INNER 冻结；发作绝不选 checkpoint。开发期已经看过的发作是探索数据，早于 producer 截止的病例明确回顾性。低可读覆盖与发作同现要报告，但“有混杂”不能未经条件复核便说完全解释了信号。

## 7. 必要检验与继续条件

| 检验 | 必须区分的解释 | 不通过时处理 |
|---|---|---|
| 分割种子独立、隐藏值扰动不改 scaler/训练输入 | 优化波动 vs 选模数据差异；真实隐藏 vs 偷读 | 修数据合同，受影响 producer 重训 |
| 主评分/冻结/校准/发作共用查询状态、同目标分数一致 | 时间演化效应 vs 漏掉发布时延 | 仅冻结消费者错误可先重算，但不能清除训练污染 |
| 真实发作区间与控制池零重叠；假想发作窗 placebo | 生理关联 vs 时间网格及缺测选择 | 修控制池，不降低匹配质量求阳性 |
| 严格 H 按真实 release 逐查询判定 | 无历史信号 vs 锚点／代码硬禁止 | 重建支持；部分不可估单独列 |
| 固定 NB MLE、零步与 FIT 小样本拟合 | 基线／训练失败 vs 状态无增量 | 不放行“状态胜弱参考”或“分布不适用” |
| 线性高斯完整均值协方差与 gap；长历史梯度/扰动 | 数值正确 vs 仅 loss 有数 | 修 q/f；gradient 检查先在 FIT，outer 只作最终描述 |
| 同源生成细 marks 再调用真实测量函数 | 输入目标一致的正对照 vs 人工直接编码答案 | 分别标模型接口与测量链，不借用人体检出限 |

合成世界首轮只需三类：固定率／粗组成但细形态受慢状态调制；固定率／粗组成但细身份受慢状态调制；相同边际但状态—未来联系断开的零效应世界。按实际曝光、release、计数离散度与缺口作匹配扰动；先各 2 个实现调接口，再按所需效应的功效扩展独立实现。合成参数真值用于评估，不输入 q。

非线性结构鉴别只在后来需要声称 N>L 时追加。必须在两臂分别充分拟合后由独立模拟展示可分性；若仍分不开，该结构问题未被检验，其他输入／冻结迁移结果照常可读。

结果不设“全层阳性”闸门：稳定改善条件形态而数量无增量是局部支持；近时可识别但长期不可预测是有限时距状态；只有漂移鲁棒性改善是泛化技术结果。若测量与基线都有效、合成有对应鉴别力而真实数据仍无增量，停止扩模型，转入效应上界／更多记录与测量覆盖研究。

## 8. 分阶段执行量与时间估计

这是一套研究顺序，**不是把所有比较塞进一个夜间窗口的承诺**。用户已授权实现；下一次长跑按单独 handoff/prompt 启动。以下最初估时保留作背景，实际预算以第 10 节及实施验收中的测量为准。

| 阶段 | 工作与交付 | 粗略时长 |
|---|---|---|
| A 集成修复 | 统一 as-of 接口、数据 mask、分割 RNG、对照区间、基线初始化；复现本次反例及既有数值测试 | 2–4h 实施与验证，视定位结果变化 |
| B 最小科学链 | E1125、固定 I-L-G1、P_stats/P_marks 各 1 seed；合格统计参考与无递归 rich 参考；立即导出细触点、规则与 S-A/S-B 可估项 | 约 3–7h，先实测稳态吞吐 |
| C 固定切分重复 | E1125 上两个输入＋无递归 rich 参考各补至 3 seeds；同物理包成对 | 按剩余拟合数重新估时 |
| D 患者与历史扩展 | 另两患者同三臂×3 seeds；0.5/2/8h、定向跨视图、必要 C-N 依次追加，不全相乘 | 通常超出一次 8–10h 窗口 |

历史 handoff 中 state 中位耗时 **2.36 秒/更新**，但混合了不同并发，不能当新配置的单卡吞吐。以每 worker 该速率保守估算，3200 步约 2.1h/fit；两 worker 的 9 个完整拟合约 9.4h，尚不含修复和冻结分析。三患者三臂三 seeds 共 27 fits，约 28.3h 的两 worker 拟合时间；若需要 6400 步会增加。**完整开发扩展按 1–3 天规划；下一晚 8–10h 目标是 A+B 与可完成的 C，不能承诺一次关闭所有科学层。**

持续前缀重建、嵌套 INNER 与 D-local 重测可能进一步增加成本；上述只是旧吞吐下的场景估算。A 结束前用 30 分钟真实配置 profile 更新预计完成量、训练曲线评估成本与内存峰值，再冻结该窗口任务表。若只能完成一条链便交付该链及剩余量，不因 8h 到点把计划条目都标 COMPLETE。

吞吐确认后可调整并发：两张 3090 各先 1 worker；逐张卡做峰值显存与长 gap 压测，保留≥6GiB余量，单卡 aggregate 目标≤18GiB，再试每卡 2 workers。出现 device-side assert 必须隔离复现，不称“偶发硬件错误”继续加到 10–12 进程。微批调小不改变有效批量或历史长度。

仅派发有科学优先级且互不写同目录的任务；锁、心跳、原子卡片和恢复试验复用已有实现。GPU 有合格待跑队列时持续供给，CPU 同步修复和统计；必要的数据有效性阻塞时可以空闲，不能用已知无效比较凑利用率。临近窗口先完成可复核交付，未结束的合法训练可按获准的时限续跑／保存，不能将预算截止伪装成平台停止。

## 10. 实施冻结条款（本节在冲突处优先）

### 10.1 接通学习通路，不把默认归零当成长记忆

q 采用残差伪观测 `a = m_prior + a_head(c, tanh(m_prior), log1p(diag(P_prior)))`。观测噪声 `R = diag(diag(P_prior) * exp(log(10) + 6*tanh(eta_head(...))))`，再作完整 Joseph 更新。零创新不再把每次后验均值拉回零；新的有界先验特征避免线性正反馈失控。协方差仍可随证据收缩，但不把其数值大小解释为生理置信度。

先修复这一参数化，再做固定 FIT 小样本记忆和真实 6–8 小时事件的自动微分／有限扰动核对。它们只准入学习通路；有用的长历史必须经严格 H 重拟合在独立目标上验证。E1125 的部分 INNER 间期 episode 不足八小时，指定 H=8 不能改变临床 reset，应报告实际历史。

### 10.2 各时距保持自己的目标支持

训练物理目标池为所有合法 `(target,h)` 的目标并集；每个被采样目标只计算该 h 的合法预测。每个时距和视图的归一分母按自己的全 FIT 有效单位数乘以 `有效批量 / 物理目标池大小` 固定，因此拆 microbatch 不改期望权重。短期目标不得因为同一个目标的两小时 query 不合法而被删除。各 h 权重为：h=1 占 0.625，另外三档各 0.125；数量、空间、形态各占主损失 1/3，负荷另以 0.25 权重保留。

### 10.3 当前可运行的后端与分析口径

准入配置为 GPU 训练和训练期评分、CPU 冻结消费者／配方生成／独立基线。第一次正式启动后，训练又出现一次异步 CUDA indexing assertion；同步从同一 checkpoint 重放越过失败步而未复现，因此 traceback 不能定位确定性坏批量。潜动力学中唯一的动态 `index_put` 已替换为固定上三角基底收缩；注册测试证明矩阵值和参数梯度与旧公式逐位相同。受影响的首次启动全部归档并从零重跑，不能混入新源码结果。由于原异步错误不能复现，这是一项有证据的风险消除，不宣称唯一根因已证明。GPU 冻结消费者仍不进入长跑派发；CPU 路径须完整通过并核对与同 checkpoint 的 GPU 主评分一致。

RELAX 的时间常数只从两个 INNER 的固定 0.5/2/8/24 小时格点按平均秩选择；outer 使用 FIT 重新估计的状态分布，不能看 outer 选择 tau。精确 K-subset 是同一条件身份拟合 head 的次级分数，其跨 community 截距没有单独为 K-subset 拟合，不能当作另一个训练充分的 decoder。

S-A 分开 `[-2h,-30min)`、`[-30min,-5min)`；raw 预测率包含时钟，额外给同一 query、同一时钟、同一噪声下相对 FIT RESET 的状态增量。可读近期率再次匹配是另一个估计问题。病例、两个时间窗和伪发作不是独立患者，不报 pooled query p 值。

所有细触点冻结读出，包括 trait 与纯 history，显式接收相同的目标时钟；状态收益不能靠独占已知时钟产生。

现有 S-B 实际可用测量是 **临床发作起点 0–10 秒** 的 1–150 Hz baseline robust-z 空间激活（CAR），不是 EEG 起点 0–10 秒。缓存按临床起点排序、通过 seizure_id 和 EEG 起点交叉核对；状态 query 在 EEG 起点前五分钟。列 FIT trait、已发布近期空间历史及同预算拟合的 trait/history/state/state+history 读出。仅作冻结间期读出与临床早期空间的描述性对应，不称发作路径预测；原先 EEG 起点空间预测仍是缺口。

D-local 仍 `NOT_AVAILABLE`：现有检测依赖既有 block-local GPU 产物，centroid 使用完整 200 秒片段；尚未重建并校验有限右上下文的检测与处理时延版本。本次不把旧包时间改成实时，也不将这一局部依赖伪装为已完成。D-delayed 的实际发生/发布信息完整保留。

### 10.4 首个长跑窗口的有限清单

机器计划先包含 E1125 的五条参考／状态臂：P_stats-state、P_marks-state、可学习 marked-history、固定丰富描述量 history、同 g 的 constant-state。每臂两个前推 INNER 生成配方，outer 三个优化重复；先种子一的完整链再补重复。另列三个测量一致的合成世界各两个输入臂、一个独立实现，以及 S-ID 三臂的首种子。具体条数由机器计划现算。

合成 identity 世界让细形态与细身份共享慢变量，使 producer 有合法的非身份学习信号；零世界断开跨事件慢关系。各一个实现只能检查该实例上的可检出性，不能叫功效校准。定向跨视图、严格历史、其他患者及结构扩展的代码接口保留，但不在首个窗口盲目全相乘；先报告本窗口实际完成的证据链。

可配置两张 GPU 每卡两个训练 worker，另两个 CPU consumer worker；仅在实测准入配置下启动。全局剩余显存低于 6 GiB 时保存暂停，派发新任务须至少 8 GiB 空闲；微批失败只可恢复同一批并累积。每个任务整个执行期持有 OS 锁，两个进程不能同时写同一结果目录。训练截止存为 PAUSED，未完成的配方依赖继续阻塞，不生成伪完成卡。

机器计划是跨窗口 backlog。8–10 小时内能完成的量由实测吞吐、INNER 停止步和消费者耗时决定；不得用共同预算截断慢参考来凑完成度，也不得为显卡占用率启动已知无效比较。
