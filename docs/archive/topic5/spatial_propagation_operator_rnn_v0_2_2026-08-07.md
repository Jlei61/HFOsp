## 一句话

v0.1 学的是一张自由的连线图，结果既认不出哪条连接存在、也认不出活动往哪边走。
这一版把那张图换成**八个有物理含义的数**——活动往哪个方向漂、沿主轴和垂直方向
各扩散多快、衰减多快、局部用完之后多久恢复、外界驱动进来多强——然后问：这么换，
付出了什么代价。

**答案是没有代价。真正够不到的东西，落在两种参数化都没碰到的地方。**

## 一、换成八个数付出了什么代价（n=21）

只有一个对比是干净的。v0.1 的组织场臂和这一版一样，预测都得**经过同一个固定观测核**
投影出去；而 v0.1 的不受约束循环臂用的是**自由稠密读出**。所以跟组织场臂比，
读出方式被固定住，唯一变的是动力学由什么承载。

相对"按各触点平均参与率猜"的静态基线：

| | |
|---|---|
| v0.1 学出来的稀疏图 | +0.0030 |
| v0.1 固定近邻图 | +0.0001 |
| **v0.2 八个物理参数** | **+0.0064**（21 位里 11 位更好，**p=0.517**） |

→ **把自由连线图换成八个物理参数，一分钱没多花**：与学出来的图**测不出差别**，
比固定近邻图好。数值上算子高一些，但 p=0.517，**只能说"不比它差"，不能说"更好"**。

不受约束的循环模型是 **+0.0635**（21 位里 0 位被算子追平，p=9.5e-07）。
⚠️ **这道鸿沟不能算在空间参数化头上**：那个臂同时带着自由稠密读出，
所以它的领先里混着"读出方式"和"不受约束的循环"两件没拆开的事。
下一版第一个该问的就是**给算子配一个自由读出能补多少**（本版没做：会改动已冻结的
嵌套家族）。

⚠️ 跨版本比数的前提已逐条核过：同一批事件、同一个时序划分、**同一份损失代码**
（v0.2 直接 import v0.1 那个模块）、静态臂同构造；做法是**差之差**（各自减自己版本的
静态基线）。两版静态基线吻合到 中位 **0.0002**、最差 **0.0017**。
⚠️ **差点读错树**：v0.1 有两棵结果树，**名字听起来更具体的 `per_subject_budget95`
是当初被截断的那棵**（静态臂每位患者都顶在 epoch 上限、21 位里 12 位仍在改善）；
准的是 `per_subject`。换对树后基线吻合从 0.0008/0.0140 收紧到 0.0002/0.0017。

## 二、空间输运买到了什么（n=21）

嵌套阶梯，每一档只放开一个部件：

| | 相对前一档 | |
|---|---|---|
| **一个有记忆的场**（会衰减、会恢复，但活动不移动） | **+0.0067**，19/21，p=6.7e-06 | 成立 |
| 再让活动**在空间里移动** | **−0.0008**，6/21，p=0.032 | 显著为**负** |
| 再加各向异性 + 有方向的漂移 | +0.0000，14/21，p=0.432 | 无 |
| 再加恢复场 | −0.0002，9/21，p=0.412 | 无 |
| **全部 vs 静态基线** | **+0.0064**，18/21，p=1.3e-05 | 成立 |

**收益全在第一档。**

⚠️ **那个 −0.0008 的显著性是脆弱的**：随队列补齐它来回穿过 0.05——
n=17 时 p=0.0395、n=20 时 p=0.058、n=21 时 p=0.032。
允许的说法是"加上可学的空间输运没有好处，且偏负"；**不宜把"显著变差"当作稳固结论**。

⚠️ 阶梯里原本有一档**同时换了两个部件**（"有扩散但关掉恢复"对"有恢复但没扩散"，
两者互不包含、方向还相反），它的平结果曾被读成"扩散没用"——**它根本没说这个**。
干净的嵌套档是"完整算子对无输运臂"（两者都有恢复，只差三个输运参数），
两臂本来就在跑，加上去不花额外算力。非嵌套那档保留在正文但**不发部件判决**
（`NOT_NESTED`，n=21 为 +0.0000，11/21，p=0.495）。

⚠️⚠️ **无输运臂并不是空间盲的**：注入和读出都过观测核，一个触点响了就在平面上点一个
斑、再按核的重叠读回来 → 它**本来就是"离得近就互相预测"的空间模型**，只是宽度固定。
输运额外给的只是**可学的**宽度和方向。所以那个负号说的是"可学的那部分没加成"，
**不能读成"间期传播不是空间的"**（此句已写进收官报告的自动措辞守卫）。

**不重训的关断对照**（拿拟合好的模型直接改，五种改法，n=21）全部 ≈0：
关掉输运 −0.0000（9/21）、**漂移翻号 −0.0000（9/21，p=0.973）**、去掉恢复 −0.0004、
拉平两个扩散系数 +0.0000（14/21，p=0.0084）。
→ 拟合出的扩散**很大**（轴向中位 0.099，上界 0.12 就在旁边），**模型在用输运，
只是把它归零对预测没有影响**。

✅ **不是预算截断造成的**：105 个单元**全部靠早停自己收敛、零个撞 epoch 上限**
（中位 49、最大 205，上限 400），五个臂一致。v0.1 正是栽在"承载否定结论的臂被截断"。

## 三、为什么空间那几档是平的：不是模型不行，是这个尺度上看不见

三条结果指向同一处但各自解释不了自己：合成数据上**认不出活动往哪边走**；
把拟合好的模型里的输运**整个关掉，预测一点不变**；**放开输运重新拟合反而偏负**。
"模型不行"能一句盖住这三条，而且是错的。

**一个触点不是采一个点，它对半径 6.0 毫米的一片组织取平均**（宽度由触点间距定）。
而拟合出的那团活动，**整段事件一共只移动 5.4 毫米**——读出半径的 **0.54 倍**，
**21 位患者里 17 位**不到 1 倍。

> **输运发生在单次读数内部。** 不是没有传播，是这个尺度上看不见。

### 去证伪这个说法

6.0 毫米有一半是建模选择（读出核宽定为触点间距的一半）。把网格、生成参数、
事件长度全冻住，**只动读出宽度**：

| 读出半径 | 方向占信号 | **方向相反的两个生成器，产出的名次有多少不同** |
|---|---|---|
| 12 mm | 2.8% | **7.6%**（守卫判无信息，剔除） |
| 6 mm | 2.4% | 48.9% |
| 3 mm | 5.7% | **85.2%** |
| 1.5 mm | **7.5%** | 64.0% |

**最右边这列在任何拟合之前就成立**：读 12 毫米的一片时，两个把活动往**完全相反**
方向推的生成器，产出的事件 **92% 一模一样** → **方向是被观测抹掉的，不是被估计器
丢的**，换任何估计器都救不回来。

✅ 判决：核宽确实是约束（`KERNEL_WIDTH_IS_THE_CONSTRAINT`）。
⚠️ **但天花板必须一起报**：缩到 1.5 毫米（假设值的四分之一）方向仍只占 **7.5%** →
**缩到物理上说得通的宽度也救不回方向**。
⚠️ 非单调：最窄那格不是信息最多的（盘小到够不着邻居触点，事件退化成各触点偏置）→
**存在一个最优宽度，且不是最小的**。

## 四、能不能预测一个从没训练过的触点（n=21）

每位患者扣掉四分之一触点：不进训练的名次序列、不进训练损失、测试时不喂给模型，
连它自己"平时爱不爱发放"的那个参数也换成其余触点的平均值。扣完之后，
这个触点身上**只剩"它在哪"**。

对照臂对扣掉的触点**一无所知**（全给同一个分数）。三臂扣的是**同一批触点**，
由结果文件里记录的触点号交叉核对（`arms_withheld_the_same_contacts: true`）。

| 相对"一无所知"的地板 | |
|---|---|
| 无输运的场 | **+0.0036**，17/21，p=0.026 |
| 完整算子 | **+0.0032**，16/21，p=0.009 |

→ ✅ **模型确实能用"它在哪"预测一个没见过的触点，好过什么都不知道。**
效果不大（约是它相对静态基线优势的一半），但方向明确。
→ **两个臂打平** → 起作用的还是**固定观测核带来的空间结构**，不是可学的输运。
与阶梯完全一致。

⚠️ **只报绝对分数**，不报"相对自己基线掉了多少"——一个到处都更差的臂本来就没多少
可掉的（v0.1 正是靠后者把冠军发错了人）。
⚠️ **扣掉的触点上的损失不能跟留下的比**（只扣了四分之一，"这一步不是它"本来就更好猜，
数值天然更低）。
⚠️ **地板臂的命中率不可解读**：它给扣掉的触点打分完全相同，取最大值退化成
"挑编号最小的"，而编号沿电极杆连续 → 沾了编号顺序的光。损失不受并列影响，
比较用的是损失。

## 五、这个算子是这位患者的吗（n=21）

同一患者两次拟合比跨患者更像：**+2.483，20/21，p=1.9e-06**。

⚠️⚠️ **先说混淆再看数字**：同一患者的两次拟合共享**这位患者的电极几何**，
而系数是按格点表达的，所以"患者特异的拟合"本身不等于"患者特异的机制"。
量过：与四个不带机制的患者级描述量（格距、读出核宽、触点数、事件长度）里
最强的相关是**恢复衰减系数与事件中位长度，Spearman 0.70**——**越过 0.6 判据线**。
→ 按判据：**拟合出的系数跟一个不带机制的患者级量跟得这么紧，不能当作
"患者特异机制"的证据**。

## 六、恢复门：三层只过一层（先于任何病人数据）

- 往哪边流 **认不出**（符号一致率 0.500 = 纯瞎猜，线 0.80）
- 扩散多各向异性 **认不出**（rho −0.111，线 0.60）
- 局部恢复有多强 **认得出**（无 0.510 vs 强 0.939）

**廓似然把"认不出"升级成有机制的结论**：其余参数钉在生成真值上只扫一个——
损失随 |v| 变 0.041，随 v 的**符号**只变 0.0010（**2.4%**，六微步时 0.6%）。
⚠️ 恢复强度那条廓**不能读极小值**（改它会同时改变整个场的幅度，混了校准进去；
真值 0.2、极小值却在 0）；该层证据只能用门自己的"重新拟合后跨生成器比较"。

**门的定位（用户明确要求）**：它界定"哪一层参数能按患者报"，**不阻断队列**——
预测阶梯从来不需要知道参数真值。按判决：**只有恢复强度允许按患者报参数**；
漂移与各向异性只能报"在此观测下不可辨识"。

## 七、建设期抓到的、会静默出错值的缺陷

1. **留出触点删空了答案**：扣掉的触点从**所有**划分里删干净 → 它从不出现在目标里 →
   评分变成"你能不能预测这些触点从不参与"，白送（损失 0.0006、命中 0.0000）。
   修法：扣法**不对称**——训练删掉并补齐名次空洞（`densify`），
   **测试保留真实名次当目标**，只把它从输入里抹掉（不驱动状态、不标记已招募、
   每一步仍是候选）＝强条件。
2. **扣掉的触点还带着自己的自由参数**：训练里它是"永远不发放"的负例 → 参数被学成
   "这个触点不会响"＝**把声称扣掉的答案还给了模型**。修法：移出训练损失 +
   测试时换成其余触点的平均值（`neutralise_holdout_bias`）。摘掉但不换 → 偏置停在 0
   ＝"比任何真实触点都更容易发放"，是反方向的同一个错。
3. **自由生成塌成长度 1**：挑下一个触点用了固定概率阈值 0.5，而十几个候选里只有
   一个对、校准好的概率本来就在 0.07 左右 → 每次第一步"没人当选"而停。
   **那是阈值的行为被当成了模型的行为。**（真实数据里 100% 的名次上恰好一个触点，
   已核。）改成"取最可能的未招募触点"后露出真现象：模型**停不下来**，
   一路招募到触点用完。
4. **每次拟合都 NaN**：停止头要对场的空间扩展开方，整流后未驱动时场恰好是零，
   `sqrt(0)` 梯度无穷 → 方差先 clamp。
5. **两个漂移方向相反的生成器产出一模一样的事件**（原注入增益下场对 logit 只贡献
   0.04，而偏置标准差 0.3 → 算子在自己的合成数据上是舍入误差）→ 现在是**硬守卫**：
   相反漂移必须在 ≥15% 的名次上不同，否则脚本停。
   **可迁移**：从没信息的生成器得出的"不可恢复"描述的是采样器，不是可辨识性。
6. **显式扩散没有稳定性约束**（跑到 0.97，而二维显式格式要求 ≤0.25）→ 有界映射
   （D≤0.12、|v|≤0.5）。⚠️ 副作用：**顶到边界的系数是被截断的值不是估计**，
   **12/21** 个单元顶到，每个都标了。
7. **驱动脚本在运行期间被编辑 → 最终一遍静默跳过三个分析阶段**。bash 恢复时用的是
   **字节偏移**，插入内容把后面全部移位，它落在了不是命令开头的位置。
   后果：收官报告一度混着 17 人的空间尺度、20 人的跨版本、21 人的阶梯，
   **而 16 项验收全过**——因为门只问"存不存在""覆盖多少"，从不问"是不是最新的"。
   修法：门加两条新鲜度检查（每个汇总产物必须比它所汇总的最后一个单元新；
   收官必须比它引用的所有文件新），驱动脚本顶部写明禁止运行时编辑。

## 八、如实记录而不是绕过去

- **只用训练触点定轴 = 未达成**（`TRAIN_ONLY_AXIS=NOT_ACHIEVED`）。轴由传播端点导出，
  重建要重接上游整条链；半吊子版本会静默污染 → 标记 + 写原因，验收门强制要求
  这个标记存在。几何相关结论沿用 v0.1 的**回溯性**状态
  （`GEOMETRY_STATUS=RETROSPECTIVE_TEST_INFORMED_GEOMETRY`：平面是用整段记录估的，
  不能说这套几何在记录前就能知道）。
- **留出触点只跑一个事先指定的强条件**（v0.1 跑了两档都没指定主档，白花多重校正额度）。
