## 一、先用几句话讲清楚

两位癫痫患者的皮层表面各贴了一张 8×8 的方形电极片，64 个触点像棋盘格一样排列，彼此的上下左右邻居关系是**物理上确定、可以直接量出来的**。每当出现一次高频放电事件，参与的触点会有先有后地放电，形成一串先后顺序。我们训练一个很小的模型，让它看着"已经放电的触点"去猜"下一批会放电的是哪几个"，并且**只用它从没见过的那几段记录来考试**。

我们问了两个**互相独立**的问题：**第一，在训练开始之前就把模型内部的连线固定成"真实的上下左右邻居"，比固定成"触点位置被打乱但每个触点连线数一模一样"的假格子，学得更好吗？** **第二，等模型训练完、一个参数都不再改动之后，把"通往某一小块连续区域"的那几条真实局部连线调弱，会不会比调弱同样多的、散布在别处的连线，更严重地伤害对这块区域的预测？**

结果是：**第一个问题在触点密度和事件数都更高的那位患者身上是明确的"有帮助"（真格子赢了全部 31 张假格子），另一位患者方向一致但没有跨过严格门槛；而且这个好处在空间上极其局部——只在"下一个触点就在正上下左右紧挨着"的情况下存在，隔一格以上反而略差，并且它需要模型每步在内部多传一跳，少传那一跳好处就没了。第二个问题在两位患者身上都是"没有看到"。**

一句话结论：**真实的物理邻接更像一个有用的"训练时约束"，而不是模型训练完成之后必须继续走的唯一通路。**

## 二、我们具体做了什么

### 2.1 数据

| | E958 | E1084 |
|---|---|---|
| 电极片 | 8×8 方形皮层电极片 | 8×8 方形皮层电极片 |
| 可用触点 | 64 个（全部可用） | 63 个（1 个触点在患者配置里被标为坏，**在做参考电极重算之前就删掉**，不插值、不补造、不跨空位连线） |
| 高频事件总数 | 163,438 | 7,918 |
| 训练 / 校验 / 考试 | 108,061 / 32,463 / 22,914 | 5,728 / 650 / 1,540 |
| 考试段里的有效"下一触点"决策 | 211,670 | 6,059 |
| 角色 | 主患者 | 预设的复制患者 |

**关键纪律**：切分是按**整段记录**分的，不是按事件随机分——同一段记录里的事件只能整体属于训练、校验或考试之一，所以"考试"确实是模型没见过的时间段。凡是与发作（按医院数据库里记载的完整脑电起止时间）重叠的窗口全部剔除；发作相关的任何量、以及临床结局，都**不参与训练、不参与选模型**。触点参与与否只由该触点自己的高频检测决定；没参与的触点在数据里是明确的"缺席"标记，**不会被当成"排在最后"**。

### 2.2 第一个问题：训练时给正确的邻居有没有帮助

我们把模型内部的连线在**训练开始之前**固定成四种样子，四种从**完全相同的初始参数**出发、用**完全相同的训练预算和停止规则**从头训练，每种跑 3 个随机种子：

1. **真实的上下左右邻居** —— 按电极片上的实际位置连。
2. **触点位置打乱** —— 把触点的身份在"角/边/内部"三类里互换，再连同一张棋盘格。结果是：每个触点连出去几条线、总共几条线、是不是双向、整张图的数学性质**全都不变**，唯一被破坏的是"谁和谁真的是邻居"。我们准备了 **31 张**这样的假格子（它们跟真实连线只有约 7% 重合）。
3. **每个触点连线数不变的随机连法** —— 连线数守恒但完全不保留棋盘格的形状，同样 31 张。
4. **线是真的、但训练答案被打乱** —— 保留每个事件最前面 3 步，把后续的部分跟别的事件的后续换掉（只在训练和校验里换，**考试的答案不动**）。这一档回答的是"事件后续的真实顺序本身是否携带可学的信息"。

**如果真实邻接不重要**，把真格子和 31 张假格子放在一起排名次，真格子应该落在中间（32 个里平均排第 16–17 名）；它排第一的概率只有 1/32 ≈ 3.1%。

### 2.3 第二个问题：训练完之后模型还非走这些线不可吗

模型训练完成、**一个参数都不再改动**。我们只把"从区域外进入某一块连续 2×2 小方块"的那些有向连线的强度乘上 1.0 / 0.75 / 0.5 / 0.0 四档（**只切进去的方向，不切出来的方向，也不切小方块内部的线**）。

对照是 **32 组分散连线**：条数一样、两端触点各自的连线数类别一样、训练后的权重大小分位也配平，而且**完全绕开这块小方块**，不构成同样大小的连续块。

只评价这样一类决策：**到当前这一步为止模型从来没有碰过这块区域里的任何触点，而下一步至少有一个触点第一次进入这块区域**。这样才是在问"要进去，是不是非走这几条真实局部线不可"。

统计上不把互相重叠的小方块当成独立样本：在每一个"小方块 × 随机种子"的层里，把"真实局部连线"和 32 组"分散连线"的标签互换 20,000 次，看真实的那一组是不是异常地更伤。

## 三、两位患者的主结果表

### 3.1 训练时给正确网格有没有帮助

先说清楚数字的含义：**"预测损失"是模型分给"真正发生的那个下一触点"的概率有多低**——模型越是没料到真实发生的事，损失越大，所以**损失越小越好**。下表的数字是"真实邻接的损失 − 对照的损失"，因此**负号 = 真实邻接更好**。单位是自然对数（nat）：损失差 0.133 nat 相当于把"分给真实下一触点的概率"的几何平均提高约 14%（e^0.133 ≈ 1.14），0.53 nat 相当于提高约 70%。

| | E958 | E1084 |
|---|---|---|
| 真实邻接 vs **31 张位置打乱格子** | **−0.1335，31 张全赢，p = 0.031** | −0.0259，31 张里赢 28 张，p = 0.125 |
| 真实邻接 vs **31 张连线数守恒随机图** | **−0.1360，31 张全赢，p = 0.031** | −0.0312，赢 27 张，p = 0.156 |
| 真实邻接 vs **训练答案被打乱** | −0.0493，3 个种子全部同向 | −0.0607，3 个种子里 2 个同向 |
| 猜中的触点属于下一并列组的比例 | **高 0.058，31 张全赢，p = 0.031** | 低 0.009，只赢 11 张（等于碰运气） |
| 猜对下一组该有几个触点 | **高 0.050，31 张全赢，p = 0.031** | 低 0.004，赢 10 张（碰运气） |
| 什么时候该停 | 略好，赢 23 张，p = 0.28 | 略好，赢 29 张，p = 0.094 |

**注意**：这个检验一共只有 31 张对照图，所以它能给出的**最小 p 值就是 0.031**。E958 拿到的正是这个下限。

### 3.2 好处长在哪里 —— 按"下一个触点离多远"分档

把每一个真正放电的下一触点，按它离当前这批触点最近的那个有多远，分成四档：

| | 紧挨着（正上下左右） | 斜对角 | 隔两格 | 更远 |
|---|---|---|---|---|
| **E958** | **−0.527，31 张全赢，p = 0.031** | +0.136，0/31 | +0.106，0/31 | +0.114，0/31 |
| **E1084** | **−0.190，31 张全赢，p = 0.031** | +0.149，1/31 | +0.224，0/31 | +0.070，1/31 |

对"连线数守恒随机图"这一族，数字几乎一样（E958 −0.534、E1084 −0.204，同样 31/31）。

**这是整个实验里最干净的一条**：两位患者、两族对照图、四种组合，全部是同一个形状——**真实邻接买到的准确度严格长在它自己连出来的那几条线上，代价是所有更远的跳跃都略差一点**。E958 事件多，这份局部收益压过代价，所以整体也赢；E1084 事件少，两边基本抵消，整体只差 0.026，够不着严格门槛。

**诚实的限制**：四个距离档一起做多重比较校正之后，"紧挨着"那一档的 p 从 0.031 变成 0.125。所以这条只能说成"方向完全一致的局部优势"，不能说成"校正后依然显著的独立结论"。

### 3.3 训练后删掉这些线是否有选择性损害

（**正号才代表"真实局部线是必需的"**。）

| | E958 | E1084 |
|---|---|---|
| **修好后的直接检验**（只切进去的线，只看第一次进入的决策） | −0.0036，49 块里 24 块为正，**p = 0.718** | −0.0901，47 块里 10 块为正，**p = 1.0** |
| 剂量越切越狠，损害是否越大 | 否（曲线不单调） | 否 |
| **原始那一版**（同时切进出两个方向，2×2） | +0.014，p = 0.124 | −0.247，p = 1.0 |
| 原始那一版（3×3） | +0.048，20 块里 11 块为正 | −0.264，16 块里 0 块为正 |

E958 的观测值**正好落在自己零分布的正中间**（零分布 2.5–97.5% 区间是 −0.012 到 +0.013，观测 −0.004）；E1084 明显在负侧。**两位患者、两种检验、两种区域大小，没有一项支持"训练后的计算必须继续走这些真实局部线"。**

### 3.4 让模型自己编事件，编出来的空间分布像不像

| | 真实邻接 | 位置打乱 | 随机连法 | 答案打乱 |
|---|---|---|---|---|
| E958 | 0.9244 | 0.9186 | 0.9184 | 0.9013 |
| E1084 | 0.9127 | **0.9184** | 0.9130 | 0.9073 |

四档跨度只有 0.90–0.93，**E1084 的名义最高值甚至落在"位置打乱"那一档**。也就是说：**这张粗的空间分布图对"哪张网络更对"根本不敏感**，判别力全部在逐步的下一触点预测上。四种网络还都把事件编得偏短（E958 编出 11–14 个参与触点 vs 实测 19；E1084 全是 5 vs 实测 10）——这是模型容量的共同限制，不是某一种网络独有的毛病。

### 3.5 换两种做法，结论会不会变

我们预先约定了两项"换个做法再看一遍"的检查，两项都完整跑完（各 192 次训练）。

**做法一：把斜对角也算成邻居（每个触点从 4 个邻居变成最多 8 个）。**

| | 真实邻接 vs 31 张位置打乱格子 | 方向计数 | p |
|---|---|---|---|
| E958 | −0.124 | 31 张全赢 | 0.031 |
| E1084 | −0.037 | 赢 28 张 | 0.125 |

**结论一点没变**：E958 照样全胜，E1084 照样方向一致但不跨门槛。

**做法二：把模型每一步的"内部更新"从 2 次减到 1 次。这一项改变了结论，必须单独说清楚。**

| | 真实邻接 vs 31 张位置打乱格子 | 方向计数 | p |
|---|---|---|---|
| **E958** | **+0.0005（方向甚至反了）** | **只赢 15 张（纯碰运气就是 15–16 张）** | **0.53** |
| E1084 | −0.046 | 赢 30 张 | 0.063 |

**E958 的训练优势在这个变体里彻底消失了。** 这不是"敏感性检查没问题"，这是给主结论划了一条边界。

为什么会这样，可以讲得很具体。模型每看到一批同时放电的触点，会在内部走两步：第一步把"这批触点刚放电"这个信息灌进去，第二步让信号在连线上再传一跳，然后才读出"下一批是谁"。**只走一步的话，刚放电的那个触点在这一次决策里根本来不及影响它的邻居**——这不是猜测，代码里有一个回归测试专门验证了这件事：一步版本里，"当前触点的输入"对"邻居触点得分"的影响精确等于 0；两步版本里不等于 0。

而 E958 的全部优势恰好只长在"下一个触点就在正上下左右紧挨着"那一档。把"刚放电的触点能在本步内推动邻居"这条路掐掉，优势就没了——两件事互相对得上。另外一个数字也吻合：E958 少走那一步，整体损失从 3.270 涨到 3.389（差 0.119），而真格子相对假格子买到的量是 0.133——**同一个数量级**。

三点纪律：

1. **主结论仍然是两步版本的结论**（这是事先冻结的正式架构，一步版本事先就登记为"架构敏感性，不替代主检验"）。
2. 但主结论**必须带上"在两次内部更新的架构下"这个前提**，不能写成"真实物理邻接普遍有助于学习"。
3. 上面那段"为什么"是**对两个已观测结果加一条已验证的架构性质的一致性解读，不是一个独立的检验**，不能写成"我们证明了这个机制"。

E1084 那个本来就不跨门槛的优势**不**依赖两步架构（一步版本反而略强一点）。两位患者在这一点上方向不同，但只有 31 张对照图、p 在 0.125 和 0.063 之间挪动，这个差别本身在噪声范围内，**不当作独立发现报告**。

**做法三（数据侧）：把"多近算同时放电"的阈值从 5 毫秒改成 0 / 2 / 10 毫秒。** 这会把"一个事件被切成几步"改变三倍以上（E958 从中位 22 步变到 7 步），但模型自由生成出来的空间分布图几乎不变（相关系数全部 ≥ 0.997）。这一项只改数据构建，不重训模型。

## 四、最终科学结论

> **在高密度皮层电极片上，真实的上下左右物理邻接是一个可辨识的训练时归纳偏置：把它作为固定约束交给模型，比交给触点位置被打乱、但连线统计完全相同的假格子，在未见记录段上预测得更准（E958 明确成立，E1084 方向一致但未跨过严格门槛）。这个优势在空间上严格局限于"下一个触点就在正上下左右"的转移，两位患者一致；并且它依赖模型每步走两次内部更新——只走一步时 E958 的优势完全消失。但模型训练完成之后，削弱通往一块连续区域的真实局部入边，并没有比削弱同样多的分散连线造成更大的损害。因此，真实的局部几何更像一个有用的、而且是有条件的训练归纳偏置，而不是当前证据下唯一且必要的在线计算通路。**

### Panel A（上半部分）—— 训练时给的网络，和它带来的预测差异

**上排四张棋盘小图 · 画的是什么**
每张都是同一张 8×8 电极片。淡灰细线是电极片真实的上下左右骨架（四张相同，只作空间参照）。中间那个红点是同一个被举例的触点，从它伸出去的**粗彩色线**表示"在这种条件下，模型被允许让这个触点直接影响哪几个触点"。

- 蓝色 = 真实的上下左右邻居（四条线整整齐齐指向东南西北）。
- 橙色 = 触点位置被打乱后的假格子（同样四条线，但指向乱七八糟的远处）。
- 紫色 = 连线数守恒的随机连法（同样四条线，指得更远更散）。
- 灰色 = 线还是真的（所以形状和蓝色一样，**这是设计本身，不是画错**），被打乱的是训练时给的答案。

**下排两张点图 · 每个点是什么**
横轴是三种对照条件，纵轴是**这个对照比真实网格多出来的预测损失**（单位：自然对数 / 每个真实下一触点）。虚线 0 表示打平，**点在 0 以上就代表真实的上下左右邻居更好**。

- 前两列每一个点 = **一张事先冻结好的对照图**（各 31 张），取该图 3 个种子的中位数再减真实网格的中位数；淡色小提琴是这 31 个点的分布形状，黑色短横是中位数。
- 第三列只有 3 个点，因为"答案打乱"只有 1 张图 × 3 个种子，所以逐种子配对相减，不画小提琴。
- **星号只在"真实网格 vs 31 张位置打乱格子"的单侧检验 p ≤ 0.05 时才画** —— 只有 E958 有。

**读者应该看到**：E958 的 31 个橙点和 31 个紫点**全部落在 0 以上**（真格子对所有对照图全胜）；E1084 的两团明显更贴近 0，还有几个点掉到 0 以下。

**科学意义**：这一排回答"训练时给正确的物理邻居有没有帮助"，且回答的是**患者内**的问题——两位患者分别报告，不能合并成队列结论。

### Panel B（下半部分）—— 训练完之后削弱局部连线

**上排两张棋盘小图 · 画的是什么**

- 红色那张：粉色的四个触点就是那块连续 2×2 区域，红色箭头是**从区域外指进区域内**的有向连线——这正是正式干预真正削弱的那些线（不含反方向、不含区域内部）。
- 灰色那张：同样条数的分散连线**示意**。请注意这只是示意；正式的 32 组对照是对每一块区域、每一个种子**重新生成**的，并按条数、两端连线数类别、训练后权重大小分位配平。

**下排两张曲线图 · 每条线是什么**
横轴是"入边强度还保留百分之多少"，**从左到右是 100% → 75% → 50% → 0%（越往右切得越狠）**。纵轴是"切真实局部入边"比"切 32 组配平分散线的中位数"**多出来的**预测损失，**只统计那些第一次进入这块区域的决策**。

- 每一条淡线 = 一块合格区域在 3 个种子上的中位响应（E958 49 条 / E1084 47 条）。
- 色带是区域之间的四分位范围，粗线加空心圆是这位患者的中位数。
- **星号只在分层随机化 p ≤ 0.05 时才画 —— 两位患者都没有。**

**读者应该看到**：E958 的粗线**从头到尾贴着 0 平走**（淡线朝正负两侧对称散开，说明区域之间有大有小但没有系统性偏向）；E1084 的粗线**随着切得越狠单调往下掉到 −0.09**（也就是切真实局部线反而比切分散线**伤得更轻**）。

**科学意义**：这一排独立回答"训练好的模型是不是还非走这些真实局部线不可"。**图上没有任何暗示这一条为阳性的元素**——这是有意为之。

## 六、边界与限制（集中放在这里）

1. **两位患者是分开报告的两个个案，不是一个队列。** 不能把 E958 的结果写成"队列级别的皮层电极机制结论"，也不能因为 E1084 方向一致就写成"跨两位患者复制"——它没有跨过严格的图零模型门槛。
2. **模型里的"连线"是计算约束，不是解剖。** 它表示"允许哪个触点在一步之内直接影响哪个触点"，**不是白质纤维、不是解剖通路、也不是什么"组织骨架"**。同理，调弱这些连线**不等于**自然发生的组织损伤。
3. **"真格子赢了假格子"不等于"找到了唯一正确的连接方式"。** 这个实验能说的是"真实邻接比这两族对照更有用"，不能说"没有别的连法能达到同样效果"。
4. **训练后删边阴性，不能反过来说"模型只学到了共现"。** 阴性只说明"没能证明这些具体的局部线是在线必需的"，不是"证明了它们无关"。同样，训练时阳性也不能顺推出在线必需——这是两条各自独立的证据。
5. **E958 的模型没有完全收敛。** 192 次正式训练里有 103 次跑满 100 轮上限时验证损失还在下降。四种条件的训练预算完全相同，所以**比较是公平的**，但绝对损失数字不应被当作收敛值引用。
6. **距离分档那条最漂亮的结论没有通过多重比较校正。** 四个距离档一起校正后 p = 0.125。它的说服力来自"两位患者 × 两族对照 = 四种组合全部 31/31 同向"，而不是单个 p 值。
7. **自由生成的空间分布图不是一个有判别力的终点。** 四种网络都能做到 ρ≈0.90–0.93，且四种网络都把事件生成得偏短。不要用这张图去论证任何一种网络更好。
8. **修复后的检验是解封之后才冻结的。** 原始那一版同时切断了进出两个方向，因此它的负号**不能**被解释成"局部连接有保护作用"或"进入区域不需要这些边"。修复由 E1084 的数据触发，所以 **E1084 的有向结果标为"开发用"，E958 的有向结果在未查看前锁定为"独立确认"**。修复后的检验**不能**回写成原始的预注册主检验，原始结果也**不能**删除。
9. **这里的"群体事件"是由一小组高活跃触点触发后再回填全网格的**，不是"64 个触点无条件同时被发现的全脑事件"。触发触点集合只由训练段的计数决定，随后冻结用于校验段和考试段。
10. **训练优势是有前提的，不是普遍成立的。** 它依赖模型每步走两次内部更新；只走一步时 E958 的优势完全消失（见 §3.5）。写这条结论时必须带上这个前提。同时，一步版本是事先登记的**架构敏感性检查**，它的作用是给主结论划边界，**不能反过来当成主结论、也不能当成"证明了某个机制"**。
