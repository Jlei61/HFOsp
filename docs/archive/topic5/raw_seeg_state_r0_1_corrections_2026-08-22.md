# R0.1 报告更正记录（2026-08-22，用户复审后）

本文件是**更正的唯一权威版本**。凡与之冲突的早期表述以本文件为准。

## C1. 「21 参数岭回归」——错

低容量频谱自回归不是一个 21 参数模型。它是**每个 horizon、每个频带各一套**
20 个系数加 1 个截距：

    4 horizon × 12 频带 × 21 = **1008 个系数**

对比网络的 1 492 496 个参数，比值是 **1481 倍**，不是七万倍。结论方向不变
（它仍然远小于网络且赢了），但量级必须写对。
来源：`src/topic5_raw_seeg_state/baselines.py`（每 (h, f) 独立拟合一次 ridge）。

## C2. 「学出了 1 分钟到 48 小时的时间常数」——错

那些尺度是**初始化时就按对数均匀铺好的**，不是数据识别出来的。实测 620 号
60-epoch 臂训练前后：

| | 值 |
|---|---|
| 初始化 | 1.0 1.7 2.9 4.9 8.4 14.2 24.2 41.2 70.0 119.0 202.4 344.3 585.5 995.7 1693.4 2880.0 |
| 训练后 | 1.3 1.8 3.6 6.9 10.3 15.3 25.7 42.0 84.5 136.2 237.6 447.9 551.1 969.0 1667.8 2812.2 |
| 相对变化 | **中位 11 %，最大 40 %** |

正确表述：**模型有能力表示这些尺度**（相对上一版 `softplus` 把 τ 压到秒级是真实
改进），但**不能说数据识别出了这些时间常数**。

## C3. 「620 号在 100 分钟赢过 persistence」——不能作为亮点

620 号 0.969 对 1.098 是赢了，但 **958 号没有复现**：完整臂约 2.44，persistence
约 1.43，输得很清楚。一处出现、一处反向，不构成亮点，只能作为待观察的模式。

## C4. 「8 个作业完成」——错

复核时是 **7 个 DONE + 1 个 RUNNING**（958 号的遮历史臂在跑）。报告必须区分
完成与运行中。

## C5. 60-epoch 臂排除了什么——范围被我写宽了

它**只**排除了「在同一配置上继续加 epoch」。它**不**排除：表示瓶颈、优化目标
与科学目标错配、优化结构问题。三者都仍然在桌面上。

## C6. 「124 个测试 + 8/8 集成闸门」证明了什么——范围被我写宽了

它们证明**实现满足了合同**。它们**不**证明这份合同能回答 H1–H3。

## C7. 图 R1 的措辞

粉色框当前写 `State`。在现有证据下应写 **candidate latent code**——它是否构成
「状态」正是待检验的事，图上不能先替结论下定义。

## C8. 阴性结果的适用范围（口径）

R0.1 的阴性**只反驳**「10 分钟 raw encoder + 32 维全局 latent + 固定衰减旋转 +
频谱预测」这一个组合，**不反驳** H1–H3，也不反驳「连续脑电中存在可演化低维
状态」这个命题本身。逐条对照：

| 假设 | R0.1 是否直接检验 | 新增支持 |
|---|---|---|
| H1 慢状态开放环预测未来 IED repertoire | 否（预测的是宽带频谱场） | 无 |
| H2a 状态改变单次 IED 的参与/顺序/分岔 | 否 | 无；旧 Epi-PRSSM 结果不受影响 |
| H2b 间期状态连接发作前及早期募集 | 否 | 无 |
| H3a IED exposure 更新未来间期功能状态 | 否 | 无 |
| H3b 这种更新参与间期—发作转换 | 否 | 无 |
