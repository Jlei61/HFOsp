## 0. pilot 是什么，不是什么

pilot **不是结果**。它是两件事：

1. **工程闸门**——这条链路端到端能不能跑、数字有没有非有限值、断点能不能续。
2. **超参冻结的依据**——在花 48 个 GPU 小时跑全队列之前，确认当前配置不是明显
   跑不动或明显学不到东西。

pilot 的任何数字都**不得**写进主文档、不得作为科学结论、不得进最终报告的结论段。
它只能进技术报告的"pilot 与超参冻结"一节，并标明是 6 位患者、单 seed。

## 1. 我会看什么（逐项，先写死）

### 1.1 工程健康（不满足就修，不是结果）

| 检查 | 通过条件 |
|---|---|
| 非有限值 | `logs/nonfinite.jsonl` 为空，或全程 < 20 步且未触发中止 |
| OOM | 每个作业最终落档记录在 `run_manifest.json`；`auto_batch_size` 之后不应有作业退到第 3 档 |
| 断点续跑 | 集成闸门第 8 项已验；队列里若有作业被中断，`--resume` 后参数与不间断一致 |
| 墙钟 | 单作业 ≤ 90 min（否则全队列 68 作业会超过 60 h，需要削 epoch） |
| 早停 | `selected_epoch` 不应普遍等于 1 或等于 30——前者说明学不动，后者说明预算不够 |

### 1.2 latent 是否塌掉（这是能否谈一致性的前提）

`n_active_dims`、`z_step_norm`、`z_scale` 每个 epoch 都记。
**任何被标 `latent_collapse=True` 的患者，其一致性数字一律不解释。**
若 6 位里 ≥3 位塌掉，说明 $\lambda_{\text{cons}}=0.1$ 过强，需要先跑
$\lambda_{\text{cons}}=0$ 臂再判断——**这属于修配置，不属于结果**。

### 1.3 阶梯的五级，各自要回答一个问题（620 号）

| 臂 | 它回答的问题 | 我会看的量 |
|---|---|---|
| `h1_only` | 这个编码器根本能不能从 10 分钟波形里读出下一分钟的频谱场？ | 归一化 MSE 与 persistence 的差 |
| `h1_h5_h10` | 加上中等尺度后，短尺度会不会被拖垮？ | h=1 的 MSE 相对 `h1_only` 的退化幅度 |
| `no_consistency` | 一致性项是帮忙还是只在压 latent？ | 与 `full` 比 forecast MSE **和** `n_active_dims` |
| `full` | 完整配置 | 四个 horizon 的曲线 |
| `identity` | 学到的衰减+旋转到底有没有用？ | 与 `full` 的差，**尤其在 h=100** |

### 1.4 广度（其余 5 位，只跑 `full` + `identity`）

看**方向是否一致**，不看显著性——6 位单 seed 谈不上显著性。
具体：`full` 相对 `identity` 的 skill 在 h=100 上的符号，6 位里有几位为正。

## 2. 什么会让我改配置，什么不会

**会改**（属于工程，不属于结果）：

- 单作业墙钟 > 90 min → 降 `train_windows_per_epoch` 或 `max_epochs`，并在技术报告
  写明改前改后。
- ≥3 位患者 latent 塌掉 → 先看 $\lambda_{\text{cons}}=0$ 臂，必要时把默认改成 0
  并**同时报两档**。
- 普遍 `selected_epoch == max_epochs` → 加 epoch 预算。
- 出现任何硬性无效条件（合同 §9）→ 修复并重跑受影响作业。

**不会改**（改了就是按考分选模型）：

- 因为 h=100 上模型输给 mean 就去调结构、调 latent 维度、调频段、调 horizon 集合。
  **h=100 输给 mean 是一个合法的、预注册允许的结果**（合同 §2.3：100 分钟失败
  不否定 1–10 分钟状态）。
- 因为某一位患者难看就把他从队列里拿掉。
- 因为 `common_all_horizons` 窗口集数字不好看就改用 `per_horizon` 当主表。

## 3. 全队列的放行条件

只要 §1.1 的工程健康项全过，就放行 34 位患者，**无论 pilot 的科学方向如何**。

理由：合同 §2.3 明确"不设置一项失败则全部停止的总 gate"，每个 horizon、每位患者
独立报告。pilot 里 h=100 为负也照样要在 34 人上跑完——否则我们报的就是一个
被 6 位患者的表现挑选过的队列，那才是真正的偏倚。

**唯一的例外**：若工程上单作业远超预算，先削预算再放行；削多少写进技术报告。
