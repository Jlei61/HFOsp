# v0.3.4 冻结组织解码器上的跨事件状态：接入与首轮结果（2026-09-03）

## 这一轮做了什么

把预测对象从“未来有多少次事件”换成“未来每一次事件长什么样”，并把打分用的解码器换成那条成熟的组织平面循环网络（局部连接加学出来的远程捷径）。原来的解码器只在记录前 20% 校准，到后段已经过期；这条线的现成权重又是按事件条数切分训练的，训练窗口越过了我们的评价边界。所以按记录时间重新切分并重训解码器，再把跨事件状态接到每次事件开始时的组织初始态上。

## 结论

- 只给解码器一个不看状态的初始态偏置，就拿到了评价期上全部可测的改善（E253 +0.015、E548 +0.012、E583 +0.006，除 E548 外区间在零之上）。那条成熟解码器在记录后段同样存在水平漂移，需要重标定。
- 在这个重标定之上，跨事件状态没有再加任何东西：E253 +0.003 区间跨零，E548 与 E583 精确为零，E1146 为负。错时代价与学到减随机全部跨零。
- E922 无法评价：重训解码器的事件流在评价窗口内没有任何事件，是覆盖空洞，不是阴性。
- 三位患者的仪器已被正对照证明有灵敏度，所以“这个跨事件状态对未来事件的传播形状没有可测贡献”是一条真结论，不是训练不足。
