# v0.3.13：可预测信息、状态保留与跨表达复用的校准方案

日期：2026-09-07。状态：**SUPERSEDED；本提案未经接受或执行，已被用户确认的 v0.4 科学方向替代。**

当前入口：[v0.4 癫痫有效状态科学 spec](group_event_state_v0_4_epilepsy_state_scientific_spec_2026-09-07.md)与[首个证据包](group_event_state_v0_4_0_first_evidence_package_2026-09-07.md)。以下保留为历史设计讨论；“下一轮仅合成/INNER”、两个 INNER 均学习的全局准入、固定大规模合成重复及严格跨视图前置要求不控制 v0.4。数值正确性、可读时间边界、合格参考和针对性校准仍按实际科学依赖保留。

依据：[v0.3.12 独立科学审阅](group_event_state_v0_3_12_independent_scientific_review_2026-09-07.md)。本提案保留原 rich-event 科学目标；对训练准入、合成校准和判读作修订。它不重命名旧结果、不撤销已看过资料的开发身份，也不把本次小规模设计检验当作人体科学结果。

## 1. 科学目标与本窗口范围

最终目标仍是：**完整群体 IED 的参与、时序、延迟、频带和波形信息，是否含有超出粗率／空间统计的未来信息；这些信息是否可由持续状态保留，并在同一患者的其他事件表达和发作中复用；事件是否进一步改变网络状态。**

下一执行窗口只交付：

1. 有明确可检出效应和零假设的合成仪器；
2. 能区分输入不足、状态压缩损失、读出失败、概率分布失准和优化不稳的分层诊断；
3. E1125 两个 temporal INNER 中冻结的训练配方及是否进入下一阶段的决定。

不在此窗口重训人体 OUTER、不扩患者、不扩 latent、不跑动力学结构矩阵、不训练发作 probe。D-local 的既有原始测量依赖／发布时延只读审计可以开展；需要生成新的局部测量时另列具体工作包，不偷偷把小时包提前发布。

后面的历史、跨视图、发作和反馈阶段写明完整路线与条件，但不随校准队列自动执行。既有开发患者授权范围沿用；新患者、原 sealed 数据和临床干预不因这份提案自动开放。

## 2. 先固定三个不同的比较对象

令 H_stats(t) 为查询时合法的粗历史，H_marks(t) 为保留丰富事件的合法历史，Z(t)=q(H_marks(t))。所有方法使用相同未来物理目标 Y、已知时钟／曝光规则和同端点分母。

| 比较 | 定义与判读 | 不允许替代的结论 |
|---|---|---|
| 信息增量 | Δ_info = L(best qualified stats history) − L(best qualified marked history) | 只说明 rich 信息有预测用处，不证明特定 recurrent latent 必要 |
| 表示保留 | Δ_repr = L(marked history) − L(Z)；另报 Z 相对 RESET／常态／短历史 | 状态可非劣保留有效信息；若要宣称建模优势，才要求 Δ_repr 严格为正 |
| 定向复用 | producer 不输入也不训练目标视图及等价代理时，冻结 Z 对另一视图的增量 | 多头联合训练各自阳性并不自动构成共同状态 |

“best qualified”必须由 INNER 选择并冻结。OUTER 上逐端点挑最强参考只能作为保守描述封底，不能当可部署模型或借此选择状态。

状态保留的非劣界限在合成校准前冻结：建议以相关场景可读 oracle 信息增量的 10% 为容忍损失，并给出对应 nats/有效分量的数值。若 oracle 增量接近零，不定义这个比例，也不以非劣证明状态有用。这个 10% 是本提案的研究容忍界限，不是临床标准。人体端点使用合成校准后、人体 OUTER 前固定的绝对界限；不得用人体 OUTER 的观测增量倒算容忍度。

## 3. 测量和目标合同

### 3.1 不丢掉已有 rich 信息

继续保留 P_stats 与 P_marks；rich 输入含实际参与 mask、固定患者内触点词表、时间顺序和真实 dt、相对 delay／并列领先、频带及 waveform 描述、有效性与质量 mask。任何池化／简化参考都须有明确的信息损失说明，不把统计向量重命名成“完整事件”。

跨 block 按 channel names 对齐；不使用 phantom rank；缺测不填成真实零。标准化、词表、编码器和任何 nuisance 模型只来自该 INNER origin 前 FIT。真实 release 决定可读性，未来文件扰动不能改变已发布前缀。

### 3.2 端点保持独立

人体合同继续保留 count、给定事件大小的粗空间、条件形态三类主端点及次要 load；数量阳性不补足形态／空间证据。合成校准可针对单个形态分量检验仪器，不因此改写人体主端点。

本校准阶段指定 `gamma/ied_low log-energy ratio`、h=30 min、W=1 min 为一个主要的形态鉴别任务；其余形态分量、h=1/5/120 分开报告为诊断。选择这一端点是提案中预定的单信号仪器任务；真实人体现有四时距报告照旧，不能事后只留这一时距。

给定未来事件时刻／K／community 的评分明确写为条件预测；不能把知道未来 K 的条件集合分数叫无条件 contact-sequence 预测。same-prefix、next-contact 和 STOP 仍是独立端点，不由集合预测替代。

### 3.3 信息年龄是实验因素

所有结果同时记录 query horizon h、最后可读源时刻的信息年龄 a、实际 a+h。校准至少区分局部即时测量与复制实际小时 release 的延迟测量；两者用同一物理事件路径及噪声，不改发生时刻。

如果真实 D-local 不可用，人体结果限定 D-delayed。数学上短尺度状态可能被延迟消除；此时应比较改善测量是否有价值，不能通过增加 latent 恢复已经不可见的信息。

## 4. 合成仪器：先有已知答案，再给神经状态模型打分

### 4.1 第一层为可精确求解的基准

用一维稳定 OU、stationary 初值、线性 Gaussian 标记测量构建基准。先验证解析传播、过滤均值／协方差和预测边际密度；已知精确滤波不需要训练 q。再通过现有 raw-to-packet 测量路径生成实际 rich 字段，检验信息能否穿过测量和编码。

分别提供：

- 可读信息 oracle：只用 release≤query 的观测，真参数下过滤再前推；这是学习器在该可观察性下的参考上限。
- 潜真值 oracle：直接知道查询时真状态，只作为测量信息损失的上界诊断，绝不能混为可部署预测参考。
- FIT 边际分布、正确时钟／nuisance 参考、固定丰富历史与可学习丰富历史。

对非线性 measurement-consistent 世界，没有解析密度时用独立高精度一维积分或经收敛检验的粒子方法；不把另一个未校准的大网络当 oracle。oracle 的当前状态估计只能读合法过去，真值仅供评估。

### 4.2 世界按不同科学零假设分开

| 世界 | 真结构 | 必须出现的结果 | 用来排除什么 |
|---|---|---|---|
| Z：无跨事件预测联系 | rich 标记独立；保持目标的规定边际与噪声 | 真未来信息增量为零；零步可以是正确最优解 | 正号／初始化差异／坏基线造成的假恢复 |
| M：仅形态慢状态 | 固定率、固定 K／粗组成，形态受 OU 调制，身份独立 | 可读 oracle 和合格 rich history 对形态有增量；count 与 identity 不应被要求阳性 | 把多端点全赢作为成功条件 |
| X：形态与细身份共享状态 | 形态和条件触点集合受同一慢变量调制 | 冻结形态 producer 可支持未监督细身份读出 | 有自预测却不能把信号传到独立消费者 |
| I：独立慢过程 | 形态和身份各自有同尺度 OU，但驱动彼此独立 | 各自历史能预测自己；去除目标视图后的跨视图增量为零 | 把多个可预测视图误读为共同状态 |
| C：已知共同驱动 | 时钟／睡眠样外部变量驱动各视图；无额外共同动态 | 不条件化可有共同相关；条件在可读驱动后无额外共享增量 | 把已知 nuisance 重命名为新病理状态 |

Z 是输入历史联系的零假设；I 是跨视图共享的零假设，不能要求 I 的自身历史无效；C 是超出已知驱动的增量零假设。这三种零假设不能合并。

M/X/I 使用 stationary OU 和相同噪声、计数、粗组成、缺口、release 设计，使跨世界差别尽量集中于待检联系。I 用独立同分布慢路径保留各视图自相关；不能简单把每个事件独立打乱后宣称已控制共同慢驱动。有限实现的边际不强行调成完全相等，以免引入未来信息或人为约束。

先只运行 Z/M 的开发校准，过门后再进行 X/I/C；不同时打开全部维度的矩阵。τ 先固定 2 h，短 τ=5 min 只做时延损失诊断；不把两种时间尺度作为人体多尺度证据。

### 4.3 效应尺度和检出规则

预定三个效应量：0、δ*、2δ*。δ* 定义为可读 oracle 相对无 rich 信息最优参考在主形态任务上降低至少 5% 的条件均方预测误差，再将该效应映射为 nats/有效形态分量。这个 5% 是初始仪器的研究分辨率，不是临床意义阈值；需在开始确认性合成批前固定生成参数和数值。若现有 release 下连真值设计也达不到 δ*，应报告信息不可见并调整观测设计，不增大模型去追不存在的信息。

检出须同时满足：独立测试数据上的配对增量超过预定实用阈值和数值误差；分布质量合格；相应对照有效。不能以 `gain>0` 或 selected_step>0 单独通过。探索多个分量／时距时采用预先定义的 Holm 或 max-T 校正；单主任务和探索任务分别标记。

先用两个新开发 realization 调通分层诊断；最多比较两套有明确失效原因的配方。之后冻结整个训练、选模及检出程序，另用未参与修复的 realization 验证。数据 seed、优化 seed、采样 seed、评分 seed 分开；不同模型臂配对物理数据和随机流。数据实现是合成统计单位，优化 seed 不增加数据样本量。

盲测先运行 12 对 Z/M 实现作为有上限的稳定性检查。它可以决定开发仪器是否值得继续，不能自动打上 `POWER_CALIBRATED=true`。如果要用该仪器支持人体的“可排除效应上界”，则需进一步做整套拟合程序的功效与错误率评估：建议至少 60 个独立零世界及相应目标效应世界，记录检出率的精确二项区间；若区间仍不足以支持预定错误率／灵敏度，则记 `CALIBRATION_INCONCLUSIVE`。60 是起始精度预算而非自动合格门槛；不得根据中途阳性不断追加直到过线。

例如 5 次零失败仍对应单侧 95% 失败概率上界约 45.1%，60 次零失败才约 4.87%。所需重复数必须服务于想声称的误差界限，不能以 4/5 正向代替。[Morris 等, 2019](https://pmc.ncbi.nlm.nih.gov/articles/PMC6492164/)

数字建议在执行计划冻结时可调整，但每次改变必须发生在新盲测数据生成／读取之前；旧合成测试转为开发资料。下一次窗口若只完成 12 对开发稳定性检查，应按实际层级收口，不临时扩大任务量。

## 5. 把失败定位到具体环节

每个开发世界按以下顺序，前一步失败就只修对应环节，不运行后续大队列。

| 检验 | 实际做法 | 不通过时的判断 |
|---|---|---|
| 测量中确有信号 | 可读 oracle 与直接 rich 统计参考恢复注入的单分量；扰动隐藏未来不改输入 | 生成／测量／release 或目标错误，先修数据层 |
| 读出能取出信号 | 给原条件形态头／触点适配器真可读 posterior 或低维预测统计；与 trait 配对 | 优化／读出容量或目标定义问题，不能归罪 producer |
| encoder 没丢信号 | 冻结 encoder 的输出接低容量线性／固定小 MLP，训练与测量同样合法 | 输入编码或池化损失；不扩慢 latent |
| q 能识别状态 | 在合成开发数据中用真状态作诊断监督，比较 posterior 均值误差与覆盖 | 仅定位识别通路；此模型不进入人体科学比较 |
| f 能传播 | 从同一个 oracle 过滤分布出发比较解析 OU 与实际 f | 时间单位、传播或 covariance 问题 |
| 端到端能复现 | 撤掉真值监督，恢复原间期预测训练；与同样合格的 history／RESET 比较 | 优化或统计模型不适配，决定继续修复还是停该家族 |

真值监督与直接 oracle 输入只用于合成诊断，不能混入最终恢复率统计。每个最终恢复结果必须来自无真值监督的正式学习过程。

先给 Gaussian observation 使用经 FIT/真生成噪声校准的固定尺度，确认均值预测可恢复；再开放可学习尺度，检验是否引入虚假改善或外推过度自信。开放前后属于明确配对的诊断，不事后挑较好分布给一个模型臂。若确需 Student-t 等重尾分布，应作为两输入臂共同的测量模型修订，并重新校准。

每个臂同时报告 log score、均值误差、CRPS／适当概率覆盖、尺度分位数、单目标最大损失及尾部贡献；不裁剪正式评分。多路径边际 NLL 应在可解析世界与积分真值比较，防止有限路径在低噪声时严重偏差。数值 SE 应对应最终实际报告的估计量；若报告单次 64-path 分数，就不能用四次分数均值的 SE 为它认证。增加路径数检查偏差和有效路径权重，而不只看重复分数的方差。[Gneiting 与 Raftery, 2007](https://www.eecs.harvard.edu/cs286r/courses/fall10/papers/Gneiting07.pdf)

本轮 Lyapunov 修复仅解决数值内核可靠性的一部分。保留一 GPU 一训练进程、已有 FP64 数值核和逐位恢复；不把这个压力测试当作均值状态、Gaussian 尺度或整个模型已稳定的证明。

## 6. INNER 训练校准：换判据，不只是延长训练

继续使用 E1125 原冻结两个 temporal INNER、原物理支持和 FIT-only 变换。所有新配方只消费这两个 INNER；已看过的原 OUTER 永远标开发资料，不因本次没有读它就重新变为独立验证。

承重训练臂为 P_stats-state、P_marks-state、可学习 marked-history；固定 rich-history／固定分布和 RESET 作为必须合格的参考。首轮保留 I-L-G1 的维度和输入信息量。

每套候选配方用 2 INNER origins × 3 optimizer seeds × 3 承重臂 = 18 个 fit；最多两套候选配方，共 36 个主要人体 INNER fits。先做一套；第二套必须由第一套的具体失效诊断触发，例如尺度塌缩或更新增益漂移，不因结果没赢就自动尝试。固定参考的小容量拟合单列，不扩成神经结构矩阵。合成与人体任务数分别登记，不拿这个 36 冒充整个校准包总数。

训练选择规则：

1. 在共同的 epoch／目标曝光尺度上保存完整候选 checkpoint，不再直接取两个单独 argmin 更新步数的中位数。
2. 每个候选预算在两个起点均有实际验证分数。按同一冻结多视图目标比较两起点的配对结果，同时报告各主端点；可采用预先固定的保守合并规则选择预算，不能由好起点抵消坏起点的灾难性退化。
3. 分清 FIT 优化和 INNER 泛化：FIT 无法学习已知信号是优化／表达问题；FIT 改善而 INNER 变坏是泛化问题，不能继续以更长训练自动补救。
4. 学习资格要求：在应当可学习的正对照，两 INNER 的改善超过 MC 分辨率和冻结阈值；条件形态不能仅靠 count 的改善掩盖；所有注册优化种子都报告。零世界或确实无信号的参考选第 0 步允许作为正确结果，不为了过门强迫学习。
5. 真正应用最终的选模程序后仍要验证跨种子稳定性；种子之间的大分歧归为 `OPTIMIZATION_UNSTABLE`，不能只拿中位数覆盖。
6. 平台停止是局部证据；预算边缘、明显恶化、尺度贴下限、大范围预测饱和分别记录。没有继续改善也可能是坏局部最优，不能用 stop_reason 代替可检出性。

准入实现必须在 `make_recipe`、队列 dependency 判断和 `run_cell` 入口形成一致的可执行阻断：不合格 recipe 可保存审计记录，但状态为 `INELIGIBLE`，不能驱动下一阶段。加入一个真实行为测试：构造 inner0 选 0 步、inner1 选非零步的输入，验证 OUTER 在创建训练工作前被拒绝。只测试字段是否存在不够。

如果在一套已校准简单参考有信号时，两套有明确修复理由的 I-L-G1 配方仍不稳定，停止该 recurrent 家族。保留 rich 输入和科学目标，转用固定丰富历史或低维线性预测表示开展信息可用性研究；不继续堆 latent、换更多优化器或扩大患者碰碰运气。

| `OPTIMIZATION_UNSTABLE` | 正对照有信息，端到端跨 seed 不稳或绝对预测崩坏 | 限定一次有理由的修复；仍失败停本模型家族 |
| `CALIBRATION_INCONCLUSIVE` | 特异性／功效区间过宽、失败多或冻结阈值未区分场景 | 保留分母，暂不解锁人体科学阴性或扩展 |
| `DEVELOPMENT_INSTRUMENT_READY` | 合成分层诊断、盲测稳定性及两 INNER 训练均合格 | 可准备下一个 E1125 开发证据链，但不是 cohort confirmation |
| `POWER_CALIBRATED_FOR_DELTA` | 全拟合程序在对应场景／效应／覆盖下达到预定错误率及灵敏度界限 | 可在相同适用范围估计效应上界；不能推广至所有生理状态 |

仪器就绪无需所有世界、所有端点都“正”。有些世界的正确答案就是零。有哪个科学联系可检验，就开放对应联系；细空间未合格不取消已成立的条件形态证据。

## 8. 校准之后的完整科学路线

### 8.1 E1125：先建立同患者前推链

配方冻结后，按原合法支持完成 P_stats/P_marks 信息增量、Z 相对 RESET／强历史、条件形态与冻结细集合的整链；同一 producer checkpoint 接所有消费者。原 OUTER 已用于开发，不升级为 confirmation；后续独立资料按可用授权另定。

首先比较强 rich history 与强 stats history，避免直接用一个尚未学好的 recurrent 模型替代“信息是否存在”。若 rich history 自身都不增加预测力，而仪器在对应效应和测量条件下有灵敏度，则可以报告该支持范围的增量上界，并停止该状态路线扩容。

若 rich history 有用、状态压缩无效，定位表示损失；若状态非劣保留信息且可冻结迁移，可接受功能表示价值。状态严格优于强 history 是更强的建模优势，需要单独证据，不作为状态存在的逻辑必要条件。

### 8.2 时间组织：只问能区分的必要问题

在上述链合格后做严格 H=0.5/2/8 h **分别重拟合**。主比较用共同可估的物理目标支持，另报各 H 自身覆盖；不能把0.5h 的155个可读查询与8h 的369个查询直接当等价分母。全部编码、GRU memory、m/P 与缓存都在真实历史截断处重启，排除跨 ictal/postictal reset 的窗口。

持续过滤的同 checkpoint HOLD/EVOLVE/RELAX/RESET 为另一个问题：同样已识别状态在无新输入时，显式演化是否有用。若只在短 h 有效，就报告有限预测时距；不要求 120 min 必须阳性才能接受短期状态。

H=8h 不胜2h，且区间足以排除预定收益时，停止长历史必要性主张。若区间过宽，记不可分辨；不要把“更多历史”自动认作下一轮必需设计。

### 8.3 跨视图：排除多个独立状态和共同 nuisance

指定一个目标视图，例如 cross-band delay 或条件细身份。producer 输入和训练 loss 同时移除该视图及等价 raw 代理；只去掉 loss、继续把同一信息放进 encoder 不成立。

主比较为 nuisance／trait／目标视图合法过去、冻结状态、状态加目标历史，给各臂相同已知时钟及曝光。另做空间条件化：给定 K 与粗 community 数量后的组内 contact-set NLL。结果只能支持实际预测到的细分辨率层级，不能升级为传播方向或 STOP。

同步跑已校准 X/I/C 仪器确认该判据：X 检出、I 与 C 的对应条件增量为零。人体背景／睡眠变量仅用有明确测量来源者；时钟不是睡眠标签，没有标签就列为未测共同驱动，不猜造。

如果多个视图仅能各自预测自己，接受多个局部预测过程，停止“共同状态”解释。共享动态可以与视图特有动态并存，不强迫所有信息进入同一个低维成分。PSID/DPAD 可作为后续低维诊断的思想来源；使用发作监督优先化表示属于另一任务，不能仍称完全间期训练的迁移。[Sani 等, 2021](https://www.nature.com/articles/s41593-020-00733-0)，[Sani 等, 2024](https://www.nature.com/articles/s41593-024-01731-2)

### 8.4 发作：关联、表达和风险分别验收

producer 始终只按间期 INNER 冻结。S-A 先保留原时钟／曝光匹配，再报告加入近期率后的条件增量；在完全相同病例和 case-query 支持上作前后对照，并单列因匹配丢失的人群和时间。

S-B 只有在间期细集合适配器有合格学习／校准后才支持迁移判断；若又选初始化，明确只剩 trait 关联。当前 clinical-onset 0–10s 不是 EEG onset 或完整传播路径，需验证 EEG/clinical 时间差后另定义对应端点。

S-C 必须先有整个分析日历的在险分母、全部发作／无发作时段、观察缺口、删失及 postictal 定义。按前推风险集报告 log score/Brier、校准、灵敏度与时间在警报内；事件病例富集采样不能直接给绝对风险。未达到这些条件时维持 NOT_ESTIMABLE，不用病例排序代替。

睡眠、药物调整、记录变化与发作可能同源影响 IED。可测的来源进入预定条件参考；不可测的驱动限制机制解释。某一 state 不转移至发作，不否定它对间期形态的局部预测价值。稀少发作的类型、发生风险、空间演化、持续时间不得混成一个合成指标。[Proix 等, 2021](https://pubmed.ncbi.nlm.nih.gov/33341149/)，[Schroeder 等, 2023](https://academic.oup.com/braincomms/article/5/5/fcad205/7226358)

第二位已有授权的开发患者只在 E1125 的仪器和配方完成冻结后按预定顺序进入，不按其既往阳性大小挑选。正式人群推断以患者为单位；多个优化 seed、事件和时间窗都不是患者复制。

### 8.5 结构必要性：有待解释的状态后再做

先比较同 q/g、同容量约束下的线性 f 与一个小非线性残差 f；再按需要比较单尺度与多尺度；耦合另做一项。每次只改变一个承重因素，避免把 C-N 对 I-L 的差异同时解释为非线性和耦合。

非线性 observation mapping 的优势归于读出。τ 是响应／衰减时间，不是周期；多个学得 τ 也不证明生理上有多个独立慢过程。通过功能干预和对未来预测的增量界定有效响应尺度，latent 坐标本身可重参数化。

如果简单模型在允许误差内保留全部有效预测信息，则接受简单模型，停止复杂结构必要性主张。原科学目标不要求最终模型必须非线性。

### 8.6 IED 反馈：保留最终问题，但不从 observer 偷渡

沿用原 H3 的两种估计问题：burden effect 不回归掉待研究窗口自身的 count/rate；content effect 固定事件时刻和数量，仅比较 marks 的额外作用。

至少比较三模型，observer 与已知共同驱动参考一致：M0 事件仅提供观测，不进入生成状态转移；M1 低容量、带符号的 count/event jump；M2 低容量 mark-specific jump。容量／截距配平，允许不同事件类别产生相反作用。所有比较从相同 pre-state 和曝光窗出发，后续目标完全未见；不能用已经同化当前 IED 后的 hidden state 同时充当原因和结果。

先在已知 common-drive、真实反馈和隐藏混杂三类合成世界上检验可区分性。若 M0 与反馈模型对现有观察分布等价，应直接报告不可辨识，不继续搜索能“证明反馈”的神经网络。人体纯观察模型优势最多支持该受限模型族中的 event-feedback-like predictive dependence。

强因果结论需要能区分事件本身与共同驱动的外生扰动／干预及对应前后响应；模拟中删事件只改变模型输入，不能算生理干预。可在后续独立授权的实验或已有合规干预数据中设计，不由本次方案自动启动。切片研究同时提供抗发作与促发作前驱机制，不能预先锁定方向。[Barbarosie 与 Avoli, 1997](https://pubmed.ncbi.nlm.nih.gov/9364076/)，[Huberfeld 等, 2011](https://pubmed.ncbi.nlm.nih.gov/21460834/)

H2b 未建立不自动阻断间期 H3 的可辨识性研究；非线性未证明也不阻断反馈问题。每条证据链单独保持身份。

## 9. 交付、资源边界和停止条件

建议下一轮新根 `/data/hfosp_group_event_state_calibration_v0313/`，保留旧 v0312 原样。结果至少包含：冻结世界参数与 release 支持、原始目标真值与 oracle 结果、逐数据实现／优化种子成绩和失败清单、各组件的分布质量诊断、两 INNER 完整曲线及选模依据、准入决定和中文科学报告。只有实际生成图后才写 figures/README，候选图仍需人工目视验收。

调度维持每 GPU 一个训练进程，按依赖先运行最能定位失败的最小任务；不得用扩大并发或人体患者数消化空闲 GPU。资源／数值失败保留在所有注册分母中，评分缺失与科学不检出分别统计。

本窗口结束必须明确回答：信号是否在可读测量中；实际 readout 能否提取；encoder／q/f 哪层丢失；两 INNER 的共同配方是否经实际比较；哪些效应及 null 已校准到何种精度。任务完成率、单测、残差和逐位恢复随附，但不替代这些答案。

**停止当前模型路线的条件**：在对应测量条件下 oracle／强丰富历史有明确可检出信息，而两套有诊断依据的配方仍不能稳定传递；或者合格简单模型已经足够，复杂状态没有额外表示／迁移价值。**停止生理否定的条件**：可读信息本来不足、校准精度不足、优化不可靠或记录覆盖不能排除目标效应。两者都不要求把原科学问题宣布为不存在。
