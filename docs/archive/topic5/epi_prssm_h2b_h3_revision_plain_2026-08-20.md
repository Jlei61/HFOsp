# Epi-PRSSM H2B / H3 修订 — 白话版

**日期：** 2026-08-20 · **状态：** 开发分区结果；正式检验分区一次都没有打开

## 0. 一句话

**目前站得住的只有一句**：一个人过去放电的历史里，含有能改变"下一次放电波及哪些触点"的信息，而且这份信息不是"模型参数多"的另一种说法。发作前那一问出现了第一个正信号但有一处方向异常需要先解释；放电反过来推动状态那一问，仪器刚刚修好、结论还没有。

## 1. 五个问题现在各自支持到哪一句

| 问题 | 现在能说的**那一句** | 不能说的 |
|---|---|---|
| **H1 有没有慢状态** | 关掉观测后，带状态的模型在往后 5/10/20/40 次放电上都比同容量的冻结对照准（−0.017 ~ −0.048） | **不能**说这是"分钟到小时的生理慢状态"——打乱间隔几乎无损，它跟的是"第几次放电" |
| **H1 是不是沿患者自己的网络** | **暂时什么都不能说**。之前那个"读出 78%/传播 22%"的拆分是**混用了两个代码包**的比较，已作废，正在按同一个包重跑 | 不能引用任何旧的图零假设数字 |
| **H2a 状态是否改变单次放电** | 把状态换成同一位患者另一个时刻——参数一个没变——代价 0.006–0.010；同样的开头之后，走法确实会因当时状态而不同（深度 1 时 +0.018~+0.024） | **不能**说定位到了"触点兴奋性 + 边耦合"：只设起点那一路的零是架构必然（它给所有候选加同一个数，比较时约掉） |
| **H2b 发作前状态是否移动** | 在**全部 361 次可分析发作**这一层，冻结 decoder 读出在真发作时刻比匹配的假时刻高 **+0.45 个标准差（20/27 位患者，p=0.019）**，且经得起留一患者与留一发作 | **不能**说它随可观测性变强：高可观测性那 203 次反而更弱（p=0.12），而连续梯度接近零 |
| **H3a 放电是否推动状态** | **刚具备提问资格**。原来的强度模型四个臂全部拟合不合格；加上"依赖上一个间隔"这一项后，基线的重标定残差从标准差 0.704 修到 **0.838（合格）** | 在其余三个臂跑完前，**一个对比数字都不能引用** |
| **H3b 暴露→发作前状态→亚型** | 患者内是**掷硬币**（21 位患者、327 次发作，11/21 为正，p=1.0）；亚型交互**算不出来**（没有患者同时有两个规模够的亚型） | 不能读成"没有这回事"，只能读成看不见 |

## 2. 分母：三个数字不能互相冒充

- **34** 位患者进入队列
- **27** 位至少有一次可分析的发作
- **361** 次发作在 30 分钟提前量下合格 —— **这是总体层，也是主分析的分母**
- **203** 次额外满足"发作前确实观测到足够放电" —— **这是高可观测性敏感性层，不是研究规模**

**禁止写法**：「分析了 203 次发作」「队列有 203 次发作」「203/34 位患者」。

四个提前量下 203 的构成几乎全是"≥20 次放电"那一层（30 分钟档 180/203），"0 次"和"1–4 次"两层恒为 0。

- 0 个歧义、0 个解析失败

## 4. 这一轮撤回或作废的东西

1. **图零假设的通路拆分**（"读出 78%、传播 22%"）——混用了五个代码包，且 50 个（臂，种子）组合里 14 个有重复运行被静默平均。聚合器已改成锁定单一代码包并去重，现在会**拒绝产出混包数字**。
2. **到达时间通道的两批结果**——第一批每 epoch 只更新一次（整个拟合 25 步）；第二批似然本身错误（生存项用了区间**终点**的状态，等于用"下一次何时发生"去算"活到那时的概率"）。两批都单独归档并写明原因。
3. **一个从未真正执行的负对照**——`event_rate_only_drift` 的生成器从来没有改动过速率，与 `no_state` 逐位相同。已修好并重跑。
