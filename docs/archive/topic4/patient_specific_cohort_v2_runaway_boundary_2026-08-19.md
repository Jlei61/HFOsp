## 摘要（朴素话）

我们本来要问的是：只用每个病人自己训练时段的间期高频事件，能不能反推出一张"哪块组织更容易被点起来"的连续地图，让仿真网络在他真实的电极摆位下自发跑出留出时段那两条传播路线。

第一个病人的第一代十个候选，**十个全部在第 6–13 秒进入停不下来的整片放电**，按合同一律作废、统一记同一个分数。进化搜索靠"这十个里哪几个更好"来决定下一步，十个同分等于没有方向，六代跑完仍是随机游走。所以这一轮不是"拟合失败"，而是**搜索根本没能开始**。

接着我们做了一组工程标定：把场的幅度逐档缩小、把连接重分配关掉、甚至把场彻底抹平到没有核。**每一档都还是跑飞**——包括那张完全均匀、连核都不存在、连接也不动的场（8.3 秒）。也就是说，跑飞不是场的幅度、几何或连接重分配造成的，**是那套慢变量机制在这个底物上本身就没有稳定区**。这与冻结基线自己写的话一致：它明说这套慢变量参考在当前这张"热"场上不安全、三个网络三个都跑飞，并且把"有没有哪张场能稳住它"留给后续的自由场搜索来回答。现在的答案是：**在我们搜索到的这个场族里，没有。**

结论上的收口方式是把两件事拆开做：**拟合间期模式时关掉慢变量**，拟合完冻结底物之后再把慢变量打开，把"什么时候进入失稳、从哪里起、扰动下多敏感"当成被测量的对象，而不是当成无效候选丢掉。

（内部归档代号：gen0 `epilepsiae_590` 10/10 `INVALID_RUNAWAY`；`invalid_objective`=10.0 恒定；`data_driven_snn_baseline_zm_v1.reference_status=UNSAFE_ON_CURRENT_WARM_H_FIELD`、`runaway_networks_per_candidate=3/3`；v2.1 `runtime.mode=paired_slow_off`）

## 2. 工程标定：跑飞的病因不是场

单病人 `epilepsiae_590`、网络种子 1901、仅训练时段、`--phase canary`，输出在
`results/topic4_sef_hfo/patient_specific_field_connectivity_cohort_v2/engineering_calibration/`。

设计为 {紧凑核, 分散核} × {满幅, 0.6, 0.4, 0.25 幅} × {连接重分配 开/关} 的不完全因子，加一个"完全均匀场"底线对照。满幅 + 重分配开这一格由第 0 代自身提供。

| 臂 | 场 | 重分配 | 慢变量 | runaway 时刻 |
| --- | --- | --- | --- | ---: |
| gen0 `c00` | 分散核 满幅 | 开 | 开 | 12 900 ms |
| gen0 `c09` | 紧凑核 满幅 | 开 | 开 | 6 131 ms |
| `disperse_a100_edge_off` | 分散核 满幅 | **关** | 开 | 8 111 ms |
| `compact_a100_edge_off` | 紧凑核 满幅 | **关** | 开 | 6 550 ms |
| `compact_a060` | 紧凑核 0.6 幅 | 开 | 开 | 8 222 ms |
| `compact_a040` | 紧凑核 0.4 幅 | 开 | 开 | 6 381 ms |
| `compact_a025` | 紧凑核 0.25 幅 | 开 | 开 | 4 279 ms |
| **`flat_edge_off`** | **完全均匀，无核** | **关** | 开 | **8 322 ms** |

读法：

- **不是连接重分配**：关掉后紧凑核 6 131 → 6 550 ms（几乎不动），分散核 12 900 → 8 111 ms（反而更早）。
- **不是幅度**：紧凑核沿 0.25 / 0.4 / 0.6 / 1.0 走出 4 279 / 6 381 / 8 222 / 6 131 ms，非单调，且没有任何一档接近 20 000 ms。
- **不是几何**：把场抹平到完全均匀、连核都不存在，仍在 8 322 ms 跑飞。

因此**"先验幅度标定"这条修复路线被证伪并放弃**。几何与幅度只调制进入失稳的**早晚**（4.3–12.9 s），不改变**是否**进入。

> 撤回记录：本轮早期曾提出"紧凑核把递归兴奋堆在一小块区域因而跑飞"的假设（依据是分散核那一格撑到 12.9 s）。均匀场对照否定了它作为病因的地位，已撤回。

### 2.1 场的物理量纲说明

`h` 是 0–1 之间的软指示，且 `project_to_budget` 把 Σh 固定在 `N_core_manual`=1129。因此**没有哪个候选"总兴奋度更高"**；候选之间差的只是这份固定额度铺成什么形状。用 64×64 网格量化：被接受的参考场（`v61_density_t100`）是两块、h 加权摊开 7.7 mm、核面积 8.0 mm²；第 0 代十个候选里 8 个是单块、摊开 2.0–4.4 mm。这个差别与 runaway 早晚相关，但与是否 runaway 无关。

## 3. Fig5 形态层：现有轨迹支持什么、不支持什么

v2 的优化任务只存了整片放电比例（1 ms）、慢变量两条均值、逐细胞静态易兴奋值与坐标、以及被检出离散事件的触点先后。**没存**逐细胞放电时刻、随时间的空间分布、以及失稳阶段的触点连续波形。因此它能支撑"持续 vs 爆发串"和整片放电率的频谱，**不能**支撑"全场"的空间主张，也不能给出电极级波形。

空间与电极级证据来自另一条线的 Fig5 回放
（`data_driven_zm_ictal_transition/fig5_replay/joint_04_control_seed_1801_frames.npz`，
`model_ictal_onset_ms=4115`，与归档运行逐项校验一致）。在跨越转变前后**等长 450 ms** 窗口上：

| 判据 | 读数 | 判定 |
| --- | --- | --- |
| 持续 | 转变前后 20 ms 窗零放电比例均为 0% | 支持（但转变前也连续，不区分两态） |
| 强度 | 整片放电比例中位 0.059 → 0.138；兴奋细胞率 58 → 139 Hz | 支持（约 2.4×） |
| 空间 | 每帧有放电的格子 21% → 36%（95 分位 54%） | 变广，非整片同时点亮 |
| **更高频** | 触点波形振幅均方根 ×1.50，但**全部来自平均电平 556 → 1168 的抬升**；去均值后的波动 ×0.79。绝对带功率：1–30 Hz ×0.63、30–80 Hz ×0.19、80–250 Hz ×0.06、250–500 Hz ×0.07。15 个触点中**仅 2 个** 80–250 Hz 上升（6.0× 与 10.6×） | **不支持** |

朴素说：这条轨迹跨过转变后是一个**持续、更密、更铺开的紧张性放电**，但比转变前**更不振荡**，高频尤其塌掉；只有两个触点出现局部高频增强。

限制：单条轨迹、单候选、单种子、转变后仅 450 ms；触点信号是模型电流代理，其直流分量在真实记录链会被高通滤除。另注意该回放元数据记载显示用 30–80 Hz 零相位带通，而 30–80 Hz 正是绝对功率下降最多的频段之一，看图须看绝对纵轴。

## 4. v2.1 的改动与不变

配置 `config/topic4_patient_specific_field_connectivity_cohort_v2p1.json`，输出根
`results/topic4_sef_hfo/patient_specific_field_connectivity_cohort_v2p1/`（v2 目录保留为证据，不删）。

**改动**

1. 拟合 / 复选 / 留出确认在**慢变量关闭**下运行；冻结赢家后以**慢变量打开**做配对转变探针，机制汇总新增 `runaway_early_stop_ms` 与 `simulated_until_ms`，把"何时进入失稳"变成被测量而不是被丢弃的量。
2. 无效候选按存活时长排序（`runaway_survival_gradient=2.0`，区间 [8.0, 10.0]），严格劣于任何被打分候选（测试锁死该不等式）。这是保险，不是主修复。
3. `CMAES.tell` 在缺特征基时自行分解协方差（`ask`→`tell` 之间 C 不变，故与不中断运行一致）。
4. 执行上限放宽：内存下限 30 GiB、全局 32 worker、4 个病人并行、逐 worker 准入（现场内存 ≥ 下限 + 一个 worker 的余量，并按 20 s 错峰启动）。
5. **搜索基底改为读取冻结产物并校验哈希**。`np.linalg.lstsq` 不是跨 BLAS 线程数逐位稳定的：同一份配置在 1 / 4 / 默认线程下得到三个不同的方向哈希。原控制器每次启动重算基底，重启后会画出略微不同的场，并在候选身份校验处以"collision"这一误导性错误崩溃。冻结脚本现固定单线程 BLAS。

**不变**：病人目标、真实几何资格（28/34 可拟合、6 例 `REAL_GEOMETRY_NOT_EVALUABLE`）、与观测无关的整片基底构造、留出块永不参与选择、每个被打分候选的目标项与权重、20 s 仿真与"迟发 runaway 无效"。

## 5. 未闭合项

- 关掉慢变量后，同一底物能否产出足量可打分的间期事件——3 个 `*_slow_off` 臂在跑，是 v2.1 全队列启动的前置门。
- 慢变量打开后的**空间起点**与**扰动易感性**尚未装配（需逐细胞首次放电时刻 / 早期活动能量这类记录，参考 Fig5 回放的 `sample_first_spike_ms`、`early_activity_energy`）。
- Fig5 形态判据中的"更高频"在现有单条轨迹上不成立，需要更多轨迹或收窄主张。
- 28 人全队列**未启动**，按用户指示先不扩大。

## 6. 允许 / 禁止的表述

允许：

> 在这个数据驱动底物上，被冻结的慢变量参考机制在我们搜索到的整个场族里都没有 20 秒稳定区——包括没有核的均匀场。

禁止：

- 把"跑飞"称为已验收的发作载体（形态判据中"更高频"目前不成立，"全场"未验证）。
- 称先验幅度或核几何是跑飞的原因（均匀场对照已否定）。
- 由本轮任何数字推出病人特异性恢复的结论（第 0 代无任何可打分候选）。
