## 第一轮继承与改变

[执行合同](../../../results/topic4_sef_hfo/spatial_reduction_validation_20260916/execution_plan.md)在新仿真评估前写出。固定当前core分岔来源的2511图、J_EE,core=1.355、阈值深度1；不换成患者优化线最新好点，不启动发作或Z/M分析。新rate保留二维位置、core边界、E/I类别和原始0.1 ms延迟，空间格为2/1 mm。它复用旧空间方程的双指数突触期望更新；colored-Siegert、瞬时独立方差及E5/I2.5 ms响应仍是待检验的候选，尚未接受。

设a为非空空间格与core身份及E/I类型的交集，n_a为实际细胞数。原突触矩阵A的元素是进入gating变量的跳量，投影为 B_ab(d)=sum A_ij/n_a。平均突触采用与native相同的离散递推：

```
g_E[k] = exp(-dt/tau_rE) g_E[k-1] + dt * (sum_d B_E[d] r[k-d] + external_E[k])
c_E[k] = g_E[k] + (c_E[k-1] - g_E[k]) exp(-dt/tau_dE)
```

I通路同理，mu=c_E-c_I。方差矩用逐边物理jump平方除以n_a，假定递归spike独立，以当前r形成扩散矩；core E私有Poisson计入方差，外围及I的外源输入只进入均值。两核OU用原0.1 ms独立进程保留，并与native逐步核验。r的更新为r_next=exp(-dt/tau_rate)r+(1-exp(-dt/tau_rate))*Phi(mu,vE,vI)，Phi对每个空间群体的经验阈值做8节点求积。

输入均值与滤波的正确实现不证明瞬时方差和率响应近似正确。当前候选不宣称为Fokker–Planck精确降阶。文献方法依据：[Augustin等2017](https://arxiv.org/abs/1611.07999)将群体密度响应约化为动态滤波与非线性；[Schwalger等2017](https://journals.plos.org/ploscompbiol/article?id=10.1371/journal.pcbi.1005507)联合处理有限群体波动与spike历史。若当前候选失配，应从具体失配选择需要保留的动态变量，不能直接把文献名称当作本模型已验证的依据。

原生冷启动为全部膜电位在reset且突触/延迟记忆为空；rate候选为率和突触/延迟记忆为空。这只是对应的启动协议，不是两个状态空间之间精确的初值映射：当前rate方程没有膜电位密度变量。若启动后进入不同吸引域，需要区分初态表示不足与闭合本身的动力学失配；不能把一次冷启动阴性解释为原模型不存在其他吸引子。率曲线的小振荡峰间距另称peak interval，不自动当作burst间隔，尤其在持续高背景条件下。

## 验证层与放行条件

先用真实SNN活动检验2/1/0.5 mm空间平均后的触点读出误差，再比较自主空间rate与SNN。原生848101重放检查新记录器；848102/848103给出同图噪声变异参照。三项主读出为平均rank、同杆共同参与条件下的先后概率、逐触点参与概率；冻结原15触点、核宽、时间平滑和事件观察器，不改阈值，不按TA/TB挑选事件。无有效事件或不可估计的接触对不能填零误差。

第一轮相容仅允许扩展验证，不直接允许分岔解释。还需低活动—起始附近的参数留出、core与外围波形/间隔/不规则性，以及扰动恢复和空间网格收敛。若失败，保留失败结果并定位到空间读出、输入统计、动态闭合或有限规模；不以调SNN物理或患者loss补偿。

## 首轮已完成：空间读出可保留，现有动态闭合未通过

三条12秒原生轨迹在2–12秒有效传播事件数为28/27/29，核心E均值约34–36 Hz。2 mm空间rate候选的A/B均值约341/348 Hz，只有3个有效事件；1 mm约310/340 Hz，没有有效传播事件。原生burst之间约82%的时间低于5 Hz，候选主要处于持续高背景。两个rate与848101原生实际核内输入逐步一致；原生848101的六群体计数、触点包络和二维场与V10/a完全相同。因此本轮拒绝把该候选的分岔解释为原生机制。

真实spike的纯空间读出投影提示：2 mm分箱破坏触点参与度，0.5 mm及几何局部细化保留28/27/29个有效事件，三项误差均在三个原生种子的描述性配对范围内。局部细化使用2 mm背景、1 mm核心邻域、0.5 mm触点邻域，共382个物理格、813个区域×E/I群体；只是下一版离散候选，未验证自主二维场。

补充的规定时变E/I输入响应显示，窗口均值相近不能保证闭环；单纯把率时间常数放慢在本局部试验中更差。尚未唯一定位失配机制。下一版拟保留膜电位、双指数突触及reset/不应期密度，先验证群体输入近似，再作低维压缩；该密度求解器尚未实现。
