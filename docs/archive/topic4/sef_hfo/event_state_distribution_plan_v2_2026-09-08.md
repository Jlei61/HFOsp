## 1. 要回答的科学问题

固定一张 SNN 的连接、空间结构、细胞与突触参数，是否可以仅通过抽取一个低维的事件前全局状态，生成患者相容的多种完整传播事件？相比所有事件共用一个最优固定状态，学习一个状态分布是否有额外价值？若有，单峰分布是否已足够，还是需要有限个状态分量？

这里的“全局”是每次试验共用的少量状态坐标；第一版采用全体 E/I 细胞各一个均匀调制量。它不同于每个神经元独立拟合初值，也不先把患者 M0/M1 映射到两个 core。每个事件都由一条完整 SNN 轨迹产生，不能把两条传播波形在事件内部加权相加。

本轮有意忽略跨事件的状态转移、驻留时间和自然状态占比。由事件集合拟合出的状态分布是该生成协议下的分布，不是大脑自然占据分布。试验成功允许写“共享结构下的状态条件生成”；不自动允许写“事件前状态已被实测”“初始化唯一决定模式”或“双稳态”。

## 4. 一个基本全局初态分布怎样进入 SNN

### 4.1 完整生成链和实际状态变量

令 c 是预热背景的完整 checkpoint，ξ 是外源随机实现。每次 episode 独立抽取 z=(z_E,z_I)，每个坐标限定在 [−1,1]：

\[
z\sim q_\psi(z),\qquad x_0=G_\theta(c,z,\xi_{\rm prep}),\qquad
\dot x=F_\theta(x,s,\xi),\quad \dot s=-s/\tau_s,\quad s(0)=z.
\]

θ 对所有状态完全共享。G 是固定时长的 SNN 准备过程，见下一节，不是一个自由神经网络。x 包括 V、不应期、E/I 突触门控及电流、delay rings；OU 状态和 RNG 同样完整恢复。新增 s 是两维慢状态，不是患者标签。

状态只通过下面的物理接口进入发放阈值：

\[
V_{\theta,i}^{\rm eff}(t)=V_{\theta,i}^{\rm base}
- (1\,{\rm mV})\,[\mathbf1_{i\in E}s_E(t)+\mathbf1_{i\in I}s_I(t)].
\]

正 z_E 让 E 更容易发放，正 z_I 让 I 更容易发放；最终传播由原连接、异质基底、抑制和噪声共同产生。全局 E/I 均匀调制可能只改变负荷，未必能选择空间路线，这正是要检验的限制。禁止把患者 TA/TB 起始通道或 mode ID 加到映射中。

τ_s 固定 1,000 ms，是本轮用于覆盖事件的建模选择，不是由患者拟合出的生理时间常数。在 64 ms 内约保留 93.8% 的 s，但等待事件时仍会衰减；必须记录交接状态及实际事件起始时的 s，不能仅按交接 z 解释晚来的事件。

这种做法扩充了系统状态方程。基础连接和参数 θ 仍共享，但有效阈值随状态变化；不能称为“原有纯 V 初始化实验的直接阳性”。状态先验和阈值振幅不能同时自由缩放，本版振幅、坐标范围和 τ_s 全固定，避免不可辨识的缩放自由度。

### 4.2 准备、交接与三个必要参照

每个独立背景 seed 从原基线运行 2,000 ms，控制器存在但为零；在固定时钟保存完整 c，不按之后的模式或是否成功挑 checkpoint。各状态从同一 c 接入 z，维持 z 做 200 ms 准备，让突触、不应期等随网络自行形成，再交接。

- **状态演化 S**：准备后保留 s(0)=z，按 τ_s=1,000 ms 自主演化，评分交接后 2,000 ms。
- **准备后释放 R**：从 S 的同一个准备完成 checkpoint 出发，只令新增 s=0，保留所有已经形成的 x、外源状态及随机流；评分同样窗口。S 与 R 的差异检验传播期间慢状态是否仍必需。
- **最佳常数 C**：所有 episode 使用同一个由训练选择的 z*，执行同样的准备和慢状态方程；它是分布模型的主要竞争者。零状态和预设 q0 是开发基线。

S/R 不是互斥的真假：R 有效支持既有快状态可以承载事件选择；仅 S 有效支持传播期间需要慢状态参与。两者都可能有效。本轮不通过把 R 的整套 x 清零来做消融。

追加 125 ms 仅为完成既有 ±125 ms 观测窗口，追加段不能提供新的目标事件。保留准备前后观察器上下文；既有 0.5 s 冷启动 burn-in 在预热阶段已满足，不可在每个 handoff 再丢弃 0.5 s。须用“连续运行观察”与“分段恢复观察”核验检测结果一致。

### 4.3 噪声配对与实现入口

使用 `simulate_kick` 的完整 checkpoint 和 `node_accessibility` 控制器协议：`threshold` 返回受 s 调制的阈值，`step` 本版只实现指数衰减，忽略 spikes；checkpoint 保存 s、阶段、计时和 τ_s。控制器从背景预热即存在，零状态必须与旧引擎逐值一致。不得通过 `initial_voltage` 与 `resume_state` 同时传参绕过现有互斥检查。

本版不改变 Poisson 率或 OU 规律，故可核验同一 background/noise 单元的外源逐步输入一致。未来若改为状态调 Poisson 率，相同 seed 不再代表相同 spike counts，必须另订共同随机变量耦合方法，不能沿用本版摘要全等声明。当前 Z/M、STD、feedback 均保持关闭。

## 5. 先验复杂度：不先猜传播模式数

模型的传播模式数 K_e、初态分量数 K_z、动力学吸引子数 K_a 分开。当前患者冻结分类器选择 K_e=2：K=2/3 的稳定性均符合旧门槛，但 K=2 silhouette 更高；这不是“真实只存在两个模式”的证明。主拟合不以 K_e=2 为目标维度，冻结标签仅用于解释既有两类。

| 家族 | 状态先验 | 新增拟合参数数 |
|---|---|---:|
| C | 一个最佳固定 z* | 2 |
| Q0 | 截断到 [−1,1]^2 的 N(0,0.5² I) | 0 |
| Q1，首选 | 截断对角 Gaussian，学习 μ_E、μ_I、σ_E、σ_I | 4 |
| Q1-full，先于增分量 | 一个相关的截断 Gaussian，多学一个 E/I 协方差 | 5 |
| Q2，条件扩展 | 两个截断 Gaussian，分量共用完整 2×2 协方差 | 8 |
| Q3，条件扩展上限 | 三个分量，共用完整 2×2 协方差 | 11 |

约束 μ∈[−0.8,0.8]^2、σ∈[0.2,0.8]^2；完整协方差的特征值同样限于 [0.04,0.64]，防止极细长分布模拟精细初值。映射完全固定，没有每细胞、每事件或每患者模式专属初值。Q2/Q3 每分量权重至少 0.05；这是本轮有限支撑约束，不能据此排除罕见生理模式。给出最佳常数 C，不用 σ 下限让 Q1 被迫胜过一个不够灵活的零状态。

先拟合 C/Q0/Q1，若单峰不足先检查 Q1-full，避免用多个分量代替一个斜向的 E/I 联合状态分布。只有响应库存在患者相容的不同传播，而这两个单峰家族不能覆盖，才允许同一库上的 Q2/Q3 离线比较；不得因为 Q1 无效而自动增加网络节点、空间基底或调 τ_s。训练目标使用固定规范化后的传播距离，加 `0.01 sum_k(w_k ||μ_k||²) + 0.02(K_z−1)`；这些是本轮预定建模惩罚，不是具有生理单位的常数。最终家族用内部验证的一标准误规则取最简单者，按实际参数个数登记。

对归一化权重施加普通 L1 没有稀疏作用，因为 sum |w_k|=1。均值振幅惩罚也不能替代分量数惩罚。保留 shared covariance、K 上限和留块比较，报告 K 选择跨折是否一致；若不一致则“分布复杂度未识别”，不投票宣称真实 K。有限混合数的推断依赖模型族和可辨识假设，参见 [Miller 与 Harrison，2018](https://jwmi.github.io/publications/MFM.pdf)，§7.3.4。

## 6. 事件结局、正确积分和主评价

### 6.1 每次试验只有一个预定主结局

从交接起定义第一个新的检测事件。若交接时已有活动跨界，主结局为 carryover；否则取第一个 qualifying onset 位于 [0,2000) ms 的新事件。若它 overlap、prolonged 或通道数不足，记对应 invalid，不能跳到后一个 primary。没有新事件为 null；runaway 和工程缺失单列，不能填作 M0=0。

保留所有检测事件作为次要分布，但主分析每个 episode 至多一个新事件。实际是否“每次只有一种模式”也接受数据检查：模糊、混合或低支持事件不能强贴两类并当作有力支持；固定分类器对任何输入选最近类不等于患者相容。

### 6.2 状态先验不等于成功事件的混合权重

设 A 表示上述第一个结局为 primary 可评分事件，a(z)=P(A|z)。则

\[
P(e\mid A)=\frac{\int q_\psi(z)a(z)P(e\mid z,A)dz}{\int q_\psi(z)a(z)dz}.
\]

事件前抽样 q 和事件集合中的状态分布 q(z|A) 必须同时报告。不以观察到的患者事件比例直接指定 q 的分量权重。对响应库，使用 `sum_z w_z sum_j 1(A_zj) phi(e_zj) / sum_z w_z sum_j 1(A_zj)`；每个 z 的试验数相同。不能先对每个状态的成功事件平均，再直接按 w 相加。

由于患者参考是已筛选事件，而非随机时刻 episode，患者数据没有提供本协议的 null 比例真值。条件传播损失以 A 为条件，另设运行资格：所选模型的 P(A) 不得低于 C 的 80%，runaway 不得超过 C 的 5 个百分点。开发库使用点估计筛查；正式比较报告配对区间，区间不能支持这些界限时资格判为不确定。它们是避免稀有成功挑选的算法约束，不能解释成已拟合患者发生率。

### 6.3 主要读出及防止把增益变成传播

主要端点为不依赖 K_e 的参与 mask 与相对通道时间联合分布距离。复用修复后的 masked observation、通道对齐和固定 RFF 特征规则；在同一数据折内，所有先验家族使用完全同一个特征空间、带宽和随机种子。只改变先验，不重新为各 K 训练分类器或评价尺度。比较绝对事件时刻已消去，但保留相对时序、参与和空间身份，不能只保留全局 rate/振幅。

具体复用 `src/topic4_joint_xy_kernel.py::event_kernel_features` 的 joint：参与 mask、参与者内 rank、以最早参与通道为零点的 lag、固定触点空间/早晚 rank 矩，各块沿既有尺度组合；`fit_kernel_maps(..., n_fourier=512, seed=2026090811)` 只在训练折拟合，lag 尺度为训练事件正 lag 的中位数。不得直接调用旧目标的 `balanced_embedding` 要求每个状态匹配患者整体模式比例。当前观察是 firing-density proxy，不是已经验证的 HFO/LFP 前向模型；本轮传播相容性限于这套观测合同。

优化可用平方特征均值距离；报告 episode/seed 成组重采样的偏差、区间和患者块参考。旧 D_off 的独立样本偏差项不能不经校验地当作相关事件库的无偏估计。距患者的尺度归一化取训练块间距离中位数，设 1e−6 下限，并在该折所有模型中冻结。

并行报告：每模式的参与 MAE、成对时差、顺序概率、支持/OOD；M0/M1/模糊比例；事件产出、carryover/invalid/null、延迟、持续时间、E/I rate。既有患者路线摘要只在报告中解释，不注入状态映射。

另用训练库预先拟合的低容量状态→模式模型，在新噪声上检查 z 是否提供超出总体模式比例的预测增量；模式分析条件于 A，应同步展示结局概率。只有 rate/参与数量变、相对时序和空间身份未改善时，判为兴奋性/负荷效应，不能称状态选择了目标传播。

该模型固定为带截距的二次 logistic：输入 z_E、z_I、z_E²、z_E z_I、z_I²，平均交叉熵加系数 1.0 的 L2（截距不惩罚）。在响应库按最终 q* 的概率质量、并保留 A 的正确权重拟合；竞争者为同一加权库的常数模式概率。两者在 P3 前冻结，概率裁剪 [1e−6,1−1e−6] 仅供 log score。新 Q* episode 的状态 log-score 增量区间下界>0，才称“交接状态包含模式选择信息”。这与分布距离的改善分开判定；若仅后者成立，只能说状态分布改善事件统计，尚未建立特定状态与模式的对应。不能用之后才知道的延迟、事件起始 s 或患者标签作这个预测器的额外输入。

随机打乱独立抽样的 z 顺序本来不改变边缘生成分布，不能充当错误状态负对照。正式必要对照是独立拟合的最佳常数 C；状态与已实现事件的关联可用配对标签打乱作诊断。只有未来有真实事件前测量 h 时，“错时 h”才是相应条件模型的科学对照。

## 7. 执行阶段、矩阵和停止条件

### P0：资格和评价灵敏度

固定 `v2_anchor_old_joint__baseline`、topology 2511；复用 v1 图/候选/观察器身份，保留 autapse 修复。检查实际每个细胞阈值在整个 [−1,1]^2 下均高于 V_reset+1 mV，失败不能逐细胞夹断后冒充同一映射。

必须通过：零控制器等于原轨迹；完整 resume 等于不中断轨迹；S/R 交接时只有 s 不同；共享外源输入逐步相同；观察器分段/连续一致；单细胞已知阈值跨越验证状态确实进入发放方程。用已知双输出的合成事件特征验证先验积分能恢复分布，用与状态无关的同分布 null 验证模型选择不系统增 K。合成检查只证明软件/评价路径，不是 SNN 可以复现患者传播的证据。

### P1：固定映射的响应库，先不训练网络

z_E,z_I 各取 {−1,−0.5,0,0.5,1}，25 个状态；8 个独立背景/后续噪声单元，编号暂定 910301–910308。共 **200 个 episode**，每个包括 200 ms 准备、2,000 ms 评分、125 ms 观测补齐；8 个共享背景各 2 秒，总模拟时间约 **481 秒**。工程 canary 计入相应正式单元，不额外抽样。8 个重复仅作筛查，不能靠池化 200 个事件得到机制显著性。

交付二维响应面：P(primary)、模式概率、联合传播距离和有效阈值。先回答是否存在不同 z 下患者相容的不同事件。允许在开发库上求 25 个状态响应分布的自由 simplex 混合作为“有限库容量上界”诊断；该上界需用留出的噪声单元检查，不能选每个患者事件最近的一次模拟来当作生成模型。

若所有稳定状态/自由混合都无法改善传播，结束本固定全局映射支线，报告容量不足或样本不足，不增加 K_z 来修补没有的条件传播。如果仅 rate 有反应，给出负荷调制结论；下一版才考虑预先固定的空间对比基底或修改共享 θ。

### P2：只学习分布，患者留块＋模拟留噪声

仅用既有 FIT 19,770 个事件/28 块。按冻结 block ID 排序循环分到 4 个外层组，每组 7 块；外层训练的 21 块再作 3 折内部选择。所有数据驱动缩放和特征标定只从对应训练块计算，外层不能选 λ/K。模拟库按 8 个背景单元作留一噪声检查；不能让同一父 checkpoint 的多个状态跨入独立训练/验证两边。

拟合 C/Q0/Q1，按 §5 触发 Q2/Q3；响应库是数值积分近似，格点权重使用截断 Gaussian 在各格点 Voronoi 单元中的概率质量，边缘不直接用密度×等面积。Q2/Q3 是这同一个积分规则的混合，禁止给 25 个权重自由优化后称只有 4 个参数。C 在库上选择格点，最终必须给它与 Q 相同的离格点公平性检查：在其被选格点的相邻单元内，用固定的 8 个候选微调点×同 8 个开发噪声实际仿真，选最优常数；最多新增 64 个 episode。不得只给分布模型连续自由度而把 C 永久卡在粗网格。

按 §5 在增 K 前检查 Q1-full；相关 Gaussian 的单元权重必须用联合矩形概率，不能仍按两个边缘概率相乘。用固定精度数值积分，并检查各单元质量之和归一、对角协方差时恢复可分解结果。这只增加离线分布拟合，不增加响应库物理仿真。

精修在嵌套验证和全 FIT 家族选择完成后进行：用最终所选格点自身的 Voronoi 方格，每轴取下边界、中点、上边界，得到 3×3 点，去掉原格点，恰为 8 点（支持边缘同样成立）。该精修使用全 FIT，因此不能把这 8 个点倒灌进外层留块成绩；内部泛化报告明确是粗格点 C 的比较，最终 P3 则与精修 C 比较。这里“最佳/最优常数”指固定预算搜索找到的最佳值，不宣称全局优化证明。若精修 C 消除了分布优势，停止 P3。

既有 FIT/CAL/PROBE 及其发现结果已用于历史开发。本轮留块是开发期内部泛化检查，不是首次独立患者验证；本轮不调用旧 evaluator.metrics() 开启其他评分，也不读取提名后的验证波形包。原 M0/M1 标签仅用作固定描述，其历史训练使用全 FIT 的事实需保留。

若 Q1 或 Q1-full 已在内部一标准误范围内达到最优，停止增 K。若没有分布模型胜过重新校准后的 C，则分布收益未建立，P3 不自动启动。外层报告完整流程表现，不能只报有利折或从外层重新调超参数。最后按同一内部规则在全部 FIT 选一个模型并冻结，P3 只确认这一项。

### P3：冻结先验，真实连续抽样和新噪声确认

第一张图使用 **128 个新独立背景/噪声配对**，暂定 910401–910528。每对运行 Q* 与最佳 C 各一次，共 **256 个 episode**。Q* 的 z 从冻结连续分布新抽取；C 使用冻结 z*。不插值已有波形，不按输出重抽 z，不挑成功 seed。两臂共享背景和外源随机输入，先验抽样 RNG 单独登记。

主比较 Δ=D(C,patient)−D(Q*,patient)：同时成组重采样独立模拟配对和患者记录块，给出 95% 区间；区间是在已冻结参数条件下的评估不确定性，不包括全部历史选模不确定性。128 是固定筛查预算，不承诺某个功效；每臂少于 60 个 primary，或任一需解释的患者模式少于 15 个模拟事件，条件结果标记样本不足，不自行补到显著。

bootstrap 固定 10,000 次、分析 seed=2026090812，不重拟合已冻结先验。零 runaway 时不能用退化的 bootstrap 区间宣称发生概率精确为零；该资格使用每臂二项比例的保守界组合（双臂 Bonferroni 的 Clopper–Pearson 界），报告配对风险差的描述结果，避免零计数制造虚假的确定性。

进入重复需同时满足：联合传播距离相对 C 降低至少 10%，Δ 的区间下界>0；§6.2 的产出/runaway 资格获得区间支持；每模式传播指标未出现超出患者块自然波动的明显恶化。10% 是本轮可继续工作的效应门槛，不是完整复现标准。即使通过，若距患者仍在匹配自然带外，只能称“状态改善了拟合”。

模式选择信息的 log-score 检查作为第二个、顺序进行的假设：只有主距离改善通过后才检验，若不通过，停止“状态对应模式”的升级及 P4 解释，只交付分布拟合收益；第二图此时仍可按冻结合同确认拟合收益，但不能改称已复现模式选择。模式指标恶化阈值在 FIT 预先计算为各患者块相对其余块的相应指标偏差第 95 百分位；不足模式事件时为不确定，不用看过 Q 输出后的容忍值。

达到条件后，在 topology 6251 用 128 个新背景/噪声配对 910601–910728 重复相同 Q*、C、映射、θ 和读出，**不重新拟合**。若新图基线变化使结果失效，结论限于第一张图，不挑第三张图。未达到门槛时完成报告，停止这轮支线。

### P4：解释状态效应由什么承载

仅在 P3 传播改善及状态模式信息均通过后，按预先编号取前 32 个 Q* 准备完成 checkpoint，从完全相同 x/RNG 释放 s，新增 32 次 2,125 ms 延续；与已完成 S 配对。另取前 16 个 z，两坐标同加 +0.1/−0.1（按编号奇偶交替）；某坐标越界时仅该坐标改用相反号。新增 16 个 episode，选择和方向均不参考输出。检查好结果是否依赖孤立精细初值，样本有限时仅作机制诊断。

S 与 R 均保持传播质量及状态相关性：支持准备后的快状态足以承载本事件。S 有效而 R 明显失效：支持慢状态在事件期间仍必需。小扰动破坏所有收益：提示脆弱拟合，不能称稳定状态区域。以上不测跨事件驻留、切换、吸引域回归，仍不作双稳态判定。

首轮最多 P1 200＋常数精修 64＋P3 256＝520 个 episode；P4 最多再 48 个分支，第二图最多 256 个 episode。按含背景、准备和观测补齐计算全路线约 2,438 秒 SNN 模拟时间，另有少量资格检查；未触发后续阶段时远低于此数。墙钟根据 P0 的实际 worker 时间估算，不能把模拟秒等同计算秒。默认最多 2 个物理 worker，并服从全任务资源约束，不中断主线。

## 8. 何时回答了问题，何时还没有

| 实际结果 | 可以得出的结论 | 后续动作 |
|---|---|---|
| C 胜过零状态，Q 不胜过 C | 工作点均值需校准，尚不需状态分布 | 保留最优常数，结束本轮分布扩展 |
| q 单峰产生不同患者相容传播，跨图仍胜过 C | 简单全局状态分布已足够支持条件生成 | 接受这条支线，不加模式专属初值 |
| Q2/Q3 稳定优于包括相关性的单峰家族 | 本模型和观察尺度需要更复杂的状态先验 | 报模型复杂度选择，不宣称真实模式数或双稳态 |
| z 只影响产出/幅度，时序和空间身份不改善 | 全局兴奋性可调，但该映射未解决传播拟合 | 停止增加先验分量，下一版再评空间状态或 θ |
| 只有低产状态的罕见好事件有效 | 条件挑选造成拟合表象，产出约束失败 | 不验收为状态分布解释 |
| 新连续 z 或新图失效 | 格点过拟合/图特异，泛化不足 | 报告限制，不换 seed/图补阳性 |
| 有效事件不足或区间过宽 | 当前预算不可估计/不确定 | 完整交付，不能写生物学阴性 |

若固定 θ 的所有合理状态都缺少目标传播，该结果不否定“共同 θ 与状态分布联合优化”这个更大模型类。下一轮可在原主线训练合同内联调共享 θ 与 ψ；本轮先固定 θ 是为了识别状态接口能否提供所需条件传播，不是宣称原 θ 已达到最优。

## 9. 与真实 RNN 状态的后续连接及文献边界

第一阶段学习无条件 qψ，只回答“是否存在简单可用的状态分布”。若成功，下一阶段再让严格事件前、时间对齐的 RNN 状态 h_t 只预测这两个坐标的 μ(h_t)、σ(h_t)，冻结 SNN θ 和物理映射，比较无条件 q、最优常数、简单显式前事件特征及错时 h。不能把全事件反推的 z 当作实际前状态，也不能用事件内部真实前缀给第一事件模式提供答案。

运动准备的初态假设说明“准备活动→后续动态”是一条有实证先例的研究路线，但不是癫痫传播的直接证据：[Afshar 等，2011](https://users.ece.cmu.edu/~byronyu/papers/AfsharNeuron2011.pdf)。LFADS 展示了共享生成动力学与不同初态的建模方式，其初态从试次观测推断，不能替代事件前因果预测：[Pandarinath 等，2018](https://www.nature.com/articles/s41592-018-0109-9)。未知分量数需依赖明确模型假设，不能把聚类数直接当作生理吸引子数：[Miller 与 Harrison，2018](https://jwmi.github.io/publications/MFM.pdf)。
