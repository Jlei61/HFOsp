状态：**定义草案，数值门槛和评价器尚未完成患者自对照资格检查；不得据此自动验收旧模型或启动下一代参数搜索。** 本合同记录用户本轮认可的方向。运行中的 V4 保留原方案作为历史覆盖实验，不原地更换评分口径。

## 1. 科学目标

同一组固定模型参数，在预先规定的噪声分布和多组网络实现下，能够产生患者反复出现、跨时段可复现的主要间期传播模式；模型产生的事件主要处在患者数据支持的范围内。评价对象是患者自身的间期事件，当前不把发作传播纳入目标。

患者内变异分为稳定模式之间的差异、同模式内部的生物/测量变异及证据不足的尾部。不能只拟合一张平均模板，也不要求复制每个患者事件、全部尾部或每一份方差。必须区分：

- 模式能不能产生；
- 模式产生得是否像患者；
- 模式比例和内部变异是否与患者相容。

覆盖患者主要模式而未恢复全部比例/方差，可以支持有范围限定的机制候选；不能因此声称已精确恢复完整患者分布。评价层级和允许的结论先冻结，不随某个候选的成绩更改。

## 3. 现有指标的精确定义与新口径

真实实现来源：`src/topic4_rev22_interictal_objective.py`、`src/topic4_joint_xy_kernel.py`、`src/topic4_joint_xy_kernel_objective.py`、`src/topic4_xy_direction.py`。

### 3.1 参与：哪些通道参加

现有 D_support 不是“漏掉多少个通道”的单一值，而是三项平均：各通道参与概率的差异、每事件参与通道数分布的 Wasserstein 距离（除以总通道数）、通道对共同参与概率的差异。通道项先在每根 shaft 内平均，通道对项先按 pair class 平均，防止通道多的一侧垄断分数。

新评价表同时展示这三项，不只保留总值。未参与不等于晚参与，不能把缺失通道填成最后一名，不能让共同参与很少的模式获得虚假的低顺序误差。

### 3.2 顺序：谁更常先于谁

现有 D_order：对共同参与的通道对，统计 i 先、j 先、并列三状态概率，以 Jensen–Shannon divergence 比较患者与模型，再按 pair class 汇总。因此它不是逐个模型事件与某个患者事件的逆序计数，也不是反向传播一出现就扣分。

例如患者某对为 80% A→B、20% B→A，模型同样 80/20 应相容，100% B→A 才明显不符。进一步的模式条件顺序评价应在稳定患者模板内进行，避免不同模式混合把互相抵消的错误藏掉。

代码当前 tie_tolerance=1e-9 ms，仅代表数值相等，不代表生理测量不确定性。新评价需要另行校准“不足以判断先后”的毫秒容差，依据测量/处理分辨率及患者重采样，不通过优化模型成绩挑容差。旧分数不静默重写。

### 3.3 时差：间隔多长

现有 D_lag：共同参与通道对的 |t_i−t_j| 分布，先截至 180 ms，再取 Wasserstein 距离，单位 ms。先后符号由 D_order 处理。它不是相同绝对时刻的逐点预测误差。

联合核的时间特征则是相对事件首通道的未裁剪时间，按患者训练时间尺度缩放；它与 D_lag 并非同一项。

新独立诊断保存各模式内**带符号** Δt_ij 的中位数、分位数及超出可判定容差的顺序概率；给截断比例和未截断尾部诊断，避免 >180 ms 的不同异常被折叠成同一个值。患者与模型事件无天然一一对应，不做任意动态时间拉伸来取得较小误差。当前 t 是估计质心/代理时间，不冒充精确神经元起始时刻。

### 3.4 联合 loss

现有 joint 是事件整体特征的高斯核均值距离，1024 维固定随机 Fourier 近似。输入包括参与 mask、masked rank、相对时间和空间矩。它**不是 D_support + D_order + D_lag 的算术和**，所以总分与这几项出现取舍并不自动意味着计算 bug。

这三项与各分解核距离属于拟合解释/残差，不包装成三个独立的外部验证。下一代用于搜索的 L_search 暂不重定权重：先冻结下面的主评价并验证其行为，再比较整体 loss、模式条件 loss 或按分量失配程度的搜索排序与科学目标的一致性。不能先选让已有模型胜出的加权方式。

### 3.5 方向：分清三个角

- θ_core：两个 core 中心连线，模型几何，180° 无向轴。
- θ_EE：E→E 连接核长轴，结构参数，180° 无向轴。
- θ_prop：由实际事件的接触点时间和患者固定坐标估计的传播方向，早→晚，360° 有向量。

主要验证是模型 θ_prop 分布是否与患者 θ_prop 分布相容。θ_core 与 θ_EE 的夹角只是参数关系，不是患者传播恢复的证据。

保留方向不可估计/非平面传播的比例。单根近共线接触点不足以估计 2D 方向时不能编造角度。既看有向分布，也看无向主轴、正反方向比例和模式内角度散布；不能只报平均轴夹角，使正反模式或多峰分布相互抵消。

## 4. 主评价：覆盖与不支持事件比例分开

### 4.1 患者主要模式覆盖：Recall-like

先由患者训练块定义跨时段可复现的稳定模式和中心支持范围，K 不预设为 2。每个稳定模式分别报告：模型是否产生相容事件、产生多少、分布于几个网络 seed、模式条件参与/顺序/时差是否合理。

主输出为每模式覆盖，以及模式等权 macro coverage；同时报告按患者频率加权的覆盖，防止高频模式掩盖次要但稳定的模式。只出现一次类似事件不能称为稳定可产生。所需事件/seed 数依据患者模式频率、样本量及患者自对照检测能力预先标定。

“未观察到”分为：有足够检验能力却未覆盖，或样本不足尚不可估计。有限仿真不能证明一个模式在机制上永远不可能发生。

### 4.2 模型事件得到患者支持的比例：Precision-like / OOD

对全部模型观察事件，评估是否落在患者训练数据定义、独立校准的模式支持范围内。不能因为最近的中心是 A，就把任意遥远事件强行归入 A；必须允许“不支持/不能判定”标签。

主输出为支持比例、明确不支持比例、不能判定比例。只有可判定集合内二分时，OOD 才等于 1−precision；不能把不确定或无事件静默算作支持。总体分母和条件分母同时保存。

患者训练参照有限，“不支持”只表示偏离当前患者资料支持范围，不表示患者永远不可能产生。患者自身跨块互评也会有被拒绝的事件，因此报告模型相对患者自对照的 excess OOD，而不要求任意模型达到零 OOD。

这借鉴生成模型评价中分开衡量样本真实性与目标覆盖的思想；距离、邻域与阈值必须在本项目的接触点事件表示中校准，不照搬图像特征网络或默认 kNN 超参数。[Kynkäänniemi et al., 2019](https://proceedings.neurips.cc/paper/2019/hash/0234c510bc6d908b28c70ff313743079-Abstract.html)；已有研究也指出普通邻域 precision/recall 对离群点和超参数的敏感性，因此这里要求患者自对照和控制实验。[Naeem et al., 2020](https://proceedings.mlr.press/v119/naeem20a.html)

### 4.3 模式比例与模式内方差

它们与模式是否存在分开。比较患者跨块模式比例区间，以及模式内 rank/时差/方向的中位数和中央分位范围。患者自对照决定什么是可接受差异，不要求每一项方差精确相等。

稳定的少数模式不能因为频率低而被忽略；只在单块出现且样本少的尾部可标为探索性，不强迫模型拟合。仅输出每类一个固定原型可能覆盖模式中心，但不能声称恢复模式内分布；严重塌缩或过度发散要显式标记。

## 5. 独立于训练 loss 的检查

“独立”分两层：不使用同一公式/不参与本次优化；以及独立患者块与新网络上的最终检验。换个公式但反复用它挑模型，仍是开发评价，不是未触碰的外部验证。方向和 K-means 都来自同一时间/空间资料，不声称统计上互相独立。

### 5.1 模板结构与 K-means 一致性

患者端只用 FIT 学 K、标准化和模板；用时间块重采样及跨块复现判断哪些模式稳定。遵守 canonical masked features，`build_masked_kmeans_features` 的输入按其实际 shape 合同，输出为 events×contacts；从模拟时间重新生成参与 rank，绝不使用 phantom rank。模板中从未参与的通道必须排除，缺失相关的分群由参与模式另行解释。

冻结患者模型后，将模拟事件投射到患者模板，并带拒绝域，报告每模板参与、排序、时差和方向一致性。补充模型自身分群及跨 seed 稳定性，检查是否一个模式塌缩、额外模式过多或中心明显偏移。

不能对患者 N 个事件的 labels 与模拟 M 个事件的 labels 直接计算 ARI/AMI；两批样本没有一一对应。ARI/AMI 只用于同一固定 probe 事件集上，不同重采样聚类器的分区稳定性。跨域模板比较用参与/顺序/时差距离及可留空的一对一模板匹配，允许未匹配模板，不能强迫每个患者模式都找到一个模拟匹配。

### 5.2 行为方向一致性

从模拟事件重新测 θ_prop，不使用 θ_EE 或 θ_core 代替。主要在患者稳定模式内比较有向角分布，并保留不可估计/非平面质量。全局汇总是补充，不让不同模式的角度抵消。

### 5.3 原始场与跨网络稳定性

使用 readout 前的完整 2D 活动、全部事件窗口和窗口外活动做检查，记录多波前、空间活动覆盖、读出敏感性、事件漏选，以及 quiet/runaway 轨迹。格点仍是 1 mm/2 ms 汇总，不是单神经元因果观测。

不规定每个事件两个 core 都起始或活跃，不要求漂亮的直线或往返。异常结构首先是需要解释的诊断，不凭 GIF 风格自动判生理错误。核心是否对模式分布有控制作用，需配对参数干预另行检验。

模板覆盖和支持比例必须在多个新网络上稳定；同时保留事件加权总体值和每 seed 值，避免一个高产网络掩盖其他网络失败。事件产率用于样本充分性和运行稳定性；当前不把所有患者间期事件间隔统计混入本轮事件内传播验收。

## 6. 患者方差、数据分区与阈值

1. 核验实际数据来源和每个对象的拟合记录：contact mapping、空间平面/方向、K、embedding、尺度、阈值、模板都纳入。文件名写 heldout 或脚本没有打开原始数据，不足以证明上游没有用过这些块。
2. FIT 定义患者表示、模板和搜索 loss；CAL 以不重叠的患者时间块定义支持范围、距离容差及置信区间。既有反复使用的开发数据明确标记为 reused development，不能重新切片后宣称 pristine heldout。
3. 用患者一组时间块作为“伪模型”、另一组作参照，匹配模型的有效样本数、模式频率和分块结构，得到可达到的自对照范围。考虑相关事件，患者侧按块、模型侧按网络重采样，而不是把所有事件当独立个体。
4. 在多个实际 N 上校准，不因 N=65 就直接套 N=128 的更严门槛。多指标同时验收需要联合校准，不把多个单项 q95 当成整体 95%。
5. 用开发评价做模型选择；最后只对预先提名的模型，用未用于选择的患者块和新网络做最终评价。若后续据结果继续调参，该轮转为开发记录，重新说明独立性边界。
6. 模式数、稳定模式名单、允许误差、置信区间算法及主要/次要指标在下一代模型排序前冻结。最终测试不用于修改这些对象。

## 7. 评价体系自身必须通过的检查

| 输入对照 | 期待行为 |
|---|---|
| 患者不重叠块互评 | 主要模式相容；容许患者本身的变异，不应系统地全部判差 |
| 只保留一个真实主要模式 | precision 可高，但其他稳定模式 recall 下降 |
| 保留患者事件并混入已知异常传播 | recall 可保持，支持比例下降/OOD 上升 |
| 同参与 mask 下随机打乱先后 | 参与项保持，顺序/模板检验变差 |
| 只拉伸时差 | 参与及秩顺序基本保持，物理时差检验变差 |
| 每模式仅输出一个固定中心 | 可覆盖中心，但模式内散布塌缩必须被识别；不当成完整分布恢复 |
| 仅改变模式混合比例 | 模式存在性可保持，比例诊断变化，不一概判成不能产生 |
| 相同潜在模式加入患者相容的噪声 | 不能只因合理方差扩大而全面拒绝 |
| 空事件、低共同参与、静默网络 | 明确不足/不可估计，不能因误差缺失而通过 |
| 独立 seed 的已知模型位置参照 | 区分位置效应与随机性；标明这是可辨识诊断，非患者机制证明 |

患者自对照先定容差，异常对照只测识别能力，不能把异常样本拿来调一个对自己有利的通过阈值。新评价失败的原因应首先在评价器修复，不先增加 SNN 搜索预算。

## 8. 可调参数字典

评价器不依赖模型只允许 XY；以下是未来参数注册表，不是现在全部放开。用户本轮允许在评价体系可靠后，将 E/EI、连接空间参数和时间常数也用于寻找基底，这取代旧 handoff 中仅允许先搜索 XY 的阶段限制。用于拟合基底的参数变化，与基底冻结后的机制必要性实验分开，不要求先有合格 XY-only 解才能评估这些参数：

| 参数组 | 必须明确的含义/伴随记录 |
|---|---|
| 两核位置和形状 | X1/Y1/X2/Y2、面积/1499 节点预算、半径、边界距离；如形状可调则单列 |
| VTH | 背景、均值、离散度、截断/保留正负变化、gain、具体神经元 realization；移动 XY 选择不同细胞须记录 |
| 通路强度 | 用 E→E、E→I、I→E、I→I 标明突触前后群体；核查代码命名，不能把 E→I 等同于 I→E |
| 空间连接 | 各通路连接长度、概率/入度、轴比、θ；结构轴变化必须重新估计输出方向 |
| 全局 E/I | 神经元数量比、连接数/入度比、有效输入强度比是三种不同参数，不能统称一个 EI ratio |
| 时间尺度 | E/I 膜时间常数、兴奋/抑制突触升降时间、传导延迟；改变 tau 若引起权重自动归一化也记录 |
| 噪声 | 幅度、时间尺度、空间相关性及输入规律；每候选固定噪声分布，多 seed 检验，不逐事件拟合噪声 |

真实图、边数、权重、时延、阈值数组、噪声 law 和缓存 fingerprint 必须留档。改变拓扑不能伪称同一图的配对权重干预；评价定义保持固定，模型参数变化才有可解释比较。
