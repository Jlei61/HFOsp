## 0. 摘要（先讲人话）

这一轮只做一件事：**把三件量错的东西量对**。结果是三个答案，各不相同。

**第一件：修好了，但答案反而更坏。** 之前判"离子稳不稳"用的是"相邻两个快照之间变了多少"，那是
**波动幅度**——事件一直在发生，它就一直很大。换成"整段窗口里有没有一直朝一个方向走"的**斜率**之后，
**离子仍然在漂，而且超标**：每个细胞的漂移速度（99 分位）是 0.075 毫摩尔每秒，允许上限是 0.021；
钾更夸张，超标 68 倍。

> **这里必须纠正我上一轮说过的一句话。** 上一轮我用"钠的群体均值净变化只有每秒 −0.0026 毫摩尔"去
> 论证"那个大数字主要是波动不是漂移"。**前半句对，后半句错。** 群体均值几乎不动，是因为**不同细胞
> 朝相反方向漂、互相抵消了**——这正是原设计文件警告过的"慢空间重排"，也正是它坚持要看逐细胞分位数
> 而不是均值的原因。真相是：**漂移是真的，只是均值把它藏起来了。**

**第二件：没修好。** 想让"初值"和"实际运行"自洽：拿运行结果去更新初值，再跑，再更新。
**预注册的方案（阻尼系数 0.5、最多 3 次更新、两个偏置锁死）没有收敛**——网络放电在每秒 0.21 与
4.53 次之间摆动（20 倍），收敛量始终离门槛很远（最小的一次也是门槛的 20 倍）。
初值本身就在决定工作点，而按合同把两个偏置锁死，就没有自由度去吸收初值变化带来的偏移。

**第三件：这个答对了，而且是这三轮里第一个真正的因果答案。** 之前那个"打开反馈钾会不会堆更高"的
比较两边条件不一样，作废了。这次两臂**除了"事件引起的钾变化要不要反馈到细胞膜"之外完全相同**（同一
随机种子、同一初值、同一刺激；开环臂只是在第一次刺激**之前**把那个反馈量冻住）。答案是：

> **打开反馈之后，第二个观察窗里的那次放电来得更晚（晚 48 毫秒）、在原地点堆起来的钾更低
> （0.672 对 0.833 毫摩尔，低 19%），但参与的细胞多 26%，而且铺得更远（参与细胞到刺激中心的
> 均方根半径 9.62 对 7.75 毫米，大 24%）。**
>
> 也就是说：**这条钾反馈让后面那次放电变得"更宽、更平"，把反馈冻住则变得"更窄、更高"。**

## 3. §2.3 匹配开 / 闭环对照：`COMPARABLE`，因果答案

**设计**：两臂共享 `q_ion`、两个偏置、初始离子场、噪声种子、kick 时刻 / 强度 / 半径。开环臂在
**第一次 kick 之前**的那个离子块把 `membrane_current()` 冻住——既切断事件诱发的 `ΔE_K` 反馈，又用
那个常数**原样保持** kick 前的工作点。**两臂在冻结块之前是逐位相同的同一次仿真**（有效性由此保证，
不由响应差异保证）。

### 3.1 先说一个必须写在结论前面的口径问题

补上的热点格时间轨迹显示：**那两个 200 ms 窗里不是干净的单次 kick 响应。** 网络自己也在放电——

| 臂 | 窗 1 [2500, 2700) | 窗 2 [2700, 2900) |
|---|---|---|
| 闭环 | **2 次**上升（起点 2510 / 2662 ms），窗最大值在 **2682 ms** | **1 次**上升（起点 **2865** ms = kick2 后 165 ms） |
| 开环 | **2 次**上升（起点 2505 / 2660 ms），窗最大值在 **2682 ms** | **1 次**上升（起点 **2817** ms = kick2 后 117 ms） |

所以 `peak1 / peak2` 是**固定 200 ms 窗内的最大值，不是诱发幅度**；窗 1 的最大值来自那次**较晚的
自发 burst**，不是 kick 本身。**臂间比较依然有效**（同样的窗、冻结前逐位相同的仿真），
但**不得**把这个量描述成"第二次 kick 的诱发响应"。

另外：两臂 kick 前的"超额钾"都是 **−0.26 mM** 左右——基线窗自己就坐在 §1 测到的下漂上。

### 3.2 有效性与效应

| | 窗 1（sanity，反馈还来不及起作用） | 窗 2（效应） |
|---|---|---|
| 热点格 | 两臂**独立**选中同一格 **444** | 同上 |
| 窗最大值出现时刻 | 两臂都在 **2682 ms** | 闭环 2879 / 开环 2835 ms |
| 窗最大值 (mM) | 0.6779 / 0.6542（差 3.6%） | **0.6715 / 0.8328（闭环低 19%）** |
| spike 数 | 57068 / 56096（差 1.7%） | 55439 / 56545 |
| 参与细胞 | 10920 / 10633（差 2.7%） | **15521 / 12297（闭环多 26%）** |

**窗 1 在每一个指标上都匹配** → 起点可比。**分歧只出现在窗 2** → 那正是唯一不同的那个因素能起作用
的地方。

### 3.3 空间层（按 §7.3 **预先锁定**的规则报告）

| 量 | 闭环 窗1 | 闭环 窗2 | 开环 窗1 | 开环 窗2 | 窗2 闭/开 |
|---|---:|---:|---:|---:|---:|
| 达自身峰值 25% 的格数 | 232 | 349 | 230 | 346 | **1.009** |
| 达自身峰值 50% 的格数 | 158 | 260 | 159 | 217 | **1.198** |
| 参与细胞 RMS 半径 (mm) | 8.427 | 9.622 | 8.372 | 7.747 | **1.242** |
| 被占据格数 | 507 | 631 | 513 | 517 | **1.221** |

**窗 1 两臂空间上也匹配**（格数 1.009、半径 1.007）。窗 2：

- **半径 +24%、被占据格数 +22%、50% 等值线格数 +20%** → 按预注册规则，可写
  "额外招募**伴随**空间范围增大"；
- **唯一持平的是"达自身峰值 25% 的格数"（349 对 346）** —— 那个阈值按**各自**峰值归一，而闭环峰值
  本就低 19%，所以它测的是**相对形状**而非绝对范围；在 50% 等值线上闭环反而多 20%。
- 臂内比较更直接：**闭环第二个窗比自己第一个窗半径 +14.2%，开环反而 −7.5%**；参与细胞闭环 +42.1%、
  开环 +15.6%。

### 3.4 可以写的一句话

> **动态钾反馈提高了后续窗口的全局招募（参与细胞 +26%），而没有提高同一热点的局部钾峰值
> （反而低 19%）；这次额外招募伴随空间范围增大（参与细胞半径 +24%、被占据格数 +22%）。**

**限制（必须同时说）**：单一种子、单一对 kick、单一热点格；共享的初始离子场**不是**自洽不动点
（§2 未收敛）；窗内含自发 burst（§3.1）；**没有**测 onset 梯度 / 传播延迟 / 虚拟电极覆盖 /
特征模投影，因此**不得**写成"促进空间传播"。描述性，无 null。

> **一处判据订正（我自己的错）**：初版判据把两次 kick 池化取 max、超过 15% 就判对照作废，于是
> 得到 `UNRESOLVED_MATCHED_CONTROL`。**那条判据在效应最大时把对照判死，无法区分"对照坏了"和
> "效应存在"**——与上一轮 P0-2 同一类错误。已改为：有效性由**结构性**保证（冻结前逐位相同），
> **窗 1** 的一致性作 sanity，**窗 2** 的差异是**效应**。只改判据、**没有重跑任何一臂**；

## 5. 允许与禁止

**允许**

- 有符号斜率估计量成立，并被合成轨迹测试证明能把"平稳但有事件"与"真漂移"分开；
- 用正确估计量测量后，**离子平稳这一关仍然不过**，且逐细胞 99 分位比群体均值斜率大 36 倍——
  存在**被均值掩盖的慢空间重排**；
- **预注册的**自洽初始化方案（`alpha=0.5`、≤3 次更新、冻结偏置）**未收敛**，稳健分位数单调上升，
  最小门值仍是门槛的 20 倍；固定偏置下初值把工作点拉动约 20 倍 → **初值与偏置强耦合**；
- 同种子下离子层把 `r_E` 抬高 **+87.3%**、`r_I` 抬高 **+92.4%**；
- 在这个工作点、这对 kick 上：**钾反馈提高了后续窗口的全局招募（+26% 细胞）而降低了同一热点的
  钾峰值（−19%），且伴随空间范围增大（半径 +24%、被占据格数 +22%）**。

**禁止**

- 说 Gate B 的任何结论——**未判决**；
- 说"离子机制被否定"——本轮修的是**仪器**；
- 说"钾正反馈被否定"——§3 说的是**它改变了后续放电的幅度—范围权衡**，不是它不存在；
- 说"没有吸引不动点 / 联合求解结构上不可能"——**已撤回**，4 次迭代不构成不存在性（§2.3）；
- 把 §3 的窗口最大值说成"kick 诱发响应"——窗内含自发 burst（§3.1）；
- 说"促进空间传播"——未测 onset 梯度 / 传播延迟 / 电极覆盖（§3.4）；
- 把 §3 的结论推广到别的工作点 / 种子 / 事件间隔——单点、单种子、共享初值非不动点；
- 说"间期工作点已恢复"——见上一份归档 §0 的两条限制，本轮未改变；
- 说"泵的电生性作用已被检验"（`eta_pump` 全程锁 0）。
