## 朴素话（测什么 / 怎么测 / 揭示什么）

**测什么**：把一片脑组织里一个"慢慢让它更容易兴奋"的旋钮**固定**在不同档位，看网络**自己**（不戳）
冒出来的放电事件长什么样——会不会从"小、扩一点就回静"长成"大、还能回静"再到"持续招募"。试了四个**物理来源
不同**的旋钮：抑制变弱（z，去抑制 / 氯离子）、GABA 反转电位去极化（e_GABA，氯离子累积）、阈值整体平移（phi）、
钾外流（g_K，发作终止）。

**怎么测**：每档跑长记录（不戳），检测每个自发事件，量大小 / 时长 / 是否回静 / 属哪类（小-回静 / 大-回静 /
持续有前沿 / 全场失控）。**先要有个"间期基线"**——旋钮在正常位时，网络应该有零星会回静的小事件，作为锚。

**揭示什么（关键，且和原版结论不同）**：
1. **最重要的一条：在这个均匀（同质）衬底上，"间期基线"根本不存在。** 旋钮放在正常位（OFF / z=1.0）时，
   网络**完全安静，一个事件都没有（纯 R0）**。我们自己在 STATUS §4 里就写明："基线如果是纯 R0、零事件无法
   刻画基线相，则扫描无意义——先报这个事实、调操作点，再扫"。**这正是发生的情况——A1 设计里的"冻结态下间期
   →发作相变"这个测试，在均匀衬底上压根没法干净地跑**（因为没有间期态可锚）。这和 M3 的初衷一致：同质组织
   产生不了"间期 vs 发作"的区别，本来就要靠异质性。
2. **能说的次级观察**：一旦把安静的网络用某个旋钮**点着**，事件的"形状"取决于旋钮的物理来源（聚合所有事件、
   较稳）：纯改阈值（phi，和上次 static-μ 一样）→ 又小又短（约 9 格 / 62 ms）；改抑制强度（z 去抑制）→ 更长
   （约 99 ms）；GABA 去极化（e_GABA）→ 最大（约 22 格）但短促。**但这是不同机制之间的"恒定差"，不是"随旋钮
   连续变化的梯度"**——同一个旋钮内部，事件大小 / 时长是平的、且每档只有 1–4 个事件（噪声）。
3. **全程没有 R4a（有结构的持续招募 = 想要的发作样中间态）。** 最兴奋的两个点各冒出**恰好 1 个** tonic 失控
   事件（e_GABA=17 是 1/10、phi=−2 是 1/25），其余全是"大-回静 R3"。

**结论**：这是一个**有界负面 + 一个次级机制观察**——
- **有界负面**：冻结慢状态、在一个本身没有间期态的均匀衬底上，产生不了"间期 vs 发作"的区分（无 R4a，
  基线锚定不满足）。
- **次级观察**：机制决定事件形状（阈值类→小短；去抑制→长；去极化→大），但只是机制间恒定差，非旋钮内梯度，
  且数据稀疏。

→ **要真正跑 A1，需要一个有"大-回静 R3 间期基线"的异质兴奋核衬底。** e_GABA 能直接骑在这种核上（电导分流路
尊重 per-neuron 阈值场，**不用改引擎**）；z / g_K 走的 slow 路用均匀阈值、**看不见核**——要让 z 骑核需要给引擎
加一个**默认关**的小钩子（slow 路在 use_phi=False 时读 V_th_per_neuron；plan Task 1 已许可）。**是否加钩子 +
在异质核上重跑 = 交用户定。**

## 3. 六问 verdict（plan Task 5 / spec §8）——诚实版

1. **事件率变？** 变（能激活的旋钮）。但基线本身 0 事件，"变"是从无到有。
2. **size 分布移？** **旋钮内部不移**（平、噪声）；**机制之间有恒定差**（z/e_GABA > phi）。
3. **duration 分布移？** 同上：z 臂内部 dur 平（94–116ms，无梯度）；z 池(99) > phi 池(62) 是机制差不是梯度。
4. **回静比例下降？** 基本 ~1.0，仅 e_GABA17=0.9（1 个 tonic）。
5. **R-class 向 R4a？** **否，全程无 R4a**；R4b 仅 2 个孤立 tonic 事件（最兴奋端各 1 个）。
6. **是否区别于纯加热？** phi=复现 static-μ 纯加热 null；z/e_GABA 事件形状与 phi 不同（机制差），**但因为基线
   不可锚 + 旋钮内无梯度 + 数据稀疏，不能升级为"candidate"**。

## 4. Caveats / 诚实边界

- **基线锚定失败（item-5）**：均匀衬底 OFF=纯 R0，是 STATUS §4 定义的"停-调操作点"条件；本轮越过该门给了结论
  =错误，已在本修订版纠正。均匀同质衬底没有"间期 returned-event 区"（与 op-point 探测一致：vth 16.8–17.4 只 0–2
  事件），这本身是 M3 的论点。
- **数据稀疏**：z/e_GABA 多数档 1–4 事件；≥10 仅 phi−1/−2、e_GABA16/17。逐档数值是点估计，机制形状对比用聚合
  （n=20–46）才稳。
- **无旋钮内梯度**：z 臂 size/dur 随 z 是平的（噪声），不是"形状随旋钮移动"。
- **占位参数、单一网络、nu0.6 单工作点**；慢变量量级未生物标定。
- **R4b 是 2 个孤立事件**（不是稳定 tonic 相），且 tonic≠发作样成功。

## 5. 停止 + 下一步（A2 之前先补 A1 基线）

按停止规则**停**。诚实状态：
- **有界负面**：冻结慢状态在无间期态的均匀衬底上不产生 R4a，也不产生"间期 vs 发作"区分。
- **次级观察**：机制决定事件形状（阈值→小短；去抑制→长；去极化→大），机制间恒定差。

**A1 还没干净跑完**——需要先补一个**有间期 R3 基线的异质兴奋核衬底**再重扫：
1. **e_GABA on excitable-core**（推荐先做，**不用改引擎**）：shunt 路尊重 per-neuron 核场，核给间期 R3 基线。
2. **z / g_K on core**：需给引擎加**默认关**小钩子（slow 路 use_phi=False 时读 V_th_per_neuron）+ parity 测试
   + re-bless（plan Task 1 许可）。注意本 worktree 有并行 M3B worker 在改 `run_m3_kick_calibration.py`，
   动 `src/snn_engine/*` 需协调。
3. 只有补好基线、确认能在间期 R3 上观察到"冻结 slow → 形状/回静/R-class 的真实移动"后，再判 candidate / 交 A2。

A2（动态）仍是后续：若异质核上冻结态仍无 R4a，则 R4a 可能需要慢变量随活动**累积**（A2，e_GABA 优先）。
