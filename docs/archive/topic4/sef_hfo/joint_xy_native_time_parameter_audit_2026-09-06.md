# 双核搜索中真正生效的时间参数

## 判断

没有发现当前 0.1 ms 积分步长、延迟量化或已抽样缓存连接的单位错配。之前离线压缩时差可以改善残差，但不能据此确定应修改哪个生理时间常数。当前搜索只改变 VTH 场位置，Z/M 关闭，时间参数不是本轮学习结果。

## 实际参数与来源

`build_substrate` 用 `Params` 构造网络参数，显式传入 g、L、density、T、dt、drive 和 seed；膜、突触及传递延迟参数沿用类默认值。worker 的实际调用是 `simulate_kick(..., KICK_BOOST=0, t_kick=1e9, slow=None, external_e_rate_drive=...)`，没有额外诱发 kick，也没有启用 Z/M。

| 环节 | 当前生效值 |
|---|---|
| 积分步长／延迟量化 | 均为 0.1 ms |
| 膜时间常数 E／I | 20／10 ms |
| 不应期 E／I | 2／1 ms |
| AMPA 上升／衰减 | 0.7／3.5 ms |
| GABA 上升／衰减 | 1／18 ms |
| 传递延迟 | `0.1 ms + distance / (0.3 mm/ms)`，再量化 |
| 全局 OU 输入相关时间 | 150 ms |
| 额外局部空间 OU 相关时间／更新间隔 | 20／1 ms |
| 放电密度读出时间分箱／高斯平滑 sigma | 2／5 ms |

这些是代码与冻结输入的数值，不表示患者真实生理参数已被识别。局部 OU 是额外输入；它没有替代 `simulate_kick` 中原有的全局 OU。模型读出仍不是经过验证的 HFO/LFP 前向模型。

## 缓存网络核验

对共同 seed 2511–2518 的 8 个缓存逐一核对 SHA256 和配置。延迟分位数计数覆盖全部保存边；公式核验在各非空延迟箱按固定随机种子抽样，总计 **104548 条边**。抽样边全部符合距离延迟公式及离散步骤，量化前后最大偏差为 **0.0499999 ms**。这不是全部边的逐边公式证明。

E→E 每个网络均有 2560 万条边，延迟中位数 **4.7 ms**、90% 分位 **8.6 ms**、99% 分位 **13.1 ms**，8 个网络在当前 0.1 ms 分辨率下相同；均值范围 **5.0764–5.0819 ms**。其他三个通路的中位数为 4.4 ms。真实传播可包含多次突触传递和阈值积累，不能把单边延迟直接等同于整个事件的通道时差。

## 对下一步的约束

1. 继续当前冻结参数的 XY 搜索。此审查没有提供立即修改正在运行模型的证据。
2. 若位置搜索持续无法消除时间残差，延迟、膜／突触动力学和读出展宽应分开做预设配对对照；不直接将某个 τ 乘以离线最佳比例。
3. 时间常数修改并非自动保持其他作用不变：缓存连接的突触增量包含膜／突触上升时间之比，外部驱动的基准计算也使用 AMPA 时间常数与膜时间常数。未来实验必须说明如何处理相应剂量和驱动变化，并重建或严格验证网络缓存。
4. 未来若开展参数扫描，不能只在 engine JSON 增加 `tau_m_E` 等字段：当前构造器没有读取这些可选字段。必须显式接入实际 `Params`，保存生效值，并以仿真输出核验。这是未来实现要求，不是当前 VTH-only 任务的缺陷。
