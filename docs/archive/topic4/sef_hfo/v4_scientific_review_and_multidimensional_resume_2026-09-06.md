## 对交回报告的数值纠正

逐项复查四轮 `analysis.json` 的 checks，发现“没有通过任何一项患者分布门槛”不准确：

| 候选 | 事件数 | D_support | 对应旧门槛 |
|---|---:|---:|---:|
| xy_interior_032 | 85 | 0.0702 | 0.0801 |
| component_r004_023 | 61 | 0.0745 | 0.0884 |
| component_r001_021 | 67 | 0.0684 | 0.0801 |

以上三者通过 D_support，其中 61 事件者仍不满足总事件数要求。所有候选仍未整体通过，kernel 参与、rank、时差、joint、D_order、D_lag 与行为方向没有过相应门槛。D_support 和 kernel support 是不同统计量，不能把后者失败写成前者也全部失败。

按 `scl_minus_icl_group_median_ms` 的实际定义，患者两组参与触点质心中位数之差的 IQR 为 16.5596 ms，V4 各候选为 **68.3182–126.5290 ms**；报告口头给出的约 50 ms 下限混入了“首触点之差”等另一种定义。该统计反映事件内两组触点的相对时间，不等于全部患者传播时间，也不能称患者时间“几乎固定”。

旧门槛使用向上取 N 档及多个单项门槛，因此门槛倍数是旧开发规则下的失配描述，不是生理不可达性的数学界限。患者自对照实际使用不相交块的抽样/参照，不能简化成对全体数据的独立自抽样等效检验。

## 补做的科学检验：宽时差能否只由混合模式或混合网络造成

用已经冻结的新患者 masked-rank 聚类器，将三组代表模型按最近患者模板分组，并保留每个网络的统计；不按相似度删掉事件。结果保存在多参数结果根 `v4_timing_conditioned_review.json`。

| 数据/候选 | 模板组 0 的两组触点时差 IQR | 模板组 1 的 IQR |
|---|---:|---:|
| 患者 | 15.94 ms | 15.61 ms |
| component_r001_015 | 88.69 ms | 59.07 ms |
| component_r004_007 | 79.22 ms | 60.32 ms |
| xy_interior_032 | 119.92 ms | 54.17 ms |

这三个候选的宽时差在按模板分组后仍在，多数单网络中也可见较宽分布，因此不只是混合两个方向或不同网络均值造成的。这里是最近模板描述，含患者支持域外事件，并非确认这些模型已正确产生患者模式；每网络样本也小。

同时检查固定接触对 ICL4−SCL9，以区分“参与通道变化导致组中位数变化”的解释。例如 `component_r001_015` 的模板组 1，此接触对中位时差为 25.92 ms，患者为 26.72 ms，IQR 为 40.45 对 34.45 ms；但模板组 0 的中位数为 −36.29 对 −5.85 ms，IQR 为 86.41 对 31.41 ms。这说明失配并非所有接触对统一乘一个慢速因子；部分模式/接触关系已接近，另一部分明显偏离。下一轮应看模式条件残差，不能只调到全局平均时间相近。

边缘波前和 core 被经过是值得检验的结构线索，但对方只目视了七个候选各一个事件，不能从中证明全部事件都由边界产生，或 core 没有控制作用。native/readout 在同一窗口内的质心接近，也不能排除 250 ms 事件窗口把多个波前合成一个事件。保留传播动力学、core 控制强弱、边界和观测分段这些可区分的解释。

## 下一里程碑如何判断

本轮首先回答：在同一位置、同一网络/噪声 seed 下，改变阈值、通路强度或快抑制动力学，能否减少模式内顺序/时差失配，同时保留主要模式覆盖和患者支持比例。

- 若多个位置、多个 seed 下同一干预均改善对应残差，并保留模式覆盖，支持继续沿该参数组寻找工作点；尚不能声称其为患者机制的唯一或必要解释。
- 若改善来自静默、事件数减少、丢掉一个模式或全部接近同一原型，不算恢复患者传播。
- 若快动力学和通路强度仍无法改善，且原始场持续表现为与 core 弱相关的多波前，下一步优先设计 core 控制和边界的配对检验，同时检查观测窗口。扩大薄片时要控制密度、入度和 core/电极局部几何；改环面会同时改变边界和远程路径，不能解释为只改了边缘。

另核对 GABA 实现：`kick_probe.py` 的电流递推为 `I_I = s_I + (I_I-s_I)*exp(-dt/tau_d)`，是单位直流增益低通。固定上升时间及脉冲增量时，12/18/24 ms 的单脉冲离散积分相同（误差 <1e-10）。因此前一版“未额外做剂量归一化”不应解释成衰减变慢就必然增加积分抑制；本实现主要重新分配单脉冲的时间形状。该检查保存于 `gaba_decay_impulse_area_review.json`，不是全网络响应证明。

完整新评价器仍属于已校准的开发诊断，不是最终独立验收；最终证据需要明确分离开发选择与独立患者/网络检验。当前不发布合格模型，不释放 Fig5。
