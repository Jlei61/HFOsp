# 第一轮：加入双 core 相对位置的软约束

作者本轮确认开始加入两个 core 的相对位置限制。这里沿用上一版预先确定的弱先验权重 **0.1**，将它从对照提升为第一轮主排序；不是新增角度硬阈值，也不是把两块固定回手放位置。

## 主目标与自由度

`J_round1 = J_direction + 0.1 * sin(core连线角 − 患者训练传播轴角)^2`

其中 `J_direction` 保持上一版完整事件云和有符号方向分布的两项拟合，以及原有训练数据标定的尺度。它的字段和数值保留，另存 `J_round1`，不把纯拟合分数改名冒充加入先验的分数。

相对位置参照轴为 −19.342543442°，来自患者训练事件；结构 EE 轴继续固定在 −22.805383965°。对齐时附加惩罚为 0；偏离 30° 时为 0.025；垂直时为 0.1。轴具有 180°等价性，交换 core 标签不改变限制。

**两个中心的四个 XY 坐标仍由数据搜索**。中点没有指定位置，间距没有固定值，沿用原有至少 4 mm、完整圆盘不重叠、预算与边界规则。该限制允许偏离，若偏离位置的数据拟合明显更好，仍可以胜出。

阈值深度生成参数继续固定，只搜索 VTH 场的位置；EE/E→I 与 Z/M 学习关闭。完成该轮事件与方向拟合、新网络确认之前，不自动冻结 VTH，不接受旧底部双核为最终基底。

## 对照与阶段

全局 132 个几何、2 个种子，共 264 个任务保持不变。已有仿真在相同输入、源码、网络和观测合同下产生，可以复用；本轮仅改变搜索选优准则，不改变轨迹生成。

全局结束后，每个空间域按 `J_round1` 选择两个局部细化锚点。短名单保留约束主目标最佳、无位置先验最佳、方向／事件云及分项指标最优；独立确认前，每个空间域分别提名约束最佳与无先验最佳，加历史对照。确认比较必须检查纯数据拟合和实际方向，不允许仅凭位置惩罚下降宣称传播行为改善。

无先验比较是在本轮已经评估的候选集合上重新排序；局部细化由本轮含先验的目标引导，因此不能把这个对照说成另一次完全独立、完整优化过的无先验搜索。

每阶段保留：

- `aggregate_cloud_v1.json`：最早事件云目标的诊断。
- `aggregate_direction_v2.json`：直接方向拟合与原弱先验对照。
- `aggregate.json`：第一轮主排序，含 `J_round1`、纯数据分数、无先验排序。
