## 0. 摘要（先讲人话）

**这一轮回答了两个问题，一个答成了，一个没答成。**

**答成的那个（但只答了一半）：把泵和离子装上去以后，网络平时**平均**放电快慢还能不能调回去？** 能。
零偏置下这条轨迹跑在每秒 6.96 次，比锁定目标 4.16 高 64%——spec 早就说这套东西**按构造**会把工作点
抬起来，两个"外加偏置"旋钮的职责就是把它按回去。实测：**按回去了，剩 1.8% 的差距**（4.085 对 4.158），
用的偏置只有 0.06 / 0.31 毫伏，远在允许范围内。

> **两处不能说过头（审阅 P1-1，已核实）**：
> (a) 那个 6.96 Hz 是 **noise401** 的离子层打开轨迹，而 4.158 Hz 是 **noise202** 的已接受泵关臂——
> **不是同一个噪声种子**，所以"离子层因果性地把率抬高 64%"缺一个 noise401 的离子层关闭对照。现阶段
> 只能说"零偏置的离子层打开轨迹比锁定目标高 64%"。
> (b) 恢复的只有 **E 群体平均率**，而且只在**一个** development 种子的**一个** 11 秒窗口里。**还没有
> 验收**：I 群体率（被选点仍高 10.3%）、事件率 / 间隔 / 时长 / 参与度、两核起始比例、种子与噪声稳健性、
> 离子统计平稳性。所以**不能说"间期工作点已经恢复"**，只能说"E 群体平均率回到了锁定目标附近"。

**没答成的那个：装上去之后，离子浓度本身稳不稳？** 看不出来，而且**这一轮连"看不出来"都还没测对**。
钠的时间常数是 54 秒，我们能负担的一条轨迹只有 11 秒——**连五分之一个时间常数都不到**。更要紧的是：
现在这个判据算的是"相邻两个快照之间变了多少"的**波动幅度**，而不是"整段窗口里有没有单向地往一个方向
走"的**长期趋势**。只要间期事件还在发生，正常的局部钾起伏就一直会让这个数很大，**哪怕离子过程其实
已经稳了**。反证：同一条轨迹的钠**群体均值**净变化只有每秒 −0.0026 毫摩尔，比那个数小 33 倍。
所以只能说"这条轨迹没通过现有的判据"，**不能说"离子浓度正在以每秒 0.26 毫摩尔漂移"**。

**所以 Gate B 没有判。** 在一个平稳性都还没测对的工作点上跑六条确认轨迹，得到的数字不代表 Gate B
声称的东西。按计划书 §15，遇到这种情况，**校准器要另外单独改进**，不在本轮继续。

**之前欠下的那个闭环问题，这一轮仍然没答上。** 我做了一个双 kick 的闭环测量（1.322）并拿它去比
一个开环数（1.366），但**两臂不是匹配对照**：闭环是活网络双 kick、`q_ion=0.013616`；开环是固定放电
记录的五事件离线重放、`q_ion=0.014544`，驱动方式和招募都不同。**先前写的"闭环没有克服清除"已撤回**，
现状是 `UNRESOLVED_MATCHED_CONTROL`（详见 §3）。

## 1. T7.1：判决层修复后的选点

五条裁决全部按 `docs/superpowers/specs/2026-07-28-topic4-fcxr-ion-T7_1-lock.md` 实施。重跑

| `f'` | ΔK_o 峰值 | 可测 ≥0.15 | 安全 ≤0.90 | 钾恢复 | 数值有效 | admissible |
|---:|---:|:---:|:---:|:---:|:---:|:---:|
| 0.5 | 0.2867 | pass | pass | pass (0.00σ) | pass | **是** |
| **1.0** | **0.5741** | **pass** | **pass** | **pass (0.01σ)** | **pass** | **是** |
| 2.0 | 1.1503 | pass | **FAIL** | pass (0.02σ) | pass | 否 |

tie-break 取最接近 1.0 → **`f' = 1.0`，PROVISIONAL_CANDIDATE**。

### 1.1 K-clamp 对照（裁决 2）——它**推翻了上一轮归档的一句话**

把 `K_o` 钳制在各档**自己的**工作点 `K_o*(f')`（不是静息 4.0），只删掉事件诱发的钾偏移：

| `f'` | 耦合（钾自由） | K 钳制 | 钾带来的加速 | 耦合 Jacobian 预测 |
|---:|---:|---:|---:|---:|
| 0.5 | 0.682 | 0.533 | **+0.149** | 1.148 |
| 1.0 | 0.655 | 0.577 | **+0.078** | 1.393 |
| 2.0 | 0.772 | 0.706 | **+0.066** | 1.873 |

**成立的部分**：钳住钾之后钠清除**变慢**，所以"同时抬高的钾确实加快钠清除"——上一轮只能猜的方向，
现在有对照证据。

**被推翻的部分**：耦合 Jacobian 预测**超过 1.0**（意味着超额应在 20 秒内被压到基线以下），而实测是
0.655。所以**实测比耦合线性化慢得多，不是快**。上一轮归档写的"实测衰减比预测快"只对**冻结钾**的
参照成立，**换成耦合参照就不成立**，该说法作废。

**为什么 Jacobian 高估——是这个诊断自身的配对错误，写明以免被当成物理**：`dK0` 取的是**单个热点格**
的峰值（0.29 / 0.57 / 1.15 mM），而 `dNa0` 是 **11329 个参与细胞**的中位数，这些细胞散布在很多格里，
大多数看到的钾抬升远小于热点格。拿热点格的钾配全体中位数的钠，会高估典型细胞感受到的钾。
**K-clamp 对照没有这个配对问题，是可信的那一个。**

### 1.2 单调性子句（裁决 3）

尾窗斜率 t = **−35.1 / −15.3 / −68.0**，衰减方向明确无疑。修复后的"净衰减 + 尾窗不持续向上"轻松
通过，而旧的零容差逐样本单调子句在抖动上失败（约 47% 样本向上，最大上跳达峰值 12–18%，1/2/5/10 秒
平滑**都**救不回来）。

## 2. B2：偏置标定与闭合

### 2.1 探针窗口必须与验证窗口一致（执行中发现）

**第一次用计划书的 4 秒探针失败了**，而且失败方式很干净：标定器收敛到 4.054 Hz，**同一个偏置**下
11 秒验证却回来 5.159 Hz，闭合门以 33% 失败。原因正是 spec §3.2b 与计划书自己的探针注记标注过的：
`tau_Na = 54.4 s`，4 秒探针只能估**快速率响应**，看不到慢漂移。

**修法**：`--probe-t-ms` 显式化，改用 11 秒探针（与验证窗口一致）。4 秒版证据保留在 `superseded/`。

### 2.2 11 秒探针的标定结果

| 偏置 (mV) | r_E | r_I |
|---|---:|---:|
| (0.000, 0.000) | 6.960 | 17.806 |
| (0.500, 0.000) | 19.519 | 46.935 |
| (0.000, 0.500) | 0.021 | 0.219 |
| (0.500, 0.500) | 6.700 | 17.241 |
| **(0.062, 0.315)** | **4.441** | **11.436** |
| (0.031, 0.157) | 4.628 | 11.998 |
| (0.127, 0.452) | 1.174 | 3.158 |

**基底的偏置敏感结构（对 B3/B4 有用）**：单独加 0.5 mV 在 E 上把率推到 19.5 Hz，单独加在 I 上压到
0.02 Hz，**两者同时加却几乎回到基线**（6.70 对 6.96）。所以存在一个近乎零效的 (1,1) 方向，可用窗口
约 ±0.15 mV/轴，而合法框是 ±2 mV。这也解释了 12.1 Hz 的"线性度误差"。

**判决 = `CALIBRATED`，偏置 (+0.062, +0.315)，E 率残差 6.8%。**

> **一处合同订正（我自己的偏差）**：执行中的判决用的是 `max(r_E, r_I)` 残差，**比合同严**。
> spec §7.1 的闭合硬门是 **E 率**残差；`r_I` 被明确列为 **Gate B 的检验项**（spec §7.1 L207）。
> 按合同重判 → `CALIBRATED`（E 残差 6.8%），`r_I` 高出 10.3% **不被豁免**，而是**带进 Gate B**。
> 只改判决规则，**没有重跑任何探针、没有改任何测量值**；原产物留在 `superseded/`。

### 2.3 闭合迭代：两条子句一过一败

`r0' = 4.4414`（与被选探针**逐位一致**）→ `q_ion` 0.01454 → 0.01362 → `r0'' = 4.0848`。

| 闭合子句（spec §7.1 要求**同时**成立） | 实测 | 门 | 结果 |
|---|---:|---:|:---:|
| E 率残差 `\|r0''−r0\|/r0` | **0.0176** | ≤ 0.10 | **PASS** |
| 离子块间**统计** q99 \|一阶差分\| | **0.2587** mM/s | < 0.05 | **FAIL** |

**判决 = `UNRESOLVED_CALIBRATION`，失败子句只有离子那一条。**

> **⚠️ 这个 q99 测的不是长期趋势（2026-07-28 审阅 P0-1，已核实）。** 它是 2 秒快照之间**一阶差分的
> 绝对值**，把所有细胞、格点、时段混在一起取 q99——测的是**波动幅度**。只要间期事件还在发生，正常的
> 局部钾起伏就会一直贡献这个数，**即使离子过程已经统计平稳它也不会趋近零**。
>
> 直接证据：同一条轨迹的钠**群体均值**从 19.8267 走到 19.8011 mM，净变化只有 **−0.00256 mM/s**，
> 比 q99 的 0.0838 小约 **33 倍**。
>
> 所以本轮**只能说**："这条轨迹没有通过现有的 q99 一阶差分门"。
> **不能说**："离子场正在以 0.2587 mM/s 做系统性漂移"。

> **两处产物订正**：(a) 执行中的一条代码路径仍按"只看速率"写下 `passed: true`，与 stage 判决矛盾，
> 已按记录数据订正；(b) 闭合门原实现只查速率，**漏了合同要求的离子平稳子句**，已补——补上之后
> 失败点从速率换到了离子平稳。

### 2.4 闭合迭代公式自身的边界（执行中发现）

第一次尝试在初始化处崩溃：`no bounded Na steady state for 23300 cells`。原因是闭合迭代按
`q_ion = J_Na,0·f'/r0'` 重算，**`q_ion` 与 `r0'` 成反比**，所以一个被压低的 `r0'` 会把 `q_ion`
放大，直到大部分细胞根本不存在有界的钠稳态。已加可行性前置检查，改为记录
`UNRESOLVED_CALIBRATION` 并说明这是**闭合公式在被压低工作点上的边界**，不是机制结论。

同时发现：验证阶段原本用**实测**率去缩放预平衡（1.068/1.103），而被选探针用的是**预测**率
（≈1.000）。在 `tau_Na = 54.4 s` 对 11 秒窗口的比例下，这个差别**不是细节**——两种选择给出实质
不同的轨迹。闭合门问的是"被标定的那个点稳不稳"，所以验证必须**复现探针的条件**。改正后
`r0'` 与探针值逐位一致。

## 3. 裁决 4 要求 B2 报告的闭环答案

本轮做的测量：同一基底、同一冻结偏置，两次相同的 kick 间隔 200 ms，**离子反馈打开**。

| 量 | 值 |
|---|---:|
| 闭环 2nd/1st（活网络双 kick，`q_ion=0.013616`） | **1.322** |
| 开环 2nd/1st（固定 raster 五事件重放取前两峰，`q_ion=0.014544`） | 1.366 |
| 纯线性叠加（工作点 `tau_Ko`） | 1.704 |

**答案：`UNRESOLVED_MATCHED_CONTROL` —— 这一轮答不了（2026-07-28 审阅 P0-2，已核实）。**

两臂**不是匹配对照**，差别不止"反馈开/关"：

| | 闭环臂 | 开环数 |
|---|---|---|
| 运行方式 | 活网络双 kick | 固定放电记录的**五事件离线重放**取前两峰 |
| `q_ion` | 0.013616（闭合后） | 0.014544 |
| 驱动 | kick，动态招募 | 录下来的自发事件 kernel |

代码注释里写的 "SAME kernel" **是错的，已撤回**。因此 **1.322 < 1.366 不能推出"闭环没有克服负荷
依赖清除"**。

**正确的匹配对照应当**：两臂使用**相同**的 `q_ion`、bias、初始离子场、噪声种子、kick 时刻与强度；
闭环臂让 `ΔK_o → ΔE_K` 动态生效，开环臂**只冻结事件诱发的 `ΔE_K`**、并用常数补偿保持相同的 kick 前
工作点；同时报告两臂每次 kick 的 spike 数、参与细胞与钾峰，确认刺激负荷确实可比。

## 4. 一条**不能**报的停机条件（自我订正）

11 秒轨迹里 `k_wave_far_over_event ≈ 0.97–0.99`，看起来触发了 spec §11 停机条件 3（普通间期事件
产生全局钾波）。**不能这么报。**

这个度量取的是**整个后燃烧期窗口内所有远端格的最大值**，基线是**窗口早期**——而离子状态正在全局
上漂，所以**只要有全局漂移，这个比值就会趋近 1.0，哪怕根本没有波**。要回答停机条件 3 需要
**事件锁定**的比较：同一个事件的短窗内，事件格与远端格各自相对**事件前**基线的 ΔK。本轮**没有
实现**，因此该停机条件是 **UNANSWERED，不是 triggered**。已在产物里标注 `..._is_confounded`。

## 5. 允许与禁止

**允许**

- 两个 nuisance 偏置在**一个 development 种子的一个 11 秒窗口**里把 **E 群体平均率**拉回锁定目标
  附近（残差 1.8%），所用偏置远在合法框内；
- 零偏置的离子层打开轨迹比锁定目标高 64%（6.960 对 4.158 Hz），方向与 spec §3.2 的预期一致
  （**但两数来自不同噪声种子，缺 noise401 的离子层关闭对照**）；
- 同时抬高的钾**确实**加快钠清除（K-clamp 对照 +0.066 ~ +0.149）；
- 在这个基底、这些尺度、**开环**：200 ms 间隔事件的钾累积是**次线性**的（闭环那一半未成立匹配对照）；
- `f' = 1.0` 是四条修复后硬门下唯一的 provisional candidate（0.5 也 admissible，2.0 超安全上限）。

**禁止**

- 说 Gate B 的任何结论——**未判决**；
- 说"间期工作点已经恢复"——只恢复了 **E 群体平均率**，I 率仍高 10.3%，事件统计 / 两核起始 / 种子稳健性
  **都没验收**；
- 说"离子层把率因果性地抬高了 64%"——两数跨噪声种子，**缺匹配对照**；
- 说"离子状态已达稳态"或"未达稳态"——11 秒 = 0.2 `tau_Na`，**这个窗口回答不了**；
- 说触发了"全局钾波"停机条件——见 §4，度量被漂移混淆，**未回答**；
- 说 `NO_GO_BASELINE`——合法框从未被括住（12 次预算用了 7 次，只探了 ±0.5 mV）；
- 说"钾正反馈被否定"或"闭环没有克服清除"——两臂**不是匹配对照**，见 §3；
- 说"泵的电生性作用已被检验"（`eta_pump` 全程锁 0）；说复现了双向传播；说获得了生命周期。
