按以下顺序完整实施，已满足的阶段门按合同继续，未触发的阶段写明未执行；不反复询问常规实现选择，也不靠扩矩阵追阳性。

2. 实现独立的全局状态控制器。每个 episode 的 z_E/z_I 对全体 E/I 阈值分别产生 −1 mV×s 的偏移；准备 200 ms 保持 z，交接后 τ=1000 ms 衰减。s=0 必须保持旧轨迹；不改 OU/Poisson 率，不注入患者路线、模式标签、事件答案或逐细胞可学习初值。背景预热 2000 ms，使用完整 checkpoint；控制器必须进入 checkpoint 协议，恢复时不丢弃突触/延迟环/外源 RNG。
3. 实现连续/恢复一致的事件观察。保留预热上下文，交接后不再丢 0.5 s。评分 2000 ms，另保留 125 ms 完成观测窗口。每个 episode 首结局为 carryover，或第一个新的检测事件，或 null；首事件不合格不能跳到下一个。runaway、工程缺失单列。
4. 先完成 P0：零状态兼容、完整恢复、S/R 仅 s 不同、外源流一致、观察器分段一致、已知阈值跨越、已知分布积分恢复和无状态信号 null。只写有科学判别意义的测试。P0 通过后实测资源预算，默认最多 2 worker，并遵守主线资源限制。
5. 执行 P1，25 状态×8 父噪声，共 200 episode。一次性生成完整 response bank，保留所有失败/无效结局。输出 P(primary)、模式/模糊概率、参与＋相对时序距离；先判定物理映射是否有患者相容的不同传播。自由 simplex 混合仅作有限库容量上界，不能成为正式低参数模型。容量/样本不足时交付明确结论，不自动增 K。
6. 执行 P2，仅学习分布。患者 FIT 28 块外层 4 折、内部 3 折；模拟按 8 父噪声留一，父 checkpoint 不拆分。各折特征标定只用训练块。拟合最佳常数 C、固定单峰 Q0、4 参数 Q1；若不足先检查 5 参数相关单峰 Q1-full，再按条件比较共享完整协方差的 Q2/Q3（8/11 参数）。相关 Gaussian 单元概率不得以边缘乘积代替。统一距离、固定正则、内部一标准误选最简单家族，不能用外层分数继续调参。全 FIT 家族选择后，常数 C 作 8 实际点×8 噪声精修，最多 64 新 episode；取其自身 Voronoi 方格每轴下界/中点/上界的 3×3 点，去掉原格点，恰为 8 点。精修结果不能倒灌外层成绩；外层只报告粗格点基线，P3 对比精修常数。若精修 C 消除分布优势，停止 P3。
7. 积分必须显式乘 P(primary|z)：以所有 episode 的成功指示量形成条件特征均值，禁止先对每状态筛好事件再等权拼接。先验权重用截断 Gaussian 的单元概率，不是自由 25 维权重。不重新聚类来改善各 K 的评分，不调用会打开其他分区的 evaluator.metrics()。
8. 只有 Q 胜过精修 C 才冻结唯一先验、最佳常数及全部读出，执行 P3 128 个新父噪声配对×2 臂。必须实际抽连续 z 并运行 SNN，不能插值波形，不补抽失败 episode。按计划做联合传播距离和产出资格的配对区间；不足样本则判不确定，不补到显著。
