## 一句话结论

冻结二值双-core Node 场后，连接参数而不是 Node 强度在当前范围内主导患者样事件的组织。EE 与 E→I
同时上调 25% 是唯一在 12 张新网络上同时改善完整事件分布、双模板一致性和 OOD 的候选；单独把 EE
或长短轴比推高虽能进一步降低距离和 OOD，却会减少事件并削弱第二种模板。没有候选进入患者匹配地板，
所以当前支持的是双模板容量和机制响应，不是完整患者间期活动复现。

## 1. 科学问题与冻结底物

本轮不再优化连续自由场，也不再把 detector 切出的两个片段当作两个事件。Node 底物固定为
`dualcore_s39`：两个半径约 1.8 mm 的二值圆盘，共覆盖 1,499 个 E 神经元；圆内仍保留冻结的
逐细胞 signed-depth 异质性 `d_i`。每个 returned event 的正式单位是一次完整、隔离、由同一因果根
支持的 edge-supported causal family。

逐次只改变一个坐标：

- Node gain、core budget、signed-depth shrinkage；
- learned E→E、learned E→I、两者联合表达；
- E→E 椭圆长轴方向、长短轴比。

`Joint=1.25` 的含义是同时把基准 `g_EE=0.5` 和 `g_EtoI=1.0` 乘以 1.25，即实际为
`g_EE=0.625, g_EtoI=1.25`；它不是第三条生物通路，也不能仅凭本轮称为 synergy。

## 2. 选择与检验严格分开

Screen 为 31 个候选 × 4 个网络种子（2511–2514），共 124 条 20 s 轨迹。每个机制族只按患者训练
事件云的**无条件完整分布距离**冻结一个候选；选择时 KMeans、OOD 和 patient held-out 均未打开。
随后才对 screen 只读打开这些验证端点。最终参考点和 8 个族内候选在 12 个全新种子
（2521–2532）上确认，共 108 条轨迹。

同一 seed 在所有候选间复用，形成 common-random-number 配对；不同 seed 会同时重建网络、背景随机
驱动和仿真 RNG。自然 KMeans 每次使用 8 个 random states，每个 `n_init=50`。因此本轮不是优化器
多次落入同一局部极值；当前边界是 network seed 与 dynamics seed 绑定，尚未独立分解两种方差来源。

三个验证端点互不合并：

1. held-out complete-distribution distance，越低越好；
2. natural KMeans 与冻结患者双模板的 balanced alignment，越高越好；
3. 全部 returned causal families 中的 OOD fraction，越低越好。

统计单位是网络种子；下表区间均为 90% paired network bootstrap。

## 4. 因素解释

### 4.1 Node 几何已提供成核底座，窄幅强度调整不是主要杠杆

Node gain、core budget 和 `d_i` shrinkage 的 screen 小优势均未在 12 个新 seed 上复制。尤其把
`d_i` 完全压平几乎不改变三个端点，说明当前宏观双-core 几何比该份微观异质性 realization 更承重。
这不证明所有 Node 参数都不重要，只说明在冻结几何周围的本轮范围内没有稳定增益。

### 4.2 EE 主要控制传播支持，但单独加强会偏向一个模板

`g_EE=0.75` 显著降低完整距离和 OOD，却把事件数从 34.3 降至 24.4；双模板一致性的配对区间跨零，
网络间波动很大。它更像把事件压进患者支持区内的一条较窄传播路线，而不是完整保留双模板 repertoire。

### 4.3 E→I 单独调节没有复制，联合调节有效但不能称为交互因果

`g_EtoI=1.5` 在 12 个新 seed 上与参考无可分辨差异。`Joint=1.25` 三个主端点均改善，说明 EE 与 E→I
协调表达是当前最稳的低维工作点；但本轮没有跑完整 EE×E→I 二维因子，因此不能把联合结果拆成
E→I 独立效应或统计 synergy。

### 4.4 连接椭圆存在清晰的结构边界

- 长轴转到 67.5°：事件更多，但完整距离和 OOD 都恶化；45° 附近仍是当前患者支持方向。
- 长短轴比 3.0：OOD 几乎归零、距离最低，但 KMeans minority cluster 平均只占 0.15
  （范围 0.04–0.32），双模板一致性显著下降；这是 mode collapse，不是最佳恢复。
- 长短轴比 4.0：4/4 网络全部 runaway，不能作为普通 `OOD=1` 点解释。
- 长轴 90°：4/4 网络零 returned events；0° 和 22.5° 也有网络不可估计。

因此各向异性不是越强越好：它在“过宽支持 → 双模板可达 → 单模板收窄 → runaway”之间形成边界。

## 5. 不能夸大的地方

1. 最低 held-out 距离仍是 aspect 3.0 的 0.851，而同事件数患者地板 q95 为 0.371；平衡候选
   Joint 1.25 为 0.994，地板 q95 为 0.337。完整患者事件分布没有恢复。
2. 这是单个患者/单套植入几何上的 development 结果，不是 cohort generalization。
3. `Joint=1.25` 是 Fig.5/ZM 下一阶段较合理的冻结间期底物，但下一阶段必须继续分别报告
   低活动期完整分布、双模板一致性和 OOD，不能只因出现 runaway 就接受。
4. 当前 12 seed 将网络 realization 和背景噪声一起变化；若下一阶段效应接近边界，应增加固定网络 ×
   独立 dynamics seed 的小型交叉审计。
