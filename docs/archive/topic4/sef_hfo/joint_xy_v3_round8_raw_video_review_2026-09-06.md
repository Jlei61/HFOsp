## 目视记录

**replicated_r008_016**：首个事件先在两个 core 外的左下区域出现，随后经过下部及边界；窗口内还有右下 core 附近向左上发展和后续右上边界活动。首事件 SCL 与 ICL 的时差和缺失接触点仍明显。

**replicated_r007_014**：首个事件上方 core 邻近活动向上和向右分开，随后下方 core 邻近活动经过下部及侧边界。首事件只有 ICL 参与，上方原始活动未转为 SCL 参与。

**replicated_r008_022**：首个事件在上方 core 外的左上区域先可见，随后沿该 core 向下发展，右侧活动与弯曲、分开的波前共同扩展至下方 core 和边界。

**replicated_r008_004**：首个事件先在左上 core 邻近可见，向右下弯曲发展，经过下方 core 时向左和向右分开，后续经过上、右和下边界。共同接触点的部分顺序接近 TA，但有缺失和过长时差。

**replicated_r008_003**：新联合最优候选的首个事件先在右侧、两个 core 外可见，随后左下也出现活动，形成分开的波前，向左上和右下扩展并经过两个 core 邻近区域。不能由较好联合分数认定是双 core 之间传播。

**replicated_r007_018**：首个事件先在上方 core 左下的 SCL 区域可见，分向上、右扩展；左方 core 邻近随后活动，多个波前向下和右边界发展。上方 core 并非明显最早亮起位置。

## 判断边界

native/readout 中位误差约 2 ms 说明接触点时序差异通常较小，不代表 readout 完整保留了整个 2D 波前，也不代表患者复现。部分事件偏差远大于中位数。患者 TA/TB 为未配对示例，不能用二者中较好者替代全患者分布评估；不重缩放时间，不删除缺失接触点来宣布通过。患者显示质心和训练 lagPatRaw 质心不是同一估计器。原始格点记录是 1 mm/2 ms 内活跃 E 神经元计数，不是单神经元 spike raster。

新最优 r008_003 的联合误差 0.0577218，仍高于同样本量患者门槛 0.00838787；其首事件对 TA 的顺序不一致率为 0.1341（82 对可分辨共同接触点），成对时差 MAE 为 14.0348 ms，参与不一致 1 点。这个示例不能抵消全事件分布失败。
