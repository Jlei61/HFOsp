## 0. 一段朴素话：A1 整段在干什么（测了什么 / 怎么测的 / 揭示了什么）

**测了什么。** 我们拿 Stage-3 那个"会自己点火的异质核"当衬底——网格上有两个比周围更兴奋的小核团，
不去踢它，它自己就会冒出一串一串离散的发放事件，方向在两个核之间来回换（这就是"间期：两条独立模板
轮流来"）。A1 问的是：去拧一组旋钮（让某些细胞更兴奋/更不兴奋、让局部小回路更强/更弱、让全局抑制更松/
更紧、让抑制随放电动态地累积），网络的整体活动会从"间期沿轴自限传播"，挪到"发作样的大范围同步"，再挪到
"彻底失控"或者"全灭"——把这张状态地图画出来，并找出哪个旋钮是把"独立间期"推成"发作"的真正杠杆。

**怎么测的。** 三步，每步都跟"如果这个旋钮没用、状态就不该变"对比：
1. **a1a（单旋钮冻结扫）**——把每个旋钮单独冻结在不同档位，看哪个能把"两个核独立轮流点火"变成"两个核
   一起点火（同步）"。同步用一个干净判据量：在自发回落的事件里，两个核在 30ms 内一起点着的比例。
2. **a1b（二维状态面）**——把"局部小回路强度"和"全局抑制松紧"两个旋钮一起扫，画二维状态地图，看哪个轴
   主导，发作样态落在地图哪里。
3. **a1c（动态全局刹车筛查）**——把全局抑制从"固定强度"换成"随网络总放电率动态变化"：放电越凶、刹车越大
   （对所有兴奋细胞一视同仁，只看全网平均，不分位置）。看这种动态刹车能不能把一个本来会失控的角，变成
   "点着以后自己回落"，同时不把别的能工作的状态压死。

**揭示了什么。**
- **a1a**：在"冻结扫参"这种**静态**测法下，最稳健地把"独立点火"变成"同步"的旋钮是**去极化型 GABA**
  （氯离子反转电位那个）——保护档静默、中间档独立、再高一档稳健同步、再高就失控。但这是**静态**结论；
  真正的动态机制（抑制随用累积、Abbott 的 z）这一步**没测**，所以**不能**说别的旋钮（尤其动态 z）没用。
- **a1b**：**全局抑制松紧是主导轴**——松了（低抑制）全失控，紧了+弱回路全灭，对角线中段能看到"发作样的
  大范围同步、但还能回落"。结构性的"局部:全局比"能走到一个比单拧去极化 GABA **更干净**的发作样态。
- **a1c**：**动态全局刹车干净终止不了"集中在核里的失控"**。因为失控集中在核，而全局刹车对所有细胞一视同仁
  ——要压住正在燃烧的核，就会把周边和较弱的工作态一起压死；**没有任何一个刹车强度，既能终止强回路的失控、
  又能保住弱回路的工作态**；而且刹车并**不**领先于放电下降（不像"动态因果终止"，更像一记很重的静态刹车）。
  结论：**均匀的全局刹车，不是核集中型失控的对的工具**——方向指向 **A2**：要么是**局部环绕抑制**（空间上
  贴着核加抑制），要么是**抑制随用动态耗竭**（动态 z / Cl⁻ 累积）。

## 1. A1 的定位（A1 是什么、不是什么）

- A1 = **状态地形图**：把这个会自己点火的异质核，在"细胞兴奋性 / 局部回路 / 全局抑制 / 动态刹车"几个旋钮
  下的活动状态铺开，找"间期↔发作↔失控"的边界和主导杠杆。
- A1 **不是**动态因果链证明，**不是**"发作机制锁定"，**不是**任何队列级结论。它给的是 A2 要在哪个区域、
  用什么机制去做"动态发作发生学"的**地标**。
- 衬底是 Stage-3 异质核（已经能自发产生离散、方向交替的间期事件）——A2 直接继承这个衬底，不要再回均匀平面。

## 3. a1a 结果 —— 单旋钮冻结扫

衬底上两个核会自发点出一串离散事件、方向在两核间交替（间期 = 两条独立模板，同步比 ~0.1–0.2）。把每个
旋钮单独冻结扫，看哪个能把"独立"逼成"同步"：

- **去极化型 GABA（氯离子反转电位）= 静态最强候选**：保护档（11–13）静默 → 14–15 独立点火（同步 ~0.05–0.38）
  → **16 稳健同步（同步 ~0.66，跨 3–5 个网络都成立）** → 17 失控。**不是放电率假象**（15 档事件比 16 档更多
  但同步更低）。
- **z（去抑制）**：平均同步在 z≤0.65 确实抬头，但 **seed-脆**（z0.6 三个网络 0.39/0.50/0.88）。
- **phi（阈值）/ g_K（sAHP 保护）**：没有转变。

**a1a 口径锁（避免"只有去极化 GABA"的坑）**：静态冻结扫里去极化 GABA 是最强候选，**但静态冻结的 z ≠ 动态
随用的抑制耗竭（Abbott 的 z）**，所以 **z 没有被否定**——它的作用要在**动态**层（A2）才看得出来。这正是把
"动态 z / Cl⁻ 累积 / 反馈恢复"整体推给 A2 的理由。

## 4. a1b 结果 —— 局部回路 × 全局抑制 二维状态面

静态扫"局部小回路强度"（`core_ei_scale/core_ee_gain`：弱 (1,1) / 中 (0.85,1.15) / 强 (0.70,1.30)）×
"全局抑制松紧"（`global_ei_scale` 0.7/1.0/1.3/1.6）× 3 个 seed + 去极化 GABA16 阳性对照：

- **全局抑制松紧是主导轴**：全局=0.7（低抑制）→ 9/9 全**失控**；高抑制+弱回路（l0_g1.6）→ **全灭**（全网率 0.06Hz）；
  中间 → 间期；**对角线中段 → 发作样**（大同步但仍回落）。
- **沿"局部:全局比"从小走到大** = 静默 → 间期 → 发作样 → 失控。
- **结构性旋钮 vs 去极化 GABA**：去极化 GABA16 阳性对照**冲过头到失控**（同步 0.72 但回落 0.12 = 同步更狠却不
  回落）；而结构性的 局部:全局 能到一个**更干净**的发作样态（同步 ~0.4 但能回落）。

**a1b → a1c 的交接**：a1b 的"发作样能回落"标签是在 **per-event 相对** readout 下打的（ret 0.96 这类）。a1c 引入
**绝对**回静比后发现：这些"能回落"的态在绝对尺度上其实仍偏高（见 §5）。所以 a1b 给 A2 的不是"这里有干净的可回落
发作态"，而是"**全局抑制松紧主导、发作样落在对角线中段**"这个地标——可回落与否要用绝对判据重新认定。

## 5. a1c 结果 —— 动态全局刹车筛查（P1 已修正口径）

**问题**：把全局抑制从固定强度换成"随全网总放电率动态变化的刹车"（`I_global = gain·EMA_Hz(全网E率)`，只压
E 细胞，一步因果延迟），能不能把一个静态会失控的角变成"点着后回落"，**同时不把别的工作态压成静默**。

**设计**（PILOT，3 seeds）：
- **失控锚 `l2_g1.0`**（强回路）：gain=0 基线在绝对回静比下 = 570–1101×，三 seed 全失控。
- **工作态保留对照 `l1_g1.0`**（弱回路）：**注意（P1-1 修正）**——它在 gain=0 基线、绝对回静比下也是 110–338×，
  **同样偏高、不是"已经能干净回落的发作态"**。它的正确角色是"**a1b 来源的、较弱的工作/活动态**"；a1c 对它只问
  一件事：**动态刹车会不会把它从'有活动'直接压成'静默'（过压）**。
- 反馈增益 `{0,8,16,32}` × τ{150（事件内）, 2000（事件间）} × 3 seeds。

**揭示什么（诚实，screen 级）**：

1. **均匀动态全局刹车干净终止不了核集中型失控。** 分增益看（强回路锚 `l2_g1.0`，τ150）：
   - g8 → 三 seed 仍失控（绝对回静比 154–302）；g16 → 仍失控（116–226）；g32 → 终止 2/3（回静比 0.22 / 0.62），
     第 3 个 seed **从没点着**（过压成静默）。
   - 弱回路 `l1_g1.0`（τ150）：g8 起开始零星终止，**g16 终止 2/3 且没压成静默**，g32 → 2/3 **压成静默**。
   - **跨格关键事实（这就是"没有联合窗口"）**：终止强回路要 g32，而 g32 把弱回路工作态压成静默；能干净
     保住弱回路的 g16 又**碰不动**强回路失控（强回路 g16 仍三 seed 失控）。两格需要的增益**不重叠**。
     （这条已由 **机器判据 `joint_window_by_gain_tau` 固化**，不再靠人工读表——见 `status_a1c_pilot.json`。）

2. **磁量级（P1-4，三个量分开讲，且只在同一 run 内比，别跨 run 配对）**：
   - `I_global_peak`（动态刹车实际峰值电流，锚 l2_g1.0 t150 **三 seed 中位**）：g8 ≈ **56** → g16 ≈ **79** → g32 ≈ **91**
     （g32 两终止 seed 91/107）。
   - `I_I_on_E_p95`（核自己产生的抑制电流，E 上 95 分位）：**失控的 g8/g16 run 里 ≈ 370–540**；run 一终止（g32）核停火，
     同 run p95 **塌到 ≈ 96–168**。
   - → **同一 run 内**比：失控的 g8/g16 run 里刹车峰值（~55–89）只有该 run 自身核 p95（~370–540）的 **~0.11–0.18 倍**
     （压不过燃烧的核 → 仍失控）；到 g32 刹车升到 ~91–107、核 p95 同时塌到 ~96–168，刹车才追平正在塌的核。**刹车是把
     边界附近的强回路推过去，不是压住满火力的核。**
   - `I_global_to_I_I_ratio`（峰值 / E 上抑制**中位数**，锚 cells ≈ **68–123**）很大，**只因分母是近乎静默的周边细胞
     中位数（~1）**——它**不**代表刹车压过了核。要比刹车 vs 核，比的是**核 p95**，不是全 E 中位数。
     （旧 recap 把"~90–300"当刹车峰值写、其实是回静比尾值；又把 g32 刹车峰值和**失控 run** 的核 p95 跨 run 配成
     "0.2–0.3 倍"——都已纠正。）

3. **那点 g32 部分终止是动态 / 时序特异的（P1-3 onset-gated 对照判定，§7）**：互相关上 `I_global` 不领先率下降
   （leads-decay≈0，与率峰**同时**非领先），但放开点火窗后施加**等幅度**刹车的对照显示——恒定刹车 + 时间打乱刹车
   （保留全部峰值幅度、只错位）**都不终止**已点火的失控，**只有**随率同步的动态反馈终止（两 seed sign-consistent）。
   （早先 from-t0 对照的"静态也终止"是 prevent-ignition 假象，已被 onset-gate 纠正、结论翻转。）

4. τ=2000（事件间）对单次亚秒失控无效（仍失控）——符合预期，长 τ 刹不住快失控。

**a1c 结论（命名纪律，P1-1）**：headline **不变**——**在这个衬底上，均匀动态全局反馈没有干净操作窗口**（终止强回路
锚的 g32 同时把弱工作态过压成静默，`joint_window_exists=false`）；机制是失控集中在核、而空间均匀的刹车一视同仁。
但 sub-claim 已纠正：那点 g32 终止**是真动态/时序终止**（不是静态强刹），**问题在空间均匀不在动态本身**。**禁止**写
"Abbott 抑制耗竭机制成立"或"全局反馈终止发作"。

## 6. A1 建立了什么 / 没建立什么（A2 别越界引用）

**A1 建立（可作为 A2 地标）**：
- Stage-3 异质核能自发产生离散、方向交替的间期事件（衬底可用）。
- 状态地形：**全局抑制松紧是间期↔发作↔失控的主导轴**，发作样落在"局部:全局"对角线中段。
- 静态扫里去极化 GABA 是把"独立"逼成"同步"的最强**静态**候选。
- **均匀全局反馈（无论静态 a1b 还是动态 a1c）没有干净操作窗口**压不停核集中型失控而不伤周边——这是 A1 给 A2 的
  最强方向性结论。**注意**：动态反馈**确有**真终止作用（时序特异，P1-3 §7），坏在**空间均匀**——所以"问题在空间、
  不在动态"，A2 把机制做成**局部/空间**或**用-依赖动态**才有戏。

**A1 没建立（A2 不能拿 A1 当证据）**：
- 没证明任何"动态发作发生学"——A1 是状态地形 + 筛查，不是动态因果。
- 没否定动态 z / Cl⁻ 抑制随用耗竭——静态冻结 z 脆 ≠ 动态 z 无效。
- 没认定"可回落发作态"在绝对尺度上存在于某个具体格（a1b 的可回落标签是相对 readout，需绝对判据重认）。
- 没做任何队列/真实数据对照——纯模型衬底内部。

## 7. P1-3 对照已收口（动态 / 时序特异，结论翻转）

a1c 的部分 g32 终止"是动态特异、还是等价于一记静态强刹"，由 onset-gated 对照判定（P1-3）：对强回路锚 `l2_g1.0`
的两个 g32 终止 seed（s1、s2），放开点火窗后施加**等幅度**的 **matched constant**（动态刹车 post-onset 均值）和
**time-shuffled**（保留全部幅度、打乱时序）刹车，跑同样读出。结果（两 seed sign-consistent，`control_informative=true`）：

| seed | 动态反馈 | matched-constant | time-shuffled |
|---|---|---|---|
| s1 | terminated (tail 0.22) | **runaway** (573–954，点火 peak 46–56) | **runaway** |
| s2 | terminated (tail 0.62) | **runaway** | **runaway** |

→ **终止是动态 / 时序特异的**：等幅度的恒定 / 打乱刹车都**不终止**已点火的失控，只有随率同步的动态反馈终止。
（早先 from-t0 对照得到的"静态也终止"是 **prevent-ignition 假象**——恒定刹车从 t=0 把点火摁住了；对抗审查 workflow
命中，onset-gate 后结论**翻转**。）**这不改变 A1→A2 的方向**：headline（无干净操作窗口）不变；新结论"动态确有时序
终止作用、坏在空间均匀"反而把 A2 推得更实——**保留动态、做成局部/空间或用-依赖**。

## 8. 交给 A2 的口子（建议范围，非强制）

A1 的负结果把方向收得很窄。建议 A2 从下面两条**机制特异**路线里选（都在同一 Stage-3 衬底上）：

1. **局部环绕抑制（空间）**——既然失控集中在核、均匀刹车压不准，A2 测"贴着核加抑制（环绕/前沿）"能不能
   选择性终止核而不伤周边。这和 M2 的"动态前沿抑制门"思路同源（见 [[project_topic4_m0_boundary_audit_2026-06-18]]
   M2 rate toy 空间腿 PASS），是 A1c 负结果最自然的承接。
2. **抑制随用动态耗竭（A2 本名）**——Abbott 的动态 z / Cl⁻ 累积 + 反馈恢复：抑制不是被外部刹车压，而是
   随放电被"用掉"而塌陷。a1a 已说静态 z 脆但未否定，动态层才是它该发力的地方。

两条不互斥；A2 计划可以先 pilot 哪条在这个衬底上更能产生"点着→自限回落"的可回落发作态（用绝对回静比判据）。
