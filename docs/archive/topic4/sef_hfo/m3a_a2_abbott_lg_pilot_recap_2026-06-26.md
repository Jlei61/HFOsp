## 朴素话（测什么 / 怎么测 / 揭示什么）

**测什么**：一片脑组织里埋了两个易兴奋的"病灶核"，平时背景噪声下各自冒一点会回静的小放电（间期样）。
我们给病灶核配一个"抑制油箱"——一个 0 到 1 的量，表示这个核当下能用的抑制有多足；**放电越凶油箱漏得越快，
安静时慢慢回灌**。核心问题：当核自己放电把自己那箱抑制漏掉（局部去抑制），网络会不会**自己**（不戳）从零星
小放电，滑进一段"大范围发作样"活动，再滑回间期样——也就是间期↔发作两个状态来回。

**怎么测**：把"油箱漏的速度"（耗竭强度）从弱扫到强，每档开长记录、不外部戳，盯一个总数：核相对全局把抑制
漏得多狠（漏得越狠、网络越容易点着）。**如果油箱完全不漏，这个数不动、只看到间期样小放电；实测让它能漏**，
我们看这个数会不会**先升过"发作样"那条线、然后再降回来**——升上去又能自己回落，才算"间期→发作→恢复"的两态来回。

**揭示什么（分两步）**：

**第一步——只靠"漏抑制"这一个慢变量：产生不了"间期→发作→恢复"的来回。** 它只有两种结局：漏太弱核没点着
（停在间期，那个数始终在线以下）；或一旦漏到能点着，就**直接冲到底**——把油箱漏空、网络卡在高放电不回头（失控，
那个数钉在最高位、整段都在发作样带里、核放电常居 300–440）。中间那段"点着了又能自己回落"的来回，扫遍各档强度、
两种油箱配置（只核 / 核+全局）、各起点、各种子、各回灌快慢、甚至把记录拉到 10 个周期，**一次都没看到**。原因很
直接：抑制漏空让网络更兴奋、更兴奋又把抑制漏得更空——**只进不退的正反馈**，没有反向力，发作后网络也不会自己安静
下来让油箱回灌。

**第二步——再加一个"放电时会自己长出来、把网络按下去"的反向刹车（钾电流类）：看到了一种慢-快耦合的放电脉冲循环，
但还不能叫"间期→发作"两态切换。** 在一个窄窗口里，网络自发地：安静一会 → 冒一串放电、那个数冲过 1.35 这条线 → 反向
刹车把它掐断、油箱回灌 → 再安静 → 再来（图 `explore3_gk/figures/gk_two_state_trace.png`：那个数来回、油箱锯齿漏了又回、
刹车锯齿长了又退、放电一串串离散爆发夹着安静）。**但这里有个关键的没做完：放电变多、那个数穿过 1.35，都不等于"传播
模式"真的从间期型变成了发作型。** 真正的发作态要在虚拟电极上看到——两个核都被招募、大部分触点近同步大爆发、空间
范围明显变大——这套传播表型检验本轮**还没做**；而且实测这些 bout 里的单个事件分类仍是"大-但回静"（R3，和间期的大
事件同一类），不是"有前沿的持续招募"（R4a）。

**所以"动态慢变量能不能产生间期/发作两态"的当前答案**：单靠局部抑制耗竭**不行**（稳健的"要么停要么失控"）；耗竭
**加上**一个反向恢复刹车，能产生一个**自发的慢-快放电脉冲/松弛振荡候选**——但三条诚实边界把话压住：(1) 这是**两个**
慢过程的事（钾电流是**第二个**机制，不能算"A2 抑制耗竭这一个机制成功"）；(2) 还**没证明**传播模式发生了间期↔发作
切换（缺虚拟电极的同步/空间范围/招募表型检验 + 率匹配对照——"放电多 + 那个数穿线" ≠ 传播变了）；(3) 这个循环**种子
脆弱**（同一参数换种子给两态/失控/安静三种结局，是骑在两个盆地边界上的**刀刃**，不是稳健吸引子），且"发作"那一极
还**偏弱**（那个数只到 1.40、放电峰 53Hz、事件还是 R3，不是剧烈大范围招募）。

## 6.1 A2-P 确认版（batch5，T=20000，源空间完整 instrument）— GATE FAIL 维持，但**纠正第一版两个说法**

**朴素话**：换了更细的"源空间"读数（事件在脑组织里铺多少 mm、招募多少神经元、质心在两核之间哪里、能不能读出传播方向）+ 4–16 倍事件量后，发现第一版（粗电极格子）的两个说法是错的：① 不是"事件和间期一样大甚至更小"——源空间里候选 bout 的中位铺开 ~12mm，是间期 ~5.6mm 的两倍多，**和失控态一个量级**；② 不是"只换时间节律不换空间"——许可度越高事件铺得越广，**控制了放电神经元数之后这个关系还在**（rate-independent）。**但传播两态依旧 FAIL，理由更准**：那个"铺得广"的态是**整片同步爆发**，不是会传播的发作波——三种情况（间期/候选/失控）传播方向都读不出来（≈0.12），候选 collision=0（间期 0.12、失控 0.5），无持续前沿（R4a=0）。**L=20 这张衬底自发只会同步爆发、不会自发传播波（与本仓库 axial-intervention 试点喊停"synchronous bursts not traveling waves"独立印证），所以"间期传播态↔发作传播态"在这张衬底上根本表达不出来，跟用哪个慢变量无关。**

## 6.2 ⚠ 源空间逐细胞复核推翻 §6 / §6.1 的"同步爆发不传播"判读 —— gate **重新打开**（2026-06-26）

**朴素话**：为了画主图，把每个事件里**每个兴奋细胞第一次放电的时刻**直接在源空间画出来（颜色=放电时刻）。一看就发现 §6/§6.1 错了：这些高许可度事件**不是整片同步齐放**，而是**颜色沿两核连线方向平滑过渡的相干传播/招募波**——一头先放、另一头后放，扫过整片。高许可度的那个大 bout 是**铺满全场、约 1.4 万细胞、持续约 57ms 的一道有向招募波**（小事件约 4–8 千细胞、局部）。所以"区域抑制油箱"这个慢变量真正做到的是：**把小的局部间期样事件，在高许可度时做成一道铺满全场、有方向的相干招募波**。

**为什么 §6/§6.1 判错了**——我之前用的两个量都测错了东西：
1. **"接触方向可读性 ~0.12"** 被我读成"同步爆发无方向"。实际是 12 个虚拟 SEEG 接触太稀，**参与的常 <7 个（低于 sign 置信门槛），所以读不出方向**；源空间逐细胞读数里这些事件方向很干净（onset 沿轴回归 R² 可达 0.87、梯度方向与轴 align≈1.0）。是仪器太粗，不是没有传播。
2. **"双核碰撞率 0"** 被我读成"没有发作样传播"。实际这些是**单源有向铺开**（从一头扫到另一头），不是"两核各自点火在中间相撞"——碰撞量只认双核相撞，有向单源波本就该=0。所以碰撞=0 不等于不传播。

**直接观测（高置信，源空间 onset 梯度 + 主图 onset map 目视，脚本 `scripts/plot_a2p_synchronous_burst_figure.py`，主图 `figures/a2p_recruitment_wave_main.png`）**：
- 事件是沿两核轴的相干招募波（onset~位置回归 R² 可达 0.87，梯度 align≈1.0，目视为连续梯度非两块离散先后块）；**非同步爆发**。
- 许可度把事件做大：小局部事件（r95≈6、约 4–8 千细胞）↔ 高许可度大招募波（r95≈13、约 1.4 万细胞、铺满全场）；T=20000 时大事件还成主导（呼应 §6.1 源空间 r95_mm 中位 ~12、reach 22.8、质心居中 71%——那批数对的是"大、铺满轴"，只是被我误贴了"同步爆发"标签）。
- 大 bout 是单源有向铺开（碰撞=0、非双核相撞）。

**判读 = gate 重新打开（NOT 翻成 PASS）**：先前 FAIL 建立在两个测错东西的粗读数上；源空间读数显示**事件确实传播、且许可度把它做大成一道相干招募波**——这比 §6/§6.1 的"FAIL/同步爆发"正面/微妙得多。但**不直接翻成"PASS/这就是发作两态"**：是否把"一道有向单源全场招募波"算作发作，需要判断（它非双核相撞；spec 当初把发作部分定义成双核碰撞，这条对本机制的有向波可能本就不合适）；也要分清"高许可度尾巴上的大事件"vs"真有一个分立的双稳发作态"。**正确仪器 = 源空间 onset 梯度（非接触方向可读性 / 非双核碰撞）**，下一步用它在多种子 + 低/高许可度上把"小局部↔大相干招募波"这个转变重测，再决定算不算两态。判读纪律：§6/§6.1 的"同步爆发不传播 / FAIL"作废，以本节为准；本节也不overclaim 成 PASS。
