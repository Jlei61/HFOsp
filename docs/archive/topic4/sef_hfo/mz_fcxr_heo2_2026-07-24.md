# FCXR-HEO2 — 宽带-尖波表型机制诊断 (Broadband-Spiky Phenotype Mechanistic Diagnosis)

**日期**: 2026-07-24 ｜ **分支**: `codex/topic4-mz-fcxr-heo1` (承 HEO1，base `01225ff7` LC1 tip) ｜ **判决**: **bounded-negative**——在最强"持续 16 Hz 同步"锚点上、用**延迟且力配比**的兴奋细胞放电后适应（spike-frequency adaptation, 5–10% 递归驱动、τ 250/750 ms）**没有**把快速窄带高态改造成"慢、尖、宽带、宽覆盖"的真实发作型（0/4 arm 过 transform 门）。适应是**刹车**（降幅 → 爆发 → 熄灭），不是**变频器**。**方向线索**：快 τ / 10% 那一格离真实频谱最近（六频段 L2 距离 45.9 → 21.5），靠的是把快事件裹进慢包络的**间歇爆发**，不是变成 3–8 Hz 尖波。**缺口本质**：模型的"宽覆盖"只活在同步里（16 Hz 全阵列 lock-step），"宽带-尖波形状"只活在**去同步**的稀疏串里；单个逐细胞刹车换不动这两者。→ 下一杠杆 = **空间去同步**（cross-link Z/M Path-B `project_topic4_zm_carrier_gate`）。

> **⚠️ 本判决被 §7 HEO2.1 复核订正（de-conflate 空间指标后）**：大多数状态与保有持续活动的主要臂呈**近全电极招募**（48/48 ≥13/15，38/48 =15/15）——**sensor-level 电极覆盖不是当前瓶颈**（≠ source-space 招募已解决，§7.7-b）；适应**不是纯刹车**而是**部分动态地拓宽（broadband 0→7/15）+ 去同步（coh 0.98→0.54）**、保住招募但只瞬态爆发；缺口是**持住这个瞬态 regime（时间持续）**；下一杠杆 = HEO3 因果 2×2（非"空间去同步已证"）。§3.3/§4/§5 的原表述以 §7 为准。

**预注册层级**: Phase 1 是机制**诊断 screen**（HEO2 plan 锁定），不是 cohort claim。本判决只对**这一个锚点 + 这一个杠杆**成立，不是"模型造不出宽带"的全局结论。

## 摘要（朴素话）

**测了什么** — 我们手上这块四万神经元、按真实病人（Epilepsiae 1146）电极几何搭的仿真发作灶，在它"最持续"的那个工作点上，会进入一种**很快（约 16 次/秒）、整片一起同步的振荡**：十五个虚拟电极几乎同时一起响、95% 的时间都在活动。可真实的 E1146 发作长得正相反——**慢（约 3 次/秒）、一阵一阵、又尖又宽带**（能量在 1–80 Hz 一整片都抬起来，不是集中在一个频段）。我们把现有 48 个工作点全量重新量了一遍，发现一个尴尬的分裂：**要么**像真实发作那样"又尖又宽带"（最接近的一格是 3.5 Hz，但只有 3/15 个电极参与、只有 28% 的时间在放），**要么**十五个电极都参与、覆盖很广（但那只有在离真实很远的 16 Hz 同步态里）。**没有任何一格同时兼得"宽带-尖波形状"和"宽覆盖"**。于是我们问：如果先让 16 Hz 态立起来，再打开"放电后自我疲劳"（每放一次电就积累一点让自己更难再放的慢钾电流），这个疲劳能不能把整片的快速同步敲碎成一个**又慢又尖、还保持宽覆盖**的宽带节律？

**怎么测的** — 我们把疲劳的**峰值刹车强度**定死成网络自身递归兴奋的一个固定比例（5% 或 10%，直接从这个 16 Hz 态里自洽量出来），这样"刹得多狠"就跟"恢复多快"（250 ms 快 / 750 ms 慢）分开了，不会混在一起。疲劳在 16 Hz 态已经立起来 1 秒**之后**才打开（延迟），然后拿每一格结果去跟真实发作的"六频段能量指纹"比对。对照组是一个把钾电流按疲劳**峰值**冻死、没有动态的恒定负荷。开门前先过一道底线闸：这个疲劳强度在病人平时的间期背景（D=0）上会不会把正常间期尖波也抹掉——四格全过，说明这强度没破坏基线。

**揭示了什么** — 疲劳是刹车，不是变频器。弱疲劳（5%）几乎没动 16 Hz，只是幅度略降、频率照旧。强疲劳（10%）要么把 16 Hz 敲成一阵一阵、放一会儿灭掉又重新点起来的**间歇爆发**（快恢复那档），要么让 16 Hz 跑约 1.5 秒后**整个熄灭**、在这段窗口里不再恢复（慢恢复那档）。唯一一格朝真实频谱靠近的（快 / 10%），靠的是给快速的约 15 Hz 事件套上一个很慢（约 1 Hz）的爆发包络——**不是**把它们重新调成 3–8 Hz 的尖-波节律，而且**没有拿到宽带的多电极覆盖**。所以：延迟、力配比的放电后适应**合并不了这两族**——它造不出"慢-尖-宽带 + 宽覆盖"的形状，只会从那个快同步态里做减法（幅度↓ → 爆发 → 熄灭）。峰值恒定钾对照把整片网络直接压死（0 Hz），说明动态各档的效果确实来自疲劳的**时间过程**、不只是它的平均量级——但因为这个对照配的是**峰值**（不是均值），它多按了钾，所以只能弱证明"动态 vs 均值负荷"这件事，不是干净的均值对照。

## §1 背景与承接（不重开）

HEO2 承接 HEO1 的两条已订正结论（见 `mz_fcxr_heo1_2026-07-24.md` §3.4 / §4）：

1. **HEO1 严格门 mis-specified**：真实 E1146 发作是 ~3 Hz 尖波宽带、间歇（fails Gate A 无持续高原），过不了"持续 30–150 Hz 平台"门；模型的 ~16 Hz 窄带态也过不了。二者都非 HEO1 平台型。真正 target 是 **empirical 宽带-尖波（~3–8 Hz）表型**。
2. **模型已有两族**：稀疏 ~3.5 Hz 尖波宽带串（离真实近、但覆盖低）+ 持续 16 Hz 窄带高态（覆盖高、但离真实远）。HEO2 的真问题不是"16 Hz → 3 Hz"，而是**"合并两族"**——同时要宽带尖波形状 + 持续 + 宽覆盖。

## §3 Phase 1 — 延迟力配比适应楔形（在 16 Hz 锚点上）

### §3.1 设计（力配比 + 延迟 + 底线闸 + 静态对照）

**问题**：让 16 Hz 态先立 1 秒，再打开适应，能否把它敲成 3–8 Hz 宽带尖波并**保持覆盖**（而不只是压回稀疏/静息）？

**力配比**（避免"时标 × 强度"混淆）：从锚点自身 m-off 高态自洽量出 `I_EE_scale = mean(gErec)·(E_E−v_match) = 309.19`（mean gErec ≈ 7.73，约 36% of g_sat=21.6 → 确认锚点无 kick 自点火到高态）。每个 τ 的 `peak_m = p90(replay_adaptation_peak)` = 87.4 (τ250) / 220.6 (τ750)。`eta_m_from_frac(frac, I_EE, peak_m)` 使**峰值适应电流 = frac·I_EE**，与 τ 无关：

| (τ, frac) | eta_m | 峰值适应电流 = frac·I_EE |
|---|---|---|
| 250 / 5% | 0.177 | 15.5 |
| 250 / 10% | 0.354 | 30.9 |
| 750 / 5% | 0.070 | 15.5 |
| 750 / 10% | 0.140 | 30.9 |

**底线闸（D=0 workpoint gate）**：适应从 t=0 在基线上跑，不得抹掉间期 IED。**4/4 全过**（P0"全 arm 失败"未触发）。

**6 arm**：`m_off`（无适应参考）+ 4 个存活 (τ,frac) 延迟适应（m_enable_ms=1000）+ `static_K`（m 冻结在 peak_m[750]=220.6 的峰值恒定钾对照）。

### §3.3 机制读出

> **⚠️ 本节被 §7 订正**：下面"缺口=覆盖绑同步 vs 宽带绑去同步稀疏串"是 de-conflate 空间指标前的错误表述。de-conflation 后所有 family recruit 15/15（覆盖非缺口），且适应部分动态地拓宽+去同步（非纯刹车）。以 §7 为准。

疲劳（放电后适应）在这个态上只做三件事之一，**都不是变频**：

1. **降幅**（弱 / 5%）：16 Hz lock-step 幅度降，频率不变。
2. **间歇爆发**（快 τ / 10%）：整片同步一阵一阵地灭掉又重新点起 → 慢（~1 Hz）包络套快（~15 Hz）事件。离真实频谱最近（dist 21.5），因为低频带被抬正；但**不是** 3–8 Hz 尖波，也**没拿到覆盖**。
3. **熄灭**（慢 τ / 10%）：跑约 1.5 s 后整片熄灭，不恢复。

**缺口本质**：模型的"宽覆盖"绑在**同步**上（16 Hz = 全电极一起 → 单一主频、窄带），"宽带-尖波形状"绑在**去同步的稀疏串**上（事件在电极间错开 → 低主频、宽带）。一个逐细胞的均匀刹车（适应）只能整体压低那个同步态，换不出"多电极活跃但彼此不同步"的宽带宽覆盖态。

## §4 诚实边界（不得越界声称）

1. **静态对照是峰值配比、非均值配比**：`static_K` 冻结在 peak_m（峰值），过量按钾 → 直接压死。它只弱证明"动态各档的效果来自疲劳时间过程、不只均值量级"；干净的"动态 vs 均值负荷"对照需要**均值配比**的 static_K（下一轮补）。
2. **dom=1.0 Hz 在 2 s-Welch 地板**（lo=1.0 → 第一 bin）：反映真实的 <2 Hz 爆发包络，但精确值受地板限制；有意义的快节律是 event-IPI 14.5 Hz。
3. **单锚点 + 单杠杆**：只测了最强 tonic 锚点（gq0.999_A8_D0.15）+ 一个杠杆（E 细胞放电后适应）。bounded-negative 只对**这个点 / 这个杠杆**成立。
4. **预注册层级 = 机制诊断 screen**（HEO2 plan 锁）：允许"per-arm 描述 + 方向线索"，**不允许** cohort claim / "证明/否证发作"。

## §5 下一杠杆（供用户定向，未自主启动）

> **⚠️ 本节"空间去同步"表述被 §7.6 订正**：均匀适应本身已经去同步（τ750/5% coh→0.31），所以缺口非"缺空间去同步"而是"**持不住**瞬态的拓宽+去同步"；HEO3 因果 2×2 测的是空间异质能否**持住**它，非"空间去同步已证"。以 §7.6 为准。

诊断把缺口定位到 **同步 vs 去同步**：要"宽带 + 宽覆盖"，需要许多电极**都活跃但彼此不同步**（事件在空间上错开 → 拉宽频段、降低主频），而适应这种逐细胞均匀刹车做不到。自然的下一杠杆是**给适应配上空间去同步**：

- **异质/斑块化的慢变量或抑制**（空间上不均匀的 K 或抑制补丁），把全阵列 lock-step 打散成局部错相的持续群体载体。
- **Cross-link**：Z/M carrier-gate 线的 **Path-B "cheap K-patch 局部去同步 → 持续群体载体 4/4"**（`project_topic4_zm_carrier_gate`）已经在一个平行线程里独立命中了"局部去同步产生持续群体载体"——那正是 HEO2 缺的方向。HEO3 = 把空间去同步（Path-B 类）与力配比适应合起来，测能否同时拿到宽带尖波形状 + 宽覆盖 + 持续。

**同时记下的旁支观察**（对其它 Topic 4 线程有用，但非 HEO2 主问题）：快 τ/10% = 间歇爆发（灭-重点起）、慢 τ/10% = 自终止（跑 1.5 s 熄灭）——这两个是 **termination / bursting** 行为，直接关联 LC1 终止线（`project_topic4_fcxr_lc1`）和 Z/M carrier 线。

## §7 HEO2.1 收口（review P1-a/b/c 修正）—— de-conflate 空间指标后结论订正

### §7.1 三个拆开的空间指标（P1-a，compute-free；per-contact lfp field 已存 (T,15)）

| transitional (7) | 15 (15–15) | 4 (3–15) | 0.91 (0.83–0.97) | 0.84 (0.47–0.90) |
| tonic_16Hz_cycle (15) | 15 (15–15) | **0 (0–12)** | 0.98 (0.95–1.00) | 高 0.96 (0.76–0.96) |

→ **模型已经在造"宽招募 + 宽带"的尖波事件**（sparse family 中位 recruit 15 + broadband 15），只是**时间上稀疏**（duty 中位 **0.17**、率 ~23 Hz）；唯一**持续**的高态是 tonic 16 Hz（窄带 broadband 中位 0 + 高同步 coh 0.98）。**§3.3 说的"宽覆盖只活在同步里 / 宽带只活在去同步稀疏串"是 de-conflation 前的错误表述。**

⚠️ **不可写成"所有 family/arm 都 15/15"**：sparse 族 recruit 低至 13；失去持续活动的臂本就低（慢τ/10% 5s 窗 3/15、peak static-K 0/15、延长臂静默段 ~0）。duty 0.28 是**最接近真实的那一代表格**（`gq0.999_A8_D0.13_nokick`），非整族（族中位 0.17）。

### §7.3 订正结论②：适应不是纯刹车，是**部分动态地拓宽 + 去同步**（Phase 1 + mean-matched 对照）

| arm | recruit | broadband | coherence | seg-label |
|---|---|---|---|---|
| ref (m_off) | 15 | 0 | 0.98 | sustained |
| τ250/5% | 15 | 4 | 1.00 | sustained |
| **τ250/10%** | 15 | **7** | **0.54** | intermittent_bursting |
| τ750/5% | 15 | 0 | 0.31 | sustained |
| τ750/10% | 3 | 2 | 0.34 | terminated(5s) |
| static-K (peak) | 0 | 0 | 0.15 | silent |
| **static-K (mean, matched)** | 15 | **1** | **1.00** | sustained |
| τ750/10% ext 9s | 0(median) | 0 | 0.33 | 稀疏再点火 |

- **τ250/10%（快 τ/10%）**：recruit 15 不变、broadband 0→**7**、coherence 0.98→**0.54**——**三个轴都朝目标走**（宽带↑ + 去同步↑ + 招募不掉），只是**间歇爆发**、没到 15/15。适应**不是纯刹车**。
- **mean-matched static-K（P1-c 干净对照）**：用**同样的平均钾负荷**（= τ250/10% post-enable 平均 m = 12.1，恒定注入）→ **持续、完全同步（coh 1.0）、窄带（broadband 1）**，同 ref。→ **τ250/10% 的拓宽 + 去同步来自适应的时间过程（动态），非平均负荷**。（旧 peak-matched 配峰值 220.6 把网络压死；mean-matched 配 12.1 不压死、持续 → 干净隔离动态 vs 均值负荷。）
- **去同步 ≠ 拓宽（部分可分）**：τ750/5% 去同步（coh 0.31）但没拓宽（broadband 0）；τ250/10% 两者都做。

### §7.4 订正结论③：强慢适应是**长周期间歇**，非永久终止（P1-c 延长 9s）
τ750/10% 在 5s 窗看像"终止"（3–5s 静默），延到 9s：高态 ~2.5s → 静默 ~3s → **6–7s、8–9s 稀疏微弱再点火（~19 Hz）**。→ **非永久终止**，是长周期间歇；5s 的 `terminated` 只对 5s 窗成立（review 要求延长正确）。

### §7.5 订正后的安全声称分层（P1-b）
**可接受**：① FCXR 造出有界、持续、**近全电极招募**（中位 15/15）但过快 + 过同步 + 窄带高态；② 模型也造近全电极招募的宽带尖波事件，但 duty 低（中位 0.17）；③ 均匀快 τ/10% 适应**部分地、动态地**拓宽 + 去同步、保住招募，但只是**瞬态爆发**没持住；④ 强慢适应给长周期间歇（高态—静默—再点火）。
**不可声称**：发作一致态；宽带**必须**来自空间去同步（均匀适应本身已经去同步——空间异质是**一个假说**非已证）；**source-space 空间招募已解决**（见 §7.7-b）；间期↔发作闭环；FCXR 架构被否证。
**缺口重定位**：不是"造宽带"（已有）也不是"sensor-level 电极覆盖"（已近全），而是**持住** τ250/10% 那种瞬态的"拓宽 + 去同步"regime（它爆发不持续）——一个**招募 + 相位 + duty 的联合持续**问题。

### §7.7 三处收紧（review 要求，写入合同）
**(a) 措辞**：禁"所有 family/arm 都 15/15"；正确写法 = "大多数 Phase-0 状态与保有持续活动的主要臂呈近全电极招募（48/48 ≥13，38/48 =15）；招募不是区分两族的主要轴"。duty 0.17 是族中位，0.28 是代表格。
**(b) sensor-space ≠ source-space**：`active_recruitment` 判的是**虚拟电极读出**（任一 1–80 Hz 频段 ≥3 dB），可能包含场传播 / 共同源投影——15/15 只证明 **sensor-level 电极覆盖不是当前瓶颈**，**不能**升级为"组织空间（source-space）招募已解决"（可能只是同一核心源被 15 个电极同时看到）。HEO3 必须同时存并检查：core / axis / off-axis 细胞活动、分区活动占空比、source-space participation ratio、活动质心与空间传播次序、虚拟电极场。
**(c) 联合窗 ≠ 分别全局平均**：现有 broadband / coherence / duty 都是**整个 post-enable 窗**分别汇总，快 τ/10% 的 "broadband 7/15" 与 "coh 0.54" **未必发生在同一 burst 时段**；且间歇信号的 whole-window coherence 下降**可能部分来自开—关切换**而非 burst 内真正的空间错相。HEO3 须用同一套 200–300 ms 滑窗**逐窗联合判定** `recruited ∧ broadband ∧ phase-dispersed ∧ high-energy`，并统计该联合目标窗能否**连续维持**；coherence 另加 **active-window / event-conditioned pairwise** 版本，避免静默期稀释同步度。

### §7.6 下一步 HEO3（review 锁定的因果 2×2 + 分阶段；conditional GO）
**问题的准确提法**（review 改写，取代早稿"空间去同步能不能产生宽带"——均匀动态适应已部分做到）：

> **空间组织化的恢复时间差，能否让不同区域交替承载活动，从而在 source-space 持续招募的同时，稳定维持低频、宽带、非完全同步的高能量平台？**

**2×2（交互项才是被测量）**：

|---|---|---|
| 空间均匀参数 | uniform-static | uniform-dynamic |
| 斑块参数场 | patch-static | patch-dynamic |
