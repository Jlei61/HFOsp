## 摘要（朴素话）

**测了什么** — 我们在一块用真实病人（Epilepsiae 1146）电极几何搭起来的、四万个神经元的仿真发作灶上，问一个很具体的问题：这块组织能不能进入一种“持续的、高频且各频段都抬起来（宽带）的、十五个虚拟电极大部分都参与的、而且自己在一个共同频率上振荡的”高能量放电状态，同时数值上还是有边界的（不会冲到放电频率的物理天花板炸掉）。这正是真实癫痫发作在颅内电极上的样子——不是零星的尖波，也不是单个点狂放，而是一整片组织一起进入一个持续的振荡高能带。

**怎么测的** — 我们给“兴奋性神经元互相激励”这条回路加了一个“合作放大”开关：活动很低时它完全关着（所以病人平时的间期背景一点没变，逐位一致），活动到中等时它给一个超线性的额外增益，活动很高时原有的“平滑封顶”还在把它按住不让炸。然后我们扫这个开关的两个旋钮（活动到多高才开、开多大），配上组织不同的“磨损程度”和不同的初始踢一脚，每一格跑四秒仿真，用一把**提前定死的尺子**去量：这段放电是不是真持续了一秒以上、是不是六个频段里五个都抬起来、是不是十五个电极里十一个以上都亮、是不是真在一个共同频率上振荡、数值上干不干净。这把尺子先用七种“假货”信号校准过（孤立尖波、密集事件串、贴天花板的死放电、窄带、宽带噪声……全都必须被拒绝），只有真的“振荡+宽带+全片高原”才放行。

**揭示了什么** — 我们把这个合作放大开关的所有档位都扫了一遍（两个开门阈值 × 四个放大幅度 × 两个磨损程度 × 三种初始踢一脚，共 48 格），**没有一格造出目标里的那种发作态高能带**（0/48 过关）。开关确实能把失效核区催得很猛——最强档下核区自己放到每秒约 330 次、周边约 125 次，而且全程有界、数值干净（不失控、不撞放电天花板）。但这股快频段（30–150 Hz）的宽带能量被死死圈在物理上最靠近核区的那三个虚拟电极上：其余十二个电极只看到低频（1–8 Hz）的抬升，看不到快频段的宽带能量。所以快能量始终没有铺开成一整片（十五个电极里过十一个）的宽带平台，没有形成持续一秒以上的高原，也没有共同频率的振荡（整片最多只点亮 7/15 个电极）。它是一个"集中在核区的高频源"，不是"一整片组织的发作平台"。**瓶颈不在"能不能把核区点起来"（能，而且很猛），而在"快能量能不能向外铺开"（不能）**。这跟之前 Stage D / LC1 看到的图景一致（核区加密加速，但不招募成平台）。

## §1 背景与承接的结论（不重新争论）

本 sprint 接手 LC1 的四条已验收结论，不重开：

1. RC1 慢-关（slow-off）间期工作点已验收（真实病人几何、外部前馈电流叠加 + 递归兴奋走电导 + 只对递归做平滑饱和 `g_sat=21.6`、`dt=0.05`、四万神经元）。
2. Stage D 沿冻结磨损轴只有**同一族核区放电随磨损连续加密**，没有稳健、独立、可重复进入的“有限高台阶”分支。
3. 动态 Z（q75）给出的是**有界密集事件串**，不是发作态。
4. q50+X 表明“持续度门控的 X”有终止权，但没有完整的发作前/发作中/发作后统计恢复。

**因此本轮的唯一新科学问题**不是“事件更密/间隔更短”（那些不算成功），而是：一个“低活动全关、中活动超线性、高活动被电导饱和限幅”的机制，能否造出一个可重复、持续、振荡、高频宽带、全虚拟电极参与、数值有界的高能量分支。

## §2 新机制与判据（方法）

### 2.1 合作放大门（cooperative recurrent conductance）

在递归兴奋电导进入“平滑封顶”之前，对它的**原始值**（`gErec_raw`，保持原样供审计/直方图读取）加一个 Hill 型合作增益，再进原有的 `g_sat·tanh(·/g_sat)`：

```
H       = relu(u−u_c)^n / (K_c^n + relu(u−u_c)^n)   （n=4）
u_tilde = u · (1 + A_c·H)
gErec   = g_sat · tanh(u_tilde / g_sat)              （g_sat = 21.6，保留主锚）
```

- `A_c=0`（默认）→ `u_tilde` 就是原始值 → 与 RC1 逐位一致（byte parity）。
- `u ≤ u_c` 的细胞 → `H=0` → 精确等于 RC1（不动间期工作点）。
- 大输入 → `tanh` 仍把 `gErec` 压到 `g_sat`（有界）。
- 只作用于**递归 E→E** 电导，不碰前馈、抑制、I 细胞、也不改原始审计值。
- 六个 blessed 引擎文件一字未动；机制全部落在非 blessed 的 `mz_slow_vars.py` 插件里。

**门槛标定（u_c）**：`u_c` 取间期慢-关基线里 `gErec_raw` 的极端分位数——`gate_quantile=0.999`（Q99.9）或 `0.9999`（Q99.99），`K_c=0.25·u_c`。标定只读 A_c=0 的基线（不读任何合作运行的结果），靠一条流式定边直方图（overall/core/surround 三组）在 F0 里累计得到。

### 2.2 “成功”尺子（HEO 判据，运行前锁定）

虚拟电极读出用真实 E1146 registered montage（15 触点，4 SCL + 11 ICL），经 `LFPRecorder` 记录。降采样到 1 kHz，1 秒窗、100 ms 跳，六频段（1–4/4–8/8–13/13–30/30–80/80–150 Hz）对同种子慢-关基线做 log-power 稳健-z + q99 双门。判据全部**提前锁定**：

| 门 | 锁定标准（朴素含义） |
|---|---|
| **B 宽带**（每触点每窗） | 六频段里 ≥5 个抬起来，且 30–80 与 80–150 两快带都过，且六带中位增益 ≥6 dB |
| **C 全片**（每窗） | 15 触点里 ≥11 个宽带高，且 4 个 SCL 里 ≥3 个宽带高 |
| **A 高原** | 全片高连续 ≥1000 ms、占空比 ≥80%、无 ≥100 ms 的“回到基线”缺口（不能是离散事件串） |
| **D 振荡** | 高原窗里群体率谱 + ≥半数触点谱都有 30–150 Hz 非直流峰、峰高 ≥6 dB、≥半数共享 ±15 Hz 中心频率 |
| **E 数值** | 有限、不 clip、tau_eff≥2dt、不 runaway、高原平均率 <400 Hz（不贴 500 Hz 不应期天花板） |
| **F 工作点**（臂级，D=0/no-kick） | 仍是间期工作点 + 有零星回返事件 + 数值安全 |

`HEO_BRANCH = A ∧ B ∧ C ∧ D ∧ E`；F 是筛选前置。单种子/单初始条件只出现 → 记 provisional。只在虚拟电极过、SCL 邻域组织招募未过 → 只写“platform readout”，不写“全组织招募”。运行时 >250 Hz 持续 100 ms → 判 OPERATIONAL_RUNAWAY（不算 HEO）。

**这把尺子经 7 个合成用例校准**：振荡宽带全片高原（应过）；孤立尖波 / 密集事件串 / 贴天花板死放电 / 窄带局部 / 宽带无振荡 / runaway / 数值不安全（全应拒）。

**clean NO-GO。** 合作型递归电导门在锁定的 E1146/RC1 底座上、在整个预注册参数盒里，都没能造出可重复、持续、振荡、高频宽带、全平台参与的有界高能量分支（0/48）。命中停机规则 §6-#5（"只有核区触点增强，没有平台覆盖"）。这是合格的负结果——不为凑正结果扩大参数盒（不加 g_sat 敏感性：该敏感性只在"所有 A_c 到 8 都已大范围进入饱和但接近成功"时触发，而这里离"平台"差得远——最多 7/15，非饱和边缘问题，故不触发）。

## §5 机制解读

- RC1 的 `tanh` 对 `gErec_raw` 斜率单调下降（≤1），沿磨损轴只能"连续加密"无再生高台阶（Stage D 结论）。
- 合作门确实在中活动区把有效斜率 `d(u_tilde)/du` 顶到 >1（超线性凸起），也确实点燃了更猛的核区（最强档 core 330 Hz）——所以"点火"这一环成立。
- 但高活动处 `tanh(u_tilde/g_sat)` 仍把 `gErec` 压回 `g_sat`，配合共享抑制/衬底几何，把整个高态**空间上锁死在核旁 ~3 个触点**：快频段（30–150 Hz）能量不向外铺开，远端触点只收到低频体积传导抬升。
- 因此瓶颈是**快能量的空间传播（招募）**，不是核区点火，也不是数值稳定性（全程有界干净）。主导的是被放大的**核区局部模式**，没有观察到全场宽带铺开或共同频率的振荡读出。这与"均质 L=20 衬底自发只出同步/单源相干招募波"的既有教训一致——传播/招募才是杠杆。
