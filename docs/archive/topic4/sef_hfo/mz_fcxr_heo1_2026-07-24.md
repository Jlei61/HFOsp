## 摘要（朴素话）

**测了什么** — 我们在一块用真实病人（Epilepsiae 1146）电极几何搭起来的、四万个神经元的仿真发作灶上，问一个很具体的问题：这块组织能不能进入一种“持续的、高频且各频段都抬起来（宽带）的、十五个虚拟电极大部分都参与的、而且自己在一个共同频率上振荡的”高能量放电状态，同时数值上还是有边界的（不会冲到放电频率的物理天花板炸掉）。这正是真实癫痫发作在颅内电极上的样子——不是零星的尖波，也不是单个点狂放，而是一整片组织一起进入一个持续的振荡高能带。

**怎么测的** — 我们给“兴奋性神经元互相激励”这条回路加了一个“合作放大”开关：活动很低时它完全关着（所以病人平时的间期背景一点没变，逐位一致），活动到中等时它给一个超线性的额外增益，活动很高时原有的“平滑封顶”还在把它按住不让炸。然后我们扫这个开关的两个旋钮（活动到多高才开、开多大），配上组织不同的“磨损程度”和不同的初始踢一脚，每一格跑四秒仿真，用一把**提前定死的尺子**去量：这段放电是不是真持续了一秒以上、是不是六个频段里五个都抬起来、是不是十五个电极里十一个以上都亮、是不是真在一个共同频率上振荡、数值上干不干净。这把尺子先用七种“假货”信号校准过（孤立尖波、密集事件串、贴天花板的死放电、窄带、宽带噪声……全都必须被拒绝），只有真的“振荡+宽带+全片高原”才放行。

**揭示了什么** — 我们把合作放大开关的所有档位扫了一遍（48 格）。**按预注册的严格标准——"必须是 30–150 Hz 宽带、六个频段里五个都抬起来、十五个电极里十一个以上同时达标"——一格都没过（0/48）**，所以严格意义上这一版没造出发作态高能平台。

但这个模型确实产生了一个**以前没有过、值得留着的新中间态**：在磨损较重（D=0.15）+ 大放大幅度的格子里，网络稳定进入一个**有界、持续、十五个电极共同以约 16 Hz 一起振荡的高发放态**——各电极主频完全一致（15.6 Hz）、互相关相干性约 0.97–0.98、相位沿电极一路错开约 170°（像一列在电极阵上行进的行波），底下群体放电率稳在每秒约 90–140 次。48 格里约 20 格进入这种相干振荡态。这**不是**之前 Stage D 那种打一下自己就灭的稀疏事件串，而是一个真正持续的振荡分支。

它为什么没过严格门：能量主要压在 13–30 Hz（比基线高约 16 dB，全电极都有），快频段 30–80 Hz 也抬到大部分电极（有格子十五个全部超 6 dB），但 80–150 Hz 基本贴基线，而且低频 1–8 Hz 反被这个振荡压下去了。所以它是一个**偏窄带（beta + 谐波）的相干振荡**，不是严格门要求的"所有频段一起抬起来的宽带招募平台"（真实发作的样子）；分频段看，快频段单独其实在 11/15 电极上过了门，是"五个频段同时达标"这一条被低频压制卡住。**失败的是"频谱形状对不上宽带发作型"，不是"没有共同振荡"，也不是"能量传不出核区"——能量确实以约 16 Hz 的相干波铺满了整个电极阵**。

**复核还用真实 E1146 发作过同一把尺子（二次订正）**：真实发作是 ~3Hz 尖波宽带（六频段全抬、低频最强、间歇），它过 Gate B/C（部分窗 12–14/15 触点）但**过不了完整 HEO1 门**（无持续高原 Gate A、~3Hz 非 30-150Hz）；模型 ~16Hz 窄带态也过不了。→ **HEO1 门（持续 30-150Hz 平台）对这个被试的真实发作型 mis-specified**，严格 0/48 只能说"没造出持续 30-150Hz 平台"、不能说"没造出发作"；真正 target 是 empirical 宽带-尖波（~3-8Hz）表型（§3.4，图 `real_vs_model_band_dB.png`）。

## §1 背景与承接的结论（不重新争论）

本 sprint 接手 LC1 的四条已验收结论，不重开：

1. RC1 慢-关（slow-off）间期工作点已验收（真实病人几何、外部前馈电流叠加 + 递归兴奋走电导 + 只对递归做平滑饱和 `g_sat=21.6`、`dt=0.05`、四万神经元）。
2. Stage D 沿冻结磨损轴只有**同一族核区放电随磨损连续加密**，没有稳健、独立、可重复进入的“有限高台阶”分支。
3. 动态 Z（q75）给出的是**有界密集事件串**，不是发作态。
4. q50+X 表明“持续度门控的 X”有终止权，但没有完整的发作前/发作中/发作后统计恢复。

**因此本轮的唯一新科学问题**不是“事件更密/间隔更短”（那些不算成功），而是：一个“低活动全关、中活动超线性、高活动被电导饱和限幅”的机制，能否造出一个可重复、持续、振荡、高频宽带、全虚拟电极参与、数值有界的高能量分支。

## §2 新机制与判据（方法）

### 2.1 合作放大门（cooperative recurrent conductance）

在递归兴奋电导进入“平滑封顶”之前，对它的**原始值**（`gErec_raw`，保持原样供审计/直方图读取）加一个 Hill 型合作增益，再进原有的 `g_sat·tanh(·/g_sat)`：

```
H       = relu(u−u_c)^n / (K_c^n + relu(u−u_c)^n)   （n=4）
u_tilde = u · (1 + A_c·H)
gErec   = g_sat · tanh(u_tilde / g_sat)              （g_sat = 21.6，保留主锚）
```

- `A_c=0`（默认）→ `u_tilde` 就是原始值 → 与 RC1 逐位一致（byte parity）。
- `u ≤ u_c` 的细胞 → `H=0` → 精确等于 RC1（不动间期工作点）。
- 大输入 → `tanh` 仍把 `gErec` 压到 `g_sat`（有界）。
- 只作用于**递归 E→E** 电导，不碰前馈、抑制、I 细胞、也不改原始审计值。
- 六个 blessed 引擎文件一字未动；机制全部落在非 blessed 的 `mz_slow_vars.py` 插件里。

**门槛标定（u_c）**：`u_c` 取间期慢-关基线里 `gErec_raw` 的极端分位数——`gate_quantile=0.999`（Q99.9）或 `0.9999`（Q99.99），`K_c=0.25·u_c`。标定只读 A_c=0 的基线（不读任何合作运行的结果），靠一条流式定边直方图（overall/core/surround 三组）在 F0 里累计得到。

### 2.2 “成功”尺子（HEO 判据，运行前锁定）

虚拟电极读出用真实 E1146 registered montage（15 触点，4 SCL + 11 ICL），经 `LFPRecorder` 记录。降采样到 1 kHz，1 秒窗、100 ms 跳，六频段（1–4/4–8/8–13/13–30/30–80/80–150 Hz）对同种子慢-关基线做 log-power 稳健-z + q99 双门。判据全部**提前锁定**：

| 门 | 锁定标准（朴素含义） |
|---|---|
| **B 宽带**（每触点每窗） | 六频段里 ≥5 个抬起来，且 30–80 与 80–150 两快带都过，且六带中位增益 ≥6 dB |
| **C 全片**（每窗） | 15 触点里 ≥11 个宽带高，且 4 个 SCL 里 ≥3 个宽带高 |
| **A 高原** | 全片高连续 ≥1000 ms、占空比 ≥80%、无 ≥100 ms 的“回到基线”缺口（不能是离散事件串） |
| **D 振荡** | 高原窗里群体率谱 + ≥半数触点谱都有 30–150 Hz 非直流峰、峰高 ≥6 dB、≥半数共享 ±15 Hz 中心频率 |
| **E 数值** | 有限、不 clip、tau_eff≥2dt、不 runaway、高原平均率 <400 Hz（不贴 500 Hz 不应期天花板） |
| **F 工作点**（臂级，D=0/no-kick） | 仍是间期工作点 + 有零星回返事件 + 数值安全 |

`HEO_BRANCH = A ∧ B ∧ C ∧ D ∧ E`；F 是筛选前置。单种子/单初始条件只出现 → 记 provisional。只在虚拟电极过、SCL 邻域组织招募未过 → 只写“platform readout”，不写“全组织招募”。运行时 >250 Hz 持续 100 ms → 判 OPERATIONAL_RUNAWAY（不算 HEO）。

**这把尺子经 7 个合成用例校准**：振荡宽带全片高原（应过）；孤立尖波 / 密集事件串 / 贴天花板死放电 / 窄带局部 / 宽带无振荡 / runaway / 数值不安全（全应拒）。

## §3 结果

### 3.1 F0 基线（已完成，seed1，wall 12.8 min）— **PASS**

- 工作点标签 `INTERICTAL_WORKPOINT`，数值安全，`baseline_preserved=true`。基线滚动率上沿 `rate_roll_hi≈9.40 Hz`。
- 合作门槛标定在范围内：`u_c[Q99.9]=19.94`、`u_c[Q99.99]=23.17`（均 <直方图上界 40，非 overflow）。注意二者都贴近/略超 `g_sat=21.6`——即合作门只在“递归电导已接近/超过饱和尺度”的极端尾部触发。
- 谱基线参考：15 触点 × 6 频段，每格 MAD>0（无 fail-closed），71 个窗。
- 关键早期发现（F1 smoke）：慢-关基线 `gErec_raw` 尾部会超过 `g_sat`（max≈25），故直方图上界从 21.6 加宽到 40 后重算，Q99.99 才落在范围内。

### 3.2 F2 screen — 已完成（seed1，48 格，2 workers，setsid nohup 跑通并跨越一次网络中断）

- **workpoint 门**：8/8 臂在 D=0/no-kick 下全部保持 `INTERICTAL_WORKPOINT`（合作门在基线只被极端尾部触碰，参与度 Q99.9≈0.001 / Q99.99≈0.0001）。全部进入 phase-2。
- **48 格全部 `subthreshold`，n_HEO = 0/48**（严格 HEO 复合门）。逐门通过数：`gate_A_plateau 0/48`、`gate_C_platform 0/48`、`gate_E_numerical 48/48`、`gate_B_broadband 32/48`。**`gate_D_oscillation` 应记为"未评估"而非"0/48"**：Gate D（30–150 Hz 高原上的振荡）按设计只在检出高原后才算，48 格无高原→Gate D 从未被评估（`gate_D_status=not_evaluated_no_plateau`）。所以"0/48"绝不能读作"没有振荡"。
- **数值全程干净**：0 runaway、0 clip、0 unsafe（`gate_E` 48/48）。合作门 + tanh 饱和把所有格点限在有界态。
- **活动量与参数依赖**（mean rate）：D=0.13 各格 8–87 Hz；D=0.15 各格 99–133 Hz；`A_c` 越大、`gate_quantile=0.999`（低阈值、更多触发）越把率推高。最强格 `A_c=8 / D=0.15` 达 mean 99–133 Hz、core 248–334 Hz、engaged_frac 0.08–0.21。复合平台覆盖上限：整个 48 格里任一格最多 **7/15** 触点在某窗复合宽带高（需 ≥11）。
- **【复核订正 1】新出现的相干振荡态**（plateau-独立探针 `oscillation_probe`，48 格全测）：约 **20/48 格**进入相干共同振荡（各触点主频一致 + 相干 ≥0.9），其中 **18 格主频 ≈ 16 Hz**。代表格 `gq0.9999_A4_D0.15_kick12`（生产脚本按最大覆盖挑）：15/15 触点主频 15.6 Hz、互相关相干 0.975、相位跨阵列 168°、mean 91 Hz；最强活动格 `gq0.999_A8_D0.15_nokick`：15.6 Hz、相干 0.98、相位 184°、mean 138 Hz。像一列在电极阵上行进的行波，是持续振荡分支（非 Stage D 自终止事件串）。
- **【复核订正 2】分频段 baseline-归一化 ΔdB**（territory 中位）：`13–30 +15.8`、`30–80 +3.1`、`80–150 +0.5 dB`；低频被压制 `1–4 −21.9 / 4–8 −14.1 / 8–13 −8.6 dB`。30–80 Hz 在某格覆盖全部 15 触点 >6 dB；分频段单独看，快频两带在 **11/15** 触点上过了严格 per-band 门（robust-z + q99）。**卡住严格复合门的是"5/6 频段同时达标"被低频压制这一条，不是快频能量传不出去**。早稿"能量仅在 ~3 核旁触点、其余只 1–8 Hz"不成立，已订正（依据 `oscillation_summary.json` + `candidate_spatial_modes.png` ΔdB 场）。

### 3.3 F3 confirm — 不执行

无 candidate（0/48）→ 按设计不做 confirm；seed3 基线也不补（仅在有候选时补）。

### 3.4 【复核 §6.3】真实 E1146 发作过同一把尺子——尺子有效（无新仿真）

把同一把 HEO 尺子（同六频段 + robust-z + q99 + 5/6频段 + 11/15平台，基于同一被试间期窗归一化）应用到**真实 E1146 发作**（`pat_114602` block 0018、1024Hz、SCL6-9+ICL1-11 十五触点、local-CAR；间期基线=发作前 ~37 min 的 120s、发作窗=onset+0/+3/+20s 三段各 15s；脚本 `scripts/run_heo_gate_on_real_seizure.py`、结果 `real_e1146_seizure_gate.json`）：

- **【二次订正】真实发作过完整 HEO1 门 = 未过**：真实发作过 Gate B/C（宽带 + ≥11/15 触点在**部分窗**平台高，12–14/15 跨三窗；7/141 窗有平台），但**过不了 Gate A**——无持续 ≥1s 高原（这是 ~3Hz 尖波、每 ~300ms 回一次基线，平台窗不连续），且主频 ~3Hz 非 30–150Hz。实测 `passes_full_HEO1_gate=False, gate_A_plateau=False, plateau=None`。**⚠️ 早稿把"部分窗有平台覆盖(Gate C)"误写成"过完整 HEO 门"，是过度声称，已订正。** → **HEO1 门（"持续 30–150Hz 宽带平台"）对这个被试真实发作型（~3Hz CP 尖波）是 mis-specified**：模型 ~16Hz 态和真实发作**都过不了 HEO1 门**（SQL 标注起源 SCL7/SCL8，与模型核区一致）。
- **真实发作 = ~3Hz 尖波宽带（间歇）**：territory ΔdB 全频段抬——`1-4 +12 / 4-8 +10.4 / 8-13 +8.6 / 13-30 +8.3 / 30-80 +5.0 / 80-150 −1.2 dB`（低频最强）；per-contact 主频 **~3 Hz**（低频节律 spike-wave + 宽带谐波）、尖波间回基线。
- **与模型 ~16Hz 态对比**（`figures/real_vs_model_band_dB.png`）：真实发作**所有频段一起抬**（含低频 +10~12dB）、~3Hz 尖波；模型 ~16Hz 态**只 13-30 抬、低频压制**、持续窄带。→ **真正 target 不是 HEO1 门，而是这个 empirical 宽带-尖波（~3-8Hz）表型**；严格 0/48 只应读作"没造出持续 30–150Hz 平台"（一个既非模型态也非真实发作的表型），**不能读作"没造出发作"**。这是 HEO2 的关键输入。
- **CAVEAT**：模型 LFP 是 2D 片上 |current| 合成代理、真实是 referential iEEG；比较对"基线归一化频段结构 + 主频"有效；coherence 是二阶量（受参考影响，未作主张）。

## §4 GO/NO-GO 判决（分两层）

- **严格 HEO screen（预注册主判据）= bounded-negative，验收。** 合作型递归电导门在整个预注册参数盒里都没造出预注册定义的"30–150 Hz 宽带 + 五个频段 + 全平台（≥11/15）"发作型高能带（0/48）。命中停机规则 §6-**#7**（"只有窄带振荡、没有宽带能量平台"）——**不是 #5**（能量确实以 ~16 Hz 相干波铺满全阵列，不是只在核区）。
- **合作门动力学 = 出现值得保留的新候选（provisional）。** 复核发现合作放大**首次**造出一个有界、持续、跨全阵列相干的 ~16 Hz 高发放振荡分支（~20/48 格），是 Stage D/LC1 都没有的东西。未做 seed3/continuation 确认，故 provisional。

不为凑正结果扩大参数盒；g_sat 敏感性不触发（离宽带平台差在**频谱形状**，非饱和边缘）。

## §5 机制解读（复核订正）

- RC1 的 `tanh` 斜率单调下降（≤1），沿磨损轴只"连续加密"无再生高台阶（Stage D）。
- 合作门在中活动区把有效斜率 `d(u_tilde)/du` 顶到 >1（超线性凸起），**确实制造了再生正反馈**：D=0.15 + 大 A_c 处，快 E–I 系统进入一个有界的 **~16 Hz 极限环样振荡**（群体率稳在 90–140 Hz、全阵列相干 0.97–0.98、相位跨阵列 ~170°=行波）。这是本轮真正的动力学新东西——合作放大改变了快系统拓扑，产生持续振荡分支，而非 Stage D 自终止串。
- 高活动处 `tanh(u_tilde/g_sat)` 仍把 gErec 压回 g_sat → 振荡有界不失控。
- 这个极限环是**窄带（~16 Hz beta + 谐波）**：主能量 13–30 Hz，30–80 Hz 抬到多数触点，80–150 Hz 贴基线，低频被压制。它对不上"所有频段一起抬"的宽带发作平台表型。**当前缺的是把这个 ~16 Hz 极限环往快频（30–150 Hz）推 + 拓宽频谱，不是空间招募（已相干铺满）也不是点火（已很猛）**。
- 尚未做：continuation/hysteresis 判定（连续增幅 vs Hopf 样起振 vs 滞回高支）、seed3 复现、以及最关键的——真实 E1146 发作窗过同一把尺子，确认它测的是真实发作型而非人工理想型。

## §8 下一步（唯一建议，复核订正）

**先别跳到多核几何/连接走廊——当前证据没把空间传播锁成瓶颈**（~16 Hz 相干波已铺满全阵列）。正确顺序：

1. **【已做，§3.4】真实 E1146 发作过同一把尺子 = HEO1 门 mis-specified、target 需重定义**：真实发作是 **~3Hz 尖波宽带、间歇**（六频段全抬低频最强、平台间断），它**过不了完整 HEO1 门**（fails Gate A 持续高原；~3Hz 非 30-150Hz）；模型 ~16Hz 窄带态也过不了——**二者都不是 HEO1 平台型**。所以 HEO2 的 target 不是 HEO1 门，而是 empirical 宽带-尖波（~3-8Hz）表型（连续指标 + 与真实 E1146 六频段向量距离）。下一杠杆 = 让模型高态**变宽带 + 尖波化**（低+中+高一起抬、主频 ~3–8Hz 尖波节律），这是**快 E–I 回路频谱形状/时间尺度 + 波形**问题，不是空间连接、也不是"把 16Hz 往快推"（真实主频反而更低）；且要**保住空间平台覆盖**（现有 ~3.5Hz 尖波串已宽带但只 3/15 覆盖）。
2. **小规模确认**（不重跑 48 格）：seed3 复跑代表格 `A8/D=0.15/no-kick` 延到 8 秒；D=0.13→0.15 间做少量 warm-start 上下行 continuation，判连续增幅 vs Hopf 样起振 vs 滞回高支。
3. 只有当源空间分析确认快活动确实局限核区时，才进轴向连接/传播算子 sprint；多核几何最后再考虑（易靠"多放源"人为点亮平台，不证明机制）。
