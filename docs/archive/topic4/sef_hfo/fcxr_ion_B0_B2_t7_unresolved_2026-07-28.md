## 0. 摘要（先讲人话）

**我们想做什么。** 上一轮把钠钾泵当成"平时应该隐形、只在发作时出来刹车"的附加装置，没通过——它在平时
就已经把间期事件拉长了四成。这一轮换了个前提：承认泵本来就一直在工作，本来就参与维持静息电位，
所以不再要求它隐形，而是把细胞内的钠、细胞外的钾、以及泵这三样一起写进模型，然后**重新标定**平时的
工作点。

**这一步只问一个问题。** 在真的动用它去做任何发作实验之前，先问：给每个模型 spike 配多少钾/钠的
"搬运量"才合理？这个量太小，一次间期事件在钾浓度上留不下可测的痕迹，机制等于没接上；太大，一次
普通的间期事件就把细胞膜推过阈值的三成，那就不是"间期"了。我们预先锁死三个候选档位（0.5×、1×、
2× 背景通量），和五条判据：**看得见、不过头、钾能回落、钠能回落、连着来的事件能累积**。

**答案：三个档位都没同时满足五条。** 但失败的方式必须分开讲，因为它们不是一回事：

1. **"看得见 / 不过头"这一对，1× 档实际上是穿过去了。** 0.5× 太小（钾峰值 0.287 mM，够不到门槛
   0.547），2× 太大（1.150 mM，超过安全上限 0.90），只有 1× 落在中间（0.574 mM）。也就是说
   "合适的搬运量"这个窗口是**存在的、而且很窄，1× 就在窗口里**。
2. **"钾能回落"三档全过，而且过得非常干净**（事件后 3 秒回到静息波动的 0.00–0.02 倍）。
3. **"钠能回落"三档全不过，但这一条主要是判据本身的参照点定错了。** 判据要求 20 秒内衰减
   15.4%–46.2%，这个数是拿**静息状态**（钠 18 mM）线性化算出来的（时间常数 54.4 秒）。但这套离子层
   **按构造就不待在静息状态**——它自己的间期工作点是钠 19.2 / 20.1 / 21.3 mM，在那里泵对钠更敏感，
   时间常数是 37.9 / 29.6 / 21.3 秒，对应的 20 秒衰减应该是 41% / 49% / 61%。实测 68% / 66% / 77%，
   离"按正确工作点算出来的数"近得多，离判据里那个 30.8% 很远。
4. **"连着来的事件能累积"三档全不过，而这一条不是参照点的锅，是真的物理结果。** 把同一次真实间期
   事件每隔 200 毫秒连打 5 次，如果钾只是"堆上去再按固定速度漏掉"，第 5 次应该比第 1 次高 2.97 倍。
   实测 1× 档只有 1.78 倍。就算把参照点也改到正确的工作点（那里应该是 2.6–2.8 倍，门槛会降到约
   2.1），1.78 仍然不够。而且**搬运量越大，越不累积**（2.005 → 1.780 → 1.536）——这正是"清除速度
   随钾浓度加快"会给出的样子：胶质摄取和泵都是钾越高吸得越快，所以事件叠不上去。

**所以这一轮真正测出来的东西是：在这个基底上，间隔 200 毫秒的连续间期事件，细胞外钾的堆积是
"越堆越难"而不是"越堆越容易"。** 这句话直接关系到这条路线的前提——路线 B 指望钾积累充当局部正
反馈。**但要立刻加一条限制：这是在"离子只看不动手"的模式下测的**（钾浓度变化没有反过来改变网络
放电）。真正的闭环里，钾高 → 更兴奋 → 放更多电 → 钾更高，这条回路在本次测量里被**按设计排除
了**。所以我们只能说**清除这一侧**是超线性的，不能说整个闭环不会失控。

**判决：`UNRESOLVED_T7_PROTOCOL`，归档并停止，不进 B2。** 判据一格都没有放宽，候选集一个也没有扩大。

## 0.1 审阅订正（2026-07-28）：为什么终局不能叫 `NO_GO_ION_SCALE`

初稿把这一轮写成了 `NO_GO_ION_SCALE`。**这是错的，已订正。** 理由不是判据被放宽，而是**被测对象换了**：

预注册的 T7 合同（plan §9.1/§9.2）是**occupancy 对齐的小网络 + 离子反馈打开**。实际产出 canonical 数字
的那次运行是**40k 基底 + `g_K_ion = 0` + 固定 raster 的 sensor 离线重放**。网络规模、事件来源、开环/闭环、
以及判据统计的对象**四样全变了**。改动本身有理由（见 §3），也确实比退化的小网络更贴近真实底座，但
**换了对象的结果不能继承它所替代的那份合同的判决权限**（CLAUDE.md §5：预注册档位在计划期就固定）。

因此：`select_f_prime` 这个实现**原样保留**（将来一次忠实的小网络运行仍然会得到 `NO_GO_ION_SCALE`），
runner 改为在协议偏离时**扣留** canonical label，输出 `UNRESOLVED_T7_PROTOCOL`，并把
"若协议未偏离本会得到的标签"单独记在 `contract_verdict_if_protocol_had_matched` 字段里。

**还有一条更硬的逻辑问题（审阅 P0-2）**：积分判据是在 `g_K_ion = 0` 下测的，也就是把
`K_o↑ → E_K↑ → 放电↑ → K_o↑` 这条回路**故意切断**之后测的。用它去封锁 B2——而 B2 的全部目的正是去测
那条回路——是**自我封闭**：一个刻意切断正反馈的诊断，因为"没表现出足够累积"而禁止进入真正测正反馈的
阶段。所以积分那一条**不应作为尺度 admissibility 的硬否决项**，本文件也不得被读成为该封锁提供了机制
依据。B2 关着，是因为**没有选出 `f'`**，不是因为机制被否证。

## 3. T7：`f'` 三点 × 五条门的完整对照

**执行偏离 plan，必须写明**：plan §9.1/§9.2 把 T7 放在小网络上（目的是在 Gate H 之前不付 40k 的成本）。
Gate H 已经通过，40k 因此被允许。第一次小网络尝试**至少有两个明确的仪器缺陷**，证据保留在
`superseded/b1_f_selection_smallnet_instrument_failure.json`：

- 它的离子预平衡是用一段 3.28 Hz 的率场建的，而协议运行实际跑在 5.48 Hz，于是整个 26 秒都是一段
  **单调上升的钠瞬态**，`na_excess_peak` 与 `na_excess_at_20s` **完全相等**，衰减对三个候选**按构造**
  都恰好是 0.000；
- 那个 kick 招募了 3200 个 E 细胞里的 **2652 个（83%）**，那不是判据里说的"一次间期事件"。

**但初稿把它整体写成"纯仪器 bug"是过强的（审阅 P1-2），已订正。** 3.28 → 5.48 Hz 这个位移里至少混着
三种成分，本轮**没有把它们分开**：(a) 小网络固定入度导致的尺度退化；(b) 预平衡率场与实际网络率不自洽；
(c) **离子反馈真实地抬高了放电率**。第三条有独立旁证：Gate H 的 `no_negative_or_bound_collision` 项里，
n4000 在离子层**打开**时平均率约 **19.25 Hz**，而同一网络 ions-off 是 3.28 Hz。Gate H 本来就不验收网络
工作点，所以这不影响 Gate H 的 PASS；但它说明**离子反馈对这个基底的工作点有很大的真实影响**，不能当作
可以丢弃的仪器噪声。这条恰恰是 B2 bias 重标定要处理的东西，也是本轮**没有**测到的东西。

修正后的仪器跑在**真实 40k 基底、用基底自己的自发间期事件**，率场直接来自被测的那条轨迹，因此上面
两个明确缺陷同时消失。**修好的标志**：钾恢复从 7.3σ 变成 0.00–0.02σ。与上一代际先例一致（泵 sprint 也
检出过一个事件判据的仪器 bug，修好、重跑一次、保留第一次运行作为证据）。**但要注意**：修好仪器换来的
是一个**开环诊断**，不是预注册的那个闭环选点实验——这正是 §0.1 扣留 canonical 判决的理由。

**测量模式：sensor（`g_K_ion = 0`）+ 孤立事件离线重放 vs 配对的纯背景对照。** 三条理由都是预先声明的：
(a) 与已接受的泵 sprint sensor-only 标定同一手法；(b) 五条门问的是"**一次**间期事件对离子做了什么"，
带反馈测是循环论证（更大的 `f'` 会改变网络、改变事件、改变 ΔK_o）；(c) 判据的解析参照（3 秒 = 4.6 个
`tau_Ko`；20 秒衰减 30.8%）都是**纯弛豫**预测，只对孤立事件成立，而这个基底每秒放 2.2 次事件，
根本不存在孤立事件——所以重放不是图方便，是让判据**有定义**的前提。

### 3.2 三类失败必须分开归因

**(a) 可测 / 安全这一对：窗口存在且很窄，`f'=1.0` 在窗口内。**
0.287 < 0.547 < 0.574 < 0.90 < 1.150。这不是"没有合适的尺度"，而是"合适的尺度窗口窄，主选档正好落
在里面"。

**(b) 钠恢复：判据参照点定在系统按构造不会待的状态上。**
判据的 30.8% 来自 `tau_Na = 54.42 s`，那是在**静息态**（Na 18.0，K_o 4.0）线性化的。而 spec §3.2 自己
就写明离子层**按构造**会把间期工作点抬起来（K_o 4.0 → 4.11），并**禁止**再说"离子层在间期是安静的"。
在各档自己的工作点上：

| `f'` | Na* (mM) | `tau_Na`(工作点) | 20 s 衰减预测 | 实测 |
|---:|---:|---:|---:|---:|
| 0.5 | 19.21 | 37.9 s | 41.0% | 68.2% |
| 1.0 | 20.07 | 29.6 s | 49.1% | 65.5% |
| 2.0 | 21.25 | 21.3 s | 60.9% | 77.2% |

有限幅度只再贡献 1–2 个百分点（初始超额 0.05 → 1.0 mM 时预测 49.3% → 51.8%），所以差距主要来自
**工作点位移**，不是幅度非线性。明细见 `b1_gate_reference_audit.json`。

**剩余缺口（41% 预测 vs 68% 实测）目前只有一个假设，没有被验证（审阅 P1-1，已订正措辞）**：参与格中
同时抬高的 K_o 会进一步抬高 `I_pump`（泵对 Na 和对 K_o 都单调递增），从而加快钠清除。上面那张表是
**把 K_o 冻结在各档工作点**算出来的，所以它**没有**包含这条耦合。要坐实这个归因需要一次钾钳制或一个
二维耦合 Jacobian，本轮**都没有做**，因此这只能写成待验证的推断。

**还有一条更要紧的：`na_excess_monotone_nonincreasing` 三档全为 `false`（审阅 P1-1）。**
这意味着即使把衰减带从静息值改到工作点，现有 adjudicator **仍然会判失败**——初稿只讨论了衰减比例，
漏了单调性这一支。诊断见 §3.3。

**(c) 积分：这一条不是参照点的锅。**
2.973 这个线性参照同样来自静息的 `tau_Ko = 0.6546 s`。在工作点上 `tau_Ko` 是 0.61 / 0.57 / 0.51 s，
事件内（K_o 4.3–5.0）进一步降到 0.55–0.50 s，**正确锚定的线性预测约 2.6–2.8，0.8× 门槛约 2.09–2.24**。
但 `f'=1.0` 实测 1.78，**仍然低于重新锚定后的门槛**。逐次峰值增量（`f'=1.0`）：

```
峰值      0.641  0.876  1.014  1.095  1.140
增量             0.235  0.139  0.080  0.045      每次大约减半
线性预测的增量   0.451  0.318  0.224  0.158
```

而且**搬运量越大越不累积**（2.005 → 1.780 → 1.536）——这是"清除随钾浓度加快"（胶质摄取 + 泵都随 K_o
单调上升）的直接特征。**这是本 sprint 唯一的实质机制结果。**

**但这条结果的适用范围必须钉死**：它是在 `g_K_ion = 0` 下测的，"钾多→更兴奋→放电更多→钾多"这条回路
**被按设计切断**。所以它刻画的是**清除侧**的负荷依赖性，**不是**闭环有没有正反馈。用它去封锁 B2
（B2 的全部目的就是测那条回路）是自我封闭——见 §0.1。它正确的位置是 **B2 的前置风险登记**：若闭环下
清除依然这么强，高态可能建立不起来；**那正是 B2 要回答的问题，不是 B2 的入场条件**。

### 3.3 钠单调性子句的诊断（审阅 P1-1 要求，本轮补做）

三档 `na_excess_monotone_nonincreasing` 全为 `false`。轨迹落盘在 `b1_f_selection_traces.npz`
（`f*_na_excess`，2.5 ms 一个采样点），诊断结果：

| `f'` | 原始样本上升占比 | 中位 \|步长\| (mM) | 最大上跳 (mM) | 占峰值 | 峰值 → 20 s (mM) | 峰后是否净上升 |
|---:|---:|---:|---:|---:|---|:---:|
| 0.5 | 46.7% | 1.44e-5 | 1.40e-3 | 12% | 0.01192 → 0.00380 | **否** |
| 1.0 | 46.2% | 2.83e-5 | 3.38e-3 | 16% | 0.02176 → 0.00747 | **否** |
| 2.0 | 46.9% | 4.50e-5 | 6.28e-3 | 18% | 0.03534 → 0.00808 | **否** |

**读法**：上升占比约 47%，接近对称抖动；中位步长只有峰值的 0.1–0.2%。真正踩雷的是那些**大的向上跳变**
（峰值的 12–18%）——那是**重放背景里的其它事件**落在了被测的同一批细胞上。**平滑救不了**：1 / 2 / 5 / 10 秒
四种箱型平滑后仍然含有上升步。

**但三档都没有"峰后净上升"**——这条子句本来要抓的物理（钠重新累积失控）**不存在**；失效的是子句的
**零容差形式**。

**这条的后果很重要**：**只改衰减带修不好这个门**——adjudicator 仍然会在单调性上判失败。子句必须与
衰减比例**解耦**，并改述为"峰值到 20 s 无净上升"（三档都过），而**不是**"平滑包络单调"（三档都不过）。
已写入 T7.1 提案，**本轮未执行**。

> **一处自我订正**：本诊断的初稿断言"1 秒平滑后的包络是单调不增的"。**实测不是**，四种平滑窗口都不是，
> 该说法已撤回。

  系统不会待的状态上；
- 说"钾的正反馈被排除"——次线性只在 **sensor 模式**下测到，那里**按设计**切断了"钾高→更兴奋→放更多
  电→钾更高"这条闭环；只能说**清除那一侧**是超线性的；
