# FCXR-HEO3 Stage H3.1 — 因果 2×2：斑块化恢复时间（逐细胞钾负荷配平）

**日期**: 2026-07-25 ｜ **分支**: `codex/topic4-mz-fcxr-heo1` ｜ **性质**: 预注册因果实验（review 锁定 2×2 + 两个对照）。

**判决**：**斑块化适应异质性 = 干净的、带对照的 NULL；按预注册停机条件，此杠杆停，H3.2 不解锁。**
- **2×2 交互项 NULL**：斑块-动态（弱 2×、强 4×）与它**自己的空间打乱对照**、以及均匀-动态，在四个判据上**无法区分**；联合目标窗 **0/8**（地板未被抬起，最长连续 0 ms）。
- **斑块-冻结 ≡ 均匀-冻结**（判据完全相同，平均钾负荷 gM 0.1909 = 0.1909 精确配平）：静态载荷上的空间花纹不做任何事。
- **无区域交替**（订正后指标）：全部 arm 为**正相关**（斑块-动态 +0.98），两个核**同起同落**，没有轮流承载。
- **一个方向性发现（有混淆，未确立）**：把**群体平均 m̄(t) 同步施加给所有细胞**后，宽带窗 32%→**0%**、去同步 10%→0%，行为退回静态臂 → 提示**细胞间适应差异**（而非平均时间过程）承载了那点拓宽；但该臂平均钾负荷 gM 0.438 是其它臂（0.175–0.227）的约 2.3 倍，**未配平**，所以此结论**尚不能确立**（见 §4）。

## 摘要（朴素话）

**测了什么** — 上一步查清：这块组织在"相位还锁着"的时候把频谱拉宽，只有在活动快死掉的时候才真正打散同步，两件好事从不同时发生。于是这一步问一个具体的因果问题：**如果让组织不同区域的"恢复速度"不一样，它们会不会轮流承载活动，从而在不把状态弄死的前提下把相位关系打乱、并且把拉宽的状态维持住？**

**怎么测的** — 把组织沿源→汇方向切成三条约 4.35 宽的带（作为对比，两个"核"的半径只有 1.5，所以这些带是走廊量级），相邻带里的细胞"放电后自我疲劳"的**恢复时间**不同：弱档差 2 倍（177 / 354 毫秒），强档差 4 倍（125 / 500 毫秒）。这里有一条关键的保险：**每个细胞的钾负荷被逐个配平**——给恢复快的细胞配比例缩小的强度，使得"强度 × 恢复时间"对每个细胞都恒等于均匀条件下的值（数值上误差为 0）。这样万一出现好结果，就不能被解释成"斑块只是多压了钾"，只能是"恢复时间在空间上排列"起的作用。四格实验：均匀/斑块 × 冻结负荷/动态适应。再加两个对照：**把同一批恢复时间值随机撒开**（直方图、均值、方差一模一样，只毁掉空间排列）；以及**把群体平均的疲劳量同步施加给每个细胞**（时间上照样起伏，但细胞之间没有差别）。判据仍是四件事必须在**同一个 1 秒窗**里同时成立，并看能连续维持多久（上一步的地板是：八个条件里一个窗都没有）。

**揭示了什么** — **空间排列什么也没做成**。斑块-动态那两格与**把它自己随机撒开**的对照几乎完全一样（宽带窗 29% vs 29%，锁相 0.87 vs 0.88），也和完全均匀的适应一样（32%、0.86）。四个要求依然从来没有在同一个窗里同时成立（八个条件全 0）。**两个核也完全没有轮流**——它们的活动是**同起同落**（相关 +0.98），跟"交替承载"正好相反。所以按事先说好的停机条件：这条"让适应在空间上不均匀"的杠杆到此为止，**不再往下扫更多斑块尺寸和对比度**。

同时看到一件值得记下但**还不能当结论**的事：如果把每个细胞的疲劳量换成**全体的平均值**（时间上照样起伏，但细胞之间没有差别），那点仅有的拉宽就**完全消失**了（宽带窗 32%→0%）。这提示真正承载拉宽的是**细胞与细胞之间疲劳程度的差异**，而不是疲劳的平均时间过程——但这一臂的平均钾负荷比别的臂高了约 2.3 倍，没有配平，所以这只能算一条**待验证的线索**，不能当作已确立的机制。

（内部归档代号：HEO3 H3.1；`tau_adp_E`/`eta_m_E`/`m_mean_field`；stripe_w = D/3 = 4.35（axis D=13.05、CORE_R=1.5）；contrast 2×/4× 几何中心 250 ms；逐细胞 load 不变式 η_i·τ_i = η₀·τ₀（max err 0.0）；判据 recruit≥12 ∧ broadband≥8 ∧ PLV≤0.60 ∧ rate≥60 Hz，1 s 窗 /100 ms hop。）

## §1 设计（为什么这样才是"恢复时间"的因果检验）

review 的提法是"**空间组织化的恢复时间差**能否让不同区域交替承载活动"。因此：
- **斑块参数 = τ（恢复时间）**，不是强度；
- **逐细胞钾负荷配平**：稳态适应电流 ∝ η_i·⟨m_i⟩ ∝ η_i·r·τ_i，令 **η_i = η₀·τ₀/τ_i** → η_i·τ_i ≡ η₀·τ₀，**每个细胞的负荷不变，只有"什么时候恢复"变**。数值验证 max|η·τ − η₀·τ₀| = **0.0**；另有沉降测试（4× τ 跨度下稳态电流差 <2%）。
- **斑块-冻结**的高低两档由**反解**得到（条带并非 50/50 分割细胞，实测 43.5%/56.5%；若按五五分设档，该臂平均负荷会高 7.8%，把"空间花纹"和"更多钾"混在一起）。实测 gM：均匀-冻结 0.1909 = 斑块-冻结 0.1909。

**⚠️ 2×2 的一处结构不对称（诚实记录）**：静态条件下"恢复时间"不存在，所以斑块-冻结的斑块参数只能是**冻结负荷**，而斑块-动态的斑块参数是**恢复时间**。两格的"斑块化对象"不同。该 2×2 仍能回答"空间异质是否只在有动态时起作用"，但它**不是**同一参数的严格析因设计。

**决定性比较**：`patch_dyn_strong`（29/10/0.87）**≈ 它自己的空间打乱**（29/6/0.88）**≈ uniform_dynamic**（32/10/0.86）。**空间组织本身贡献为零**；差异落在打乱对照的噪声范围内。**0/8 无一抬起地板。**

### §2.2 区域交替（订正后指标）
全部为**正**：uniform_dynamic +0.98、patch_dyn_weak +0.98、patch_dyn_strong +0.98、shuffled +0.98、patch_static +0.45、uniform_static +0.51、meanfield +0.08、reference +0.87。→ **两核同起同落，没有任何轮流承载**；斑块化并未制造交替。

> **⚠️ 指标 bug（已修，记录以防重犯）**：初版 `region_alternation` 用两区**份额** a/(a+b)、b/(a+b) 求相关——**两个份额恒和为 1，必然完全负相关**，于是**每个 arm 都报 −1.0（"完美交替"）**，包括纯共同驱动的均匀臂。已改为两区**原始率**的相关（负=交替、正=共同驱动），并补回归测试：一个纯共同驱动、但份额非恒定的信号必须报**正值**（旧实现在该例报 −1）。

### §2.3 方向性线索（未确立）
`meanfield_dyn`（每个细胞都用群体平均 m）：宽带 32%→**0%**、去同步 10%→0%、PLV 0.94、能量 100% —— 行为与静态臂一致。提示**细胞间适应差异**承载了那点拓宽（这些差异在均匀参数下也**内生存在**，因为细胞放电本就不同）。

## §3 与预注册停机条件的对照 → **停此杠杆，H3.2 不解锁**

review 执行顺序写明：**H3.2 仅当 patch-dynamic 提高联合目标窗占比时才扫两个 patch 尺度 × 两个 contrast**；停机条件：**"若 patch 只增加碎裂、没有提高联合持续时间，立即停掉适应异质性，转向区域间走廊维持招募、局部恢复时间错开的结构机制"**。

实测：patch-dynamic **没有**提高联合目标窗（0%，与打乱对照同）；招募略降（81%→74–84%）但未见明显碎裂。→ **前置条件未满足，H3.2 不执行**；按停机条件，**适应异质性杠杆停**。

## §4 诚实边界（不得越界声称）

1. **可声称**：在此锚点、此 2×2、走廊尺度斑块（4.35）、2×/4× 对比度、逐细胞负荷配平的条件下，**恢复时间的空间组织不改善**任何联合判据，也**不产生区域交替**；打乱对照证明差异不来自空间排列。
2. **不可声称**：空间异质性在**任何**尺度/对比度/几何下都无效（只测了走廊尺度条带、两档对比度、单 seed、单锚点）；也不可声称"空间去同步被否证"。
3. **`meanfield_dyn` 结论未确立**：该臂 gM 0.438 是其它臂的约 2.3 倍，**未做负荷配平**（高负荷是"去掉细胞间差异→自限性减弱→活动升高→m 升高"的**后果**，非独立操纵）。要确立"细胞间差异承载拓宽"，需**负荷配平的重复**（按 gM 反标 η 后重跑）。
4. **2×2 不对称**：静态格的斑块参数是冻结负荷、动态格是恢复时间（§1），非严格同参数析因。
5. 单 seed（seed1）、单锚点、T=5 s；`region_alternation` 只看两个核，未覆盖走廊/轴外的交替。
