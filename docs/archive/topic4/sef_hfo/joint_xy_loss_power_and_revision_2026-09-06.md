# 双核搜索：损失敏感性验证与首批后的版本修订

## 结论

已确认当前 v1 联合投影损失对患者 rank 和时滞破坏的响应偏弱。这是需要修正的损失问题，不能用“多换几个随机起点”替代。新事件核在训练对照中表现出更高敏感性，但尚未据此找到或验收新的双核；持续 goal 保持 active。

上一轮完成了新观测、随机多起点、资源控制、自动诊断与 Fig.5 衔接程序的实际设置并启动。当前轮在核实服务进程/worker 活跃后，完成训练块配对对照、候选核资格检查、新模块测试，并设置首个批次结束后安全退出 v1 的守护进程，因此属于实质进展。

## 为什么重新做配对检查

先前“全量 rank 打乱距离 0.003，小样本患者容差 0.007”的比较只能提示风险，不能当成等样本量检验。本次分别在 16、64、256 个事件下，使原始与扰动伪模型共享同一批事件索引、保持参与掩码一致，对照参考来自互不重叠的患者训练块。每种设置 48 次训练块重采样，不打开 heldout。

95% 阈值取自对应未扰动抽样，所以以下比例是描述性的敏感性指标，不是独立估计的统计功效；几何和重采样均不能作为患者数。

## 实测结果

| 扰动与样本量 | v1 联合投影损失超过患者阈值 | 候选完整事件核超过患者阈值 |
|---|---:|---:|
| rank 打乱，16 事件 | 6.3% | 31.3% |
| rank 打乱，64 事件 | 8.3% | 100% |
| rank 打乱，256 事件 | 16.7% | 100% |
| 时间拉伸至 1.5 倍，64 事件 | 6.3% | 100% |
| 时间拉伸至 1.5 倍，256 事件 | 8.3% | 100% |

完整 rank 模式的专门核在首个敏感性审查中也在 64/256 事件下达到 100%；新核资格检查进一步把参与、rank/空间、时间/空间以及完整事件联合模式分开验证。参与核对纯 rank 打乱、纯时间拉伸仅有约 6.3% 超阈，符合其输入未变的预期，说明改进不是把所有变化都判坏。

v1 的四块向量虽形式上等尺度，但高维随机投影后的联合距离仍容易被参与分布与抽样波动主导。单独 rank 投影损失到 256 个事件才有 83.3% 的 rank 打乱超阈率，在 64 个事件时仅 18.8%。因此只把原投影向量分块，不足以解决短轨迹下的识别能力。

## 候选新损失

`src/topic4_joint_xy_kernel.py` 保留固定接触点身份、参与掩码、仅参与通道的 rank、相对时间及由实际 XY 计算的早/晚空间矩。使用由患者训练事件距离确定带宽的高斯核，通过 1024 维固定随机 Fourier 特征计算整事件分布距离，没有 K=2 标签、目标角度或 core 连线惩罚。

患者正相对时间的中位数为 20.63 ms，而旧时间表示按 180 ms 缩放。新时间核使用这个训练中位数作为量纲标尺，不按模型拟合结果挑标尺；接受度仍需重新按患者块变异校准，而不是直接增大一个分数就算改好了。

5 项新模块测试通过：时间整体平移不改变比较，时间拉伸只改变时间相关表示、不会改变 rank 表示，缺失/空事件处理正确，核能识别模式比例改变，地图与随机特征可复现。原 v1 的 22 项测试记录不变。

## 执行调整

当前第一批 24 个新几何、48 个工作单元继续完成，所有轨迹可由新损失重评分，不需要废弃或重跑。守护服务 `codex-t4-joint-loss-review-guard-20260906.service` 监测首批 `rounds/001/analysis.json`，到达边界后先暂停当前控制器的新任务派发，等待所有已开始的子进程自然结束，再停用 v1 服务。它检查实际 PID、启动身份和命令，不以一个状态文件直接认定任务已经终止，也不终止运行中的仿真。

下一步应创建新的搜索版本，保留原始合同、源码锁和验收结果；用经训练对照验证的完整事件核及分解诊断重新评估全部已有几何。约 16 个观测事件仍不足以稳定识别 rank 破坏，所以需要对多个有潜力、位置不同的候选追加独立的短网络重复，先达到约 64 个事件，再作有决定性的局部提名。不能在低样本下挑一个最幸运的几何，也不能靠放宽方向/顺序/时滞验收宣布成功。

后续新控制器还应避免继承调度器日志中 `objective_version=xy_direction_v2` 的旧标签：这只是旧调度函数的标签，不代表当前 v1 实际损失；科学版本以 `objective_contract.json` 和评分文件为准。
