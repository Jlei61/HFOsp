## 朴素摘要（测了什么 / 怎么测 / 揭示了什么）

**测了什么**：在 Step 1 鉴定出的稳健衬底上，只加"抑制资源会被用掉"这一张慢变量地图（q_I），不加疲劳（g_K）。想看 q_I 能不能把一个局部沿轴事件推成**更大、更长、但仍然沿轴、仍然能平息**的 expanded axial——这是用户计划里 Step 2 的目标（Step 3 才谈破轴）。

**怎么测**：3 个稳健衬底（primary/sensitivity/backup headroom 梯度）× 4 档 σ_q × 3 档 q_min × 5 档**目标轴向耗竭 Δq_axis**（k_q 用 baseline event 重放标定，K_q 已 mass-normalized，σ_q 是纯展宽旋钮）× 4 seed。每个 run 量 R_area/S_axis/F_off/returned + **q_axis/off/global_min**（轴 vs 离轴耗竭）+ 与同 seed baseline 的 paired Δ，按 A–E 分类。

**揭示了什么——q_I 单独给不出 expanded axial（干净 NEGATIVE）**：
- **576 个 q_I run：532 = A_no_effect、44 = E_runaway、B_expanded_axial = 0。** 一个目标态都没有。
- **532 个 returned run 全部 R 几乎不变（max dR=+0.016）、轴向完好（S>0.9）**——温和 q_I 去抑制被事件**完全吸收、不长大**。
- **会长大的（dR~0.05–0.07）全部 runaway（ret=0、dS~−0.7 轴向崩）**，且几乎全在 **headroom 最少的 sensitivity 衬底（42/44 runaway）**；headroom 最多的 backup **从不 runaway 但也从不长大**（dq=0.30、q_axis 耗到 0.69，dR 仍 +0.006）。
- **没有"更大但仍沿轴仍 returned"的中间窗**：要么不动（returned），要么长大即崩（runaway）。

## §1 为什么——两条都成立，互相印证

1. **几何（L-invariant）**：踢出的事件**已经沿整条轴端到端**（axial reach = **1.00**，L=10 和 L=16 都一样；L=16 只是更细的长条但仍到远端）。**没有沿轴可长的空间**——baseline 已经把轴向走廊铺满（R~0.41、F_off~0.13 = corridor-saturated）。所以唯一能"扩"的方向是**垂轴出走廊**=离轴。
2. **机制（无自限）**：q_I 只给去抑制、**没有刹车**。当去抑制强到能把事件推出走廊（离轴），它同时**没有终止机制 → runaway**（不 returned），而不是受控扩张。所以 off-corridor push = D/runaway，不是 B。

**合起来**：corridor-saturating 的踢出行波 + 无自限的 q_I ⇒ expanded-axial 这个中间态**结构上不可表达**。这与 memory 的均质衬底 all-or-nothing 老教训一致（衬底给满走廊行波、不给可部分填充的事件）。

## §3 判读 + 下一步（fork）

- **Step 2 = NEGATIVE（但 informative）**：q_I 单独**不**产生 expanded axial recruitment。不是参数没调够（dq 到 0.30、σ_q 到 wide、q_min 到 0.6、3 衬底 headroom 梯度都扫了），是**结构性**——满走廊行波没有沿轴扩张余地，q_I 只能往离轴推、而无 g_K 刹车则离轴推=runaway。
- **这直接 motivate Step 3**：缺的正是 **g_K（use-dependent 疲劳刹车）**。q_I 推（去抑制）+ g_K 刹（活动越多越压）合起来，才可能给"更大但仍能终止"的事件——这正是 Step 3 q_I+g_K 要测的（off-axis recruitment 但 returned = ictal-like candidate，对比 q_I-only 的 off-axis→runaway）。
- **另一条 fork**：若坚持要看"expanded axial"中间态，需要换**事件类型**（不是满走廊踢出行波，而是可部分填充的局部事件）——但这块衬底 all-or-nothing 给不出，是更深的 substrate/protocol 改动。
