## 朴素摘要（测了什么 / 怎么测 / 揭示了什么）

**测了什么**：在 Step 1 鉴定出的稳健衬底上，只加"抑制资源会被用掉"这一张慢变量地图（q_I），不加疲劳（g_K）。想看 q_I 能不能把一个局部沿轴事件推成**更大、更长、但仍然沿轴、仍然能平息**的 expanded axial——这是用户计划里 Step 2 的目标（Step 3 才谈破轴）。

**怎么测**：3 个稳健衬底（primary/sensitivity/backup headroom 梯度）× 4 档 σ_q × 3 档 q_min × 5 档**目标轴向耗竭 Δq_axis**（k_q 用 baseline event 重放标定，K_q 已 mass-normalized，σ_q 是纯展宽旋钮）× 4 seed。每个 run 量 R_area/S_axis/F_off/returned + **q_axis/off/global_min**（轴 vs 离轴耗竭）+ 与同 seed baseline 的 paired Δ，按 A–E 分类。

**揭示了什么——q_I 单独给不出 expanded axial（干净 NEGATIVE）**：
- **576 个 q_I run：532 = A_no_effect、44 = E_runaway、B_expanded_axial = 0。** 一个目标态都没有。
- **532 个 returned run 全部 R 几乎不变（max dR=+0.016）、轴向完好（S>0.9）**——温和 q_I 去抑制被事件**完全吸收、不长大**。
- **会长大的（dR~0.05–0.07）全部 runaway（ret=0、dS~−0.7 轴向读出崩、peak 到 415Hz）**，且几乎全在 **headroom 最少的 sensitivity 衬底（42/44 runaway）**；headroom 最多的 backup **从不 runaway 但也从不长大**（dq=0.30、q_axis 耗到 0.69，dR 仍 +0.006）。**注意：runaway 的 F_off 仍低（max 0.17、mean 0.14）——这不是 off-axis recruitment，是高率 + 轴读出崩**（P1-2）。
- **没有"更大但仍沿轴仍 returned"的中间窗**：要么不动（returned），要么长大即 runaway。**口径收窄**：这是**当前单事件、q_init=1、dq≤0.30、3 衬底**范围内的负结果（未测低-q 初始态、未证 off-axis recruitment）。

## §1 为什么（scope-limited：当前**单事件 + q_init=1**，见 §3 边界）

1. **几何（L-invariant，可审计）**：踢出的事件**已经沿整条轴端到端**——`axis_reach_frac=1.00`，**L=10 和 L=16 都一样**（L=16 只是更细长条但仍到远端；见 `results/topic4_m3a_v2_step2_qI/L16_control.json`），走廊填充 `corridor_fill_frac~0.6–0.8`。**没有沿轴可长的空间**（baseline corridor-saturated）。这两个量现在都进了 raw_rows，可审计（不是只放文字）。
2. **机制（无自限 + 单事件 q_init=1）**：这一轮 q_I **从满箱 q=1 开始**、被**同一个被踢事件**耗竭（`simulate_kick` 先用当前 q 影响膜流、spike 后才更新 q——见 kick_probe.py:255）。温和耗竭 → 被事件吸收、不长大（A）。**强耗竭 → 高率 runaway + axis readout 崩**（peak 到 415Hz、S_axis<0.5）；**但 F_off 仍低（max 0.17、mean 0.14、dF mean +0.01）——当前读出并未证明这是受控或明确的 off-axis recruitment**，更像是强去抑制 → 高率/长尾/失控、onset axis 变得不可解释。

**口径（收窄，P1-1/P1-2）**：**在当前单事件、`q_init=1`、`dq≤0.30`、3 衬底范围内**，q_I-only 没有 returned expanded-axial window。**两个未测/未证**：(a) 前面多次间期事件已把 q_I 降低后、下一个事件在**低 q 初始态**下怎样（科学含义不同，本轮未测）；(b) 强 q_I 是否是**受控/明确的 off-axis recruitment**（F_off 没起来，未证）。**不写"结构上不可表达"这种满话。**

## §3 判读 + 下一步（fork）

**安全口径（不写太满）**：

> Step 2 给出了一个有信息量的负结果。576 个只开 q_I 的仿真中没有出现 returned expanded-axial regime：能返回的事件招募范围几乎不变，而真正扩大的事件直接进入 runaway。这说明**在当前衬底、单事件、q_init=1 范围内**，空间去抑制本身更像 permissive destabilizer，而不是自限性扩张机制。由于 baseline 事件已铺满轴向走廊（axis_reach_frac=1.0），q_I 几乎没有沿轴继续扩展的空间；当它强到失稳时，又因为缺少恢复刹车而进入 runaway（且 F_off 没起来，未证明是受控 off-axis recruitment）。
>
> *Step 2 produced an informative negative result. Across 576 q_I-only simulations, no returned expanded-axial regime was observed: runs that returned showed negligible changes in recruitment area, while runs that expanded transitioned directly to runaway. Within this substrate / single-event / q_init=1 scope, spatial disinhibition alone acts as a permissive destabilizer rather than a self-limited expansion mechanism. Because the baseline event already spans the full axial corridor, q_I has little axial space to expand into; once strong enough to destabilize, it lacks a recovery brake and collapses into runaway.*

- **结论支持把 g_K 作为下一步必要测试**（因为 q_I-only 缺少终止机制）；**但 g_K 是否能把 runaway 变成 returned recruitment 仍未证明**——这是 Step 3 的判决性问题，不是已知结论。
- **fork B**：若坚持先看"expanded axial"中间态，需要换**事件类型**（可部分填充的局部事件，而非满走廊踢出行波）——更深的 substrate/protocol 改动。

**锁**：descriptive screen；q_I-only NEGATIVE = **scope-limited**（此衬底 + 踢出行波 + 单事件 q_init=1 + dq≤0.30），非"q_I 无用"普遍判决；**未测低-q 初始态**；破轴/发作未证；g_K/D_EE 未开。
