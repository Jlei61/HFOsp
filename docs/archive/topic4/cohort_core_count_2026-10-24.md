作者要求先启动此实验，再制作从旧 Fig4 拆出的新 Fig5。科学问题是：在相同数据、物理模型与可用搜索预算下，一个单 core 配置能否同时获得与患者 TA 和 TB 均相似的传播模板；双 core 是否改善其中不足的一项。预期“单 core 只拟合一种模式”只是待检验假设，不能预填为结果。

样本固定为旧 Fig4I 的全部 25 位可运行患者，来源为原 34 人中的执行资格子集，不按相关性、共享轴反向程度或新模拟结果筛人。统计单位为患者，两项模板相关来自同一拟合配置，不能分别挑两个不同工作点。旧 F 数据源是 `cohort_recurrent_expansion_20260927` 的冻结选点；新实验的单、双 core 均独立重新优化，完成之前不能将新单 core 与旧 F 分布直接称作同预算配对。

每位患者每臂 32 次 60 s 原生 SNN 仿真：8 个独立 Sobol 初值，随后每轮 8 点的反馈优化，失败点也消耗同等预算。搜索单核/双核的各自 XY、核内向核外 EE 强度（0.9–1.6）和相对患者轴的 EE 角度（±60°）；其余参数冻结。单核半径 1.7525782906 mm，固定每核阈值和输入规律，完整圆形 core 留在 20×20 mm 平面内、双核不重叠。固定拓扑 2511、训练噪声 847401，去除前 1.5 s。两组均采用原冻结患者观察器和三分量训练 J，rank、时序/杆内先后和参与模式等权；TA/TB 标签不进入优化。

各臂达到全部 32 点后，只按训练 J 最低值提名一个工作点。随后以两个新噪声 1024401/1024402 各复测 60 s，并用原跨记录开发数据计算辅助分布误差。主要图读出保持旧 F 定义：仅用模型事件的有效参与 rank 做固定 K=2，再以最大有符号相关之和作一次一一命名，输出 TA–MTA 和 TB–MTB 两项 Spearman ρ；不取绝对值，不删除负值，不把缺失模式记作零。全队列训练预算 1,600 条、噪声复测 100 条，先行单/双 core 短程核验 50 条。

核验包括单核输入流与对应双核输入流的一致性、无额外阈值升高、患者通道次序、双核原生轨迹前缀与原 1 s 数据逐点相同、冻结 J 复算。独立读出核验已复现全部 25 位患者原 F 的两项相关。共享资源最多 24 个 worker、保留 64 GiB 系统可用内存；每 worker 单线程。新角度的可重建全局图仅保存在内存中，避免磁盘上累积大量一次性图缓存；这一存储差异需由双核前缀一致性核验通过后才放行训练。旧批次和其他任务不修改。

判断时先看同一患者的两项相关和两种 core 配置的配对改变，再看新噪声复测是否保留。若单 core 一项高、一项低而双 core 两项均改善，支持“双 core 更适合同时表达两类模板”的本模型配置解释；若单 core 同样两项高，则不能主张双 core 必要；若两组均差或结果随噪声不稳定，先核查优化覆盖与活动/事件支持，不能作生物学否定结论。固定 K=2 本身不证明自然双模态；32 次评估和一个优化重启不等于全局最优。固定每核面积同时改变总兴奋面积、输入人口和参数维数，故本比较不隔离纯 core 个数。完整模板相似性是在 FIT 选点后的描述性读出，不是新临床盲验证。
