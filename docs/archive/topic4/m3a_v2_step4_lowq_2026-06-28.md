## 朴素摘要（测了什么 / 怎么测 / 揭示了什么）

**测了什么**：Step 2/3 负的原因是单个 55ms 事件来不及耗深离轴 q。fork A 补这个：先**多次 kick 把 q 耗低（preload）**→ 网络安静（washout）→ 再**probe 一个标准 kick**，看 q 已经低了之后事件会不会受控离轴招募（returned + F_off↑）。两版：`qonly`（probe 时无刹车，问 q permissiveness 够不够）、`braked`（probe 时动态 g_K 刹车，问能不能控住）。

**揭示了什么——fork A 也 NEGATIVE（0/24 success），且原因结构性一致**：
- **preload 的 q 是双稳悬崖、没有稳定中间态**：kq 0.02→q~0.98、0.05→0.94、0.06–0.07→~0.91（都太浅）；**kq=0.08（sensitivity）直接砸到 q~0.18，0.10 分岔到 {0.89 或 0.02}**——**从 ~0.9 跳到 crash，中间 0.5–0.7 落不住**（saddle，不稳）。**够不到你要的稳定低-q 态。** 这是全场/全或无老瓶颈在状态空间的体现：事件全场 → q 到处一样耗 → 也造不出空间 q 剖面（spatial 退化成 uniform）。
- **唯一够到 q<0.7 的是 crash 态（q~0.02–0.18）**：probe → **off-axis 确实出现（F=0.635！R=1.0）**，**但 runaway**；**braked 也救不回来**（q≈0 时事件太爆，动态 g_K 来不及积累、刹太晚 → 与 qonly 结果几乎一样）。
- **浅 q（~0.9）**：qonly 没 off-axis（dF~0.01）；braked 要么没效果要么 **over-suppress（R~0.05）**。两头都不行。
- gate：q_off<0.7 只在 crash 态达到（pre-probe 仍安静），但那是 runaway 态——**"可用的稳定低-q regime"这个扩大前提不成立**（双稳结构决定的），所以没必要扩大，结论是结构性的。

## §1 M3A-v2 closed-loop 线收口（field-only 正 / closed-loop 负，原因统一）

| 阶段 | 结果 | 原因 |
|---|---|---|
| field-only probe | **sanity 正** | prescribed 持续 400ms 活动 → 宽去抑制+窄疲劳能造离轴 net 兴奋度优势 |
| Step 1 衬底鉴定 | **正** | 稳健局部沿轴自限事件存在（AR=4/nu=0.46，8/8 seed） |
| Step 2 q_I only | **负** | 事件 corridor-saturated（axis_reach=1.0），无沿轴扩张余地；强 q_I→runaway 非 off-axis |
| Step 3 q_I+g_K | **负** | g_K 是刹车（终止/缩小轴向），不重定向离轴；离轴 q permissiveness 没形成（q_off 没<0.7） |
| **Step 4 低-q (fork A)** | **负** | **q 双稳无稳定中间态**；off-axis 只在 crash(runaway) 出现，dynamic 刹车太晚、pre-built 杀点火 |

**统一结论**：**M3A-v2 空间慢变量是个 sound 的 field-level 载体（field-only 正），但当前 SNN 的事件时标 / 状态轨迹触发不了它**——衬底**全或无 / 全场**：给不出局部事件、给不出稳定中间低-q 态、离轴招募只在总去抑制（runaway）时出现而那里没刹车能控（pre-built g_K 杀点火、dynamic g_K 太晚）。**closed-loop 机制在当前 SNN regime 未闭合。**
