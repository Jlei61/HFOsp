## 朴素摘要（测了什么 / 怎么测 / 揭示了什么）

**测了什么**：Step 2/3 负的原因是单个 ~55ms 事件来不及把离轴 q 耗深。fork A 补这个缺口：先**多次 kick 把 q 耗低（preload，k_K=0 不建疲劳）**→ 网络安静（washout）→ 再**probe 一个标准 kick**，看 q 已经低了之后事件会不会受控离轴招募（returned + F_off↑）。两版：`qonly`（probe 无刹车，问 q 许可度够不够）、`braked`（probe 时动态 g_K 刹车，问能不能控住）。
**口径校正**：本 harness 测的是 **q-preloaded braked probe**（preload 只耗 q、不带 g_K；g_K 只在 probe 的 braked 版起作用），**不是** full-state（q+g_K 一起 preload）。full-state preload 是一个**有意未测**的变体（需要再加一组 k_K>0 的 preload）。

**揭示了什么——fork A 也 NEGATIVE（small 0/24、finer 0/12、合计 0/36 success）**，原因结构性一致：

- **在我们扫的 kq 网格里，preload 后的 q 没有落在"稳定中间低-q 带"——是一个 sampled-grid 上的 sharp transition**：要么停在**浅耗竭无效区（q_global ~0.87–0.98）**，要么直接掉到 **crash（q ~0.015–0.18）**；**0.5–0.7 这个中间带在我们扫的每个点上一个都没落到**。
  - small 实测：primary 衬底 kq 0.02→0.10 全停在浅区（q_axis 0.97→0.81）；sensitivity 衬底 kq 0.10 直接 crash（q_axis 0.0154 / 0.0157）。**同一个 kq=0.10，primary 还在 q≈0.81、sensitivity 已经 0.015**——转变很陡。
  - finer 实测（seed 1，补 0.06/0.07/0.08）：primary 三档都浅（q_axis 0.907/0.891/0.875）；sensitivity kq 0.07 还在 q≈0.868、kq 0.08 就 crash 到 q≈0.112——**0.87 与 0.11 之间没有采到任何点**。
  - ⚠️ 这是**采样网格上的观察**（"扫到的点里没有稳定中间态、浅区与 crash 之间转变很陡"），**不是**对 saddle / 双稳态结构存在性的证明。措辞锁在"sampled grid 中 sharp transition / no stable intermediate q band"。
- **唯一够到 q<0.7 的就是 crash 态（q ~0.015–0.18）**：probe → **off-axis 确实出现（F_off=0.635、R_area=1.0）**，**但 returned=False（runaway）**；**braked 也救不回来**（q≈0 时事件太爆，动态 g_K 来不及积累、刹太晚 → 与 qonly 结果几乎一样）。
- **浅 q（~0.9）**：qonly 没 off-axis（dF~0.01）；braked 要么没效果要么 **over-suppress**。两头都不行。
- gate：q_off<0.7 只在 crash 态达到（pre-probe 仍安静），但那是 runaway 态——所以**没有出现"可用的稳定低-q regime"**；在采样网格内结论一致，没有需要扩大的中间窗。

## §1 M3A-v2 要回答的三件事（为什么推 / 怎么推 / 怎么回来）

A 线 doc 的科学目标骨架（局部资源耗竭"推"、恢复项"回来"）放到 closed-loop SNN 里逐条对账：

| 问题 | 机制要的 | closed-loop 实测 | 判 |
|---|---|---|---|
| **为什么推** | 活动越多→局部抑制资源越耗→局部许可度升高 | **field 层成立**：field-only pilot 正（持续 400ms prescribed 活动把离轴 net 兴奋度推上来，σ_q>σ_K 造离轴优势，剂量可控） | ✔ 载体方向对 |
| **怎么推** | 慢状态把 core-localized 轴向事件推向**受控**离轴 / 全局招募 | **未达成**：closed-loop SNN 里**没有一次推到"受控离轴/全局招募"**；唯一出现 off-axis（F=0.635）是在 crash/**runaway**（不受控、returned=False） | ✘ 当前 regime 不闭合 |
| **怎么回来** | 恢复项（g_K/sAHP）把高许可度态拉回低许可度态、完成"发作样招募→恢复" | **方式不对**：g_K **能**把活动压回来，但走的是 **suppress**（终止/缩小轴向事件），**不是**"完成发作样离轴招募之后再恢复"；浅 q 时 over-suppress，crash 时太晚 | ✘ 只刹不"招募后恢复" |

## §2 M3A-v2 closed-loop 线收口（field-only 正 / closed-loop 负，原因统一）

| 阶段 | 结果 | 原因 |
|---|---|---|
| field-only probe | **sanity 正** | prescribed 持续活动 → 宽去抑制 + 窄疲劳能造离轴 net 兴奋度优势 |
| Step 1 衬底鉴定 | **正** | 稳健局部沿轴自限事件存在（AR=4/nu=0.46，8/8 seed） |
| Step 2 q_I only | **负** | 事件 corridor-saturated（axis_reach=1.0），无沿轴扩张余地；强 q_I→runaway 非 off-axis |
| Step 3 q_I+g_K | **负** | g_K 是刹车（终止/缩小轴向），不重定向离轴；离轴 q permissiveness 没形成（q_off 没<0.7） |
| **Step 4 低-q (fork A)** | **负** | 采样网格内 q 无稳定中间带（sharp transition）；off-axis 只在 crash(runaway) 出现，dynamic 刹车太晚、pre-built 杀点火 |

**统一结论**：**M3A-v2 空间慢变量是个 sound 的 field-level 载体（field-only 正），但当前 SNN 的事件时标 / 状态轨迹触发不了它**——衬底**全或无 / 全场**：给不出局部可部分填充的事件、给不出（在采样网格内）稳定中间低-q 态、离轴招募只在总去抑制（runaway）时出现而那里没刹车能控。**closed-loop 机制在当前 SNN regime 未闭合**——这支持"这条机制在当前 regime 不闭合"，**不支持**"慢变量机制总体失败"。
