# 核内burst周期分支连接与分岔 v5（2026-09-15）

本版回答上一版约1.3附近的均率陡升，以及burst、混合、两核高率周期支之间的连接。加密后的1.246附近属于同一稳定周期支的波形重塑；右侧确认周期轨道鞍结LP1与三个倍周期点PD1–PD3，并实际求得两段不稳定连接及三条2T子支。模型与v2–v4保持一致，不把降阶系统临界值当作原生随机SNN的分岔阈值。

完整科学解释、关键数值、适用范围与复现入口见[结果报告](../../../results/topic4_sef_hfo/core_branch_connections_v5_20260915/scientific_report.md)。图包括[单轴主图](../../../results/topic4_sef_hfo/core_branch_connections_v5_20260915/figures/00_connected_core_bifurcation.png)、[四状态合图](../../../results/topic4_sef_hfo/core_branch_connections_v5_20260915/figures/01_connected_bifurcation_four_states.png)及[九页PDF图册](../../../results/topic4_sef_hfo/core_branch_connections_v5_20260915/figures/core_branch_connections.pdf)。[数值验证](../../../results/topic4_sef_hfo/core_branch_connections_v5_20260915/numerical_validation.json)通过；候选图仍待用户目视检查。

本次“连接已确定”专指完成双向周期/波形一致性验证的两段右侧连接；较早J≈1.176区域的全部不稳定族，以及强不稳定连接上的所有次级分岔和远端吸引子并未穷尽。
