## 3. 固定项、控制量与 M 的处理

原生方程按实际离散更新核对，其连续记号为：

\[
I_{net,i}=I_{E,i}-Z_i I_{I,i}-\eta_M M_i,\qquad
\tau_Z\dot Z_i=\mathbf1[I_{I,i}<I_{th}]-Z_i,
\]

\[
\dot M_i=-M_i/\tau_M+\sum_k\delta(t-t_i^k).
\]

Z感受原始GABA电流阈值暴露，不是另外增加的事件计数器。改变Z只作用于E靶端抑制；均值与方差的投影要分别处理，不能把它替换为同时缩放I→E/I→I的全局q。

**主分析：冻结逐细胞 Z，M 保留原动力学。** 每条续接中Z固定为选定场；M按原参数继续响应。对同一初态和未来输入，改变Z所产生的差异，就是当前M反馈存在时的Z干预效应。相应数学对象称“冻结Z、含动态M的条件系统”，不能因冻结Z就把1秒M当成已消去的快变量。

**机制对照：同时冻结Z和M。** 仅在主分析找到可比较的自限/持续相邻两侧后执行，用两个实际M空间场交叉检查Z是否在固定适应电流下也能改变状态。它属于不同的条件系统，单独标注；不能拿它的临界点替代主分析。

冻结只停止对应状态更新，保留该状态对电流的作用：冻结Z后仍应用Z×原GABA电流，冻结M后仍应用eta_M×M。不能用关闭`use_z/use_m`替代冻结而同时删掉电流效应；需做一次实际应用检查。

**本次不以自主Z闭环预测为通过前提。** 主目标是冻结Z状态结构及对应关系；原自主轨迹用于提供实际场、观察点和通过时间。若以后要主张近似模型能自主预测何时跨界，需另行验证慢Z方程的闭合，本次不把提供原Z路径的回放称为自主预测。

3. **尾窗与分辨率**：承重两侧结果在延长后保留；若两种网格给出不同状态方向，资格不通过。空间百分比必须转换到共同网格和同样细胞权重后比较。
4. **轨迹连接**：另做两个源轨迹的真实Z(t)回放、M按原动力学演化、相同OU输入，每条≤12.5 s。原生与近似使用同一事件定义；需要分别报告最后静息结束、高率起点和空间扩大，不能只拟合9.870 s。该回放是已提供Z路径的条件预测，不是自主Z验证。

第1–3项决定“冻结Z对应资格”；第4项若失败，则不能把近似相图直接贴回原图③，需单独标为“静态条件匹配、动态路径映射未通过”。任何关键门槛失败均保留完整反例，不用平均分掩盖。

## 7. M3：通过资格后才进行的分岔候选图

### 7.1 坐标和可画范围

主图使用**沿实测空间Z路径的条件状态图/分支图**，不先开展Z_A×Z_B×Z_surround×M大网格。

- 原SNN部分：源Z时点作为有序状态索引，并同时标注全E、核A、核B的Z。必要时画横轴“Z场来源时间”，明确它是控制场的索引，不是续接中的演化时间。
- 近似部分：在两侧之间对逐细胞/联合分组Z场逐分量插值，定义λ∈[0,1]；延续时不能按平均Z重新排序、跳过回折或手工连接不同根。
- 仅当平均Z在该局部路径上单调且一一对应，才可用平均Z作为显示横轴，同时保留λ映射和空间场。数学平衡支与原SNN瞬时率、有限窗均值、振荡极值使用不同符号并写清观测量。
- ①–④只作原轨迹参考标记。它们不属于已验证的延续区间时放在单独轨迹条中，不外推成已算分支上的点。

### 7.2 确定性与随机部分的关系

理论系统固定Z，保留M、实际滤波和时延。去除OU随机创新时，明确使用何种确定性外部输入及Poisson扩散闭合，保留原名义均值；不能把“OU关闭”误写成“所有外部输入归零”。

先在承重两侧×两历史做4条10 s确定性近似轨迹，检查OU-on相邻状态是否仍有对应的确定性状态。若两者关系不成立，仅交付随机条件状态图和确定性诊断，不把确定性fold作为原SNN进入阈值。

### 7.3 类型判据与预算

- 固定点先检验物理范围和归一化残差≤1e-8，再用完整条件系统判断稳定性；saddle-node需分支折返、简单零模、参数横截与二阶非退化条件，进行差分步长核查。离散映射用+1乘子，连续表述用零特征值，不能混用。
- Hopf型候选需完整滤波、时延和动态M下的复共轭模态过界，核对过界两侧的其他不稳定根。未算第一Lyapunov系数及周期分支时，不命名超/亚临界；离散映射需标明对应术语。
- 原静态residual Jacobian只能用于求根和fold，不能代替延迟系统稳定性。局部shift-targeted谱找到不稳定根可证明不稳定，没找到不能证明全谱稳定；要标stable，须有经收敛验证的根计数/右半平面覆盖或等价保证。
- 若承重状态是周期活动而非固定点，分支图保留实际极值，但不将短轨道包络当作已延续的周期支。Floquet、周期折叠、SNIC、同宿或crisis留作下一里程碑，不在本轮强行定型。
- 本轮最多400个校正后的平衡支点、6个承重工作点的完整稳定性检验，至多一次局部步长加密；另允许2条同条件的网格/时间步敏感性轨迹。改变dt须保持物理延迟和突触脉冲面积，不同时改变工作点。

## 10. 方法依据与适用范围

- [Schuecker、Diesmann与Helias，2015](https://journals.aps.org/pre/abstract/10.1103/PhysRevE.92.052119)：有色噪声的时间相关影响LIF动态响应；不能只用静态率匹配判断振荡边界对应。本文只据公开摘要核对其方法主题，不据此宣称当前慢GABA参数满足其近似条件。
- [Moreno-Bote与Parga，2004](https://journals.aps.org/prl/abstract/10.1103/PhysRevLett.92.028102)：突触滤波时间尺度影响输入响应，支持把动态响应列为近似检查入口。执行Agent如实际采用其中公式，须读取适用推导和参数范围。
- [Kuznetsov，Saddle-node bifurcation](https://www.scholarpedia.org/article/Saddle-node_bifurcation)：平衡点合并、零模与非退化条件是类型证据；源参数相近或轨迹外观不构成类型证明。

这些文献是方法约束，不提供本网络的临界Z值。旧s≈0.337591及其他q/Hopf数值只用于历史对照，不能作为当前搜索目标或拟合约束。
