# Group-Event State v0.3.5–v0.3.6 架构阶段收口

**日期：** 2026-09-04  
**最终状态：** `OLD_GATED_RNN_LONG_STATE_ASSAY_INVALIDATED`  
**后继版本：** v0.3.7

## 1. 一句话结论

上一阶段没有得到“多小时状态不存在”的科学阴性；它得到的是一个更靠前、也更确定的结论：**旧门控 RNN 的有效训练记忆约一小时，不能拿来检验 6–8 小时的预测状态。**

## 2. 我们原本想测什么

我们想把一位患者连续的群体间期事件压缩成同一个随真实时间演化的状态，并检验它能否：

1. 预测未来 0.5–8 小时的事件负荷和条件传播结构；
2. 在已经知道一次事件如何开始后，解释它接下来招募哪些触点、何时停止以及频带如何表达；
3. 冻结后预测距发作的时间和下一次发作的早期空间场；
4. 最后再区分 IED 只是慢背景的读数，还是对未来状态另有反馈式依赖。

这四个问题仍然有效，没有因换架构而改变。

## 3. 旧仪器为何不合格

旧更新同时做两次遗忘：先按真实 `dt` 衰减，又在每个事件到来时把历史乘一次 `(1-f)`。因此事件越密，历史被擦得越快；标称 8 小时的通道在 E253 上实际只有约 0.92 小时的 90% 信用距离。

关键实测如下：

| 诊断 | 结果 | 能说明什么 |
|---|---:|---|
| 0.5 h 改为 2 h 反传窗 | block grammar 训练降幅 15.7% → 25.7% | 旧 `detach` 确实妨碍学习 |
| 旧门控、37.3 h 整链不截断 | 90%/99% 梯度在 0.92/1.65 h 内 | 仅移除 `detach` 仍测不到 6–8 h |
| 一行残差更新探针 | 90%/99% 延到 16.5/29.0 h | 长信用在工程上可实现；旧阴性是仪器限制 |
| 残差探针最大状态范数 | 8.08 | 本切片未发散，但不等于跨患者稳定 |
| 状态读出精确零初始化 | 第一步上游梯度为零 | 后继版本必须小非零初始化 |

这些均是 CALIBRATION/FIT 上的仪器诊断，不是留出期人体科学结果。

## 4. 哪些产物保留，哪些撤销

### 保留

- `H_N dynamic baseline`：它是多尺度事件率/事件概要的动态基线，不是隐状态；
- 按时间重训且冻结的成熟 contact-sequence decoder：它仍是 H2a 的事件内读出骨架；
- 长窗 exposure、gap、发作边界和 horizon-specific 留出修复；
- 梯度到达探针、null-event 反证和训练充分性诊断。

### 降级为诊断

- v0.3.5 shared producer 已完成的 13/18 cells；
- 读取这些 producer 的 evaluator；
- v0.3.6 full-credit smoke；
- 单行 residual update 的梯度结果。

### 不再允许

- 用旧 producer 的阴性写“没有 6–8 小时状态”；
- 把名义 `tau` 当成实测生理时间常数；
- 把 observer 在事件后的更新写成 IED 改变生理状态；
- 把长窗计数基线写成完整 `S_N`，或把它替代 `S_G`。
