# Group-Event State v0.3.7 修复后收口：白话版

**日期：** 2026-09-05  
**状态：** `ENGINEERING_ACCEPTED_SCIENCE_DEVELOPMENT_ONLY`

## 一句话结论

这次修复是到位的：上一轮没有真正训练起来的透明基线和事件内调制接口，现在都获得了真实梯度、发生了参数移动，并与模型臂通过同一训练充分性检查。修复后，**“模型没赢”已经不能再简单归因于对照没上场或接口没训练**。

科学结果则很克制：目前只看到一位患者 `E1077` 的连续背景 EEG 形成了时刻相关的未来事件负荷候选，以及一位患者 `E1125` 的过去事件数量对更远非事件背景有持续的方向性预测候选。**没有建立事件形态历史形成跨患者慢状态，没有建立该状态调制下一次群体事件传播，也没有建立向发作风险或早期发作路径的跨任务迁移。**

## 这次到底修好了什么

上一轮最大的问题不是 CT-DSSM 记不住，而是比较不公平：透明 `B_mark` 基线在多数患者上权重严格为零，H2a 的状态接口也常停在原点。修复后：

- 先完成 48 个控制配方单元，再冻结唯一控制配方；
- 再完成 264 个状态模型配方单元，控制和模型使用同一训练充分性标准；
- 每个新增臂都保留已经拟合的父臂，随机小初始化只负责启动梯度，不能凭空制造增益；
- H2a 保留冻结 decoder 的零调制精确对齐，但延长耐心并记录训练期间接口是否真的移动；
- 32 小时通道退出人体主分析，主记忆库上限为 16 小时；
- 6–8 小时结果同时报告互不重叠窗口数，不再把每五分钟一个的重叠行当独立样本；
- 每张卡记录源码哈希，旧代码产生的卡不能被新代码汇总；
- H3 的 observer state 与生理生成状态继续严格分开。

最终形成 220 张正式结果卡，所有队列完成、零失败；正式 development target 和 sealed partition 均未打开。H2b 的发作结局只在三套间期特征全部冻结后读取。

## H1：从间期事件和背景中，学到了慢预测状态吗

### 事件历史本身：目前没有

`E1125` 和 `E958` 表面上都能看到 event-state 相对透明历史的增益，但把整段状态换成一个固定水平后，固定水平反而更好：

| 患者 | event-state 相对 `B_mark` | 常数之外剩余 | 正确时刻优势 |
|---|---:|---:|---:|
| E1125 | +0.358 | -0.083 | +0.007 |
| E958 | +0.100 | -0.005 | -0.001 |

所以这里支持的是记录阶段或慢水平变化，不是已经识别出的时刻特异动态状态。逐事件 SSM 与五分钟慢链给出几乎相同的判断；加入背景流后，事件历史也没有稳定留下超出背景和常数的增量。

### 连续背景：E1077 是一位明确的 development 候选

E1077 的持续背景状态相对当前背景窗口改善 `+0.415`，常数解释后仍剩 `+0.053`，正确时刻相对错时状态再改善 `+0.017`，五个 seed 方向一致。这支持：

> 在 E1077 中，连续背景 EEG 含有跨窗口、时刻相关的未来事件负荷信息。

但它仍只是单患者 development 结果；它首先是 **background-driven predictive state**，不是 IED-history state，更不是已经识别出的独立生理状态。

### 错时对照的质量（2026-09-05 审阅补记）

三层（未来负荷、发作风险、生成模型）用的是同一条错时供体规则：在每个留出覆盖段内把行循环滚动一半。由此产生两件此前没有记录的事：

- **供体的时间距离不受控**，取决于该患者留出期被切成几段：E958 只有 3.25 小时，E916 是 9.33 小时，E1125 与 E253 是 12.0 小时，E1077 是 6.42 小时。因此**正确时刻优势可以在患者内读，不能跨患者比大小**。
- **错时臂有时比「把状态换成一个固定数」还差**，即它不是"无信息"而是"给了矛盾信息"，会把优势撑大。逐时间尺度检查：E1125 与 E253 四档全中，E916 三档，E958 一档；**E1077 一档都没有**。

另外，本队列**结构上无法构造「相差整整一天、时钟相位相同」的错时对照**：留出期最长的单段只有 12.8–24.0 小时，段内不存在相隔 24 小时的两个锚点。这一条要明写，免得被当成"做过且通过了"。

关于昼夜混淆，本轮做了直接检验：用三次谐波的时间基底拟合（只在 FIT 上拟合），只能解释背景状态方差的 **0.96%**（事件状态 −0.58%），而且**扣掉时钟成分后的残差状态仍给出正的正确时刻优势**（0.5 小时 +0.023、2 小时 +0.028）。所以 E1077 的候选**不是**昼夜相位造出来的。

## 时间尺度边界

留出段中，每位患者大约有 42–48 个独立 30 分钟窗、10–12 个独立 2 小时窗、3–4 个独立 6 小时窗、2–3 个独立 8 小时窗。因此 0.5–2 小时是本轮较可解释的范围；6–8 小时只能作探索，不能靠上百个重叠锚点制造精度错觉。

## H2a：状态会改变下一次群体事件怎样传播吗

目前没有建立。

冻结的 contact-sequence decoder 本身和状态入口都不是死的：把“当前事件未来答案”故意泄漏给状态后，四位患者的 grammar 改善为 `+0.271` 到 `+0.552`；所有真实状态调制支路也都在训练期发生了参数移动。

但真实、因果的事件前状态没有形成完整证据链：

- 多数患者的 contact、STOP 和 grammar 增益为零或为负；
- E253 虽有正确时刻优势，但相对静态或 `B_mark` 的基础增量不一致；
- E1077 的 H1 背景候选没有迁移到事件内传播 grammar；
- 允许间期形态损失更新 observer 的 joint sensitivity，也没有产生一个同时通过 H1 与 H2a 的模型。

因此这不是“读出头看不见”的阴性，而是当前四位患者中，**尚未发现能稳定调制下一次事件具体传播形态的事件前状态**。

## H2b：间期学到的状态能预测发作吗

目前没有支持，而且大部分问题是分母不足。

- 五位患者中只有 E958 有 11 次 held-out 发作，可作重复发作评价；其三套状态相对历史或背景的风险增量均接近零或为负。
- E916 只有 1 次 held-out 发作，只能描述。
- 其余三位不满足拟合或留出发作要求。
- 早期发作空间场与路径在 5/5 患者中均不可估。

所以正确结论是：**本轮没有建立 seizure transfer；早期 ictal field/path 仍是未检验，不是生物学阴性。**

## H3：过去 IED 会不会对后续状态产生额外影响

这一线使用独立 `Z_phys` 生成模型，不把 observer 看见一次 IED 后更新 hidden state 当作生理反馈。

合成仪器通过了无反馈假阳性控制、count feedback 恢复和 mark feedback 恢复；这只证明仪器能测，不证明人体存在反馈。

人体中出现两个层级不同的 count-history 候选：

- `E1125`：一步模型中，过去五分钟事件负荷对下一段非事件背景增加 `+0.009`，胜过六小时延迟对照 `+0.025`；持续模型进一步比一步模型改善背景 `+0.080`，且 2 小时和 6 小时尺度可估。**承重量是相对「完全没有这条边」的嵌套改善 `+0.089`（5/5 seed 同号）。**
  先前写的「胜过拟合错时暴露 `+0.757`」已撤回：那个安慰剂自己在留出期比「没有这条边」还差 `0.663`（同一批留出行、同一支撑），所以那个差额里约 88% 是安慰剂过拟合，不是真实边更强。安慰剂封底到「无边模型」后，该对比就等于嵌套改善本身，即 `+0.089`。四位患者中有三位的错时安慰剂出现同样现象（5/5 seed），因此这是系统性口径问题，不是单点异常。
- `E253`：一步背景增益 `+0.026`，持续模型相对一步只剩 `+0.0018`；方向一致但量很小，只能算弱提示。

没有患者形成可信的 mark-specific feedback。一步 mark 岭回归在 14/20 张卡上仍把最佳惩罚推到扩展网格上界，因此相关零值应读作“没有支持且部分仍难估”，不能写成已经排除形态反馈。

针对默认 M0 停在原点的 E1077/E958，又补了 20 张低学习率、长耐心卡。E958 的 M0 在两档学习率下都 5/5 真正改善了 INNER，但人体的未来背景效应仍约为 `-0.084`，所以负方向不是由 M0 没训练造成。E1077 在两档中仍回退父模型，因此只保留“没有正向候选、共同驱动模型未增加预测”的边界。

最安全的表述是：

> E1125 支持一个患者内、count-history-to-future-background 的持续方向性依赖候选；E253 有较弱的一步提示。它们尚不是队列结果，也不是干预意义上的 IED 因果塑形。

## 五层证据现在到哪里

| 层级 | 当前状态 | 白话解释 |
|---|---|---|
| 1. 额外预测信息 | 部分支持 | E1077 的背景流有时刻相关增量；部分事件模型增益只是常数慢水平 |
| 2. 事件历史记忆 | 未建立 | 事件历史在强基线和背景之后没有稳定动态增量 |
| 3. 时刻特异慢状态 | 单患者候选 | 仅 E1077 的背景状态同时胜过当前窗、常数和错时状态 |
| 4. 跨事件形态读出 | 未建立 | H2a 真状态阴性，但泄漏 oracle 证明仪器有灵敏度 |
| 5. 发作易感状态 | 未建立/多数不可估 | E958 有重复发作但无增量；早期发作场全部不可估 |

H3 不属于这五层的自然升级，而是单独的机制扩展。本轮只得到 E1125 的反馈式方向依赖候选。

## 阶段判决

v0.3.7 可以验收的对象是：

1. 双流连续时间 observer、透明长历史基线和冻结 decoder 的公平训练合同；
2. 单患者 E1077 背景驱动 predictive-state 候选；
3. 单患者 E1125 持续 count-feedback-like directional dependence 候选；
4. H2a/H2b/H3 的测量边界被明确，而不是把不可估或未训练写成科学阴性。

不能验收的对象是：

- 群体 IED 形态历史形成了跨患者慢病理状态；
- 该状态控制下一次 IED 的传播路线；
- 该状态能预测发作早期路径；
- IED 在人体中因果塑造了生理状态。
