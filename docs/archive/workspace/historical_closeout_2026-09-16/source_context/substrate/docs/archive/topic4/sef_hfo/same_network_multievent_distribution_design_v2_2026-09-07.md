## 1. 科学问题与本轮改变

一个固定双核网络，在固定噪声规律下，能否在不同事件中自主产生患者多种传播模式的参与和时序分布？TA/TB 是患者示例；不能要求一次事件同时拟合两种模式，也不能在两类事件之间换 core、参数、噪声规律或定向刺激。

本轮保留患者逐事件的 mask、rank、相对质心时差和真实空间信息。具体的“TB 从右下开始”“随后 SCL/左侧 ICL 参与”“TA 左上早”等规则只用于提名后的验证，不进入 loss、奖励、core 位置先验、初始化筛选或优化器排序。患者确有方差，所以验证比较模式条件分布，不要求每个事件照抄两个示例。

已完成的上一轮提示两种标签可以在同一网络出现，但具体路径仍不稳定。不能把这种差距预先归因于参数范围不足或双核机制不可能。本轮同时检验：通用分布目标是否更能约束每个网络的多模式行为，以及更广的连续参数搜索是否能在不注入具体路线的情况下改善验证。

## 3. 通用训练目标

令 `phi(e)` 为原有联合事件核的固定 512 维映射，输入仍是完整单事件的参与、masked rank、相对质心时间和空间矩。令 `c(e)` 为患者 FIT 聚类器的事件标签，`p_k` 为患者 FIT 的模式频率。模型所有可读的主要事件都进入目标，不因被判为 OOD 而删除。

每个模式使用质量敏感的特征：

`psi_k(e) = 1[c(e)=k] / p_k * [1, phi(e)]`。

第一个常数维度保留模式频率；后面的核特征保留模式内部事件分布。按患者 `p_k` 归一化，防止常见模式完全遮住另一模式；目标仍是患者实际比例，**不是强制 50/50，也没有右下、左上、SCL 起始等手写条件**。

对每个固定网络分别计算整体核距离 `D_global` 与等模式权重的质量敏感距离 `D_modes`。两个训练分量均采用每网络 **16 事件**的匹配样本量。对实际 N≥16，不只挑 16 次，也不重复抽样产生优化噪声，而是计算全部大小为 16 的无放回子集之距离的精确期望：

`D_m(X,target) = ||mean(X)-target||² + (N-m)/(m*(N-1)) * mean(||X-mean(X)||²)`。

这使用全部实际事件，比较的是相同有效事件数；它是代数恒等式，不是事件独立性或置信区间声明。N<16 标记 `INSUFFICIENT_EVENTS`，没有零 loss；任一训练网络不足时该条件不取得可排名总分，不能仅平均另一个网络。固定 24 秒后不自动延长低产候选直到“等到好事件”，数据不足也不直接称为机制失败。

最终目标：

`L(theta) = mean_network [0.5*D_global/a_global + 0.5*D_modes/a_modes]`。

`a_global/a_modes` 为 CAL 的 128 次、每次 16 事件患者抽样距离中位数，在查看 SNN 新分数之前确定。按随机顺序取完整 CAL 块，事件不足 16 时继续合并下一个块，再无放回抽样；保留稀疏块并记录使用的块。0.5/0.5 是本版预先声明的算法选择，不根据已有赢家调权重。

不能将这一目标描述为完整波形拟合：单质心仍会丢失多峰及事件内部动力学。时间分辨的路径在验证侧检验，验证失败不得改名为已恢复。

## 4. 11 个连续参数与固定项

| 参数 | 范围 | 实际含义 |
|---|---|---|
| X1、Y1、X2、Y2 | 各 0.75–19.25 mm | 两核在整个平面内自由寻找位置 |
| node_gain | 0.5–1.4 | 带符号 VTH 空间偏移的整体增益；不是绝对阈值 |
| E→E 权重 | ×0.8–1.2 | 实际兴奋到兴奋突触增量 |
| E→I 权重 | ×0.8–1.3 | 实际兴奋到抑制突触增量 |
| I→E 权重 | ×0.8–1.2 | 实际抑制到兴奋突触增量 |
| GABA 衰减 | 12–28 ms | 上升时间与 jump 固定，积分剂量不匹配 |
| EE 权重轴角 | 参考轴 ±45° | 与 core 连线不绑定 |
| EE 权重轴比 | 1–3 | 各向同性至较强各向异性 |

这些是工程搜索范围，不是患者参数的置信区间。保留 1,499 个 core 节点、双核不相交、中心距离≥4 mm、每核至少分配总节点的 25%；没有沿患者轴摆放、左上/右下端点或 interior 优先约束。历史手放位置只是显式比较条件。

现有执行器做的是**固定连接图上的 EE 权重重分配**，每个 E 目标的 EE 总输入先守恒，再施加全局 EE 增益；不会重抽图的边与时延。图生成参考轴和 AR=2 固定。因此角度/轴比结果只支持“现有图上的有效连接权重空间分布”，不能冒充任意连接生成机制的充分搜索。更大的角偏转不能创造原图不存在的边。

固定 Z/M 关闭、I→I ×1、全局/空间 OU 规律、E/I 数量、膜与其他突触时间常数、延迟和接触点读出。暂不同时开放所有噪声与连接长度，避免本轮失去可解释性；这不表示这些参数没有作用。

## 5. 有限预算搜索与自动衔接

1. **物理 canary**：从首批条件中取历史基线及两个随机条件，各跑原定 24 秒、seed 2511，检查实际参数、读出、原生场、内存与输出时长。完成后复用这些正式任务，不重复计费。工程失败先修执行器；真实 runaway 保留物理失败状态，不能自动调弱参数直到通过。
2. **首批 48 条件**：两个人口各 24 个。共 42 个新 scrambled Sobol 11 维点，使用两套独立的随机化序列；另 6 个历史对照平均放入两组。实际 master seed 已落盘，不在重启时重抽。每条件共用 seed 2511/2512，各连续 24 秒。
3. **16 个自适应条件**：每个人口生成 8 个 DE/rand/1/bin 后代，F=0.6、CR=0.8，在归一化参数空间操作，越界反射；几何无效重提案。父代索引/随机数/候选实际值全部记录。仅使用训练 loss 做替换，不读取路径、GIF、方向验证、PROBE、覆盖或 OOD 表。
4. **冻结提名**：各人口按训练 loss 提名前两名，合计最多 4 个不同条件。相同条件去重后依次递补；不足四个可估计条件如实报告，不补开额外轮次。排名相同时按 candidate_id；不人工挑更像 TA/TB 的动画。
5. **自动接验证**：提名文件写定后，对最多 4 个候选和 3 个历史基线去重，使用本任务未用于搜索的种子 6101–6104，各 24 秒，共最多 28 次仿真。执行前核对种子确未在本任务使用；若已用，则先在清单中分配新的未用 seed，不能运行后换 seed。

总上限 **64 条件 ×2 训练网络 =128 次训练仿真，另最多28次确认，共156次24秒仿真**。这是一轮有界的 11 维搜索，不能称为全局最优证明。没有自动再开 generation、自动改 loss 或自动进入 Fig. 5。

## 6. 验证真正看什么

所有指标按固定网络单独给出，再汇总跨网络结果。比较时按实际样本量作患者块自对照，并保留不确定性和条件分母。

- **一般分布检查**：患者模式支持/覆盖、OOD/uncertain、模式混合比例、逐模式逐通道参与、共同参与、有符号顺序与时差、模式内部散布。没有自然一一对应的患者/模型事件，不能直接对两组 labels 算 ARI。
- **具体路径检查**：TB 示例所在模式右下早期招募的比例，中部先于两端的比例，随后 SCL 和左侧 ICL 的相对时序；TA 类对应的上方/左侧先于右侧。沿用本次四区域诊断定义，但它们只在提名后打开。患者自身也有中部较早的事件，不把其中每一次判为不可能。
- **区分时间含义**：当前区域指标基于质心，不能把最早质心写成起燃位置。补充时间分辨读出时，保存每个参与接触点正包络累计质量到达 10%、50%、90% 的时刻及完整包络；10% 仅称“早期包络时间”，不冒充首次神经元放电或因果波前。使用各自既有背景校正，窗口与掩码固定，不能按候选换阈值或时间拉伸。
- **患者原始事件小包**：从 PROBE 各患者模式预先随机选 32 次，共 64 次，尽量跨至少 4 个块，每块最多 8 次；选择只使用身份/块/冻结标签，不使用方向或像不像。每模式另存固定顺序的 32 个备用 ID，原始文件缺失或明确读出失败时按顺序替补并保留原因。先追溯 training contract 的原 producer，重建原始 event ID/块/packed window/通道映射；不能只凭相近 rank 或四舍五入后的相对时间猜配对。公开 Fig. 2C 两示例另列，不能取代这个患者变异小包。
- **原始场与多事件 GIF**：每条件预定最低确认 seed 的全部检测窗口按时间顺序展示，包含排除拟合的窗口、原始时间间隔和整段24秒活动概览；保留全部确认种子的事件表与原生数组。原生场不用 readout 平滑；患者几何上的模型投影按通道身份标注，不能把插值场当作患者连续组织真值。

若人口级原始事件身份/波形暂不可恢复，继续已授权的仿真、逐点质心分布和全模型影片检查，但将时间分辨患者验证标为未完成；只靠两个 GIF 示例不能放行最终基底。

## 7. 里程碑判定与失败解释

**M0：设计与离线目标资格。** 已完成8项检查：匹配样本量期望与枚举相等、低样本不填零、相同 pooled 事件分数相同、同网络模式缺口可识别、顺序打乱可识别、时差拉伸可识别、绝对时间平移不影响评分、不足的网络不能被其他网络遮盖。患者对照的混合网络损失中位数0.668，按网络隔离模式5.536，顺序打乱3.780，时差拉伸1.516。这仅验证目标实现及部分检测能力，未证明新模型有效或已校准临床等价。

**M1：本轮搜索与固定提名全部完成。** 交付128次以内训练任务的完整状态、每网络分数和16个后代的出处。凡基于具体路径选择候选，或改变每事件输入来凑模式，该里程碑不通过。

**M2：提名后验证完成，返回科学审阅。** 交付新种子上的各模式分布、患者小包、全事件GIF、关键残差与患者匹配样本量参考。出现以下情况分别处理：

| 结果 | 判断与处置 |
|---|---|
| 训练改善且各确认网络中出现患者相容的多模式路径 | 保留为待审基底；仍需用户目视及完整证据验收 |
| 训练改善，但仍大量中心起始/关键区域缺失或顺序不符 | 训练目标下有改进，传播验证未恢复；不把具体路线加进 loss 补救 |
| 训练改善只在旧 seed，确认网络消失 | 随机性/优化泛化问题；不归因于患者路径定义错误 |
| 有事件但不同起点/多维参数都反复保留同一残差 | 为模型容量或观测表征缺口提供证据；另做有针对性的区分实验，不机械扩大同一搜索 |
| 事件不足或患者模式支持不足 | 可估计性不足；不声称模式在机制上不可能，也不通过验收 |
| runaway 或工程失败 | 分别记录物理失败与运行失败；不能混成低拟合分数 |

当前没有完成多指标联合等价门槛校准，不能给某个 q95 自动通过即宣称生理复现。M2 的完成标准是完整证据可审阅，不是必须找到正结果。结束后停在审阅点。
