# 全局慢状态 s：命名与患者时间序列约束的 drift–diffusion 方案

状态：DESIGN_READY_NOT_FITTED。用户提出改名与患者事件间隔约束；本次没有更改或重跑 R1 的物理模型，没有估计新的漂移参数。

同日设计澄清：间期事件是持续状态下由 SNN 产生的带标签读出，不触发全局 s 重置；DDM 的候选越界与重置对象改为临床发作。发作相关重置属于下一层待检验假设，不是 R1 已有机制。本修订取代此前把首次通过模型列为间期事件时间基线的安排。

## 1. 命名与父版本

从本次讨论开始，全局一维慢状态统一写 s(t)；Z/M 专指独立分支的 per-neuron 抑制资源及相关慢变量。R1 的模型、数组和结果不因改名改变；旧归档 `state_z` / `z_at_detection_start` 等键作为历史 schema 保留，新的图面改用 s。后续实现采用 s 的接口并显式记录旧字段映射，不批量改写冻结 worker。

物理父版本仍是 R1 历史手放双 core 在当前 v2.1 引擎的基底。core 位置、大小、每神经元阈值、图、连接倍率和时延均不动；不采用之前被排除的最佳评分候选。s 通过固定的 I 群空间投射与幅度 0.2 作用于网络，资源 Z/M 仍关闭。

## 2. 目前过程已经是漂移—扩散

R1: ds=−s dt/(5 s)+sqrt(2/(5 s)) dW。回复与噪声在同一时间持续作用；不是先回到基线再开始扰动。无噪声时指数回归，有噪声时围绕零波动。当前参数手工指定，未由患者拟合，整条轨迹在 SNN 启动前产生，不接收网络反馈。

下一版先写成 ds=κ(μ−s)dt+σ dW，估计 μ、κ>0 和 σ>0；保持 s→局部 I 的投射和增益固定。R1 对应 μ=0、κ=0.2/s、σ=sqrt(0.4)/sqrt(s)，稳态方差为1。必须报告 κ、σ 的不确定性；5秒不是患者估计值。

间期阶段保留持续 s(t) 和由 SNN 自己产生事件的机制。s 的正负对应两类响应的不同发生概率，不是到达正负阈值才各产生一次间期事件。第一版不把间期事件加入 s 的跳变或重置项；SNN 本身的电压、突触和不应期仍按原方程响应事件。若未来加入网络到 s 的连续反馈，应单独立版本，不与全局重置混淆。

经典 DDM 的候选首次通过对象在本方案中是临床发作，而非每次间期事件。发作起始是候选进入发作状态的边界；发作结束及发作后恢复才可能约束返回间期状态的分布，二者不能用同一个无持续时间的瞬时重置代替。当前 R1 没有实现这部分动力学。

## 3. 间隔能约束什么

需要推断的是连续记录内带标记的事件过程 {(t_k,m_k)}，而不只是打乱后的间隔直方图。总发生强度 λ_total 控制等待时间，分模式强度 λ_m 控制传播类别；只用间隔可以丢失 s 正负的信息。R1 五点的合格事件总数恰好为 s=−0.5/+0.5 各7个、s=−1/+1各5个（均为3个噪声重演的描述性合并），但模式偏好不同；这说明至少在当前有限样本中，总数不能替代模式信息，不能据此宣称发生强度严格对称。

分解 λ_m(s,H)=λ_total(s,H) p_m(s,H)，其中 p_m 是已发生事件的模式条件概率。状态符号只提供偏好，不直接指定标签；当前正 s 倾向 M0、负 s 相对倾向 M1 的映射以冻结观察器和实测响应为准，不要求概率达到0或1，也不保证单调性。训练目标是整个带时间标记的模式序列；时间与标签两部分均需报告预测质量。为区分仅解释总事件率与解释模式选择，必要对照保留相同总率模型，只令模式概率不依赖 s。按实际时间滞后检查模式相关，不只按事件序号检查。

统计近似采用 λ_m(s_t,H_t;θ)，其中 θ 为冻结 SNN/投射，H_t 包含必要的事件历史或恢复状态。给定潜在轨迹的标记点过程似然含 sum_k log λ_mk(t_k)−integral λ_total(t)dt，实际推断需对未观测 s 轨迹积分，不能把任意挑选的潜在轨迹当作已观测事实。中间的 λ 只是为估计构建的响应近似，必须检查其对保存 SNN 时间序列的适用性，不能因点过程模型拟合成功就宣称 SNN 拟合成功。

固定当前 s→I 增益及空间图样来锚定状态尺度，不同时自由估计潜变量尺度、输入增益和触发阈值。若不同 μ/κ/σ 给出近似相同预测，报告可辨识的组合或范围，不输出虚假的唯一物理参数。

## 4. 患者数据入口与时间轴

先以当前建模患者为单位，恢复全部可用连续间期记录和群体事件时间；模式不确定的事件保留为未标记事件，仍约束总强度。不把单触点 HFO、群体事件、只留双杆的传播子集混为同一事件过程。

现有传播训练 artifact 为 results/topic4_sef_hfo/data_driven_dual_core_interictal_identifiability/objective_qualification/patient_training_contract_v1.npz：包含30049行逐接触时间及块ID；冻结评估器 FIT 是其中19770行。它不是已校验的完整观测时间线：本轮只检查键和维度，未证明其保留全部原始事件、零事件记录或完整块起止。必须回源核对事件过滤、时间单位、块边界和事件锚点后再形成间隔。

时间轴保留观测起止、无事件暴露、记录缺口、发作及排除段；不跨缺口计算一个长间隔。记录断点处的截尾纳入统计，不把首个已观测事件当作从零时刻开始等待。短间隔还需检查检测合并窗口及重叠排除造成的观测死区。已知记录/睡眠变化先作分层或外部协变量对照，避免全部归为内在势阱。

全部可用记录参与时间建模方案，但先按完整时间块做训练与预测验证，选择完成后才能全量重估；验证块不得事后重新命名为未见数据。既有 PROBE 是已重复使用的开发数据，不作独立临床验证。

## 5. 有界执行顺序及判断

1. 时间轴审计：输出逐事件 timestamp/模式概率/记录ID/资格与所有观测区间；画间隔分布、时间上的事件率、间隔串行相关及同类/切换条件间隔。先确认此前的模式聚集是否仍在完整事件流存在。
2. 低参数比较：共同训练/验证时间块上比较含短期恢复的无慢状态基线与持续单阱 OU 驱动的标记点过程，并检查模式概率不依赖 s 的对照。短期恢复属于 SNN/观察历史，不意味着重置全局 s。先不引入任意双阱势场、每模式初始向量或神经网络漂移函数。用合成恢复检验现有事件数和观测缺口是否允许识别参数；首次通过与重置仅留给后续发作假设。
3. 连接 SNN：对冻结基底的状态条件总事件率和模式率建立有不确定性的响应估计，检查瞬时状态是否足够，还是必须包含短时历史。当前每条件1–6个合格事件不足以把响应曲线当成精确已知函数，不能无误差地反推患者参数。
4. 在上述条件成立后才拟合 μ/κ/σ，再把这些参数放回相同 SNN 做独立噪声验证；不依据患者实际事件时刻逐事件 reset、kick 或强制切换模式。
5. 验收同时看预测时间似然/生存分布、窗口计数、间隔相关、模式条件间隔与模式聚集，并保留原有参与和毫秒传播质量。只恢复间隔，称为时间统计恢复；只恢复标签，称为模式偏好恢复。

若 OU 已能预测，停在低参数模型。只有稳定、可重复的预测缺口支持时再立版本加入正则化非线性漂移；若主要缺口是事件后的短期抑制，优先比较恢复/事件历史项，不能自动解释为双稳态。若响应尺度、观察过程或多个参数仍不可辨识，先报告缺口，不能扩大参数空间掩盖问题。

## 6. 发作作为候选越界与恢复：独立后续层

假设分开检验：H1 是持续 s 调制间期事件的模式概率；H2 是发作对应慢状态进入特定区域；H3 是发作使返回间期后的状态发生重分布。H1 成立不意味着 H2/H3 成立，发作前后统计改变也不直接证明硬阈值越界。

先从可靠临床标注取得发作起止、连续观测及发作后恢复段，检查本患者是否有足够的独立发作与可用前后数据。恢复缺失或事件标记跨状态不可靠时保留缺口，不把每个记录块开始当作临床重置。首轮间期拟合对不可观测的边界状态积分，不在每次间期事件或记录断点将 s 设为零；跨发作段不强行要求原 OU 已经适用。

若数据支持独立后续试验，先比较持续过程与发作后状态分布发生改变两种解释；同时考虑总事件率的发作后恢复，以免把观察率变化误归为模式状态重置。用发作标注提供边界的分析属于条件分析。只有用发作前数据预测后续边界并在保留发作上验证，才能讨论发作时刻的预测；不能把已知发作时间强制重置后的拟合称为自主发作生成。

当前 s 表示两 core 的相对抑制准备程度，投射有界并近似守恒总 I 背景输入；它没有被定义为整体发作易感性。因而正负极值不能直接指定为发作边界。若相对模式偏好与发作风险不能由同一维解释，应先报告单维假设受限，再提出独立的整体易感性维度；本版本不自动增维或添加发作阈值。发作期间动力学与发作后返回的实现仍需单独方案。

## 7. 文献支撑及适用边界

- Ditlevsen & Lansky (2007), https://pubmed.ncbi.nlm.nih.gov/17995025/ ：在明确的首次通过模型假设下，从事件时刻估计扩散过程参数具有方法学先例；不自动证明群体 IED 是同样的首次通过过程。
- Genkin, Hughes & Engel (2021), https://www.nature.com/articles/s41467-021-26202-1 ：从随机点过程观测反演潜在 Langevin 动力学，需要显式建模观察机制和初末状态；这是持续隐状态方案的直接方法参考，不是 IED 数据上的验证结果。
- “Interictal epileptiform discharges show distinct spatiotemporal and morphological patterns across wake and sleep” (2022), https://pubmed.ncbi.nlm.nih.gov/36483575/ ：Epilepsiae 的 IED 率和空间分布受到睡眠/清醒及脑区调节，支持把外部状态变化列为解释对照。
