## 2. G0：首臂前的定点定义与局部修复

建立独立入口、配置和结果目录，建议 `scripts/run_group_event_state_v040.py`、`config/group_event_state_v040_first_package.json`、`/data/hfosp_group_event_state_epilepsy_state_v040`。这些路径仍待实现，不能直接运行旧队列冒充新合同。数据检查、简单参考与发作支持从开始即可并行，G0 不是全局方法认证。

### 2.1 支持、短历史及训练截止

按科学 spec §5.1 输出逐 query/字段的观察区间、已发布曝光、支持末端、最后 IED 时刻、episode/reset 年龄，区分安静、部分可读、整段未发布及 count/marks 异步。窗口选择只读两个 INNER 的预定时间元数据：0.5 coverage、H/2 支持年龄、每个 INNER 80% query 的规则；不读效果。

本轮 INNER0=12、INNER1=24 个主时距 query，30min coverage 中位数为 0、0.083，故 **2h 替换主短臂，仍为五臂**。INNER0 的 2h 支持也弱，必须保留局限。输出全配对支持及 memory_support，后者限定较早历史归因；它不要求有 IED，充分观察到的安静也是信息。较早/近期事件数分层另列，不能靠曝光声称整合了多条 IED。

训练截止同时约束输入、标签、scaler、模板和统计量的实际 release 与全部原始依赖；现有包结束初筛需补检查。晚发布目标可以事后评分，不能提前拟合。若边界修复改变支持，在首臂前重算并冻结全部种子的 query/target/mask 与 H_short，不按新效果改窗。

### 2.3 数值及接口检查

定位已有极端 NLL：拆均值残差、尺度/尾部、单位、曝光、MC 和参考拟合；不剪 final score，不留下未拟合基线制造 rich 增量。只阻断依赖故障的比较。

必要检查限于：不同事件数/缺失字段下的权重；小集合枚举归一；训练截止后 release/右上下文不参与拟合；完整重放与分批查询；时距顺序不污染状态；公共随机流不随批大小改变。独立抽样按 MC 精度比较，不要求逐位相同。

每次更新用当前权重无梯度重建旧前缀，再在登记后段展开梯度；m/P/c、事件记忆和历史核都遵守边界。不得跨权重版本携带 stale hidden 假称完整重放。保留 2h 梯度与既有恢复修复，不增 8h 全反传或大型压力测试。

## 3. G1：五臂首种子，针对性诊断并行

优先完成 S_marks 的两个 INNER 和最终重拟合以释放 G2；其余四臂、合成与 D-local 按资源并行。

### 3.1 明确采用 25 次主体拟合

只用 seed=20260906 的两个 INNER 冻结每臂配方：5×2=10 次。三个 seed 各最终重拟合一次：5×3=15 次。**主体共 25 次，不是 45 次；后两个 seed 不重做 INNER。** 这检验固定配方的优化重复性，不是整个选模程序的重复性。

避免拼接未经验证的步数/调度：同一臂两条 INNER 轨迹使用共同评估网格和共同 LR 里程碑；数据、模型、优化器和状态仍完全独立。

1. 初始 network lr=1e−3、dynamics/covariance lr=3e−4，AdamW、有效 batch 和梯度裁剪沿用修复配置；每 50 步两条轨迹都评价 §9.1 的组织 J，含第 0 步。
2. 两条轨迹均到达该步后，以两个 J 等权均值驱动共同 Plateau：容限 1e−3，连续 6 次未改善则 lr×0.3，最多两次；两次降率后连续 8 次未改善停止。上限 3200，边界仍改善才延至 6400。
3. 在实际共同评估点中选平均 J 最低的步，同分取较早步；保存到该步的共同 LR 里程碑。禁止对两个 argmin 或不同 LR 历史取中位数合成配方。
4. 三个最终重拟合固定选中步数/里程碑，在各自合法最终 FIT 重估 scaler/trait；OUTER 不选 checkpoint。选中 0 步则产生初始化/未学习输入驱动结果，不能称学习。

这只是旧配方协调方式的局部修复，不增加候选模型。两条轨迹可交替执行并保存，不要求同时常驻一张 GPU。某个 INNER 的组织目标不可估时，单列配方选择依据不足，继续独立有效任务，不从 OUTER 补造选择依据。数值修复后重跑另计。

### 3.2 两个合成任务的实际范围

每任务 3 个独立数据实现，每个只拟合 S_stats、S_marks、S_marks-short 三臂，一个优化种子，共 **18 次**小型拟合。它们直接校准状态 rich 增量及较早历史贡献，不声称校准了 B 参考或整个人体双 INNER 程序。

每实现用独立时间 FIT/验证/测试段，一次拟合按同一组织评分选 checkpoint；复用概率头、优化起点与 3200/6400 上限，不做合成搜索。这是单验证段的定向能力诊断。条件零对实际可读 H_stats/C 成立；组织阳性将标准化旧 marks 系数固定为 1、目标独立噪声标准差为 1，旧信息在 H_short 外且已发布，近期 rich 与其独立。直接使用合法旧汇总的 oracle 无需新拟合。若实现只注入近期信息，不得声称长历史校准。详细生成合同见科学 spec §9.2；少量实现不支持错误率或小效应功效声明。

### 3.3 D-local 必须给字段结论

FIT 内按时钟/记录覆盖预定小段，逐字段列出 count/参与、事件结束、delay/同步组、band_ratio、signed_xlag、delay_iqr、波形描述的左/右上下文、block/200s 依赖、最早可验证 release、处理时延和 producer 函数。

每字段明确：已有有限上下文且可验证；需局部重算并列具体步骤；当前不可满足并列缺少来源。不能只交“仍需审计”。可重算字段完成同原始时间比较，保留事件集合变化；不只取两版交集。缺完整低延迟版本不阻断合法 D-delayed。

## 4. G2：S_marks 首种子冻结后立即接下游

仅依赖该 producer 及消费者自身接口，**不等待其余四臂完成或 H1 阳性**。先完成首种子链，再优先投入额外优化重复。

- H2a-A：C、C+H、C+S、C+H+S 四个条件集合 head，事件等权；合法间期训练/验证。沿用上限 400 步、每 20 步验证、patience=6、AdamW lr=0.01/weight_decay=1e−3，显示第 0 步与真实权重变化。
- 正确时刻：固定 C+H+S head，按 spec §5.3 的 FIT 供体匹配，只换状态，不改 recipient C/H、目标、K_c。无供体局部不可估，分布外限制单列，不重训 producer。
- H2a-B：同一真实前缀有/无 m24 两个消费者；next-contact/同步组、STOP，teacher-forced/free continuation 分开。G0 复制一个既有合格 decoder 的实际配置及预算，不开所有 legacy 变体；无合法前缀只阻断 B。
- S-A：固定 Ψ 的有符号逐坐标变化和整体描述量；率增量/方差为辅助。给标准/近期率匹配、共同病例、相同 query 支持，不能挑 latent 轴或用发作选 producer。
- S-B：复用 H2a-A head；EEG 起点前≥5min 的合法 query，临床 0–10s 宽带空间，community 内 Spearman 为主，不新增发作监督 head。
- S-C：风险支持资格表；缺完整人时不拟合，不影响 S-A/S-B。

H2a-A 固定一分钟前查询接口，不复制旧四时距×四 head 矩阵。初始化选中时消费者仍可运行，但必须区分未学习输入驱动表示与真正静态 trait。

## 5. G3：两个固定配方重复与汇总

补两个登记种子的五臂最终重拟合，每份 S_marks 冻结后导出同样消费者。query/目标/mask/H_short/配方不随 seed 改变；优化、采样和评价随机流分别记录。种子不当患者。

输出 spec §5.2 五个差值：rich 历史输入、state rich、表示保留、较早历史、冻结状态条件增量。每项同目标/字段/物理支持；历史另给 memory_support 和较早/近期事件分层，不把“旧率+近期 marks”升级为“旧 marks 整合”。

H1 主效果窗口等权，配套形态事件等权、逐族和缺失支持；H2a 事件等权。权重与不确定性单位分开：开发汇总默认 2h 配对时间块，另给 4h 块敏感性及逐日结果，不宣称已经独立；发作按簇/日期处理。约 3 个测试日不能提供稳定人群区间，不靠增加 bootstrap 次数制造精度。

## 6. 拟合预算和任务分母

| 任务 | 计划次数 | 解释 |
|---|---:|---|
| 人体 INNER | 5×2×1=10 | 每臂两套独立轨迹、共同选模调度 |
| 人体最终重拟合 | 5×3=15 | 固定配方；主体合计 **25** |
| 合成 | 2×3×3=18 | 单时间验证段，独立于人体主体 |
| H2a-A | 4 head×3 S_marks seed=12 | 如 C/H 头完全一致而复用，记录实际减少数 |
| H2a-B | 有/无 state×3 seed，最多 6 | 合法前缀才运行；既有 decoder 实际预算 G0 冻结 |
| S-A/S-B、wrong-time | 0 个新 head | 冻结函数/已有 head，仍有运行成本 |
| 支持、D-local、直接 oracle、评分核查 | 无新增训练 | 单列处理成本与状态 |
| 数值修复重跑或必要参考拟合 | 另列实际次数/原因 | 不暗含在 25/18 内，不无限等阳性 |

上述是次数，不是时长承诺。首臂实测稳态吞吐、最长前缀、峰值内存与消费者成本后形成机器任务表。每 GPU 一个训练进程；共享 INNER 调度可保存/恢复交替执行，不堆积训练模型。预算停止照实记录，数值失败、不可估、依赖阻塞及未运行保留在分母。
