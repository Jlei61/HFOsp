## 1. 一句话判断

**建议接收可追溯的运行产物与训练诊断；报告须大修后才能收口，原始科学闭环仍不能验收。下一版应恢复“事件前状态如何解释患者内事件表达”的主问题，不能继续把当前两小时次数/粗空间代理任务当作全部科学目的。**

## 3. P0 / P1 关键问题

### P1-1：充分性结论遗漏了真正承重的对照阶段

逐阶段结果如下：

| 阶段 | 降 LR 后平台停止 | 预算停止 |
|---|---:|---:|
| 背景父模型 | 47 | **73** |
| 事件残差/状态 | 118 | 2 |
| 重拟合常数 | 45 | **75** |

因此，148/240 个背景与常数阶段仍以预算结束。预算结束本身不证明没收敛，但也不能作为收敛证明。状态阶段的 INNER 平台，可能来自验证过拟合、输出初始化回退、读出饱和或优化失配。代码自己明确写 `NOT_ESTABLISHED_BY_STOP_REASON`，报告结尾却说“训练充分性这一条解释被排除”。

33/120 个事件阶段最终选择初始化；固定历史读出的大面积 Tanh 饱和也没有解除。容量已实际扩大过（状态 16/32/64、读出隐藏层 32/64/128），不能再说“没试大网络”；但退回初始状态或读出饱和时，容量试验的判别力很弱。

**怎么改：** 接受“排除了部分完全没训练/批次错误/简单截断问题”；撤回“排除训练不足”。先用 FIT-only 特征缩放和非饱和的线性/广义线性读出建立可靠基线，延长仍在改善的承重臂，检查完整阶段。不能用给所有臂同一个步数代替公平优化。

### P1-2：M1 没按新合同实现触点主检验，不能验收为真阴性

新合同要求主适配器为线性/低容量、直接优化触点身份，STOP 单独判，且 event-only 与 B+E 做同家族配对。实际 `run_group_event_state_v0310_m1_transfer.py` 调用旧 `train_group_event_state_v039_contact_transfer.py`：

- 适配器是隐藏宽度 8 的非线性头；优化与 INNER 选择目标都是 **subset NLL + STOP BCE**。
- 仍为固定 LR、旧 patience，未接入新 LR 充分性流程。126 个下游阶段中 **44 个预算停止**。
- 两种 source mode 都在“前缀＋背景”的父模型上加状态；不是 event-only 状态的独立事件主线检验。
- 两种 source mode 分别选家族，9 个患者×seed 配对中 6 个家族不同。
- 18 个导出中 **11 个是 F**，其 `state == initialized`。它们不能承担“训练后的跨事件状态缺少信息”的分母。

复算 exact-next-subset 的 18 个导出：相对父模型 **1 正、13 零、4 负**；相对父模型/重拟合常数中更强者 **1 正、7 零、10 负**，中位增量 −0.00928。正式正文中的“1 正、14 零、3 负”以及转述的“17 零、1 负”均不对应这组完整数据。见[逐状态对照表](/data/hfosp_group_event_state_v0_3_10_independent_review/contact_comparisons.csv)。

前缀/常数/功能输出能改善，只证明那些输入和任务下能拟合到一部分信号；不能校准“冻结状态以当前强度编码触点身份时能否检出”。缺少同一状态通路、同一支持和同一训练流程的已知效应注入/生成正对照。

**怎么改：** 降为“当前旧适配器下无稳定增量”；实现独立 identity 目标、线性主头、同家族配对、完整充分性和效应强度曲线。STOP、触点集合、路径、条件 mark 分开验收。

### P1-3：漂移的描述部分成立，统一失效机制不成立

原诊断用“留出点在 FIT 中位数同一侧”推出“读出在从没见过的状态范围预测”。这个推理错误。独立审计保留原报告的 FIT 参考、第一主成分与全部导出，额外计算留出点落在 FIT PC1 最小/最大值之外的比例：

| 患者 | 六个导出的 PC1 范围外比例 | 可以说什么 |
|---|---:|---|
| E1096 | **92.6%–100%** | 该投影上存在严重跨期分布偏移，值得定位 |
| E1125 | **7.14%** | 同侧并不等于大部分越界 |
| E253 | **0%–1.16%** | 报告所用的这个投影不能支持普遍范围外预测 |

这只是 PC1 支持检查，不意味着 E253 的所有维度都没有分布变化。它足以推翻“所有状态都因同一个范围外失效”的证据链。部分状态甚至不全在 FIT 中位数一侧。

PCA 轴可以任意乘 −1；不同 seed 的状态坐标还可旋转。“漂移方向跨 seed 翻转，所以不是数据属性”的推论应撤回。训练与初始化状态的标准差、坐标系也不同，直接比较 7.76 与 4.3 不能单独定位因果机制。

**怎么改：** 称为“跨期分布变化和读出失配候选”。补联合距离、支持重叠、原始输入/观测质量变化，以及同支持上的误差分层。FIT-only 可逆缩放可以修数值条件；不应把所有状态强制对齐到同一分布，因为真实病理状态变化可能正是目标。

数据：[drift_support.csv](/data/hfosp_group_event_state_v0_3_10_independent_review/drift_support.csv)。

### P1-4：发作 S-C 是按时间切分的病例/对照判别，不是连续发作风险

`seizure_scores.py::forward_in_time` 只取早期发作窗口和匹配对照窗口拟合一维 logistic，再在较晚病例/对照上评分。没有连续风险集、有效观察人时或阴性抽样概率校正。其输出叫 `risk`，报告又拿 Brier 0.25 作为普遍无技能基线。

这组 Brier 可以描述所抽样病例/对照上的预测误差，但不能解释为实际连续时间中的风险质量。常数最优 Brier 随真实阳性比例 π 为 π(1−π)，并非总是 0.25。只按发作簇所属阶段判断“全部早于测试”也不够；最早预测查询及其输入/参数冻结时刻应逐条比较。

**怎么改：** 当前结果重命名为“时间排序的病例/对照探索性判别”。优先保留无需训练发作头的患者内关联与冻结空间对应；只有构造完整风险集后才计算真实风险、Brier skill、时间警报占比和每小时误报。少量发作可研究关联，不能通过错误的概率口径放宽风险预测标准。

### P1-5：长历史梯度和非线性仪表仍有过度解释

preflight 的八小时梯度测试使用新初始化的 N、E1125 的 FIT 历史，以及 `mu.sum()+logits.sum()`，测试的是预测数值对**逐块汇总 token**的导数。它很好地检验计算图连通，但不是已选中人体 checkpoint 的 held-out 损失梯度，更不是每个真实 IED 的生理作用。

`nonlinear_usage()` 用 `U tanh(Vz+b)` 与 `Az` 的幅度比作 ACTIVE 判据。tanh 在近原点几乎线性；分支幅度非零不等于非线性作用非零。48 张 N 卡中 **11 张选中初始化仍标 ACTIVE**，另有 **5 张 ACTIVE 的 tanh 相对余项 <0.001**。

**怎么改：** 给连通性、已训练参数使用、真实 held-out 损失远程信用和非线性余项各自命名。生产 checkpoint 上做按真实时间段的损失梯度/有限差分；非线性比较必须含线性化替代、预测变化与合成功效，不凭 ACTIVE 放行。

### P1-6：初始化哈希字段实际上写的是最终哈希

`trainer.py::_finalise` 在训练结束对当前模块调用 `per_parameter_hash()`，却存入 `initial_parameter_hashes`。独立读取 `model.pt` 验证：**2,196/2,196 项所谓初始化哈希等于最终参数哈希**。这是可复現的审计字段错误，不是参数未更新的证据；另存的初始化张量所计算的更新范数仍有意义。

**怎么改：** 从训练前冻结的 `initial_weights` 生成初始哈希，同时存 selected/final 两套哈希。旧字段加勘误，不能伪造重写历史。恢复测试还需补配置/源码/数据身份绑定，以及恢复跨阶段边界；目前保存但未恢复的 RNG 状态，不能推广为所有未来随机模型也逐位可恢复。

### P1-7：长历史测量完整性和原始时间语义尚未闭合

`history.py` 保持逐块 release-time 的汇总输入。一个块中的事件被相加后一次写入，块内跨事件次序丢失。每个 anchor 又从截断历史边界重建；这不能当连续逐 IED 的病理轨迹。

120 个配置的 `min_history_coverage` 都是 0。实际 FIT 查询存在低覆盖：例如 E1096 的 0.5h 最低约 9.6%；E1096/E1125 的 24h FIT 分别有 37/36 个查询低于 80%。这不是认定缺失处理必然错误，而是要求把缺测、真零事件和完整历史分开。16/24h 可正确重建，不等于每个查询有完整长历史。

**怎么改：** 保留严格 availability；恢复事件级时间和独立可用的内容测量，记录 exposure/missing mask。比较长度时在共同支持与相同边界初始化上配对；如果采用不完整历史，要明确状态不确定度或缺测规则。数据：[history_coverage.csv](/data/hfosp_group_event_state_v0_3_10_independent_review/history_coverage.csv)。

没有发现需要丢弃全部 120 张现存卡的新增全局数据损坏证据。以上 P1 在相应主张上构成验收阻断；不能把每个工程风险都夸成全局 P0。

## 4. 与最初科学目的的一致性

| 原始问题 | 目前能回答的程度 | 缺的关键证据 |
|---|---|---|
| 间期事件是否携带患者内动态状态信息？ | 新计算路径和训练过程更可信；当前两小时次数/粗空间任务没有稳定净收益，部分状态有错时依赖 | 超过强历史和背景的稳定功能性状态；不能把“错时会差”当净收益 |
| 状态是否按时间作非线性演化？ | 尚未有效辨别；N/L 的旧合成优势经充分性复核不稳 | 可辨识且有功效的转移/读出分离实验；自主预测与带观测重放分开 |
| 同一状态是否关联多种事件表达？ | 当前冻结探针大多回退或无增量；存在个别小收益 | 正确优化的独立空间/形态检验，未参与 producer 训练的视图迁移，同 checkpoint 证据链 |
| 冻结间期状态是否含发作前特异信息？ | 七个发作簇有描述价值；方向和相对未训练状态的增量不稳定 | 适合稀缺资料的匹配关联、独立早期空间对应；风险预测须另补完整人时 |
| IED 是否反过来改变生理状态？ | 没有回答；观察器历史消融不能识别生理反馈 | 共同原因模型与反馈模型的可识别比较，独立未来观测，最终仍需额外因果证据 |

**有设计偏移，而且部分来自我此前给出的 v0.3.10 spec。** 把固定 2h 提前量、次数/粗空间 joint 目标、旧 decoder 的冻结迁移放在中心，容易把“多种事件表达背后的状态”缩成“少数小时级统计量的预测器”。同时，冻结主分析中的 normalization 是为了不改原实验，不应该长期阻止已发现的数值条件修复。下一版必须纠正这一取舍，不能把责任全归执行者。

反过来，加入更强的背景对照没有偏离目标；偏离的是只允许“背景之上的增量”代表所有状态信息。若间期事件和背景共同反映同一状态，事件条件增量为零仍可能有生理意义，需用总预测价值与条件增量两条结果区分。

旧 v0.3.8 / v0.3.9 结论不能因本轮阴性自动全部推翻：患者、测量、目标和训练器不同。应逐比较保留有效旧事实，撤回其超范围推论。旧 N-over-L 正对照失败仍须记录，新任务不能抹掉这条历史。

## 5. 工程验收与最小修改路线

1. **报告勘误先行。** 修上述三条过强结论、S-C 命名、M1 分母与家族、长历史正文仍写 9 张但实际 12 张的遗漏；明确合成新训练器档未实现。旧报告保留，修订版并行输出。
2. **修测量与仪表。** 修初始化哈希、非线性使用判据、真实 checkpoint 信用、resume 身份绑定。调度器的进程内已派集合可防本次重复，但还需跨重启的单元文件锁与原子发布；现有溯源吻合不替代竞争条件测试。M1 的 COMPLETE 不能只检查 contact 路径存在而忽略 expression 失败。
3. **先救公平基线与主端点。** 固定历史不饱和的线性读出、独立 identity 适配器、同家族配对、真实可用时间；在新训练器运行独立合成数据，再运行新的人体小矩阵。
4. **按科学层级扩展。** 短时事件表达 → 冻结跨视图 → 自主/非线性动态 → 稀缺发作关联/空间 → 有条件的连续风险；H3 保持独立。

## 6. 下一版的决定

不推荐立即再启动一轮更大网络 × 更长历史 × 更多 seed 的全面扫描，也不推荐先强制消除状态漂移。推荐执行[v0.3.11 完整方案](group_event_state_v0_3_11_event_expression_state_spec_2026-09-06.md)。

**最终验收意见：`ARTIFACTS_ACCEPTED / REPORT_MAJOR_REVISION / SCIENTIFIC_CLOSURE_OPEN`。** 本轮产物有价值；正确的收口不是“已证实无状态”，而是“已定位多个限制，当前代理任务未显示稳定增量，核心命题需要重设承重检验”。
