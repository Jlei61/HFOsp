### 2.2 主训练目标和独立读出

主三视图均预测未来真实数据：

1. **数量**：有效区间内的群体事件计数，保留exposure和绝对水平。
2. **空间组织**：给定有事件/事件大小的粗community组成，不将count变化重复记为空间改善。
3. **条件形态/传播**：预先冻结的频带log-energy ratio、signed cross-band lag、参与触点延迟IQR。前两类按固定测量坐标建实值分布；非负IQR用零点质量＋正值LogNormal，不用Gaussian后裁零。仅使用确实可测的字段，单位、频带及质量规则从实际producer记录在measurement_manifest中，不猜频带边界。

## 3. q–f–g架构及过滤修正

`infer`读取截至当前已发布的包，输出过滤均值m、完整协方差P；`rollout`只读m/P及真实dt，不读未来事件、背景、GRU记忆；`observe`将同一状态预测映射到真实观测分布。时钟在目标时刻为所有臂共同的已知协变量，不把供体时钟随错时状态一起换走。

### 3.1 动力学及共同数值核

latent24分3个8维块，初始衰减τ=5min/1h/8h，允许2min–48h内学习；边界、合并及实际响应尺度必须报告，不把τ叫周期。`A=-D+Omega`，Omega反对称；I-L中跨块系数固定零，C-N中开放跨块，并有块内`r_a=U_a tanh(V_a z_a+b_a)`，每块秩6。首轮两家族同时改变多个因素，不能用其差异证明非线性或耦合。

生成模型为`dz=(Az+r(z))dt+diag(sigma)dW`，小时为动力学单位。所有臂共同采用：精确线性OU半步 → 非线性残差中点步 → 精确线性OU半步；L的残差为零。线性子步`F=exp(A*dt)`，`Q_dt=integral exp(A*s) diag(sigma^2) exp(A*s)^T ds`。Q可用稳定Van Loan/等价方法，不能简单用sigma²dt冒充旋转/衰减后的精确Q。

过滤使用Gaussian均值/协方差近似：线性子步精确传播`m←Fm, P←FPF^T+Q`；非线性子步用相同中点映射及其Jacobian传播P。块内残差Jacobian可解析向量化，无需按每个时间点调用通用高阶求导器。N的Gaussian近似需在独立真值上校准，不称精确随机后验。

最大主步1min，实际短间隔用真实dt。FIT片段做1/0.5/0.25min比较；采用耦合的底层Brownian增量或等价共同OU随机路径，而不是每张网格重抽互不相关噪声。必要时所有比较臂一起细化。长gap按模型传播；方差可增加或下降到稳态，不要求人为单调膨胀。

### 3.2 观测更新：纠正完整预测分布

慢GRU读取当前已发布包及过去记忆，预测证据位置a和测量噪声R；head还接收当前先验m^-及diag(P^-)。主证据维24，固定H=I。令v=diag(P^-)，`R=diag(v * rho)`，`rho=exp(log(10)+6*tanh(eta))`。eta头初始化权重/bias为0，所以初始R=10 diag(P^-)，没有未定义的softplus(0)绝对方差。a头小非零初始化，避免断开事件编码梯度。

观测更新为：

```
S = P_minus + R
K = solve(S, P_minus.T).T
m_plus = m_minus + K @ (a - m_minus)
P_plus = (I-K) @ P_minus @ (I-K).T + K @ R @ K.T
```

R是学习到的证据噪声，**不是过程噪声Q_dt**；P^-包含历史不确定性和Q_dt。直接从更新后的Normal(m+,P+)采样，不能仍给旧样本共同加偏移。missing包完全跳过证据更新。实际实现优先使用Cholesky/square-root解与Joseph形式，保留全24×24协方差，不将耦合后非对角项悄悄删除。FP64用于矩阵分解/概率累计；相对数值jitter≤1e-9×max(trace(P)/24,1e-12)，若必须超过1e-6相对尺度才分解成功，记录数值故障，不能静默“修正”。

这是一种由预测任务训练的**近似Gaussian证据过滤器**。对真实非Gaussian事件，a/R并非直接推导自完整事件似然，不能称精确Bayesian后验。借鉴连续—离散过滤的均值/协方差更新思想，不声称复现NCDSSM完整生成或变分训练。[Ansari等，2023](https://proceedings.mlr.press/v202/ansari23a.html)。

### 3.3 初始化、梯度及分布语义

记录起点m=0、P=I、GRU记忆0。GRU各门循环矩阵正交、输入Xavier、bias0；Omega独立系数std=0.01/h，U std=0.01/h、V std=1/sqrt(8)、b=0；sigma初始0.1/sqrt(h)，下界1e-4/sqrt(h)。**不存在旧绝对后验方差下界1e-6、旧潜路径KL或KL warm-up**。

a/eta头输入112维（64＋24＋24），各输出24维，分别2712参数；a末层std=0.001，eta末层0。GRU参数按`3H(D+H+2)`核对；块内U/V共288、bias18，完整反对称Omega276、独立块内84，跨块差192。事件编码器、词表和观测头的实际参数数目/shape逐层导出，不以总量替代。

输入缩放只用FIT：计数/负荷输入log1p，连续量中位数/IQR缩放，IQR退化回退FIT标准差，仍恒定则尺度1；mask不缩放。主模型无BatchNorm、无latent逐段归一化，不对齐outer均值。损失在事先冻结的无量纲目标坐标上计算，并保存原始单位换算；不以任意单位下的绝对NLL给视图定权。

### 3.4 区间观测和条件表达

对包区间I，计数均值为`Lambda(I)=integral_I exposure(t)*rate(z(t),clock(t)) dt`，由合法预测路径上的求和/求积得到，再用NB建模过度离散。实际未来exposure仅用于条件评分，不能流入状态或风险预报；无效支持不作零事件。

在区间开始处由过去过滤分布生成整段预测路径，保存预测；区间包发布后评分，再更新到结束/发布时刻。不能拿同一包同化后的终点latent评分自己。迟到包若无法正确同化原支持，首轮保留真实延迟并将其作为当前可用的历史证据，标近似延迟过滤；不伪装成即时测量。

条件空间/形态在实际未来事件时刻读同一g，未来真实事件时间只作条件评分索引，不读入q/f。它回答“给定该时刻有事件，其表达如何”，与事件发生时间/数量分开；多项条件评分的加权训练不冒称已经构造所有事件时间和mark的精确联合似然。给定K、粗community或prefix的结果必须显式标条件。

G1为自然参数的一层hidden64 GELU读出；G0为自然参数线性读出，必要的log/softmax分布链接两者相同。主未来头不接受自由lead embedding；先演化z，再用同一g。多分钟计数由minute条件分布卷积/混合，保存尾部误差，不用MC计数直方图的零频率打分。

## 4. 主训练和计算组织

主目标不含当前包后验重建，也不含旧KL。使用：**0.5×逐包先验预测损失＋0.5×多时距自主预测损失**。三主视图等权，视图内有效维等权；多时距1/5/30/120min等权，主目标为对应提前量后的1min区间，另报5/30min聚合。以INNER同一组合选择checkpoint，outer分项完整呈现。

物理基本单元是连续episode，不是128份重复历史：一次有梯度的过滤前缀提取多个合法起点，每个起点只rollout到最大提前量，再切四个目标。初始有效batch目标为128个起点，最多来自8个episode；微批从1个episode、16个起点开始，累积达到固定目标。若资料不足，预先冻结实际有效batch，不伪称128。每个epoch的观测项按唯一物理包平均；重复历史前缀只提供计算上下文，不自动增加其loss。预测项按起点/时距/目标视图分别平均，并对目标包多重覆盖记录固定权重；梯度累积必须与这一标量目标一致。

首批主训练有梯度前缀上限2h；严格0.5/2/8h历史重拟合另做，24h后移。持续过滤可带更早的m/P/c，但detach位置及真实反传范围明确；不能以持续状态或记录跨度宣称超过2h的训练信用。共享前缀仅在同一参数版本内复用，优化器更新后不能继续复用旧缓存图/旧状态作为“精确重放”。

训练预测抽样4条状态路径，评估64；关键差值以128复核，最多512。同一比较用共同随机数。标准化分数的MC绝对SE目标1e-3 nats/有效目标，达不到时继续到预算上限并附MC区间；不以接近零效应的1/5触发无限加采样。激活重计算、有限差分、恢复和求解器对比复用随机流标识。

AdamW：LR=0.001，betas=(0.9,0.999)，eps=1e-8，weight_decay=1e-4，bias/尺度不衰减，clip=2。每50更新评价，patience8，至少400更新后首次×0.3，再至少200更新后第二次×0.3；基础3200，仍改善可续6400。0.003为预定义FIT/INNER优化敏感性，必须对承重比较双方同等开放。FP32网络，不先启FP16。

停止原因不是充分性。记录初始/所选checkpoint、逐LR曲线、真实参数更新、读出饱和、方差/R/Q/K范围、非有限值和预算余量；常数、固定历史、背景及适配器也要拟合诊断。选中初始化允许如实保留性能，但不能说学到了状态。大网络仅在FIT逼近不足且优化有效时，对对应比较双方作latent48/hidden128敏感性；首轮不全面扩容。

排除区间复用既有被接受的临床台账和持续时间定义，不按新版结果调整。只读取时间边界作排除，不让发作标签训练producer。主间期预测若目标跨过发作或排除区间，所有臂一起移出该端点，报告被排除比例及“无发作/有效观察支持下的间期条件预测”。不能将该分数称所有时刻无条件能力。后续真实风险评分必须使用完整风险集，不能沿用这一筛选分母。

## 6. 首轮依赖与最小实验

### G0：一条完整链，必要检查同时做

首先接通事件包→因果过滤→区间先验预测→自主预测→冻结细identity。以下检查是数值/权限正确性的依赖，不是等待全部结构世界的总门槛：

- 解析线性高斯：覆盖不规则dt、强/弱观测、长gap及恢复；人工给定H、观测与R时，对参考Kalman均值/P和创新似然比较，FP64相对误差目标1e-6。应复现“先验约0.98027、R=0.01，后验约0.009899”，而非共同创新留下约0.9801。这个测试只验证过滤核，不冒充学到人体后验。
- 另用同一训练器拟合已知线性真值，检查神经证据输入与预测校准；不能只通过手工oracle核就放行学习接口。
- 一种关键形态世界：率/粗composition固定，只有慢变量调制合法shape或传播；P_stats/P_marks与旧/新目标2×2，每个2个数据实现，共8个小拟合。目标固定时检验输入，输入固定时检验学习目标。另做同通路细identity效应注入和零效应读出对照。
- 数据未来截断、参与mask、概率归一化、共同分母、累积梯度/重计算随机流、故障恢复和单写者。FIT真实损失对0–0.5/0.5–2h包做梯度与有限扰动；更早信用随长历史任务验证。

核正确、字段合法、预测loss有真实梯度后可开展依赖已满足的人体任务；形态世界的功效范围未完成只限制解释。不能要求六类动力学世界全部通过才能开始状态识别，也不能明知该数据通路有bug仍发卡。

### G1：18次主体及少量定向消融

| 阶段 | 数量 | 作用 |
|---|---:|---|
| S-E主体 | 3患者×2输入×2家族×1种子＝12 | P_stats/P_marks；I-L-G1/C-N-G1，目标相同，检验输入与粗粒度表达能力 |
| S-ID最小对照 | 3患者×2输入×I-L-G1×1种子＝6 | 保留分散覆盖问题，避免又只剩单个前推窗 |
| **首批主体** | **18** | 一种子仅是开发pilot，不给稳定性/排除性结论 |

主优化种子20260906，后续复核20260907/20260908。每个主体都有相同支持的逐包、1/5/30/120min和冻结细identity；有资格的S-A/S-B立即接入。统计基线、冻结适配器及合成拟合另计，不藏在18中。

定向目标消融：E1125、P_marks、I-L-G1、canonical S-E，将三视图主目标改回旧count/负荷/粗composition，仅新增1个拟合，与主体已有相同输入/模型的新目标比较；若该患者源字段不可估，则报告该项不可估，不按结果换患者。

定向跨视图：同一E1125主模型移除传播延迟目标，且从原始输入重建时移除所有delay、tied order、first-contact派生量与保留该信息的跨触点波形对齐编码，仅保留允许的数量、参与集合及无方向形态；新增1个拟合，再用冻结状态预测传播延迟。未来跨视图可预测只支持信息共享，不自动证明共同生理驱动。普通主体使用目标视图的过去是合法预测，不当泄漏。

因此本轮预定义紧凑开发包为**18主体＋2定向消融＝20次**，不是旧273次承诺。定向消融依赖完整基础配对，不延迟首位患者完整证据链的交付。

### G2：同checkpoint的保持/演化/回归及冻结迁移

每份冻结checkpoint无需重训即可比较三种规则：HOLD保留当前状态分布；EVOLVE按学到f传播；RELAX按FIT固定常态分布回归。RELAX的m0/P0与回归τ只在FIT/INNER确定，用`m_h=m0+a(m-m0), P_h=a²P+(1-a²)P0, a=exp(-h/tau)`定义有效Gaussian分布。三者观测头、目标时钟、exposure和mask相同；HOLD不得冻结未来时钟。比较用于判断当前信息和演化规则的预测作用，不叫生理干预或唯一机制。

identity主头固定K时用规范化集合概率（可用elementary symmetric polynomial动态规划），不是平均contact log-softmax；给定粗community计数的组内集合概率另列。same-prefix只看已见前缀，STOP另训另评。主适配器是低容量线性，训练/选择只用producer FIT/INNER；与截距、患者固定空间trait、完整marked history、常数状态重拟合和producer功能读出配对。

功能状态导出同checkpoint对数量、粗空间、条件形态的预测参数及不确定度，latent几何作辅助。对相同prefix/相近近期负荷的实例，只在真实共同支持中找状态差异；不能为补故事性例图使用从未出现的分位区间。

### G3：发作与记忆并行

S-A：冻结功能状态在−2h至−30min的患者内关联；−30至−5min为次要。对照按同患者、时钟/质量/既有临床变量匹配；近期率匹配另报条件版本。单次发作可给轨迹和差值，不能称重复支持；独立单位为发作簇。匹配病例对照不报告真实绝对风险。

S-B：冻结间期空间trait、近期历史、trait＋state比较早期0–10s能量场、0–30s招募；优先复用既有early→late gradient fields，channel name和参与mask对齐，不从当前发作重建模板。没有够多历史发作训练适配器时先给固定几何对应/个案，不伪造留一训练。真实发作K/起始通道不能进入发作前输入。

S-C仅在完整可观察时间风险集和台账存在时计算风险/校准。S-A/S-B不因风险分母不足而停止。canonical S-E checkpoint之前的发作不可冒充该模型的前推迁移，可另标回顾性个案。提前看发作之后不得按它选择producer；后续若受其启发修改模型，显式降为新的开发版本。

历史实验：3患者、同一INNER-selected P_marks家族，0.5/2/8h严格重拟合各1种子，共9次；全部从相同FIT固定先验/零c开始，训练和评分语义一致、目标取共同支持。主体“持续过滤”不当严格2h臂。24h仅在实际时长/资源与已提出的长记忆问题支持下扩展，不作首轮实现前置。

### G4：围绕具体解释调用结构实验

需要区分非线性时补C-L与G0；需要区分耦合时补I-N或配对C-L/I-L；需要比较衰减尺度时补S-L。同维度/读出/训练机会，数据真值对比同步校准；生成器写了耦合，不代表观测分布必须保留同一潜块耦合。独立动力学＋非线性观测是重要反对照。

旧v039收敛N−L三种子−0.0082/+0.0007/−0.0419必须保留。新世界成功不能改写旧正对照失败。人体首批I-L/C-N差异不能直接归因非线性。某结构对比无鉴别力只限制那条结构解释，不封死状态识别/迁移。

增加种子、其他前推起点、多fold、B-only/B+E与正式功效，是后续明确问题的扩展。背景模式必须同家族、同未来目标和优化机会；不比较各模式各自挑出的不同家族。执行队列按依赖和完整配对推进，不按outer得分给“赢家”更多预算。

## 7. 科学判定、参考与停止条件

每个划分拟合：截距/exposure、时钟/质量、近期率历史、完整marked-history，以及同观测头的常数状态。完整历史使用固定核1/5/30min、2/8h，主读出无Tanh饱和瓶颈；各输入版本另有信息权限一致的历史参考。基线最好允许充分优化，不能因其胜截距很少就宣布它必须无效；但若优化或表达能力明显不足，状态胜它不能承担“超越充分历史”的结论。

主参考在INNER选定；所有状态臂同时印对完整marked-history、常数和所选参考的增量。与旧表兼容的封底只在**共同支持的汇总损失**上取更强参考，不对每个outer点取oracle最小值。定义统一为`loss(reference)-loss(state)`，正值表示状态较好。

错时供体来自同患者合法可用库，按record/质量/时钟层匹配、物理支持不重叠；若为严格前推，供体只能早于查询时刻。换latent时保留目标时刻clock、exposure、mask和合法prefix。印匹配成功分母及协变量差异；不能用不同分母计算两个臂再相减。

预测分布混合采用`log(mean(p(y|trajectory)))`，不是mean(log p)；标出有限MC估计误差。count、条件形态、粗空间、细identity、STOP逐项报告，不能用总分补全多端点证据。S-ID长提前量的目标必须在outer核心内，起点可在核心前；不足则仅报告可估时距，不为30min核心伪造2h完整目标。

单位依次为物理时间块、发作簇和患者。重叠事件/锚点、优化种子不是独立患者。三位已看过患者只给开发证据；块数不足时给完整配对值/范围，不用事件级bootstrap造窄区间。适当时按日历日/连续块聚类，报告2/6/24h相关性敏感性。单种子pilot不作确认性显著或阴性判断。

| 观察到的组合 | 允许的解释 |
|---|---|
| P_marks优于P_stats，且超越充分marked-history | 丰富事件结构有可学习的状态增量；仍需跨时间稳定性 |
| 只有P_marks输入改善，目标消融无差别 | 信息来源更关键，不宣称新目标本身有效 |
| 新目标改善形态而count不变 | 条件表达获得增量，不因count不变否定状态 |
| 识别有用，EVOLVE不优于HOLD | 当前状态有信息，演化增量未建立；不是“没有状态” |
| 长历史只改善识别 | 长历史帮助估计当前状态，尚未支持更长自主时距 |
| S-ID改善、S-E失效 | 回顾性覆盖或时间漂移是候选解释，不能只归咎切分 |
| 细identity仅在不控制粗community时改善 | 主要是粗空间信息，不能升级为细身份迁移 |
| 有发作关联，无可估风险 | 患者内关联/个案；不称临床预测器 |
| 非正且功效未校准 | 当前任务未检出，不是生理阴性 |

状态证据要求真实训练后的参数/信息被使用，但非零梯度本身不是功能增量。FIT梯度/有限扰动可用于修实现；outer梯度只在最终冻结后描述，不选择checkpoint、配方或追加预算。若outer发现实际bug，修复并把该outer降为开发，不能继续称独立确认。

正式排除预定效应时，另冻结端点、delta和样本量/噪声匹配的功效模拟；不以18次pilot宣称有界阴性。结构阳性也要对应可区分的真值/反对照，原N/L仪器失败不能靠增加人体拟合洗掉。

停止/修订按分支：测量权限或概率错误先修该链；某结构仪器不可分则停止该结构扩展；缺少发作/长支持则标不可估并继续事件主线；优化仍改善则续承重配对而非共同截断；简单模型足够则接受简单模型，不为复杂故事扩容。没有合格GPU任务时记录科学原因，不制造无关负载。

## 10. 文献依据与实施边界

- [Fouad等2022](https://pubmed.ncbi.nlm.nih.gov/36483575/)支持空间/形态会随状态和脑区变化的研究动机，不保证P_marks胜出。
- [Ansari等2023](https://proceedings.mlr.press/v202/ansari23a.html)提供预测协方差与观测校正的参考；本文使用近似证据过滤和预测训练，不能套用该论文的完整后验/ELBO声明。
- [BRAID，2025](https://proceedings.iclr.cc/paper_files/paper/2025/hash/082d3d795520c43214da5123e56a3a34-Abstract-Conference.html)提醒区分内禀与输入驱动动力学；关掉未来观测后的退化不自动意味着状态不存在。
- [Sani等2024，DPAD](https://pmc.ncbi.nlm.nih.gov/articles/PMC11452342/)支持分开定位转移与读出非线性；首轮混合家族只作表达能力筛查。
- [Yang等2026](https://onlinelibrary.wiley.com/doi/10.1002/epi.70110)说明因果周期提取影响预测，S-ID与S-E不能混报。
