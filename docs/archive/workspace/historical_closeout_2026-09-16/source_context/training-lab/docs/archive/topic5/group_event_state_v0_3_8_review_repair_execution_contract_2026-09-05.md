# v0.3.8 审阅修复与补实验执行合同

日期：2026-09-05。来源：用户明确要求设置修复 Goal，并追加“不要让 GPU 空置，监控需要补充的实验的同时修复问题”。本文件是现有 Goal 的执行补充；应用中 Goal 正文和暂停状态只能由支持相应操作的界面或工具修改，不能用本文件冒充修改成功。

## 目标与验收

修复独立审阅确认的同 seed 交集、same-prefix 后缀评分、已学习 checkpoint 资格、训练及承重对照充分性、同模型长程 credit、复现来源和报告图表错误。原始结果只读，修正版写入 `/data/hfosp_group_event_state_v0_3_8_review_repair`。按同一患者、family、seed、checkpoint hash、预测 horizon 和 endpoint 绑定证据，不把不同患者或模型的结果拼成统一病理机制。

验收以可重放的代码、针对性回归、必要补实验和经核验的中文报告为准，不以阳性结果或 GPU 累计使用时间为准。工程运行、训练充分、可估、探索性支持和科学确证分别记录。

## 新增执行约束：实验与修复并行

1. 在 GPU 上运行已通过数据、语义和数值检查的必要实验，同时修复独立的汇总、报告及其他代码。只要有已就绪且适配资源的必要任务，就及时接续两张 RTX 3090；不等全部代码修完才启动全部实验。
2. 每项运行固定源码快照、输入和 checkpoint hash、参数、随机种子、输出目录及完成条件。开发中的文件不能悄悄改变正在排队的实验语义；依赖有变化的任务必须重新通过检查。
3. 监督器定期记录 GPU 利用率、显存、进程存活、单元进度、失败和待运行数；完成即接下一单元。根据实测显存和吞吐调整并发，避免 OOM 与重复启动。
4. 发现 NaN、来源不符、重建不一致、评分目标错误或进程失败时，隔离该单元并修复，同时继续其他独立合格任务。失败不得改写为完成或科学阴性。
5. GPU 空档须记录原因：等待数据、测试或依赖、CPU 阶段、故障隔离、无剩余必要任务。不能用空转、重复训练、无科学目的的超参搜索制造满载；不承诺数据加载期间也达到 99%。

## 补实验顺序与冻结边界

- 第一批：同 checkpoint 的长程依赖审计。先补 E1125 dual，五个原登记 seed，分别绑定 6 h 和 8 h 预测端点，分开 event/background 梯度；验证重建状态与保存轨迹一致，再记录按历史年龄删除输入后的预测损失变化。删除是模型敏感性检验，不是生理因果干预。对审计中失效的预处理或来源先报错，不静默重训。
- 首例重建检查通过后，对其余五位原长尺度患者 E1096、E253、E958、E1077、E916 的同一 dual 家族执行完全相同的五 seed × 两 horizon 审计。所有六位统一覆盖，用于区分事件分支、背景分支和初始化特征；不按增益筛选患者，不新增训练或超参。这是原结果的来源与敏感性复核，不是独立确认。
- 并行修复：同 seed 完整交集与训练闸门、same-prefix 已知前缀屏蔽及同子集 FIT 常数对照、硬编码结论和混队列绘图。
- 后缀重评：原 H2a 长/中两层全部 150 张卡统一登记。30 张原不可估卡继续保持不可估；其余用原冻结 adapter 重评，无训练。先核验正确状态、常数和 B_mark 的完整事件分数能重放，再在完全相同的前缀/段落/错时可用事件集上计算后缀 grammar、STOP 和 contact 分数，保存逐事件值。严格后缀不包含已给定第二组的预测或前缀内 STOP。
- 第二批：仅对已发现的优化受限单元补预先登记的预算敏感性；优先 E1096 随机对照与 E253 H2a。固定原配方，先增加有限预算，不根据 SELECTION 或发作结果调整学习率。记录所有承重臂逐模块梯度、初始化到选中权重变化和停止原因。
- E1096 随机对照预算细则：仅重跑原 event/grid 中触顶的 seed20260903、20260905、20260907，共六个单元。保持原冻结随机 encoder、已拟合父臂、学习率、权重衰减、INNER 耐心和零残差起点，将 random head 上限从 900 增至 2700；其他权重必须逐张量保持不变。先在原 CUDA 计算平台通过原父臂、原随机臂和原状态分数重建检查。CPU float32 count loss 的数值偏差不能用放宽容差掩盖；跨平台精度差另作工程边界记录。
- E253 H2a 预算细则：grid 家族五个原 seed 全部采用原初始化、原学习率和 AdamW 配方，从头重放 adapter 训练，将状态与 B_mark adapter 上限由120增为360 epoch；静态与 oracle 配方仍分别为原80 epoch。保持 H1 observer 和 contact decoder 权重冻结。保存逐参数梯度、真实优化步数、原预算内 INNER 曲线重放差异、三个 rich-mark ridge 读出及完整评价输入；它是固定配方预算敏感性，不是丢失 Adam 状态后的伪续训。
- H2b 审计细则：统一对原55个冻结特征单元复核，保留所有不可估者。LBFGS保持lr=0.5、strong_wolfe、原六档L2与INNER选择；记录160迭代后的真实梯度，不满足1e-5最大绝对梯度的拟合最多再给480迭代，仍未满足者不能称收敛。记录所有配方及已选读出参数。加入原已冻结12维随机历史投影的同宽度对照，及明确泄漏的未来发作诊断特征（30min、2h发生标志和exp(-距离/2h)）；它们不能选择间期状态。空间场使用已核验的主目录 bb150 缓存显式路径，旧工作树缺少此路径时未评价的能量场不能当作阴性；所有空间臂在相同、确实有足够FIT事件的触点列上比较，并用FIT拟合的最多4维未来残差场oracle审计可读出性。发作簇按1/6/24h间隔作透明敏感性计数，不把操作性簇自动称为生理独立。
- 后续：完成同状态多端点验证与 H2b 优化、正对照和分母审计。当前已查看的 SELECTION 只能作修复复核；development/sealed 保持关闭，确认实验须先形成独立冻结合同。
- 非线性转移与 H3 分别登记最小匹配对照后执行。固定滤波器的非线性读出不是非线性转移证据，observer 的逐事件更新不是 IED 改变生理状态的证据。

# 全部 H1 checkpoint 重放与可携带输入冻结（审阅追加）

固定端点身份闸门：图表交叉核验发现“每个seed任意两项通过”仍可在seed之间更换端点组合，制造多端点复现。多端点主候选现要求同一对预先列明的非同义端点在同一批至少3个seed上同时满足所有条件；全部端点对交集保留，任意两项/seed仅作诊断。H1的mixture/embedding仍只算一个repertoire组；H2a继续使用既定contact_subset、continue_stop、same_prefix_continuation、conditional_rich_mark四类，不因结果调整名单。该补修不需要重新训练，只修判据并加入构造反例测试。

H2a 承重预算补齐：按训练日志而非 SELECTION 方向筛选 E253 的剩余不合格单元：三个 family 的 seeds 20260904/20260907 静态头未满足耐心停止，event/dual 的 seed20260905 状态头未满足耐心停止，共八单元。固定原 LR、AdamW、初始化和 patience，将 static 上限 80→240、state/B_mark 上限→360；不延长已经灵敏的泄漏 oracle。使用修复后的、绑定实际数据的预处理，保留原上游参数；这是预处理与承重预算的修复复核，不冒称原运行的精确续训。输出 `h2a_budget_complete`，旧原卡与第一轮 grid 补训保留。真实 E253 双 epoch CPU 预检已完成。已测单个 H2a worker 约0.5 GB；可每卡同时四个，加一个轻量 checkpoint 重放仍远低于24 GB，登记最多四个 H2a worker/GPU；各进程固定 seed、单 CPU 数值线程和独立目录。允许与本任务的预处理审计在其输入加载空档接续，监控实际显存、进程和失败，不挤占外部工作。

缓存来源补修：旧 rich-mark 缓存只按患者/seed 命名，未核验词典与实际数据。新增缓存按使用的 pre-80% 行、实际 band/cross-band/waveform 内容、FIT 词典和 producer hash 命名，旧缓存不回退、不覆盖。保存 mark 标准化、词典、rich normalization、ridge residualization、PCA 变换及可携带数据包。登记 55 个患者/seed/尺度单元，每单元只重建一次安全预处理，在同一数据上重放 event/grid/dual 原权重，共 165 个模型。新结果写 `checkpoint_replay_verified`，旧缓存条件下的重放留在 `checkpoint_replay`；新旧输入或分数不一致时只保留来源受限诊断，禁止宣称原结论已完全复现。GPU 队列在第一批重放之后自然接续，CPU 上先检查完整路径。

H2b 数值补修：第一次全量诊断发现 121/420 个选中 hazard 读出因默认 `tolerance_change=1e-9` 提前停止而未满足已锁定的 `max|gradient|<=1e-5`。第二阶段保留已有 160+480 次上限、学习率、L2 网格、优化器历史，将数值停止精度固定为 `1e-12`，对 55 个冻结单元统一复核。增加实际正 hazard 行对应的不同 onset 数；FIT/INNER/SELECTION 至少为 3/1/1，临床清单中没有进入这些预测行的发作不能补分母。原诊断卡保留，修正卡写入 `h2b_instrument_polished`。

对原 long/medium 队列全部 165 个 H1 checkpoint 统一重放，覆盖所有患者、family、seed，不按发作结果筛选。上游参数保持原值；从当前数据构造器重建事件输入及端点，保留原存档 B_mark/background 特征，对齐 anchor、segment、phase、count、exposure，再检查状态和原 SELECTION 分数的数值一致性。复用原对齐容差与 FIT-only repertoire permutation，不为过关放宽阈值。

每单元保存可携带 `replay_inputs.pt`、输入哈希、实际逐层形状与选中权重处的 FIT 损失梯度。不一致的端点标记为重放未通过，不能作为已复现的科学结论。此工作恢复的是明确输入边界上的重放能力；不声称找回原先未存的全部原始预处理算子，也不把最终 checkpoint 的梯度冒充历史训练日志。

## 事件与背景分支归因复核

审阅发现 E1125 的完整 dual 对照不能回答事件分支本身的动态价值。登记原55个dual checkpoint的冻结单分支对照：只将一个分支替换为FIT均值或原段内错时，另一分支、B_mark、q及读出权重全部保持原值；另记录事件分支相对持续背景的增量。使用已有hash核验的重放包，先验证原端点分数，再输出每个horizon/endpoint的配对值。不改训练、不开新分区、不接触发作标签。队列 `dual_branch_controls_batch`，每GPU最多4个轻量worker。

汇总保留完整dual模型候选，同时增加事件分支的独立资格：选中事件输入矩阵确实更新、事件训练路径合格、匹配随机事件对照、事件分支常数与错时及对持续背景的增量均需在同seed通过。不能由背景收益替代事件收益。新增构造反例：所有整模型对照通过且事件矩阵已更新，但事件分支常数更好时，事件动态资格必须为false。

非线性演化与H3的验收边界：本轮修复的是原v0.3.8实验能否有效回答这些问题。源码、参数及真实历史删除已确认原observer是固定指数演化加学习输入映射，逐事件更新属于模型定义；现有观察数据没有把IED生理反馈与观察器更新分开的识别设计。因此两项标记为原设计未建立，不能靠延长原训练补成阳性。新的非线性模型对比和生理反馈识别是后续科学实验，需要独立合同及未参与当前判断的数据；本轮不把它们冒充已经执行。

## H1其余承重对照的有限预算复核

全部165卡叠加已完成补修后，仍有15条原预算耗尽路径：9条random与6条dual background_current。仅依此日志登记，不按预测方向选人。使用hash核验的存档边界重放包，先确认原对照端点分数；通过后保留原初始化零残差、LR、AdamW、INNER耐心，将对应head上限900→2700。只更新该对照头，其余参数逐张量必须保持原值；新background_current作为更充分拟合的独立强基线，不能冒充原科学模型的下游也重新优化。评分不一致则保留SOURCE_LIMITED，预算再次耗尽则OPTIMIZATION_LIMITED，不放宽容差或无限延长。输出`h1_remaining_controls`，队列等待中尺度H2a释放后接续，最多4轻量worker/GPU。
