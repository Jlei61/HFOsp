## 0. 已作的决定

下一轮的首要问题是：

> **只读当前事件之前的间期信息，能否得到一个在患者内可复用的状态，改善随后事件的内容与组织预测；并且这份信息能否跨到未参与状态训练的事件表达和发作观测？**

两小时后的次数/粗空间预测保留为与 v0.3.10 对接的次级任务。它不再独自决定整个状态命题。小时级记忆、非线性演化、发作关联、IED 生理反馈仍是独立待检验层，不能因短时形态预测变好而全部放行。

采用分阶段设计：**正确测量与可靠基线 → 可测效应的仪器 → 近时事件表达状态 → 冻结跨视图 → 长时与非线性演化 → 稀缺发作关系**。每一步产出都可以独立报告。H3 生理反馈另设识别性分支。

不采用三种捷径：只加宽网络/历史；把全部留出状态强制对齐到训练分布；改变合成真值或阈值直至 N 胜过 L。

## 1. 假设与可接受的结果

| 编号 | 要检验的对象 | 阳性允许说什么 | 阴性/未决如何处理 |
|---|---|---|---|
| Q1 | 事件历史是否包含可泛化的表达信息 | 患者内预测状态有功能证据 | 当前测量/分母下未检出；未经功效或等效界限不能说没有状态 |
| Q1b | 给定背景后事件是否还有额外信息 | 事件历史包含所测背景未解释的信息 | 可与 Q1 阳性并存，解释为信息冗余/共同背景，不自动否定状态 |
| Q2 | 学习时间整合是否优于固定历史 | 需要可学习的历史整合 | 固定历史足够或当前任务无法区分，不代表事件无信息 |
| Q2b | 非线性转移是否有额外预测需要 | 在锁定的模型类/坐标与端点上，非线性转移有增益 | 正对照不灵敏则未检验；即使充分检验为零，也不是大脑动力学线性 |
| Q3 | 同一状态是否迁移到未训练视图 | 跨视图的共同预测信息 | 多任务 head 各自变好不能替代这条；各视图可有独立原因 |
| Q4 | 冻结间期状态是否与发作前/早期 ictal 表达有关 | 分别报告关联、簇外迁移或时间前推性能 | 少量发作允许个案/病例系列，不强制 3/1/1；不自动升为临床预测器 |
| Q5 | IED 是否反过来改变生理状态 | 当前观察资料最多提供反馈模型相容性/预测必要性 | observer 更新与历史删除都不能单独证明生理因果 |

“共享”首先指同一患者、同一 producer checkpoint、同一可用时间上的状态可跨读出复用。它不等于唯一潜因子，也不等于唯一生理机制。跨患者泛化是另一个外部验证层。

## 2. 数据与真实可用时间：先决定能不能做新任务

### 2.1 逐事件资料合同

一条完整群体事件保留：event start/end、各触点有效 mask、实际相对延迟/并列招募组、各频带量、负荷、waveform 可用特征、测量支持范围与质量。旧 `lagPatRank` 不得把未参与触点当有效秩；按现有 masked 合同消费，触点以名称对齐。

为每种输入保存四个时间：`event_time`、`raw_support_start/end`、`release_time`。当前事件的完整内容只在其全部所需原始支持已结束后可用。归一化、编码器、模板、通道筛选只从 FIT 建立。

在事件 e 的预测时刻，状态为 `S(t_e^-)`：禁止包括 e 的完整内容。same-prefix 解码可以使用已观察到的前缀，但事件级状态保持不变。整个事件测量可用后，才更新后续事件的状态。

**若只能取得每小时发布的汇总量，就明确停在小时观察器层；不得通过提前时间戳伪造逐事件状态。** 先实现分块内因果测量/可用时间再进入分钟任务。若 waveform 提取需要事件后小段数据，将实际延迟写入 release；不得默认为零。

最低测试：至少 100 个跨块、跨 gap、事件附近查询，截断原始输入至查询时刻重新提取，与在线保存结果一致；向未来追加数据不能改变过去已发布特征。早于 release 的事件内容不可见。至少含一次同时出现多个事件的情况。查出误差先修测量，不开大矩阵。

### 2.2 背景、缺测和零事件

背景仍用独立非事件片段，先保留 v0.3.10 的可追溯特征，不用当前事件完整 waveform 去预测它自己。记录背景支持时间、IED 邻域排除、坏道、缺口、reference 和采样率。时钟是时钟，不能当睡眠标签；睡眠/用药若无可靠标签，记未测混杂。

`exposure=0` 表示没有有效观察，不是事件数为零。主分钟目标要求有效观察比例 ≥90%；80% 为已注册敏感性。历史可以部分缺测，但必须携带 exposure/missing mask、最长 gap 和距最后观测时间，不将缺口补成“零事件已观测”。长历史长度的主配对要求各长度均 ≥90% 覆盖，另报全支持分析。

### 2.3 先盘点本数据的时间尺度

只用 FIT 估计：事件间隔、各 mark 的可靠性、去时钟/观测质量后的滞后依赖、不同时间聚合对 within-event 模板与形态变异的保留程度。固定输出 1、5、30 min 和 2、8 h 的诊断，不按 SELECTION 挑最漂亮的尺度。

主状态历史先用 **2h**，目标为 **随后 5min** 的事件表达；5min 不是已知生理常数，是第一轮可计算的设计尺度。预先保留 30min 目标和事件 e 的条件内容检验。原 2h 提前量、随后 30min 目标单独复现。若真实测量延迟使 5min 任务不可用，登记 `MEASUREMENT_NOT_READY`，先修测量，不能悄悄换主目标。

## 3. 数据划分、独立性与旧结果的身份

E1096/E1125/E253 及已看过的 SELECTION 一律作为开发资料。先用它们复现问题和修正流程；不能因改名、换 seed 或换模型恢复“独立确认”身份。

每个患者的划分清单在训练前落盘：连续 FIT → INNER → 最晚审计段，记录所有 raw/event/target IDs。训练标签支持不得跨到 INNER，INNER 标签支持不得跨到测试；根据目标长度清除边界样本。测试可因果读取过去已经出现的无标签历史，不要求人为挖掉长历史；这不增加独立分母。

开发阶段同时报告：

1. **时间前推分割**：暴露真正的跨期分布变化；所有参数、normalizer、模板选择早于第一条测试查询。
2. **多个患者内前推折**：每折只用此前资料重新训练，用于观察单个晚期切分是否特殊。多个折仍来自同一个患者，不冒充多个患者。

需要新确认资料时，先只按有效记录/事件/标签可用性冻结患者或时间段名册，不按效应方向筛选。已有 development/sealed 的读取权限和用途需按既有合同明确记录；本方案本身不宣称已打开这些分区。

主损失先在同一物理窗内等权，再在窗间等权。时间窗因历史共享仍可能相关，置信区间按连续时间大块/记录 session 重采样；块长度只用 FIT 自相关或预设 2h/6h 敏感性决定，不能由测试显著性决定。患者是队列单位，seed 是优化重复。

## 4. 最小模型与对照：先把强基线救活

### 4.1 输入与输出

事件输入分开保存 rate/load、composition、coupling、frequency/mark 三类信息。计数使用 exposure 校正；composition 带 effective sample mass，不能靠事件更多就机械增大所有维度。初版使用现有可审计特征与 FIT-only 线性降维，不同时上线一个难以定位问题的深层 waveform encoder。

主 producer 学未来 5min 的 count、负荷和粗 community composition。三个 head 分开记损失，不允许用一条 weighted joint 曲线掩盖某个 head 完全没有学习。条件 composition 在实际有事件时评分，并明确其条件分母；计数在所有有 exposure 的窗口上评分。

**严格保留未训练目标：** 细触点身份、same-prefix continuation、完整细延迟、独立 waveform 形态。频带粗量若已参与 producer 目标，则该频带读出属于训练内端点；不能再称全新迁移。

### 4.2 预注册比较矩阵

| 臂 | 信息 | 目的 |
|---|---|---|
| C | 患者 FIT 常数＋时钟＋质量/exposure | 截距/时钟地基 |
| B | C＋非事件背景 | 背景能解释多少 |
| H_rate | C＋固定多尺度计数/负荷历史 | 排除“只是近期事件多” |
| F | C＋完整固定 marked history，保留七核 | 必须强且非饱和的历史基线 |
| L | C＋可学习线性时间转移的事件状态 | 学习历史整合是否必要 |
| N | C＋非线性时间转移的事件状态 | 锁定模型类内是否需要非线性 |
| B+F / B+L / B+N | 同家族加入背景，使用配对配置 | 给定背景后的事件增量 |
| 常数重拟合 / 未训练状态 / 错时 / 内容打乱 | 对应父臂之上，真正重拟合或严格同分母置换 | 排除适配器自由度、初始特征、时刻及纯计数解释 |

完整 F 必须直接有线性或 GLM 读出，不先经过饱和 Tanh。count 主头用 exposure offset 的 NB，dispersion 先只在 FIT 估计后固定，各臂共用；Poisson 为敏感性。负荷主头用 log1p 后 Gaussian；粗 community 使用条件 composition likelihood，并保存实际有效事件分母。线性头先用全批二阶/准二阶优化检验数值收敛；比较其目标与梯度容差，不只看迭代次数。训练、INNER 和测试必须使用相同的缺失标签归一化定义。

过去可见事件先按真实 dt 传播，再作事件写入。第一轮 L/N 共享相同的输入表示和**加性写入**，N 仅增加 `U tanh(Vz+b)` 时间转移项；输入依赖跳跃是另一个候选模型，不混入这次 N/L 解释。缺测和真实无事件分别记录。

这仍首先是观察器/预测状态模型。输入进入观察器不表示事件改变生理状态；第 8 节另设无未来观测的预测检验。

### 4.3 容量、初始化与优化合同

- 主状态维度 32、非线性秩 16；非线性读出为一层隐藏宽度 64 的 GELU。线性读出必须始终保留。只有小型功效/优化诊断表明确显示容量限制时，运行状态 64、隐藏 128 的预注册敏感性；不重复三档全面扫描。
- 参数量逐层生成：输入投影、A、U/V/b、各 head、背景、常数、冻结/可训练数，写实际 shape。固定 F 维度可不同，不能为了参数量相等删掉它的信息。报告匹配容量敏感性和完整强 F，两者不互相替代。
- 初始化保存真实张量/哈希，按 fan-in 缩放。所有臂都有各自充分优化机会，paired seed、数据顺序、batch IDs 一致。零初始化残差允许初始一步核心梯度为零，但必须记录之后是否真实更新。
- 先做 32 个真实训练样本的过拟合检查，以及损失/梯度/输出尺度测试。它不证明泛化，只排除明显实现和尺度故障。
- FIT-only 输入稳健缩放；读出使用 **在 FIT 状态轨迹拟合的可逆逐维仿射缩放**，和该 checkpoint 一起冻结。校准/重拟合必须在每个 INNER 候选的训练流程内完成，不能看测试状态确定均值。主动态方程不插逐样本 LayerNorm；它会改变状态的量与动力学。
- 神经部分 AdamW：候选初始 LR `0.001 / 0.003`，betas `(0.9,0.999)`，eps `1e-8`，weight decay `1e-4`，bias/尺度/dispersion 不衰减；梯度裁剪 2。选择仅用 INNER，并给每个承重臂同一搜索机会，不强迫相同最佳 LR。
- 每 50 次更新评价；patience 8 次、至少 400 次更新才第一次降 LR，此后每档至少 200 次；×0.3 两次。神经阶段初始上限 3200，仍改善的臂恢复到 6400。用独立验证曲线、FIT 拟合程度、学习率续训共同判断；仍预算受限则明确标注，不能把耐心停顿当数学收敛。
- 基线/常数也执行自己的充分性判断，不再统一砍在 1600。所有阶段的停止原因并列表；残差从初始化回退是有效选择，但不算状态已学成。
- 有效 batch 先固定为 128 个带明示权重的预测锚点；同一物理段共享历史只重放一次，microbatch 逐段累积，归一化分母固定。显存不足减物理 batch，不改有效 batch、loss 权重或历史长度。稀疏窗口按真实样本与权重处理，不填虚假事件。
- 使用激活重计算实现完整目标历史的梯度；不因计算预算默默 detach。长段审计分别记“计算上连通”“所选模型实际使用”“对 held-out 预测有用”。

## 5. 先校准新仪器；不再拿旧训练器的 toy 结果代替

### 5.1 世界库在看新人体效果前冻结

保留旧 `nonlinear_transition`，包括强度 1.0 上 N/L 分不开的历史结果。新增的世界不是为了冲掉失败，而是覆盖不同替代解释：

1. 只有时钟/背景/计数，没有额外 marked-state 信息。
2. 真实线性状态、线性观测；学习线性整合可优于固定核。
3. 线性状态＋非线性读出；不能错报成需要非线性转移。
4. 非线性转移＋线性读出，包含预先固定的交互和饱和参数。
5. 多端点共享原因与各端点独立原因两个版本；多头预测好不能自动判共享。
6. 纯观测增益/通道漂移与真实潜状态变化两个版本。
7. IED 只报告共同原因，与 IED 真有反馈两个版本；只用于 Q5 仪器。

同一 world 的观测长度、事件密度、噪声、缺失/release 模式按开发患者 FIT 资料冻结；不能借生成器提供真实人体没有的状态输入或更长记录。效应强度固定 `0 / 0.25 / 0.5 / 1`，完整报告；零强度是负对照。真值可给 oracle 分析，但不能给待测模型。

### 5.2 拆开“能否观测到”与“网络能否学到”

每个主对比运行四层：真状态 oracle → 经过本观测/延迟/缺测后的 oracle → 新训练器可学习模型 → 原分割及统计判据。若 oracle 都没有可检测差别，先标本任务不可区分，不能无限给 N 加步数。

每个新 pipeline 至少先做 2 个独立 data seed × 3 个优化 seed 的完整配对冒烟测试。随后以**独立 data realization**为单位，做每个承重对比至少 20 个 realization 的灵敏度曲线。优化 seed 不能代替数据重复。

20 个 realization 只作为功效筛查。需宣称“在效应 δ 上有足够功效”时，继续到足够重复数（初始计划 100），要求检出率的 95% Wilson 下界 ≥0.8，零效应假阳性率的 95% 上界 ≤0.1；若未达到，报实测区间，不称已校准。阈值只是本研究的仪器标准，不是生物学真值。

δ 先定义为相对强基线 **1% 的预测损失改善**，并同时报告 0.5%、2% 敏感性；这是可检测预测效应界限，不是临床意义界限。后续阴性需同时给置信上界/等效性结果，不能以 P>0.05 替代。

**硬依赖：** 新人体负结果不能绕过“同训练器、同观测、同端点”的功效判断。新仪器没实现时，优先实现它；不准先用长历史/单视图备用队列填掉这项工作。

## 6. 人体主检验：分清总信息与背景条件增量

第一批固定三位开发患者、3 个优化 seed。先跑 C/B/H_rate/F，再跑 L/N；每个患者的全部预注册臂保留。主结果不按患者胜负挑模型容量，也不因初始化被选中删除该 seed。

第一批神经主头为线性；非线性读出进入第 8 节的完整定位矩阵。固定种子 `20260906/07/08`。每患者 L/N/B+L/B+N 四臂，先在首 seed 各试两个 LR（合计 24 次拟合），各臂按 INNER 选择 LR 后跑另两个 seed（再 24 次）；上限 48 次神经拟合。C/B/H_rate/F/B+F 的确定性 GLM 共 15 次，不复制为伪 seed 重复。是否能在一晚全部完成由实际吞吐决定，不能挤占 P1 新仪器。合成冒烟 data seeds 固定 `391101/391102`，后续重复顺延并保存 manifest。

各端点均报告以下配对：

- **事件总预测价值**：F/L/N 对 C、H_rate、常数/未训练/错时；这允许事件与背景包含共享信息。
- **学习的必要性**：L/N 对非饱和、充分拟合的完整 F。
- **背景条件增量**：同家族 B+E 对 B 及其重拟合常数的更强者。不能把 event-only N 与 B+F 的差叫“只加背景”的效应。
- **事件内容的贡献**：保持真实事件时刻、计数/负荷和 exposure，只在预先匹配的时间块内置换其余内容；另作保留主要 mark 边际分布的次序破坏。置换损害只能辅助解释，主证据仍是重拟合对照下的 held-out 增益。

选择和评分分别列 raw count、条件 composition、负荷。联合目标权重从 FIT 固定，但每个主端点都有独立判定与分母，不能把空间平坦掩盖 count 崩溃。少于两个有数据的测试时间大块只称个案描述，仍保留结果，不写可靠重复。

H=0.5/2/8h 为嵌套历史比较；16/24h 只在 8h 仪器灵敏、资料覆盖允许且共同锚点充足时运行。比较同时区分有效历史、可用事件数、初始化边界；超过短历史的收益才支持更长记忆。长程梯度非零本身不给长记忆功能结论。

## 7. 同一个 checkpoint 的事件内部形态与网络桥接

### 7.1 冻结协议与端点

producer、输入 normalizer、患者模板/轴先冻结，只用 FIT/INNER 训练新的低容量适配器。主头为线性＋ridge/合适的 likelihood；隐藏 8 或 32 的非线性头只作敏感性。对照使用相同可用 prefix、触点 mask、观察支持和优化机会。

端点至少分为：

1. **触点身份**：给定同一 prefix 和实际集合大小 K 的 exact set NLL；它只检验条件身份。K 的预测单独计分，不能称已预测完整集合生成过程。
2. **same-prefix continuation**：分叉资格完全由 FIT 的前缀和后续多样性确定；错时供体和正确状态严格用同一事件子集。
3. **STOP / extent**：独立训练、独立选择与报告，不把 STOP 的改善替代 subset。
4. **route/相对延迟**：只在共同有效、已招募触点上；方向、集合、同步程度各自记账。
5. **细 waveform/频谱形态**：使用未纳入 producer 目标的特征；测量质量和物理单位随表附上。

为触点通路构造已知 state→identity 耦合的正对照，保留原 prefix、K、触点有效性和真实分母。另有只影响 STOP、只影响 rate 的世界，要求不能错误报成 identity 信号。必须通过新主头流程，不借别的特征臂改善代替。

### 7.2 多端点不等于共同状态

第一批至少执行一次 leave-one-view-out producer：不以空间视图作训练目标而检验空间迁移，或不以负荷视图作目标而检验负荷迁移。历史输入可以包含过去该视图，目标的“未训练”与输入的“从未见过”是两个概念，明确写清。真正强调信息共享时，再做去掉该视图历史输入的严格敏感性。

建立证据表的主键：`patient / producer hash / input recipe / selection rule / freeze time / query time / split / endpoint / arm / physical support`。至少在同一患者同一状态上出现功能预测与未训练表达的可重复改善，才称证据链候选；不能用 E1125 的状态、E253 的形态、E922 的发作拼接。

### 7.3 接回已经存在的事件内网络结果

患者的固定触点/传播骨架作为 trait。优先读取现有 masked 模板及 `results/interictal_propagation_masked/template_gradient_fields/per_subject/` 的冻结语义；逐文件核验 producer/hash、通道名称、有效 mask 与 early→late 方向。不能仅因旧目录存在就把它作为新确认资料。

比较：固定 trait 预测、trait＋近期频率、trait＋状态调制。问的是状态是否改变同一骨架上的 occupancy、coupling、方向权重与局部表达，不预设空间骨架必须移动，也不预设全部 ictal 路径是 IED 重放。

例图必须在 FIT 定义的 prefix、时间区间和状态分层规则上生成。若缺少共同支持，报告不可估并画支持分布；不按测试期有无漂亮分叉重新选例。PC1 中位数分组失败不是所有状态表达检验失败。

## 8. 非线性与自主时间演化：单独验收

首轮至少保留四种组合：线性转移×线性读出、线性转移×非线性读出、非线性转移×线性读出、非线性转移×非线性读出。输入特征构造相同；完整 F＋非线性读出也保留。锁定模型类后比较，不能声称潜变量非线性具有坐标无关的唯一物理解释。

在所选 checkpoint 上：记录 N 支路近线性余项、局部 Jacobian 随状态的变化、用 FIT 最佳仿射近似替代后的输出变化，以及重新拟合 L 的 held-out 对照。一个 ACTIVE 标记不够。

**观察器停止接收未来输入时，不可把“没有未来观测”误当“未来真实没有事件”。** v0.3.10 的 event-input=0 重放本身不构成这个检验。必须区分两种任务：

- 已观察历史后的直接多提前量预测：有用，但不单独证明自主 latent flow。
- 冻结到时刻 t 的状态分布/估计，之后不读任何真实未来事件，只用自身模型预测未来观测：才进入自主预测层。

第二种若需要新增生成模型，使用最小潜状态模型，而不偷换现有 observer：`z_next = f(z, dt) + process_noise`，`y ~ g(z, exposure)`，因果过滤器只读过去。f 使用上述 L/N 两类，g 使用线性/非线性两类；过滤器结构、训练目标、状态宽度和计算机会相同。训练用 causal filtering/预测似然或明确的变分下界，记录 KL/后验坍缩；不能让平滑器在预测时读取未来。

先在第 5 节真值世界证明这套生成模型可识别目标，才跑人体。未来 count/mark 用模型预测分布边缘化，缺测只失去观测，不当零事件。若这项在一晚内无法完成，就将 Q2b 自主证据记为未运行；不把短时观察器的成功改名来补位。

## 9. 发作稀缺：主研究不再被临床预测条件拦住

### 9.1 S-A：患者内冻结关联，作为当前主层

沿用按 6h 分簇的主台账，2/12h 为敏感性；使用 SQL/onset 与可用原始资料核对。一个簇只贡献一次独立病例对比。病例窗口固定 `[-2h,-0.5h]`；`[-30min,-5min]` 作为近时敏感性，仅在真实低延迟测量达标时可用。前次发作后主洗脱 2h，0.5/8h 分层敏感性，不把短洗脱混进主队列。

对照同患者、相近时钟（±2h）、相同记录/测量阶段、覆盖差 ≤0.1、既往发作距离档匹配；若背景/睡眠标签可靠，另报条件匹配。限制对照复用，保留全部候选和选择概率/规则。一个有效对照可描述；两个以上增加支持但不创造可靠性保证；无对照则只画轨迹，标 `MATCHING_NOT_ESTIMABLE`。

间期数据先冻结功能坐标：预期负荷、触点概率、谱/形态读出。主关联为这些预先冻结的预测分布相对患者 FIT 参考的偏离；同时完整报告有方向的功能坐标。不能只用一个 PCA/Mahalanobis 半径判断所有发作特异状态：不同方向可能有相同半径。

比较 E、B、B+E、F、未训练、时钟/近期事件量，保持配对。报告每簇的病例−参照效应、秩、可用窗口和事件数；少量患者/簇不做种子投票式显著性。置换只在真实可交换的时间块内；对照数少时显示可达到的最小 P 值。没有共同支持不外推配对效应。

### 9.2 S-B：跨发作簇迁移

有至少两个簇时可做留一簇检验低维方向/读出。训练集合可能含测试簇之后的资料，所以称回顾性跨簇迁移，不称前瞻预测。上游保持仅间期训练，并在每折审计可能重叠的 peri-ictal 支持。一个簇时不训练新的高维发作分类器。

### 9.3 S-spatial：连接发作早期空间场，允许少量发作

在 onset 前冻结得到预测触点概率/固定网络上的状态权重，不使用 ictal prefix、实际早期 K 或发作场选模型。只对有独立秒级标签的病例评价 onset 后 0–10s 空间能量场及 0–30s 招募顺序，按名称对齐有效触点。

先与患者间期固定平均场、近期事件场、背景场和原固定网络 trait 比；有早期发作训练资料才加过去发作平均场。绝不使用所有发作的平均场来预测其中一场。空间 null 包括同杆/活跃度匹配，避免几何与触点活跃率冒充路径特异性。

即使只有一次发作，也能贡献“冻结间期空间预测与该次发作的对应”个案证据；不能据此估计临床敏感度。预测场对应、方向关系和路径重放分别表述。

### 9.4 S-C：连续风险是条件分支

只有完整连续风险集可用才启用。固定 5min 查询网格，预测未来 `(30min, 2h]` 内首个发作簇 onset；排除已经发作/注册洗脱期与未观察时段，记录删失及实际 exposure。过去的全部 producer/normalizer/选择/发作读出参数冻结时间必须早于每个测试查询。

先用低维、正则化离散 hazard 或点过程模型：时钟＋过去发作＋近期事件/完整历史＋背景，与加状态的嵌套模型配对。不能以匹配病例/对照抽样直接训练绝对风险；若必须抽样阴性，保存采样概率并使用正确权重/截距修正。

报告 log score、Brier 及相对 FIT 学到的基准风险的 skill、校准、预警时间占比、误报/有效小时。重叠预测窗以时间块评价，一两次测试发作只列个体预测和巨大不确定度。S-C 不具备条件时，S-A/S-spatial 仍可正常完成。

## 10. 漂移诊断与 Q5：避免产生新的假机制

### 10.1 漂移

同一输入/输出单位中分别比较：原始测量与质量漂移、固定历史变化、未训练状态变化、训练状态变化、读出误差。报告 FIT 分位区间之外比例、联合距离/邻域支持、按时间的误差。PCA 符号只用于绘图，跨 seed 在预测函数空间或对齐后的表示比较。

两条已注册干预式工程敏感性：FIT-only 可逆缩放；只在过去可用的校准段调整观测映射并冻结动力学。后一条属于适配实验，单列，不与完全冻结预测混合。若有睡眠/用药/参考变化，优先做有标签的分层。不能为了“消除漂移”使用测试结局或强迫发作前后分布相等。

### 10.2 Q5 事件反馈

先比较共同慢原因且无生理事件反馈的世界，与显式 event jump 的世界；两者都允许 observer 在看到事件后更新。时间戳、事件测量延迟、背景和未来独立观测一致。先验证在这个观测设计下可区分，再申请人体解释。

人体预测端点必须是独立未来背景/表达，而不是模型自己的状态跳变量；控制事件前状态、近期计数/负荷、时钟、观测质量，并做状态匹配的事件/无事件、内容/计数保持对照。即使反馈模型预测更好，未测共同原因仍可能解释；只能称反馈式预测依赖。生理因果仍需适当干预、自然实验或更强识别假设。不得预设“每次 IED 都影响病理状态”。

## 11. 执行顺序、算力与停止条件

### 第一轮 8–10h 是实现/判别窗口，不保证科学闭环完成

| 优先级 | 工作 | 后续依赖与可交付物 |
|---|---|---|
| P0 | 报告勘误、测量 availability、可靠基线、哈希/resume/锁/identity 修复 | 任何影响输入/评分的问题先定位；输出缺陷复现及修复验证 |
| P1 | 新训练器的独立合成配对、oracle/已知身份信号测试 | 未实现/失灵时先完成它，不能跳去更长历史 |
| P2 | 三位开发患者的最小近时表达矩阵与冻结同家族迁移 | 仅在测量和拟合已合格时运行；保留所有负结果/初始化回退 |
| P3 | 跨视图、S-A/S-spatial 台账与分析 | 与训练可并行；无稀缺发作训练门槛，但必须守冻结和共同支持 |
| P4 | 长历史、4 类转移/读出定位、独立生成模型自主检验 | 只在相应仪器与支持具备后运行；否则产出明确未决原因 |

两张 RTX 3090 的 8–10h 是 16–20 GPU-hours。初始资源分配为新仪器/基线诊断约 40%，人体最小矩阵与冻结验证约 40%，剩余 20% 用于必要重跑/扩展；按实测吞吐调度，不能把卡数当科学产出。运行有意义且已合格的待办以利用 GPU；没有合格 GPU 任务时记录原因，不启动无关扫描制造满载。

显存预检必须用最大实际 shape 跑完整前向、反向、optimizer step、checkpoint 保存；一 GPU 初始一任务。24GB 卡的调度上限设为 **18GiB 实际峰值**，保留至少约 4GiB 余量；并行任务只在实测峰值总和满足上限时放行。physical microbatch 依次减半，保持有效权重和完整梯度；不混入降低科学历史长度的 OOM 重试。一次 OOM 记事故、清理本单元进程后从一致 checkpoint 重试；反复失败标资源不可运行，不能更改主 endpoint。

每个单元 ID 绑定 config、数据、split、源码 manifest 哈希；使用跨进程文件锁，写临时目录后原子发布。已存在结果必须比对身份才可复用；不得凭 `card.json` 存在就跳过。snapshot 保存优化器、调度、所有 RNG、batch 位置和版本；恢复测试覆盖背景→事件→常数和 LR 降档边界。

每 30s 监控进程/显存/卡状态；5min 无 GPU 活动且有合格待办才触发调度诊断。9h 不新开预计不能在截止前形成完整配对的任务；9.5h 保存状态与汇总；10h 交接运行/完成/失败/未实现的完整台账。不会因到时停止就写“收敛”。

## 12. 最终验收与交付

1. 修订报告及逐条勘误表，保留旧产物；所有数字从机器表生成。

3. 每层参数/初始化/更新、所有阶段 LR/预算/恢复/非有限值和峰值显存。
4. 每个主对比的功效曲线、oracle gap、训练和数据 seed、失败正对照。
5. 同一 checkpoint 的近时预测、未训练视图、长历史、发作关系证据表。
