# 下一阶段设计：端点先验双核的局部连接与传播范围搜索

日期：2026-09-10。状态：**设计与候选表已准备，尚未实现新版物理、尚未派发正式仿真**。这份方案回应用户要求的“除了位置，什么参数控制每次事件的招募范围，并能否恢复患者两模式”。不把历史位置试验延长，也不将拟合分数或两个分类标签当作传播恢复。

## 2. 先固定新版物理定义

新版拟命名 `core_connectivity_v2`；现有`core_driven_input_v1`和位置试验物理源保留，不原地修改。

1. **两核均只降低E阈值。** 对每个E细胞保留固定潜在阈值抽样，`Vth=18−a_k d_i`，`d_i=max(18−Vraw_i,0)`；核外为对应背景值。沿用11 mV下界并记录截断量。核编号交换不得重新抽样；不把抑制连接的作用混进升E阈值。重叠情形取较强降低、不叠加；本轮几何边界尽量避免重叠及截边。
2. **随机外部输入仅加载E-core。** 核内保留共享OU调制和独立Poisson到达；空间局部OU关闭。核外E及全部I不再接受独立随机Poisson到达，而以原时变基线的期望到达量`nu_signal*dt`进入同一突触滤波器。背景平均驱动保留，外部随机波动去除；不强迫核外神经元静默，核外仍可由递归连接放电。
3. 上述第2项是对用户“噪声只能驱动核”的严格实现，**比已完成的仅OU限核版更强**。每个布局的新基线与已完成旧输出配对报告，不能把输入改变后的结果全部归因于连接。去外部噪声不保证所有事件都由核因果起始，也可能改变背景易感性，这是本轮明确的模型假设。
4. 不加入kick、按模式指定起点、沿SCL定向刺激或事件后reset。两核共享同一固定网络，不为TA/TB分别拟合两套连接。Z/M、旧慢I外部状态、空间OU均关闭；GABA18 ms和其他时间常数固定，不用延长GABA追赶患者HFO宽度。
5. 新引擎实际输出核内外阈值、输入期望/方差、静态数组身份和应用后边权。核外输入应是确定量，但核外膜电位及发放仍可因递归活动变化。只保存controller输入不能算参数应用验证。

输入桥直接复用三个旧位置×两条噪声的20秒输出，新基线属于下方正式预算；不重跑历史旧图，不把旧全场Poisson版纳入新版连接搜索排名。

## 3. 位置初值和连接作用域

保留三个有不同残差的布局，右核始终从(16.47920304, 3.96551153) mm开始：

| 布局 | 左核中心(mm) | 保留原因 |
|---|---|---|
| 端点几何原位 | (4.19921432, 9.12890135) | 保留原先验与两类事件参考，不能因SCL缺失提前删掉 |
| 原位上移4.5 mm | (4.19921432, 13.62890135) | 两杆参与明显增加，检验连接能否缓和模式取舍 |
| 靠近上部SCL | (5.71218492, 13.57404719) | 已有少量SCL9参与，检查横向范围与完整ICL时序 |

初始半径均为1.7525782906 mm。参与加权中心作为已完成的历史对照保留；当前与原位仅约0.3 mm之差，不为它重复整套连接扫描。联合阶段允许各中心局部±0.75 mm，但这个范围是工程搜索边界，不是患者位置置信区间。

E_A/E_B按阈值圆形几何定义，I_A/I_B按同一圆选择I细胞；O为两圆之外。同一核内、两核之间、核到外部、外部到核分别统计，不以“core相关边”混合。主要核内权重对两核施加相同因子，先测共享作用；后续选定通路允许A/B不等，并保留其实际值。局部I成员不复用已关闭的旧慢I状态mask。

现有E→E核为旋转椭圆指数核：`K=exp(−sqrt((u/l_parallel)^2+(v/l_perp)^2))`。当前名义尺度约0.537/0.269 mm，**不是硬半径或实际平均边长**。默认增加轴比会缩小横向尺度，因此本轮独立调整`l_perp`和`l_parallel`。轴为双向对称，不预设向某个SCL触点的单向扇形。

## 4. 参数范围与希望区分的作用

表中的倍数相对于各布局新版基线，数值是初始工程范围，不是已估计的患者参数。

| 参数 | 第一阶段探针 | 联合阶段允许范围 | 主要要回答的问题 |
|---|---|---|---|
| 同核 E→E权重 | 0.75、1.25× | 0.6–1.5× | 局部发放是否得到放大，还是变成过强同步爆发 |
| E_core→E_out权重 | 0.75、1.25× | 0.6–1.6× | 核内活动能否离开核、招募更远区域 |
| E_out→E_out权重 | 1.15× | 0.8–1.2× | 离核后能否逐级接力；是否出现核外自维持活动 |
| 同核 E→I权重 | 0.75、1.25× | 0.6–1.4× | 局部兴奋如何招募抑制，是否过早终止传播 |
| 同核 I→E权重 | 0.75、1.25× | 0.6–1.4× | 反馈抑制如何改变可输出活动、模式取舍与时序 |
| 同核 I→I权重 | 0.75× | 0.6–1.4× | 改变抑制网络后是否发生去抑制或持续活动 |
| A核降阈值幅度 | 1.5× | 0.5–2.0× | 改变左核被访问的概率及活动量 |
| B核降阈值幅度 | 1.5× | 0.5–2.0× | 与A核分开，避免总把一种模式推向主导 |
| A核半径 | 2.5 mm | 1.4–3.2 mm | 扩大支持域是否改善SCL，实际调制量如何变化 |
| B核半径 | 2.5 mm | 1.4–3.2 mm | 改变另一端招募，是否与A核作用不同 |
| E_core→E_out实际连接数 | 1.5× | 0.7–1.6× | 更多独立靶接触能否区别于单条边变强 |
| E→E横向核尺度 | 1.5× | 0.75–2.0× | 前沿能否横向展开，还是因局部连接稀释而失败 |
| E→E纵向核尺度 | 1.5× | 0.75–1.7× | 纵向跨区招募距离和时延的作用 |
| E→E轴方向 | −15°、+15° | 参考轴±20° | 实际连接方向是否改变两杆传播，不能只看名义角 |

前三类EE以及三类EI/II干预必须用明确的前/后突触mask应用。尤其不能直接修改旧`Params.w_EE`当作纯EE干预，因为该参数还参与派生I→E权重；`w_IE`在旧代码表示E→I，不按缩写猜方向。

**权重、密度、范围是三个不同实验。** 权重干预保持边和时延；密度增减只改变E_core→E_out块，每个外部E靶的该块入边数取基线数量乘因子后确定性取整，未改边不补偿。扩展所需候选边使用固定拓扑随机键，排除自连接/重复；记录实际零基线靶，不能声称度数乘子会自动覆盖这些靶。

范围/方向干预重采样E→E对应靶的入边位置，保持该通路总入度基线；其他三类连接保留。第一阶段范围变化覆盖整个EE传播介质，以便传出核后仍能接力，不把范围变化伪称为仅core内改变。新边时延按原距离/传导速度规律重算。这时保留的是神经元位置、异质性和拓扑随机身份，**不是完全相同的邻接图**。固定旧边的重加权不能冒充连接范围或密度变化。

几何变化先产生该布局的阈值与输入支持，再定义其连接mask；记录实际成员数、降阈值总量、噪声支持细胞数和每条通路总权重。扩大半径同时改变这三者，不称为单纯阈值覆盖因果效应。主搜索不强制总量守恒；确需归因时再做一个匹配干预，不用补偿抹掉用户要测的效应。

## 5. 固定第一批，再做真正受数据影响的联合搜索

**第一阶段：3布局×(基线+19个单参数探针)×2噪声=120条20秒运行。** 上表已列出全部19个探针；候选在派发前固定。拓扑2511，配对动力学种子847101/847102，完整窗口起点≥1.5秒才进入正式事件分布；所有检测和完整连续输出都保留。阶段中即可自动产生每个参数的响应图，不等待选出一个最佳模型才画图。

最多6条0.5秒短程工程检查用于新输入、局部权重、实际加边/重采样的应用核对，不以传播好坏卡住第一阶段。若某条运行达到冻结runaway定义，保留物理状态及此前输出；工程OOM另记。当前完整正式120条未启动。

**第二阶段：最多16条件×2噪声=32条20秒运行。** 第一阶段完成后，对每个参数报告两条噪声的逐项差值，选择两个保留互补响应的布局作为两个人口。各人口保留8个有效父代；最多放松6个有响应的参数，不把所有范围一次性当成已覆盖。优先保留“横向范围×向外连接数/权重”“核半径×降阈值强度”“离核输出×局部E/I反馈”中的有依据组合。未进入的参数照样在响应图中展示，不写成已经联合优化。

每人口先生成4个DE/rand/1/bin后代，完整批次后统一替换，再由更新后的父代生成4个；两个人口共16。固定F=0.6、CR=0.7、提案随机流，父代快照、donor索引和目标索引落盘。第二批实际参数依赖第一批得分后的替换，不使用同一个旧快照把“随机追加”称为自适应。反射处理边界，几何无效点重新提案并保存拒绝记录；不启用polish或其他隐含评估。

**第三阶段：4条件×2新拓扑×2新噪声=16条60秒确认。** 保留一个新版原位基线和最多三个互补候选，共同使用新的两个拓扑与两个动力学随机身份。新种子在阶段启动前检查未使用并冻结；同拓扑下静态身份相同，不同噪声重演改变动力学输入，不把二者混成一个legacy seed。新拓扑无需重拟合是更强的迁移检验；失败不自动证明固定网络无法拟合。

总上限为168条正式运行，第一阶段120条是可独立审阅的主要里程碑；确认时长60秒的作用是增加实际支持量，不假定传播形态会随运行更久自行改善。任何阶段不按“两标签出现”作为逐运行硬门。完成后停科学审阅，不自动冻结模型、进入Fig5或无限扩大搜索。

调度按真实进程树内存派发，初始2 worker，测得峰值后最多8个；保留机器至少40 GiB及其他任务余量，图生成/压缩也计入。当前引擎主要CPU运行，不为占用GPU而更换物理。图缓存从不可变基线计算，不把上一候选的权重继续相乘；重启恢复原提案不重新抽样。实际墙钟时长由canary估计，本设计不承诺在8小时内完成。

## 6. 优化怎样奖励患者分布，验证怎样发现失败

第一阶段参数表不依赖损失，因而不用等新评分得到好结果才运行；正式联合阶段前冻结以下最小调整。

保留当前多事件去自配对分数`L_off`，包括现有患者FIT、特征、模式特征与正尺度。它已经包含参与、rank/质心时差信息，不能说旧损失完全没看参与。新增显式的**全15触点联合参与掩膜分布**项，避免只提高SCL平均参与或以ICL全部参与代偿。

对事件二值掩膜b，用混合核`k(b,b')=mean_h exp(−Hamming(b,b')/h)`，固定h=1、3、6个触点。使用模型去对角自配对、模型—患者交叉项及固定患者自项计算`D_mask_off`；不是各触点参与误差的简单相加，能区分“同一事件的两杆都出现”和“不同事件分别出现一杆”。患者目标使用完整FIT自然频率，不用人为平衡的32+32包或Fig2C两例估计比例。

提议联合阶段排序：`L_search=0.5 L_off + 0.5 D_mask_off/a_mask`。`a_mask`从患者FIT固定记录块匹配样本量的**非负有偏距离**分布取正中位数，记录实际块来源/样本量；若不可建立正尺度则联合阶段先保留旧分数并报告，不以机器epsilon构造极大新项。0.5/0.5是设计权重，不叫总体恢复率。患者参考尺度冻结后不按候选表现改动。

新旧分数同时输出。去对角项允许负值，不截断、不额外惩罚模型事件方差；按网络/噪声等权，不将事件多的运行作为更多网络。原`N<16`记不可评分的本轮约定保留：不伪造巨大loss、不进入总榜；几何向量可用于提案，可评分后代替换不可评分父代，两个不可评分者不比较拟合优劣。两个训练重演需各自可评分才有正式条件均分，实际支持不足单列。

新掩膜项只需离线用现有输出检查：准确的患者联合掩膜分布、把两杆参与拆散、把所有触点都打开、频率偏移/散布收缩，是否得到预期排序。此检查验证统计量奖励方向，不等于患者传播验收。它不要求额外仿真，也不恢复16事件稳定性方差惩罚。

**这仍是分布选择工具，不能通过加一个参与项就保证真实路径。** 每个候选还要按以下层次交付，阶段二提名保留分数赢家和参与—顺序—时差有不同优势的候选；提名规则及权重在看新候选之前固定，不在GIF中挑一个好看的事件覆盖多数失败。

| 观测 | 具体定义与比较 | 是否用于本轮主排序 |
|---|---|---|
| 参与 | 完整15触点联合掩膜，逐触点概率，两杆共同参与；全部/TA/TB分别展示 | 联合掩膜入新项；旧特征也含参与 |
| 顺序 | 两触点共同参与时，质心先后概率；每对实际支持量，缺失不填零 | 已在旧特征中；逐对图另展示 |
| 时差 | 同事件触点对质心时差分布，跨杆间隔；实际ms，不只相关系数 | 已在旧特征中；单项均值/中位数及散布另展示 |
| 早期招募 | 完整包络t10/t50的相对时序、招募跨度；不把质心或t10叫作真实起燃点 | 开发验证；患者波形小包按其真实来源使用 |
| 局部持续 | 每触点t90−t10，窗口截断、完整包络与重叠度 | 诊断；当前不以85 ms为GABA拟合目标 |
| 空间过程 | 同一真实SEEG几何的时序帧、核内外全原生活动、早期位置/多热点和源—模式关系 | 开发验证；不加入命名路线、指定core先发的奖励 |
| 模式支持 | TA/TB频率、各自完整条件分布及患者邻域外事件；实际事件量/块参考 | 保留旧模式特征；标签齐全不作验收 |

每个分布同时报告模型与患者的均值/中位数、5–95%范围和联合关系；运行是主要比较单位，事件是运行内部样本。条件模式少不能填零误差，也不能由标签占比一个数断言能力消失。模板类别不预设对应哪个core，患者细路线仅作开发对照。

## 7. 必须先产出的图，以及结果如何改变下一步

1. 每个参数一组配对响应：整体、TA、TB分面；各触点参与、两杆共同参与、顺序、时差、局部宽度、两核活动和实际N。横轴写真实参数值，细线为噪声重演，图注注明权重干预保持邻接、密度/范围干预改变邻接。
2. 保持SEEG布局的2D参数图及同网多事件原生GIF，颜色只能在一张图内表达一种量。阈值/权重图和活动先后图分开，不把名义轴当实际传播箭头。
3. **患者Fig2C TA/TB黑底完整包络在最左，候选与其直接基线在右。** 不按rank重排，不拉伸毫秒轴，不删未参与触点背景。黑图为通道×时间包络，不冒称已恢复HFO频谱。各运行按模式取最接近自身均值的例子，同时交付按时间排序的全部事件图；稀少模式和缺模式留空并标N。
4. 新拓扑/噪声确认后，给出参数效应的逐运行配对差值。候选成功不等于某个参数有因果效应；联合候选的参数归因仍以第一阶段单参数和必要组合对照为准。

若增大离核EE只让核外总活动增加、上部SCL时序仍错，不写成范围恢复；若扩大横向核后覆盖增加而传播减弱，检查范围×连接数的交互；若参与改善但TA被压制，比较A/B阈值/半径与局部抑制，不再只继续扩大左核。若两核都有活动但始终缺一条患者相容的原生路径，本轮报告结构残差，停止重复同一参数域，不自动追加状态或第三core。

当前已有位置响应与历史范围响应足以启动这一**有先验的连接实验设计**，尚不足以保证会获得两个患者相容模式。成功标准是完整患者局部传播分布与黑底/原生图共同改善，并在新噪声有支持；用户目视验收仍保留。
