# corrected rate 高活动端能力测试

用户最新明确授权：不等待最终SNN间期工作点及低端定量保真，直接测试持续振荡能力。这替代旧流程中本项必须等待V1/V2通过的执行顺序；不会把低端验证改标为通过。

科学问题是：目前corrected spatial rate方程，在固定一套实现图、恒定背景输入下，能否到达持续振荡状态？若能，匹配的SNN是否支持该现象？一个底物的阳性结果证明该实现具有这种能力，不证明所有双核几何都具有该性质，不指定患者发作工作点。

复用已经身份重建的 `v2_1_pop1_de_b_002/topology6101` 作为能力测试载体，避免把尚未辨明的两个中部历史版本混合。保留实际延迟、经验阈值组和两级突触；群体响应沿用已开发的输入相关性修正与E/I响应时标5/2.5ms。混合GABA输入修正仍是待检验近似，尤其较长GABA时间常数超出小相关时间展开的安全范围。

控制量只有全局GABA突触jump倍率 `q` 与GABA decay。q同时作用于I→E和I→I，rate均值项乘q、方差项乘q²；它不是活动依赖Z的连续耗竭，也不是旧模型只改core Z的干预。tau decay改变孤立电流的时间分布，按原归一化低通约定不改变无限时窗脉冲面积。Z/M动力学关闭，不添加新的全局抑制池。

初轮q={0.25,0.5,0.75,1,1.25} × tau_GABA={9,20.61155048,42}ms，10×10空间格、dt0.1ms、3秒，从100Hz E/I历史和对应稳态突触期望初始化。关闭两种OU，保留恒定标称外源Poisson率在diffusion transfer中的均值与方差。输出1ms局部E/I场，末半窗按三段检查振幅驻留，频率不限制在30–80Hz。同时检查群体平均和全部局部格，避免异步波被平均掉。

初轮候选筛选是开发诊断：末半窗至少8个有prominence的峰、周期CV<0.25、最后/最早分段振幅比0.7–1.3，绝对振幅≥1Hz。所有均值、峰谷、绝对/相对振幅与频率同时输出；较小周期纹波单列，不将微小平台纹波命名为发作。慢频率、非平稳或多频结果保留为未决，不机械判成无振荡。

阳性或边界候选需要更长观察、减半步长并保留同一物理延迟、低态初值、1mm格以及同q/tau的SNN对照。必要时按初轮转变区做有界细化。只有实际持续轨道和边界对象明确后，才决定计算固定点Hopf、周期轨道失稳或其他机制；频谱峰不等于Hopf。
