## 0. 这个提案要修什么（先讲人话）

上一轮我们要给"每个模型 spike 搬多少钾和钠"选一个合适的量。预先定了三个候选和五条判据。跑完发现
三个候选都没同时满足五条，于是初稿写成了"没有可行的尺度"。

**这个写法有三个毛病，本提案就是修这三个。**

第一，**我们中途换了被测的东西**。原计划是在一个小网络上、把离子的反馈打开来测；实际做的是在真正的
40k 基底上、把反馈**关掉**、用录下来的放电重放着测。换的理由是对的（小网络那次的测量本身坏了），但
**换了对象就不能继续用原来那份合同的判决权限**。

第二，**有一条判据在逻辑上把自己封死了**。"连着来的事件能不能累积钾"这一条，是在**故意切断**
"钾多→更兴奋→放电更多→钾更多"这条回路的情况下测的。然后我们用它去禁止进入下一阶段——而下一阶段的
全部目的，恰恰就是去测那条被切断的回路。这等于用一个刻意关掉正反馈的实验，去证明不该去测正反馈。

第三，**有两条判据的参照数是在"静息"状态算出来的，可这套离子层按设计根本不待在静息**。就像拿一辆
空载的车的刹车距离，去要求一辆一直载着货的车。

**修完之后不是让它通过**，而是让每条判据测的东西和它被用来做的决定对得上。

## 2. 三条判据的具体问题与建议改法

### 2.1 `5σ_rest`（可测门的相对项）

- **现状**：实测 `σ_rest = 0.109 mM`，使门槛变成 0.547 mM（而绝对地板只有 0.15）。
- **问题**：`σ` 被称为"静息波动"，但这个基底每秒放 **2.2 次**自终止事件，而 `tau_Ko ≈ 0.57–0.65 s`，
  钾**从来没有**回到过一个安静基线。0.109 mM 量到的是**持续的、由其它事件驱动的钾起伏**，不是噪声地板。
- **建议**：二选一，由审阅决定——
  (a) 删除相对项，只保留绝对地板（"膜必须看得见"这个原意由 0.15 mM 承载）；
  (b) 把 `σ` 重定义为**同一格在事件间隔内的残余起伏**并显式声明它包含邻近事件的贡献，同时把倍数从 5
  下调到与该定义相称的值。
- **注意**：spec rev3 当初加绝对地板，正是为了防止"初始化越好门越松"。改动**不得**把这个保护删掉。

### 2.2 钠恢复：衰减带 + 单调性

- **衰减比例**：参照 30.8% 来自静息 `tau_Na = 54.42 s`。工作点上是 37.9 / 29.6 / 21.3 s
  → 41.0% / 49.1% / 60.9%（f' = 0.5 / 1.0 / 2.0）。实测 68.2% / 65.5% / 77.2%。
  **建议**：参照按各 `f'` 自己的工作点算，且必须用 **(Na, K_o) 二维耦合** Jacobian，不能像本轮的审计
  那样把 K_o 冻住——冻住 K_o 会低估清除速度（见下）。
- **未验证的缺口**：即便用工作点参照，实测仍偏高（68 vs 41）。**目前唯一的假设是**参与格中同时抬高的
  K_o 会进一步抬高 `I_pump`。**本轮没有验证它**。建议在 T7.1 中加一条**钾钳制对照**（把 K_o 固定在
  静息值重放同一 kernel），代价是一次纯离线重放、**无需新仿真**。
- **单调性（本轮遗漏的一支，已补做诊断）**：`na_excess_monotone_nonincreasing` 三档全为 `false`。
  实测（归档 §3.3）：约 **47%** 的原始样本向上，中位步长只有峰值的 0.1–0.2%，但存在达峰值 **12–18%**
  的大向上跳变——那是重放背景里的其它事件落在同一批细胞上。**平滑救不了**：1 / 2 / 5 / 10 秒四种箱型
  平滑后**仍然**含上升步（这一点已实测，早先"1 秒平滑即单调"的猜测已撤回）。
  **但三档都没有"峰后净上升"**。
  **建议**：与衰减比例**解耦**，改判 **"从峰值到 20 s 无净上升"**（三档都过），**不要**用"平滑包络
  单调"（三档都不过）。诊断轨迹见 `b1_f_selection_traces.npz` 的 `f*_na_excess`。

### 2.3 钾积分：降为 non-blocking

- **参照同样锚错**：2.973 来自静息 `tau_Ko = 0.6546 s`；工作点是 0.61 / 0.57 / 0.51 s，事件内
  （K_o 4.3–5.0）降到 0.55–0.50 s，正确参照约 **2.6–2.8**，0.8× 门槛约 **2.09–2.24**。
- **但重锚也不过**：`f'=1.0` 实测 **1.78**。逐次增量 0.235 / 0.139 / 0.080 / 0.045，线性应为
  0.451 / 0.318 / 0.224 / 0.158。而且**搬运量越大越次线性**（2.005 → 1.780 → 1.536）。
- **所以这不是参照问题，是真实的开环结果**：组合清除（胶质摄取 + 泵）有很强的负荷依赖性。
- **建议**：**保留测量、保留报告、保留进图，但从 admissibility 里移出**。理由不是"让它通过"，而是
  它**开环测的东西无权封锁闭环阶段**（P0-2）。它应当作为**风险指标**进入 B2 的前置说明：若闭环下清除
  依然这么强，高态可能建立不起来——**那才是 B2 要回答的问题**。

## 4. 预期与禁止

**预期（不是结论、不得预判）**：按 §1 的四条硬门，`f'=1.0` **可能**成为 provisional candidate
（它是唯一同时落在幅度窗内且钾恢复干净的候选）。但这**必须**由新 adjudicator 正式判定。

**禁止**：
- 不得因为本提案就宣称 `f'=1.0` 已被选中；
- 不得因为把积分降为诊断，就宣称"钾正反馈成立"——闭环从未被测；
- 不得在新 DESIGN LOCK 之前启动 B2 的任何 40k；
- 不得把本提案读成"上一轮的判据是错的所以结论作废"——上一轮的**测量**有效，作废的是**判决标签**
  与两条**参照值**。
