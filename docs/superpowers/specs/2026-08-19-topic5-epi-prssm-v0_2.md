## 0. 朴素话摘要

我们看的是：一个人在不发作的日子里整天都在放很小的电，每次波及一小撮触点、有先有后。真正想问的**不是**孤立一次放电长什么样，而是：**过去一段时间里放了多少电、怎么放的，会不会通过某个看不见的内部量，改变接下来"下一次什么时候来"和"来的时候走哪条路"。**

v0.1 只让模型解释"已经发生的这次长什么样"，**没有让它解释"什么时候发生"**。时间戳喂进去了，但损失里没有任何一项逼它被解释，于是模型可以只跟踪"这是第几次放电"、完全无视钟表——实测正是如此（把间隔整体打乱只损失 0.0012）。这不是"没有慢生理状态"的证据，是**我们没问过这个问题**。

v0.2 把"什么时候来"写进似然，并把两个此前被揉在一起的假设分开：**放电只是让我们知道了状态**，还是**放电真的推动了状态**。

## 1. Estimand

对每一段**连续记录**，联合优化

\[
\log p=
\sum_e\Big[
\log \lambda_p\big(t_e\mid z_{\rm rate}(t_{e-1}^{+}),\,a_e,\,\mathcal H_{e-1}\big)
+
\log p_\psi\big(m_e\mid t_e,\,z_{\rm spatial}(t_e^{-}),\,z_{\rm rate},\,\mathcal G_p\big)
\Big]
-\int_{\rm recorded}\lambda_p(u)\,du
\]

- \(a_e=t_e-t_{e-1}\)：距上次事件的时间，显式承载不应期与更新过程形状
- \(z_{\rm rate}\)：解释**何时发生**
- \(z_{\rm spatial}\)：解释**波及谁、什么顺序、何时收尾**
- 两者**允许耦合，禁止强制为同一潜变量**（Topic 2 已证 rate 与 participation 只部分共享）

### 1.1 强度项的硬约束（v0.1 在此犯的错）

区间 \(e\) 的乘性项**必须只依赖 \(t_{e-1}^{+}\) 及更早**。v0.1 的实现把状态推进到 \(t_e^{-}\) 再用于该区间的补偿项，即用"下一次何时发生"计算"活到那时的概率"——这是依赖结局的伪似然，**即使跑赢也不能读成时间状态效应**。

**验收测试**：只改动 \(a_e\) 时，区间 \(e\) 的状态行必须逐位不变，区间 \(e+1\) 的必须改变。

## 2. 记录区间合同

生存项是**关于"没有发生"的证据**，只在记录设备确实开着的时间上成立。

| 情形 | 处理 |
|---|---|
| 有记录、区间内无事件 | **进入积分**——这段沉默是识别速率的主要信息 |
| 跨越未记录时间的区间 | **不进入积分**，两个方向都无证据；状态在此**重置**，不得沿用 |
| 最后一次事件到记录结束 | **右删失**，须进入似然（v0.1 遗漏） |
| 每段开头 | 执行 burn-in，丢弃前 \(B\) 个事件的似然贡献（v0.1 未执行） |

**区间归属只能来自元数据解析的记录 block，禁止用 session index 推断。** session 会把间隔小于 join 阈值的 block 并成一段，v0.1 因此把 **1,070 个区间、1,337.6 小时**未记录时间当作连续记录送进了积分（2,097 block → 481 session，实际跨未记录时间的区间 1,551 个）。

## 3. 假设定义

### 3.1 时间侧阶梯（此前不可识别，本节是修正的核心）

| 档 | 状态由什么驱动 | 回答什么 |
|---|---|---|
| `renewal_only` | 无慢状态 | 基线 |
| `t0_exogenous_clock` | 只有昼夜相位与段内时间；**完全不含放电信息** | 有没有任何慢东西在动速率 |
| `t1_observer` | 上一档 + **仅未被预测的那部分事件**（对因果运行预测取新息） | 放电是不是状态的**观测** |
| `t2_physical` | 上一档 + **即使被完全预测也照样交付的推力** | 放电是不是**物理推动**了状态 |

**判别原理**：一次被完全预测到的放电，对观测臂**零贡献**（新息为 0），对物理臂**仍有贡献**。v0.1 的 T1 完全不含放电信息，于是 T2−T1 同时包含"提供信息"和"物理推动"，**两者不可分**。

**验收测试**：在恒定负荷流上，两臂必须给出不同状态。

### 3.2 空间侧图零假设：必须是 2×2

真实图同时进入**慢生成器的传播**与**事件内 decoder 的空间先验**。整体打乱两条都打到，因此不能区分"慢状态需要正确接线"与"decoder 需要正确空间先验"。

| | decoder 图真实 | decoder 图打乱 |
|---|---|---|
| **生成器图真实** | 基线 | 只考验 decoder |
| **生成器图打乱** | 只考验慢状态传播 | v0.1 的整体零假设 |

**措辞约束**：本队列的图 **99.8% 触点出度已达 \(N-1\)**，几乎全连通。所谓"保度重连"实为**重排边权**。因此只能写"患者特异的**加权**空间关系 + 触点身份对齐"，**不得写"患者特异的物理拓扑接线"**。

## 4. 模型阶梯（全部运行，阴性只降对应主张，不阻塞后续）

`M0` 固定 repertoire + 可观测时间/风险 → `M1` + 非图自主慢状态 → `M2` + 患者图 → `M2-null` 图 2×2 → `M3` + 原始暴露 → `M4` + 新息暴露 → `M5` resource ODE（仅作机制解释层，不作主模型）

**resource ODE 退出主线的理由**：v0.1 在方向性尚未成立前就把问题收缩成有界 ODE，结果恢复时间常数在整个声明网格内**不可辨识**，获胜臂的资源全部塌在边界，时间倒放 32/32 更优。先做无参数的滞后发现，确定尺度后再映射回 ODE。

## 5. 判读规则

### 5.1 一律输出证据向量，禁止单一 boolean

```
predictive increment · lag specificity · directionality ·
common-cause resistance · state-update consistency · resource health
```

v0.1 的 `h3a_supported` 只要任一臂 CI < 0 即为真，不要求资源健康、新息层跑过、方向性成立或多重比较通过——已废除。

### 5.2 效应必须先超过换种子漂移

同一臂不同种子的成对中位差给出噪声地板；效应小于 3 倍地板者**不得解读**。当前图零假设的地板是 **0.0017**。

### 5.3 拟合优度是前置条件

时间重标定残差的均值与标准差**都**须接近 1。远离 1 时，任何臂间比较都是"两个都错的模型之间的比较"，不得进入 evidence card。

### 5.4 每个假数据真值用自己的判据

禁止一律用"验证损失最低者胜"。no-state 真值判**同容量对照的增量应为零**；graph 真值判**正确图胜过错误图且开环也胜**；rate-only 真值判**风险动、空间状态不动**；hidden-common-cause 判**原始暴露阳性但新息归零**。

## 6. v0.1 结论的处置

| v0.1 结论 | 处置 |
|---|---|
| 存在可自主预测的慢状态（阶梯） | **降级**。同容量负对照未通过：无状态假数据上会动的状态仍好 0.011–0.062，人体 0.0306 落在其中 |
| 状态调制单次事件（换状态、前缀分叉） | **保留**为历史信息影响事件标记；换状态那把尺子通过了同一道负对照（真状态 −0.018 / 纯容量 +0.001 / 冻结 0.0000） |
| 机制定位到触点兴奋性 + 边耦合 | **撤回**。起点通路的零是 softmax 抵消的架构必然；耦合臂同时含逐触点调制，纯耦合臂此前不存在 |
| 发作前状态位移 | **未见**。四个提前量全是掷硬币；唯一稳定变化是**放电间隔变短 22/27, p=0.0015**，但伪时刻未按间隔匹配，须先修合同 |
| 暴露驱动状态（H3） | **未决 / 仪器不合格**，非生物学阴性 |
| 图零假设 | **保留但重新措辞**，见 §3.2；生成器/decoder 两条通路解耦前不得称"慢状态沿网络流动" |
