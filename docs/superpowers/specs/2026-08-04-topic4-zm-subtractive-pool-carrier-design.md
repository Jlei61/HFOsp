## 0. 朴素话摘要

**测了什么.** 上一轮我们给仿真皮层片子加了一种"哪块地方最近放电多，那块地方就慢慢攒起一点衰减很慢的额外兴奋"的机制，指望它把爆发之间那约 0.3 秒的全场安静填上。它确实填上了——但填法不对：不是在安静期把活动托住，而是**把爆发振荡整个消灭掉，换成一条不动的平线**。放电末段的起伏从 1.9 掉到 0.05，空间图样的中心几乎停住。

**为什么会这样.** 这块片子的共享抑制刹车只有"除法"一种形式——把递归兴奋电流按比例砍掉一块。降阶理论早就算过：**只有除法式刹车的系统根本不会自己振荡，它只有一个固定点**，仓库里有专门的测试锁着这一点。低强度时看到的爆发来自另一套东西（抑制突触用久了会变弱、然后慢慢恢复）。所以慢兴奋一加大，系统就被推过去、落到"除法式刹车唯一提供的那个固定点"上。**缺的不是能量，也不是空间自由度，是这个系统在持续段根本没有极限环可去。**

**这一轮要测什么.** 给刹车补上第二种形式——**减法式**：不是按比例砍，而是直接减掉一个固定量，而且这个量跟着最近的总活动走、还有约 120 毫秒的滞后。快的正反馈（递归兴奋）和慢的负反馈（滞后的减法刹车）之间就有了相位竞争，这是产生真正节律的标准配方。引擎里这个成分**一直存在但从未被打开过**（关着的时候逐位等同于原路径）。

**判据这次要补上"还在动".** 上一轮暴露了判据的一个盲点：现有的"安静缝隙要短"这一条，对一条完全平的恒定放电给满分。这次**在跑之前**把"末段还在起伏"写进判据。

（内部归档代号：`beta_SG`、`alpha_G=16`、`tau_S=120 ms`、`credible_carrier` 七条 gate、`sustained_core_cv`、`test_divisive_only_beta0_has_no_orbit`）

## 1. 问题陈述

两个已测事实拼在一起给出唯一的机制缺口：

1. **实测（本仓库 §10）**：在 PV/SOM 衬底上，凡是让活动连续的局部慢兴奋强度，持续段都是不动点——末段放电相对起伏 ≤ 0.071、空间质心速度 ≤ 20.8 bin/s、12 s 长跑的轴向主模态一律是被阻尼的 0 Hz 实模态。凡是保住振荡的强度，深间隙都 ≥ 0.35。18 臂 / 3 套连接 / 5 个工作点，无例外。
2. **理论（降阶场筛 §1）**：本线的共享抑制池是**纯除法式**（`alpha_G=16, beta_SG=0`）。纯除法式的均值场**没有轨道**，只有固定点（实测 r≈0.50–0.68；`test_divisive_only_beta0_has_no_orbit`）。要有一个可供维持的振荡，**必须**有减法式成分 `−β·S`。

结论：持续高能与持续时间结构在上一轮机制下互斥，不是因为参数没调对，而是因为**持续段的相空间里没有极限环**。

## 2. 机制

打开共享抑制池的减法式成分：

```
E 细胞上的池作用 =  I_EE /(1 + alpha_G·S_G)      （除法，现有，alpha_G=16）
                  −  beta_SG · S_G                （减法，本轮新开，现为 0）
dS_G/dt = (−S_G + S_max·mu_G)/tau_S               （tau_S = 120 ms）
```

`beta_SG = 0` 时 `dI_rec` 恒为 0 → 逐位等同原路径（引擎已有守卫与 parity 测试）。

**为什么这满足 §10.8 的三条约束**

| §10.8 约束 | 本机制 |
|---|---|
| 不得靠提高局部标量兴奋强度 | 这是**抑制**项，方向相反 |
| 持续段要有自持的时间尺度，需慢负反馈与快正反馈的相位竞争 | 快正反馈=递归兴奋；慢负反馈=带 120 ms 滞后的减法刹车。这正是相位竞争，不是再加一层局部正反馈 |
| 不得依赖 detector / 定时开关 / 改 E→E 拓扑 | 池由活动自身驱动，无阈值触发、无计时器；E→E 不动 |

**为什么不是把池局部化.** 降阶场筛已在 `β>0` 的双成分池上直接测过"局部 vs 全局"，513/513 空间模态全部严格为负（`both_stable`）——局部化不会把均匀振荡打散成相位错开的图案。但那一轮问的是"如何把**均匀**振荡打散"，而我们的持续段**本来就不均匀**（有效秩 2.6–5.4、PC1 0.48–0.66）。我们缺的不是空间自由度，是时间节律。所以本轮**不动池的空间秩**，只补它缺的那个成分。

## 3. 锁定范围

**做**：冻结 Z/M 下的快载体一层 + 注册一个门关闭侧的检查点。

**不做**（留给下一份 spec）：释放 Z/M、M 的终止因果、native offset、postictal recovery、刺激/控制。理由：上一轮已证明"载体不合格就释放慢变量，只会测到一个静止态被慢变量拖走"。

## 4. 预注册判据（跑前锁死）

沿用现有七条 `credible_carrier`，**新增第八条**：

| # | 判据 | 阈值 | 来源 |
|---|---|---|---|
| 1 | 无 runaway early-stop | — | 现有 |
| 2 | 虚拟电极场增益 | ≥ 20 dB | 现有 |
| 3 | 能量占空 | ≥ 0.50 | 现有 |
| 4 | onset 后深间隙占比 | ≤ 0.20 | 现有 |
| 5 | 空间 PC1 占比 | ≤ 0.95 | 现有 |
| 6 | 核心平均放电率 | ≤ 250 Hz | 现有 |
| 7 | 饱和通道占比 | ≤ 0.25 | 现有 |
| **8** | **末段核心放电相对起伏 `sustained_core_cv`** | **≥ 0.15** | **本 spec 新锁** |

第 8 条的窗口：2.5 s 臂取末 1 s；12 s 臂取末 2 s。

**阈值 0.15 的来源与诚实标注.** 上一轮实测两类形态之间是空的：不动点臂 0.040–0.071，爆发臂 0.893–1.894，中间**一个数据点都没有**。0.15 放在这个空隙里，对应正弦调制约 ±21% 的深度——明确不是平线，但仍是温和节律。**因此这是一个放在观测空隙里、约束很弱的阈值。** 预注册的配套规则：任何落在 **0.10–0.25** 的臂一律报 `ambiguous_modulation`，**不得**记为干净通过；要升级必须补 12 s 长跑与频谱证据。

**必须同时报告（不入 gate）**：
- 末段核心放电的 Welch 频谱峰值频率，及该峰相对 2–200 Hz 中位功率的突出度；
- 轴向 DMD 的 leading mode 频率与增长率（上一轮四条长跑一律 0 Hz 实模态，这是最干净的对照量）；
- 空间质心中位速度（上一轮不动点臂 ≤ 2.0 bin/s）。

**失效模式的预注册判别.** 减法式抑制最可能的平庸失效是"只当刹车"：放电率下降、深间隙回来。判别规则写死为——`beta_SG` 必须在**不把深间隙推过 0.20** 的前提下把第 8 条抬过 0.15。两者只满足其一即为该档失败。

## 5. 实验设计

### Phase 0 — 标定与前置（与 β 取值无关，可先跑）

- **P0-a 仪器**：把 `trace_Irec_mean`（引擎已收集、未落盘）与逐步的减法移除量写入 npz。**理由**：β 的量级必须对着实测的递归电流定，不能拍脑袋；这是本轮 Z 门 over-claim 的同类教训——机制参与度要测量，不能假设。
- **P0-b 电流标定**：在锁定衬底上跑一条短轨迹，读持续段的 `median(I_E_rec)` 与 `median(S_G)`，据此把 β 阶梯定为"减法移除量占 `I_E_rec` 的预声明比例 f"：**f ∈ {0.05, 0.10, 0.20, 0.40, 0.80}**，`beta_SG = f · median(I_E_rec) / median(S_G)`。f 是预声明的，β 的数值由测量导出，**不是 outcome 网格**。
- **P0-c 门关闭侧检查点**：现有最早检查点 `pre_entry__natural` 的**核心区** z = 0.525 → Z 门开度 0.989（全片 z=0.811，但机制作用在有活动处，故以核心区为准）。自然锚定轨迹（seed1, T=15 s, 25 ms/bin）的核心区 z 从 1.0 降到 0.343，**穿过 0.75 在 t≈3175 ms**。在同一条确定性轨迹上于 **t = 2500 ms** 增存一个状态并注册为 `pre_gate__natural`，预期核心区 z ≈ 0.78–0.80、Z 门开度显著低于 0.5。验收：门开度 ≤ 0.5，且重放该锚定轨迹与现有 `pre_entry__natural_t73500.npz` 逐位一致（确定性回归）。

### Phase 1 — β 阶梯（冻结 `bounded_late__peak`，wiring 1，2.5 s）

五档 f × 两档衬底慢兴奋（`g = 0` 与 `g = 0.32`）= 10 臂，加两条 `β=0` 对照（已有，复用）。

**2×2 的意义**（这是本设计的核心结构，不是顺带）：

| | β = 0 | β = β\* |
|---|---|---|
| **g = 0** | 已有：爆发串，间隙 0.70 | 减法式**单独**能否给出连续且有节律？若能，慢兴奋是多余的 |
| **g = 0.32** | 已有：不动点，间隙 0，起伏 0.048 | 慢兴奋供连续、减法供节律——两者是否互补 |

它把"谁提供连续性"和"谁提供节律"分开，任何一格的结果都不能替另一格发言。

### Phase 2 — 复现与耐久（仅当 Phase 1 有臂过全部八条）

1. 最弱通过档在 SOM 连接种子 2、3 上各复跑一次（各配 `β=0` matched control）；
2. 最弱**跨种子**通过档跑 12 s，套 `_validate_short_prefix` 前缀确定性检验；
3. 12 s 上重算全部八条 + 频谱 + DMD。

## 6. 停机规则（跑前锁死）

- **A．五档 f 全部无法在深间隙 ≤ 0.20 的前提下把起伏抬过 0.15** → bounded-negative，停。结论写成"减法式成分在测过的强度范围内没有给持续段一个节律"，**不得**外推成"减法式抑制被否证"。
- **B．某档抬过 0.15 但深间隙同时超过 0.20** → 减法式只当了刹车，未产生节律；停，不扩阶梯。
- **C．`g=0, β=β*` 单独通过** → 局部慢兴奋非必需；后续一律以 `g=0` 为衬底，并在归档中明说上一轮机制被本轮取代。
- **D．有臂落在 0.10–0.25 起伏带** → 记 `ambiguous_modulation`，只允许对**该一档**补 12 s 长跑，不得扩阶梯。
- **E．出现 runaway** → 记录该档为上界，不做二分，不再往上加 β。

## 7. 明令禁止

- 不改 E→E 拓扑 / 核 / 各向异性 / 方向 / 延迟；
- 不加 detector、定时开关、手工 reset Z/M、activity mask；
- 不在看到结果后调整第 8 条阈值或任何既有阈值（要改必须新开 spec 预注册）；
- 不重开上一轮慢兴奋的剂量网格（只用 `g ∈ {0, 0.32}` 两档）；
- 不在本 spec 内释放 Z/M；
- 不把 Phase 0 的电流标定读成任何科学结论。

## 9. 已知风险与诚实缺口

1. **第 8 条阈值弱约束**：0.15 落在观测空隙里，没有独立数据支持它就是"节律 vs 平线"的正确分界。已用 `ambiguous_modulation` 带缓解，但不能消除。
2. **减法式成分从未在本 SNN 上跑过**：降阶场筛用的是不同归一化的率场（W0=2, α=4, β=2），β 的绝对量级**不可迁移**，所以必须走 P0-b 的电流标定。
3. **单工作点**：Phase 1 只在 `bounded_late__peak` 上做。工作点覆盖留到过门之后。
4. **降阶理论只保证"有减法式才可能有轨道"，不保证"加了就有"**：均值场有极限环 ≠ 全 SNN 的持续段有极限环。本轮是存在性检验，不是理论验证。
5. **P0-c 的门开度预期值 0.78–0.80 来自 25 ms 分辨率的锚定轨迹插值**，实际存点后必须重测，不得沿用预期值。
