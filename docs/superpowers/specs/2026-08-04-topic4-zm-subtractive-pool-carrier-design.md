## 0. 朴素话摘要

**测了什么.** 上一轮我们给仿真皮层片子加了一种"哪块地方最近放电多，那块地方就慢慢攒起一点衰减很慢的额外兴奋"的机制，指望它把爆发之间那约 0.3 秒的全场安静填上。它确实填上了——但填法不对：不是在安静期把活动托住，而是**把爆发振荡整个消灭掉，换成一条不动的平线**。放电末段的起伏从 1.9 掉到 0.05，空间图样的中心几乎停住。

**为什么会这样（注意措辞边界）.** 这块片子的共享抑制刹车只有"除法"一种形式——把递归兴奋电流按比例砍掉一块。降阶率场在**它测过的那个工作点与参数范围内**算出来：纯除法式反馈收敛到固定点，加上减法式反馈后那个降阶模型才出现振荡窗口。

**这不能外推成"这个 SNN 没有极限环"**——恰恰相反，β=0 的 SNN 本来就有弛豫爆发串，那个振荡来自抑制突触用久了变弱再慢慢恢复（I→E 短期抑制），跟池无关。能说的只有一句更窄的话：**慢兴奋把系统推进去的那个高率持续 regime 是一个固定点，而池按现在的配置在那个 regime 里不提供任何振荡倾向。** 缺的不是能量，也不是空间自由度，是**那个特定 regime** 里没有可去的极限环。

**这一轮要测什么.** 给刹车补上第二种形式——**减法式**：不是按比例砍，而是直接减掉一个固定量，而且这个量跟着最近的总活动走、还有约 120 毫秒的滞后。快的正反馈（递归兴奋）和慢的负反馈（滞后的减法刹车）之间就有了相位竞争，这是产生真正节律的标准配方。引擎里这个成分**一直存在但从未被打开过**（关着的时候逐位等同于原路径）。

**判据这次要补上"还在动".** 上一轮暴露了判据的一个盲点：现有的"安静缝隙要短"这一条，对一条完全平的恒定放电给满分。这次**在跑之前**把"末段还在起伏"写进判据。

（内部归档代号：`beta_SG`、`alpha_G=16`、`tau_S=120 ms`、`credible_carrier` 七条 gate、`sustained_core_cv`、`test_divisive_only_beta0_has_no_orbit`）

## 1. 问题陈述

两个已测事实拼在一起给出唯一的机制缺口：

1. **实测（本仓库 §10）**：在 PV/SOM 衬底上，凡是让活动连续的局部慢兴奋强度，持续段都是不动点——末段放电相对起伏 ≤ 0.071、空间质心速度 ≤ 20.8 bin/s、12 s 长跑的轴向主模态一律是被阻尼的 0 Hz 实模态。凡是保住振荡的强度，深间隙都 ≥ 0.35。18 臂 / 3 套连接 / 5 个工作点，无例外。
2. **理论（降阶场筛 §1，注意其适用范围）**：本线的共享抑制池是**纯除法式**（`alpha_G=16, beta_SG=0`）。在降阶率场**测过的那个工作点与参数范围内**，纯除法式反馈收敛到固定点（实测 r≈0.50–0.68；`test_divisive_only_beta0_has_no_orbit`），加入减法式成分 `−β·S` 后该降阶模型才出现振荡窗口。

**边界（不得越过）**：这**不是**"纯除法式系统没有轨道"的一般定理，也**不能**外推到全 SNN 的状态空间——β=0 的 SNN 本来就有弛豫爆发串，那个轨道由 I→E 短期抑制产生，与池无关。

结论（限定形式）：**在慢兴奋把系统推进去的那个高率持续 regime 里**，持续高能与持续时间结构互斥；池按现在的配置在该 regime 不提供振荡倾向。本轮问的是：给池补上减法式成分，能否在**该 regime** 里打开一个极限环。

## 2. 机制

打开共享抑制池的减法式成分：

```
E 细胞上的池作用 =  I_EE /(1 + alpha_G·S_G)      （除法，现有，alpha_G=16）
                  −  beta_SG · S_G                （减法，本轮新开，现为 0）
dS_G/dt = (−S_G + S_max·mu_G)/tau_S               （tau_S = 120 ms）
```

`beta_SG = 0` 时 `dI_rec` 恒为 0 → 逐位等同原路径（引擎已有守卫与 parity 测试）。

**为什么这满足 §10.8 的三条约束**

| §10.8 约束 | 本机制 |
|---|---|
| 不得靠提高局部标量兴奋强度 | 这是**抑制**项，方向相反 |
| 持续段要有自持的时间尺度，需慢负反馈与快正反馈的相位竞争 | 快正反馈=递归兴奋；慢负反馈=带 120 ms 滞后的减法刹车。这正是相位竞争，不是再加一层局部正反馈 |
| 不得依赖 detector / 定时开关 / 改 E→E 拓扑 | 池由活动自身驱动，无阈值触发、无计时器；E→E 不动 |

**为什么不是把池局部化.** 降阶场筛已在 `β>0` 的双成分池上直接测过"局部 vs 全局"，513/513 空间模态全部严格为负（`both_stable`）——局部化不会把均匀振荡打散成相位错开的图案。但那一轮问的是"如何把**均匀**振荡打散"，而我们的持续段**本来就不均匀**（有效秩 2.6–5.4、PC1 0.48–0.66）。我们缺的不是空间自由度，是时间节律。所以本轮**不动池的空间秩**，只补它缺的那个成分。

## 3. 锁定范围

**做**：冻结 Z/M 下的快载体一层 + 注册一个门关闭侧的检查点。

**不做**（留给下一份 spec）：释放 Z/M、M 的终止因果、native offset、postictal recovery、刺激/控制。理由：上一轮已证明"载体不合格就释放慢变量，只会测到一个静止态被慢变量拖走"。

## 4. 预注册判据（跑前锁死）

沿用现有七条 `credible_carrier`，**新增第八条**：

| # | 判据 | 阈值 | 来源 |
|---|---|---|---|
| 1 | 无 runaway early-stop | — | 现有 |
| 2 | 虚拟电极场增益 | ≥ 20 dB | 现有 |
| 3 | 能量占空 | ≥ 0.50 | 现有 |
| 4 | onset 后深间隙占比 | ≤ 0.20 | 现有 |
| 5 | 空间 PC1 占比 | ≤ 0.95 | 现有 |
| 6 | 核心平均放电率 | ≤ 250 Hz | 现有 |
| 7 | 饱和通道占比 | ≤ 0.25 | 现有 |
| **8** | **末段核心放电相对起伏 `sustained_core_cv`** | **≥ 0.15** | **本 spec 新锁** |

第 8 条的窗口：2.5 s 臂取末 1 s；12 s 臂取末 2 s。

**阈值 0.15 的来源与诚实标注.** 上一轮实测两类形态之间是空的：不动点臂 0.040–0.071，爆发臂 0.893–1.894，中间**一个数据点都没有**。0.15 放在这个空隙里，对应正弦调制约 ±21% 的深度——明确不是平线，但仍是温和节律。**因此这是一个放在观测空隙里、约束很弱的阈值。**

**三档判读（写死，避免"既过又模糊"的自相矛盾）**：

| 末段起伏 | 判读 |
|---|---|
| < 0.10 | 第 8 条**不过**，记 `tonic` |
| 0.10 – 0.25 | 记 `ambiguous_modulation`，**不是干净通过**；只允许对该档补 12 s 长跑与频谱，不得据此宣布候选 |
| **> 0.25** | 第 8 条**干净通过** |

即：**干净通过等价于末段起伏 > 0.25**，clause 8 的 0.15 只是"不算平线"的下限，不是通过线。

**CV 高本身不等于极限环.** 高 CV 也可能来自噪声起伏、未稳定的瞬态、正在碎裂的爆发串，或非平稳的幅度漂移。因此 2.5 s 臂即使干净通过也只记 `modulated_candidate`，升级为 orbit 至少还需要 12 s 上同时满足：起伏不随时间衰减；Welch 峰频率稳定；DMD 出现非零频率且弱阻尼/近中性的复模态；最好再补一次状态扰动后的相位返回。

**必须同时报告（不入 gate）**：
- 末段核心放电的 Welch 频谱峰值频率，及该峰相对 2–200 Hz 中位功率的突出度；
- 轴向 DMD 的 leading mode 频率与增长率（上一轮四条长跑一律 0 Hz 实模态，这是最干净的对照量）；
- 空间质心中位速度（上一轮不动点臂 ≤ 2.0 bin/s）；
- **实际达成的移除比** \(R_\beta=\sum_t I_\beta(t)/\sum_t I^{EE}_{postdiv}(t)\)（同一 β 在两行上必然不同，必须逐臂报出）。

**失效模式的预注册判别.** 减法式抑制最可能的平庸失效是"只当刹车"：放电率下降、深间隙回来。判别规则写死为——`beta_SG` 必须在**不把深间隙推过 0.20** 的前提下把第 8 条抬过 0.15。两者只满足其一即为该档失败。

## 5. 实验设计

### Phase 0 — 标定与前置（与 β 取值无关，可先跑）

- **P0-a 仪器**：落盘三条量——原始递归电流 `trace_Irec_mean`、**除法之后**幸存的递归电流 `trace_Irec_postdiv_mean`、以及减法电流 `trace_Isub_mean = beta_SG · S_G`。**理由**：β 的量级必须对着实测电流定，不能拍脑袋；这是本轮 Z 门 over-claim 的同类教训——机制参与度要测量，不能假设。用引擎直接落盘而不是事后由 `S_G` 重建，是因为除法分母里还可能有 `alpha_H·H` 与 M 分量，重建会在那些成分打开时静默失真。

- **P0-b 电流标定（电荷平衡，跨两行共用一组 β）**：

  β 移除的是**除法之后幸存**的递归驱动，不是原始电流；而且在爆发臂上 `I_E_rec` 大量时间接近零，中位数不是电荷量度。因此标定必须用**时间对齐的电荷积分**：

  \[
  \beta_f \;=\; f\;\frac{\sum_t I^{EE}(t)\big/\big(1+\alpha_G S_G(t)\big)}{\sum_t S_G(t)}
  \]

  - **共同参考臂固定为 `g = 0.32`**（连续固定点，平稳，窗口不敏感），**得到的同一组数值 β 同时用于 `g=0` 与 `g=0.32` 两行**。按行各自标定会得到差 3.7 倍的两组 β（144.1 vs 39.2 at f=1），那样 2×2 就不是同一处理，交互项无从解释。
  - f 预声明为 **{0.05, 0.10, 0.20, 0.40, 0.80}**；β 的数值由测量导出，**不是 outcome 网格**。
  - **每条臂必须回报实际达成的移除比** \(R_\beta=\sum_t I_\beta(t)\big/\sum_t I^{EE}_{postdiv}(t)\)。同一个 β 在两行上的 \(R_\beta\) 本来就不同（`g=0` 的 `S_G` 更低），这是设计的一部分，不是缺陷——但必须报出来，否则无法解释两行的差异。

  **反例留档**：早稿写的 `beta = f · median(I_E_rec)/median(S_G)` 是错的，两处都错：用了除法前的电流（高估约 6 倍），且中位数在爆发臂上比均值小 268 倍。该公式在 `g=0.32` 上会给出 242.5 而非 39.2。
- **P0-c 门关闭侧检查点（注册，且必须被使用）**：现有最早检查点 `pre_entry__natural` 的**核心区** z = 0.525 → Z 门开度 0.989（全片 z=0.811，但机制作用在有活动处，故以核心区为准）。自然锚定轨迹（seed1, T=15 s, 25 ms/bin）的核心区 z 从 1.0 降到 0.343，**穿过 0.75 在 t≈3175 ms**。在同一条确定性轨迹上于 **t = 2500 ms** 增存一个状态并注册为 `pre_gate__natural`，预期核心区 z ≈ 0.78–0.80、Z 门开度显著低于 0.5（存点后必须重测，不得沿用预期值）。验收：门开度 ≤ 0.5，且重放该锚定轨迹与现有 `pre_entry__natural_t73500.npz` 逐位一致（确定性回归）。

  **为什么"只注册"不够（Phase 1b 强制项）**：`β·S_G` 是对**所有 E 细胞施加的同一个全局标量减法**，引擎里既**不经过 Z 门也不经过 M 门**（`out[:nE] -= … + beta_SG·S_G`）。因此即使慢兴奋在高 z 时被门关掉，β 仍可能改变正常的间期事件。**任何 Phase 1 候选在进入 Phase 2 之前，必须先在 `pre_gate__natural` 上跑 `β=0` 与 `β*` 一对（相同 future noise），比较间期事件率、传播轴、空间参与度，以及是否出现原本不存在的人工节律。** 该对照不通过，只能说"找到了冻结载体"，**不得**说它与 Z/M 生命周期兼容。

### Phase 1 — β 阶梯（冻结 `bounded_late__peak`，wiring 1，2.5 s）

五档 f × 两档衬底慢兴奋（`g = 0` 与 `g = 0.32`）= 10 臂，加两条 `β=0` 对照（已有，复用）。

**2×2 的意义**（这是本设计的核心结构，不是顺带）：

| | β = 0 | β = β\* |
|---|---|---|
| **g = 0** | 已有：爆发串，间隙 0.70 | 减法式**单独**能否给出连续且有节律？若能，慢兴奋是多余的 |
| **g = 0.32** | 已有：不动点，间隙 0，起伏 0.048 | 慢兴奋供连续、减法供节律——两者是否互补 |

它把"谁提供连续性"和"谁提供节律"分开，任何一格的结果都不能替另一格发言。

### Phase 2 — 复现与耐久（仅当 Phase 1 有臂过全部八条）

1. 最弱通过档在 SOM 连接种子 2、3 上各复跑一次（各配 `β=0` matched control）；
2. 最弱**跨种子**通过档跑 12 s，套 `_validate_short_prefix` 前缀确定性检验；
3. 12 s 上重算全部八条 + 频谱 + DMD。

## 6. 停机规则（跑前锁死）

- **A．五档 f 全部无法在深间隙 ≤ 0.20 的前提下把起伏抬过 0.10** → bounded-negative，停。结论写成"减法式成分在测过的强度范围内没有给该 regime 一个节律"，**不得**外推成"减法式抑制被否证"，也**不得**外推成"这个 SNN 没有极限环"（β=0 的爆发串本身就是一个轨道）。
- **B．某档抬过 0.15 但深间隙同时超过 0.20** → 减法式只当了刹车，未产生节律；停，不扩阶梯。
- **C．`g=0, β=β*` 单独通过** → 局部慢兴奋非必需；后续一律以 `g=0` 为衬底，并在归档中明说上一轮机制被本轮取代。
- **D．有臂落在 0.10–0.25 起伏带** → 记 `ambiguous_modulation`，只允许对**该一档**补 12 s 长跑与频谱，不得扩阶梯，不得据此宣布候选。
- **F．任何干净通过的臂（起伏 > 0.25 且八条全过）** → 先记 `modulated_candidate`；进入 Phase 2 之前**必须**先过 P0-c 的 `pre_gate__natural` 间期兼容性对照（β=0 vs β\*，相同 future noise）。该对照不通过则停在"冻结载体"，不得宣称与生命周期兼容。
- **E．出现 runaway** → 记录该档为上界，不做二分，不再往上加 β。

## 9. 已知风险与诚实缺口

0. **减法项是全局标量，只管时间节律，不创造空间图样**。空间结构仍完全依赖既有的各向异性 E→E scaffold 与 PV/SOM 快抑制。因此成功的判读必须**同时**看到"持续在动（起伏/频谱/DMD）+ 空间非共模（PC1 < 0.95）+ 高能连续 + 无 runaway"四项，**只看到放电率被重新调低不算**。
1. **第 8 条阈值弱约束**：0.15 落在观测空隙里，没有独立数据支持它就是"节律 vs 平线"的正确分界。已用三档判读（<0.10 不过 / 0.10–0.25 模糊 / >0.25 干净）缓解，但不能消除。
2. **减法式成分从未在本 SNN 上跑过**：降阶场筛用的是不同归一化的率场（W0=2, α=4, β=2），β 的绝对量级**不可迁移**，所以必须走 P0-b 的电流标定。
3. **单工作点**：Phase 1 只在 `bounded_late__peak` 上做。工作点覆盖留到过门之后。
4. **降阶理论只保证"有减法式才可能有轨道"，不保证"加了就有"**：均值场有极限环 ≠ 全 SNN 的持续段有极限环。本轮是存在性检验，不是理论验证。
5. **P0-c 的门开度预期值 0.78–0.80 来自 25 ms 分辨率的锚定轨迹插值**，实际存点后必须重测，不得沿用预期值。
