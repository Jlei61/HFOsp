# Adaptation 时间尺度 pilot：跑前预测（2026-08-06）

**状态：** PILOT，预测在任何结果产生之前提交。不是 spec；spec 依 pilot 结果再写。

## 0. 为什么跑这个

用户问：不同时间尺度的 adaptation 能不能把发作拉回来。从现有参数直接算：

- adaptation 按 `dm/dt = −m/τ + spikes` 累积，稳态 `m = r·τ`；
- 每单位 m 值 `η_m = 0.001` mV，阈值尺度 `CORE_MEAN = 17.5` mV；
- 持续段实测 `r ≈ 200` Hz，当前 `τ_M = 500` ms → `m = 100` → 电流 **0.1 mV = 阈值的 0.6%**。

所以卡点是**增益**不是时间尺度的存在性。要把电流做到 5 mV（阈值的 29%），需要 `τ_M ≈ 25 s`（保持增益）或增益 ×50（保持 τ）。

另外 M 还有第二条通路：作用在慢兴奋上的门 `1/(1+(m/30)^4)`。冻结点 m=20.4 时门开 0.824；m=100 时门关到 0.008。`--g-M` 只缩放 `η_m`，**不动门**，所以两条通路可以分开测。

## 2. 预测（写在看到任何结果之前）

- **P1 不终止。** m 在约 1.5 s 内饱和到 ~100，电流 0.1 mV 可忽略；但 M 门关到 0.008，把慢兴奋掐掉，因此系统**换分支**到深间隙爆发串（上一轮实测 `g=0` 即该形态，间隙 0.70）。预期：强直平台 → 爆发串，持续到 30 s，**不熄灭**。
- **P2 终止。** m 缓慢爬升，电流在约 25 s 达到 5 mV。门也随之渐进关闭。预期：**在 30 s 内熄灭**，且因为两条通路都是渐进的，形态应是**演化式**的（连续 → 逐渐出现间隙 → 间隙拉长 → 熄灭）。
- **P3 终止但形态不像发作。** 电流在约 1.5 s 内就到 5 mV，等于把开关一次扳下。预期：**早期（数秒内）熄灭**，没有中间的爆发相。
- **P4 在 5–15 s 之间终止**，形态介于 P2 与 P3 之间。

**判别 P2 与 P3 的关键不是"是否终止"，而是形态**：P2 若如预期呈现"连续 → 间隙渐现 → 拉长 → 熄灭"，则时间尺度本身是承重变量；P3 若只是一次性掐断，则说明"够大的增益"能终止但产生不出发作形态。

## 3. 会推翻上述计算的观测（预先声明）

- P1 **熄灭** → 说明 M 门（而非电流）足以终止，我的"电流是卡点"判断错；
- P2 **不熄灭** → 说明 5 mV 仍不够，或 z 的正反馈（τ=5 s，抑制效能耗竭）抵消了 adaptation，需要重新算；
- 任何臂 **runaway** → 说明释放 z 后正反馈占优，adaptation 方向的问题被 z 掩盖，须先处理 z。

## 4. 边界

- 本 pilot **不是** carrier 测试，也**不是**生命周期测试。它只回答"adaptation 能不能让这个高活动态停下来，以及停下来时长什么样"。
- 熄灭 ≠ 发作终止：还需要熄灭后抑制恢复（z 的 τ=5 s）并回到原有的间期事件分布，本 pilot 不检验后两者。
- 单种子、单衬底、单工作点。
