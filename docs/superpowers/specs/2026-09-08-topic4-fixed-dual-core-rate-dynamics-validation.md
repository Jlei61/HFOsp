## 1. 科学目标与证据次序

先回答“该 rate model 是否保留指定 SNN 的动力学”，再回答“这些动力学是否足以解释患者数据”。不能用患者 loss 补偿降阶不忠实，也不能把忠实复现一个仍有患者偏差的 SNN 称为患者机制成立。

必要链条：原 SNN 多事件参考 → 相同底物的降阶响应与多事件验证 → 同底物 SNN/rate 持续振荡对照 → 活动依赖 Z/M 积累的连续转变 → 对实际相关吸引子的分岔分析。两端可以位于同一模型族的不同控制参数；不预设同参数双稳共存，不要求发作终止。

## 4. 降阶必须保留与实测的内容

1. 使用同一实现图的空间聚合，并保留 core/周边及格内阈值组。当前10×10方案只是待检验近似；基线至少比较1 mm与2 mm空间聚合的事件相关响应，不能单凭固定点收敛选择网格。
2. 保留所有实际延迟和突触 rise/decay。若简化成单指数，必须分别报告脉冲面积、峰值和响应延迟误差。**执行审计更正**：原 SNN 的电流是归一化低通，固定 jump/rise 改变 GABA decay 时，无限时窗电流脉冲面积不变，峰值和时间分布改变；此前“积分抑制剂量会变”的推断不正确。有限窗电流和网络闭环总抑制仍可能变化。原生步长下单位 jump 的面积为 `dt/(1-exp(-dt/tau_r))`，须保留这个离散因子。
3. OU 先在原神经元位置产生并按原顺序裁剪/映射。分别检查格内均值、方差、空间协方差及与阈值组的关系。简单平均后过非线性是待验证近似，不能通过任意增大噪声弥补事件缺失。
4. 校验静态输入—放电率关系及有限脉冲响应。`tau_mem dr/dt=-r+Phi` 的时间核不是默认已正确；只在匹配响应不合格时比较动态滤波或更高阶群体闭合。
5. 第一阶段保持 Z/M 关闭，忠实复现历史基线。后来开启 M 或 Z 是有标识的新干预，同时应用于 SNN 与 rate model；不能把其他底物的 eta_M/tau_M 直接称为本候选拟合参数。

## 5. 验证流程与交付

### V0：参考重建与观测接通

核对静态数组；同历史 seed 的短前缀重演检查原始活动与触点包络，记录读取的全部外源输入参数。优先复用已存24秒轨迹作为参考，但参考文件核验不能代替新执行器重演。

将 SNN 投影为和 rate model 同一空间分辨率的原生场，保留未经电极空间平滑的版本。SNN 的谱系事件观察器依赖逐神经元 spikes/因果边，不能直接声称连续 rate field 有相同 lineage。先在 SNN 投影场上校验场级事件边界与原观察器的一致性，再在 rate 场使用同一场级观察方法。

### V1：可激性与自终止

在相同背景下做短局部输入阶梯，位置覆盖 core A、core B 和按几何预定的周边对照。输入通过同一物理驱动通道施加并记录剂量；不能把一次强制 spike 与一次 rate 电压脉冲当相同剂量。记录无刺激、未点火、成功点火、自终止和不返回五种结果。

主要读出为刺激撤除后活动、波前前进、峰值/范围、事件持续时间、回落以及双脉冲恢复。先用 SNN 的剂量阶梯定位，再原样给 rate model；不按 rate 是否能点火反向选剂量。自限事件不要求存在不稳定固定点。

### V2：连续多事件

固定6101，先对应7101/7102两段24秒连续参考；不重置事件间状态，不指定逐事件刺激。对事件量不足的运行报告可估计范围，不能靠追加到“恰好出现两类”为止。校准完成后，另外冻结至少3个未使用噪声种子做确认，种子在首次仿真前检查占用并写入运行清单。

主要评价是自限事件占比、事件间恢复、事件率/持续时间分布、空间参与、成对时差与顺序、模式覆盖和额外模式。单次事件不需要同时符合TA/TB；跨事件检查两种模式的支持，保存所有事件而非只挑最佳GIF。对患者的TA/TB细节、Supplementary Video 1和分布支持/OOD沿用独立检验角色；训练损失不新增手指定起源或路线。

### V3：持续振荡能力

只有V0–V2通过后，才在同一底物上展开有限的成对 SNN/rate 控制扫描。先改变明确的有效抑制控制量，再决定是否需要加入 M 或改变 GABA 时间常数；每个干预的完整方程、参数范围与配对种子必须在读该批结果前落盘。此文件不将未知振荡窗口预填成已存在，也不授权无界寻找正结果。

每条轨迹分别分类为无事件低态、反复自限事件、局部持续活动、全局 tonic、持续振荡、未驻留/不可判定。持续振荡同时报告局部区域与全局群体的频率、绝对幅度、相对调制、持续占空比及跨后期窗口衰减。时间窗应包含足够周期，不照搬30–80 Hz、100 ms窗口或20%调制门槛；振荡判定阈值先由指定SNN参考、背景及衰减/tonic阴性对照校准。

正候选延长观察并减半时间步，检查振荡持续性与数值稳定；用不同起点区分局部高态吸引与由间期可到达的状态。如果原SNN该范围只有tonic，停止把该范围解释为持续振荡；若SNN能振荡而rate不能，回到降阶闭合。不能为做出振荡单独给rate加新的全局抑制池。

### V4：积累驱动转变与后续分岔

两端动力学成立后，在SNN/rate中同时启用相同定义的活动依赖Z/M，连续携带所有状态与延迟历史，比较自然演化和固定Z对照。检验重复放电积累是否改变进入持续振荡的概率/临界控制区，而非只画M随高率上升。

到此才放行Fig.5分岔解释：按实际轨迹附近的对象决定分析固定点、周期轨道或随机跃迁，不能预先指定一定是Hopf。高态局部谱、低支fold及吸引域跨越分别报告。

## 6. 验收原则与失败诊断

物理重建使用数值身份与前缀检查；科学匹配以SNN的同图多噪声参考及事件量匹配区间为标尺。验证不是“差异不显著即等价”：每个主要读出的可接受偏差须在新rate结果打开前由参考及测量误差确定，冻结为独立数值文件。幅度、时间结构、空间传播任何一个必要层明显失败，都不能被较低联合loss抵消。

- 基线已错：先查阈值/驱动/突触单位与闭合，不搜core。
- 有限刺激可自限，连续噪声失败：查随机触发、恢复及格内波动，不只抬高驱动。
- SNN两端成立，rate一端缺失：修降阶表示；不宣称原SNN缺机制。
- rate两端成立，SNN未复现：视为降阶伪模式候选。
- 两端成立而动态Z不能连接：积累因果链未成立，不能由两端存在替代。
- 患者路线仍偏差但rate忠实复现SNN：可以接受降阶方法验证，不能接受患者传播机制结论。
