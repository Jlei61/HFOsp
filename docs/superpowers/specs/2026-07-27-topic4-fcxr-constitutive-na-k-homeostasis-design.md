## 0. 为什么换代际，而不是改上一版的激活函数

上一版把泵当作一个**应当在间期隐形的附加终止器**，并要求 `pump-on ≈ pump-off`。它没有通过：
即使把强度压到平均只扰动阈值 2% 的水平，间期事件仍变长约 40%、源区放电份额降低约 11.5%。

上一版归档给出的"下一步"（在激活函数里加半激活位置 `K`）**已作废**，理由是它自身不自洽：
在稳定间期的时间平均意义下

```
E[phi_K(u_i)] ≈ a_load * tau_N * r_i
```

在每 spike 跳变、清除时间与平均放电率固定时，改 `K` **不改变平均激活度**；它只改变工作点、局部
斜率和单次跳变的相对尺度，而且 `a_load`、`tau_N`、`K` 三者互相补偿，会引入参数不可辨识。

**本代际改变的是前提本身**：Na/K 泵本来就在正常状态下持续工作，参与维持静息电位与间期兴奋性。
因此不再要求它对基线隐形，而是把它写成**构成性**的离子稳态，并**重新标定**间期工作点。

新模型必须重新证明的，不是"泵开等于泵关"，而是：

> **离子化之后的网络，是否仍然产生与真实数据一致的稀疏、不规则、双向轴向的间期传播？**

## 1. 科学假设

不再是"抑制失效 → 高态 → 额外泵把它压死"，而是三个相互耦合的慢坐标：

| 慢坐标 | 承担的职责 |
|---|---|
| `Z_i` | 局部抑制可靠性与 onset permissivity（保留，参数不动） |
| `[K+]_o(x,t)` | 活动依赖的**局部正反馈**：招募与传播易感性 |
| `[Na+]_i → J_pump` | 累积负荷 → **负反馈**：终止与爆后记忆 |

预期生命周期（**预期，不是预设结论**）：

```
稳定间期 → Z 下降 / K_o 上升 → 轴向招募 → Na_i 上升、泵激活
        → K_o 回落 → offset → 高泵水平维持爆后抑制 → 离子稳态恢复
```

**onset 归因不得预设**。它可能主要由抑制可靠性下降驱动、主要由胞外 K 积累驱动、或二者协同才跨过
进入面；必须由 Phase B4 的消融决定（本 spec 不授权 B4）。

## 2. 最小构成性 Na/K SNN —— 明确不做什么

第一代际**不加入**：动态 `Cl_i` / KCC2、`Ca_i`、胞体—树突双室、细胞体积变化、去极化阻滞、
完整 Hodgkin–Huxley 离子电流。这些在更完整的模型里都有意义，但一次全部加入会让当前网络失去可辨识性。

第一版只加入六件事：

1. 每个 E/I 神经元的胞内 `Na_i`；
2. 二维空间共享的胞外 `K_o(x,t)`；
3. 构成性 Na/K 泵；
4. `K_o` 对膜兴奋性的 Nernst 型调节；
5. 线性储库/胶质等效清除；
6. 局部 `K_o` 扩散。

**命名合同**：本模型只称

> **reduced ion-homeostatic SNN**（约化离子稳态 SNN）

不得称为 ion-conserving neuron model，不得声称重建了患者真实离子浓度。`Na_i` / `K_o` 的
mM 单位是机制先验的量纲，不是 E1146 的实测浓度估计。

## 3. 方程

神经元 `i` 属类型 `a ∈ {E, I}`，映射到离子网格位置 `g(i)`。

### 3.1 构成性 Na/K 泵

```
J_pump_i = rho_a * F_Na([Na]_i) * F_K([K]_o,g(i))

F_Na(Na) = 1 / (1 + exp((Na_half - Na) / s_Na))
F_K(K)   = 1 / (1 + exp((K_half  - K ) / s_K ))
```

同时依赖胞内 Na 与胞外 K 的乘性 sigmoid 形式取自 Cressman–Ullah 系列。**半激活位置与斜率在
第一阶段固定，只标定 flux scale `rho_a`**；不得混用不同文献的半激活常数（见 §4 B0）。

### 3.2 每个细胞的胞内 Na

```
d[Na]_i/dt = J_Na_rest_a + q_ion_a * S_i(t) - 3 * J_pump_i
```

`S_i(t)` 是 spike train；`q_ion_a` 是一次 spike 对胞内 Na 的**有效**浓度增量；系数 3 来自泵每循环
外排 3 个 Na。因为当前 LIF 没有显式 `I_Na`，`q_ion` 是 spike 对真实 Na 内流的**粗粒化表示**。

静息 leak **不作为自由参数扫**，由参考工作点解析确定：

```
J_Na_rest_a = 3 * J_pump_0_a - q_ion_a * r_0_a
```

使得在参考平均放电率 `r_0_a` 下 `<d[Na]_i/dt> = 0`。

### 3.3 二维胞外 K 场

```
d[K]_o,g/dt = q_K_E * r_E,g + q_K_I * r_I,g
              - 2 * beta * mean(J_pump)_g
              + (K_res - [K]_o,g) / tau_K
              + D_K * laplacian([K]_o,g)
```

五项分别是：E 放电 K 外流、I 放电 K 外流、泵每循环回泵 2 个 K、胶质/血管等效储库清除、局部扩散。
`beta = V_i / V_o` 为细胞内外体积比。

储库浓度**不独立搜索**，由参考稳态求解：

```
K_res = K_o_0 + tau_K * (2*beta*J_pump_0_bar - q_K_E*r_E_0 - q_K_I*r_I_0)
```

这样不需要人为增加逐空间位置的 baseline source field。

### 3.4 胞内 K 与 K 反转电位

第一版用 Cressman 式近似，避免再引入一个独立的 `K_i` 动态方程：

```
[K]_i  = K_i_0 - ([Na]_i - Na_i_0)
E_K_i  = (RT/F) * ln([K]_o,g(i) / [K]_i)
```

### 3.5 与既有膜方程的耦合 —— 受引擎钩子约束

不重写整个 LIF 膜方程，采用**相对参考离子稳态的校正项**：

```
tau_m_a * dV_i/dt = F_FCXR_i
                    + ion_K_term_i                       # K_o 上升 -> E_K 变浅 -> 兴奋性上升
                    - eta_pump_a * (J_pump_i - J_pump_0_a)   # 高于静息的电生性外向电流
```

减去 `J_pump_0_a` **不等于**把泵变成静默插件：它只是把静息泵电流吸收进重新标定的 leak/bias 平衡。
**离子质量方程始终使用完整的、非零的 `J_pump_i`**（§3.2、§3.3）。

#### 3.5.1 引擎钩子审计（2026-07-27 已在代码中核实，是本 spec 的硬约束）

| 需要的钩子 | 现状 |
|---|---|
| 每步拿到 **E+I 全体** spike mask，用于网格累积 | **已有**：慢协议的 `step(spk, labels, dt)` 收到全长 `N` 掩码 |
| 慢对象自行决定更新频率（多时间尺度） | **已有**：慢对象持有自己的步计数 |
| **I 细胞的电导型耦合** | **不存在**：引擎在电导分支里执行 `Vtmp[~is_E] = cond_drive[~is_E] + …`，把 I 细胞强制拉回纯电流式，`g_rel[NE:]` / `g_rev[NE:]` 被**静默丢弃** |
| I 细胞的**附加电流**耦合 | **已有**：`cond_drive[NE:]` 生效 |
| 虚拟电极读出的空间范围 | **E-only**：记录器只对 E 细胞加权（`posE = pos[:NE]`） |

**由此产生的设计锁定**：Phase B0–B2 里，`ion_K_term` 与泵电生项**对 E 和 I 都写成附加电流**，
在模型自己的力匹配锚点上求值：

```
ion_K_term_i = g_K_ion_a * (E_K_i - E_K_0)          # 电流量纲，非电导
```

**不得**把 K 项写成 I 细胞的电导——那会被引擎静默丢弃，产生一个只作用于 E 的机制而报告成 E/I 都有，
这正是本 spec 要防的静默污染。若 B3 之后证明 I 细胞必须走电导路径，**另开一份受审阅的
guarded-engine-change spec**，不在科学 sprint 里顺手改 blessed 引擎。

## 4. E 与 I 都必须带离子状态

上一代际只让 E 细胞带泵，是为了隔离一个候选终止器。本代际**不再这样做**：

- I 细胞高频放电同样改变局部 K；
- 泵会改变中间神经元自身的兴奋性；
- 只改 E 会人为重塑 E/I 平衡；
- 更完整的局灶模型里，强烈的中间神经元放电可参与早期 K 建立与发作起始。

第一版为降低参数数目，**固定** `q_ion_E = q_ion_I`、`rho_E = rho_I`；只允许 E/I 的参考放电率和
膜电流转换因子不同。通过 Gate B 之后才做 cell-type sensitivity。

## 5. Z / M / X / H 的处置

- **`Z_i` 保留，参数一个不动**，仍解释为现象学的抑制可靠性，**不得**称为真实氯离子浓度；
- **`M = 0`、`X = 1`、`H = 0`**。否则无法判断终止来自 Na/泵、旧适应、突触中继耗竭还是全局刹车；
- **动态 `Cl_i` / KCC2 延后**。只有在 Na/K 生命周期通过、且抑制效能的发作内变化仍无法解释时，
  才另写 spec。

## 6. 新的 baseline gate：不再要求泵开/泵关等价

上一代际的 Gate I-a 判决**保留不重判**，作为上一代际的归档证据。

本代际的 baseline 问题改为：

> **这块新的构成性离子 substrate，是否重新达到真实数据与原科学目标所要求的间期工作点？**

优先级：

1. 真实 E1146 的间期分布（第一位）；
2. 原 substrate 已稳定的**双向轴向传播**性质（第一位）；
3. 上一代际模型的统计分布只作**工程参考**，不是必须逐项复制的真值。

**允许重新标定的 nuisance 参数最多是**：`I_bias_E`、`I_bias_I`，必要时再加一个全局背景驱动尺度。

**禁止修改**：椭圆连接梯度、core 位置、合作增益、连接权重、`Z` 参数、源/汇标签、泵以外的终止机制。

> 若必须同时修改连接、合作增益或 `Z` 才能恢复间期，说明 FCXR-ION 不是当前 substrate 的可控扩展，
> **应当停止**（见 §11 停机条件 4）。

## 7. 参数辨识顺序（禁止笛卡尔搜索）

**不得**直接搜索 `q_ion × rho × tau_K × D_K × g_K_ion × eta_pump`。分五步锁定，B0–B2 只执行前三步。

### B0（本 spec 授权）：选定一套**完整**参考家族并锁单位

固定：`Na_i_0`、`K_i_0`、`K_o_0`、`beta`、泵 sigmoid 的半激活点与斜率、K/Na 化学计量、
`K_i–Na_i` 近似关系。**必须整套取自同一个参考家族**（primary：Ullah–Cressman network family，
因为它本身就带空间 K 扩散、胶质清除与 E/I 网络），不得跨文献拼半激活常数。

同时锁定：mM、s、网格体积与膜电流之间的换算；建立真实 E1146 间期目标分布。**不跑 40k。**

### B1（本 spec 授权）：小网络确定 spike→ion 尺度与局部衰减

- `q_ion`：使单个 spike 变化很小；一次间期事件在参与区域留下**可测但会恢复**的 `Na_i` / `K_o` 瞬态；
  普通事件不产生持续 K 累积；重复事件簇能产生时间积分。
- `tau_K`：先把 `D_K` 固定在文献尺度（或接近零的 local-field primary），再拟合 `tau_K`。

> **`D_K` 不得用来拟合毫米尺度的传播速度。** 秒级的真实分子 K 扩散主要作用于较短空间尺度；
> 模型里的轴向传播仍应由突触连接产生。若最终必须使用远大于分子扩散的值，必须命名为 `D_K_eff`
> 并明确它是未解析胞外运输的 mesoscopic 参数。

### B2（本 spec 授权）：40k 新间期 substrate

只允许 `I_bias_E` / `I_bias_I` 重标定，重建稳定间期并验收双向轴向传播（见 §9 Gate B）。

### B3 / B4（**本 spec 不授权**，roadmap）

- B3：由冻结态的局部 `K_o` 微扰确定 `g_K_ion`（局部率增益、轴向传播易感性、共模/横向响应）；
- B4：由冻结高分支的 exit 确定 `rho` 与 `eta_pump`（先扫 pump activation 找到高支失去可持续性的
  最小泵权限，再区分离子通量尺度与膜耦合尺度）。二者不得分别任意拟合生命周期，且必须共用同一个
  激活函数。

## 8. 空间实现与积分

### 8.1 状态布局

- `Na_i`：per-cell，E/I 共 `N = 40000`；
- `K_o`：二维网格，primary `64×64`；sensitivity `32×32` 与 `128×128`；
- 每格保存 `K_o(g)`、`r_E(g)`、`r_I(g)`、`mean(J_pump)(g)`。

spike source **必须**除以该网格中的细胞数与网格体积，使改变网格分辨率不改变总浓度源。

### 8.2 不给离子场预设方向

primary **`D_x = D_y`**。不得让 K 扩散沿行为学轴更快——那等于把目标答案写进离子机制。
行为学轴只来自既有的椭圆连接、core 几何与事件起始位置。活动历史自然产生的离子场**可以**有方向，
但**参数本身**不得预设源→汇。

### 8.3 多时间尺度

膜与突触仍用 `dt = 0.05 ms`；离子状态 `dt_ion = 0.5–1 ms`。一个离子块内：

1. 用当前 `Na_i` / `K_o` 计算 `E_K` 与泵电流；
2. 跑若干膜步；
3. 累积 E/I spikes；
4. 块末更新 `Na_i`；
5. 更新 `K_o` 的 source、泵通量、储库清除；
6. 半隐式或稳定显式更新扩散；
7. **新离子状态从下一块才生效**。

必做：`dt_ion ∈ {0.5, 1, 2}` ms 收敛；网格分辨率收敛；3 Na : 2 K 化学计量测试；无 spike 时回到稳态；
不允许负浓度；safety bound 只作 fail-fast，**不得**充当动力学饱和器。

## 9. 本代际授权的两道门

### Gate H：稳态与数值合同（小网络 `N≈1000`，再到 `N≈4000`）

必须全部通过：

- 无 spike 时离子稳态稳定；
- **baseline 泵通量非零**（构成性，不是静默插件）；
- Na / K 平均质量残差接近零；
- 局部 Na / K 扰动能恢复；
- 3 Na : 2 K 化学计量正确；
- 网格、`dt_ion`、checkpoint/restart 一致；
- **离子插件关闭时旧引擎 byte-parity**；
- 不出现负浓度或触及 safety bound。

**Gate H 失败不进入 40k。**

### Gate B：40k 新间期 substrate

需要证明：

- 长 burn-in 后 `Na_i` / `K_o` 平稳，**没有缓慢倒计时**；
- 稀疏、不规则的间期事件保留；
- **forward / reverse 两种轴向传播保留**；
- 普通间期事件**不**产生全 sheet 的 K wave；
- 源 / 轴上 / 轴外参与度进入真实或预锁目标区间；
- baseline 泵不饱和；
- 普通事件后 `Na_i` / `K_o` 可恢复；
- 连接种子 1、3 与**未见**噪声种子同方向通过。

允许两项 tonic bias 重标定；**不得**为了修 event morphology 改连接。

### Gate T / C / S / E：**本 spec 不授权**

roadmap 见 §12。特别地，Gate T 的坐标不再是旧的二维，而是 **`(Z̄, K̄_o, N̄a_i)` 三维**，
在固定 `Z` 切片上画快系统吸引子并计算 branch-conditioned 慢流。

## 10. 三套虚拟电极读出

离子电流在本代际是**构成性**电流，因此需要三套读出：

```
V_synaptic          只含突触分量
V_synaptic_K        + K 相关的膜项
V_all               + 泵电生电流
```

主要的数据一致性判据仍用 `V_synaptic` 或 `V_synaptic_K`，以证明宽带变化来自网络活动重构，
而不是慢泵电流直接制造低频功率。`V_all` 只作机制敏感性，**不作**主要判据。

读出空间范围仍是 **E-only**（引擎记录器限制，§3.5.1）；这一点必须写进产物元数据。

## 11. 停机条件（任一触发即停）

1. 无法建立稳定的**非零**泵静息平衡；
2. 离子变量在普通间期持续漂移；
3. 普通间期事件产生全局 K wave；
4. 恢复间期需要修改连接或合作增益；
5. 必须加入 M / X / H 才能终止；
6. 泵关与完整泵的 offset 无差异；
7. 终止主要来自 LIF 的不应期上限；
8. `K_o` 只能通过人为增大的扩散沿轴传播；
9. 系统只能产生规则周期性的发作振荡器；
10. 高态进入 LIF 无法表示的去极化阻滞区；
11. 生命周期只在单一连接/噪声种子中存在；
12. 需要动态 `Cl` / `Ca` 才能保住最基本的 baseline。

触发后归档为 bounded negative，**不得**自动转入下一机制或扩大网格。

## 14. 允许的结论层级

- **Gate H only**：离子稳态与数值合同成立；尚未证明任何网络级性质。
- **Gate H + B**：构成性离子 substrate 重新达到间期工作点并保留双向轴向传播；尚未证明相图或生命周期。
- 更下游的层级由后续 spec 定义，本 spec 不预授权。

即使全部通过，安全表述也只能是：

> **reduced ion-homeostatic mechanism on an E1146-informed spatial scaffold**

不得声称重建了患者真实离子浓度，不得声称"证明了发作由离子稳态终止"。
