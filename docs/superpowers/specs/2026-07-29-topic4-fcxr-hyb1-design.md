## 0. 为什么换这条路（一句话）

**不要求一套离子方程同时承担"进入 / 维持 / 终止 / 恢复"四件事。** 每个慢变量只负责一件事：

| 变量 | 唯一职责 | 现状 |
|---|---|---|
| `Z` | 缓慢降低抑制裕度，触发 onset | 已有两档标定，夹住需要的中间档 |
| `δK` | 事件之后提高空间招募 | B2.1 刚测到这个效应（闭环 0.991 vs 开环 1.273，参与细胞 +42%） |
| `X` | 感知持续高态并终止 | 已证明能终止一次持续发作（有界、时序正确、两 seed） |
| `M` | 候选形成后再塑造宽带 / 去同步波形 | 已知能拓宽 + 去同步，单独持不住 |

## 1. 关键结构性改动：用**超出背景**的钾，而不是绝对浓度

$$\delta K(x,t) = K_o(x,t) - K_{\mathrm{bg}}(x)$$

`K_bg(x)` 逐格取自**已验收的间期工作点**（传感器模式 `g_K_ion = 0`，只记录不反馈，取时间平均）。
活网络里**只有 `δK` 进膜**。

**这一条正面绕开 B2.1 的阻塞，理由是结构性的**：B2.1 要靠**迭代**去找一个不动点，
而"超出量"形式让间期基线**按构造**就是不动点（间期 `δK ≈ 0` ⟹ 反馈为零 ⟹ 工作点不动）。
把"迭代求不动点"换成"让基线本身是不动点"。

**命名纪律（强制）**：这是 **activity-excess K recruitment layer**（活动超额钾招募层），
**不是**完整的患者离子浓度模型。归档、图题、commit 一律用前者。
`eta_pump` 仍锁 0；**不得**声称检验了泵的电生性作用。

**必须同时记录的自证**：间期窗内 `q99|δK|` 与 `q99|slope(δK)|`。若间期 `δK` 不在零附近，
本条设计前提失效，**停止并如实记录**，不得靠调 `K_bg` 救回。

## 2. `Z` 的非对称恢复（唯一新引擎改动）

- 高活动时按 `tau_Z_down` 耗竭；`X` 已终止、活动回落后按 `tau_Z_up` 恢复；
- **禁止瞬时 reset**（瞬时 reset 会把"恢复"变成脚本动作而不是动力学）。

改 `mz_slow_vars.py`（**非** blessed）。**必须复刻 LC1 给 `X` 做非对称 kinetics 的同一套纪律**：
默认关闭、开关关闭时**逐比特**还原单-`tau_z`、契约测试全绿。六个 blessed 引擎文件仍然不许动。

## 3. 一维有效失效速率轴（不做多参数插值）

`q75`（`I_th_EI = 95.198`, `tau_z = 5000`）与 `q50`（`I_th_EI = 1.665`, `tau_z = 10000`）
**两个原始参数同时不同**，直接插值会同时移动两件事，得到的点无法归因。

**改为**：用两个**可观测量**定义标量轴 —— onset 前 `D_Z(t)` 的斜率、以及 onset latency。
先在冻结慢变量 / 低维代理上求出参数到这两个观测量的映射，再**只挑三个**落在 q75 与 q50 观测值
之间的有效速率点。三个点在提交前锁死并写进本文件。

## 4. 执行顺序（严格按此）

1. **低维拓扑先行**：在冻结慢变量 / 低维代理上检查 `Z–δK–X` 是否存在
   `稳定间期邻域 → 有界高态 → X 终止 → 恢复` 的拓扑。**没有这个拓扑就不上 40k。**
2. **40k 开发格点约 12–18 个**：3 个有效 `Z` 速率 × `δK` 关/开 × `X` 关/开。
3. **只有出现完整生命周期候选**之后，才固定一个 `M` 配置去改善宽带与去同步。
4. **最后**才跑 seed3 与未见 noise seed。

## 5. 最终验收（七条**同时**满足；每条给数值门 + 坏数据回归）

| # | 门 | 数值判据 | 应当**失败**于 |
|---|---|---|---|
| 1 | 无 kick 自发进入 | `n_kicks == 0` 且 onset 被检出（构造可验证） | — |
| 2 | 间期 ≥ 8 s 稀疏不规则 | onset 前连续窗 ≥ 8 s；事件率在已验收间期率 ±50% 内；`CV(IEI) ≥ 0.5` | **`q50`**（pre-ictal 仅 0–1 s） |
| 3 | 1–5 s 有界持续高能量振荡 | 高态时长 ∈ [1, 5] s；带内功率 ≥ 间期 5×；`bounded = True`；零 clip | **`q75`**（episodes 自灭，X inert） |
| 4 | 真实空间招募 | 招募虚拟电极数 ≥ 待锁 N；源空间 onset 梯度**非同时** | 同步全场共点火 |
| 5 | `X` 在 onset 之后启动 | `x_after_onset = True` 且 `D_X` 上升起点晚于 onset ≥ 待锁 Δt | — |
| 6 | 回到原间期统计邻域，**不是**固定周期轨道 | post-ictal 事件率与 `CV(IEI)` 落在 pre-ictal 的容差内；**且**跨 seed 的发作间隔 `CV ≥` 待锁值 | **`q50`**（Z 停在耗尽位 / seed3 近全静默） |
| 7 | 无 clip、无 runaway | 零 clip；末段率 < runaway 界（`q50` 单独是 452.8 Hz） | **`q50` 无 X** |

**坏数据回归就是已有的两条 bounded-negative 轨迹**：`q75` 必须挂 #3，`q50` 必须挂 #2 与 #6。
**一个不能把 q75/q50 判失败的判决器，没有资格判成功。** 这两条回归在跑任何新格点之前先上。

第 4/5/6 行标"待锁"的三个数值，**必须在看任何新结果之前**填死并写进本文件。

## 6. 允许 / 禁止

- **禁止**把本设计说成"完整离子模型"、"发作生命周期已达成"、"limit cycle"、"bistability"；
- **禁止**跨过 §4 的顺序（低维拓扑不过就跑 40k）；
- **禁止**用生命周期结果反选判决阈值（§5 待锁值先填死）；
- **允许**说：这是把 B2.1 测到的钾招募效应，作为一个受控部件，接回**已分别验证过**的
  `Z` onset 与 `X` termination。
