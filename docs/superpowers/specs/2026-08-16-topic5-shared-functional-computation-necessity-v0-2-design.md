# Topic 5.2 跨网络共同功能响应 necessity v0.2

**状态**：P0 修复后冻结并全量重跑。  
**性质**：这是 v0.1 的 outcome-blind 修复合同，不是重新选择问题、方向、事件、终点或统计方法的独立预注册。

## 1. 科学问题

四种连接方式不同、但都用同一患者真实事件顺序训练的冻结 RNN，会产生相似的“扰动一小片组织后，未来哪些触点输出改变”的响应图案。本实验检验更强的问题：

> 只用另外三种网络的训练事件定义共同响应成分；从第四种网络的留出事件状态中删除该成分，是否比删除同样大小的无关成分更明显地损害未来触点预测？

只有选择性损害成立，才支持“不同连接实现依赖同一个低秩内部成分”。响应图相似、与数据相关或扰动当下输出改变，都不能单独证明必要性。

## 2. 冻结对象与拆分

- 28 位患者，42 个患者内 fit。
- 四种真实顺序网络：仅近邻、近邻加短连接、近邻加随机远连接、近邻加数据选择的远连接。
- “前半段—后半段对应关系打乱”的网络只提供顺序对照。
- 630 个 checkpoint 的模型参数、连接掩码、触点读出、STOP head 和 size decoder 全部冻结。
- 功能响应算子只由训练事件提取。
- 删除检验只在留出事件的冻结 reference states 上执行。
- TA/TB 标签不进入训练、方向定义、删除或预测终点。

## 3. 训练侧功能响应表

对每个 checkpoint，在训练事件的早、中、晚状态上依次扰动组织平面的 Gaussian 小片，teacher-force 相同真实后续输入，记录未来 1–3 步每个触点的 pre-mask logit 中心差分。得到：

\[
O_a\in\mathbb R^{C\times M},
\]

其中行是未来触点，列是被扰动的组织小片。每列减去触点均值，去除 softmax 共同平移；每张表除以 Frobenius norm，避免响应幅度大的网络支配比较。

## 4. 跨网络留一方向

测试网络 \(a\) 时，只用其余三种真实顺序网络：

\[
O_{-a}=\operatorname{median}\{\widetilde O_b:b\ne a\}.
\]

对 \(O_{-a}\) 做 SVD，并通过测试网络自身冻结的组织小片基底把前三个右奇异向量映射回 hidden space。Primary 删除第一维；前 1/2/3 维累计删除是预注册 sensitivity。

方向冻结不得读取：测试网络自身响应表、留出事件 target、留出事件完整传播场。

## 5. P0 修复：删除中心必须与留出结局无关

v0.1 使用：

\[
c_{e,k}=\gamma(s_{e,k})+u_e b(s_{e,k}),
\]

其中 \(u_e\) 由该留出事件的完整 future field 计算。这使删除幅度 \((h-c)\) 和 support gate 在评价前看到了事件后半段，违反 target-free 合同。

v0.2 唯一允许的中心是训练阶段拟合的 phase curve：

\[
\boxed{c_{e,k}=\gamma_{\mathrm{train}}(s_{e,k})}.
\]

- `event_u` 与旧 `conditional_center` 在读取 reference archive 后立即删除；
- feature scale、kNN support 和流形残差阈值全部在该 train-phase 中心下重新拟合；
- 留出事件真实后半段只在方向冻结完成后用于计算预测损失；
- 全部 630 个训练算子、168 个留一方向、504 个单方向删除和 504 个累计删除单元重新执行或重新冻结。

## 6. 删除与对照

对留出状态 \(h\)、共同单位方向 \(u\) 和剂量 \(\alpha\in\{0.25,0.50,1.00\}\)：

\[
h_\alpha=h-\alpha uu^\top(h-\gamma_{\mathrm{train}}(s)).
\]

删除仅作用于 hidden state；已出现触点、rank index、STOP/size bookkeeping 与模型参数不变。每个状态同时运行：

1. 共同方向；
2. 同范数正交方向，并匹配扰动当下的 readout change 与一步 hidden gain；
3. 同范数高方差方向；
4. 同范数“后半段对应关系打乱”网络方向；
5. 不删除基线。

分支必须通过有限值、node range、局部 kNN support 和 train-phase 流形残差检查；禁止 clip。

## 7. 终点与统计

Primary 是扰动后未来第 1–3 步实际 next-rank set 的 NLL 改变：

\[
\Delta L=\operatorname{mean}_{\tau=1}^{3}[L_\tau(h_\alpha)-L_\tau(h)].
\]

三档剂量以 dose AUC 汇总。聚合顺序固定为 reference state → seed → fit → patient。三个 primary 患者级检验为：

1. 删除共同方向后损失大于 0；
2. 比同范数正交方向造成更大损失；
3. 比打乱后半段网络方向造成更大损失。

三项做 Holm 校正；还要求四种待测网络中至少三种方向一致。高方差方向、即时下一步、早中晚阶段及累计前 1/2/3 维均为 sensitivity，不改 primary。

## 8. 工程与科学判据

硬工程门：630/630 训练算子、168/168 留一方向、504/504 单方向删除、504/504 累计删除；参数 hash 不变；留出 reference 全来自 test split；方向不读待测网络；有效 NLL 有限；位移范数相等；浮点重放误差不超过 \(10^{-5}\)。

科学判据：三项 primary 的中位数均大于 0、Holm \(P<0.05\)，且至少 3/4 网络方向一致，才判 `SUPPORTED`。
