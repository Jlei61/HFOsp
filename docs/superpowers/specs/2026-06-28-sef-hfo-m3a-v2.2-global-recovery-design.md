## 0. 一页纸朴素话（测了什么 / 怎么测 / 想揭示什么）

**想测什么** —— 把"组织里慢慢变化的抑制资源 / 疲劳 / 全局恢复"做成三个分工不同的慢状态，
看它们能不能让网络走完一条完整轨道：**沿一条主通道的小事件 → 旁边也被招募、范围变大 →
大到一定程度时，一个"看整体活动"的全局抑制被自然唤起，把活动按回去 → 回到安静**。
关键是这条轨道里"破轴（拐到旁边）"和"回来"是**两个不同的变量**干的，不是同一个刹车既破轴又终止。

**怎么测** —— 不再用一次 55ms 的瞬时踢出（上一轮就卡在事件太短、慢变量来不及形成离轴许可度），
改成**缓慢把背景驱动加上去再 HOLD 住不撤**，给慢变量几百 ms 去积累。然后对照：
如果完全没有这套慢变量（slow-off），同样的持续驱动下网络是什么样；加上慢变量后，活动的"范围、
方向、能不能自己回到基线"有没有按设计的顺序发生。最重要的是要排除一个假阳性：**一个全局刹车把
活动硬压下去也能制造"回到了基线"，但那不等于"闭环轨道成立"**——所以要拿"时序打乱的 / 静态等量的"
假 `h_G` 做对照，只有真·活动触发的 `h_G` 比这些假对照都强，才算数。

**想揭示什么** —— 在这个尺度上，"慢变量闭环轨道"**看起来像 / 不像 / 没看清**可被实现。
若 slow-off 在持续驱动下本身就变温和了，那是协议/衬底的功劳、不归慢变量；若真·`h_G` 跟静态等量
假 `h_G` 没区别，那是"全局刹车"不是"闭环轨道"；若"破轴"只在失控里出现，则 prior 未被推翻。

（内部归档代号：M3A-v2.1 Step 1–4 NEGATIVE；`q_I`/`g_K`/`h_G`；sustained ramp+HOLD `nu_signal_fn`；
matched-static / time-shuffled / constant-peak surrogate-`h_G`；causal-lead；no-rebound gate；
Exp 0 frozen `M50/B50/Π50`；ablation A–F；`λ_G` q-replenish secondary；D_EE deferred）

## 1. 背景：v2.1 立住的事 + 根因（不复述，仅锚点）

- **v2.1 closed-loop 四步一致 NEGATIVE**：field-only 载体正（`σ_q>σ_K` 能造离轴易激优势），但接回会自放电的
  网络推不动。根因**不是缺恢复变量**，而是：
  - **全或无是 recurrent E→E 衬底属性**：一旦点着，接力网把波推到底。Step 2 `axis_reach_frac≡1.0`
    且 L 从 10 加到 16 仍 1.0（薄片多大铺多大）；field pilot "一传播即全场，无局部沿轴行波窗口"。
  - **事件太短（~55ms）**：`q_I/g_K` 来不及在离轴把许可度耗深。Step 3 `Γ_K` 目标 2.0、实际中位 0.082；
    `q_off_min` 从未 < 0.7（最低 0.735）；离轴只在 runaway 出现且 `returned=False`。
  - **无稳定中间态**：Step 4 低-`q` 预载是鞍点，~0.9 → 直接砸到 0.18/0.02，0.5–0.7 落不住。
- **结论锚点**：`docs/topic4_m3_stage.md §2/§6`；`docs/archive/topic4/m3a_v2_{field_pilot,substrate_qualification,
  step2_qI,step3_qI_gK,step4_lowq}_2026-06-28.md`；公式 `docs/snn_core_model_equations.md §B5`。

**v2.2 的两个改动正是冲着根因去的**：(a) 换持续驱动协议，给"刹车类"慢变量积分窗口；
(b) 新加全局恢复变量 `h_G` 把"回来"从 `g_K` 身上分出去。**但**根因里"全或无是衬底属性"这条意味着：
**持续驱动本身不保证造出部分填充**——真正限制蔓延的是刹车机制（本轮 `g_K`，给够时间后），
这一点写进硬合同 C1/C4，**不预设成立**。

## 2. v2.2 假设 + 变量职责分离

**假设（可证伪）**：在持续 ramp+HOLD 驱动下，

```
局部沿轴点火
  → q_I↓（推：局部+周边去抑制，事件扩大）
  → g_K,axis↑（转·限：轴向兴奋性资源↓ + 给够时间后在波前刹住、造部分填充）
  → 大范围 / 高参与活动（M,B,Π↑）唤起 h_G（回：全局抑制按回去）
  → 在 HOLD 驱动不撤的情况下仍回到基线且不反弹
```

这条轨道**可被实现且可被检出**，而且"回来"由 `h_G`（全局、活动触发）完成、"破轴"由 `q_I/g_K`（空间）完成——
**两件事是两个变量**。

| 变量 | 职责 | 看什么 | 状态 |
|---|---|---|---|
| **`q_I(x,t)`** 抑制资源场 | **推**：局部+周边去抑制（足迹宽 `σ_q`） | 局部活动 | 已有（§B5.2） |
| **`g_K(x,t)`** 疲劳场 | **转·限（hypothesis，不预设）**：轴向资源↓ + 给够时间在波前限范围（足迹窄 `σ_K`） | 局部 E 活动 | 已有（§B5.3），**新职责（不预设）** |
| **`h_G(t)`** 全局恢复标量 | **回**：大范围/高参与/高弥散时被招募，全局压 E、按回基线 | **网络整体活动**（非轴/旁分区） | **新加** |

`h_G` 的设计核心：**不看轴/旁硬分区**，只看整体活动（总放电 `M`、软参与面积 `B`、空间弥散 `Π`）。
所以小的沿轴事件不强触发它；越接近失控（参与神经元越多、整体放电越强、越铺向全场），它越自然上来。

## 3. 硬合同（review P0/P1 → 不可绕过的设计约束）

> 这些是**承重定性主张的数值/结构闸门**（memory `feedback_acceptance_gate_encode_conclusion`）：
> 每条都带一个会让 v2.2 **诚实落回负结论**的分支。spec 正文与后续 TDD/runner 必须逐条落实。

### C1 — slow-off sustained baseline 是硬分支（P0-2）

**先跑** `slow=None` 在持续 ramp+HOLD 协议下的事件，按四类分类。

- **分支 A（失败模式被保留）**：slow-off 仍全或无 / 全场 runaway / 不 returned → 协议保住了 v2.1 的失败模式
  → 后续 graded/returned 行为**才可**归因给 `q_I/g_K/h_G`。
- **分支 B（协议自己改了衬底）**：slow-off **已经** graded / 部分填充 / returned → **停止归因给慢变量**，
  结果改写成"**持续协议本身改变了衬底的事件 regime**"（属 handoff fork 2 / 协议·衬底发现），
  **不得**写成 `h_G`/`q_I`/`g_K` rescue。spec 与 runner 必须显式判定走 A 还是 B 并据此措辞。

### C2 — HOLD 是 primary recovery gate；release 只做外源对照（P0-2）

- **主 recovery 判据**：驱动 ramp 到 `r_hold` 后**保持不撤**整个观察窗。"回到基线"必须是 `h_G`（+`g_K`）干的。
- **ramp-and-release 仅作对照**：撤驱动后的回落只能用来区分"内源 vs 外源 recovery"，**不得**进入主成功判据。

### C3 — `h_G` 因果归因 surrogate 电池（**onset-gated**）+ recovery-causal 时序（P0-1）

`I_net,i -= η_G h_G` 本质是**全局 E-only 刹车**；rate 掉下去 ≠ 闭环轨道成立（A1c 已证全局动态反馈有 timing 作用但会过压弱态）。

**关键防伪：surrogate 必须 onset-gated。** 否则从 `t=0` 起恒定的假 `h_G`（尤其 constant-peak）会直接**压住点火**，
那时 dynamic "赢" 只是因为它允许先点火，而不是证明动态恢复时序必要。故所有 surrogate 在 dynamic run 的
`t_gate`（= `t_{hG5}`：`h_G` 首次过其 run-max **5%** 的**起势时刻**；或退用 `t_{χ50}`。另 `t_{hG50}` = 过 50% = **主升**时刻）**之前一律设 0**（与 dynamic 早段一致、同样允许点火 + 早段演化），
`t_gate` **之后**才回放各自值——只隔离**恢复相**的 `h_G` 时序：

- **matched-static**（timing surrogate，保留抑制"预算"、毁时序）：`t≥t_gate` 时 `h_G ≡ mean_t h_G^dyn`。
- **constant-peak**（保留峰值幅度、毁渐升）：`t≥t_gate` 时 `h_G ≡ max_t h_G^dyn`。
- **time-shuffled**（保留幅度/形状分布、毁与 `M/B/Π` 的对齐）：`t≥t_gate` 回放时间反转 / block 置换后的 `h_G^dyn(t)`。

**`ignited` 记录 + 判读**：每条 surrogate 记 `ignited`。若某 surrogate **没点火**但 tail 低 → 标
`prevented_no_ignition`，**不算 "surrogate 失败"**（不得据此给 dynamic 记功——它只说明该 surrogate 把点火也压了）。
只有当 **dynamic 给出按顺序的 returned+off-axis+no-rebound 轨道，而 onset-gated surrogate（均已点火）给不出**
（runaway / oversuppress / 破坏顺序）时，才允许说"恢复相的动态时序是必要的"；否则只是"全局刹车"。

**recovery-causal 时序闸门**（替代单纯 causal-lead）：单纯 `χ_G` 领先 `h_G` 是 ODE 结构**自然**发生的、不足以证因果。
真正的因果证据是 **`h_G` 领先 rate 回落**：`h_G` 主升/峰值须早于 `-dM/dt` 主峰 / `Y_new` 回落主段；
满足才可写 "`h_G` 驱动回落"，否则只写 "`h_G` 伴随上升"。（`t_{χ50}<t_{hG50}` 仅作 necessary sanity，保留但不单独承重。）

### C4 — `g_K 负责转` 不预设；破轴须在 `h_G` 主升前确立（P1-2）

Step 3 显示 `g_K` 主要是**刹（压轴）**不是**转（重定向）**；Step 4 中间态落不住。故：

- **轨迹顺序闸门（paired，禁裸 `>0`）**：在 `[event_onset, t_{hG5})`（**`h_G` 起势之前**）的窗口里，相对**同 seed 的
  slow-off / arm C 或事件 pre-window** 的配对增量，必须 `ΔF_off ≥ δ_F` **或** `ΔG_PR ≥ δ_G`，
  **且超过 slow-off sustained 自身的同窗变化**（扣掉 ramp/HOLD 协议本身的 broadening / rate-scale 污染），
  且**不是只有 `ΔS_axis < 0`**（轴死≠破轴）。`δ_F/δ_G` 用 pilot 分布标定。
- 若离轴/全局只在 `h_G` 起来**之后**才升、或全程只 `S_axis↓` 无 paired `F_off↑/G_PR↑` → 判为
  "**axis-suppressed-not-redirected**"，**不算成功**（是 `h_G` 全局压制冒充破轴）。

### C5 — no-rebound gate（HOLD 下 `h_G` 衰减后不复燃）

防"`h_G` 压下去 → 衰减 → 持续驱动又点回来"的平凡循环被当成功：

- HOLD 驱动**不撤**，`h_G` 自然衰减后，继续观察 **≥ `max(2τ_G, 1000 ms)`**：
  rate **不得**重新越过 `baseline + m·σ_base`。复燃即 **fail**。

### C6 — Exp 0 标定冻结 + eligibility fail-closed（anti-circularity）

`M50/B50/Π50`（及 `τ_s`、Hill `n`）必须从 **no-`h_G` replay** 标定并**冻结**，Exp 2 期间**不可**为成功而回调。

- **eligibility fail-closed**：若 no-`h_G` replay 里**缺** clean returned-axial anchor **或** near-runaway anchor
  （`M50=√(M95^{returned-axial}·M20^{runaway})` 无法成立）→ Exp 0 标记 `UNCALIBRATED`、**不进入 Exp 2**，
  **绝不**临时手调 `M50/B50/Π50`。spec 与 runner 记录冻结值 + 来源 run + eligibility 判定。

### C7 — `λ_G` q-replenish arm 定义（P1-1，修我原稿矛盾）

- **主模型（arm E）= `q_I + g_K + h_G`，`λ_G = 0`**（无 q 回灌）。primary 成功判据只认 arm E。
- **arm F = arm E + `λ_G > 0`**（开 q 回灌）：**secondary**，只回答"q 回灌是否**额外**改善 no-rebound（C5）"，
  **不得**进入 primary 成功判据。

### C8 — 红线 / 措辞（继承 + 收紧）

descriptive mechanism screen，非发作机制 validation。**禁**："已破轴 / 已出现发作样离轴招募 /
证明存在 saddle·双稳态结构 / 慢变量机制被证伪或被证成 / Abbott 机制已验证 / `h_G` rescue 成发作样招募后恢复"。
`h_G` 只能写成 **global recovery / restraint variable**。off-axis 若仍只在 runaway 出现 = prior 未被推翻。
`ictal-like candidate` 必须沿用现有四条件（大范围 ∧ 轴优势↓ ∧ off-axis/global↑ ∧ returned），不得只看 returned
（分类器结构 `src/topic4_m3a_v2_phenotype.py::classify_event` 已对，**不改 gate 结构、只标定阈值**）。

### C9 — 行为保留腿（behavioral preservation；从 C3 拆出，P1）

"preservation control" **不是** matched-static（那是 timing surrogate，归 C3）。真正要问的是：
**同一组主模型 `h_G` 参数，会不会把本应保留的小局部轴向 / returned-axial 工作态压成 silent / tiny blip？**

- 在**低 `r_hold`** 或 **canonical local-axial 事件**上跑主模型 `h_G` 参数：`χ_G` 应保持低、`h_G` 不应强触发，
  小轴向事件仍被分类为 `interictal_axial`（不被压成 silent / tiny blip）。
- 若主模型在大事件上"成功"但**保留腿 fail**（小轴向工作态被压死）→ 只能写
  "**过强全局刹车，无可用操作窗（no usable operating window）**"，**不得**写成机制成功。

## 4. 公式

### 4.1 事件协议：持续 ramp+HOLD 驱动（runner 级 `nu_signal_fn`，**不碰核心引擎**）

引擎已暴露 `simulate_kick(..., nu_signal_fn=None, ...)`（`kick_probe.py:91`），每步
`nu_now = nu_signal_fn(t_ms) + xi`（`:229`），`None` 时回落到常数
`p.nu_ext_ratio·nu_theta`（`:145–147`）→ **常驱动路径字节不变（parity 自动）、无需 re-bless**。

```
nu_signal_fn_holdN(t):  r(t) = r0 + (r_hold - r0) · clip((t - t0)/t_ramp, 0, 1)        # ramp 到 r_hold 后 HOLD
nu_signal_fn_release(t): 同上，但 t ≥ t_release 后 r(t) → r0                            # 仅对照（C2）
nu_signal_fn(t) := nu_theta · r(t)
```

`KICK_BOOST` 可设 0（纯持续驱动），或留一个小 seed kick 触发首点火（runner 参数，不进 primary 判据）。

### 4.2 `h_G` 传感器（全部从率场算，复用基础设施）

传感器用一个**更快的**率场 EMA `r̃_E`（时间常数 `τ_s`，独立于慢变量的 `tau_a`，§B5.1）：

```
M(t) = ⟨ r̃_E(x,t) ⟩_x                                          # 总活动强度
B(t) = ⟨ σ( (r̃_E(x,t) - r_A)/Δ_A ) ⟩_x ,  σ(z)=1/(1+e^{-z})    # 软参与面积（非硬阈）
Π(t) = (Σ_x r̃_E)^2 / ( N_x · Σ_x r̃_E^2 + ε )                  # 空间 participation/globality（局部高峰→低；大范围均匀→高）
```

### 4.3 `h_G` 触发 + 动力学 + 膜耦合

```
χ_G(t) = H_{nM}(M; M50) · H_{nB}(B; B50) · H_{nΠ}(Π; Π50),   H_n(z; z50) = z^n / (z^n + z50^n)   # 平滑 AND
ḣ_G    = - h_G/τ_G + k_G · χ_G(t) · (h_G^max - h_G),         0 ≤ h_G ≤ h_G^max                    # 有界 build（同 g_K 写法）
I_net,i -= η_G · h_G        (i ∈ E)                                                                # 仅 E（I 细胞先不加）
```

### 4.4 可选 q 回灌（**仅 arm F**，C7）

```
∂_t q_I(x,t) += λ_G · h_G(t) · (1 - q_I(x,t))        # arm E: λ_G=0；arm F: λ_G>0（secondary，只看 no-rebound）
```

### 4.5 相图新 Y（`h_G` 不伪造破轴）

```
P_R^new(t) = log(lgr_R) - ⟨log(q_I+ε)⟩_R - β_K⟨g_K⟩_R - β_G h_G(t)     # -β_G h_G 对 axis/offaxis/global 一视同仁
X^new = P_axis^new - P_offaxis^new = X        （h_G 在差分里抵消 → 破轴仍须来自 q_I/g_K 空间差）
Y^new = P_global - β_G h_G                     （h_G 的职责是把 runaway-risk 的 Y 拉回）
```

|---|---|---|
| A | slow-off | **C1 硬分支基线**（决定能否归因给慢变量） |
| B | `q_I` only | 推单独够不够 |
| C | `q_I + g_K` | 推+转·限（无全局恢复） |
| D | `q_I + h_G`（`λ_G=0`） | 恢复单独能否（破轴未必 `g_K`） |
| **E** | `q_I + g_K + h_G`（`λ_G=0`） | **primary 主模型** |
| F | E + `λ_G>0` | secondary，仅看 q 回灌是否**额外**改善 no-rebound（C5） |

**判读口径**：D 成而 C 不成 → recovery 是关键但破轴未必 `g_K` 驱动；E 成 D 只 expanded → `g_K` 转、`h_G` 回
（**"`g_K` 负责转"只有 C4 pre-`h_G` paired off-axis gate 过才可写，否则只写"`g_K` 压轴"**）；
E 只把事件压小 → `h_G` 太早/太强（oversuppress）；E 仍 runaway → `h_G` 太晚/太弱或越 separatrix 太深
→ 才轮到 D_EE / 衬底重做（deferred）。

## 6. 成功判据（轨迹顺序，防 oversuppress / 防"只压不转" / 防复燃）

**不只看 returned**。一次 arm-E 事件算"候选成功轨道"需**同时**满足：

1. **破轴在前（C4 paired）**：`[onset, t_{hG5})` 窗内**配对**增量 `ΔF_off≥δ_F` 或 `ΔG_PR≥δ_G`，**且超过同 seed slow-off sustained 同窗变化**，非只 `ΔS_axis<0`。
2. **`X` 先降**：`X^new(t)=P_axis-P_offaxis` 在 `h_G` 主升前/同时已下降（轴优势先被 `q_I/g_K` 改）。
3. **`h_G` 驱动回落（C3）**：`h_G` 主升/峰值**领先** `-dM/dt` 主峰 / `Y_new` 回落主段（非仅 `t_{χ50}<t_{hG50}` 形式领先），且动态 `h_G` 跑赢全部 **onset-gated** surrogate。
4. **`Y` 拉回**：`Y^new=P_global-β_G h_G` 先升后降，事件 tail 回落。
5. **HOLD 下 returned 且 no-rebound（C2+C5）**：驱动不撤，post-rate ≤ `baseline+m·σ_base`，且 `≥max(2τ_G,1000ms)` 不复燃。
6. **phenotype**：四类 gate 判 `ictal_like_candidate`（大 ∧ `S_axis`↓ ∧ off-axis/global↑ ∧ returned）；runaway 不算成功。
7. **保留腿（C9）**：同参数在小局部轴向 / 低 `r_hold` 上不被压死；保留腿 fail → 写"过强全局刹车、无可用操作窗"，不算成功。

任一不满足 → 不是成功轨道（按缺哪条诚实写"axis-suppressed-not-redirected" / "oversuppress" /
"rebound" / "off-axis-only-in-runaway" / "no-usable-operating-window"）。

## 8. TDD 合同（engineering，写进 writing-plans 的 red 测试）

- **parity（拆 engine-output vs trace-behavior）**：(a) **engine-output**：`use_hG=False`（ODE path）**且** `k_q=0,k_K=0,h_G0=0` → 与 `slow=None` **字节一致**；`eta_G=0` 时 `apply_currents` 膜电流与 `h_G` 无关（**但 trace 可非零、分开断言**）。(b) **script path**：`hG_script` 非 `None` → `h_G` 逐步精确等于脚本（覆盖 ODE）。(c) `k_G=0` **仅在** ODE path 且 `h_G0=0` 才等于"无 `h_G`"——`k_G=0` 配非零 init/`hG_script` **不是**无影响。engine-output parity 与 trace-behavior **分别测、不混**。
- **onset-gated surrogate（C3）**：`hG_script` 在 `t<t_gate` 返回 0、`t≥t_gate` 返回 surrogate 值；runner 记 `ignited`，未点火+低 tail → `prevented_no_ignition`（不计 surrogate 失败）。
- **`h_G` 动力学**：bounded build（`0≤h_G≤hG_max`）、`χ_G=0` 时只衰减、长随机无 NaN、`k_G` 是强度旋钮（更大 build 更快/更高）。
- **scripted-`h_G`（clamp/surrogate 路径）**：`hG_script` 非 `None` 时 `step` 内 `h_G` 逐步**精确等于** `hG_script(t)`（跳过 ODE，不衰减）；`hG_script=None` 回到 ODE 路径。
- **传感器单测**：小局部轴向事件 `χ_G<0.1`（不触发）；大范围高参与事件 `χ_G→`高（触发）；`Π` 在单热点→低、均匀→高；`B` soft 非硬阈。
- **膜耦合**：`apply_currents` 只压 E 不压 I（I 细胞输出与 `h_G` 无关）。
- **相图**：`proxy_phase_point` 新 `Y_new=P_global-β_G h_G`；**uniform `h_G` 下 `X` 不变**（差分抵消）。
- **协议**：`nu_signal_fn=None` 路径与现 baseline 字节一致；ramp+HOLD vs release 行为正确。
- **判据**：`trajectory_success` 在合成轨迹上正确区分 success / oversuppress / axis-suppressed-not-redirected / rebound / off-axis-only-in-runaway。
