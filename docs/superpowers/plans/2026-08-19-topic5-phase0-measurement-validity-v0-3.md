## 0. 这一步要回答什么（朴素话）

v0.2 得到两个"没测出来"：顺序里没有额外信息、患者方向轴没有优势。但方向那一层已经查明是
**仪器没有检出力**（把正确答案直接告诉它也认不出）。顺序那一层还没查过同样的问题。

所以 Phase 0 只问一件事：**给这套流程一份「我们知道答案」的数据，它能不能把答案找回来？**
找不回来，就不再跑几千个结构单元，也不许把真实数据的零结果解释成"不存在"。

这是**测量有效性闸门**，不是结果阳性闸门。四种 teacher 的期望结论各不相同，其中两种期望是零。

## 1. 四种 teacher（都长在真实患者的电极几何与真实事件量上）

用真实 SEEG 患者的 `coords_3d_mm` / `contacts_xy_mm` / `shafts` / 事件数 / 每事件 rank-set 数分布，
只把"谁按什么顺序被点亮"换成已知规则生成。

| id | 生成规则 | 顺序信息（**设计时就知道**） | 该 teacher 用来判什么 |
|---|---|---|---|
| `T1_ORDER_BLIND` | 下一个触点只由**累计集合**决定 | **恒为 0** | 假阳性对照 |
| `T2_SINGLE_DIRECTED` | 沿一条固定轴单调推进 | **接近 0**（集合已编码进度） | 诊断：真实数据的零是否兼容"传播是真的但单调" |
| `T3_TWO_MODE` | 前两个触点定方向，之后保持；同一集合有两种未来 | **大** | 检出力（power） |
| `T4_HIDDEN_RELAY` | 未观测 source / 中继驱动，学生只看到部分触点 | 中等，且被部分观测削弱 | 部分观测下还剩多少检出力 |

**T2 是本设计的关键**：如果传播是沿一条轴单调推进的，那么"到目前为止点亮过谁"这个集合
**已经**是充分统计量，顺序不带额外信息。这时零结果是**正确**的，不是仪器坏。
T2 与 T3 的对比把"仪器瞎了"和"单调传播本来就没有额外顺序信息"分开。

## 2. 真值统计（不依赖任何被拟合的模型）

对每个 teacher、每位患者，直接从生成器算**给定集合后顺序还携带多少关于下一步的信息**：

I(顺序; 下一触点 | 集合) ≈ E[ KL( p(·|S, π_真) ‖ Σ_π w_π p(·|S, π) ) ]，
w_π ∝ P_teacher(π | S)（自归一化重要性权重，K 个采样置换）。

按 teacher 自己的生成概率给置换加权是必须的：对 T2，除按投影排序外的顺序生成概率≈0，
因此条件顺序分布退化、该量趋于 0——这正是"单调传播没有额外顺序信息"的形式化。
朴素置换（等权）会把 T2 误算成有大量顺序信息。

**验收**：`T1 ≈ 0`（构造上恒等于 0，作为实现自检）且 `T3 ≫ T2`。不满足说明 teacher 实现错了，
先修 teacher，不许继续。

## 3. 学生（两条臂，同容量，唯一差别是有没有转移算子）

- `FREE_ORDERED` = family `DIRECT_HORIZON_UPPER_BOUND` + 自由基（`free_basis=True`）
- `FREE_BAG` = family `ORDERLESS_BAG` + 自由基（`free_basis=True`）

两者同架构、同秩、同训练预算，`FREE_BAG` 只是把前缀状态换成对**累计集合**编码并且不建 `f_raw`。
**这正是 v0.2 复审 P0-2 指出的、当时不存在的那个对照**；Phase 0 顺带把它建起来，
v0.3 正式跑与真实数据都要用它。

参考臂：冻结 `U_FULL_SET` 无序基线（每 (患者, teacher) 一次确定性拟合）。

## 4. 主统计与闸门

逐 (teacher, 患者)：`effect = 留出目标(FREE_BAG) − 留出目标(FREE_ORDERED)`，正数=有序模型更准。
聚合按 v0.2 口径：seed → 患者 → 队列中位 + **同时重采样患者和重训**的区间。

| 闸门 | 判据 | 不过怎么办 |
|---|---|---|
| G1 假阳性 | `T1` 队列区间**跨零**（不得显著为正） | 实现有泄漏，停 |
| G2 检出力 | `T3` 队列区间**不跨零且为正** | **仪器对顺序无检出力** → v0.2 的顺序层零结果改判为 uninformative；v0.3 不按原样跑 |
| G3 真值一致 | 各 teacher 的 `effect` 与第 2 节真值 I 的秩相关 > 0 | 仪器读到的不是它该读的东西 |
| G4 逐患者可检出度 | 每位患者给出 detectability score | 低于阈值的患者在 v0.3 里标注，不得据其零结果下结论 |

**detectability score**（逐患者）= 该患者在 `T3` 上的 effect ÷ 该患者换种子重训的 effect 散布。
< 1 记为 `UNDETECTABLE`：这位患者的电极数与事件量支撑不起顺序检验。

**四个闸门的结论互不蕴含**，逐条报告，不得跨条外推。

## 5. 规模

28 位真实 SEEG 患者 × 4 teacher × 2 臂 × 3 seed = **672** 单元，外加 112 次基线拟合。
不做参数扫描、不做 null 家族——那些属于 v0.3 正式跑，不属于闸门。
