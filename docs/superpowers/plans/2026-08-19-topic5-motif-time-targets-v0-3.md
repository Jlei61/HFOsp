## 0. 为什么换问题

上一轮问的是「已知起点和已点亮集合后，先后顺序还有没有额外预测价值」。这个问题
**不能**回答「哪种动力学在起作用」——本项目自己造的单向传播过程就是反例：它有清楚的
方向性 motif，但给定累计集合后顺序增量**恰好为零**。所以顺序信息不是 motif 实验的前门。
（该轮已归档为方法学 pilot：`results/topic5_phase0_measurement_validity_v0_3/STATUS.md`。）

v0.1 自己的收口（§12 第 3 条）指出：那一轮所有模型用的「时间」只是**事件内序号**，
而数据里另存着一个**事件内时间代理**，整轮没用。已独立复核：控制名次差后，
触点间空间距离仍与时间差相关，**27/28 位患者同向**，中位偏相关 +0.125，符号检验 p=2.2e-7
（唯一反向：`yuquan_chengshuai`）。

⚠️ 该时间代理是**事件内谱质量中心位置**，不是临床招募时间，不是轴突传导延迟，
**不得**用它计算传导速度（v0.1 已锁定，本轮继承）。

**该目标到底加了什么（跑之前已核实）**：名次**就是**这个时间代理的排序——两种排法在
99.7–100% 的事件里一致，且 28 位患者**无一例**负增量。所以时间目标提供的是
**相邻两步的间隔幅度**，与「谁先谁后」按构造正交，模型不会被要求预测它已经看得见的顺序。
这也定死了参照的下限：序号恰好就是那份顺序信息。

## 1. 本轮**只**回答一个问题

> 相邻两步的时间间隔，能否区分均匀扩散、轴向走廊、方向输运、轴向前馈这四种传播规则？

**本轮不承诺**：未来 2–5 步的触点分布作为**目标**、late-field endpoint、完整 suffix field、
传播范围与事件长度。这些在早先那版 spec 里出现过，本轮**不做**，不得在结果里引用。
（触点分数**会**被计算并报告，但只是诊断量，见 §4。）

## 2. 比较哪几条臂

| 记号 | v0.1 模型 | 机制 | 新增参数（初值均为 0） |
|---|---|---|---|
| M0 | `DM0_ISOTROPIC` | 各向同性局部扩散 | — |
| M1 | `DM1_FREE_AXIS` | 患者轴向各向异性走廊 | `theta`, `eta_raw` |
| M2 | `DM2_LOCAL_DIRECTIONAL` | 由早期位移选方向的局部输运 | `beta` |
| M3 | `DM3_AXIS_FEEDFORWARD_TRANSIENT` | 轴向前馈的有限时程放大 | `gamma_raw` |
| Mfree | `FreeLowRankDrive` | **自由低秩上界** | 低秩 `U`,`V` |

**Mfree 是上界，不是同容量对照。** 它子类化 `MotifRNN`，保留完全相同的 leaky-**tanh** cell、
leak、input gain、node bias、contact readout 与观测算子，**只**把递归项换成 `U Vᵀ h`。
早先那版写了一个独立的**线性**递归，那会把「结构是否自由」和「动力学是否线性」混在一起。
不强行把参数个数匹配到个位——匹配会把那两个差异重新绑回去。

## 3. 时间读出与三个信息对等的基线

**读出**：两个标量，`Δτ̂ = offset − slope · h_t[j]`，损失是**标准化 log1p 增量上的均方误差**。
高斯方差被解析剖面掉而不是学出来：联合学方差在可用学习率下把方差推到下界后平方项爆掉
（实测 NLL 冲到 10.8），会污染本轮承重的分数。早先那版 spec 写的「三参数 + softplus +
learned variance」**作废**。

**基线（必须对等，这是本轮最关键的修正）**：motif 在**实际点亮的那个触点**上读它的场，
也就是被告知了目的地。只知道序号的基线会把「目的地有多远」带来的增益白送给 motif——
实测该项**单独**就值 0.2%–5.5% 的方差，与 motif 全部效应同量级。因此基线逐级加信息：

| 基线 | 知道什么 |
|---|---|
| `STEP_ONLY` | 事件走到第几步 |
| `STEP_DISTANCE` | 再加：到**真实**下一 rank-set 的质心距离 |
| `STATIC_TARGET` | 再加：那个触点是否惯常早到/晚到（训练集估计） |

三者都是闭式最小二乘，训练集求解、测试集评一次，不引入任何额外优化选择。

## 4. 训练与选择协议

- **训练目标只有时间。** 触点交叉熵**不进**损失，也**不参与**任何选择。这样整条链上不存在
  任意加权。触点分数在测试集上照常计算并报告，作为**目标之外**的诊断量。
- **副作用（已实测确认）**：时间目标不经过静态读出，所以 `StaticReadout` 收到**零梯度**、
  始终停在其零初值。它那两个自由 C×C 矩阵（`start_weight`、`recruited_weight`）本轮
  **完全惰性**，触点诊断实际上只反映算子本身。这解决了「禁止自由 C×C」那条约束。
- **真正的嵌套 warm-start**：M0 → M1 → M2 → M3，每层用 `load_warm_start` 继承**已拟合**的
  父模型，并把自己的新增参数置零。继承后**断言**父子前向逐位一致（阈值 1e-5），不通过则报错。
- **两种继承方式都进候选，由 validation 选**：`inherit_readout`（连时间读出一起继承，
  逐位复现父模型，这是「子不劣于父」的保证来源）与 `refit_readout`（只继承算子，读出重置）。
  只留前者会造成**协议不对称**——父模型的读出是从零拟合的，子模型的不是——而收敛后的读出
  几乎没有梯度：实测患者 1077 在只有前者时四层完全相同（各向异性恒为 0），
  加入后者后 M1 找到 0.0195、M2 找到 0.167 并把误差从 0.67986 降到 0.67077。
  两种模式**各有胜出且随患者与层次而变**（1077 的 M1 选重拟合、M2 选继承；1084 相反），
  所以两种都必须提供。
- **优化起点不是随机种子。** 本栈每个权重都确定性初始化，所以在轴角未变化前三个「种子」
  逐位相同。轴角三档（0, π/3, 2π/3）是**优化起点**：只在 validation 上选一个，
  test 只评一次；起点间散布单列为**盆地敏感性**，**不进**患者 bootstrap。
  M0 无轴，只跑一次；Mfree 三个随机起点同样由 validation 选一个。
- **统计单位是患者。**
- **STOP 不参与本轮任何拟合或选择**（本轮不评价传播范围/事件长度）。

## 5. 工程断言（实现检查，非科学闸门）

1. warm-start 后新增参数为零时，父子状态轨迹最大差 < 1e-5，否则报错；
2. test split 不参与起点选择（起点只看 validation）；
3. 时间增量出现负值**直接报错**，不再静默 `clamp(min=0)`；
4. M0 的 `chosen_theta_init` 记为空值，不记虚假角度；
5. 逐层记录**拟合后**的 `theta` / `eta_raw` / `beta` / `gamma_raw`——非负参数初值恰在边界 0，
   「各向同性确实最好」与「参数从没离开过 0」在分数上完全一样，只有拟合值能分开
   （已验证：患者 1084 的各向异性拟合到 2.32，证明参数能动）。

## 6. 规模

28 位 SEEG 患者 ×（1 个 M0 + 3 轴角 × 2 读出模式的 M1 + 2 个 M2 + 2 个 M3
+ 3 个 Mfree 起点）= **392** 训练单元。
不做参数扫描，不做 null 家族。

## 7. 判读纪律

三层阶梯，逐层报告，**不合成单一分数**：

1. `STEP_DISTANCE` vs `STEP_ONLY` — 相邻空间距离是否携带时间间隔信息；
2. `M0` vs 最强基线 — 递归局部场是否提供简单距离以外的信息；
3. `M1−M0`、`M2−M1`、`M3−M2` — 走廊、方向输运、轴向前馈是否各自再增加解释。

- 每条效应必须与**起点间散布**并列，低于它的不单独下结论。
- Mfree 明显优于全部四个 motif → 候选 motif 过窄，如实报告。
- 阳性、阴性、患者异质性**原样呈现**；某项阴性不停止后续比较。
