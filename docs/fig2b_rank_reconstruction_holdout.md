## 固定实验设计

使用当前 all-event 队列的26位患者。患者内按记录块奇偶两折交叉验证，整块只属于训练或测试；前半记录块训练、后半测试作为固定敏感性分析。每折保留原实验的两个训练模板：rank sequence 使用 masked normalized ranks；rank trajectory 额外使用三维方向视图与训练内方差尺度。模板为原参与通道 raw-rank 众数窗估计，不根据新评价目标重新优化。

冻结训练结果读取 `results/topic1/direction_distribution_holdout_20261022/per_subject/` 的 `folds.models`。这些模板已在前一轮核对复现当前 all-event 分析；本轮逐患者核对原始数据的通道、事件和块库存，记录输入哈希，并重新读取 raw ranks 与 participation。前一轮的方向损失、角度误差和方向 null 均不进入本轮 rank 误差。

## 主指标：normalized rank MAE

对于事件 e 的实际参与通道集合 S_e，将其 rank 重排为相对顺位 u_ec=(rank_ec−1)/(|S_e|−1)。每个训练模板也仅在同一 S_e 上重排，得到 v_kc；并列值使用平均顺位。误差定义为

`L_e = min_{k∈{A,B}} mean_{c∈S_e} |u_ec − v_kc|`。

0 表示顺序完全重建。误差0.1表示每个参与通道平均偏离序列跨度的10%。此为两个固定模板的留出重建误差；测试序列参与选择 A/B，但不更新模板或训练分组。不能称为未读取 rank 的预测。至少两个参与通道；若任何参与通道在任一方法的任一训练模板中缺失，则整条序列在两种方法中共同排除并报告，禁止悄悄缩小通道集。方向不可估计不会导致该 rank 检验自动排除。

先对每折事件误差求均值，再对两折等权，得到每位患者的一个误差。患者是统计单位，两种方法配对比较。主检验为双侧 Wilcoxon；报告患者中位数、患者内配对差的中位数及患者 bootstrap 95%区间。固定辅助读出为两折事件数加权 MAE、时间顺序留出 MAE、同一 MAE 最近模板的 MSE；不按显著性切换主指标。

## Null 与图示

每个留出事件内部随机置换 rank 与参与通道的对应关系，保持参与集合、rank 多重集、事件数与记录块不变；100次随机化，两种模型共享每次随机化序列。每次随机化仍从各自两个冻结模板中重新选取最小误差，避免真实数据享有挑选模板而 null 没有的优势。该 null 检验通道特异的顺序结构，不单独检验空间信息的独立因果作用。增加空间信息是否改善重建，由两种真实模型的患者配对差决定。

每位患者对100次 null 误差取均值再比较；不能把随机化次数或事件数当作临床样本量。图底部显示患者重抽样的队列中位数分布；两个方法各有配对的 null，灰色虚/实线区分。图中三个计划比较（sequence vs trajectory、sequence vs 自身 null、trajectory vs 自身 null）统一作 Holm 校正后标记：* <0.05，** <0.01，*** <0.001，否则 n.s.；原始及校正 P 值存入结果表。

玫瑰图只作方向结构示意：E10/E14 第一折留出方向直方图，叠加训练模板的直线（TA/TB 颜色、sequence 虚线、trajectory 实线）。它不是 rank 重建误差的计算空间。

## NLL 的适用边界

NLL 可以评价明确的 rank 概率模型，例如对排列使用 Mallows 混合模型；需要定义排列概率及归一化项，并只用训练数据估计离散度和权重。当前两个点模板并不直接定义 rank 似然，把 MAE 或方向密度重新命名为 NLL 不成立。本轮使用可解释的 rank MAE，不额外改变模型族。参考：[Gneiting & Raftery, 2007](https://doi.org/10.1198/016214506000001437)；[Vitelli et al., 2018](https://jmlr.org/papers/v18/15-481.html)。
