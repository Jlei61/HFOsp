## 同一模型、两个目标

26位患者，沿用 all-event masked rank sequence 与 rank+3D direction trajectory 两种训练方法，各产生两个模板。原奇偶记录块两折及前半块训练／后半块测试沿用冻结训练模板。另增加三个固定随机种子（0、1、2）的50%记录块留出；每位患者随机化整块，不按事件拆分，每次重新训练两种模型，训练内完成尺度估计及模板发现。

rank 主指标保留参与通道上归一化 rank MAE；方向主指标为同一事件与对应训练模板三维梯度轴之间的平均夹角（度）。**两张主图共用按归一化 rank MAE 选择最近模板的规则**，方向不参与测试事件模板选择，避免不同分配规则混淆目标比较。测试 rank 参与模板分配，因此两者都是留出表示／重建读出，不是未知事件的事前预测。方向来自同一事件的 rank 加电极坐标拟合，并非独立测量的传播真值。

每事件 MAE = min_k mean_c |r_ec−t_kc|；r和t仅在真实参与通道上重排至0–1。方向误差 = acos(d_e · a_k)，其中k仅由rank确定。每患者先对每折事件平均，再对两个互补折等权。患者为统计单位。rank任务全部支持的参与序列纳入；方向任务在相同序列中进一步要求方向可估计，两种方法共享分母。

## 固定的误差检查与留出范围

rank另检查：

- RMSE：每个模板的通道平方误差均值开根号，再选择RMSE最小模板，最后对事件平均；区别于上一轮在MAE分配下计算MSE。
- 通道对先后错误率：只对事件中有明确先后关系的参与通道对计分，反序记1，同序记0，模板并列记0.5；选择两个模板中错误率最低者。它直接测“哪些通道先后关系错了”。

方向另检查余弦损失 `1−d·a`，仍用主分析的rank分配。MAE、RMSE、pair-order error、angular MAE、cosine loss共5项；比较两折合并、各单折、时间前后留出、三个随机块留出共7个读出，完整报告35项检验并统一Holm校正。合并两折与单折并非独立重复，不以任一个显著格子代替队列主结果。

## Null 与显著性

rank null复用上一轮已验证的100次事件内rank-channel置换，两种方法每次共享置换并重新选择最近模板。方向null保持每个记录块内的真实方向分布，随机打乱方向与rank指定模板之间的配对；100次置换，两种方法共享配对随机化，模板和rank分配不重拟合。该null检查事件方向与模板身份的对应关系，不是新增空间信息的训练消融；空间信息的直接比较仍为两种真实模型的配对差。

两张主图各显示真实方法比较和两种方法各自vs null，共6项双侧患者Wilcoxon，统一Holm后用星号表示；原始P、校正P、患者配对差及bootstrap区间均保存。方向null不使用人为均匀方向，避免患者固有方向偏好构成过弱对照。

## 阴性结果解释检查

量化两个模型模板顺序的差异、模板排序完全相同的事件比例、事件重建误差完全相同的比例及模板轴转动。用训练模板排序对齐标签后，另算“只换轴”和“只换rank分配”的方向读出，区分几何轴与分配变化的贡献；它们是描述性拆解，不增设挑选显著结果的主检验。
