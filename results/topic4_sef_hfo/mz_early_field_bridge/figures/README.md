# MZ early-field bridge — 图说明

这两张图回答同一个问题：同一块 E1146 模型底物，安静自发（slow-off）时间期样事件里 15 个虚拟电极点亮的**先后顺序**——这是一条**双向病理轴**（A→B 和 B→A 都合法，从哪一端起始由噪声/瞬时网络状态决定，不作为成功判据）——能不能预测只开 `z`（抑制效力消耗）后底物滑向失控放电时、**跨过失控阈值 t120 之前**那段早期招募窗（相对 t_recruit 的 0–50 ms）的能量分布。失控 = operational runaway，是模型代理，**不是临床发作**；能量是 virtual-LFP 30–80 Hz 包络能量代理，不是临床宽带功率。主统计量 = **方向无关的 maxAB**（两个方向取更强的一个，置换 null 里每次重新取大）。

### mz_early_field_bridge_seed1.png
单 seed 诊断图。上两条是**分别标注**的两段轨迹：slow-off（间期模板来源，浅蓝阴影 = 预先规定的**第一个留出事件**，仅作展示示例）与 z-only 操作性失控（红虚线 = t120 起始，粉带 = t_recruit 后 0–50 ms 早期招募窗），绝不把 slow-off 事件阴影画到失控轨迹上。下两格是同一虚拟 SEEG 平面上的对照场：左 = 间期时序模板（此图展示方向 TB，标注为**双向轴的一个方向、非固定表型**；viridis 紫=早），右 = **pre-t120 早期招募能量**（Blues，深=高）；灰箭头标 source→sink 轴（轴本身是双向的）。

**关注点**：左右两格是否在同一端「早=热」地对上（此 seed 是高轴/sink 端最早、也最热），即间期指纹是否预测了早期招募能量；标题里的 mirror-inv maxAB 是这个对齐的方向无关强度。哪一端起始不是重点、也不是成功标准。

### mz_early_field_bridge_multiseed.png
三 seed（1/3/4）诊断网格，分母 = **一块 E1146 底物 × 三个随机种子，不是三个患者**。五面板各答一问：Q1 模板在**留出事件**上是否可复现（held-out Spearman；圆=A→B、三角=B→A）；Q2 每个 seed 同时画两个方向的关联（灰圈 = rho_A / rho_B）+ 方向无关 maxAB（彩色星）+ 同杆内置换 null 的 p95（黑线）——**seed3 的星正落在自己的 null 线上，是弱/与随机重叠**，seed1/4 的星明显高过；Q3 电极与源空间的**轴被调用强度**（方向无关的 maxAB 幅度，源空间只作补充诊断，**不写「方向一致」**）；Q5 能量场支撑数与动态范围（无柱=退化场）；Q6 逐 seed 的 onset / 模板 / maxAB 资格 + within-shaft p（弱 / 未跑 / 不合格显式标 MISSING）。标题只报中位数 / 范围 / 同号计数，**不做 n=3 的 cohort p 值**，也不把某个固定方向当成稳定表型。

**关注点**：Q1 模板是否可复现、Q2 彩色星是否高过黑线（seed3 只是弱阳性 / 与随机重叠，要如实看）、Q3 电极×源的轴调用强度是否都为正（这是幅度、不是方向一致）、Q6 表里 within-p 逐 seed（两强一弱）；任何弱、反号、退化、MISSING 都据实显示。方向由噪声决定，不作为成功标准，也不把某一端当固定发作灶。
