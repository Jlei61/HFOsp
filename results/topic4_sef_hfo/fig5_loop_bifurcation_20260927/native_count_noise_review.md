# 同OU、仅计数噪声改变：退出时序与空间对应分开判断

两条预先冻结的原生10–20秒续演均已完成。除外部Poisson计数抽样流928701/928702外，初始全部细胞/慢状态/时延环、空间图、参数和全局/空间OU路径保持。每条100条输入记录、终点全局xi/RNG和完整空间OU状态/cache/RNG/时钟均逐位相同，100000次新计数抽样完整；原始RNG继续消耗原计数以维持OU配对，另存新计数RNG状态。没有重新设定Z、K、反馈参数或静默计时器。

决定性结果是：两条原生均在13.748/13.744秒首次连续100毫秒R<=5，随后约17秒重新活动；原参考则16.868秒才持续低活动。两个分布数值流为13.750/13.764秒。由此支持该次低谷对有限脉冲抽样敏感；不能用与单条原参考相差约3秒就断言耦合模型系统失效。这也不能用2条新结果估准早退概率，或自动宣称候选整体通过。

空间证据仍不充分。18–20秒，两条新原生均率约211/212Hz、两核约190–232Hz，候选全E约168/180Hz、两核约116–123Hz；候选偏重右上方，原生招募更广。该窗两个新原生的平均场加权RMS差约50Hz；候选与这两条原生逐对约79–123Hz，两个数值流之间约30Hz。它们是所观测路径间描述性差值，不是2个样本估出的容差或置信区间，不据此反向放宽预定门槛。

这一段再活动是持续群体活动，不是充分恢复后的间期短事件返回。新原生20秒Z仍约0.41–0.42，候选约0.44；观察到退出和局部Z上升不能替代原目标的完整闭环验收。此前单条比较保留，其正式含义更新为“候选在参考轨迹中存在路径偏差，计数试验解释了部分时序差异；自主空间对应仍未认证”。
