# 实际退出场对应检查：目前不接受正式延拓

原始问题是高活动何时结束，以及结束后 Z 是否能净恢复。仅复现高活动/静默标签不够，空间活动和恢复方向也必须对应。此次用原生16.7秒的完整Z/K场形状，固定均值Z=.21，K=9或12，各从高态和恢复态完整历史开始。膜、突触、M、R、G及递归活动自主演化；只是Z/K被固定，不是自主闭环。

四条候选10秒全部完成，原生比较前10秒，另保留原生末20–30秒而不混作相同时窗。K=9高态的全E均率由原生242.59降为216.64Hz，核外由231.21降为203.56Hz；两核反而略高。K=9恢复史、K=12两史均静默。新图已实际打开检查，候选高态活动带收窄清楚可见，人工仍待审阅。

这个误差会改变机制：原生K9高态的G全程高于阻断Z恢复所需的2.6694，5–10秒全E自然漂移为−.042/s。候选10秒端点G约1.731，约34.1% E粒子满足恢复资格，全E自然漂移为+.0263/s。两者是不同时间统计，已明确标注；候选端点不是五秒平均。两核在两模型中仍消耗，错误发生在核外。负的高斯抑制电流仅约3.9%，不足以单独解释34.1%的恢复资格，不能未经检验就钳制负电流来调好结果。

为了定位而非继续调参，新增一条原样42–44秒原生观察，从K9高態42秒完整状态继续，Z/K不变。完整初态逐位相同，20,000条每步记录以及E/I计数汇总全部通过；没有44秒既存参考，因此不宣称终点重放逐位一致。随后完成两种群电流均值输入×两条数值流的4项局部检验。原生上游放电、外源与R/G都提供给候选，不能当自主网络验证。

局部区域均值接近不能验收：核外整体420.84Hz对419.11Hz、核472.40对472.39，但边缘群531原生55.54Hz，候选0Hz；即便群平均电流换成实测也为0。选中的大多数E群接近不应期上限，平均能掩盖少数传播边缘的失败。I群也有约2–2.5%均值偏低。下一项有界检验保留同一210细胞的实际入度/权重差异，用原图逐目标细胞投影，比较群平均、保留个体均值、保留个体均值和方差；不增加原生轨迹或拟合参数。
