# 群平均输入抹掉了传播边缘的细胞差异

要解释自主终止与Z恢复，必须保留维持高态活动范围的机制。四条实际退出场候选虽复现高/静默类别，K9高态的空间活动带和G都偏小，甚至把全E的Z漂移从消耗预测为恢复。不能在这套候选上直接命名分岔。

新的局部检验已明确一个误差来源。固定原来的210个几何抽样细胞、原生42–44秒上游群放电、R/G、Z/K及外源，使用原始连接的每条物理权重和时延重建各目标细胞的入度与权重分布；不拟合任何参数。原群平均均值/方差、保留个体输入均值但仍用群方差、保留个体输入均值与方差，三种方式各两条数值流，共6项全部完成。

关键边缘群531含13个E细胞，原生末1.5秒均率55.54Hz。群平均输入为0，个体均值为55.75–55.77，个体均值与方差为55.36–55.39。群平均和个体均值两种方式的群电流均值误差相同，说明恢复不是把平均兴奋输入整体抬高。原生E/I电流的群内SD为121.93/103.75 mV-equiv，群平均近似仅16.56/14.85，保留个体均值后为121.41/102.08。也就是说，稳定存在的细胞间输入差异被错当作可平均掉的部分；电压阈值使平均输入的放电不等于不同细胞放电的平均。

该检验不支持所有局部响应已通过。其余接近不应期上限的E群有小偏差，选中I群仍低约2–3%；两个数值流不是独立原生网络。边缘群是从前一检验中发现的问题，因此这是开发诊断，后续自由耦合才检验它是否解释空间/G/Z偏差。
