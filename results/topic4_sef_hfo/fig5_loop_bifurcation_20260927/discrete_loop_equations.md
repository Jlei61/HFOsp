# 原生离散方程：条件图怎样与自主闭环相连

下表使用原生0.1毫秒更新，不把统计窗口当作物理步。图中K是当时的钾样电导/gL，与每spike增量参数或k100旋钮区分。

|符号|维度/单位|定义或运算|
|---|---|---|
|n，dt|步，0.1 ms|原生更新顺序中的物理时间|
|S_i,n|0或1|该步实际放电，不是事后分期标签|
|p_C,n|无量纲|固定群C内S的平均；C可为全部E或某一核心E|
|R_n|Hz|原生15 ms因果率状态；与有限窗计数率分别报告|
|q_n|无量纲|clip((R_n−200)/300,0,1)|
|G_n|g/gL|未乘Z的全局分流；其对E的应用值是Z_i,n G_n|
|K_i,n|g/gL|不再乘Z的钾样电导|
|h_i,n|0或1|原始I_I,i,n+(18−E_G)G_n小于95.198513 mV时为1|
|Z_i,n，M_i,n|无量纲|原资源状态；每spike加1的原M计数状态|

## 精确收支与条件化

令a_R=exp(−dt/15 ms)、a_G=exp(−dt/500 ms)。原实现给出

    R_(n+1) = a_R R_n + (1000/15) p_E,n
    G_(n+1) = a_G G_n + 30(1−a_G) q_n
    Kbar_(n+1) = exp(−dt/tau_K(R_n)) Kbar_n + 0.16 q_n p_E,n
    Zbar_C,(n+1) = Zbar_C,n + (dt/5000 ms)(hbar_C,n−Zbar_C,n)
    Mbar_C,(n+1) = (1−dt/1000 ms) Mbar_C,n + p_C,n

其中tau_K=500 ms当R_n>5Hz，否则5000 ms。q和时间常数依据步前R；外源Poisson、膜/突触及不应期产生该步spike，再按原顺序更新慢变量。Z资格h中的局部I_I是乘Z之前的原始负荷。hbar是逐细胞指标的平均，不能替换为“平均负荷小于阈值”的单一指标。

E细胞的瞬时膜稳态与有效时间常数分别是

    Vinf_i = [I_E,i − Z_i I_I,i − 0.0005 M_i
              + Z_i G E_G + K_i E_K] / [1+Z_i G+K_i]
    tau_eff_i = tau_m,i / [1+Z_i G+K_i]

E_G=−17.6628479383mV，E_K=−30mV。每步对本步突触输入使用该电导形式，并执行阈值/复位/不应期规则。上述Vinf是当前步的膜更新量，不是已认证的全网络平衡电位。原生R=1共同外源计数检验已核对这一整条更新。

原生R的脉冲归一化有一个明确的离散修正：若平均放电率为常数r，R的均值是r·dt/[15ms(1−a_R)]，因子约1.00334。因此因果R与长窗原始计数率略有差别是既有实现约定，不能用两个观察器之间的差异判断网络失稳。

## 为什么条件高态不等于全系统平衡

当前新图固定完整空间Z/K场，保留膜、突触、不应期、M和G动态。它回答“在这个资源与电导条件下，活动能否维持、历史是否改变响应、核心Z若释放会向哪走”。它不声称Z/K两个均值是整个网络的自治状态。

例如K=9.425附近，条件高态的R小于200，q=0；如果解除K钳制，K会以0.5秒消退，瞬时连续式收支约为−18.85每秒。这样的K>0、q=0条件态不可能同时成为未钳制原系统的平衡。静默支中R<5，K也不是不动，而是以5秒消退。条件图是响应几何；全系统沿什么路径移动由上列K/Z/G收支决定。

更关键的是，自然高活动段K与G的时间常数同为0.5秒，M为1秒。不能把G/M已经充分平衡当作自然K变化时自动满足的前提。实际退出的G尾迹干预与完整携带状态检验，正是补充这一联系，不能用一条冻结场临界线取代它们。

## 终止后的恢复为什么有次序

若原始局部I_I非负，G>=95.198513/(18−E_G)=2.669403时，所有E细胞h=0，Z继续消耗。G下降越过此上限只是必要条件；剩余局部I_I还可以暂时阻断部分核心细胞恢复。充分的群体净恢复条件始终是hbar_C>Zbar_C。

在已经核验的自主片段中，R于16.868秒进入低率，G于17.551秒越过全局阻断上限，17.58秒起两核消耗预算为零，23.90秒两核达到原间期参考，49.31秒出现首次返回短事件。达到参考之后继续恢复的余量，不能用首次跨线代替。

整段16.868–49.31秒的采样间R严格上界仍小于5，因此K确实一直按5秒指数消退；全段K记录逐点符合该式。32.442秒不是手动静默计时。用5 ln(K起始/K返回)还原这段时间时，K返回是事后观测值，不是预先写入模型的释放阈值，也不能单独预测其他噪声下的返回时刻。

两核在17.58秒之后遵循原离散恢复式Z_(n+j)=1−(1−Z_n)(1−dt/5000)^j，直到返回前误差小于4e−13。全E均值恢复、核心恢复、达到间期参考和持续核心主导短事件返回，仍是四种不同的证据。
