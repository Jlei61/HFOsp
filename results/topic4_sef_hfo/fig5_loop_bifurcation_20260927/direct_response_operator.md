## 符号与零频自洽关系

|符号|定义|单位|
|---|---|---|
|r_a|源群a的平均放电率|Hz|
|rho_i|目标细胞i的平均放电率|Hz|
|S|按原群成员数平均目标率的矩阵，r=S rho|无量纲|
|W_A/W_I|原图目标到源群的权重和，保留每个目标差异|原电压权重单位|
|Q_A/Q_I|先逐边平方再向源群求和的权重|原平方权重单位|
|a_A/a_I|dt/[tau_r(1-exp(-dt/tau_r))]|无量纲|
|h_i|1+Z_i G+K_i|相对漏电导|
|chi_mu/chi_vA/chi_vI|直接细胞率对有效均值/两类噪声强度的响应|Hz/mV或Hz/(mV²)|
|chi_g|原始电流保持不变，新增反转电位E_G的分流响应|Hz/(g/gL)|

这里r使用Hz，输入算子乘r时必须除以1000；tau_m及dt仍使用ms。固定空间Z/K场族，令G根据全部E率自洽，局部M按自身率自洽。M稳态为 tau_M(s)*rho_i；当前tau_M=1秒。其局部隐式修正因子为

    D_i = 1 + eta_M*tau_M(s)*chi_mu,i / h_i.

对源群r_a的直接导数，在E率处于q的线性段时为

    d rho_i / d r_a = [
      chi_mu,i * tau_m,i*a_A/(1000*h_i) * W_A[i,a]
      - chi_mu,i * Z_i*tau_m,i*a_I/(1000*h_i) * W_I[i,a]
      + chi_vA,i * tau_m,i*a_A²/(1000*h_i²) * Q_A[i,a]
      + chi_vI,i * tau_m,i*Z_i²*a_I²/(1000*h_i²) * Q_I[i,a]
      + E_i*Z_i*chi_g,i * 0.1*b_R*w_a
    ] / D_i.

w_a是该源群占32000个E细胞的比例，I群为0；b_R=dt/[15*(1-exp(-dt/15))]是原因果率滤波的精确离散DC因子。q关闭或饱和的工作分段，G项的导数需相应为0；折点本身不能套光滑公式。最终静态自洽Jacobian为 S*(d rho/d r)-I。

chi_g已经包含G引起的电流均值和现有电流噪声重缩放，不能再次加这些项。K改变同一膜电导但反转电位为E_K，因此固定原始输入下，零频K导数为

    chi_K,i = chi_g,i + chi_mu,i*(E_K-E_G)/h_i.

沿既定K空间形状的参数导数还要乘每个目标的形状系数并除以D_i。该关系来自同一个膜方程，不是新的疲劳机制。局部响应不确定性须以保存的共同随机数和重复块传播到矩阵作用；不可估计的组件不置零。

## 动态稳定性还需要什么

静态Jacobian只回答零频自洽，不能用其特征值直接冒充原延迟系统的稳定性。后续特征方程必须保留原图的每条时延、AMPA/GABA均值滤波、局部M及全局R/G的更新顺序。局部噪声强度的直接频率响应已包含噪声创新经过突触滤波的过程，不能再重复乘均值滤波器。

写z=exp(lambda*dt)，原离散G反馈由r到G的传递为

    H_RG(z) = 0.1*(1-a_G)*(dt/15) / [(z-a_G)*(z-a_R)],
    a_G=exp(-dt/500), a_R=exp(-dt/15).

这两个延迟因子来自当前spike影响后续R、后续G的原更新顺序；z=1时恢复0.1*b_R。M的传递为 (dt/1000)/(z-a_M)，a_M=1-dt/1000。K在高活动时与G同为0.5秒，不能因为作了条件K切片，就宣称自然K变化是准静态慢参数。

以z=exp(i*2*pi*f*0.0001)表示原0.1ms离散步，定义r[n]为当前步产生的Hz放电率。原边延迟读取r[n-d]，所以每条边保留z^(-d)。局部均值电流的归一化突触传递为

\[
H_{\rm syn}(z)=\frac{(1-a_r)(1-a_d)}{(1-a_r/z)(1-a_d/z)}.
\]

R和G均由膜更新前的状态参与反馈，故

\[
H_{RG}(z)=\frac{0.1(1-a_G)(0.1/15)}{(z-a_G)(z-a_R)},\qquad
H_M(z)=\frac{0.1/1000}{z-a_M}.
\]

a_R=exp(-0.1/15)，a_G=exp(-0.1/500)，a_M=1-0.1/1000。前式仅适用于当前R位于200–500Hz的q线性段；其他分段必须重新取导数。局部M按其均值反馈消元，分母为D_i(z)=1+eta_M*E_i*chi_mu_i(z)*H_M(z)/(1+g_i)。这是局部M均值响应近似，未证明逐粒子M波动完全可忽略。

均值通道乘H_syn及原延迟算子；噪声强度通道只乘原延迟平方权重算子，因为直接方差响应已经含噪声创新通过突触滤波的过程，不能重复滤波。G项使用真正的physical-applied-G响应乘Z和H_RG；该响应已经包含原有随机电流的瞬时重缩放，不重复加链式项。所有源率进入权重矩阵时均由Hz除1000。
