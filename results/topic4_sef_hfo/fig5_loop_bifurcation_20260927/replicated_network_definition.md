# 递归平均模型的明确对象与分岔解释边界

目的不是给原生SNN另拟一个转移函数，而是先定义一个保留原图、逐细胞参数、延迟和局部状态更新的可检验模型族。以下定义直接来自当前实现。R=1共同外源计数核验已完成：100毫秒、40000细胞的1000步spike全同，不应期全同，完整末状态最大误差1.4e-11，R/G全同（mean_single_replica_identity_v2/result.json）。这支持该已测条件下的原生端点，但不是全参数解析等价证明。

|符号|含义与单位|运算|
|---|---|---|
|i,j|原40000个物理细胞的编号|原图源/目标身份不合并|
|r=1,…,R|每个原细胞的数值复制|不是R个独立原生网络或生物样本|
|S[j,r,n]|第n个0.1ms步的0/1放电|复制间取平均，得到barS[j,n]|
|w[i,j,d]|原图延迟d步后到达的突触rise变量增量|含原生目标tau_m/tau_r单位换算|
|A[i,n]|当前步递归突触rise增量|sum(j,d) w[i,j,d] barS[j,n-d]|
|C[i,r,n]|独立Poisson(nu[i] dt)外源计数|乘原外源rise增量，保留离散计数规律|
|X[i,r,n]|V、ref、突触rise/current及M等局部状态|执行原局部物理时间更新|
|Z[i],K[i]|这一条件系统中固定的完整空间场|场族和均值坐标必须同时注明|
|R_E[n],G[n]|原因果率滤波和全局分流状态|由全部E复制的均值放电驱动，保持自由动态|

有限R时，每条原边可解释为源细胞的R个复制到目标R个复制的全连接，每条边权重w/R、延迟不变。因此每个目标复制收到相同的递归平均脉冲，但不同的外源计数；它们各自保留膜、不应期、M和突触历史。R=1时barS退化为实际0/1放电，代数上应恢复原图脉冲输入。仍需共享外源计数的全网络检验，因为更新顺序、延迟索引、排队初态或单位错误会破坏这个结论。

这说明“没有另外加递归残余噪声”不等于有限R网络没有递归波动：barS仍由有限复制的随机活动产生。它省去的是另外独立采样的Gaussian残余。原来把相同一步源方差白化再叠加的做法，会同时遗漏时间相关，而且当前审计显示经过突触滤波后的方差严重偏大。不能把这次成功推广为所有条件下都可忽略原生有限规模波动。

若研究R增大后的分布动力学，候选数学对象是每个原细胞局部状态分布的非线性概率转移映射：X按原更新T推进，外源按已知Poisson律积分，递归输入用各源分布预测的放电概率和原延迟生成。G保留自己的动态。这里仅定义待逼近对象；不把64复制的随机轨迹宣布成确定性分布极限、平衡点或周期解，也不预设其振荡周期。

## 与Figure5问题的联系

先检验退出附近同一Z/K场下的高态、不对称态和恢复态是否对应原生，以及哪一处失去持续活动。它们决定有没有相关的条件高态分支值得延拓。随后才选择适合该分布动态的固定点/周期求解与线性稳定性方法，并检查数值复制或分布离散误差。

真正自然退出仍要另核对：G和K在高活动段均约0.5秒，不能先假设K相对G准静态；自然轨迹可因G尾迹或噪声跨越吸引域而退出。即使找到冻结场的fold，也不能自动等同于自主轨迹的退出原因。

Z恢复则有原生精确收支：核均值dZ/dt=(核恢复资格比例−核均值Z)/5秒。资格由原始局部抑制和未被Z乘过的全局负荷共同决定；K直接不进入这个资格判据。G先参与压低放电，再需消退到允许恢复的范围。平均全E的Z恢复不能替代两个核心的恢复。进入前后是否有可重复的核主导短事件，还须在真实raster、空间时序和持续窗口内独立验收。
