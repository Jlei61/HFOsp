# Figure5闭环：现有机制解释与分岔缺口

目标始终是同一个空间SNN在没有定时干预的情况下，保留原有核心主导间期群体事件，进入高活动，随后自主终止，并在两个核心恢复足够资源后重现间期传播。一次降到低率、平均Z上升、一次短事件回来，分别只能回答其中一段。

|量|含义及单位|当前方程中的作用|
|---|---|---|
|Z_i|无量纲局部资源，0至1|乘在局部抑制和作用于E的全局分流上|
|M_i|逐spike加1、以1秒衰减的计数状态|原适应电流eta_M M，eta_M=0.0005 mV；与新增K区分|
|K_i|新增钾样电导/gL|反转电位−30mV；不再乘Z|
|G|原始全局分流电导/gL|实际E细胞所受分流为Z_i G；反转电位−17.66285mV|
|R|全E群体放电的15毫秒因果滤波，Hz|驱动高率门q及K消退分段|
|h_i|当前是否具备资源恢复资格，0或1|决定恢复与消耗的收支|

## 从公式到闭环

将时间统一为秒，E细胞的膜方程可写为

    tau_m dV_i/dt = -V_i + I_E,i - Z_i I_I,i - eta_M M_i
                     - Z_i G (V_i-E_G) - K_i (V_i-E_K).

因此负反馈同时改变膜稳态电位和有效膜时间常数，不能只按电流常数相减。膜稳态分母为1+Z_i G+K_i；原生实现、同计数R=1实现核验均保留这一点。

高率反馈为

    q = clip((R-200)/300, 0, 1)
    0.5 s * dG/dt = 30 q - G
    每个E细胞spike: K_i增加0.16 q
    spike之间: dK_i/dt = -K_i/tau_K(R)
    tau_K = 0.5 s 当 R>5 Hz；tau_K = 5 s 当 R<=5 Hz。

这解释了为什么当前新增机制能保留第一次进入前的原工作区：正常间期群体事件未把全E的因果率推过高率门时，新增反馈不会积累。原生前缀核验显示第一次新增K出现在9.874秒，属于分类onset前的高率加速阶段；不能把分类进入时刻和连续反馈开始时刻混为一谈。

资源方程为

    h_i = 1{ I_I,i + (18-E_G)G < 95.19851 mV }
    5 s * dZ_i/dt = h_i - Z_i。

这里I_I是乘Z之前的原始局部抑制，18mV是资源负荷判据使用的参考电压。K不直接进入h的定义。对任一固定核心取平均，净恢复的必要充分条件就是“该核心恢复资格比例 > 该核心平均Z”。全E平均达到这一条件，不能代替两个核心都达到。

间期事件反复产生抑制负荷，可以使Z逐渐下降；Z下降又减弱已作用于E的局部抑制和全局分流，为兴奋活动进一步扩展提供正反馈。高率后q才招募G/K。K不随Z变弱，在Z较低时仍能抑制活动；G的已有尾迹也参与压低活动。资源恢复还需原始抑制负荷真正下降，不能只看应用后抑制Z I_I变小。

尤其是G：只要G>=95.19851/(18-E_G)=2.669403，且原始局部I_I非负，所有E细胞都失去恢复资格。G既可帮助终止高活动，又可在其仍很大时阻止Z恢复。它需要先压低活动，再继续消退。若q保持0，G以0.5秒指数衰减；这是可直接与原生记录核对的预测。

## 已有原生证据支持到哪里

同一个真实16.8秒状态的配对记录中，原轨迹先在16.868秒进入持续低率，17.551秒G降到上述必要上限以下，两个核心随后出现持续净恢复，23.90秒达到原间期参考。它们是不同的物理时刻。一次去掉已有G尾迹，第一次下降最低仍约9.18Hz，严格采样间下界也高于5Hz；没有及时进入K的慢消退段，随后反弹。G重新产生后仍可再次退出，不能把一次移除说成永久阻止退出。

把低率K衰减也改为0.5秒，最初低率转换不变，却在核心Z尚低时再次招募高率反馈。后来核心仍能恢复到参考，反证了“5秒K保留是Z恢复的必要条件”。完整56.8秒续演还有13个短事件，但仅持续2.97秒就再次进入；有的活动先出现在核外再招募核心。因此它通过“可恢复并产生短事件”的部分检验，未通过原定持续间期返回标准。

原式首次短事件返回前两个核心Z约0.999；恒定tau对照返回前约0.79，随后再进入前已降至约0.70/0.69。这支持区分“达到参考线”和“积累恢复余量”。K/G/M及事件时刻的外源也不同，尚不能把返回持续时间差完全归因于Z余量一个变量。

低活动持续约30秒不是手动插入的静默窗口。上述R依赖的衰减规则始终在模型内执行，K从退出时的较大值逐渐降到允许活动重现的范围，持续时间随状态和输入而变。用于报告的R<=5持续100毫秒是诊断读出；物理方程按每0.1毫秒步前R切换，没有检测到低活动后启动30秒计时器。

对原轨迹16.868至49.31秒的完整低活动尾部，进一步只读核验得到：采样间因果率严格上界仍低于5Hz，K由11.094降至首次返回时的0.01687，全段逐点满足K(t)=K0 exp(−t/5秒)，32.442秒的实际持续时间与5 ln(K0/K返回)一致。这是原式自由衰减的结果。K返回值是事后读数，不是模型内设定的释放门或跨噪声通用临界值。

从同一状态出发，G解析预测在17.550秒越过恢复阻断上限，记录为17.551秒。但17.56秒后的第一个预算里CoreA仍有极少局部负荷，所以“解除全局阻断”不等于立即全部具备恢复资格。17.58秒起，两核心的消耗预算均为零，随后直到返回前的完整Z曲线与原离散最大恢复式相符，误差小于4e-13。由此达到两核原参考至少还需约6.31秒；实际在23.90秒达到，之后继续积累资源余量。这把终止、恢复阻断解除、参考恢复和事件返回连接成了可由方程核对的时序。见autonomous_quiet_duration_review/result.json。


原生离散资源方程还给出无需降阶的严格上界：在恢复资格始终为1这一最快情况下，Z_n <= 1-(1-Z_0)(1-dt/5s)^n。已有15个退出片段嵌套于3个种子；其中5个再次进入前的时间连这个最快界都不够，8个完成充分恢复和间期返回，2个Z已恢复但返回判据仍截尾。这不能算15个独立重复，也不能把参考Z值称为已认证分岔阈值。

## 分岔图应增加什么

最有信息的对象仍是固定真实空间Z/K场族、保留G/M动态的条件系统：同一Z/K坐标是否可容纳不同活动状态，高态在K增强时何处无法维持，核心资源收支在那里是否转正。它能把“允许高态”“允许恢复”两种区域联系起来。Z/K是这一条件系统的参数坐标，不意味着整个网络仅有两个动态状态。

两个十秒原生历史已由新的自由递归平均模型复现：高态全E约197Hz，不对称态约99Hz，空间招募不同，而Z/K场和外源规律完全相同。它们两核仍是净消耗。该结果保留有限时间历史依赖，尚不认证两个稳定吸引子。R=1共同外源计数核验支持明确的原生端点；64复制仍不是确定性分布极限的证明。

K9.5的十秒原生/候选模型配对已完成：两者分别在2.016和2.031秒开始持续低率，后五秒共同静默，两核若释放Z的收支转为正。复制数64增至256时退出起点不变，100毫秒空间场最大RMS差0.439Hz。这支持相关退出条件的物理对应，不认证稳定性。空间分解还显示，高率区域面积先明显收缩，区域内群体在大部分收缩期仍维持高率；不能把整体降频误认为空间均匀压低。三个K内部点及一次静默史返回低K均已完成：高活动持续至9.4625，而静默史退到9.35后仍静默。同一82秒起态的原生9.4625/9.5及模型9.5核对也已完成并全部通过：原生9.4625保持两核高活动，9.5在2.057秒进入持续低率，模型为2.030秒；静默后两核收支一起转正。因此9.4625–9.5已是这一完整起态和十秒协议下原生/模型共同支持的有限转换区间。当前只做共同K9.425的四条五秒物理历史返回检验，区分相邻高态能否回到同一空间模式及静默史能否保持不同；点间不画未经计算的不稳定支，不先命名fold。自然轨迹的G和活跃期K均约0.5秒，还需检查携带状态和穿越速度，不能把冻结场阈值自动等同于每次自主退出时刻。

病理连接轴在目前证据中组织的是空间招募和传播路径：相同几何下的不同状态仍沿原结构出现不同活动范围。已有轴变更对照没有完全匹配入度/权重等量，不能把它们作为“轴单独导致闭环”的因果证明。闭环的时间机制与传播的空间组织应在Figure5中相互关联，但各自的证据强度保持独立。
