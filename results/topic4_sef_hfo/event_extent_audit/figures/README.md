# event_extent_audit 图说明

Task 0（M2 数据侧 audit）：真实间期 HFO 群事件在"病灶传播轴"上到底铺多长、垂直方向多窄，
用来判断 M2 模型该不该把"轴向收住到一段"当靶子。轴帧来自每个被试已接受的可复现轴
（skeleton_geometry 的 source/sink 核），把 broad 通道池里每个事件的参与通道投影到这条轴上；
分母 = 该被试"被招募到的通道沿轴铺开的范围"（所以 axial_fraction ∈ ~[0,1]）。
对照 = 同被试、同参与通道数、**按电极杆配额**随机抽通道（shaft-matched null），
专门排除"只是电极插在那一片"的采样假象。n=23（3 个 yuquan 因核通道不在 broad 池被 core_unmapped 剔除）。

### event_extent.png
左图 A = 每个事件沿轴铺的比例 `axial_fraction`（蓝=实测，灰=随机对照）；绿线 0.75 / 红线 0.5
是预注册阈值（≥0.75 倾向"轴向铺满"，≤0.5 倾向"只占一段"）。右图 B = 事件垂直方向相对轴向的窄度
`lateral_ratio`（紫=实测，灰=对照），红线 0.5。两图最关键的现象：**实测曲线几乎贴着随机对照走**——
绝大多数被试 axial_fraction 在 0.8–1.0（事件铺满轴，只有 epi_384 掉到 ~0.36 像一段），
且实测与对照在 axial 和 lateral 上都基本重合。

**关注点**：看实测（蓝/紫）是否偏离随机对照（灰）——这里几乎不偏离，说明事件的空间足迹由"哪些通道被招募"决定（采样），不是神经层面的轴向自限；而且事件是轴向铺满（AF≈0.92）而非收在一段，所以"把事件轴向收住到一段"不是数据支持的 M2 靶子。
