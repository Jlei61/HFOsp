# 局部分岔、全网节律与传播：可回答到哪里

当前能直接建立的是：**六群体确定性模型的分支状态 → 核内及周边群体率；原生空间 SNN 的实际放电 → 触点事件、二维传播和三项指标。** 两者之间“相同参数意味着相同吸引子”的联系没有成立。本版保留这条实测边界，不把六条率曲线插值成空间传播，也不将同一个 J=1.38 的冷启动重复标成两个空间状态。

## 左侧分岔图修复

横轴 `J_EE,core` 是无量纲的参考权重倍率，**同时只缩放 A 核内部 E→E 与 B 核内部 E→E**。原生稀疏矩阵为 target 行、source 列；`_block_masks` 要求 source 与 target 属于同一个 core 且 target 为 E。既有边和延迟不变，其余权重倍率均为 1。降阶模型的输入一阶矩乘 J，二阶矩乘 J²；这不是所有投向 core 的 E 输入增强。实际应用记录位于各 `native/*/applied_physics.json`，定义与核验位于 `parameter_mapping.json`。

重读了 8 段母支的 841 个周期解以及 PD1–3 的 9 个已核验短 2T 子支样本。每个解导出 `branch_id`、`solution_id`、延拓顺序、精确 J、完整周期、网格及原始状态数组引用；A/B 使用相同的解和稳定性。连线保留旧版本经过核验的延拓段顺序，不按 J 重排，不将未知全局连接补齐。本版不宣称已经找齐全局所有周期族；LP0/PD0 的更窄局部结构仍以 v7 的数值报告和原局部图为准。

原周期解使用等间隔傅里叶相位网格，因此数组平均确实等于此离散周期积分。841 个均值复算与原图完全一致。极值统一重采样到 32768 点；与原 8192 点极值的最大差为 **0.03838 Hz**，16384→32768 的最大差为 **0.003753 Hz**。这不足以解释原先看到的宏观尖角。均值仍用橙线，最大/最小值改为绿/青稀疏小方块，实心/空心分别表示稳定/不稳定；它们是轨道时间极值，**不是置信区间**。完整 2T 轨道仍只有一对全局极值。

Core B 的低率折返不是漏画。在 **J=1.1247479472476345** 的两条平衡解中，A 率为 **0.43691556 / 0.47220397 Hz**，B 率都为 **0.30613318 Hz**（差约 8.3×10⁻¹⁶ Hz）。低态周边近乎不活动，A/B 又无直接跨核连接，因此 A 的 fold 在 B 率上的投影可以重合。新增线性放大图把虚线放在上层，并用空心点标出原解；没有人为错开曲线。

底部的 `T_full(J)` 是完整六群体轨道的重复周期，与事件间隔分开。平衡点 fold 由实特征根 λ=0 确认；周期 fold/LP 由除自治相位方向外的 Floquet 乘子 μ=+1 确认；PD 由 μ=−1 及实际子支方向、稳定性确认。PD1/PD3 向减小 J 为超临界，PD2 向增大 J 为亚临界。图形包络交叉本身不提供新的分岔证据。继承的谱与左右临界模精度记录为 `../core_network_bifurcation_v7_20260916/{numerical_validation,analytic_critical_mode_validation}.json`。

## 原生空间 SNN：对应参数的实测对照

沿用分岔投影来源的冻结空间底物：40,000 个细胞（32,000 E + 8,000 I），拓扑 2511，噪声 848101，core 阈值深度 1，独立 core OU、均值倍率 0.95；无 kick、无慢变量。三个不同 J 各模拟 12 秒，剔除前 2 秒。a 与 c/d 对照的全程群体计数及固定样本精确 spike 与 v7 **逐点完全相同**；b 为精确子轨道 J 下的新原生运行。

记录新增了覆盖全部 E 细胞的 1 mm×1 mm、2 ms 空间发放场，以及冻结 15 触点的发放密度包络。空间计数每帧之和严格等于同帧全 E spike 总数；图含 core 内外 E 活动，不是仅 core 活动。接触读出沿用 Gaussian 空间核 σ=0.25 mm、时间平滑 σ=5 ms。它是模型发放密度，不是患者 HFO 频谱。

三个原生对照都表现为双核重复 burst，A/B 平均率约 **35–37 Hz**、中位 burst 间隔约 **265–270 ms**。它们未在本次冷启动中进入降阶 b/c/d 的高背景轨道，也没有独立确认 PD1 的稳定 2T 状态。a 只获得“双核 burst”这一层面的定性对应；周期和均值并不相同。因此 **不能将右侧标作四条降阶分支各自的空间传播**。c/d 共用一个 J=1.38 原生对照；`state_correspondence.csv` 明确把真正的分支条件传播指标保留为缺失，同时另列同参数对照数值。这些冷启动结果不排除尚未探索的其他原生吸引域。

快照按固定 **4–6 秒**窗口中的全部有效事件依时间顺序出图（a 6 个，b 8 个，c/d 8 个），不按 TA/TB 或相似度挑选。三个窗口均自然包含两类冻结分类器标签。每个事件用最早有效触点质心作为零点，展示 −20/0/+40/+80 ms 四帧，所有图共用 **0–97 E spikes / 2 ms / 1 mm²** 色标。三个动画还显示整个 4–6 秒空间活动，不进行事件筛选；每 4 ms 采样一张 2 ms 场，10 倍慢放。整个 2–12 秒内全部检测事件另有固定触点时序图，包括被排除者；未参与触点保持缺失，未填成 0 延迟。

## 三项传播评价

三项指标严格复用当前 data-driven 评价实现 `report_topic4_label_free_dense.py::{describe,metrics}`，目标仍是原冻结患者 **19,770 个 FIT 事件**。它们是三个 **摘要误差**，不是优化器使用的完整分布目标，也不是图中 32 个患者示例包络的误差。所有有效模型事件先合并再算，不是先算 TA/TB 后平均。

1. 平均传播顺序：每个参与触点在事件内归一化 rank，比较患者/模型的触点平均 rank；先在杆内平均绝对差，再对两杆等权。
2. 杆内相对顺序：只在两触点共同参与的事件中估计先后概率，完全同时各计 0.5；比较同杆所有触点对的概率，先在杆内平均绝对差，再对两杆等权。
3. 两杆触点参与度：每个触点参与有效事件的概率之差，先在杆内平均绝对差，再对两杆等权。

三次运行的 15 个触点、SCL 全部 6 对、ICL 全部 55 对均可估计；逐对共同参与分母已导出到 `metric_provenance.json`。固定事件观察器沿用原阈值、250 ms 比较窗、重叠双方排除和持续事件排除；没有为本次结果调阈值。每次均有36个完整落在分析窗内的检测事件，8/6/6个未进入主评价。全部事件和排除原因见 `event_inventory.csv`。

这是同一拓扑、同一噪声的参数对照，事件不是独立网络重复。两种分类标签都出现，不等于两个患者传播分布均被恢复；同参数对照的误差有变化，也不能归因为未复现的 LP/PD 分支切换。

## 本版验收与剩余联系

已完成：左侧读出和绘图修复；同母支 T/2T 对照；四条降阶轨道的全网/周边率；三个同参数原生空间重放；22 个实际事件的快照页、三个整段动画；全量事件时序和三项指标及逐触点原量。数值复算、native 重放一致性、计数守恒、参数应用、共同时间窗、两类标签覆盖和图文件检查由 `validate.py` 完成。图为候选，尚未经用户目视验收。

尚未完成的是 **降阶四种吸引子 → 原生空间四种状态** 的对应，因而本版不能回答“PD1 是否改变两类传播的相对占比”或“c 与 d 的空间传播指标是否不同”。其替代解释是闭合近似和状态初始化不同：六群体模型丢失空间结构，率时间常数亦为闭合假设；目前原生记录只有同参数冷启动。后续若要把这种分支因果解释做实，需要有完整原生状态/延迟记忆的受控延续或经过核验的空间闭合，并先验证状态，再计算这三个条件指标。不能用更换噪声或挑选传播图代替这一步。本次没有启动新的模型拟合、E→I 扫描或人为诱发的高率实验。
