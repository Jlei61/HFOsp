# 图说明 — Topic 4 状态条件化空间易感性（state-conditioned spatial susceptibility）

纯模型问题：一个固定的、带方向"骨架"的仿真皮层小片，戳一下会沿某条固定横轴短暂传一小段再停（间期传播轴）。让每个细胞的"抑制刹车效力"沿一条已算好、固定不变的轨迹慢慢失效直到失控，问：**走向失控前，随着刹车失效，这张骨架对空间扰动的短时放大能力（易感性）怎么变。** 模型侧诊断，不是发作。

**术语（2026-07-19 复查后修正）**：图里"沿轴/垂直"指的是**输入条纹的波矢方向**——沿轴（k∥）=条纹沿横轴方向起伏、垂直（k⊥）=沿纵向起伏，**不是**输出的传播方向。传播方向的证据在"最优输出 U1"那一行的横向拉伸。三个数学对象严格分开、不混叫：**本征模式**（长期渐近最慢衰减的模式形状）、**V1 最优输入**（30 毫秒内最容易被放大的输入图案）、**U1 最优输出**（该输入产生的响应场）。

### state_conditioned_susceptibility_diagnostic.png / .pdf

**五行静态状态地图** × 四个时间点（基线→中段→失控前 500→失控前 100 毫秒；失控点工作点已越边界、线性化失效，本图省略；传播**动力学**见单独的 `time_response` 图）。第 1 行：刹车效力地图（三种子中位；三角=源核、倒三角=汇核、虚线圈=核、白线=轴）。第 2 行：**真本征模式** |φ_E| ——基线弥散（全局），失控前收缩到源/汇两个核团沿轴（从"全局"变"沿轴"，直接画出来而不只是标量）。第 3 行：**V1 最优输入**（signed，红蓝发散色）——30 毫秒窗口内最易被放大的输入图案。第 4 行：**U1 最优输出**——响应场，它沿横轴的拉伸=输出的传播方向证据。第 5 行：**G(k∥,k⊥)** 探针增益谱（k∥=横、k⊥=纵）。三个数学对象（渐近本征模式 / V1 最优输入 / U1 最优输出）严格分开、不混叫。

**关注点**：看第 2 行本征模式从弥散变两核沿轴、第 4 行 U1 输出沿轴的中等拉伸；别把 k∥（输入波矢方向）当成输出传播方向，也别把 peak_k=1.26（整片尺度，见收敛图）当成找到了真实最优波长。**这是静态地图；"什么时候放大、传得多远、多快、传到汇没有" 看 time_response 图。**

### time_response.png / .pdf

只比较 baseline 与失控前 100 ms，用**同一个**源核 Gaussian kick 沿 `C_E e^{J_s t} b_fixed` 演化。Panel a 先给 5/15/30/50 ms 的两行空间响应，panel b–c 给时间×轴位置图；panel d 是固定 kick 的 E-rate 总响应范数，panel e 是累积汇/源响应能量比（100 ms 时 baseline≈0.12、pre-onset≈0.58）。灰色与赭金色只编码网络状态，避开论文中 template A/B 的红蓝语义色；主画布不再放 arrival 曲线或方法注释。10% arrival-threshold 拟合仍保存在 `time_response_summary.json`：baseline 不可拟合，pre-onset 斜率≈4.97 ms/归一化空间单位、R²≈0.89。

**关注点**：固定 Gaussian kick **没有**总范数净放大，但 pre-onset 明显延长响应并增强远端招募；arrival-time 正斜率支持顺序招募，尚不足以单独证明连续 wavefront。该图是 MZ z-only 轨迹映射到 frozen-q M3B 率场代理，不是直接刺激完整 MZ SNN。

### operator_gain_envelope.png / .pdf

补充图：每个状态都允许重新选择自己的最优输入，画 E-rate→E-rate 算子块的最大奇异值 `σ1(T)`。baseline 从 1 单调下降；pre-onset 在约 5 ms 超过 1、约 15 ms 达峰≈1.51，之后衰减。它是算子上界，不是主图中固定 Gaussian kick 的实际增益。

**关注点**：只用它回答“是否存在某个会被净放大的输入、最佳时间窗多长”，不要把它当成固定刺激响应。

### eigenmode_timecourse.png / .pdf

横轴是真实的距锁定 SNN runoff 时间，不再用 `alpha` 插值。Panel a–d 是 representative seed 1 的主 Jacobian 不变子空间 E-loading；panel e 为 `Re λ`，panel f 为 `τ=-1/Re λ`，panel g 为三种空间分数；约 22–24 Hz 的频率轨迹保存在 sidecar，但因信息较弱不进入主画布。`Axis` 用模态功率 `|φ_E|²` 的空间二阶矩张量计算：其各向异性乘以主轴相对骨架轴的 `cos(2Δθ)`；`Globality=(Σp)²/(NΣp²)`；`Overlap` 是相邻两个非负子空间 loading 场的归一化点积。seed 1 可解析到 -20 ms，seed 3/4 到 -100 ms；0 ms 边界均留空。

**关注点**：领先模式在中段后发生从近静态全局模态到约 22–24 Hz 轴向模态的切换；Re 接近 0 表示阻尼变弱、持续时间变长，不表示传播速度变快。相邻 overlap 用来提示主模态身份切换，传播本身仍看 fixed-kick 图。

### state_conditioned_susceptibility_controls.png / .pdf

两块（基线、失控前 100 毫秒）× 6 种对照，每种一对柱（绿=k∥、紫=k⊥ 增益，三种子中位）。real=真实失效图案；uniform mean=抹平成同一平均值；rotated 90=图案旋转 90 度；spatial shuffle=随机打乱；z blocked=完全不失效；AR1=去骨架方向性。失控前：real 最高（≈uniform 两倍）说明**放大强度由失效的空间图案定**；z blocked 平说明**没失效就没放大**；rotated/shuffle 保住 k∥>k⊥ 差、AR1 把它减半说明**k∥ 偏好由各向异性骨架给、不是图案朝向给**。

**关注点**：real vs uniform 看"图案定强度"；rotated/shuffle 保住 k∥ 差、AR1 减半，一起看"k∥ 偏好由骨架给"。

### convergence.png / .pdf

网格分辨率收敛检查（n=8→24，同一批已捕获的慢状态重新铺网格，无新仿真；**representative seed 1，非三种子**——三种子一致性另在 n=12 由主 atlas 建立）。两块=基线、失控前 100 毫秒；每块画算子层量（σ1、k∥、k⊥、本征模式沿轴度、U1 输出沿轴度）随 n 变化，右轴另画 peak_k。

**关注点**：看算子层量（σ1/本征沿轴/U1 沿轴）在 n≥12 是否**稳住**（稳住=结论不是 n=12 的分辨率假象）；基线的 n=8 本征模式是明显异常点，n≥12 才稳成非轴向。peak_k 钉在**最低非零波数**（=2π/L，整片尺度）——**扩 p_max 只加更高波数、动不了这条低波数轨**；要看是否有更大尺度（更低 k）的最优，得增大空间域 L、用连续/分数 k、或加非周期不同宽度的平滑空间基。

### continuation.png / .pdf

临界点 continuation：沿 z_α=(1-α)z_pre100+α z_onset（α：0=失控前100毫秒 → 1=失控点）warm-start 求平衡点、跟踪**主本征值**，问"静息态怎么变成振荡/失控态"。左：主本征值实部随 α（≥0=线性失稳；虚线=不动点丢失）。中：主模式频率 |Im|/2π（>0=复共轭对=Hopf 型）。右：平衡点率 rE_max（对数；跳升=饱和/分支丢失）。

**关注点**：三种子一致——实部**升向 0 但不过 0**、静息不动点在**低率**丢失（右图 rE_max 跳升发生在更晚的 α，不是这次丢失），主模式全程 **~24 Hz 复共轭对**。所以是"**与到 ~24 Hz 极限环的振荡型转变兼容、但非确证超临界 Hopf**"（可能 fold/亚临界）；确证要 onset 后 time-dependent tangent operator + Floquet。α_crit 逐种子漂（因直线插值到边界深浅不同），但 ~24 Hz 低率丢不动点机制稳健。

### post_onset.png / .pdf

onset 后自主动力学 + 沿轨迹易感性：从"失控前 100 毫秒的不动点"起步、换上"失控点的 q 场"，让率场自己往前跑 2500 毫秒（回答 continuation 留下的"是极限环还是饱和"）。A：rE_mean(t)——seed1 一直低（稳到低率不动点）、seeds 3,4 停一会儿后**跳到高率支**（饱和）。B：rE_max(t)（对数）——同上，跳前有 ~24 Hz 振荡增长。C：谱（2 nd half FFT，虚线=continuation 的 ~24 Hz）——没有干净的持续振荡峰（不是极限环，主要是跳变的 DC）。D：**沿轨迹的 frozen-J σ1(30ms)**——seed1 平在 ~1.3；seeds 3,4 在**逃逸处 σ1 尖峰到 ~12–14**（同时 Re 穿过 0=线性失稳），随后落到 ~5–7。

**关注点**：D 的 σ1 尖峰是核心——失控是 fold/双稳**逃逸**到饱和高率支（逃逸处巨大非正规放大 + Re 真穿 0），**不是极限环、不是静息态的 Hopf**；~24 Hz 是低支弱阻尼模式。seed1 在此背景不失控（代理复现 2/3 种子），是粗代理的诚实局限。
