# 图说明 — Topic 4 状态条件化空间易感性（state-conditioned spatial susceptibility）

这一组图问的是一个纯模型问题：一个固定的、带方向"骨架"的仿真皮层小片，戳一下会沿某条固定轴向短暂传一小段再停（间期传播轴）。现在让每个细胞的"抑制刹车效力"沿一条已经算好、固定不变的轨迹慢慢失效（去抑制），直到网络走向失控。我们看：**在走向失控之前，随着刹车失效，这张骨架对空间扰动的短时放大能力（易感性）怎么变——原来的轴是被保留、加强、还是转向。** 这是模型侧的机制诊断，不是发作复现。

### state_conditioned_susceptibility_diagnostic.png / .pdf

四列 = 刹车失效的四个时间点（基线 → 中段 → 失控前 500 毫秒 → 失控前 100 毫秒；失控点本身工作点已越过边界、数值上解不出，在第 4 行画成空的端点）。第 1 行：粗网格上的"刹车效力地图"（三个随机种子的中位数），三角=源核、倒三角=汇核、虚线圈=核团、白线=轴；可以看到失效沿着含两个核团的那条横带逐步加深。第 2 行：用不同空间波长/朝向的探针去戳，30 毫秒窗口内的放大量在波矢平面上的分布——越接近失控越集中到"低波数（大尺度）"且略沿横轴（=轴向）拉长。第 3 行：最强探针经过网络后的有限时响应场（**这是响应场，不是本征模式**）——从基线时贴在源核，逐步变亮并沿轴corridor朝汇核铺开。第 4 行 a：沿轴/垂直/全局放大量随时间点的轨迹（细线=3 个种子，粗线=中位数），三条一起从约 0.2 涨到约 0.75，沿轴≈全局>垂直；b：沿轴放大量随时间窗口 T 衰减（自限），失控前那条整体更高更持久。

**关注点**：放大量随刹车失效急剧上升 + 偏好尺度掉到大尺度沿轴 + 三种子高度一致；但要看清"沿轴只是略微超过垂直、整体偏全局放大"，不要读成"变成一条窄窄的轴向线"。

### state_conditioned_susceptibility_controls.png / .pdf

两块 = 基线 与 失控前 100 毫秒；每块里对 6 种对照各画一对柱子（绿=沿轴、紫=垂直放大量，三种子中位数）。对照含义：real=真实失效图案；uniform mean=把失效抹平成同一平均值；rotated 90=失效图案旋转 90 度；spatial shuffle=随机打乱失效图案；z blocked=完全不失效（去抑制前的算子）；AR1=把骨架的方向性去掉（各向同性核）。基线时六种都平（没有方向偏好）。失控前：real 最高（≈uniform 的两倍）说明"放大强度"由失效的空间图案决定；z blocked 平说明没有失效就没有放大；rotated/shuffle 虽然强度掉了但"沿轴>垂直"的差还在，AR1 强度高但沿轴≈垂直——说明"沿轴这个方向"主要由各向异性骨架给，不是图案的朝向给。

**关注点**：real vs uniform 看"图案决定放大强度"；rotated/shuffle 保住沿轴差、AR1 抹平沿轴差，一起看"方向由骨架给、不是失效图案创造的"。
