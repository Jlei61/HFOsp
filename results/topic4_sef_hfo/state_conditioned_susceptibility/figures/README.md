# 图说明 — Topic 4 状态条件化空间易感性（state-conditioned spatial susceptibility）

纯模型问题：一个固定的、带方向"骨架"的仿真皮层小片，戳一下会沿某条固定横轴短暂传一小段再停（间期传播轴）。让每个细胞的"抑制刹车效力"沿一条已算好、固定不变的轨迹慢慢失效直到失控，问：**走向失控前，随着刹车失效，这张骨架对空间扰动的短时放大能力（易感性）怎么变。** 模型侧诊断，不是发作。

**术语（2026-07-19 复查后修正）**：图里"沿轴/垂直"指的是**输入条纹的波矢方向**——沿轴（k∥）=条纹沿横轴方向起伏、垂直（k⊥）=沿纵向起伏，**不是**输出的传播方向。传播方向的证据在"最优输出 U1"那一行的横向拉伸。三个数学对象严格分开、不混叫：**本征模式**（长期渐近最慢衰减的模式形状）、**V1 最优输入**（30 毫秒内最容易被放大的输入图案）、**U1 最优输出**（该输入产生的响应场）。

### state_conditioned_susceptibility_diagnostic.png / .pdf

六行 × 四个时间点（基线→中段→失控前 500→失控前 100 毫秒；失控点工作点已越边界、线性化失效，画成第 6 行的空端点，**不是增益=0**）。第 1 行：刹车效力地图（三种子中位；三角=源核、倒三角=汇核、虚线圈=核、白线=轴）。第 2 行：**真本征模式** |φ_E| ——基线弥散（全局），失控前收缩到源/汇两个核团沿轴（从"全局"变"沿轴"，直接画出来而不只是标量）。第 3 行：**V1 最优输入**（signed，红蓝发散色）——30 毫秒窗口内最易被放大的输入图案。第 4 行：**U1 最优输出**——响应场，它沿横轴的拉伸=输出的传播方向证据。第 5 行：**G(k∥,k⊥)** 探针增益谱（k∥=横、k⊥=纵）。第 6 行 a：k∥/k⊥ 增益 + σ1（真正的最大有限时放大，跨全部输入图案，30 毫秒过 1.0 于失控前）随时间；b：**渐近本征模式的沿轴度（→0.9）vs 有限时 U1 输出的沿轴度（→0.55）**——两者的差就是非正规系统的关键区别（渐近模式已强沿轴，30 毫秒的输出只是中等沿轴）。

**关注点**：看第 2 行本征模式从弥散变两核沿轴、第 6b 行"渐近强沿轴、有限时中等沿轴"的分叉，以及 σ1 于失控前过 1；别把 k∥（输入波矢方向）当成输出传播方向，也别把 peak_k=1.26（整片尺度，见收敛图）当成找到了真实最优波长。

### state_conditioned_susceptibility_controls.png / .pdf

两块（基线、失控前 100 毫秒）× 6 种对照，每种一对柱（绿=k∥、紫=k⊥ 增益，三种子中位）。real=真实失效图案；uniform mean=抹平成同一平均值；rotated 90=图案旋转 90 度；spatial shuffle=随机打乱；z blocked=完全不失效；AR1=去骨架方向性。失控前：real 最高（≈uniform 两倍）说明**放大强度由失效的空间图案定**；z blocked 平说明**没失效就没放大**；rotated/shuffle 保住 k∥>k⊥ 差、AR1 把它减半说明**k∥ 偏好由各向异性骨架给、不是图案朝向给**。

**关注点**：real vs uniform 看"图案定强度"；rotated/shuffle 保住 k∥ 差、AR1 减半，一起看"k∥ 偏好由骨架给"。

### convergence.png / .pdf

网格分辨率收敛检查（n=8→24，同一批已捕获的慢状态重新铺网格，无新仿真）。两块=基线、失控前 100 毫秒；每块画算子层量（σ1、k∥、k⊥、本征模式沿轴度、U1 输出沿轴度）随 n 变化，右轴另画 peak_k。

**关注点**：看算子层量（σ1/本征沿轴/U1 沿轴）在 n 增大时是否**稳住**（稳住=结论不是 n=12 的分辨率假象）；peak_k 在固定 p_max=4 下钉在整片尺度那条轨（=2π/L），这是**域大小/探针范围**限制、不是分辨率假象——要找更细的最优波长得单独扩 p_max。
