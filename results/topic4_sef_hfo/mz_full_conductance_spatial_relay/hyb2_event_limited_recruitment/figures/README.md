# FCXR-HYB2 事件受限招募 —— 图说明

### b0_gap_resolved_envelope_seed1.png

原本的第 2 条子句问的是"下一次事件开始之前，上一次事件留下的包络清干净了没有"，它只在事件
开始前 2 ms 采一个数。这张图把那一个数摊开成整条空档期的曲线，用同一个统计量（跨空档期 ×
占据体素的 q99，除以预注册的开启阈值 `Q_on = 112.505`），并且只采"距上一次事件结束至少
4τ_R"的点——所以图上任何高值都**不可能**是上一次事件的衰减余量（那时余量已 < 2%）。

读出来三件事。**包络确实清空了**：事件开始前 30–75 ms 那条绿带里是 0.0044，稳稳低于 0.01 的
参考线，说明记忆时长 τ_R 选得对、事件之间没有残留累积。**但那一个采样点不在绿带里**：事件
开始前 2 ms 是 0.244，因为全局事件的判定条是网络级的，局部体素总要先烧起来才能把整体推过条，
那段爬升正好落在采样点上。**空档期深处还有一批局部活动**（200 ms 处约 0.4），它们够不到全局
判定条所以不算事件，但在体素尺度上是真的在放电。

正因为这一条测到的是"下一次事件的起火"而不是"上一次事件的残留"，它在 Gate B0 里已被降为
诊断项、不再单独否决模型（判据改在膜层：只有越过 `Q_on` 生成的 `R_evt` 才进入膜方程）。

**关注点**：绿带（包络清空）与右端橙点（采样点）之间那个陡升——它属于下一次事件，不属于
上一次事件。

### hyb2_gate_summary.png

这张图把 HYB2 的两个关键门放在同一行。A 显示执行器在间期的膜层占空比：seed1 只有
`1.08e-4`，seed3 为 0，都远低于 1% 门，因此 Gate B0 通过。B 显示真正的阻断：三个锁定的
`S_Z` 输入在执行器关闭时已经占据 90.1%–90.3% 的体素，全部越过预注册的 90% 天花板。

C 说明执行器并非没有被加载：沿 S25→S75，最大 `R_evt` 从 0.23 增到约 2.24；D 则显示最终
1 s 群体率的 off/on 差异很小。由于 B 已证明空间读出没有足够余量，C/D 不能被用来声称执行器
无效，只能支持 `A0_UNDECIDABLE_ALL_LEVELS`。

**关注点**：B 中三根柱都刚刚越过黑色 90% 线；这是不能继续进入 12 格生命周期短屏的预注册
停机原因，而不是机制阴性。
