# MZ early-onset dynamics — figures

### mz_onset_natural_trajectories.png

用 E1146 单被试小网络，看「间期事件反复出现时，去抑制 D 和放电适应 a 两个慢变量怎样此消彼长」。左 panel（A）是单个 z+m 细胞（适应强度 0.05、seed 1）的时间过程：每次间期事件（阴影）同时把 D（=1−z̄，抑制刹车松开的程度）和 a（=η_m·m̄/I_EE，适应电流）往上顶一下，事件之间 a 衰减得比 D 快（τ_adp=2s vs τ_z=5s）。右 panel（C）是 D–a 状态平面，叠三个 seed × 所有适应强度：只有 z（红，a=0）时系统沿 D 轴一路冲到失控（红星＝run-off 起点，约 D=0.1）；一旦加入适应，轨迹就被拐上 a 轴、停在低 D 区不再失控。

**关注点**：红线（纯 z）向右冲到失控 vs 彩色线（z+m）被适应拐上去停在低 D，这就是「z 推、m 拉」；连最弱的适应（a=0.01）都能在三个 seed 里都挡住 run-off。诚实提示：a=0.10–0.20 时 seed 1 被完全压死（掉回原点附近）而 seed 3/4 仍维持间期活动——高适应端结局与 seed 有关，不是干净一致的。这是 4 联相图里的「轨迹」两格（A+C）；冻结系统的 α₁ 背景（B）和点火阈值 ε_c（D）待冻结 (D,a) 网格算完后补上。
