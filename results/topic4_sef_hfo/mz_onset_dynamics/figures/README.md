# MZ early-onset dynamics — figures

### mz_onset_natural_trajectories.png

用 E1146 单被试小网络，把「放电疲劳」的强度从零开始一点点**加密**往上扫，看它怎么改造「抑制刹车耗尽 → 失控」这条链。左 panel（A）是最弱疲劳那一档（target frac 0.001、seed 3）的时间过程：一连串正常大小的间期事件（上排 rate 的尖峰）每次把去抑制 D（中排，=1−z̄）和疲劳 a（下排，=η_m·m̄/I_EE）往上顶一格，D 像**楼梯**一样爬到约 0.056 就卡住不再上（离失控的 ~0.096 还差一截）——这是「卡在半路的高位平台」，不是冲上去又回落。右 panel（C）是 D–a 状态平面叠三个 seed × 所有疲劳强度：只有刹车（红，无疲劳）时沿 D 轴一路冲到失控（红星，D≈0.10）；疲劳越弱轨迹越往右（D 越高、越靠近失控），越强越被拐上疲劳轴、卡在低 D。

### mz_onset_tau_sensitivity.png

审阅 §5 的追问：把疲劳的**恢复速度**调快（时间常数从 2s 缩到 1s/0.5s），会不会在最靠近临界那档（target frac 0.001）凑出「发作—收住—恢复」的循环？左 panel（A）去抑制 D 随时间：恢复慢（2s，蓝）稳稳卡在失控线（虚线，~0.098）以下；恢复中（1s，橙）两个 seed 贴着失控线、一个直接翻过去失控；恢复快（0.5s，红）三个 seed 全部冲过失控线、跑到 0.75–0.83。右 panel（B）每个 seed 的最高去抑制 vs 恢复速度（圆=有界平台，叉=失控）：恢复越快，从「卡在半路」跳成「翻车」。

**关注点**：恢复更快**不是**凑出循环、而是**削弱刹停**——平台一路升到失控边缘再翻车、始终不回落。这把结论钉死：这个最小线性疲劳**能防不能控**。

### mz_onset_natural_trajectories.png（承上）

**关注点**：红线冲到失控 vs 彩色线被疲劳挡住的**梯度**——最弱疲劳（紫）让 D 爬到约六成失控水平再卡住，越强卡得越低；但**没有任何一档在冲高后回落**（都停在平台）。图例的 "target frac" 是离线标定的目标强度、不是实现的 a(t)（纵轴才是实现的 a）；"population-averaged" = 全 E 细胞平均，非单细胞。结论：这个最小线性疲劳**能梯度化地防住 / 拖住失控，但不能「发作到边缘再收回来」**（无回落 = 平台，不是循环）。近临界的疲劳恢复更快（时间常数 0.5/1s）的扫描在跑；落地后本图会加一格 target frac 0.0025 的三 seed，并视结果补一张「卡住位置 vs 疲劳强度」的直读曲线。
