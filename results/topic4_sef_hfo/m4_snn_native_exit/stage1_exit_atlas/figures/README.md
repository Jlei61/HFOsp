# Stage-1a 退出边界开环探针（诊断图）

这一批图回答一个最省的问题：那个"卡住不结束"的 M4 有界持续态（`k_q=0.10, alpha_G=16`），
如果在它稳定之后（t0=3000ms）用抬高兴奋阈值 `inhibitory_pulse`（+15mV）把发放**压住一段时间**再松手，
它会不会掉回间期？三行分别是：E 群体发放率（Hz，灰带=压制窗口）、抑制油箱均值 `q_I`、除法抑制池 `S_G`。

### exit_atlas_s1_seed1.png
短压制扫描：压 500 / 3000 / 6000 ms。压得越久，`q_I` 加得越满（0.22 / 0.51 / 0.70），松手后越不容易失控——
500ms/3000ms 松手直接冲到 240–293Hz **失控**（runaway），6000ms 松手不失控但**弹回原有界态**（~70Hz）。
可见压制期间 `S_G` 被排空到 0，一松手前几十毫秒没有任何刹车 → 初始再点火过冲；只有 `q_I` 够满，过冲才弱到能被 `S_G` 追上。
**关注点**：退出的敌人是"松手瞬间 S_G=0 + 低阈值灶自发再点火"；`q_I` 回灌是真实且单调的杠杆，但单靠它不足以退出。

### exit_atlas_s1long_seed1.png
长压制扫描：压 10000 / 14000 ms，把 `q_I` 加到接近基线（0.82 / 0.87）。结果**两者都仍弹回有界态**
（rebound_bounded，不再失控，峰值降到 85–90Hz，是单调趋势的延续），松手后活动在 ~2s 内爬回 ~75Hz、`q_I` 又被重新耗回 ~0.10。
**关注点**：即使抑制几乎恢复到基线，低阈值双灶 + 递归骨架仍把网络重新点着成持续态——**有界态是个稳健吸引子，开环抬阈值在任何压制时长下都退不出去**。这解释了为什么历史上所有终止器都失败、以及 R4 为何必须用离散 latch 硬切。下一步（动态 arm D）测的是缓慢淡出、且最强作用在灶上的恢复电流能否在开环做不到的地方做到。
