# Phase-2 冻结退出相图（frozen exit atlas）

问：那个"一直烧、停不下来"的持续放电态，网络里到底存不存在一个"安静的间期落脚点"能退回去？若有，需要多满的抑制油箱 / 多强的除法刹车 / 多大的恢复电流才够得着？

方法：把三个慢变量**冻死**——抑制油箱充盈度 `q_core`（整片均匀冻结的 q_I）、随活动升高的除法式全局刹车 `S_G`、一股恒定外向恢复电流 `J_exit`——在冻住的条件下让真脉冲网络从**两种起点**各跑一遍：冷起点（不踢、从安静起步）、热起点（先狠踢核区把它点着，模拟"已经在发作"的起点）。同一套冻结条件下若"冷→安静、热→持续烧"就是**双稳**（发作支可被踢到）；两种都归安静=只有安静落脚点；两种都烧=只有发作态。

### exit_atlas_coarse_seed1.png
三块面板对应抑制油箱三档（`q_core` = 0.05 空 / 0.40 半 / 0.90 满）；每块内 y 轴=除法刹车 `S_G`、x 轴=恢复电流 `J_exit`(mV)。格子颜色=判决（蓝=只有安静落脚点 low-only、琥珀=双稳 bistable、红=只有发作 high-only）；格内数字=热起点稳定后的发放率(Hz)，`RA`=失控；黑点=连冷起点都在烧。读出的故事：**红只出现在完全无刹车（`S_G`=0）+ 油箱不满的角落**；**琥珀（发作支）随 `S_G`/`J_exit` 抬高而收缩成阶梯**；**蓝（安静落脚点）占主导，且在油箱恢复到满（右面板）时几乎处处存在**。关键定量：即便油箱空到 0.05，只要刹车强（`S_G`=0.4）+ 恢复电流不弱（`J_exit`≥8），热起点也归于安静——安静落脚点够得着。

**关注点**：这张图回答的是"冻结地形里有没有、够不够得着安静落脚点"（有、够得着，不是"无落脚点"瓶颈）；它**不是**动态轨迹本身——真实动态下抑制油箱会随再点火重新耗空、刹车会随活动停下衰减，能不能真的走到并停在蓝区要靠 Phase 1（成形后能否终止）和后续含"刹车慢记忆"的动态实验判。冻结 `S_G` 会低估真实动态里刹车能升多高，所以"有界但持续烧"这一支在冻结图里偏向显示成失控（红/琥珀），属已知偏差。
