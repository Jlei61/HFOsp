# Phase-2 冻结退出相图（frozen exit atlas）

问：那个"一直烧、停不下来"的持续放电态，网络里存不存在一个**低放电/静默的落脚点**能退回去？要多满的抑制油箱 / 多强的除法刹车 / 多大的恢复电流才够得着？

方法：把三个慢变量**冻死**——抑制油箱充盈度 `q_core`（**整片均匀**冻结的 q_I，不是核空周满的真实空间场）、除法式全局刹车 `S_G`、一股**全场恒定**外向恢复电流 `J_exit`（p=1 产生，不是动态局部 p(x,t)）——在冻住的条件下让真脉冲网络从**两种起点**各跑：冷起点（不踢、从安静起步）、热起点（先狠踢核区把它点着，模拟"已在发作"的**焦点** kick 代理，非真实宽带已成形态）。

### exit_atlas_coarse_seed1.png
三块面板=抑制油箱三档（`q_core`=0.05 空 / 0.40 半 / 0.90 满）；每块内 y=除法刹车 `S_G`、x=恢复电流 `J_exit`(mV)。格子颜色=**四类判决**：蓝=only 低（冷热都归低放电/静默）；琥珀=bistability-consistent（冷低/热踢失控）；红=only 高（冷热都失控）；灰=reverse-discordant（冷高/热低，非双稳、判不清）。格内数字=热起点稳定后发放率(Hz)，`RA`=失控；黑点=连冷起点也在高态。计数：**17 only-低、7 bistability-consistent、2 only-高、1 reverse-discordant**。

**揭示了什么（安全口径）**：
1. **测试范围内不是"处处只有高态/失控"**——低放电落脚点广泛存在（17/27 冷热都归低），抑制油箱恢复到满（右面板）时处处是低放电态。
2. 在严重耗竭 `q_core=0.05` 时，**抬高 `S_G` + `J_exit` 能把热起点从失控转成低放电**（(S_G=0.4,J≥8) 或 (S_G=0.2,J=20)）。
3. **分工**：在**抑制耗竭+被 kick 激活的已测区域**里，除法刹车 `S_G` 是必需刹车（=0 则踢就失控）；但 `S_G` **非普遍必需**——`q_core=0.9` 或 `J_exit` 足够强时无 `S_G` 也归低。恢复电流+高刹车把被兜住的热态推进低放电落脚点。

**关注点（诚实边界，别过度解读）**：
- 蓝格多是**接近 0 Hz 的低放电/静默态**，**不是**已证明"回到产生原有间期事件的间期吸引子"。安全说法是"冻结慢坐标下存在低/静默 fast-state 结果"。
- 7 个 bistability-consistent 格**全是 低-vs-失控**（非 低-vs-有界发作态），所以只能叫"bistability-兼容的双探针结果"，**不是**想要的 间期↔发作 双稳。
- 冻结≠动态；冻结 `S_G` 低估动态刹车（真·有界持续支可能被读成失控）；`q_core`/`J_exit` 都是均匀近似（非真实核空周满空间场、非动态局部 p(x,t)）；未探 wavefront stall/annihilation；seed 1。
- **这张图把瓶颈从"有没有低落点"收缩成"动态轨迹能否进入、停住、释放后恢复原有 IED"**——后者要靠 Phase 1（成形后能否终止 + 释放后 IED 恢复匹配器）和含"刹车慢记忆" H 的动态实验才能判。
