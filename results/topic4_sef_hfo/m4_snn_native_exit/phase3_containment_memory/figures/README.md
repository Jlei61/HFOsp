# Phase-3 vNext：除法兜底慢记忆 H + 恢复腿诊断

问：Phase-1 显示减法恢复电流能把成形有界态压到 0 但活动一停 S_G 塌了 → 灶复燃碎裂、不回间期。审阅的解法是一个**不靠活动、自己慢建慢衰的除法兜底记忆** H（`τ_H Ḣ=<Φ(p)>−H`，进 `I_EE/(1+α_G·S_G+α_H·H)`），在抑制油箱回灌期替 S_G 保住兜底。做三个消融 + 一个"快放"诊断。

### arms_Honly_seed1.png（H-only：只 H、无减法电流）
`C_sensor_on`（p 演化驱动 H，`eta_r=0` 无减法电流）+ H（α_H=16, τ_H=6000）。**读出=H 自己就是个干净终止器**：有界态没被减法电流自限 → p 建到 0.36、**H 慢慢建到 0.31**（峰在 ~11s、终止之后仍高）；H 的除法兜底把有界态在 ~5.2s 收住、活动停后**兜着不复燃**、抑制油箱平滑回灌到 0.82。（因果确认：`C_sensor_on` 不加 H = anchor 的 persist 永不终止；加 H 才终止。）
**关注点**：审阅赌的 H 对**终止**这条腿是对的、且比减法 p 干净（p 自限只把 H 喂到 0.05）。**但终止后=静默、无间期事件**。

### arms_pH_seed1.png（p+H：减法电流 + H，跟 fragment 干预臂同参 + H）
H 几乎没建起来（H_peak≈0.05）——因为减法电流把活动压到 0、切断了 p 的传感器输入（自限），`<Φ(p)>` 又被大片不活跃网格稀释。所以 α_H·H≈0.8 可忽略。结果**仍 fragment，但无后段击穿、抑制油箱回灌更满(0.83)、然后静默**。
**关注点**：减法电流的自限让 H 在 p+H 里失效；H 要有用必须让活动**别被立刻压死**（→ H-only 那样，或用持续时间门控 θ_p）。

### arms_pfast_seed1.png（快放诊断：τ_down=2000，衬底能否恢复间期？）
把减法电流放快（τ_down=2000），去掉赖着的压制。**读出=失控复燃**：放太快 → 抑制油箱没灌满 → 灶重新点着成 ~200–250Hz 的**反复高幅爆发**（非 ~40Hz 间期事件），`cls=runaway`。
**关注点**：这是恢复腿的**根本张力**——兜底松（放快）就复燃失控、兜底紧（H 保住）就静默；**中间没有落到间期事件那一档**。

## Phase-3 判决（seed 1）
- **Entry ✓ · Containment ✓ · Termination ✓**（减法 p 能压下；**H 是更干净的新终止器**，慢建慢衰兜过回灌窗）。
- **Recovery ✗（根本瓶颈）**：终止后的低态是**静默**（跟 Phase-2 相图一致：low=近0Hz静默、非 interictal）。间期事件只在"抑制油箱边耗边发"的**进入瞬态**里出现，**不是一个能回去的稳定吸引子**——放快就复燃、保住就静默。
- **所以缺的不是终止器（H 就是），是衬底没有可回的稳定间期吸引子。** 下一杠杆（待用户）=持续时间门控 θ_p 让兜底只对持续态起作用（也许能容许稀疏 IED），但更可能的判断是：需要给衬底一个**独立的间期节律发生器**（不靠 q_I 耗竭瞬态），否则 recovery 腿无对象可回。⚠️seed 1、诊断层、H 值受 `<Φ(p)>` 网格稀释影响（可考虑改用活跃区均值或非对称 τ_H 让 H 在 p+H 里也建得起来）。
