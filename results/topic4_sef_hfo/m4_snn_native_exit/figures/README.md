# SNN-native M4 containment-to-exit —— 退出尝试诊断图

本线问：能不能给"卡住不结束的 M4 有界持续放电态"加一个恢复坐标，让它自己终止、回到能重新产生间期事件的状态。

### fig5_exit_attempts_diagnostic.png
四列并排给出已测退出尝试的结局（上行=E 发放率 Hz；下行=抑制油箱 `q_I`(绿) 与除法 containment 池 `S_G`(红) 叠画）：
(1) M4 有界态=一直烧（persist）；(2) 开环抬阈值压 14s=`q_I` 灌到 0.87 但一松手弹回有界态；
(3) 对称恢复电流=被负反馈压到一个更低的持续水平（不终止）；
**(4) 真·不对称 slow-release（快充 τ_p=3000 / 慢放 τ_p_down=12000）= 有希望的候选**：初段活动被电流**压到 0** → 一段安静期 `q_I` **回灌到 0.7–0.8** → 之后出现**离散、短促、自终止的 burst**（~14.5s、18.5s，伴 `q_I` 下凹 + `S_G` 瞬起），**不再回宽持续态、不失控**。
**关注点**：第四列是本线唯一像"活动→压住→`q_I` 恢复→返回式短事件"的轨迹，但**未确证**：`τ_p=3000` 快充可能在有界态成形期就压住（更像 prevention 而非 terminate，须加大 τ_up 复验）；后段 burst 是否真返回间期事件未验；`cls=fragment` 非 `terminate_clean`；seed1 单例；退出 basin（`q_core×S_G`）未映射。看下行 `q_I`(绿)/`S_G`(红)：两者对活动**符号相反**（活动耗 `q_I`、建 `S_G`），负相关——但这**不是**"绝无重叠/不可退出"的证明。
（⚠️ 旧 `fig5_no_go_diagnostic.png` 第四列因 `d_sweep` 漏传 `tau_p_down` 的 P0 bug 实为对称、已作废删除；本图为修复后重跑。）
