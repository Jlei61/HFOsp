# SNN-native M4 containment-to-exit —— 结论诊断图（BOUNDED-NEGATIVE）

本线问：能不能给"卡住不结束的 M4 有界持续放电态"加一个恢复坐标，让它自己终止、回到能重新产生间期事件的状态。
结论是**做不到（bounded-negative）**，而且有一个干净的结构性原因。

### fig5_no_go_diagnostic.png
四列并排给出所有退出尝试的结局（上行=E 发放率 Hz；下行=抑制油箱 `q_I`(绿) 与除法containment 池 `S_G`(红) 叠画）：
(1) M4 有界态=一直烧（persist，`q_I` 空、`S_G` 满）；(2) 开环抬阈值压 14s=`q_I` 灌到 0.87 但一松手弹回有界态；
(3) 对称恢复电流=被负反馈压到一个更低的持续水平（fragment/游走，不终止）；(4) 不对称电流（快充+慢放长压）=一列周期性失控脉冲。
**关注点**：看下行——**`q_I` 只在安静时回灌、`S_G` 只在活动时起效，两者时间上反相**；没有任何一条连续轨迹能让"油箱灌满"和"刹车就位"同时成立，所以有界态退不回间期。这解释了为什么历史所有终止器都失败、以及 R4 为何必须用"固定 bath（外挂 q 储库，跟活动解耦）+ 离散 latch"硬造生命周期——完整自发 SNN 里没有这种解耦。
