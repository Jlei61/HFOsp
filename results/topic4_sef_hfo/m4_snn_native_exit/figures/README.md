# SNN-native M4 containment-to-exit —— 结论诊断图（BOUNDED-NEGATIVE）

本线问：能不能给"卡住不结束的 M4 有界持续放电态"加一个恢复坐标，让它自己终止、回到能重新产生间期事件的状态。
结论是**做不到（bounded-negative）**，而且有一个干净的结构性原因。

### fig5_no_go_diagnostic.png
四列并排给出已测退出尝试的结局（上行=E 发放率 Hz；下行=抑制油箱 `q_I`(绿) 与除法 containment 池 `S_G`(红) 叠画）：
(1) M4 有界态=一直烧（persist，`q_I` 低、`S_G` 高）；(2) 开环抬阈值压 14s=`q_I` 灌到 0.87 但一松手弹回有界态；
(3) 对称恢复电流=被负反馈压到一个更低的持续水平（不终止）；**(4) ⚠️ 原标"不对称电流"因 `d_sweep` 漏传 `tau_p_down` 的 P0 bug 实为对称 `τ_p=3000`、已作废——真·不对称正重跑，本列待替换。**
**关注点**：看下行 `q_I` 与 `S_G`——**它们对活动响应符号相反**（活动耗 `q_I`、建 `S_G`），随周期负相关；已测 actuator 没把网络带进低活动间期 basin。**但**这不是"绝无退出轨迹"的证明：`q_I` 有始终存在的恢复项、`S_G` 有有限记忆（第 2 列 release 后两者曾同时非零 ~403ms），且这里画的是**空间均值** `q_I`（可能掩盖 core 仍低）——退出 corridor 是否存在需 `q_core×S_G` 冻结-态 atlas 才能定（未做）。R4 用"固定 bath+latch"闭环可解读为绕过这个负相关，但不等于 SNN 里绝无退出。
