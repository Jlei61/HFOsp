# 条件分支的历史和空间读出

科学问题是在同一完整Z/K场及未来输入下，两种内源历史是否仍表现出不同活动，进一步比较图结构是否改变这种响应。统计单位是一条条件轨迹，末10秒内的格点、触点和时间样本不是独立重复。

新摘要保留全E、两核及核外平均率，400个原生格点平均率，以及同一15触点算子的平均电流。历史差定义为间期历史减高态历史；结构差明确注明参考图。空间绝对差按每格E细胞数加权，先核验空间场加权均值等于直接放电计数得到的全E率。空间均值描述活动位置和强度，不描述传播方向；事件传播仍需看原生5ms序列。

相同粗分类不判定为相同吸引子，零差也不认证完整状态收敛。触点电流包含背景输入且排除K/M，不能当作HFO能量。没有设立数据后验的相似性阈值。

顺带纠正末10秒自然漂移摘要的端点：每条漂移记录覆盖其时间戳之前20ms，因此应选右端点位于(horizon−10,horizon]的500条，而非包括左端点的501条。已有三个条件的放电率、事件和分类均不变；低K高态历史的平均dZ从−0.0849652/s变为−0.0849323/s，机制方向不变。旧摘要和生产脚本保存在prior_to_paired_readouts_20260925。原生仿真及冻结的物理方程没有修改。
