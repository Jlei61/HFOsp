这是 LC4f 实际执行到 X1 后的四联诊断图。A 显示网络在 29 个 returning IED 后于 11 s 无 kick 进入高态，但直到 22 s 记录末端都没有 offset；B 显示群体平均 X 最低仅 0.488，没有跨过独立冻结试验给出的 0.380 终止边界；C 显示 D–H 慢轨迹进入高态后没有折返；D 显示两个核心的 X 已下降到约 0.41，但轴带、轴外及全体平均仍明显高于终止边界，提示 cell-local X 的覆盖不足。该图是单 seed 阴性 screen，不是完整 seizure lifecycle 图。

**关注点**：D/Z entry 已经稳定复现，真正失败在 X 无法在自然闭环里形成足够广泛的终止负荷；图中没有 postictal 或 recovery 段，不能据此声称返回间期。
