### lc4f_x_depth_screen.png / .pdf

这是 LC4f 实际执行到 X1 后的四联诊断图。A 显示网络在 29 个 returning IED 后于 11 s 无 kick 进入高态，但直到 22 s 记录末端都没有 offset；B 将群体平均 X 与旧 late-bout 冻结试验的 0.380 参照并列，实测最低为 0.488。0.380 不是对当前 D/H/空间状态普适的终止边界；C 显示 D 与 H 在 X 下降时仍继续改变，真实退出面可能在移动；D 的区域均值只说明 X 场与存活 carrier 的空间支撑不匹配，不能单独证明必须全场统一抑制。该图是单 seed 阴性 screen，不是完整 seizure lifecycle 图。

**关注点**：D/Z entry 已稳定复现；当前 cell-local X 在预注册 1–5 s 窗内没有产生 offset。尚未区分剂量自限、移动终止面、作用通道不对齐和空间支撑错配，图中也没有 postictal 或 recovery 段。
