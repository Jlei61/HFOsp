# 原 SNN 的 Core A 局部资源检验

支持一个有限范围内的结论：只降低 Core A 的 Z，可以使该核持续高活动，而核 B 仍有低活动间隔，全局未达到原 onset 标准。这与当前 rate 模型的局部状态结果方向一致，尚不是完整空间动力学验收，更不证明分岔类型。

## 实际控制

复用经过逐位重放验证的原 Fig.5 native9s 完整状态及同一未来输入。仅把754个Core A E细胞的Z替换成原10.37s时这些细胞各自的值，核B/外围/抑制细胞Z均不变；全部Z固定、全部M动态。连续运行原时钟9–12.5s，并与已有且独立审核的native_t9000_Zheld配对。没有移植膜电位、突触/延迟历史、M、时钟或噪声状态，没有换网络参数。

## 结果与边界

末1秒，核A参考条件平均111Hz、低活动56.7%；仅核A耗减后平均433Hz、低活动0，10ms平滑率最低359Hz。核B仍约43.5%时间低活动；外围均率57Hz并有持续驱动，并非完全静息。两条件均无原200Hz/200ms全局高率进入，也无75%空间招募联合进入。只耗减条件的持续空间参与（50Hz/90%时间，原10ms箱定义）约8.0%。

只有一条配对原生历史/一套未来输入，短窗结论不升级为永久吸引子。rate模型用自身已演化的快/M初态和常数均值外驱，原SNN使用原9s状态及真实未来输入；跨模型不是相同历史或逐时刻拟合。特别是CoreB末1秒的活动量在两模型间明显不同，不能把核A干预结果的一致称为传播/全部动力学通过。

## 验证与文件

原生对照的动态重放QA保留PASS。新增状态除slow.z外逐位一致，且差异严格限制在754个CoreA细胞；末态Z逐位保持，M实际变化；未来输入序列及最终随机/外驱状态与原参考逐位一致。区域计数守恒，原事件/onset和区域读出独立重算，result.json为AUDIT_PASS（数值/来源检查，不是完整模型科学验收）。10ms滑动求和在零率处约1e-13负数为浮点误差，未改数据或阈值，不影响分类。

figures/fig_core_a_native_rate_resource_control 为同样1秒平均窗的原生/率模型空间对照，PNG/同版PDF已Agent目检，人工待用户检查。详细条件在protocol.json，原生读出在result.json，率模型同长度窗口读出在rate_comparison_last1000ms.json。所有均率仅为时间统计，不是平衡点或周期均值。
