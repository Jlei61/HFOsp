# 平稳方差分配在动态输入下的适用范围

问题是：上一轮修正使稳定输入下的公共/私有递归电流方差相加正确，但它是否也使变化输入下的方差相加正确？本次使用原935群体投影、原连接权重、358个延迟箱及AMPA/GABA双指数电流核；没有运行网络、拟合参数或修改响应函数。计算单位是有向群体连接对；结果按目标E细胞数量加权，不是多次随机仿真的统计推断。

在独立Poisson源群体、各源相干小幅相对调制的假设下，直接计算总电流平方核和公共电流交叉核。真实剩余私有核应为二者之差；常数分配比例只在零频严格满足这个恒等式。比较两侧都用同一个精确电流平方核，因而不把原率响应中已经标定的方差滤波近似混进本次误差。

| 输入调制频率 | AMPA平均绝对复误差/静态总递归方差 | GABA同量 |
|---|---:|---:|
| 0 Hz | 数值零 | 数值零 |
| 3.783 Hz（旧候选周期基频） | 0.320% | 0.468% |
| 10 Hz | 0.838% | 1.066% |
| 40 Hz | 2.812% | 1.713% |
| 80 Hz | 3.461% | 1.458% |

表中背景取旧候选周期的平均空间率；均匀10 Hz背景也计算了相同8个频率。零频相对恒等式误差小于3e-15，两个突触类型各11个分散连接对的独立双延迟求和误差小于3e-15；这些连接对的直接时间域公共核积分误差小于2.8e-6，剩余私有核非负。以上验证计算公式，并不验证原生放电的Poisson独立假设。

判断：平稳修正仍留下可量化的动态误差，在本次相干低频探针下较小；不足以据此提出又一轮参数修补。高频总响应本身衰减，因此表中以静态总方差归一化的百分比不能读成相对该频率响应的百分比。此结果没有排除空间相位差、非线性爆发、相关输入或临界附近小误差放大的影响，也没有证明强输入率响应准确。原来的局部响应失败和网络同一时钟D轨迹失败继续保留，模型不升级为通过验收。
