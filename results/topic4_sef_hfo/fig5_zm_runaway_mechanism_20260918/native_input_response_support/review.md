# 固定率响应的输入范围核对

六个预先选定群体的原生8–10.37秒输入经同一均值/私有方差投影形成原39个特征，排除首1秒准备。用原480条训练输入的逐分量范围、原冻结白化坐标的范数，以及固定8192训练行的最近邻距离核对；另4096训练行提供距离参照。不涉及新拟合或新的仿真。

进入前大部分特征落在原训练逐分量范围内，白化范数也未普遍超出训练最大值。所选Core A群体在9–9.42秒没有分量超界；所选Core B和I群体的瞬时特征有少量超界。原生点相对训练集的最近邻距离通常高于训练内部中位数，但多数低于训练内部参照的99分位。

因此不能把当前误差简单归为输入幅度大面积越界。逐分量范围内并不等于处于训练联合分布、凸包或被充分采样区域，也不证明局部传递函数准确。这里只排除了最粗略的解释，不支持继续无目的扩大同类训练集。

全部定义、18个群体×阶段条目及抽样种子见[result.json](result.json)；原特征保留在native_features.npz。单条原生历史、六个固定群体，没有总体统计推断。后续空间细分与自身放电记忆分别检验两个具体近似，不能把范围核对当成模型验收。
