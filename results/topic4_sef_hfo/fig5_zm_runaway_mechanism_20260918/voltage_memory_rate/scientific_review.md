# 单一近似膜电位记忆：局部验证失败，停止本候选

该候选针对原生膜平衡诊断提示的缺口，在冻结父模型的输入历史之外增加一个由自身放电驱动的近似平均膜电位状态，含输入与不应期占据的乘积。它没有逐粒子电位，不输入未来原生放电，也不改变空间网络或Z/M参数；此状态并非精确条件电压分布，仍忽略钳制条件协方差和阈值越界量。设计见[design_review.md](design_review.md)。

固定训练和全部216条复用验证已结束，执行无失败。原24条强输入/域内验证通过23条；三组各64条通过52、55、50条，另有6条时间步收敛门槛失败。仍未通过的原外围E强输入波形相对误差0.171，高于原0.15门槛。实现检查、训练后独立积分和独立评分均通过，所以这是模型验证失败，而不是将程序执行完成误记为科学通过。

它改善部分误差，但不足以证明一个平均电压记忆就补足局部响应。按事先合同停止这一候选，不追加拟合、不做新64条/匹配线性响应、不推广到空间运行或分岔。正在使用的空间率模型仍为此前冻结的conditioned39版本。证据：[验证](validation/result.json)、[独立评分](independent_score_audit.json)、[合同](contract.json)。
