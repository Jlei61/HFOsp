# Z怎样推动全局持续活动：2026-09-20当前结论

**有原生空间反馈的干预证据；尚未确定对应的分岔类型，正式分岔图仍未完成。** 原生参考轨迹在全局平均Z约0.744、D=1−Z约0.256时达到预定的持续高率进入标准。这是该空间场和历史的进入坐标，不是已经证明的普遍临界阈值。

从同一个9秒完整原生状态出发，未来输入和随机流相同，四组M全部动态，只改变哪些区域的Z继续更新：

| Z继续更新的位置 | 9–12.5秒内的结果 |
|---|---|
| 全部 | 进入广泛持续活动 |
| 全部固定 | 未进入，仍有自行终止事件 |
| 仅两核 | 局部持续，未出现同样的全局招募 |
| 仅核外 | 进入广泛持续活动 |

Z乘在E细胞收到的抑制电流上，因此Z下降削弱同样原始GABA输入的抑制效力。上述对照支持核外继续的资源反馈是这条历史下全局招募的关键；它不是不同区域等剂量、单位细胞效力的比较，也不是无限时间吸引态证明。runaway指有界持续高活动，不是放电率无限发散。

旧率模型在全局Z约0.7807的周期几何转折候选针对较早的自限事件变化，尚未通过决定性的分支稳定性与原生对应检验。旧图的多个平衡SN位于已有不稳定模的分支上，也不能直接用作稳定静息态消失触发onset的证据。**当前不能将原生onset定为SN、Hopf或已认证的周期轨道鞍结。**

本轮完成固定条件化率响应的局部验证，以及七条12.5秒空间诊断，所有Z/M都动态。局部拟合改善，却没有恢复原生自主事件、资源轨迹与全局进入。进一步确认并修复了外驱均值绕过AMPA滤波、Poisson群体输出违反不应期人数约束这两个问题；它们会改变结果，但修复后仍未通过原生对应，不能提升为解释原生onset的正式模型。
