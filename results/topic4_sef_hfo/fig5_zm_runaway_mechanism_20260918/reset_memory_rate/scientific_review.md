# 自身放电记忆候选的审阅（2026-09-20）

**结论：未通过，停止这个候选的扩展。** 它没有替换二维空间率模型，也没有开启网络仿真、分岔延拓或新一轮拟合。

这里检验的具体解释是：原39输入历史特征及绝对不应期，是否漏掉了膜时间尺度上的自身放电记忆。新候选只增加一个由模型自身发放驱动的指数衰减计数q，时间常数固定为原生E/I膜时间常数20/10ms；q不是实测膜电位，也不是精确的条件膜电位闭合。输入连接、阈值、突触、传导、Z/M的物理参数均未调节。局部训练只复用原480条训练输入及原静态/线性标定；原生发作时刻、传播和验证目标未参与拟合。

原模型可以通过把q的读出系数设为零精确嵌入。该等价、非零q反馈的解析频率响应、训练后独立逐步积分、因果时序和不应期质量守恒均已通过；这些只证明实现按定义工作。

这里后三套均是复用的诊断集，不声称是新独立验证。全部预测使用模型自己的不应期占据和q历史；没有把LIF的实测放电历史输入预测。新增候选还有5条波形未达到0.1/0.05ms的2%步长门槛；不通过延长训练或放宽阈值补救。原强输入的factorial_waveform_06仍失败：波形L2从0.1815变成0.1856，平均率误差虽减小，波形没有恢复。

为判定这个缺口是否只影响泛化输入，还把冻结后的新候选代入前一轮已经固定的六群体原生输入记录。9–9.42s完整50ms窗、原时钟、相同私有方差和Z/M下，换成真实群体均值时，Core B所选群体相对局部LIF的波形误差从13.5%减到10.0%，低阈值Core B从14.7%减到8.2%；Core A所选群体则从11.4%变差到18.1%。这是一条轨迹上的描述性诊断，不能作人群推断，也不能代替闭环网络验证。

因此，“遗漏一个膜时间常数的自身放电记忆”不足以解释并修复目前误差。它可能参与部分响应，但不能据此认定网络进入机制。没有理由用这个失败候选生产带SN/Hopf标签的正式图。0.5mm空间细分对照属于另一项已注册检验，仍使用原冻结响应，独立收尾。
