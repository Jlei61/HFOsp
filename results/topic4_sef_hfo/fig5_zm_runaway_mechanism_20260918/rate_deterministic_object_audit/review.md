# 确定性分岔对象：关闭抽样不等于现有期望率条件

本次只核对现有代码和固定输入算子，没有运行新网络、改变物理参数或拟合响应。问题是：已经恢复双向传播的有限计数率模型，要转成平衡/周期延拓方程时，究竟保留哪一个方差算子？

`SpatialEngine(noise=False)`使用完整递归扩散方差Q。`noise=True`则在构造时换成私有方差(1−f)Q，同时由实际有限群体计数产生共同输入波动；相同计数也驱动不应期、递归电流与M。因此，既有期望率和计数两列并非只相差一次随机抽样。只在构造后关闭计数创新、保留私有方差，得到的是另一套确定性条件漂移，不等于当前期望率模型，也不等于随机系统的精确集合平均。

在同一个预先保存的8–9.42秒计数率均值探针下，转移出私有扩散部分的GABA方差比例，在核A、核B、外围E分别约80%、79%、70%；AMPA计入不变的外部方差后，约61%、60%、17%。这些按目标细胞数加权，是指定静态率探针下的算子差异，不是实际电流随时间的方差，更不是“抑制强度减少了这些百分比”。均值探针不是平衡解；尤其不能把平均率算出的静态Z目标当成爆发过程中真实Z目标的平均值。

平稳独立Poisson假设下，共同项与私有项相加的恒等式通过；有限计数过程带不应期，且网络活动相关，因此该恒等式本身不证明实际动态方差闭合。当前固定场实验五个条件都使用相同计数规则和私有算子，所以其干预比较不受这个定义区别影响；同一种模式下粗/细空间外部输入的比较也仍有效。

对后续分岔的约束是：分支必须明确属于全扩散的群体均场，还是保留私有分拆后的条件漂移，不能把两种方程的平衡、周期或稳定性混画。既有全扩散期望率仍是原登记的确定性均场对象；它与有限计数条件之间的对应关系仍需验证，不能把计数条件恢复传播直接算作确定性分支的验证。本次不选择新的模型、不启动延拓，也不归因哪个因素造成了Z路径误差。

数据见[result.json](result.json)及[fields.npz](fields.npz)。源代码为`refractory_spatial_diagnostic.py`中的构造分支和`shared_variance_network_sensitivity.py`中的私有算子构造；本次脚本`audit_rate_deterministic_object.py`使用相同物理投影，另由原始群体连接对独立复算四个率探针的完整算子输出。
