# 固定场比较可使用的原生证据，以及历史差异

本次未新跑原生SNN；重新检查了此前32条原生冻结场记录中相关的16条，精确来源与原读出保存在[native_reference_context.json](native_reference_context.json)。原条件包含8.00秒或10.37秒完整快历史及各自真实M初值，两套未来创新，统一从10.37秒外部输入时钟续接。新率模型条件则统一从自己的9秒状态及9秒输入时钟开始，二者不是逐条件匹配的完整状态移植。

原生9.00秒Z场在四个初始条件及四条延长记录中都没有达到持续全局高率，末窗平均约31–45 Hz，没有50 Hz以上占据90%时间的持续空间区域；部分记录属于自限，部分仍未解决，不能全部标为SELF_LIMITED。原生9.42秒Z场在两种历史下差异明显：低历史侧仍有静息或长自限段，高历史侧可局部持续，但四组均未达到持续全局高率。9.87秒Z场在四组中都达到持续高率，末窗约213 Hz、持续占据约54%的E细胞空间。

这些较长记录支持把9.00与9.87秒完整Z场用作两侧参照，同时提醒9.42秒不是已确认的单一临界点。它们不能证明无限时间吸引子、所有吸引域或普遍平均Z阈值。原生末窗为4秒，新率模型对照总长3.5秒、末窗1秒，两者的持续占据不能作为严格同窗统计检验。

新对照自身五组初始M完全相同且均动态。但不同模型之间，9秒时两核m=eta_M M约为原生0.018/0.020 mV、率模型0.030/0.024 mV；外围为0.013与0.005 mV，快电流历史也未强行匹配。因此，新对照若出现与原生相反的两侧，说明当前模型及状态映射未恢复相同条件行为，仍需区分闭合误差与历史映射，不能只凭这一结果指定或排除某类分岔。

此文补充既有证据的解释边界，不改变运行合同、阈值、初态或未来随机流，也不追加仿真。最终判读应以本次实际完整结果为准。

共同9秒初态保存后，还直接计算了移植瞬间的输入变化：delta_mu=(Z_own−Z_transplant) I_G，快电流和M保持原值。换入原生9.00秒场时，两核及外围的细胞加权净输入改变量分别约+8、+19、+13 mV等效；换入9.87秒场约+48、+86、+31 mV等效。这里是膜方程的输入驱动变化，不是膜电位瞬间跳跃。精确逐区域结果见[initial_transplant_input_shift.json](initial_transplant_input_shift.json)。

这说明该干预是有限幅度的参数骤变，而非沿稳定吸引态的准静态延拓。若早场也引出持续活动，除了模型闭合或历史映射失配，还须保留有限扰动跨吸引域的解释；若后场持续而前场自限，则支持有限时间两侧对应，也仍不单独证明周期或平衡吸引态消失。这是为什么最终分岔主图仍需要同一确定性方程上的稳定性与分支连接证据。
