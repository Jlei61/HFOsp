# Core A 局部资源转变：当前结论

目前没有经过认证的 Core A–Z 分岔图。旧 Core A 图的横轴是核内 E→E 耦合，不是资源 Z，不能改轴名复用。本轮接受的是有限时间、完整空间网络中的 Core A 资源干预结果；模型与原 SNN 的完整自主 Z/M 对应及 onset 分岔类型仍未成立。

## 回答了什么

保持当前 g40/3479 群体二维 rate 模型、连接、延迟、响应参数和全部快速/M/历史初态不变，核 B 与外围 Z 都固定在 native9s 晚间期水平。只把 Core A 的 Z 从 native9s 核内空间场改为 native10.37s 核内空间场，各续接10秒；所有 M 全程动态，Z 在各条件内固定。外驱为原常数均值，无未来随机创新；不是直接隔离核 A，也不是从原 native10.37s 高活动初态开始。

最后5秒的结果：

|条件|核 A 平均 Z|核 A 平均率 Hz|核 A 低活动占比|核 A 完整局部活动段|
|---|---:|---:|---:|---:|
|参考|0.744|103.0|66.4%|19|
|仅核 A 耗减|0.599|423.2|0.0%|0|

耗减条件下核 A 的10ms平滑率全程在354–436Hz，M适应仍存在；核 B 在最后5秒有22个完整局部活动段，约36%时间低活动。外围均率约44Hz，存在持续驱动，但空间上仅约8.1%的E细胞所在网格满足50Hz/90%时间的持续参与标准；原全局200Hz/200ms进入标准未触发。不能把外围描述为完全静息，或把核A局部持续称为全局发作。

核 A 仅占 E 细胞约2.36%，这次局部 Z 改变使全局平均 Z 只下降约0.0034。反过来，核 A 单独维持354Hz时已足以给全局均率贡献约8.3Hz，超过全局5Hz低活动阈值。因此“全局低活动间隔消失”和“全局空间招募”必须分开，这正是采用局部资源轴和空间读出的原因。

## 原 SNN 支持和限制

原 Fig.5 9.42s 核 A 平均 Z 约.725，全局约.771，外围约.774，支持核内耗减较快。对单条原生轨迹0.5–9.42s的35次完整全局自限事件，24次核A净耗减大于外围；34次外围也有净耗减。该统计是事件端点的净变化，包含恢复；不等于总消耗通量，也未覆盖所有微小核内事件，不能宣布不存在“核内消耗而外围恢复”的其他事件。逐事件数据见 native_complete_event_resource.csv。

旧 native 双核动态/外围Z固定对照也出现局部高活动而未达到全局 onset，但它同时操纵两核；本轮率模型补充了只改核 A 的匹配对照。两种模型的证据层级保持分开。

## 下一步的局部分岔对象

横轴使用 D_A=1−核A E细胞加权平均Z，纵轴核A E率；沿真实核内空间Z场族继续，核外Z暂固定native9s。完整二维快变量、全部M、延迟历史与核间耦合保留。先在本轮两个端点之间定位局部自行终止消失的区域，再跟踪完整状态的解/吸引子和空间扰动，检验临界变化是否主要位于核A。

这两个端点不构成严格分岔夹逼；局部率最低值越过阈值也可能只是已有活动连续变形。只有完整状态分支、稳定性/返回动力学和步长检查支持时才标SN、Hopf或周期分岔。还需以原生局部干预检验模型对应，随后再释放外围Z连接到全局招募；本轮没有证明SN、Hopf、周期鞍结、双稳态或separatrix，也没有修改 Z/M 生理参数。
