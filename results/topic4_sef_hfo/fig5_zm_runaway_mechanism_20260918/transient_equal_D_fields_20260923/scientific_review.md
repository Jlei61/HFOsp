# 同平均耗减、不同空间 Z 场的配对干预

**在当前固定率模型中，全局平均 Z 不能唯一确定自限或持续状态。** 两臂都固定 D=0.20，即全E平均 Z=0.80；使用相同9秒完整快状态、延迟/不应期历史、M初态、未来外部输入及计数随机创新键，M继续动态。只改变完整空间Z场。

两个场均取自已完成轨迹首次向上跨越D=0.20的相邻观测作线性插值。原生形状来自约7.6744秒，自由率模型形状来自约7.5518秒；这只是空间场来源时间，两臂的实际外部输入时钟都从9秒开始。两核平均Z分别为0.756/0.764和0.601/0.580，核外分别约0.802和0.811；两场全E加权D之差约1e-15。

| 同一9–12.5秒观察窗 | 原生空间形状 | 自由率模型空间形状 |
|---|---:|---:|
| 完整自限事件数 | 13 | 0 |
| 静息时间占比 | 46% | 0 |
| 末1秒全局平均率 | 29.8 Hz | 190.9 Hz |
| 末段持续活跃空间比例 | 0 | 0.475 |
| 全局200 Hz持续200 ms进入判据 | 未达到 | 未达到 |

空间形状差异在这个配对历史中足以改变自限与持续活动，支持把完整空间Z场保留为分岔参数路径。不能把右臂写成已满足全局高率onset；它是约半个网络的持续活动。有限时间场置换包含抑制电流的即时改变，因此也不能据此声称找到了吸引域边界、separatrix或SN。

`implementation_check.json`验证真实9000ms检查点的10ms续接逐位复现，以及常值外供Z与固定Z积分一致。`independent_audit.json`从保存的群体率重建空间率、核对计数物理上界、加权守恒和固定D；状态、事件数、持续时间、方向和参与统计均复现。保存float32空间场后，阈值恰等位置使原生形状的传播距离中位数从运行时9.60245变成9.61569 mm，差异单列保留，未改变状态或科学门槛。
