# Z/M 进入持续活动的机制分析（运行中，2026-09-19 04:40）

当前已证实：在固定二维空间 rate 模型中，继续让 Z 随活动耗减，可以把相同完整初态从自限事件推入广泛持续活动。尚未最终确定先于这一过程的周期失稳类型；数值小回折不能直接命名为 SN/LPC。

## 模型与坐标

固定 v3 方程、静态传递表、响应表、原物理连接及延迟，20×20网格、935个E/I/阈值群体、14个状态/群体。本轮没有调整连接、工作点或Z/M参数。Z是作用在E群体上的抑制增益资源，较低Z减弱GABA反馈；m=eta_M M是负反馈适应电流。条件分岔系统固定完整空间Z场，M仍动态；释放Z实验中两者均动态。

D=1−原E细胞数加权平均Z，纵轴全E细胞平均放电率（Hz/neuron），不是爆发重复频率。两条条件路径分别为原生检查点空间Z场插值，以及rate自身7.7→7.8s的空间Z场插值；二者不共享一个通用平均Z阈值。

## 已回答的机制联系

1. 同一个实际rate周期完整状态出发，固定Z时末4s平均率27.63Hz、保留自限事件；释放Z时末4s483.52Hz、空间广泛持续。M始终动态。原生Z路径上的同初态配对也得到相同方向。见release_Z_audit.json及figures/fig_Z_release_spatial_control.png/pdf。图中是同一时钟的50ms空间窗，0–500Hz；PNG/PDF已自查，人工验收待用户。
2. 原方程的周期平均Z慢漂移，与rate自身7.7→7.8s路径方向余弦为0.938，而与native路径只有0.075–0.182。因此onset主分析应沿rate自己的空间路径进行，native路径承担同场对应检验。稳定短爆发仍在平均消耗资源；释放Z使其继续向后续状态演化。见cycle_slow_drift.json。
3. 固定M对照保留了两侧差别，长事件也仍可以终止。因此不能把该差别只归因于M在续接中继续累积。分区域对照已经完成：仅将外围Z从7.7s场替换到7.8s场，双核Z保持不变，就形成局部持续活动；只改双核Z仍有4个完整自限事件。此为指定幅度、相同初态、12s续接的充分性对照，不是等总耗减的区域效能比较。见spatial_Z_controls_audit.json。
4. native路径D=.219稳定周期与D=.2196的不规则段在空间复现和扰动增长上明显不同。D=.2196两种初始扰动幅度的有限时间增长率分别9.7486/s、9.7548/s；稳定周期控制为−0.1254/s，接近自主周期的中性相位。更细dt=.025ms复核也为正（8.7011/s，各1s块均为正），与dt=.05ms数值并非完全相同；现有结果支持有限时间敏感的不规则活动，暂不以此宣称已证明长期混沌吸引子。见lyapunov/与field_recurrence.json。
5. 高活动历史退回D=.219后，先经历约数秒的不规则过渡，后段峰值和事件间隔才逐渐靠近原短爆发周期。因此12s内相同的自限类别不等于已经证明同一渐近吸引子，也不能反向把过渡窗口称作另一稳定发作态。

## 分岔证据与必须保留的边界

native路径D=.216466周期已通过全空间Floquet相位和谱残差检查，采样横向乘子约0.768。临界近旁周期的dt=.0125ms相位误差降至0.000802、相位投影0.999349；该旧native近临界谱在相位检查通过后未收敛，已停止，计算转向实际rate路径；不把旧谱当作完整结果。

N1024的数值周期转折在D=.219349附近，但时间离散和小回折位置尚未共同收敛。普通N2048 collocation轨道平移半个网格后产生约40Hz的局部残差；去混叠Galerkin显著降低这一误差。周期和参数的解析导数也已经通过独立差分核查，用于后续临界延拓。所有这些修复只涉及同一方程的数值求解，不改变网络。当前不把候选标成已确认LPC，更不沿用旧图的分岔类型。

native 9.87s场的高率平衡有12个右半平面特征根，是不稳定平衡。14个平衡支SN通过静态非退化和延迟特征矩阵简单零根检查，模式主要位于外围；它们不自动是实际onset边界。周期分支折叠需转折、分辨率复核和额外+1 Floquet乘子一致；方法依据为[DDE-BIFTOOL官方手册](https://ddebiftool.sourceforge.net/doc/manual.pdf)。

## 当前最接近进入边界的同场结果（03:15）
