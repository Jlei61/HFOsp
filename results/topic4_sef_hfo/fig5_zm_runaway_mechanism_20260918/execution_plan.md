# 本夜 Z/M runaway 机制检验

授权：用户要求自主探索一晚，完成 Z 耗减至约 0.7–0.8 时进入全局 runaway 的相关结果和分岔类型。工作窗口按北京时间 2026-09-18 23:30 至 2026-09-19 07:30 组织；不预设一定存在单一标量分岔，也不以超时为完成科学目标的理由。

模型：原展示 v2 的局部响应符号反证保留。工作区已存在 v3（实测 colored-LIF 传递表、分开的均值/方差响应），保留同一连接、阈值、物理延迟与 Z/M 参数；本夜先采用 v3 的冻结快照做条件机制检验，明确标记 SNN 对应仍部分通过、动态方差响应尚有误差。原路径 D=1−〈Z_E〉继续使用，不将 v2 的临界点移植到 v3。

关键发现：既有 v3 stage_b 的 a_carried7000_Z* 对照未将目标 Z 写入初始状态第 11 行，全部 11 条轨迹逐位相同；此外检查点历史数组未按原 tick 旋转就以 tick=0 重启。旧数据保留，本目录独立修复与重跑。

执行顺序及判据：

1. **检查点和移植正确性。** 将保存的延迟历史旋转到重启时钟，把目标 Z 明确写入完整初态，M 保持携带值。从 7000 ms 续到 7250 ms 与原完整轨迹比较；加速器与普通积分同态同历史比较。检查通过后才能读机制。
2. **实际路径的状态变化。** 分别使用 rate 自主轨迹的 7.5–9 s Z 场、原生 8–10.37 s Z 场；同快态/M/历史且只变 Z，比较自限周期、持续局部、持续广泛活动。全局率、活动面积、静息间隔分开报告，不以任意 200 Hz 阈值越过自动称为分岔。原生字段路径是独立条件试验，不能冒称完整原生快态迁移。
3. **确定动力学对象。** 对持续活动的终态求同方程平衡解、残差与增长根；对自限轨道做周期 BVP。优先沿相邻实际空间 Z 场插值寻找吸引子丢失位置，而非继续对历史规定幂路径盲目扩大扫参。若高率阈值仅沿一条已稳定平衡支连续越过，明确报告该阈值不是新分岔。
4. **临界验证。** 根据谱证据判 SN、Hopf、LPC、PD 或其他类型；若临界前后吸引子共存则做同完整历史下的 basin 对照，若动态 Z 时间尺度改变进入方式则检查慢快滞后。重要候选做时间步长/周期网格和 0.5 mm 空间检查；失败即缩减机制主张。
5. **模型有效性。** 先核实 v3 是否修复原符号错误，再对相关工作点的静态及动态响应做独立核查。传播/间期验收沿用同网络、同读出和原生噪声尺度，不以精确特征值替代原生对应。
