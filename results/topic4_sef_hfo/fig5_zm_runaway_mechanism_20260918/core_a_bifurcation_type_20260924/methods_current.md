# Core A 资源判型：实际使用的方法

问题是：只改变核A的抑制资源，为什么完整空间网络的核A活动会从自行终止变成持续？控制坐标为 D_A=1−核A内按细胞数加权的平均Z，纵轴的率始终为Hz/neuron。D_A每取一个值，使用原生轨迹对应的核A内部非均匀Z场；核B、外围和I的Z固定为原生9秒场。这个条件动力学中所有Z固定，所有M动态。它是对原动态ZM路径的条件切片，不是把动态Z也纳入每条平衡/周期分支，也不是孤立核模型。

## 平衡分支及其类型

在所有3479空间群体上求原方程的平衡态。静态求解把各线性滤波器、延迟和M消去为它们各自的平衡约束：E群体M=.5*r，此处内部r以spikes/ms计，绘图时再换算成Hz；I的M恒零。稳定性计算恢复这些量的完整动态响应。logit仅是保证率域的求根坐标。数值同伦的辅助参数不作为物理参数，不显示为网络分岔图。

使用伪弧长沿D_A继续平衡根。切向量的D分量反号只提示折叠；真正判SN要求原方程残差小、单一零特征值、左右零向量满足方程，并验证左零向量投影下参数导数与二次项均非零。还检查含突触、输入记忆、M与物理延迟的特征方程对频率的导数不为零，排除双零退化。临界两侧再验证实特征值异号及其他不稳定模态。

当前这一套已经认证D_A=.3531576413处的非退化SN。但两片平衡态均已有振荡不稳定模态，零模态主要分布在核A外侧活动带边缘。因此不能用它代替实际自行终止边界。相同完整低活动初态下，SN上下各20秒的真实轨迹均显示核A末段持续；这种状态对照没有支持该SN是目标阈值。

## 实际不规则活动与周期结构

先比较较强耗减端的长时间续接与时间步长减半，再对原方程的完整状态变分方程积分。被动切向量不改变名义轨迹；全状态有限差分验证其正确性。记录的是有限时间扰动增长率，不能仅凭正值判混沌，更不能直接判危机分岔。

平均固定滞后的回返检验没有找到稳定周期，因此转为搜索单次完整空间近返回：对原始E/I各群体的率、0–128毫秒滞后以及M比较；随机投影只筛选候选，最终误差用全部群体重算。不同续接文件的段内时钟不能直接拼接，按已审核的连续历史建立累计时间。对候选从原始完整检查点逐位重放，取回突触、局部响应记忆、全部M与完整延迟历史，而不是把近似相等的平均率当作同一状态。

目前对D_A=.3281215991的间歇活动候选求 P_D(X)−X=0：P_D是完整状态经过一次正向Poincare截面返回的映射。Newton–GMRES的每个矩阵向量积都来自实际全空间变分方程，并包含返回时间的导数。首个截面导数已通过非线性有限差分；每步要求物理状态合法，不允许剪裁制造解。闭合容差达到以后，仍需更换起始相位、减小时间步长并验证同一条解，随后才能计算Floquet乘子。

周期轨道的非平凡乘子跨过+1、−1或复单位圆，分别只是相应周期折叠/倍周期/Neimark–Sacker的候选，还要检查分支两侧及非退化性。若目标是混沌吸引子的危机，则还必须找到与相关不稳定集合/吸引域边界的联系；“事件变长”“有限时间无返回”以及“扰动增长为正”都不满足这个判据。

四段多重打靶同时求X_0到X_3与周期T，使每段原方程积分Φ_(T/4)(X_j)与下一段初态X_(j+1)完全一致，最后一段接回X_0；另加一个自主相位条件。每一段都保留原突触、输入方差和记忆、动态M，以及完整的延迟/不应期历史。段端的非整数时间用四个实际时间步的三次插值，变分方程使用完全相同的插值权重，周期导数也包括在联合Newton方程中。Krylov子空间用于解数值线性方程，不是把物理网络降成几个模式。

为减少重复计算，沿每段名义轨迹缓存float64局部响应导数；四段缓存存放在主存，逐段使用同一GPU缓冲区。已在四个不同起始相位与原全状态变分实现逐一比较，另对完整周期和状态联合方程做实际非线性差分。缓存、右预条件及信赖域只改变求解方法，不改变模型积分。非负边界限制只施加于数值候选初态；从不剪裁原方程产生的轨迹。每次候选还必须降低原始完整状态闭合残差。判定周期根要求每段联合误差<1e−7、各物理状态块<1e−6；相位、步长、Floquet和onset对应验收仍独立保留。

## 因果解释的边界

在原生SNN中只耗减A的干预支持核A持续这一方向，但两核量值与自主Z路径尚未完全一致。当前数学类型只能先归属于这套条件rate方程。核A持续期间B仍间歇、全局空间持续占据不足，因此不能把核A局部转变直接写成整个网络onset。
