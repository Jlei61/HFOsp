# Core A 资源分岔：当前科学核查

要回答的是：在原二维空间 rate 网络中，核A的Z耗减怎样改变活动自行终止的能力，以及真正起作用的分岔类型。全部连接、3479群体、0.5mm网格、物理时延、锁定响应函数保持；只改变原生核A内部Z空间图案，核外Z逐位固定native9s。每个参数点Z固定、全部M动态，原恒定均值输入，无未来放电创新。参数D_A=1−核A细胞数加权平均Z；局部持续和全局onset分别定义。

## 已确认的数学类型与适用对象

D_A=0.3531576413、Z_A=0.6468423587有一个非退化**平衡点鞍结**。原方程残差9.1e−15/ms；简单零模态、左右零向量、参数横截项和二次项均通过。含动态M和物理延迟的特征方程在0.05、0.025ms及连续表达式下的零频导数非零。这个点已可明确叫SN，不能再叫未定TP。

局部正规形及两支精确根共同确认：该对平衡态存在于D_A>D_c一侧，即随Z_A降低而产生；两个相接的平衡态都不稳定，另有约32.1Hz振荡模态增长约57.5/s。临界E零模态约99.82%在surround；平衡态核B约368Hz，而实际局部活动的B会反复结束。因此证书只证明这个SN存在，没有证明它导致所关心的实际跃迁。不能把它标为稳定静息态消失或原生onset边界。

## 实际状态的关键反证

D_A=0.34315764、Z_A=0.65684236的原0.05ms轨迹无重置续接70秒，A在0.467–64.830秒的活动最终结束，随后有89、132、169ms三段合格静息。原60秒“没有结束”是观察右删失；不能继续把这个参数当作已经证明的渐近持续端点。

从原60秒同一完整状态出发，0.025ms再续接5秒，也在64.521–64.682秒出现161ms核A静息。粗、细步完整状态扰动增长分别约8.03/s和9.69/s，去掉2秒对齐后的所有1秒块为正。它们支持该邻域仍有长活动后返回与敏感不规则动力学；不单凭有限时间正增长就声称渐近混沌或crisis。

另从64.650秒的粗步完整状态开始做局部两次减半，三条轨迹最初接近，细步误差起初随步长缩小，但0.025/0.0125ms在750ms内都未复现粗步的这次静息。因而具体返回时刻、长期寿命和临界参数尚未实现步长收敛；不能隐去这个阴性结果。两种较早完整续接都出现静息，与这次局部不复现是不同问题。

D_A=0.33563962的两种完整历史20秒内都返回，最后5秒都不返回，说明末窗也会错分。D_A=0.3281216已有两条30秒记录，包含9秒、16秒后结束的活动。终止时核A的M在下降，不能把它说成M上升越阈值；M和空间快速反馈的因果分量仍未单独分离。

## 周期分支能排除什么

一条短爆发的完整数值周期根已在0.05ms下延至D_A=0.32812、0.330、0.334、0.34316；周期约261.6ms，在这些采样点没有消失。D_A=0.334有直接完整算子验证的截面乘子−33.05746，残差1.7e−14；这说明该数值解不稳定，不是−1穿越的证据。

0.025ms、D_A=0.32812的周期根闭合1.22e−9，周期261.41656ms；独立四分之一相位闭合3.86e−6仍未达到原1e−6门槛。物理周期/Floquet验收不升级。细步D_A=.34315764也已闭合到5.79e−8，但独立四分之一相位1.23e−6略超原门槛。短周期根随后在D_A=.35315764和.36315764均闭合，后者周期262.582741ms、完整闭合3.72e−9，核A每周期仍约57.7%时间低于5Hz，独立四分之一相位3.31e−6仍未过原门槛。这证明数值短爆发根在实际70秒局部持续场仍存在，并未证明它是实际吸引态。此支的参数扩展到此收束。

原实际961ms连续A/间歇B结构的四段校正在保存完整已接受状态后停止，没有闭合证书；当前转向更强耗减70秒原记录中的172ms单B爆发和537ms三B爆发候选，均已从原检查点逐位重放，保留实际持续A/间歇B的结构。四段全状态周期校正采用精确循环M衰减逆作为数值预条件，全部M反馈仍在真实变分方程中。33ms候选趋向双核持续且未闭合，已经停止。数值预条件、导数缓存和提案投影均只改变求解方式，不改物理方程；辅助除根/同伦没有得到独立非对称根，不等于这种根不存在。

## 验收

接受：当前平衡SN的数学类型；原方程下的实际有限时间记录、全状态续接和独立读出；两种步长的完整轨迹确实返回；局部步长失败及其对临界参数的限制。原生单核资源干预只支持局部方向一致，核B量值和完整自主Z路径不等价仍保留。

不接受：把SN作为实际onset原因，宣称稳定周期、双稳态/separatrix、已定位crisis或已完成分岔主图。真正的自限—持续分岔类型仍为NOT_ESTABLISHED。更强耗减D_A=.36316已观察70秒，A在起始39ms后未出现合格静息，69.961秒活动仍为右删失；核B仍间歇。返回侧D_A=.32812的粗、细步控制均已完成，头5秒各有8段合格A静息。统一使用对齐后2–5秒窗口，粗、细步完整方向增长10.207/s和6.753/s；不是独立重复，也不单凭这些正值命名混沌或crisis。匹配窗口读出见actual_growth_same_window_contrast.json。
