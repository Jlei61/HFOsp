# Core A 资源场的连续延拓路径

原生 Z 在事件之间会恢复，故 D_A=1−核A细胞数加权平均Z 不是全局单调、唯一的路径坐标。旧 Family.field(D_A) 取9秒后第一次向上穿越。审计发现9--10.37秒间有3处跳接，其中 D_A=.27043518 的跳接从9125ms跨到9288.697ms，A内同均值场的最大差.0086195。临界分析不能把这样的取值跳接当作动力学分岔。

后续连续延拓以原生路径时间 θ 为内部参数：每两个相邻存储时刻之间，逐群体线性插值 A 核的原生 Z；A 核以外所有 Z 始终为 native9s。θ 只负责选择一个冻结参数场，单次物理轨道的全 Z 仍固定，所有 E 的 M 仍动态；θ 不是该轨道的运行时间，也没有注入未来原生放电。方程、连接、延迟、局部响应、M 方程与外部均值均不变。

图的横轴仍标 D_A=1−〈Z〉_A，但同一个 D_A 可能出现多个场，绘制时按 θ 的顺序连接，不按 D_A 排序跳接。显示坐标的回头不构成 SN，必须靠不变解/特征值及非退化条件认证。记录路径逐点连续；采样结点处导数可有折角，临界点应报告其原生 θ 段，并排除路径折角与物理失稳混淆。

固定场的既有仿真和数值根继续有效；变更的是它们如何组成连续参数路径，而不是重解释单点方程。当前重要的两端为 θ=9116.474ms（D_A=.270，20秒最长完整活动94ms）与 θ=9594.907ms（D_A=.300，有多段数秒长活动），中间包括原图③ θ=9420ms。下一固定场检验直接使用③的原生核A场。

另一个须纠正的来源标签：D0255722 数值短周期使用的是 θ=9015.710ms 的首次回升场，不是 exact native9000 场；两者平均相同、A内最大Z差.001353。因此它的−32.87766数值乘子不能直接称为原9秒参考场的稳定性。正在校正的 actual_reference_recurrence 六爆发种子来自精确原9秒场，未受此问题影响。D0270/D0300 的数值根与各自实际仿真仍使用完全相同的场。

实现：core_a_parameter_path_audit.NativeTimeFamily.field_at_time；periodic_newton 和 multiple_shooting 新增显式 --target-native-time。原 --target-D 保留以复现历史单点结果，后续路径延拓优先使用连续时间参数。
