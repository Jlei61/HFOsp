# 同一空间 rate 方程的数值积分修正

本目录检查数值求解器，不重新拟合或替换网络模型。此前一阶积分在相同完整初态下，dt=0.05 ms 给出短自限活动，而 dt=0.025 ms 给出长活动，因此原粗步的窄 Z 区间不能充当分岔括区。保留全部旧结果，先解决这个会影响科学判断的数值差别。

## 保留的物理定义

- 3479 群体、0.5 mm 二维空间网格，原连接图、阈值、物理传导延迟、私有输入方差和锁定的群体响应及瞬态修正。
- 各条件全部 Z 固定，全部 E 的 M 仍动态。只沿原生记录路径改变 Core A 内 Z，核外保持原生 9 s 场。路径时间只是冻结场的索引，不是新的外部驱动。
- `m = eta_M M`，单位 mV 等价量；`dm/dt = (0.5 r_E - m)/1000 ms`，r 的内部单位为 spikes/ms。没有固定 M，也没有把瞬态平均值代入它的平衡式。
- 原生恒定外部输入均值、无未来输入创新。该条件漂移模型本身的 SNN 对应性缺口不因数值检查通过而消失。

连续更新律为

\[
 r(t)=\rho(t)\left[1-\int_{t-\tau_{\rm ref}}^t r(s)\,ds\right],
 \qquad \rho(t)=e^{\ell(t)}/(0.1\,\mathrm{ms}).
\]

其中 ell 是原锁定响应得到的 log hazard。空间输入均值、方差、突触及 36 个输入记忆状态均保留。

## 指数中点更新

用已知延迟输入先预测半步突触、方差、M 和输入记忆，在中点计算原 hazard。对这个时间格内恒定的中点 hazard 和延迟释放通量，精确积分可用比例。若格宽 h，旧不应期占据量 R，释放通量 q，则

\[
 \bar r=(1-R)\frac{1-e^{-\rho h}}{h}
       +q\left[1-\frac{1-e^{-\rho h}}{\rho h}\right].
\]

保存的是格内平均通量，不是端点瞬时率。突触和方差滤波器使用精确线性更新，输入记忆使用中点特征，全步 M 使用格内通量。中点缓冲区不是额外的物理状态。算法没有裁剪物理率或不应期占据量；非法状态报错。小 hazard 使用等价级数避免数值抵消。

该更新在常 hazard 下保持原平衡通量 `rho/(1+tau_ref*rho)`。网格切换时将源通量格保守细分为同一个分段常数历史，保留每个源格的积分和初始不应期占据量；不用点值线性插值冒充完全相同的初始历史。周期延拓时的相位插值仍须独立检查。

## 已通过的检查及边界

1. `scalar_renewal_check.json`：已知正弦通量制造解、常 hazard 平衡和非负性。通常区间误差随 h 减半约缩小四倍；接近饱和的刚性例子只在更细步长才趋向二阶，不能忽略。
2. `spatial_identity.json`：两个网格的独立 CPU/GPU 单步逐块对照；原完整平衡根保持不变。
3. `short_spatial_convergence/analysis.json`：同一个完整初态，四档步长 0.05/0.025/0.0125/0.00625 ms，新旧方法共八条 120 ms 轨迹。将细网格历史按格积分限制到公共网格；20/60/120 ms 完整状态误差均显示新方法二阶，且新旧方法趋向同一极限。这不是长时吸引态或临界点收敛的证明。
4. `full_variational_check/result.json`：新更新律的完整变分方程。40 ms 超过最大传导延迟；两档网格的突触/M、方差/记忆和完整历史均通过中心非线性差分；变分计算不改变名义轨迹。
5. `cached_variational_check/result.json`：在实际中点状态保存 45 个 float64 局部导数系数，单独保留释放通量导数。两种方向、两档网格与原完整变分流误差低于 3e-14。缓存仅加速导数求积；旧端点算法的缓存不能用于新方法。

`reference_stability_gap/matched_short_history_numerical_limit` 是独立的 5 s 数值对照。新方法两档网格都出现长 Core A 活动，但事件结束时间和完整长时轨迹尚未收敛；不能把它写成已确定的临界参数。任何周期、Floquet 或分岔类型仍须通过完整状态闭合、独立相位、网格、临界模态和实际状态变化的对应检验。

6. `section_variational_check_offgrid/result.json`：两网格的分段完整变分与未分段返回导数差异低于 2e-13；包括隐式返回时间的中心非线性差分随扰动减半约缩小四倍。初始精确网格交点试验跨越了两个三次插值多项式，误差出现平台，原结果保存在 `section_variational_check/result_grid_knot_original.json`，已单独标为诊断而不用于验收。后续周期求解与谱均要求离开插值节点的独立检查通过。
