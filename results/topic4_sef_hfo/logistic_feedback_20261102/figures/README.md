### paired_clip_logistic_validation.png / .pdf

同一网络、同一噪声种子的旧 clip 与不同宽度的共享 logistic 连续仿真。从上到下为全体 E 发放率、两个 core 的抑制资源、平均适应电流和全局抑制；每行共用纵轴范围。虚线为持续高活动的进入时刻，灰区为60秒筛查停止后未继续计算的区间。
**关注点**：比较完整的发作、终止、间期恢复、再次进入，结果为单网络单种子机制检查。
