# Paper-Ready Figure Outputs

This directory collects figure outputs intended for manuscript assembly. Each
main figure or panel group should use its own subdirectory and should include a
`figures/README.md` explaining what the generated image shows and which output
file is the accepted version.

Current figure groups:

- `fig1_hfo_group_event_demo/` - compact Yuquan Y1 interictal HFO group-event
  example, generated by
