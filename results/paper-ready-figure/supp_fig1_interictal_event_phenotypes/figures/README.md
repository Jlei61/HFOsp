复用旧论文 Figure S2 的原始 TIFF：A 展示人工标注 HFO、spike 和 coupled 三类事件的平均波形、原始频谱及基线归一化频谱；B 展示三类事件的频率能量曲线。该图的源样本量为 HFO n=178、spike n=202、coupled n=296，属于 legacy 手工标注形态学/频谱验证集。

**关注点**：HFO 的主要高频峰约在 80–100 Hz，coupled 事件约在 120 Hz 另有高频峰；不能把该图概括成“三类都在 100 Hz 响应”，也不能把这组 legacy 标注样本量当作当前双队列分母。

**中文图注**：人工标注的间期 HFO、棘波与耦合事件具有可区分的形态和频谱特征。A，三类事件的单事件波形、平均波形以及平均原始和基线归一化时频图。B，三类事件的平均归一化频谱能量曲线；HFO 事件在约 80 Hz 处呈现主要高频峰，棘波以低频成分为主，耦合事件在约 120 Hz 处呈现独立高频峰。图中 n 表示历史人工标注验证集中的事件数。
