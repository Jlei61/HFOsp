# 定稿来源与恢复方式

`native_exports/`冻结已获作者确认的整图及A–I单图，保留原PNG/PDF/SVG，不重新栅格化或改变版式。正式入口build_fig4_current.py只验证与恢复这些原文件，无需数据盘、旧worktree或历史候选目录。

本目录其余数值快照与绘图脚本保留原始来源，用于后续科学修改和追溯。旧脚本的路径及版本条件是当时的绘图环境记录，不是当前正式发布命令；重新按参数绘制仍需按其原依赖进行适配。历史candidate路径的迁移映射见../historical_versions.json，完整旧包在归档。

A的两个core位置取E中两个边际密度峰，仅作为位置示意，不等于联合最优解或临床病灶。SEEG readout为SNN发放密度代理，不是新增电位前向模型；B–I数据与先前正式版保持。
