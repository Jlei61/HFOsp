## 总损失的真实定义

`J = (1/3) Σ_g D_off,g / s_g`，三组为 `rank_pattern`、`local_and_interrod_timing`、`participation`。患者特征均值、随机 Fourier 映射、时间归一化及校准尺度均来自原冻结目标 `training_objective.pkl`，SHA256 为 `7dfc4192163e94abe3214a5e0b6cbdc1c90463b24555061dcecd3a41e822b464`。

三个固定尺度依次为 **0.04485866893176316、0.043128270322858264、0.04559242266535053**。对每组特征 `φ_i`，令 `S=Σ_i φ_i`、`Q=Σ_i ||φ_i||²`、冻结患者均值为 `μ`，使用

`D_off = (S·S − Q)/(n(n−1)) − 2(S·μ)/n + μ·μ`。

这等价于原评分器的 `A−B`，其中 `A=||S/n−μ||²`，`B=(Q/n−||S/n||²)/(n−1)`。保留 signed `D_off`，不截断负值；每次重采样的 `n` 随抽中的时间块事件数变化，必须用该次的 `n(n−1)`，不能用 `n²` 或固定原事件数。

**彩色三线是原始描述性 MAE，不是 J 的三个代数加项。** 它们分别比较参与条件下的平均归一化 rank、同杆触点对先后概率和触点参与概率，原数值及每杆等权规则均不变。真实 J 的三个校准分量另外保存在 CSV 的 `J_component_*` 列。这批扫描没有后续 `J_joint`，不引入其他批次的损失。

与 C/F 可统一使用上述训练 J 公式，但不同实验的冻结映射及尺度仍可能不同，不能仅凭同名 J 声称校准完全一致。F 的误差带来自优化重复，I 的误差带来自同次仿真的事件块采样，统计单位不同。

## 实际最小值

在 13 个已测角度中，`J` 最低点为 **0°，1.6218772580**，主 bootstrap **SD=0.1280048258、方差=0.0163852354**。次低为 **+3.3333°，1.6587930289**，差 **0.0369157709**。竖虚线来自对原 13 个 J 值的 argmin，不是把参考参数强制指定为最优。

`J(0°)−J(+3.33°)` 的配对事件块重采样 2.5%–97.5% 范围为 **[−0.20943, +0.17397]**，跨过零；2.25 s 和 9.75 s 块长的敏感性结果也跨零。因此只报告实测网格最低点，不宣称唯一真实最优或独立验证通过。该范围是条件性重采样分布范围，不是选择校正后的置信区间。

J 的条件性采样方差在 **+20°** 最低，为 **0.0038897140**。原 J 与该方差的 Pareto 集为 **0°、+3.3333°、+16.6667°、+20°**。真实三个校准分量分别在 +16.67°、0°、−13.33° 最低，不存在总损失、所有分量和方差共同最低的角度；未经指定不增加方差惩罚权重。

## 方差的统计单位及实现验证

每角度只有一个 60 s 仿真，种子为 topology=2511、dynamics=847401。合格事件要求 primary 且整个窗口位于 1.5–60 s，保留每点 133–161 个事件；事件定义与正式旧 D 一致。患者 19,770 个 FIT 事件的目标嵌入保持冻结。

主分析将该 58.5 s 区间分为 **13 个 4.5 s 时间块**，每次有放回抽取 13 块，执行 4,000 次；不同角度使用同一组物理时间块权重，保留同一时段的共同变化，不把不同轨迹第 k 个事件配对。块内完整事件及触点联合结构保留，每次重算原 `D_off/s_g` 和 J，协方差包含在 J 方差内。

重复抽中一个块会产生重复事件“出现次数”。`S` 和 `Q` 均用线性重复次数累加，`S·S` 自然含乘积次数；去除的只是每个出现位置的对角项，不能用平方重复次数去除 Q。该实现已逐角度与**显式事件对核矩阵**及**不均匀重复时间块展开后直接调用原评分器**交叉核对，均在 1e-12 内吻合。全部 13 个历史 J 和 39 个真实校准分量也已重现，原三条 MAE 的 39 个值完整保留。

带宽是原样本 J ±1 bootstrap SD，不是置信区间；方差为重采样 J 的样本方差 `ddof=1`，不是三分量间的离散度。统计单位是同一轨迹内的时间块，不是独立网络或噪声种子，未包含患者采样和重新优化的变异。块可交换性及有限时间依赖是条件性假设；2.25/4.5/9.75 s 敏感性见 `i_block_sensitivity.csv`，0° 的 SD 分别约为 0.14922/0.12800/0.14693。
