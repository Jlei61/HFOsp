## 定义与可回答的问题

比较对象是 E1146 在固定其余参数下的 `EE_angle_offset_deg`，角度为相对基准连接方向的偏移量。每点为一次 60 s 仿真，拓扑种子 2511、动力学种子 847401；改变角度会改变实际 E→E 图，固定拓扑种子不表示边集不变。患者参考是冻结的 19,770 个 FIT 事件摘要。

`L_display = (mean_rank_error + within_shaft_order_error + participation_error) / 3`。

三项均为 [0,1] 范围量的绝对差，保持原数值和原来每项内部 SCL/ICL 等权，不作扫描内 min–max 归一化。Mean rank 是参与触点在单个事件内归一化 rank 的条件均值之差；Order 是共同参与条件下同杆触点对先后概率之差，相同质心时间计半票；Participation 是触点参与概率之差。每项先在杆内等权平均，再在两杆间等权平均；总误差再给三项相同权重，这是本候选明确采用的描述性权衡。

原训练 `J` 则等权平均经固定尺度校准的 signed `D_off`，对应 rank pattern、local/interrod timing、participation 的分布特征，保留负值；它不是这三个摘要 MAE 的平均。CSV 单独保留原 `optimizer_J`。这批方向扫描没有后续事件共现目标 `J_joint`，该列留空，不伪造或混入后续批次分数。

## 实际最小值与方差

等权显示总误差的实测最低点为 **+16.6667°，0.1311301099**，次低为 **+3.3333°，0.1320337377**，差 0.0009036278。各分量的最低点分别为 Mean rank **+16.6667°**、Order **0°**、Participation **−20°**；不存在三个分量共同最低的角度。原训练 `J` 在 **0°** 最低，值为 **1.6218772580**。

主分析的总误差 bootstrap 方差在 +16.6667° 为 **0.00003215874**，SD 为 **0.00567087**；方差最低点是 **+20°**，方差 **0.00002477511**。显示总误差与条件性方差的 Pareto 集是 +16.6667° 和 +20°；不指定“误差加方差”的权重就不存在唯一的综合最优定义。图中星号明确标记显示总误差的实测 argmin，不强制标在参考 0°。

两低谷的配对重采样差 `L(+16.67°)−L(+3.33°)` 的 2.5%–97.5% 范围为 **[−0.02169, +0.03017]**，跨过零。这是条件性 bootstrap 分布范围，不是独立验证或选择校正后的置信区间；不能将该经验 argmin 宣称为唯一真实最优。

## 不确定性的统计单位

已核对该完整扫描每角度只有一个种子组合；仿真重复方差不可估计。原始轨迹中先保留 primary events，再要求整个事件窗口落在 1.5–60 s 内，得到每点 133–161 个事件；重新计算全部 39 个误差值，与正式 CSV 在 1e-12 容差内一致。

主分析将 1.5–60 s 划成 **13 个 4.5 s 非重叠时间块**，以时间块为重采样单位，有放回抽取 13 块，共 4,000 次。每次重采样保留块内完整事件及所有触点/触点对联合结构，重新估计三个摘要误差与总误差；不同角度使用相同物理时间块权重，不能把不同轨迹的第 k 个事件硬配成一对。缺失触点或触点对支持不足的 draw 明确拒绝；本次三种块长度下各 4,000 个 draw 全部有效。

方差为重采样总误差的样本方差 `ddof=1`，保留三项的协方差，并核对等于三项协方差矩阵元素总和除以 9；**绝不是三个分量之间的离散度**。黑线是原完整样本的等权平均，灰带为该值 ±1 bootstrap SD，不是置信区间。原患者 FIT 参考保持固定，因此只描述这次模拟内的有限采样稳定性，不包含患者采样、独立种子、独立网络或重新优化的变异。

2.25、4.5、9.75 s 块长的敏感性结果见 `i_display_block_sensitivity.csv`。+16.67° 的 SD 分别约为 0.00818、0.00567、0.01164，三个差值范围均跨零，方差最低点均为 +20°。块长会影响绝对方差；本次仅在后 burn-in 块可交换的条件下解释，不能由单次 60 s 轨迹证明长时间平稳性。
