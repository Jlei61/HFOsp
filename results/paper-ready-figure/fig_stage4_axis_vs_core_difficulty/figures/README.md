# 挡轴 vs 打灶 + 自发难点图（Topic 4 cm-SNN）

两张图都是**模型内单轨迹 + 小扫描的机制/效率示意**（visual diagnostic），不是"电刺激治发作"的临床证明；runaway / tonic 饱和**不是**真的 ictal 事件。

### difficulty_3row.png

回答一个铺垫问题：**为什么不直接让一个自发的灶自己发作、就地做刺激？** 我们把一块很容易兴奋的脑组织放在那儿，只靠背景噪声让它自己放电（不从外面戳它），看它会怎样，比三种底物：一个大而均匀的热核（r=6）、一个小而均匀的热核（r=3）、以及外部按节奏戳出来的两灶。每行左图画"每个位置第一次放电的时刻"（早=紫、晚=黄），右图画整体放电率和一个"抑制油箱"`q_I` 随时间怎么变。结果：大核在 23 ms 整片**同时**炸成一次事件、铺满整片（无从中心往外的梯度）；小核在 42.8 ms 从中心往外扩，但前锋一路**铺满到边界**（也是一次事件、铺满 100%），只是比大核慢一点；只有**外部戳的两灶**能先冒出 **3 次分开的小事件**（`q_I` 分 3 档一级级往下掉、左图上下缘保持灰色=没点着=被控制住），一直磨到 757 ms 才塌进失控。

**关注点**：自发单灶只有"整片同步爆"或"前锋铺满"两条路、中间没有"一串分开的小事件慢慢累积"那条路——所以做刺激实验的事件串必须**外部戳**出来（右下 `q_I` 的 3 级台阶就是被戳出来的那串）。根子是"要能自燃就得过自持阈值，可一过就铺满停不下来"这个矛盾。

### axis_vs_core.png

回答临床落点：**在固定电极预算下，把刺激挡在"活动往外传的必经窄通道（轴）"上，效果能不能至少不弱于打在"发作源（灶）"上？** 两种刺激用**同样多的 4 个电极**，比谁把失控（runaway）推得更晚。上行=外部戳的两灶（引用已提交的 E1146 结果，不重跑）：灶通常比预算大盖不全，打端点只掐掉一个灶、剩下的灶和中段走廊照样磨 `q_I`，把失控推后 +414 ms；把同样 4 个电极压在**中段走廊**（两灶之间的唯一咽喉）上，两灶的事件都传不过去，推后 +834 ms——**挡轴 ≥ 打灶**。下行=一个**小的中心核**（新跑的诚实检验）：打灶把失控从 42.8 ms 推到 +37 ms，挡轴只推 +8 ms——**这里打灶反而更狠**，因为中心核是往**四面八方**径向漏的、没有单一咽喉，挡轴只堵住了 montage 那条轴的两个方向、其余方向照样漏出去。

**关注点**：图的结论是**有条件**的——"挡轴 ≥ 打灶"成立在**有单一咽喉**的多源几何（两灶+走廊），在**单个中心核**这种没有咽喉的几何里如实报告为**不成立**（这是预先说好的压力测试，不是 bug）。公平性由"两臂都 4 个触点、且灶盖不全（4<5 个源触点、留 1 个残余源）"保证；小核几何里残余源那颗触点在图上以灰点显示、落在核圈内。
