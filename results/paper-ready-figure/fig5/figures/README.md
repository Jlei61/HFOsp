# Fig5 · data-driven 底物上的低活动到 runaway 连续轨迹

这一版是**基础版**：只讲同一条轨迹上发生了什么。没有 KMeans、没有扰动、没有空间零假设、没有 12 个正式种子——那些是后续扩展面板。

底物是冻结的 data-driven `Node + E→E + E→I`，慢变量（失抑制 z 与疲劳 m）全开。种子 1801 是三个探路种子里进入时刻的**中位数**（3877 / 4115 / 4541 ms），按规则选取，不是挑好看的。

### fig5-data-driven-zm-runaway-transition.gif

连续单轨迹的可视化诊断，一行三列：**左**是慢变量净场（失抑制减疲劳），**中**是同一时刻的二维兴奋神经元发放率场，**右**是同一条 15 触点连续读出，从间期样事件一路画到进入持续高活动态，中间没有拼接。红虚线是进入时刻（4115 ms），灰底区是进入之后。左中两格的白线是病人的间期传播长轴，圆点是 15 个触点（沿轴杆橙色、横轴杆青色）。

**关注点**：先看右侧前 4 秒是否始终是一个个分立的、能回落的小事件；再看左侧净场是否逐步累积（实测全场均值从 0.8 涨到 148，且**累积主要在周边而不是病灶核**，因为核内神经元自身放电积累的疲劳电流把失抑制抵消掉了）；最后看中间的二维活动是否在同一条轨迹里铺满全场。

## 必须一起读的边界

- **"进入持续高活动态"是操作性定义**：群体发放率的 20 毫秒平滑值 ≥ 120 Hz 并持续 ≥ 100 毫秒。它**不是**临床发作起始，本图不主张复现了临床发作，也不主张恢复或终止。
- **右侧不是电压**：那是 15 个虚拟触点的**放电密度包络**，不是突触电流意义上的场电位，更不是 SEEG 电压。
- **重放与被分析的那次跑批逐位一致**：触点包络、群体活动分数、进入时刻三项全等（记录在 `fig5_replay/*_frames.json`），帧记录不消耗随机数。图上展示的就是被分析的那条轨迹。
- **2 秒那个存档点不叫 baseline**：实测该处发放率已高于同种子慢变量关掉时的支持区间上界（37.3 / 63.6 / 49.7 Hz 对 29.9 / 30.1 / 30.6 Hz，每条参考轨迹 40 个非重叠窗）。符合定义的低活动窗在 500–1000 毫秒。本图不使用 baseline 一词。
