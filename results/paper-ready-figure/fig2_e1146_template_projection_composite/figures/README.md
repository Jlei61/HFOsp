左图显示 E1146 的 ICL/SCL 两根空间 SEEG 电极。每根植入载体及其空间接触点严格排在同一条最佳拟合直线上，并统一使用金属灰样式；原始坐标相对直杆的小幅偏差只被视为定位误差，不再把空间电极画成折线。为了在二维版面中显露近共面的 ICL 杆和 SCL 杆穿过切面的关系，切面仅在左图中沿法向下移 1.2 个显示单位：SCL 穿面点以小圆点标记，切面下方的短段使用淡虚线；这一显示偏移不改变任何二维坐标或场。平面落点保留 E1146 原始接触点的二维投影坐标，但只用无边框、低透明度的小灰点表示，投影连线也相应弱化；它们只是辅助映射，不与中图的实心场节点共享视觉权重。观察方向采用 32° 俯角和 −95° 方位，使两根杆在版面中更平，同时保留投影距离所表达的空间深度。

TA 与 TB 是两个模板各自独立的方向向量，因此使用两个不同起点绘制成长而细的箭头，标签采用常规字重。两支箭头均位于两根空间杆之间：TA 位于左侧并朝蓝色端方向，TB 位于右侧并朝红色端方向。它们共同指向画面内部，但不共享空间起点。本图不绘制共享主轴、夹角楔面或圆弧。

仅在左图的空间杆上，TA rank 最早的 3 个触点以红色表示，TB rank 最早的 3 个触点以蓝色表示；共同入选的 SCL9 使用红蓝半分圆点。红蓝触点与其他空间电极触点使用相同尺寸和深灰描边，不增加白色外圈。该颜色不传递到平面投影、中图或右侧场图，避免把起始端标记误读为空间支持或场值。
