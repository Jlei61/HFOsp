## 单坐标轴与两核联合动力学修订

### 05_native_core_a_b_simultaneous.png / .pdf
两核曲线来自同一原生40000细胞网络、同一运行文件及相同4–7秒窗口；固定拓扑2511、阈值幅度1、噪声848101。每核分别按自身E细胞数720/742归一化，未对波形移相或跨运行拼接。
**关注点**：不同条件下的招募幅度和时序可分别变化；率相近不能单独证明同步或固定相位差。
