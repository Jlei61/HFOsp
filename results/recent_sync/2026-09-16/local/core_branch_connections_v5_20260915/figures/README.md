# 核内周期分支连接与分岔

### 00_connected_core_bifurcation.png / .pdf
单坐标轴显示原平衡分支、稳定周期均值与峰谷，以及延拓得到的不稳定周期均值。LP1为周期轨道鞍结，PD1–PD3为倍周期点；均值线的陡升本身不作分岔证据。
**关注点**：实线与虚线表示稳定性；编号1–4仍是原生SNN的实际均值坐标。1.176附近的低周边活动周期族与招募周边活动周期族不强行补线。

### 01_connected_bifurcation_four_states.png / .pdf
上方为同一单轴分岔图；下方是低活动、不规则burst、中间态、规则burst的原生SNN波形与raster。四个编号与主图逐一对应。
**关注点**：下排不是降阶周期轨道生成的伪spike图，不能将不稳定周期支等同于原生SNN的irregular状态。

### 02_connected_period_means_linear.png / .pdf
线性纵轴分别展示同一联合系统的A核和B核完整周期均值。两侧延拓的连接检验使用全部六群体波形和周期，而非只凭均值相交。
**关注点**：多次折返属于已延拓的不稳定周期支；同一参数下多个稳定轨道可共存，不能画成唯一状态随参数的单值函数。

### 03_continuous_waveform_doublet.png / .pdf
对1.244–1.254加密后，A核波形先延长，再出现第二峰，完整周期变化很小。两端在J=1.2462求得相同的六群体周期解，且局部Floquet抽样均稳定。
**关注点**：第二峰增加每周期放电面积，使均值迅速上升；一个周期内双峰不是周期翻倍，未发现这里有局部轨道分岔。

### 04_critical_floquet_multipliers.png / .pdf
LP1的非平凡Floquet乘子到达+1；三个PD点的实乘子穿过−1。自治相位方向在Poincaré截面上投影去除，临界条件另由周期/反周期线性化零空间独立确认。
**关注点**：只把临界附近已计算乘子画成点；极强不稳定区的单周期传播可能病态，不能据其浮点误差判定新的临界点。

### 05_critical_right_and_left_modes.png / .pdf
左列为周期边值问题的临界右率模态；PD使用反周期边界条件，LP使用相位约束后的固定参数零模态。右列给出对应伴随率模态六群体的平方范数比例。
**关注点**：这是六群体降阶模型的模态分量，非原生SNN逐细胞eigenvector；LP还含周期变化分量，右列只比较率分量。

### 06_period_doubled_branches.png / .pdf
从反周期临界模态切换到2T周期边值问题，并用非零半周期差排除重复两遍的T周期解。PD2子支位于母支稳定侧且不稳定；PD1和PD3在降低J时产生稳定2T子支。
**关注点**：超/亚临界判断依赖实际求得的子支方向与Floquet稳定性；参数窗极窄，须使用局部坐标查看。

### 07_switching_after_bifurcations.png / .pdf
从临界周期轨道的完整延迟历史出发，小幅提高J并积分8秒。越过LP1后到达A核burst/B核高率状态；越过PD2后到达两核高率振荡。
**关注点**：这是给定初始历史和参数阶跃的去向，不能把局部分岔定理解释为对所有初始条件都只有一个去向。

### 08_stable_unstable_periodic_extrema.png / .pdf
补充展示同一批稳定与不稳定周期轨道的A核最大值、最小值，作为完整周期均值图的经典极值分岔读出。所有极值来自周期波形的傅里叶重采样。
**关注点**：均值、峰值、谷值是同一条周期支的不同投影，局部投影折返不应自动当成新的动力学分岔。

**关注点**：候选图已供本地自查，仍待用户目视检查。
