# 候选图说明

### fig5_spatial_z_bifurcation_single_axis.png / .pdf / .svg
按旧单轴分岔图形式展示当前 Fig.5 网络：横轴为空间 Z 耗竭、纵轴为全 E 群体放电率，蓝线是实际求解的 v1 平衡族，绿色为原生冻结 Z 的峰谷，橙色为原生均率。蓝线不编码稳定性；图中核验的折点属于近似模型的高率平衡支，③的 irregular burst 分岔尚未定位，v1 对原生爆发的对应验证仍失败。
**关注点**：不要把绿色峰谷当作周期解包络，也不要把蓝色高率折点当成③的分岔。

### fig5_spatial_z_bifurcation_preview.png / .pdf / .svg
上方与单轴图使用完全相同的数据，下方补充三个代表性冻结 Z 条件的最后 4 s 原生全 E 率轨迹。它展示峰谷点的时序来源，均为已有续接数据，无新增原生仿真。
**关注点**：平均率不能替代爆发结构；③场仍有明显的时间起伏，后面的高率场持续占据高活动水平。

### fig5_z_branch_continuation.png / .pdf / .svg
此图属于瞬时方差敏感性模型的分支延拓，标题已明确标出其与原冻结 v1 的动态差别。真正保留方差滤波的当前候选图在 `../frozen_filtered_v1/figures/`。
**关注点**：不得把此图的 H1/H2、周期振幅或稳定性作为冻结 v1 的数值。

### fig5_z_branch_continuation_physical_range.png / .pdf / .svg
同一瞬时方差敏感性计算的物理 Z 区间放大图。它没有通过原生状态对应验证，不能用于给③命名分岔。
**关注点**：当前候选请查看滤波方差子目录，保留本图仅供模型敏感性追溯。
