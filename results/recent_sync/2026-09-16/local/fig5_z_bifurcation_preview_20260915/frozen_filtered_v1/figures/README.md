# 当前 Fig.5 投影模型：分支图候选

### fig5_z_branch_continuation.png / .pdf / .svg
完整空间 Z 路径上的分支图：蓝实线为检查过的稳定平衡支，红虚线为不稳定平衡支，灰点线为动态稳定性未判定的平衡支；绿色与橙色为求解的振荡波形极值和均值，插图放大这两族振荡支。横轴沿真实逐细胞 Z 场插值，纵轴为全 E 群体平均率，③的位置单独标出；灰底 Z>1 是超出资源物理范围的数学延拓。
**关注点**：这是当前滤波方差 v1 的探索性数学结果，尚未解释原生③的全局同步 irregular burst；绿色不表示周期支已通过稳定性判定，曲线末端也不表示新的分岔。

### fig5_z_branch_continuation_detail.png / .pdf / .svg
放大同一组低态平衡与振荡分支，标出核 B、核 A 主导的两个振荡失稳点，以及随后的低态 saddle-node。两个振荡族共展示 13 个收敛参数点，振幅/相位约束和加密相位网格残差已检查，仍未判定周期稳定性。
**关注点**：三个标注点均落在 Z>1，不能把其中任何一个直接称为③处的分岔；本图范围不包含③，其位置需看完整路径图。
