# 最初空间序列的 Agent 目视检查

已逐图查看 `native_storyboard_sahp4_g0.5_s9108401.png` 与 `native_storyboard_sahp2_g0.5_s9108401.png`。原生20×20计数确实显示高率带在空间移动，而不是电极readout造成的模糊：A附近出现的条带向左下移动，另一段经B附近向右上/上边界移动，先前活动位置会退出高率。

gain4在约2s后初期空间活动消失；gain2在3s仍有B附近的活动，5s快照已静默。但两者最初波前都接触了场边界，因此不能仅凭最终静默认定全局反馈在场内部消灭了波前。局部高率明显时，全E均值仍可低于原200Hz入态标准；这个标准不能用来否认局部传播，也不能事后放宽后把它直接记作原定义的发作恢复。

这些过程从仿真初始化附近开始，当前尚不能代替“先有稳定间歇事件、随后资源演化造成入态，再自主退出”的Fig5验收。需要继续检查40s完整连续记录中的后续活动，区分仅有初始化暂态、持续抑制和自主再入。当前为Agent空间自查，不代表用户人工验收通过。
