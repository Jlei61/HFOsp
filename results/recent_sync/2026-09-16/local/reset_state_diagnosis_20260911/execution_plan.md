# Zreset 后再进入 runaway 的定位实验

固定当前历史手放双核、40,000 神经元和原始输入模型；ηM=0.02、τM=2秒、τZ=5秒。此处沿用本对话的 Figure 5 底物，不切换到正在另一分支优化的患者传播模型。

**用户再次确认：以之前完整Figure 5验收。** 必须用同一轨迹对应①–⑤、原生电极读出、连续raster、同轴Z/M及空间招募；局部诊断或一次阈值越过不替代整图。[完整验收标准](figure_acceptance.md)同时规定E1轨迹与E2固定Fig3C参考的含义。

## 顺序及判读

1. **延长原轨迹**：从完整238秒检查点续算，重演238–240秒并核对已有结果，继续到绝对时间1000秒。若再次进入高态，保留确认后5秒，分析局部放大、Z分布和等待时间；这将直接排除本次reset使网络再也不能进入的解释。
2. **仅增加M清零**：仅当第一步在观察上限前未再次进入时，回到原始76.5秒释放点，将全部E神经元M清零一次，立即恢复M方程。Z同样补满，膜电位、不应期、AMPA/GABA、延迟历史、全局与空间OU及其随机状态均保留，继续到相同的1000秒上限。
3. **检验M作用是否可重复**：如果只有M清零分支再次进入，追加3个配对后续噪声实现（9109401–9109403）。每个实现同时运行Z-only与Z+M，观察释放后500秒；每一对使用相同的OU起点和随机数状态，报告进入情况与右删失等待时间，不将3对试验升级为永久稳定性证明。
4. **定位其他初始状态差异**：若前两步均无再次进入，同时检查Z/M加全部快状态清零，以及原始完整初始化回放。前者保留释放时的OU状态与随机历史，后者重现原始随机序列；回放不是新的独立样本。若清除快状态后能进入，再拆成膜电位/不应期与突触/延迟两组，定位对演化有影响的状态。

高态判据保持为10ms全E放电率≥200Hz持续≥200ms。认定“再次进入”之前，必须先出现连续两个1秒窗：每窗平均E率<50Hz，且低于5Hz的10ms窗比例≥20%；未达到恢复条件的持续高活动单独报告。每条观察到再次进入后再保存5秒，否则报告有限时间窗内未见，不能证明永久不进入。

## 实施与验证

已通过75.5–76.6秒及238–240秒的逐项重演：原生放电计数、固定抽样raster、区域计数、空间计数、电极读出和Z/M均一致。M清零应用检查确认Z不变、所有E的M归零、I不变，膜电流差恰好等于移除的ηM·M；检查记录见[qa.json](qa.json)。

每10秒保存观测块和完整状态检查点，最多3个worker；本轮不调整静态网络参数、不重采样双核或连接。运行中保留阶段状态，完成一个条件自动生成分析和比较图；条件流程结束后停在科学审阅点。
