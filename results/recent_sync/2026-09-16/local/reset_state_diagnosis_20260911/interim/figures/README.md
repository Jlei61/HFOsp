显示完整已保存轨迹的全E及两核放电率、Z和适应电流；绿色标记唯一一次Z补充及释放。全程概览的放电率采用500ms均值，避免密集短峰被误看成高平台；局部对照和高态判据仍使用10ms分箱。只绘制闭合观测块，时间终点写在图内。
**关注点**：长窗中期记录不构成永久不发作或稳定吸引子的证明。
