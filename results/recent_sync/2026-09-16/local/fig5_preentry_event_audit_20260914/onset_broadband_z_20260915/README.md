# Fig5 模型与患者的早期 broadband robust-z 场

F左使用当前模型首个持续高态起点后1秒；基线为0.5–3.5秒，包含5个完整的1秒PSD窗，hop为0.5秒。先对15个模型虚拟触点做CAR，再逐触点计算1–150Hz PSD之和的自然对数，按基线median与1.4826×MAD得到robust-z。复用的是当前Fig3C公式和绘图函数；模型短基线阈值由患者50帧改为5帧，不能视为相同统计精度或已验证的10倍时间映射。

患者仍用每次发作原本的CAR、EEG onset前120至90秒基线，以及clinical onset后0–10秒。25个完整精确1–150Hz病例已按当前冻结场重新核对checkpoint；按共同15触点的固定shared-A核平滑后有方向Pearson相关排序，无镜像、无符号翻转。预先要求患者平均z>0；本次两个选中病例也分别是全部25次发作中的第一名。
