## 科学问题与当前结果

不能从Z下降直接推出独立间期事件的次数必然递增。有效抑制为逐细胞Z乘以GABA输入，事件访问还受输入与快网络状态影响；本轮先对实际连续轨迹检验时间关联，没有做冻结Z的因果试验。

统计单位为同一拓扑上的一个噪声实现；两个种子按参数配对，不将几十个事件当作几十个独立网络。早期窗0.5–3.5秒，晚期窗为首次高率起点前3.5至0.5秒，都是3秒，排除持续高态。有限事件需前后都有至少20ms低于5Hz的静息，活动至少20ms、峰率至少20Hz；统计事件起点数、持续时间、真实连续静息间隔、活动占时。补做5ms分箱与1Hz静息阈值敏感性。

## 图的变化与范围

子图左列A–C、右列D–F顺序编号，坐标标签21pt、刻度18pt；两个core的固定采样神经元占据raster约70%高度，增加同一数据的300ms放大窗。Z与有效M共时轴；四个状态在raster、ZM、实际3D轨迹与50ms原生场图中逐一对齐，M右轴两条件共用0–0.5 mV等效范围。

状态2取自限事件的早期招募相位；展示选择不进入优化目标，也不能证明整次事件只限于core。减半M种子1在4.005秒主要是Core A先起，随后Core B被招募，放大窗可见时序；当前两个减半M种子的选中帧均不是两核同时高活动。旧ηM=0.001种子1的4.060秒帧可见两核较局限激活。旧种子2在2–6秒没有达到65% core邻域放电占比的帧，保留最高实际占比62.9%的帧并在metadata标为未满足展示筛选条件，未修改神经元或场。

Entry取全E最后一次至少20ms静息结束时刻，它所属的活动段随后不再自限而进入高态。减半M种子1为9.420秒，种子2为9.260秒；达到全E≥200Hz持续200ms的高态起点均为9.870秒。原生网格在20Hz阈值下的激活面积，减半M种子1为状态2约2.5%、Entry约13.3%、高态约74.5%，只用于描述，不是训练目标。

D为随机SNN实测轨迹，不是vector field或已证明的分岔。E合入新ηM=0.0005实际测得的两个首次终点，48个终点/24个实测格；本格40秒内两次均观测到事件，无删失，其他旧180秒观察窗及未测灰格保留。

F保留旧三联语义：两个模型先行事件家族与同一次early高态未滤波电流代理平方均值增量ΔP。减半M种子1有3触点为轻微负值，保留负号与发散色条；ΔP仍主要包含电流均值抬升，不能写成频带振荡增强。模型家族没有替换成患者TA/TB标签。
