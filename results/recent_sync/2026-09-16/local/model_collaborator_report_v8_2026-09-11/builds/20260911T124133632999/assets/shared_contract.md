**结论边界与教训：** 把相同的 core 名称、XY 或 mask 当作相同物理假设，是本线的实质失误；公式、形状和缓存一致性都不能代替最终应用参数与科学定义的核对。旧文档已经承认参数化等价需要检验，后续却没有持续保留这一差别。当前混合阈值场结果只能解释该实际模型，不能用于断言用户定义的纯降阈值双核无法恢复 TB；同时不能断言升阈值就是全部传播缺口的原因。旧轨迹、观测层诊断和原始手放结果保留，不倒改、不一概作废。

## 1. 核心问题与统一表述

患者间期事件的分布分析已提供传播方向、传播轴及两端候选区域的信息，经研究者核查后，用端点区域的空间几何中心初始化 core。由此建立患者几何引导的共享网络，再用多事件观测分布拟合 core 的范围、中心偏移及底层有效参数，研究这些参数如何影响患者个性化传播模式。

**统一表述：以患者间期传播几何为先验，拟合能够生成患者相容事件分布的有效网络配置，并通过配对参数干预和独立重演分析传播对网络设置的依赖。**

这一路线保留手放双核已经获得的空间信息，并允许数据修正其范围、位置和连接参数。主要任务是“已知粗传播几何下的网络实现与参数作用”，不再默认把“完全从零发现 source 位置”作为 Figure 4 的任务。历史双核初值具有经验依据，但尚未被证明是最优 XY；自由场探索中的正、负结果仍保留为能力和方法参照。

## 2. 先验、拟合与验证各负责什么

| 层次 | 输入或可调内容 | 要回答的问题 |
|---|---|---|
| 患者几何先验 | 经核查的端点区域、几何中心、传播轴和接触点映射 | 从什么共享空间结构开始建模？ |
| 患者分布拟合 | core 范围与中心偏移、阈值调制、EE/EI 等连接强度、连接各向异性等 | 怎样的有效网络设置能够同时改善患者的参与、顺序、时差与空间联合分布？ |
| 状态与访问机制 | 同一结构下不同局部状态及固定规律的随机输入 | 两种条件传播能否在同一网络中产生，怎样被访问？ |
| 参数作用与独立验证 | 同网同噪声的配对干预、新噪声/新拓扑、患者留出事件或记录块 | 改善是否稳定、具体改变了什么，以及哪一部分仍未恢复？ |

数据给出的是观测支持的传播端点与轴，组织真正起燃位置仍需时间分辨证据。双向传播可以共享一条轴；连接轴向先验本身不规定每次事件的传播方向，也不把两个 core 编号直接等同于 TA/TB 标签。

## 3. 先验与数据的权衡

初始化只决定搜索起点；持续的先验约束由允许偏移范围或显式正则表达，两者需要分别说明。当前小规模 pilot 采用固定几何初值加有界局部变化，尚未实施概率先验或新增几何正则项。

后续每版设计应写明：哪些患者几何量固定，哪些可以调整；各自的单位、偏移范围或惩罚强度；哪些来自数据，哪些是工程搜索范围。数据更稳定的结构可使用更强约束，不确定部分保留更大调整空间。不得把人工设定的搜索边界写成已估计的患者置信区间。

先验来源必须能追溯到患者、记录块/事件、参与掩码、模板或端点算法、坐标映射及数据划分。历史几何若不是仅从 TRAIN 得出，应明确为 development prior；不能事后宣称它与患者留出集独立。先验已使用的轴或端点不能再单独充当独立恢复证据。

本次允许使用患者粗传播几何初始化和约束模型，更新了此前“不能把任何端点信息用于初始化”的过宽理解。细粒度的命名路线、某一个示例事件的逐站顺序、指定时刻刺激等，不因这项更新自动成为训练目标。路径约束若另有设计改变，必须明确其输入身份；不能把输入过的路线再称为独立验证。

## 4. 可拟合的参数与机制含义

| 参数组 | 后续设计可考虑的自由度 | 解释时必须区分 |
|---|---|---|
| 双核空间范围 | 两核各自半径/尺度、必要时形状，以及中心附近的偏移 | 起源候选位置与能够招募的范围；两核不必同大 |
| 阈值场 | 非正局部阈值偏移的幅度、散布及实际神经元成员 | core 表示局部易激性增强，不保留升阈值尾部；不等于硬性独占起源区。历史正负混合场见上方修订 |
| E/I 连接 | EE、E→I、I→E 等有效强度，适用时区分局部与全局 | 改的是哪条通路、哪个空间区域；全局乘子不能解释成局部连接已被识别 |
| 连接各向异性 | 参考轴附近的方向、轴比和作用范围；如实现支持再考虑空间位置等 | 名义轴与实际加权连接几何；“长轴位置”必须对应具体可执行参数 |
| 状态/动力学 | 已有局部状态、时间常数等有物理依据的维度 | 固定结构、外加状态和内源演化；不同分支保持独立身份 |

这些是可分版本纳入的参数组，不表示当前一次性联合优化了全部维度。先完成正在执行的范围/中心 pilot，再根据残差安排连接或其他参数实验。局部 HFO 包络宽度与模型 burst 持续时间的读出关系尚未完全建立，不能仅通过调 GABA 把两者强行视为同一个量。

## 5. 评价原则与 Figure 4 的证据链

**传播几何提供初始结构 → 事件分布拟合改善工作点 → 配对参数干预解释变化 → 独立重演与患者留出数据检验稳健性。**

1. 拟合对象是多次事件形成的分布，而非要求单个事件同时满足两种模式。分别报告参与、rank/顺序、毫秒时差、空间结构的均值/中位数、散布和联合关系；整体与 TA/TB 条件分布都保留。有限事件中的少数模式缺失先报告支持量，不能自动判定机制不存在。
2. 当前冻结损失用于选候选，损失降低不能替代原生传播与完整读出的验证。明确哪些量进入损失、哪些作开发诊断、哪些在提名后或患者留出数据上检验；看过的开发 GIF 不再称作盲验证。
3. 保持 SEEG 布局，提供同一网络的多事件展示、患者对照及时间分辨原生场。检查 SCL/ICL 招募是否补足，同时保留合理相对顺序，是否通过增加并行热点或读出筛选获得表观改善。质心、起始时间、局部持续时间和跨区招募跨度分别解释。
4. 参数响应先在同一网络、配对噪声条件下比较，再在多个噪声和拓扑上检验。事件是网络内样本；新模型噪声重演检验模拟稳健性，不等价于患者留出记录泛化。
5. Figure 4 既展示拟合工作点，也展示“参数 × 观测”响应及取舍。历史几何参考持续保留在对照中，不能因联合损失未进前三就从关键传播对照中消失。多个相容工作点可以形成可行参数族；拟合不能唯一识别患者真实机制。

推荐成果表述是“患者传播几何约束下的个体化有效网络模型”和“模型内参数作用”。当前不使用“已找到真实 SOZ 内部设置”或“已识别患者因果连接”。传播端点与临床 SOZ 分开，临床对应需独立证据。后续 Figure 5 消费具体已核验的基底版本，间期拟合、外加状态响应、原生 Z 演化、runaway 与分岔类型分别验收。
