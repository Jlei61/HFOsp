# 连续原生场中的短暂旋转检测

**结论：确认存在短暂的波前卷曲及圆周活动绕行；存在相位奇点支持的螺旋样候选，尚未确认自维持或持续重复绕行的螺旋转子。** 两核近同步之后发生波前相遇，是本例形成旋转的合理解释，但这次离线观测没有单独启动/抑制任一核的因果干预，不能认定碰撞为必要原因。

上一轮仅抽查两段稀疏帧，不能排除 GIF 其他时段的旋转；本次完成了实际检测。短暂螺旋也不能仅因不足一整圈而被排除。这里分别报告原生卷曲、相位绕行及持续转子证据，不把单一圈数阈值当作完整物理定义。

## 对象、单位与比较

分析此前实际展示的两条连续 GIF 对应原始轨迹：候选 `coreOU_mid_EE085_mean095_rho000`，同一拓扑 2511，动力学噪声 847101/847102，各固定 1.5–7.5 s，共 6000 个原生帧。每帧是 2 ms × 1 mm 网格中至少发放一次的 E 神经元数，全部核内外活动都保留。不消费患者、TA/TB 标签、事件资格或选定 lineage。相位候选轨迹不是独立实验样本，两个噪声也不是两个拓扑。

7.15 s 示例中，3 ms 高斯平滑后的左核、右核群体放电峰分别位于 7149.9、7147.9 ms，相差2 ms。原生图可见两核附近活动及其外向波前，随后在中下部接近并形成弯曲亮带；在右核上方的固定测量圆周，亮带方向连续绕行约259°。峰值不是起始时间，核外波前身份也不是逐突触因果 lineage。

## 检测及反证

主筛选采用 3–50 Hz 带通后的 Hilbert 相位与网格闭环 ±2π 绕数，连续追踪同号奇点，允许每2 ms移动不超过1.5 mm、不补轨迹空隙；≥40 ms只是候选展示约定。此类相位方法参考 [Huang等2010的皮层旋转波分析](https://pmc.ncbi.nlm.nih.gov/articles/PMC4433058/)，本研究信号是模型发放计数，不能照搬原研究的生物学验收。

主设置每个方向空间平滑0.5 mm；3–30 Hz与无空间平滑3–50 Hz条件下，上表三个候选在主轨迹每帧2 mm内都有同号奇点。2–25 Hz条件更敏感：对应匹配比例分别为16%、78%、12%，说明检测位置及持续时间依赖时间表征；不写成全频带稳定转子。

另用未带通的原生计数（仅3 ms时间、0.5 mm空间平滑）及6/10/16 ms延迟构造前沿/尾部相位坐标，考察3/5/10个活跃细胞的门限。它也在所示位置附近检出短暂波尖轨迹；这支持现象不完全由带通滤波产生，但该延迟坐标不是实际抑制/不应期场。

**重要反证：** 解析平面波、单中心扩张波没有产生长期相位奇点；解析旋转波被检出持续6 s，圆周方法追踪约30圈。但两组同心脉冲的线性叠加也产生了≥40 ms奇点，并可出现约0.89圈的圆周活动变化。因此“有奇点 + 绕过半圈”仍不足以单独判定自维持螺旋。不能把主检测65/90条候选轨迹写成65/90个真实螺旋事件。

在本次四种相位设置、两个原生片段中，可连续读出的圆周弧段最大仍不足一周；没有建立反复完整绕行的证据。这是当前采样分辨率和检测设置下的证据边界，不是该网络不可能产生持续螺旋的证明。图中轨迹可能断裂、中心可能漂移，有限记录和活动支持也会影响可读圈数。
