# TB 锯齿读出与原生场同步审阅

本次问题是：用户截图中的 TB 是否反复表现为锯齿，以及这个锯齿是否意味着二维波前在两根电极之间来回传播。以下仅分析已经保存的真实模型轨迹，没有改损失、重新分类或新跑物理仿真。

## 判断

**在这一工作点上很常见，但不是所有 TB 都如此。中部重复锯齿的直接原因是：原图把两根相距较远的电极杆按共同横向坐标交错排列，而 SCL 在多数对应位置比 ICL 晚。** 蓝线逐行连接质心，因此每次跨杆都会向右、再向左折返；它不等于二维组织中的传播路线。

这并非可以全部归为绘图伪影：SCL 较晚是真实时序差。按杆重新排列，只消除了跨杆连线产生的视觉锯齿，没有消除延迟，也没有改善模型与患者的匹配。

## 样本、定义与范围

候选为 `coreOU_mid_EE085_mean095_rho000`，拓扑种子 2511；两次 60 秒运行的动力学噪声种子分别为 847101、847102。采用原报告的 primary 事件，排除窗口起点早于 1.5 秒及窗口超出真实运行终点的事件；沿用 TB 标签 0。每次运行均有 105 个符合此定义的 TB。

定义四个“齿”：对于 k=9、8、7、6，SCLk 的质心均晚于其在原行序中上下相邻的 ICLk 与 ICL(k−1)。只有相关 4 个 SCL 与 5 个 ICL 接触点均参与，才判断完整四齿；缺接触点不能记成无锯齿。这是本次描述性显示诊断，不是患者模式验收条件。

| 噪声种子 | 合格 TB 总数 | 四齿所需接触点均参与 | 完整四齿 | 可读但不完整四齿的事件 |
|---|---:|---:|---:|---|
| 847101 | 105 | 60 | 59 | 123 |

以上是同一拓扑、同一参数下两次噪声重演的事件统计，不是多个独立网络的普遍性结论。具体配对时差的中位数、5–95%范围及有效事件数见 `paired_rod_lags.csv` 和相应图；部分分布存在较长尾部，不能将所有 TB 简化成固定延迟的复制。

因此，相邻行实际上跨越约 9–11 mm；不仅质心，包络的早期质量时间和峰值时间也有近似的杆间差异。10%累计时间仍是窗口内包络量，不直接称为起燃时间。

原生帧显示右下 core 先活动，主要波前向左上扩展；左侧 core 也随后参与，有额外分支，不能将这段活动描述为已经证实的单源、单一路径传播。以 3 ms 高斯平滑的 core E 群体发放计数测得，右核峰为 27.6389 秒、左核峰为 27.6639 秒，相差 25 ms；这是**峰时差**，不是核间因果传导时间。原生帧没有蓝线所暗示的反复跨杆跳转。

最下端 ICL1–ICL2–ICL3 的小折返属于另一种情况：ICL2 靠近右核中心，其相对质心为 0 ms，ICL3 为 5.72 ms、ICL1 为 7.54 ms。它与核附近向相邻两侧扩展相容，并非上方交错行序造成的重复锯齿。
