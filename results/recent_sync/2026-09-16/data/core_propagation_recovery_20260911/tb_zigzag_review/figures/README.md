# TB 锯齿与原生场同步图

**显示版本已更新**：本目录保留“原交错行序如何产生锯齿”的历史诊断。用户已要求日后及回改对照统一按杆固定Y轴；当前三个相同事件请使用[固定行序GIF](../../tb_fixed_shaft_review/figures/README.md)，不再将交错面板作为当前展示。

均来自已有真实轨迹；未新增仿真。完整样本定义、统计分母及解释见上一级 `scientific_note.md`。

同一事件 72 的包络分别按原行序、按电极杆排列，右侧显示实际横向位置与质心时间。橙色为 ICL、青色为 SCL；改行序没有改包络、参与情况或时间。**关注点**：中部大锯齿消失，但真实杆间延迟保留；底部局部折返属于另一现象。

### tb_all_events_rod_lags.png

同一拓扑的两次噪声重演分别显示 SCL−ICL 质心时差，中位数为点、5–95%范围为横线，并逐对注明有效事件数。每次合格 TB 均为 105，但完整四齿所需触点均参与的事件仅为 60 和 67。**关注点**：杆间差异常见，仍存在例外、长尾及参与缺失。

### tb_all_events_rod_lags.pdf

全部 TB 杆间时差图的 180 dpi 栅格 PDF，与 PNG 内容一致。配对分母及四齿分母不同。**关注点**：不要把缺接触点的事件算作无锯齿，也不要把两次噪声运行称为多个独立网络。

### event72_native_stills.png

事件 72 的 12 个未筛选原生 2 ms 帧，时间相对于最早参与质心；保留真实双核与电极布局。全部小图共用原生计数色标。**关注点**：主要波前与额外核活动应从原生场判断，蓝色质心连线不能当作组织路径。

### 847101_event72_field_and_readout.gif

### 847101_event123_field_and_readout.gif
