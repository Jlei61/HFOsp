# 2026-09-12：形状与局部连接实验的科学审阅

**尚未整轮完成，也尚未恢复患者完整 TA/TB 传播。** 本报告固定于 `snapshot.json` 中的133/140条完整输出：形状/范围52/52，局部响应56/56，新拓扑确认25/32；共14,186个原合格事件，133条均为完整60秒、无物理runaway。剩余7条仍在实际计算，未评分、未补零、未当作失败。所有数值与图使用这个独立快照，不被后续流式更新覆盖；实时进度仍读上一层 `status.json`。

这轮已经建立了一些“参数改变→观测改变”的对应关系。最清楚的是：**core形状与核内抑制招募有相互作用；向外增边与单纯增权产生不同的招募结果；同一模式的时序可以稳定，而模式比例随噪声变化使总体中位数反转。** 但这些进展主要解决TA的部分参与—时序取舍，TB的左侧顺序结构仍未恢复。建议接受参数响应证据，不接受双模式传播恢复、最优病灶参数或稳定螺旋波结论。

## 本次比较的前提

患者参考是本轮冻结FIT的19,770个事件：TA13,165、TB6,605；不是历史所有合格事件的混合总表。模型以每个60秒运行作为实验单位，事件是运行内部样本。训练拓扑2511下的两条噪声847101/847102逐条配对；确认采用2611/2612与847201/847202，图中只用已完整的对应条件。

模型为只降阈值的E双核，随机输入仅加载于core E，核外E和I仍有确定均值输入及递归活动。空间OU、慢I状态、Z/M、定向刺激关闭，GABA18ms不变。所示“上移”条件的左核中心为(4.1992,12.1289)mm，右核为(16.4792,3.9655)mm；右核半径约1.753mm。左核4:1椭圆轴来自已采用的三个左端点几何的主轴，约79.45°，**不是两核中心连线，也不是全局EE轴**。形状匹配E成员数和降阈值总量，但会改变成员身份及附近I集合。

主要局部干预实际应用于两核对应通路：核内E→I表示E招募本核I，向外E→E表示core E到核外E。增权不增边；本次“增边50%”按原已接受core输入的核外E目标增加入边，实际从647,798条增至974,747条，权重总量同步增加约50.5%。原本没有core输入的目标不因这个操作自动得到输入。因此它不是均匀扩大传播覆盖，也不是与增权25%做剂量匹配。

观测定义：

- **SCL上部参与**：SCL9、SCL8各自参与概率的平均，分母为对应类别所有原合格事件；不是“两点同时参与”的概率。
- **跨杆时差**：每个两杆都参与的事件，取杆内参与触点质心时间中位数，计算SCL−ICL；再看这些事件差值的分布。负值表示SCL较早。参与集合改变也会改变这个量，不能单独称为固定路线传播速度。
- **顺序概率误差**：对每个共同参与的触点对，比较模型与患者的先后概率，再对可估计触点对等权平均。完整105对保存在 `pairs.csv`，既报告误差也保留支持事件数。
- **模式比例**：对应标签事件量/全部合格事件量；标签不是两种真实传播机制恢复的验收证明。条件中位数变化也不等于同一个事件被干预后改变。
- **局部宽度**：每事件参与接触点的包络t90−t10的中位数，再看事件间分布。模型仍是发放密度包络，患者示例为真实HFO STFT，二者不能直接当成同一种局部生理持续时间。

## 1. TA的招募与时序确实可以同时改变，但不是所有改变都有利

下表数字是两次噪声各自统计的范围，未将事件合并充当独立重复。左核均上移3mm，除明确列出的形状或连接干预外保持当前背景。

| 条件 | TA上部SCL参与 | TA跨杆时差中位ms | TB跨杆时差中位ms | TA/全部合格事件 |
|---|---:|---:|---:|---:|
| 患者FIT | 84.8% | −9.28 | +1.19 | 66.6% |
| 圆形基线 | 93.2–97.7% | +91.3至+92.9 | +36.4至+37.0 | 17.3% / 17.3% |
| 圆形，核内E→I减25% | 27.5–28.0% | −19.7至−19.1 | +34.6至+34.9 | 48.5% / 42.1% |
| 椭圆，核内E→I减25% | 80.6–84.6% | −21.8至−21.4 | +35.1至+35.2 | 25.0% / 19.7% |
| 圆形，向外E→E增权25% | 33.0–33.8% | −16.5至−15.7 | +35.4至+35.7 | 48.6% / 40.8% |
| 圆形，向外E→E增边约50% | 98.2–99.2% | −19.6至−19.5 | +34.5至+34.5 | 51.8% / 38.9% |

核内E→I减弱后的TA时差改变在圆核和椭圆都出现，但SCL参与的响应不同。圆核平均减少约67.7个百分点，椭圆平均增加约16.0个百分点；两噪声都支持这个方向差异。这是**形状和局部抑制招募存在相互作用的配对线索**，不是“椭圆本身优于圆形”的总论。单独把上移圆核改椭圆时，冻结训练分数在训练两噪声和四次新拓扑确认中都变差。

增边也能保留SCL并改善TA时差，但模型ICL参与几乎达到100%，患者TA各ICL触点平均约82.7%，TB约76.9%。因此不能把“覆盖更全”写成“分布更像”。增边与增权同时改变总输出剂量及有效伙伴，不可从本轮宣称纯连接数量优于纯权重强度。

这些EI/增权/增边响应尚未在本轮新的拓扑中确认：旧140条的确认名单主要检验形状、范围与半径，不包含这些局部组合。不能把别的条件完成的确认借给它们。

## 2. TB缺口有完整事件统计支持，不只是选例不好

Fig2C对照中，模型TB大多沿ICL从一端连续扫向另一端；患者左侧的折返结构未正常出现。以已经展示过的ICL11/ICL9为解释性诊断：患者TB两者共同参与的4,879个事件中，**69.38%是ICL11质心较早**。模型圆形基线为9.57%/14.58%；向外增权为21.33%/12.99%；向外增边为15.19%/17.17%；椭圆减EI为0%/0%。模型各单元共同参与支持为75–126个事件，详见 `tb_branch_pair_diagnostic.csv`。

该触点对是审阅既有图后选择的残差说明，不是新的训练目标、筛选门或独立显著性检验。它与全部触点对及真实原生场一起表明：一些TA观测改善，并不表示TB路径也恢复了。**在这些响应候选中，TB跨杆时差仍集中在约+35ms，和患者+1.19ms的中心位置不同。** 本轮有限参数族内的共同残差，削弱了“仅换一个噪声或再多扫同类参数即可解决”的解释；尚不能证明这个SNN基底绝对不具备所需能力。

## 3. 噪声影响要拆成模式比例与模式内时序

向外增边的圆核条件给出一个直接例子：同一网络，两条噪声的TA跨杆时差分别−19.52/−19.58ms，TB分别+34.54/+34.46ms，条件中位数十分接近；TA比例却从85/164=51.8%变成63/162=38.9%。不分模式的总体时差中位数因而从−14.62变到+11.36ms。

所以，“总体时差换seed变号”在这里并不意味着两种模式内部传播方向也翻转。混合分布中位数不是两个条件中位数的线性平均。后续要同时展示ALL、TA、TB和模式比例；这个例子不意味着所有噪声差异都由比例解释。

## 4. 其余局部参数改变了什么

完整28个局部条件、56次运行见 `figures/all_local_parameters.png`，行标签为实际配置值，不是相对各自基线的变化百分比。各参数均以自己的同形状对照配对。

- **减弱向外E→E到0.75**：每次只剩0–3个合格事件，全部检测也只有0–3个。对应当前传播维持能力明显降低；少事件不构成精确模式能力上界。
- **增强核内E→I到1.25**：四次运行均无检测事件，核外平均活动也接近零。这是该背景下的强抑制响应，不是OOM或readout丢失全部事件。
- **核内E→E从0.85提高到1.0**：TA时差向较早SCL移动，但圆核TA上部SCL参与几乎消失，椭圆也仅约50%；说明较强局部递归并不自动扩大目标杆的正确招募。
- **平均外部输入从0.95提高到1.0**：合格事件仅6–13个，却有251–255次全部检测，约238–249次因250ms窗口重叠被排除。这里是事件更密集导致资格集合改变，不能解释为网络不再发放。
- **两核OU相关性从0提高到0.5/1**：主要改变TA出现量和事件组合，TB跨杆时差仍约36ms。左核降阈值幅度也能改变两类数量，但没有稳定修复该时差。
- **I→E/I→I调整**：部分参与及事件数有响应，但这些单点没有同时补足TA/TB时序结构。少数模式样本小时保留“观测支持不足”，不补出虚假的低误差。

模型每事件局部宽度中位值几乎都在16ms，增边的TB某些运行到18ms。这些几何和局部连接干预没有恢复患者示例的宽时间包络。本报告没有把不同信号层的宽度差直接归因于某个膜或突触时间常数，也没有重启GABA扫参。
