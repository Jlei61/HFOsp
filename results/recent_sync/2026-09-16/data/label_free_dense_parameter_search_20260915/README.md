## 预算与选点算法

复用32个既有条件在指定唯一噪声上的真实轨迹并用无标签分数初始化。六条13点曲线合计73个独特条件，其中3个与上述旧条件相同，新增70条。另运行4批×8条自适应组合：总新增上限102条，额外拓扑/噪声重复为0。旧候选池最初由带标签目标探索，这个来源不能被当前重评分抹去。

使用Matérn-5/2高斯过程预测无标签J。每批优先6个局部预期改善点，再加2个全范围高不确定性点；局部范围随前一批真实反馈伸缩。GPU上的PyTorch自动微分配合多起点L-BFGS-B优化采集函数，搜索连续坐标。几乎重复的提案不重复派发，用已记录的不确定性备选补足。每批完整8条结束后才开启下一批；单参数网格与优化并行，完成的网格结果也可进入下一批冻结训练表。训练输入、随机seed、实际候选、模型参数均落盘，重启复用同一快照。

单个固定噪声不提供跨seed方差估计。GP只使用很小的数值nugget，不把它解释为生物随机性估计；预测不确定性用于搜索，不作为患者/网络统计置信区间。事件不足或runaway不取得拟合排名，但保留执行及物理状态。CPU完成真实积分，GPU用于特征计算和提案梯度；本轮不改原生SNN物理后端，不以代理预测冒充实际传播。
