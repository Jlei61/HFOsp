# TB残差与两核窗口内活动先后：新的数据定位

问题：当前模型是完全不能产生患者所见的局部先后关系，还是同一个TB标签中混入了不同的活动过程？这里只分析五个已完成工作点×同一基础网络2511×两次噪声，共10条60秒轨迹，没有新增仿真、重新分类、修改loss或按这项诊断提名。

观测定义：横轴为右核减左核的累计发放10%时间，正值代表左核较早。每个核分别按既有250ms事件窗内自己的全部发放质量计算；50%时间作为现有数据中的定义对照。它不是神经元起燃位置、刺激前的准备状态或因果驱动时间。只比较同时参与的ICL11和ICL9质心先后，未参与不填成失败；完整通道对概率误差、参与误差、杆间时差和实际事件量一并保留。

患者完整FIT中，TB两接触点共同参与的4,879次事件，ICL11早于ICL9占69.38%，ICL9−ICL11时差中位为+5.97ms；TB两杆时差中位为+1.19ms。患者没有对应的core状态标签，所以下表的模型亚组并非与患者某个已知亚组匹配，也不应要求每一亚组单独等于完整患者TB。

主要判断：

1. “TB始终只有一种错误的直线顺序”过强。当前组合确实会产生另一批ICL局部顺序更接近患者的TB标签事件；右核较早的大多数事件则维持约−14.6ms的ICL9−ICL11时差和约+35ms的杆间时差。这些不同输出被同一个冻结TB标签汇总了。
2. 这不只是挑中一个有利接触对：左移圆核的左核较早亚组，完整可比较触点对误差约0.24，右核较早亚组约0.39–0.40；但0.24仍非恢复，参与结构、局部宽度和分布形状仍有残差。两个亚组的组成改变也会影响全部TB摘要。
3. 50%累计时间的分层保留相同方向；新组合各运行t10与t50先后符号一致率较高，完整数值见timing_definition_agreement.csv。这减弱了结果只由10%阈值选择导致的解释，但两种统计仍使用同一窗口，不能消除窗口与双前沿叠加问题。
4. 原始圆核基线中，“左核较早”亚组的TB杆间时差仍约+87至+91ms；连接调整后相应亚组才接近0ms。因此不能只写成“调两核谁先发就足够”。已有网络动态与连接设置共同关联于实际输出。
5. 原生GIF中两核附近可出现先后活动与传播前沿叠加，少数事件的较好接触顺序未必是一条连续的右侧→上杆→左侧因果路径。它也不是新增了某个隐变量或证明存在双稳态；当前只是同一固定模型内部的后验分层。

对正在进行实验的影响：不改变已有多网络和方向探针的物理、loss或单位数。审阅新结果时把“同一活动先后亚组的路径改变”和“不同亚组的比例改变”拆开看，尤其检查右核较早的TB事件是否真的改掉固定接触时序偏差。这里的分层是结果诊断，不作为新的路线约束或硬门槛；不能直接用筛选掉右核较早事件的办法宣称恢复。

图件见[四页图集](core_phase_tb_paths.pdf)。散点为事件、分格为运行；连线连接同一轨迹的统计集合，不是独立重复或参数干预。10条来源和旧数据复用记录在sources.json。图件经Agent目视检查，用户人工验收待定。

窗口与波形补查：对两个左移组合的377个TB事件，将仅用于核累计时间诊断的窗口平移−25或+25ms，原标签和接触时序不动。377次在+25ms仍全部保留两核先后；−25ms有1次先后改变，其余376次保持，未发生记录边界截断。原始1ms核心发放与接触包络已加入新增图，两个例子使用相同发放率纵轴。该结果减弱了任意窗口位置造成这项分层的解释，但仍不是因果验证；详见window_shift_diagnostic.csv。
