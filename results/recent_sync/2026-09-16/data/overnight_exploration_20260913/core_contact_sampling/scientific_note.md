# 两核活动与接触信号之间，有一个不对称的采样环节

这里回答的是：当前模型的两个core，是否被虚拟电极同样直接地采样？分析对象为左移圆核／向外EE增强组合，以及同中心的左移椭圆／核内EI减弱组合，均取基础拓扑2511的保存坐标与真实core成员。它不是患者组织的已知事实，也不是新的仿真或拟合指标。

读出代码对每个触点使用空间标准差0.25mm的高斯权重，并在全部32,000个E神经元间归一化。本审计调用同一个读出构造器，从导出的E坐标重建权重，然后按左核、右核、核外求和；坐标保存为float32，结果用于几何量级判断，不声称还原未保存权重数组的逐字节身份。三部分之和与1的最大误差约2.1×10⁻¹⁵。

|空间采样观测|左移圆核组合|左移椭圆组合|
|---|---:|---:|
|任一触点中最大的左核权重份额|约2.1×10⁻³⁰|约1.1×10⁻⁹|
|SCL9距最近左核E神经元|2.85mm|1.51mm|
|ICL1的右核权重份额|73.3%|73.3%|
|ICL2的右核权重份额|约100%|约100%|
|ICL3的右核权重份额|66.5%|66.5%|

这些百分比是**几何权重份额，不是某次事件的信号贡献、发放量比例或解释方差**。活动强弱仍需乘以真实发放。当前左核几乎不直接进入任何接触点的读出，而右核直接覆盖ICL1–3；所以左核可以先活动，接触点却较晚才看到它招募的核外组织。这为“核心活动先后不完全等于接触点标签”提供了具体解释，并不证明哪一核因果驱动另一核。

图中保留原20mm平面和SEEG布局，点线圈仅表示读出核的2σ尺度，没有增加硬截断。两个组合同时改变形状与连接设置，此处只比较采样几何，不能将实际传播差异全归因于形状。不修改读出宽度、loss或正在运行的模型；也不能因为某个core不直接覆盖电极，就自动判定位置错误。
