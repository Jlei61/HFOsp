# 14种局部参数干预：完成数据的作用范围

问题是哪些底层参数改变参与、时间顺序和模式支持。此处只重读原140条中的56条局部干预与4条各自基底，没有新增仿真或重排候选。每个差值是同一基础拓扑2511、同一噪声种子、同形状基底下的两条60秒运行之差；蓝色圆核和棕色左椭圆核不是两张独立随机网络。事件不是独立网络重复，横线也不是置信区间。

所有14种干预完整列出，ALL/TA/TB分别展示，缺失用“不可估计”标注而不填0。TA/TB是冻结分类器的条件分组；参数改变后的TA事件并非与基底中的某次TA事件逐一对应，因此条件均值变化也可能包含事件组成变化。零差值不等于恢复；每个原值、基底值和实际模式事件数均保存。

目前最清楚的响应是：

- 改变核内连接、向外连接可以大幅改变TA的杆间时序，但TB的约+35ms时差对多数这些局部干预变化很小。增加输入或阈值深度有个别噪声下的大幅TB变化，不能将两次噪声平均后解释为稳定改善。
- 将两核OU相关系数从0提高至1，在两个形状下都提高TB标签比例；TB杆间时差却平均只减少约0.1–0.3ms。这说明“某类更常出现”与“该类传播路径恢复”是不同响应，不支持只靠调两核输入相关性解决TB。
- 向外EE增强25%在圆核基底会降低TA的SCL9/8参与，同时使TA杆间时差接近患者；椭圆基底的参与响应不同。不能笼统地写成“增强EE就改善SCL招募”。这也解释为什么要用形状×连接的组合响应及中心微调，而非只按单个好分数排序。
- 核内E→I增强25%的四条运行均没有检测事件；核内仍有约0.8–1.0Hz发放，并非全网零发放。该条件的传播指标不可估计，不能填成“误差为0”或“没有噪声影响”。
- 多数条件的局部宽度中位数保持16ms；增向外边数时TB增加约1–2ms。这个读出含5ms标准差的时间平滑，16ms摘要不是单神经元burst时长，也不是对患者HFO持续时间已恢复的证据。本轮仍优先处理传播而不继续增加GABA。
