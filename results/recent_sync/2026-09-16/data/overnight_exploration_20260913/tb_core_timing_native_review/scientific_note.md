# 相同TB标签内部，两种原生过程的直接对照

两例来自同一个左移圆核＋向外EE增强25%的60秒运行，基础拓扑2511／噪声847101。先按既有250ms窗口内两核各自累计10%活动的先后分组，再用已有特征选各亚组自身均值附近的例子：事件60来自左核较早的13例，事件137来自右核较早的59例。没有按照患者相似度挑选；这组诊断不替代每类前三例按时间选取的原多事件GIF。

每个GIF同步呈现患者固定Fig2C TB真实STFT、模型全部E的原生2ms场、原始1ms两核发放率、固定分杆接触包络。只有模型图有移动光标；患者与模型没有逐事件配对，均保留真实毫秒轴。两个例子共用场强色标及核心发放率幅度轴；模型场没有按lineage或起点筛选。

事件60的左核累计10%活动早约27ms，右核随后出现明显发放。场中能看到两片先后展开的活动前沿；在全场活动峰附近，它们的活动分布相遇。虽然该例ICL局部质心顺序较接近患者，但上杆仍缺触点，局部持续时间仍短；不能据此认定患者的完整TB路径已经恢复。事件137中右核较早，左核累计10%活动约晚64ms；下杆主要沿ICL1向ICL11逐次招募，上杆较晚，这与该运行大多数TB的时差残差一致。

这支持“同一TB标签中存在不同原生过程”的诊断，仍不能单凭动画确定某一核是否因果驱动另一核、证明独立振子或双稳态。当前分层使用事件发生后的活动，不能当作事件前隐变量。两核与电极的[采样不对称](../core_contact_sampling/scientific_note.md)也使核心先后和接触先后不能直接互换。

两条GIF各125帧，原生时间步2ms，播放每帧60ms，约30倍慢放；六时刻图均匀覆盖完整窗口，保留静默阶段。选例、源轨迹、固定显示顺序与色标见manifest.json。Agent已检查峰值与时序快照、逐帧解码；仍待用户人工目视审阅。没有据此改变loss、提名或物理运行。
