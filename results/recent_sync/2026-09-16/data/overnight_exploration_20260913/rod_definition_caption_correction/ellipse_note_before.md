# 左椭圆再上移1mm：两噪声结果

问题是同一椭圆、核内EI×0.75背景下，左核y再增加1mm，能否改善SCL招募并保留患者传播时序。四条完整60秒记录构成两组直接配对：同一基础网络2511、噪声847101/847102分别比较改动前后。均排除前1.5秒；核心成员和随机输入支持随位置改变，不能解释为同一组细胞的刚性平移。

|观测|847101 改前 → 改后|847102 改前 → 改后|
|---|---:|---:|
|合格事件数|156 → 165|157 → 169|
|TA占合格事件比例|25.0% → 34.5%|19.7% → 26.0%|
|TA上部SCL参与|84.6% → 98.2%|80.6% → 100.0%|
|TA参与误差|0.142 → 0.158|0.147 → 0.159|
|TA顺序概率误差|0.235 → 0.239|0.235 → 0.241|
|TA杆间时差中位数(ms)|-21.80 → -29.74|-21.37 → -30.52|
|TB杆间时差中位数(ms)|35.21 → 34.87|35.10 → 35.00|
|TB中ICL11早于ICL9|0.0% → 0.0%|0.0% → 0.0%|
|局部宽度中位数(ms)|16.0 → 16.0|16.0 → 16.0|
|冻结训练分数|7.488 → 6.430|8.827 → 7.627|

上部SCL是SCL9/8参与概率的平均；杆间差为每事件参与SCL质心均值减参与ICL质心均值，再取该类事件中位数。患者FIT TA上部SCL约84.8%、杆间差−9.28ms；TB杆间差+1.19ms，ICL11先于ICL9约69.4%（4879个共同参与事件）。局部宽度为参与触点10–90%包络质量宽度的事件内中位数，模型包络并非患者真实HFO信号。

两噪声均重复：上移增加参与、提高TA比例并降低联合训练分数，但TA参与和杆间时差反而偏离患者；TB关键回返仍0/108、0/125。较低总分来自全体／模式条件项下降，参与组合项反而增大。模式条件项包含比例与类内特征，不能将其变化全部归因于比例。

当前接受本网络上的招募—时序取舍，不接受双传播恢复或跨网络普遍性。两次噪声具有相同静态数组身份，但只是一张网络的两次重演。患者固定Fig2C图和模型自身均值附近选例并排，GIF采用时间上前三事件及固定连续片段，不筛选有利个例。

实际读出几何补充：上移使SCL9最近core-A细胞距离从1.011降至0.408mm，该触点归一化采样权重中core-A份额由0.00268%升至7.82%；这不是活动信号或解释方差的份额。SCL8的core-A直接权重仍约2.29e−18，因此两触点参与一起增加不能全部归因为直接采到核心，还涉及核外招募。见geometric_readout_weights.json；读出宽度与算法均未改。
