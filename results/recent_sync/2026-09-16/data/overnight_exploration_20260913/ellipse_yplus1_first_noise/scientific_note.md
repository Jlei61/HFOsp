# 椭圆左核再上移1mm：首条新噪声结果

问题是，在已固定核内E→I×0.75、向外E→E×1的左椭圆工作点上，再沿y上移1mm能否改善患者两杆传播。比较基础拓扑2511、噪声847101的两条60秒运行，排除前1.5秒；中心移动是名义干预，实际core成员、随机输入支持和局部连接分块也随之变化。第二噪声尚未完成，不作重复性结论。

总分从7.488降至6.430，TA标签比例由25.0%升至34.5%，但不能据此称为整体传播改善。TA的SCL9/8平均参与由84.6%变为98.2%，患者约84.8%，因此是招募更多而非更接近该参考；TA整体参与概率误差由0.142增至0.158。TA杆间时差中位数由−21.80变为−29.74ms，离患者约−9.28ms更远；接触对顺序概率误差由0.235略增至0.239。

TB的杆间中位时差仅由35.21变为34.87ms；108个TB事件中，ICL11早于ICL9仍为0%，患者共同参与4879例中约69.4%。TB全部接触对的平均顺序误差略有降低，但这一具体缺口未解决。模型TA57、TB108，均为完整轨迹中的合格事件，不是独立网络数；局部宽度中位数仍16ms。

新增患者对照图和原生场GIF与这些数值一致：TA上杆招募增加，但两杆之间仍分离较大；TB下杆主要为从右向左的单调接触顺序，未恢复患者示例在ICL上部的折返。模型实例按自身模式均值选取，GIF按每类最早三例并另给固定连续片段，没有挑患者最相似事件。单例与六例用于目视审阅，全部数值仍来自57/108个对应事件。
