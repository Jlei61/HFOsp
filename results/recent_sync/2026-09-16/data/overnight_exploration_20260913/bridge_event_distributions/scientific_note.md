# 新噪声下，时差的分布是否恢复？

本图只读预定原位置／左移对照中已完成的首条新噪声847401，不新增仿真、损失或提名。每条60秒运行是实验单位，前1.5秒排除；ALL、TA、TB均保留该集合全部合格事件，不按路径好坏删样本。患者为FIT自然分布，标签也参与冻结目标；不是独立患者验证。

两个观测分别为：每事件参与SCL质心的中位数减参与ICL质心的中位数；固定ICL9质心减ICL11质心。前者要求两杆各有参与，后者要求两个触点均参与。模型与患者各事件沿用自身参与集合；共同触点敏感性另有审计，不在本图替换观测。每类的事件量与各观测有效n不同。

**左移候选的TA时差中心更接近患者，仍没有恢复患者的散布。** 在开发网络2511的新噪声下：

|TA杆间质心差|患者FIT|原位置|左移0.75mm|
|---|---:|---:|---:|
|有效事件n|13005|67|90|
|均值ms|−12.52|−7.70|−13.28|
|中位数ms|−9.28|−15.62|−12.48|
|方差ms²|268.52|667.42|23.97|
|5–95%范围ms|−42.63至5.42|−23.25至51.27|−21.73至−5.57|

这些是该观测的一维描述，不是总体方差恢复率，也没有将患者事件数与网络重复数混为一谈。原位置少数明显偏晚的TA可抬高方差；左移后虽移除这些晚尾，主要事件也比患者集中得多。不能用均值接近或方差减少自动接受完整分布恢复。

**TB的范围甚至可以与患者部分重叠，但事件质量分布仍明显不同。** 左移后TB杆间差5–95%为−6.96至36.80ms，患者−21.19至35.57ms；模型大部分事件集中在约35ms附近，患者更多在零附近。固定ICL9−ICL11差的中位数，模型仍−14.51ms，患者+5.97ms，说明具体局部顺序残差仍在。CDF把这种集中位置的差异直接展示出来，不能仅凭范围或一个方差数判断恢复。

新网络2711的原位置与左移配对现已完整；左移TA杆间差反而远离患者，完整结果见[新网络配对](../position_new_network_replay/scientific_note.md)。所有实际均值、中位数、方差、5–95%及有效n见event_distribution_statistics.csv；这些是两个边缘分布，不替代完整参与—顺序—空间路径联合检验。
