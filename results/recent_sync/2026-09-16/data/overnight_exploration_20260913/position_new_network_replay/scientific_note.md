# 同一个左移，在新网络上没有保留整体收益

四条完整60秒运行：两张基础网络2511/2711，各自比较原位置与左核x−0.75mm，固定首条新噪声847401、圆核、向外EE×1.25及核内EI×1。第二条新噪声与第三张网络仍在运行；这是两个网络上的首条噪声配对，不是完整3×2确认。事件不是独立网络重复。

|观测，原→左移|开发网络2511|新网络2711|患者FIT参考|
|---|---:|---:|---:|
|合格事件数|139→139|140→144|—|
|TA / TB数|67/72→90/49|78/62→78/66|13165/6605|
|TA上部SCL参与|39.6%→61.7%|90.4%→94.2%|84.8%|
|TA通道参与概率误差↓|0.230→0.195|0.191→0.232|0|
|TA成对顺序概率误差↓|0.167→0.156|0.211→0.188|0|
|TA杆间质心差中位数ms|−15.62→−12.48|−18.84→−21.28|−9.28|
|TB杆间质心差中位数ms|35.15→34.94|35.73→35.51|1.19|
|TB的ICL11早于ICL9|10/72→12/49|6/57→5/61|3385/4879，约69.4%|
|冻结训练分数↓|3.200→1.952|2.377→2.553|无经验零点验收|

两张网络的TA顺序误差均下降，上部SCL参与率均增加；但新网络原本已超过患者参与参考，继续增加反而伴完整参与误差升高。TA杆间差的变化方向跨网络相反，训练分数也由改善变为恶化。因此可以说某些原始观测具有同向响应，不能说患者相似度或全部传播具有普遍改善，更不能冻结一个对所有随机网络都“最优”的左移位置。

TB在两个网络中都仍集中于约35ms；局部ICL顺序的改善也未跨网络保留。完整CDF另显示事件间散布未恢复，不能仅依赖均值、中位数或标签数。

每张网络的原位置／左移条件中，实际保存的两条独立核OU曲线及两核原始调制率逐值相同；rho=0，未使用的global_xi不参与该一致性结论。位移仍改变core成员、阈值及连接分块，逐细胞Poisson创新未核对。换网络同时改变位置、静态异质性和边结构，不能把这些结果写成“拓扑单独解释了多少总体方差”。

固定分杆的患者对照、正常选例与每类前三事件原生GIF由新噪声消费者接续生成。两张网络共用患者FIT标签和观测，仍是拟合／重复性诊断，不是独立患者机制验证。现有确认和108条队列继续按冻结预算，不据本结果重选噪声或改变loss。
