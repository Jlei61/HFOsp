# TA/TB标签是否改变优化：同一候选池的离线核查

2026-09-15。**标签相关项明显改变候选排名，但去掉标签尚未解决患者TB传播失配。** 本次对已完成的32个训练条件、64条训练轨迹以及8条既有确认轨迹重新计算分数，没有新跑SNN，没有改写原轮次、候选或原目标。

## 比较前提

三个观测组仍为整体rank、杆内/杆间时序、联合参与。事件、15触点身份、FIT/CAL划分、原生读出、Fourier特征、毫秒变换、N≥16约定与去自配对公式均保持一致；每条件两条训练噪声等权，事件不跨运行混池。

做了两个相互区分的计算：

1. **只删除标签项**：从原Ψ中删除所有按TA/TB划分的特征块和模式比例常数，只保留全事件φ；保留原正尺度，回答“删除这些项是否改变选择”。这些原尺度继承了标签信息，故这个对照不宣称整条评分构建完全无标签。
2. **无标签评分构建**：从全FIT事件独立计算φ目标；在相同256组CAL连续16事件索引上，以无标签的平方均值差重新计算正尺度。评分器只接收事件×触点质心时间，不含分类器、模式比例、模式目标或按模式采样。映射/带宽本来由全FIT无标签特征生成，可以复用。

新公式为每运行 `D_j = ||mean(phi_j)-mean_patient(phi_j)||² - V_j/(N-1)`，三组除以固定正尺度后等权，再对两条运行等权。不截断负分，不按TA/TB分配奖励。新正尺度：rank 0.044858669、时序0.043128270、参与0.045592423；原尺度分别0.148792295、0.140892341、0.151262930。不同目标数值不能直接相减称性能提升，以下比较名次和原始观测。

## 历史口径核查

- `src/topic4_contact_event_objective_v2.py` 的 `FrozenCentroidAnchor` 显式复用全FIT无标签特征，`ContactEventObjectiveV2.score` 不调用模型TA/TB分类器。它证明之前确有不依赖模型分类标签的接触包络拟合实现；外部患者小包及权重的构建仍应另外追溯，不能仅凭函数名把整个历史流程称为无标签。
- `src/topic4_multievent_distribution_objective_v2_1.py` 则显式存储FIT模式比例和分模式目标，`score_network` 将全事件和模式项各赋0.5权重。因此历史多事件v2.1并非无标签损失。
- 9月14日三组目标继续使用模式频率加权特征；这次离线核查才是明确删除这些项的独立评分实现。

“标签不进入神经元输入”和“标签不进入优化函数”必须分开。带标签的分布拟合本身不是数学错误，也不因标签来自FIT就自动构成数据泄漏；但它回答的是有模式监督的拟合问题，不能把同一标签下的改善当作两类结构被独立发现的证据。

## 建议的下一版设计口径

训练只使用未按TA/TB分组的完整单事件观测分布，不读取分类器、模式自然比例或分类目标。保持患者已确认的粗端点几何先验；这一先验来自模式信息，所以准确名称是“患者几何先验下的无标签事件分布拟合”，不是整条流程完全无监督。TA/TB用于提名后的模式条件诊断，其数据仍是开发患者，不能叫未见患者独立验证；新噪声/新拓扑另作确认。

可以强调跨杆共同招募、有符号杆间时差和招募跨度，但应匹配患者实际分布，不能奖励每事件两杆100%参与、强行让全部事件时差接近零，或只拟合一个总体中位数。TA负时差和TB正时差可能在总体摘要里相抵，错误的混合也能产生正确中位数；单事件联合参与—顺序—时差结构必须保留。

“事件时间范围”需先明确：250 ms是分析窗，不是事件持续时间；最晚−最早参与触点质心是跨通道招募跨度；单通道HFO包络宽度又是另一个量。前两种可按统一时间定义核查，HFO与模型密度包络的可比关系仍需处理。本次只移除标签并重校准，没有把跨度、脉宽或新正则混入损失，避免把不同改动的效果混在一起。

核均值嵌入提供不依赖模式标签的两样本分布比较；有限Fourier表示、有限且相关事件及当前特征仍不能保证恢复全部患者多模态结构。方法依据：[Gretton等，2012](https://jmlr.org/papers/v13/gretton12a.html)。
