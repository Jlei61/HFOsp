# 全局EE连接轴：首噪声三点结果

问题是固定左移圆核、向外EE×1.25条件的TB时序残差，是否对全局EE轴的±15°调整敏感。三个条件均为20秒、基础拓扑种子2511、噪声847101，排除前1.5秒；实际EE边及距离时延随角度重采样，不是同一物理图上仅改变显示轴。各运行是实验单位，模式内事件数仅为支持量。第二条开发噪声尚未完成三个角度，不能称为多噪声确认。

|观测|−15°|原轴|+15°|患者FIT参考|
|---|---:|---:|---:|---:|
|合格TA/TB事件数|23/24|22/31|24/26|自然比例66.6%/33.4%|
|TA上部SCL参与|37.0%|54.5%|89.6%|84.8%|
|TA成对顺序概率误差↓|0.177|0.137|0.202|0|
|TA杆间质心差中位数 ms|−2.71|−12.39|−18.96|−9.28|
|TB成对顺序概率误差↓|0.366|0.321|0.258|0|
|TB杆间质心差中位数 ms|31.94|35.31|33.15|1.19|
|TB的ICL11早于ICL9|0/23|8/31|8/26|69.4%|
|整条运行冻结分数↓|2.867|3.416|3.014|不作零分验收|

+15°改善TA参与和TB全部可比较触点对顺序，但TA杆间差与成对顺序反而变差，TB杆间差仍有较大残差。TB局部顺序的比例从8/31到8/26，分子仍是8，不能说观察到了更多正确折返事件。三条件显示连接轴能影响接触分布，但未找到同时恢复患者两类完整模式的角度。

−15°的冻结分数最低，TB顺序误差却最高；总分排序与特定路径判断不同。主损失不因此更改，也不由本次路径诊断重新提名。三个条件局部宽度仍16ms；患者真实STFT和模型发放密度包络的信号差异保留。

+15°另有两段44/48ms、约0.56圈的筛查候选，频段匹配比−15°更稳定；两段原生帧均呈左下弯曲前沿移出固定环，未见持续重入。见[全部两例GIF与审阅](../plus15_rotation_review/scientific_note.md)，仍不接受稳定螺旋。
