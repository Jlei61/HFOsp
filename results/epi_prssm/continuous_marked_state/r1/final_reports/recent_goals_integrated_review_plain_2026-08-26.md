## 一句话结论

这几天的工作没有证明“IED 已经塑造了癫痫网络”，但完成了两件很重要的事：第一，路线已经从不直接回答问题的未来频谱预测，转回到下一次 IED 的真实发生时刻和完整空间招募；第二，现在在少量 development 患者中，确实看到了跨窗口保留的预测记忆，而且它主要帮助判断下一次 IED 招募哪些触点、后面怎样延续。

H3 仍未决。短尺度实验的零后来被证实是模型边停在零初始化造成的结构零；早期长尺度实验又存在免费截距、名义长尺度被 54 分钟衰减核压回最近约 0.5–1.6 小时、滑动窗口虚高样本量等问题。最新超长实验没有强行给出结果，而是发现目前没有患者同时具备“稳定可用的前状态”和“足够多的独立长窗口”。这正确关闭了超长 boxcar，但不能阻断 N=100 的事件级 H3。因此当前结论仍是：**H1 有有限的 development 支持，H2a 是目前最强的一条，H2b 仍是探索性关联，H3a/H3b 尚未获得合格人体支持。**

## 我们的三个核心假设

### H1：脑内是否存在一个跨时间持续的功能状态

白话说，不是只看当前 30 秒脑电，也不是只数最近一次 IED，而是问过去的信息能否在多个观察窗口之间保留下来，形成一个对未来仍有用、并且属于正确时刻的内部状态。

### H2：这个状态是否决定下一场 IED 或发作怎样展开

- H2a 问下一场 IED：哪些触点参与、事件何时停止、相同开头后会怎样继续。
- H2b 问发作：这个间期状态是否在发作前移动，并与早期发作招募或发作亚型相连。

### H3：IED 是否反过来长期改变这个状态

- H3a 问经过很多次 IED 后，未来状态是否发生了超过共同背景状态所能解释的改变。
- H3b 问这种 IED 造成的状态改变是否进一步参与发作转换或发作模式。

## 这几天每一阶段到底解决了什么

### 1. Raw-SEEG R0.1/R0.2：证明了原任务不适合承担 H1–H3

第一版让 raw SEEG 编码器预测 1、5、10、100 分钟后的频谱场。这条线的工程实现很完整，但科学目标错位：预测频谱不等于预测 IED timing、空间招募或发作转换。

三位预先指定患者上，wide Transformer 在全部四个 horizon 上都优于等容量 Conformer，但 1、5、10 分钟仍输给直接读取频谱历史的低容量自回归。后续复审还纠正了几条过强说法：这个自回归不是“21 参数”而是总共 1,008 个系数；1 分钟至 48 小时的时间常数主要来自初始化，不是数据识别；单个患者 100 分钟胜过 persistence 也没有在另一患者复现。

因此这一阶段可以验收为高质量的技术排错和路线纠偏，不能进入 H1–H3 阳性证据。

### 2. R1/R1.2：第一次把真正的问题写进 likelihood

模型开始同时回答两个问题：下一次 IED 何时发生，以及一个事件内哪些触点按 tied groups 被招募。记录缺口不再计入生存积分，同一时刻参与的触点也不再被强行排出假顺序。

这一阶段还发现旧 recorded support 是由“有无入选 IED”反推的，会把有连续 SEEG 但没有入选事件的记录块误当成缺失。R1.2 改为从原始记录块建立时间轴，再排除 ictal 和发作后两小时。这个修复使旧 timing 数字失效，但保住了 exact mark likelihood 的工具价值。

六位患者的全锚点 R1.2 结果显示：显式 IED history 对 timing 为 6/6 有利；对完整 mark 则明显异质。persistent state 的 filtered、关闭后续校正、wrong-time 三把尺子都只有 2/6 有利，中位为 0。因此这一阶段支持“历史有信息”，不支持“背景观测已经形成稳定持续状态”。

### 3. R1.2b：发现部分 mark filter，但 raw 上游其实没有真正训练

R1.2b 只对齐 observation 的空间尾部。958 和黄瀚文出现 mark 改善，620 三个 seed 都选择 epoch 0。整体是 filtered 与关闭校正对比 2/3 有利，但 correct-time 对 matched wrong-time 为 0/3。

后来确认 raw tokenizer 和 temporal blocks 没有接受目标梯度，所以 raw 与 explicit 近零差异没有 raw 生物学阴性解释力。这个阶段正确收口为“有限的 observation-conditioned mark filtering”，不能叫 raw-informed persistent state。

### 4. R1.3：目前最重要的新结果

R1.3 第一次让完整 raw temporal observer 接受正确的 IED timing + sequential mark 目标梯度，并加入真正的 memoryless 对照和严格 matched wrong-time 对照。

在固定的三位 development 患者中：

- persistent 胜 memoryless：3/3；
- correct-time 胜 matched wrong-time：2/3；
- persistent 对 first recruited subset 有利：3/3；
- persistent 对 later continuation 有利：3/3；
- fully trained raw 相对 explicit 的 joint 指标只在 1/3 有利，患者中位反而略差。

最准确的解释是：**三位患者都有跨窗口预测记忆，且这份记忆确实影响下一次 IED 的触点招募和后续延续；但它还没有稳定达到“正确时刻专属的 raw 生理状态”。**其中黄瀚文 validation 事件只有 107 次，且其 joint 改善主要来自 mark，timing 反而变差，所以不能把 3/3 当成队列比例。

### 5. H3 的短尺度筛查：有前置信号，但不是因果边

早期 H3-S0 在 34 位患者上发现，约 25–200 次近期 IED 的累积历史能小幅改善下一次事件的 mark，收益主要集中在 STOP/事件规模，典型 NLL 改善约 0.001–0.003；timing、contact order 和真实钟表时间没有稳定优势。

这说明值得继续问“多个 IED 是否留下累积痕迹”，但它仍可能是同一个未观测状态同时造成前后 IED 相似，不能写成 IED 已经物理推动了状态。

后续 N=100/1000 T2 中，real cumulative 和 state-matched placebo 的边在所有检查 epoch 都停在零初始化，对比恒等于 0。早期报告写成“0/2 患者支持”是错误的；正确分母是 0/0，表示没有得到可估计的人体对比。

### 6. 长尺度和超长尺度 H3：工程跑完，但人体问题仍未被合格检验

长尺度复审抓到四个会改变结论的问题：

1. `real` 相对 `no-edge` 白拿一个状态截距。完全没有 IED 信息、只有常数偏移的假数据也能产生 −445 的巨大假阳性。主比较现已改为 `real` 相对拟合截距对照；causal-delayed 只作支持性对照。拟合截距对照只吸收固定偏移，并不是与真实臂参数量相同的“同容量”对照。
2. 名义 10,000 次和约 6 小时实际上都经过约 54.1 分钟的冻结衰减核；一半权重来自最近约 0.5 小时，九成来自最近约 1.6 小时，不能称为万次或六小时总效应。
3. 张家齐的 4,715 个滑动 validation 窗只覆盖 1.63 小时，约等于 1.8 个有效独立窗口；窗口数不是样本量。
4. 张家齐整个 T1 状态模型停在初始化，decoder 对 state 的秩为 0，因此所有人体对比都是结构零。

随后 whole-window boxcar 确实实现了真正的几千次长记忆。五位长记录患者、每人七个 seed 的结果显示：只有韩宇轩在旧 T1 标准下 7/7 有 predictive persistent memory，但 correct-time 仅 2/7。

这两档必须分开读：**N=2,000 那档 7/7 都是有效估计，但没有胜过拟合截距对照**；
**六小时那档 7/7 都不是有效估计**——拟合臂内含截距对照那个常数，验证误差却达到
截距对照的 20–149 倍（全部 70 条已归档超长臂里有 26 条落在 4 倍以上，最极端
6,809 倍），属于外推爆掉，
应与结构零同类写成"不可估计"，而不是"检验失败"。原因是正则化网格实际上等于不做
正则化（76 条拟合里 47 条把强度选在网格上界），已改为尺度无关的惩罚并加了发散闸门。

“每个 validation 条件只有一个不重叠整窗”还说轻了：boxcar 的去相关长度是
整个窗口而不是 54 分钟的生成器时间常数，按正确分母算，有效独立 validation 窗口是
**0.48–0.93 个**，即不足一个。另外延迟对照与真实臂的暴露窗重叠中位 **66.7%**
（N=10,000 时高达 90%），所以 `real − delayed` 的零值不能读成"载荷时序不重要"。

陈子阳在旧的宽松闸门下曾出现方向有利的读数（N=4,000 为 −4.31、5/7；
六小时为 −33.70、6/7），超长总报告已正确撤回并标为"若未来 T1 修复后值得复查"的候选。
这两档拟合本身可估计，但陈子阳的 T1 外层验证为 0/7 合格，因此它们不是当前 H3
证据；若未来在该患者建立合格 T1，可以按冻结的新估计器复查。

最新一轮用 R1.3 重新训练韩宇轩、陈子阳和程帅，并在运行 H3 前同时审查 T1 稳定性和完整对照所需的独立长窗。韩宇轩只有 1/3 seed 的 persistent joint 有利；陈子阳 0/3 发生有效更新；程帅只有 1/3 有利，虽然 N=1,000 时有 8/3 个 TRAIN/validation 完整独立窗。没有患者同时满足两边条件，所以新人体 H3 调度为 0 个作业。

这是本轮最科学的一次“没有运行”：它避免了继续在不可解释的分母上制造数字。结论是 **H3 未检验完成**，不是 H3 阴性。

## 下一步最应该做什么

不再继续超长 boxcar 主线，也不再要求患者先拥有 N=1,000–2,000 的多个独立整窗才有资格回答全部 H3。这个条件只适用于“数千次 IED 总效应”，而当前最稳定的人体前置信号实际位于 **25–200 次 IED**。下一步分成两条直接服务原始假设的路线。

第一条是 **R1.4 六患者 H1/H2a 复现**。患者在看新结果前固定为 `epilepsiae_620`、`epilepsiae_958`、`yuquan_huanghanwen`、`epilepsiae_922`、`yuquan_pengzihang` 和 `yuquan_hanyuxuan`。主臂使用 explicit continuous-SEEG observation；raw Transformer 只作为配对 residual sensitivity，不再搜索编码器家族。主要问题是 persistent 是否胜 memoryless、正确时刻是否胜 5–10 个严格匹配的错误时刻，以及增量究竟落在 timing、STOP/size、first subset、later continuation 还是 same-prefix continuation。E922 和彭子航加入这一轮是为了扩展 T1/H2a，不是为了继续超长 H3。

第二条是 **T2-R2.0 的 N=100 一步 generator-edge 检验**。N=100 事前固定在 H3-S0 的 25–200 次稳定范围中间，不按患者选择。优先在当前 T1 最稳定的 E620 和 E958 上运行；新患者只有在 R1.4 中形成可解释的 persistent/time-specific state 后再加入。每个事件先用 pre-event state、显式历史和 observation 预测其 load 或 participation，再只累加无法预测的 innovation。事件本身仍由跳变前状态预测，事件结束后才允许 exposure 更新状态。

核心比较是：T1 no-edge、真实 N=100 累积 exposure、state-matched 且历史不重叠的 donor exposure、current-event-only jump。一级端点从完全相同的 pre-event state 出发，关闭下一事件前的 raw correction，预测下一次事件；二级端点只在 anchor event 注入一次跳变，随后关闭 raw correction 和新 T2 jump，比较 H5/H10。只改善下一事件时称 exposure-conditioned prediction；差异通过冻结 generator 延续到后续事件时，才接近 exposure-induced state update。拟合截距只保留为固定偏移诊断。

只有 N=100 的 edge 确实离开零、胜过 donor 与 current-event，才扩到 N=50/200 和匹配 physical-time sensitivity。H2b 另行用修复后的 pseudo-onset 代码重跑旧 12 个产物一次并归档，不让 seizure loss 反向训练 state。

## 给合作者的一段话

> 过去几天的主要进展不是证明了 IED 的长期因果作用，而是把测量问题拆清楚了。现在少量 development 患者中已有可信的跨窗口预测记忆，这份记忆能改善下一次 IED 的触点招募和后续延续，因此 H2a 是当前最强证据；但原始波形尚未稳定提供显式背景统计之外的信息。H2b 的主层仍有探索性偏移，但当前数值来自两处 pseudo-onset 修复前产物，尚需重跑。关于 H3，早期短尺度零是结构零，早期长尺度比较又受截距、衰减核、拟合发散、暴露重叠和滑动窗口影响，不能作生物学解释。下一步不再把超长整窗当作全部 H3 的入口，而是在六人中先复现 H1/H2a，再在稳定 T1 患者上用事前固定的 N=100 检验近期多个 IED 的不可预测部分是否改变下一事件和后续状态。H3 目前仍是未决，而不是阴性；正式检验分区尚未打开。
