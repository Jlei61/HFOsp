### h3_event_feedback_future_block.png / .pdf

问的是同一件事的四个侧面：间期群体事件到底只是慢状态的读数，还是它的数量或内容
还会进入之后的状态演化。四个面板各答一个独立问题，互不重复。

**A（未来这段时间会有多少次事件）**：每个点是一位患者，纵轴是"把事件的
发生/大小/密度这条线加进状态"（burden）或"在事件数与时刻都不变的前提下再把
事件长什么样加进去"（content）之后，对**没见过的**未来时间块的对数分数增量。
正值＝那条线有帮助。红点在零线之上，蓝点在零线之下；黑横线是队列中位数，
竖线是自助法 95% 区间；越出坐标范围的患者点画成三角并把真值写在旁边，不隐藏。
**灰带是这一档的"重训噪声地板"**：把同一个模型换随机种子重训一遍能造出多大的差
（同患者、同块、同样取三次中位数，只把右边换成重复拟合）。灰带按每个时间档单独画，
数值标在带的右端。落在灰带以内的中位数**不能读作看到了增量**。

**B（那些事件长什么样）**：与 A 同样的两条对比，但端点换成"给定这段时间里确实
发生了事件，它们的空间—频带表达"。分数按 mark 维度平均，所以触点数不同的患者可比。
A 与 B 是两个不同的科学问题（多少 vs 什么样），不是同一张图的两种画法。

**C（一次事件对下一段时间做了什么，带符号）**：在冻结的模型上精确读出——因为状态
是线性的、事件冲击是输入驱动的，一次事件对之后任何预测的影响有闭式解。纵轴是
"下一段时间的期望事件数变化的比例"，一个点是一位患者的中位事件。模型结构上
**不强制**这个量为正；图例里给出每档有多大比例的事件把它推高。

**D（每位患者到底贡献了多少独立的留出时间）**：纵轴是**互不重叠**的留出块数（对数轴），
虚线是在任何模型跑之前就定下的最低要求（每位患者 6 块）。低于这条线的患者不进
A/B/C 的任何统计。这一格是前三格的分母，必须与它们一起读。

**关注点**：先看 D 再看 A/B。120 分钟这一档只有 8 位患者过线、6 小时档一位都没有。
实测结果是 **A/B 里 18 条对比的中位数无一越出自己那一档的灰带**（最大 0.61 倍），
所以图上出现的 p=0.019 / p=0.001 只是"对 0 检验"的结果，不构成阳性；
C 面板同时显示 27/27 位患者的单事件影响都小于 1%（24/27 小于 0.1%）。
本图的正确读法是"**这一轮没看清**"，既不是阳性也不是阴性。
