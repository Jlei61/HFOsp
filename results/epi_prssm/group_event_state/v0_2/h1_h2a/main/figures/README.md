# Group-Event State v0.2-A（H1/H2a）图说明

统一读法：纵轴一律是**相对"多尺度滑动平均基线"的对数似然改善**，正数=更好、零线=与基线持平。
每个点是一位患者（同一患者的多个随机种子先取中位数），粗点+误差棒是队列中位数与其 95% 自助区间。
横轴下方标注的"non-overlapping windows"是每位患者留出段里**互不重叠**的窗口数中位——
观察点每 5 分钟一个，两小时窗口相邻之间有 96% 内容重合，所以观察点数不是样本量。

### future_block_state_gain.png / .pdf

承重图。四个面板各答一个独立问题：未来一段时间里**会来多少次事件**、**哪些触点参与**、
**事件长什么样**，以及最右边——**起头相同的事件后来走法有没有不同**。
四条曲线：只预测下一次事件的模型、被直接要求预测未来整块的多时长模型、
**状态里只带"距上次事件多久"这一个数的对照**、以及把同一份状态在同一段记录内平移到别的时刻。

前三个面板要一起看：5 分钟档的"会来多少次事件"上三条模型曲线都略高于零，但
**"只带间隔"那条不低于携带历史的两条**——所以那点改善不是"记住了历史"，
而是基线里把间隔写成单独一列太死板。平移曲线贴在零线上；30 分钟与两小时档三条全部塌到零。
第四个面板全部落在零或零以下，最右侧的"后续频谱表达"明显低于零。

右下角的"N patient points outside"是被纵轴裁掉的离群患者点数——纵轴按中间 96% 的散点定范围，
否则少数离群患者会把尺度撑开、承重比较完全看不见。

**关注点**：不是"有没有点高于零"，而是**靛蓝那条（什么都不记）是否低于青色/橙色那两条**——
它不低，就意味着跨事件携带的历史在固定物理时间的未来块上没有额外贡献。

### which_part_of_the_block.png / .pdf

辅助图，回答"如果状态有用，用在哪一部分"。只画 conditional mark 的六个分块
（哪些触点、招募到多少触点、招募持续多长、频带能量、频带峰时、整体事件形态），
它们都是**每次被评分观测**的对数似然，单位一致；事件数是"每窗口"单位，
放在承重图的第一个面板，不与这些同轴。

**关注点**：有没有哪一个分块系统性地高于零——如果"传播范围"高而"频谱"不高，
那说明找到的是范围类的状态；本轮的实际情况是没有任何分块稳定高于零。

### memory_truncation_diagnostic.png / .pdf（待生成）

诊断图，回答"这个状态到底用了多久的过去"：把同一个训练好的模型在评测时每 K 次事件
或每 T 分钟清零一次，看未来块的改善怎么变。**这是诊断，不承担结论**——
历史尺度由改善随真实 horizon 的曲线决定，不能用"哪个清零档位首次不显著"来定义。
该图依赖记忆截断重放阶段，跑完后补。
