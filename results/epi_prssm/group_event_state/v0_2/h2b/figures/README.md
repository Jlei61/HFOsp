# H2b（发作转移）图说明

本目录是 Agent B 的图。目前只有一张，是**质检图**，不是科学结论图。

### early_ictal_field_onset_alignment_qa.png / .pdf

这张图只回答一个问题：**我们标的那个"发作起点"，真的是电活动开始变化的地方吗；
而且各条通道有没有对错位？** 每格是一次发作：横轴是距脑电起点的秒数（黑竖线 = 0 秒），
纵轴是这位病人的所有触点，颜色是 1–45 Hz 的功率相对发作前安静期的偏离
（红=比平时强，蓝=比平时弱，白=和平时一样）。触点按**快活动到达的先后**排序，
所以如果起点标对了，红色应该在黑线附近或之后从下往上铺开。

选哪几次发作是**写死的规则**（每个队列按字母序取头三位有数据的病人、各取其第一次发作），
不是我挑出来好看的。左列 Epilepsiae、右列 Yuquan，两列横轴范围一致，可直接对比。

看图能看到：chenziyang 在 0 秒之后明显起来、1077 在 0 秒处由蓝转红、
1096 有一条触点从起点开始持续发红。**1073 这一格几乎是平的**——这不是画错了，
这位病人本来就是全队列里发作之间最不像的那个（同一人两次发作的场相似度只有 0.03），
它在这里是有用的负面样本。

**关注点**：黑线两侧有没有可见的变化交界；同一格里红色是不是集中在少数几条触点上
（而不是全屏均匀）；1073 那格的平坦要读作"这位病人本来信号就弱"，不要读作对齐出错。
