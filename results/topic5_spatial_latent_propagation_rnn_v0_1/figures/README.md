# 图说明 — 患者特异空间潜变量传播 RNN v0.1

### topic5_slp_rnn_v0_1_overview.png / .pdf

五个面板，每个回答一个独立问题，不重复画同一个构造。

**A — 模型长什么样。** 灰点是撒在患者自己那张传播平面上的组织单元（状态住在这里），
空心方块是真实的记录触点。红色方块那个触点被高亮出来，蓝色圆点是它实际读到的那几个
组织单元，点越大表示它在这个触点的读数里占比越高。要看的是：触点只是一个**观测口**，
它读的是周围一小块组织的加权平均，而不是网络里的一个节点——这正是"预测一个从没训练过
的触点"这个问题第一次变得可问的原因。

**B — 预测上谁赢。** 每个点是一位患者，同一位患者的多个随机种子已经先合并。纵轴是
相对于"只按各触点平均参与率猜"的改进量（组内配对差），不是原始误差——原始误差的绝对
水平会随触点数变化（触点越多，大部分触点在任一步都不参与，光把"不参与"猜对就能显得
很好），跨患者不可比。虚线是零改进。

**C — 结构到底能不能被认出来。** 这一栏用的不是患者数据，而是**答案已知**的合成数据：
先造一张稀疏的空间连接图，用它生成事件，再让模型去把这张图找回来。三层分开评分，因为
它们允许的结论完全不同：哪些连接存在（逐边身份）、活动整体往哪个方向走、以及各组织块
往前推的**相对排序**。三个量原本量纲不同、随机水平也不同（0.5 / 0.5 / 0），所以统一
换算成"随机=0、完美=1"。虚线是事先定好的可报告门槛。中间那层每次结果只有对/错两种，
所以画的是比例加二项置信区间。

**D — 能不能外推到没训练过的触点。** 每个点是一位患者，纵轴是"组织场模型"相对"触点即
节点模型"在**被完全排除在训练之外**的那些触点上的优势。两档：左边那档该触点仍出现在
输入序列里但不计入损失，右边那档连输入也被拿掉。两个模型都在**没有逐触点偏置**的条件
下训练——一个从没训练过的触点没有办法学到属于自己的偏置，带着它这个检验在被测的那些
位置上根本没有定义。

**E — 连线经济学有没有真的起作用。** 横轴是学出来的连接的平均长度（1 = 组织单元之间
的典型间距），纵轴是这张图在给定内部传播步数下，实际能够覆盖的观测跃迁比例。竖虚线是
典型间距。要看的是连接是否确实偏短，以及偏短之后是否仍然够得着。

**关注点**：C 面板的判决先于一切——逐边身份没过随机水平，所以任何"这位患者的图长这样、
和别人不一样"或者"删掉模型认为重要的连接会怎样"的说法在这一版里都不成立；能说的只有
预测层面的结论，以及 C 最右边那一层许可的**相对排序**。
