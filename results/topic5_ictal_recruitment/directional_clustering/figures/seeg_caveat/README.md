# SEEG / 近一维 caveat 合图（不进结论）

深部电极（SEEG）或近一维电极（`coord_aspect < 0.15`）被试的同款合图——"间期模板 A/B 事件方向空心直方图
（红=A / 蓝=B）+ 发作两类平均方向（黑线）"，按发作主要方向旋到 0°。

**方向是 2D 投影估计**：SEEG 把 3D 触点投影到平面、近一维电极把所有梯度方向挤到电极线上，方向角不可靠。

**关注点**：这些图**只作 caveat 展示**，不进主队列（6 个 ECoG）、不参与任何描述性汇总或结论。典型如 922
（ECoG 但 aspect=0.11，近一维）：红/蓝间期直方图 + 黑色发作均向全部压在一条线上 = 几何塌缩伪影。
