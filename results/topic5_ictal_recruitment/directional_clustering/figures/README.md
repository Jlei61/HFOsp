# 发作早期方向两类聚类 ↔ 间期 A/B 方向（图说明）

> 探索性、描述性、无预设假设、不声称重放。口径见
> `docs/superpowers/specs/2026-06-27-topic5-ictal-direction-clustering-design.md`。

我们对每个几何干净的板状电极（ECoG）被试，把每次发作头十秒"往哪个方向烧"取成一个方向角，
**不看间期、不预设正反**，纯按方向把发作分成两堆；分完再看这两堆的平均方向和这个病人平时那两条
间期传播路线（模板 A/B）的方向是什么关系。三道事先锁死的门防止"算法硬把一个主方向切成两类"。

### epilepsiae_<id>__dir_cluster_broadband.png / _hfa.png

每被试一张极坐标玫瑰。彩色细线 = 该被试逐次发作的早期激活方向（按无监督两类着色，绿=类1 / 紫=类2）；
两条彩色粗线 = 两类各自的堆内平均方向；两条黑虚线 = 间期两条传播路线（模板 A / B）的方向。
标题角注给出该被试分档：`report_tier`（two_class_mapped / two_class_unmapped / single_axis / diagnostic_only）、
`axis_tier`（间期 A/B 两方向夹角够不够大、成不成一根可比的轴）、`p_bimodal`（发作方向是不是真的分两堆，越小越像真两类）、
`p_align`（两类方向贴间期 A/B 是否超过随机旋转，越小越显著）。

**关注点**：先看两条黑虚线是不是基本相反（成轴）——若几乎重合（如 1084，Δ≈6°）则 `axis_tier=diagnostic_only`，
两类对不对得上无从谈起；再看 `p_bimodal` 是否 <0.05（否则只是把一个主方向硬切两半，只能读"主方向"，不读"两类"）；
只有三门全绿（`report_tier=two_class_mapped`）才可读成"发作两类分别对上 A/B"。
**本队列结果（宽带+快活动各 6 个被试）：没有一个被试到 two_class_mapped。** 唯一真的分成两堆的是 442（宽带，绿类贴近间期 B、
紫类离间期 A 约 45°），但两类整体贴合 A/B 没有超过随机（`two_class_unmapped`，p_align≈0.31）；其余多为"一个主方向"
或几何不成轴。与本 topic 其它线一致：共性是粗的网络/解剖锚，不是细到方向两类可分的重放。

### epilepsiae_442__classes_vs_interictal_hist_broadband.png / _hfa.png

cohort-pooled-rose 风格的合图：**四条都画成空心直方图**——两堆发作方向（绿=类1 / 紫=类2，粗线）+ 两个间期模板的事件方向
（蓝=模板 A / 橙=模板 B，细线），黑线=发作轴（0°/180°）。因为间期事件比发作多约一千倍，每条曲线**各自归一化到自己的峰值**
（半径 0–1），只比"方向形状"不比绝对量（绝对量 n + 集中度 R 在图例里）。发作轴旋到 0°/180°（与 A 线玫瑰同一约定）。
这是用户要求的"两堆发作方向两色 + 间期事件 hist 同一张图、且都画成 hist"的对照图。

**关注点**：看绿/紫两堆发作方向和蓝/橙间期模板瓣是否落在同一方向。442 里间期 A（蓝，n≈4871，R=0.80）大瓣在 ~315°，
发作类 2（紫）在其附近、类 1（绿）在 ~160°（与 A 大致反向），间期 B（橙，R=0.32）弥散——两堆发作方向并没有干净地各对上
一个间期模板瓣，这正是 `two_class_unmapped`（旋转 null p_align≈0.31）在图上的样子。
