### contact_similarity_broadband_cohort.png

四面板队列图，考察"间期顺序场与发作期激活在空间上相似"这一主张到底依赖几何表示方式的哪一步（n=18 合格被试，宽频 80–500 Hz，B=1000 次轴内零假设抽样；1 个单杆被试 epilepsiae_139 因 within-shaft 零假设退化被排除）。三档只差几何处理：R1=不投影的逐触点 Pearson；R2=复用发作场同一 2D 触点平面 + 同一带宽的高斯平滑、但在触点上算（无网格）；R3=现有铺网格的场相关（与 A-line 主统计逐位一致，本图内 R3 对照 max|Δ|=0.0000、18/18 命中）。面板 A：各被试 R1/R2/R3 观测值分组条 + 各自零假设 p95 黑线（问"绝对高度是否超零假设"）；面板 B：每被试两步增量——橙=smooth_delta(R1→R2，平面内平滑贡献)、红=grid_delta(R2→R3，网格贡献)，零线横贯（问"每步几何各动多少"）；面板 C：把 R2 带宽缩放 0.5×/1×/2× 看带宽稳健性；面板 D：不含几何的 Spearman/Kendall 顺序基准（问"纯触点序列本身像不像"）。

**关注点**：橙色 smooth_delta 队列普遍为正（中位 +0.18）= 平面内几何平滑实质性提升相似，是"场"的主要来源；红色 grid_delta 贴零略负（中位 −0.018，CI[−0.10,+0.02]）= 网格这一步没带来可分辨增益（在 SESOI=0.05 下等价检验未通过，故只能说"未见可分辨网格增益"，不能说"严格为零"）；within-shaft 超零假设的被试不多（R1=6/R2=5/R3=4 /18）。合起来回应"场投影是否必要"：相似性主要来自触点平面几何，不来自网格；不铺网格的触点度量(R2)已基本复现场(R3)。属 sensitivity/robustness 读出，非新的队列级主张。

### contact_similarity_hfa_cohort.png

同一四面板，发作侧改用 HFA(高频)激活作敏感性对照（n=18，B=1000，R3 对照 max|Δ|=0.0000、18/18 命中）。

**关注点**：与宽频同向——smooth_delta 中位 +0.20、grid_delta 中位 −0.024(CI[−0.08,+0.00])，within-shaft 超零假设 R1=9/R2=7/R3=5 /18（HFA 略多于宽频）。结论方向跨频段一致：几何平滑是相似性的主要来源、网格无可分辨增益。仅作稳健性对照，不单独下主张。
