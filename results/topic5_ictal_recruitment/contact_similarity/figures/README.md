四面板队列图，考察"间期顺序场与宽频发作期激活相关"这一主张对几何表示方式的依赖程度（n=5 个合格被试，宽频 80–500 Hz，B=200 次轴内零假设抽样）。面板 A 展示各被试在三个梯度（R1 原始 Pearson、R2 平面内高斯平滑 Pearson、R3 网格场相关）下的观测值分组条形图，黑线标示各梯度零假设 p95 阈值（回答"各梯度绝对高度是否超出零假设？"）；面板 B 展示每个被试的两步几何增量——橙色条（R1→R2，平面内平滑贡献的 Δ 相关）和红色条（R2→R3，网格插值贡献的 Δ 相关），零参考线横贯，直接回答"每步几何操作各带来多大变化？"（与面板 A 的绝对高度视角互补，非重复）；面板 C 将 R2 的高斯带宽分别缩放至 0.5×/1×/2×，检验带宽选择对结果的影响；面板 D 以 Spearman ρ 和 Kendall τ 对角散点图展示不含任何几何的基准顺序统计量，验证信号是否在零假设之上。

**关注点**：面板 A 中各被试 R1/R2/R3 绝对值是否超出 p95 黑线；面板 B 中平滑 Δ（橙）与网格 Δ（红）的符号与幅度——橙色普遍为正说明平面内平滑实质性提升相关，红色接近零或负说明网格插值无独立增益；面板 D 顺序统计量的点若普遍落在对角线以下，说明纯顺序对齐本身不显著，几何贡献需单独归因。
