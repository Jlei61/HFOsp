### contact_similarity_broadband_cohort.png

四面板队列图，考察"间期顺序场与宽频发作期激活相关"这一主张对几何表示方式的依赖程度（n=5 个合格被试，宽频 80–500 Hz，B=200 次轴内零假设抽样）。面板 A 展示各被试在三个梯度（R1 原始 Pearson、R2 平面内高斯平滑 Pearson、R3 网格场相关）下的观测值条形图，黑线标示各梯度零假设 p95 阈值；面板 B 以斜率图展示每个被试沿 R1→R2→R3 的轨迹，同时标注平滑增量和网格增量的队列中位数；面板 C 将 R2 的高斯带宽分别缩放至 0.5×/1×/2×，检验带宽选择对结果的影响；面板 D 以 Spearman ρ 和 Kendall τ 对角散点图展示不含任何几何的基准顺序统计量，验证信号是否在零假设之上。

**关注点**：各被试 R1→R2 的跳变幅度（平面内平滑是否实质性拉高相关值）；R2→R3 的网格增量是否接近零（场插值的额外贡献是否可忽略）；面板 D 中顺序统计量的点是否普遍落在对角线以下（纯顺序对齐若显著，则几何操作的独立贡献需重新评估）。
