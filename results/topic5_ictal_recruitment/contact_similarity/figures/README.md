### contact_similarity_broadband_cohort.png

四面板队列图，考察"间期顺序场与发作期激活在空间上相似"这一主张到底依赖几何表示方式的哪一步（n=18 合格被试，宽频 80–500 Hz，B=1000 次轴内零假设抽样；1 个单杆被试 epilepsiae_139 因 within-shaft 零假设退化被排除）。三档只差几何处理：R1=不投影的逐触点 Pearson；R2=复用发作场同一 2D 触点平面 + 同一带宽的高斯平滑、但在触点上算（无网格）；R3=现有铺网格的场相关（与 A-line 主统计逐位一致，本图内 R3 对照 max|Δ|=0.0000、18/18 命中）。面板 A：各被试 R1/R2/R3 观测值分组条 + 各自零假设 p95 黑线（问"绝对高度是否超零假设"）；面板 B：每被试两步增量——橙=smooth_delta(R1→R2，平面内平滑贡献)、红=grid_delta(R2→R3，网格贡献)，零线横贯（问"每步几何各动多少"）；面板 C：把 R2 带宽缩放 0.5×/1×/2× 看带宽稳健性；面板 D：不含几何的 Spearman/Kendall 顺序基准（问"纯触点序列本身像不像"）。

**关注点**：平面内平滑 (R1→R2) 把观测相似度中位数抬高 +0.176(宽频)/+0.201(高频),CI 不含 0 —— 即用触点的平面位置做平滑确实抬高了观测到的相似度数值。**但这不等于'几何让更多被试超过随机对照'**:超过'同电极杆内打乱'零假设的被试数从 R1→R2→R3 是**下降**的(宽频 6→5→4,高频 9→7→5),因为平滑同时也抬高了零假设(打乱后的数据平滑后也更像)。准确说法:平滑抬高的是**原始相似度数值**,不是**超随机对齐的证据量**。网格步 (R2→R3) 中位数几乎不动、略降(−0.018/−0.024),等价检验在 ±0.05 内未通过 → 只能说'未见可分辨的网格增益',不能说'严格为零'。不带几何的纯触点序列 Spearman/Kendall 分别 7/18、8/18 超零假设。R3 场数值与 A 线主统计逐位一致(0/18 偏差),证明复刻无误。结论(稳健性层,非新主张):场更高的相似度数值主要来自平面几何平滑(它同时抬高信号与零假设);不铺网格的触点度量已复现场;网格无可分辨增益。口径提醒：本结果只支持'场相似度更高主要来自平面几何平滑而非网格插值'，不支持'触点相似度已刻画病理网络'——升级为病理网络主张需要临床验证（SOZ/切除/预后等），进行中的 R2b 3D 敏感性检查只是排除 2D 投影伪影，并非这种升级。

### r2b_sensitivity_broadband.png / r2b_sensitivity_hfa.png

R2b 3D 敏感性检查图（`scripts/augment_topic5_r2b_3d.py` → `scripts/plot_topic5_r2b_sensitivity.py`）：给上面 R1/R2/R3 阶梯再加一档 R2b——把 2D 触点平面投影换成电极的原生 3D 毫米坐标（不做镜像翻转），看"同平面几何有效"这个结论是否只是 2D 投影产生的假象。R2_nm 与 R2b 在**同一批"既有 2D 平面记录、又有合法 3D mm 坐标"的公共通道子集**上，用同一套轴内打乱零假设重算（不镜像、median-over-seizures 折叠、B 次打乱）；primary 对比是 `R2b − R2_nm`（两者都不镜像、同一公共子集），`R2b − R2(镜像,全通道)` 只是连接读者熟悉的原图 R2 数值的说明性字段，不是判据。两面板：**A** 每个被试的 `R2b − R2_nm` 条形图，零线横贯——蓝=零假设正常，斜纹=该被试零假设有效打乱次数不足（`INSUFFICIENT_NULL`；即便整体状态是"ok"也不能默认这个零假设可信，见下方 M-1），灰=坐标覆盖不够/单位不对/通道太少而被跳过的被试（跳过原因码标在条上）；**B** 把阶梯拉长成 R1(原图存档,镜像,全通道) → R2_nm(2D 平面,不镜像,公共子集) → R2b(原生 3D,不镜像,公共子集) 三点连线，方便对照熟悉原图 R1 位置的读者看 R2b 落在哪。

**关注点**：口径是 `R2b − R2_nm` ≈0(落在 ±0.05 等价区间内)→2D 平面投影已经够用；显著 >0→3D 坐标补充了额外可用信息；显著 <0→应收窄回只用 2D 平面。**M-1（零假设够不够）**：面板 A 的队列中位数/CI/等价判定只用 `r2b_status=="ok"` 的被试，但"ok"只保证两个 rung 都算出了观测值，不保证零假设打乱次数够——斜纹条单独标出"ok 但零假设不够"的被试，不能把它们悄悄当作干净证据。**M-2（读 Δ 前的口径差异）**：`R2_nm` 用的带宽 `sigma_xy` 是在**全部匹配通道**的平面几何上冻结的旧带宽（复用阶梯"同一 σ"的约定），`R2b` 用的带宽 `sigma_3d` 是重新在**公共子集**上算的 3D 最近邻中位距；当某被试的公共子集是匹配通道的严格子集时，两个带宽来自不同的通道群体几何，此时 Δ 里混了"带宽估计群体不同"这一口径差异，不是纯粹的"2D vs 3D 坐标"差异。

**B=1000 全队列实测结论（已核验）**：n_ok=18/19（两个激活量），`R2b − R2_nm` 队列中位 = **+0.0001（宽频）/ +0.0012（高频）**，bootstrap CI = **[−0.0099,+0.0077]（宽频）/ [−0.0051,+0.0107]（高频）**，SESOI=±0.05 等价检验**双双通过** → 命中"2D 平面读出已够用、当前结论稳定"这一支：把平面换成真三维坐标，观测相似度实质不变，§3 的结论不是 2D 投影伪影。`n_ok_insufficient_null=0`（无斜纹条），stored-R3 逐位对照 18/18 一致（未漂移基线）。本队列所有 ok 被试 `n_common==n_matched`（0 触点因缺坐标被丢、坐标全为 mm），故 M-2 的"带宽群体不同"口径差异在本次不发生。**守窄口径**：这只是"2D 平面几何 vs 原生三维几何"的稳健性附注，绝不据此写"刻画病理网络"。详见 `docs/archive/topic5/contact_similarity_ladder_2026-07-01.md` §5。

**六个 NA 原因码朴素话**（面板 A 灰条上标注的跳过原因；本次全队列只出现 `NA_insufficient` 一例）：
- **NA_ineligible** — 连触点相似性阶梯的基础上下文都没建起来（没匹配到发作触点 / 缺 T0 缓存），根本没进 R2b。
- **NA_coords** — 拿不到该被试触点的 3D 毫米坐标（坐标文件缺失 / 加载器报错 / 坐标通道顺序与匹配通道顺序对不上）。
- **NA_units** — 坐标不是毫米单位（如体素 voxel）；mm 硬门直接拒绝，不做静默回退。
- **NA_insufficient** — "既有 2D 平面记录、又有合法 mm 3D 坐标"的公共触点子集太小：公共触点 <6、或跨的电极杆 <2、或没有一次发作在公共子集上凑够 ≥6 个有限值。（本次唯一一例 `epilepsiae_139` = 单杆 → 跨杆数 <2。）
- **NA_degenerate** — 公共子集 3D 点云退化（触点坐标几乎重合）→ 3D 最近邻间距中位数=0 → 高斯核带宽 `sigma_3d≤0` 无法定义。
- **NA_no_null** — 零假设 harness 没给出观测统计量（R2_nm/R2b 两级里至少一级没产出 `obs_subject`）。
