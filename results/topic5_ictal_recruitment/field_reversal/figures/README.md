# TA/TB 间期传播场反向门 — 图说明

**测了什么**：每个病人间期都会反复出现两种"传播模板"（这里叫 TA、TB）——同一批电极触点，事件有时候按一种先后顺序被激活，有时候按另一种顺序。这里问的是：把 TA、TB 两类事件各自摊成一整张连续空间场（谁先谁后的空间分布，而不是一串离散触点数字）之后，这两张场是不是恰好"反过来"的——TA 里早的地方在 TB 里变晚、TA 里晚的地方在 TB 里变早，像同一根轴的两个走向？而且反得比"只在同一根电极杆内部把触点顺序打乱"这种最起码的对照更狠？

**怎么测的**：给每个病人建一张两类事件共用的空间场坐标（同一批触点坐标、同一个平滑带宽），算 TA 场和 TB 场之间的带符号相关（越接近 −1 越像"完全反过来"）。零假设 = 只在同一根电极杆**内部**随机打乱触点的值（杆间顺序不动），重建场、重算相关，重复几百次；看真实观测值落在这个随机分布里的什么位置（同时还有一个"全部触点整体打乱"的粗对照，以及一个不看 TA/TB 标签、随机切两半事件比较的非推断对照，后者应该长得偏正——用来衬托"TA/TB 是真的不同，不是随便切两半就会出现的巧合"）。另外单独测了"摊成场"这一步是不是让方向估计更可靠——用留一法：拿掉某个触点，只用其余触点重建的平滑场去预测被拿掉的这个触点，看这个预测比"直接用离散触点原始均值"准不准。

**揭示了什么**：cohort 层面确实观测到明显反向——两个触点覆盖范围（下面简称 `broad` = 覆盖更广的 20 触点、`narrow` = 更贴近临床 SOZ 核心的小触点集）观测到的带符号相关中位数都在 −0.61 附近，明显偏负。逐病人对着自己的零假设检验，`broad` 6/26、`narrow` 9/26 病人的反向强度显著超过随机水平（二项检验 p 都远小于 0.05；n_perm=1000 正式全量，2026-07-07）——这是目前最站得住的主张。但如果换一个问法——"整个队列 Data 中位数是不是系统性低于 Null 中位数"（配对 Wilcoxon）——`broad` 不显著（p=0.099），只有 `narrow` 显著（p=0.0002）。这两种问法不是同一件事：前者看"个别病人有没有打穿自己的 5% 门槛"，后者看"队列整体有没有系统性偏移"，两者可以不一致，不是矛盾。另外，"摊成场"是否让**逐触点重建**更可靠这件事看起来是否定的（**注意：这只是"逐触点重建"层面，不是"传播方向 / 轴"的鲁棒性**）：用留一法比较，平滑场预测未见触点的准确度在全部 26+26 个病人里**都**不如直接用离散触点原始均值——但这个检验天然偏向触点 self-mean（大量事件平均的高 SNR 量），邻居插值必糊掉 contact-specific 信息，**它测不到"哪种表示给更鲁棒的传播方向"**。"场是否给更鲁棒的传播方向"由 axis-level supplement 另测（读方向要用真实坐标、坐标盲于杆内位置的杆折叠读法会跑偏、平滑不额外加分；见 `axis_robustness/figures/`）。只看"过没过自己的零假设"这种二元判断，场和触点基本打平。下文按图说明，`broad`/`narrow` 全程分开报告、从不合并。

### field_reversal_cohort_stat.png — 队列反向的头条图

`broad` | `narrow` 两组并排，每组内 `Data`（每个病人观测到的带符号相关）vs `Null`（每个病人自己那条同杆重排零假设分布的中位数），violin+箱线+散点，浅灰线连接同一个病人的 Data/Null 配对，不显示病人姓名。纵轴 = 带符号 r，虚线标 r=0（"反向"定义为点落在 0 以下、且低于自己的 Null）。显著性用配对单尾 Wilcoxon（`alternative="less"`，即检验 Data 是否系统性比 Null 更负）：`broad` p=0.099（n.s.，n=26，data<null 16/26）、`narrow` p=0.0002（\*\*\*，n=26，excluded: c1_violation=6, plane_not_built=1, degenerate_null=2, data<null 20/26）。每组脚注同时给出这次配对检验的结果和正式的逐病人二项 gate 结果（`broad` 6/26、`narrow` 9/26 通过own null）。

**关注点**：这张图只是把"队列层面整体是不是往负方向偏"这件事画出来——`broad` 在这个问法下不显著，不代表 `broad` 没有反向个案（下面 6/26 通过自己零假设的病人是真实存在的），只说明"整体中位数偏移"和"个别病人打穿阈值"是两个不同的问法，可以给出不同答案。正式的"过/不过"判定以逐病人二项 gate（脚注里的 `cohort_binomial`）为准，本图是可视化，不是判决。

### accountability.png — 谁进了队列、为什么

`broad`/`narrow` 并排的分组条形图，横轴 = 8 种可能的入组结果（`no_planes`/`load_error`/`c1_violation`/`plane_not_built`/`cluster_map_ambiguous`/`insufficient_overlap`/`degenerate_null`/`ok`），纵轴 = 病人数。`broad` 26 个候选全部 `ok`；`narrow` 35 个候选里 6 个因为标签本身不满足"稳定两簇"前提被挡在门外（`c1_violation`）、1 个几何平面没建成（`plane_not_built`）、2 个因为可打乱的触点太少而判定零假设退化（`degenerate_null`），剩下 26 个 `ok`。

**关注点**：`narrow`（更贴近 SOZ 核心的小触点集）确实比 `broad` 更容易在门槛前被挡下——这正是"贴近核心 = 触点更少、更容易退化"的预期代价，是一个真实结果，不是运行失败。两个底物最终都剩下 26 个可推断病人，样本量恰好相等只是巧合。

### broad/field_vs_contact_headtohead.png / narrow/field_vs_contact_headtohead.png — 场 vs 触点，二元过关对比

2×2 混淆矩阵：横轴 = 触点法（无几何，直接对 TA/TB 逐触点值算带符号 Spearman）是否通过自己的同杆零假设，纵轴 = 场法是否通过。`broad`：都通过 5、只场通过 1、只触点通过 2、都没通过 18（场 6/26、触点 7/26，触点略胜 1 个）；`narrow`：都通过 9、只场通过 0、只触点通过 1、都没通过 16（场 9/26、触点 10/26，触点略胜一筹）。

**关注点**：单看"过没过自己零假设"这个二元问题，场和触点表现几乎打平，场没有明显买到更多"过关"的病人——这一层面的答案和下面 `loo_reproducibility` 的连续精度层面答案不同，两者分开看，不要合并成一句"场没用"。

### broad/loo_reproducibility.png / narrow/loo_reproducibility.png — 逐触点 LOO 重建 sanity（**降级，非 axis test**）

留一法可复现性：每个病人一对点——用训练半段事件重建的场，在被拿掉的触点位置做预测（`field`），vs 直接用训练半段触点原始均值做预测（`contact`），都跟保留半段的真实均值比较跨触点 Spearman。浅灰线连接同一病人的两个值。

**关注点**：`contact` 在全部 26 个 `broad`、26 个 `narrow` 病人里都比 `field` 更准（配对 Wilcoxon p=3.0e-8）。**但这测的是「逐触点重建」，不是传播轴 / 方向的鲁棒性**——该检验天然偏向触点 self-mean（大量事件平均的高 SNR 量），邻居插值必糊掉 contact-specific 信息。「场是否给更鲁棒的传播方向」由 axis-level supplement 另测（见 `axis_robustness/`，已跑：读方向要用真实坐标、坐标盲于杆内位置的杆折叠会跑偏、平滑不额外加分）。**别把这张读成「场没用 / 去噪被证伪」**。

### broad/field_reversal_null_forest.png / narrow/field_reversal_null_forest.png — 逐病人诊断图（辅助，非正式结论图）

横轴 = 26 个 `ok` 病人按观测带符号 r 从负到正排序（不显示姓名），每个病人画一根竖线连接"自己同杆零假设的第 5 百分位"（灰色短横）和"观测值"（圆点，黑色实心=通过、空心=未通过）。

**关注点**：这只是把 `field_reversal_cohort_stat.png` 背后逐病人的账目摊开看——通过的病人清一色集中在最负的一端，且都是观测值明显低于自己那条零假设门槛线的情形；这张图不是新结论，是上面二项 gate 数字的可视化台账，供排查用，不是论文级图。

### field_reversal_broad_vs_narrow.png — 反向能不能扛到核心触点

对 26 对里"两个底物都 `ok`"的 20 个病人，横轴 = `broad` 观测带符号 r，纵轴 = `narrow` 观测带符号 r，按四种"过关组合"上色（`both_pass`=3、`broad_only`=1、`narrow_only`=4、`neither`=12），左上角嵌一张 2×2 过关一致性表。虚线 = broad=narrow 参考线。

**关注点**：多数点落在虚线附近、且落在第三象限（两者都负），说明反向在 `narrow`（贴近 SOZ 核心）下并没有消失，不是一个只在粗覆盖下才出现的远场/粗糙现象；但"同时通过各自零假设"的病人只有 3/20，大部分反向个案要么只在一个底物里打穿阈值、要么两个都没打穿——反向的**方向**在两个尺度下相当一致，但**统计显著性**在两个尺度下经常各自独立地打穿或打不穿阈值。

### broad/per_subject/ 与 narrow/per_subject/（子目录）— 逐病人示例

每个底物各挑 2 个有代表性的病人（不是全部 26/26 个都画）：`broad/per_subject/epilepsiae_1077.png`（清楚通过：TA/TB 场肉眼可见反向梯度，观测 r=−0.985 远落在自己零假设分布左侧尾部）、`broad/per_subject/epilepsiae_1125.png`（未通过但值得看：观测 r=−0.894 看起来"很反向"，但这个病人自己的零假设本身就集中在 −0.85 附近，所以这个负值并没有打穿阈值——这正是"必须配零假设看，不能只看裸相关数字"的活教材）；`narrow/per_subject/epilepsiae_1096.png`（通过，但只有 6 个触点，场几乎是单排点的平滑插值，是 `narrow` 底物"贴近核心=触点少"的真实样子）、`narrow/per_subject/yuquan_zhaochenxi.png`（未通过，同样是"裸相关很负、但零假设也很负"的情形）。每张图三联：TA 场 | TB 场（展示用 VIS 平滑常数 + rank01，只为方便肉眼看，不是统计输入）| 观测值落在同杆零假设直方图 + 通道地板零假设中位数 + 随机切半对照上的位置。

**关注点**：这组示例图故意不是"挑好看的"——`epilepsiae_1125` 和 `yuquan_zhaochenxi` 两个"未通过"例子专门用来说明为什么报告纪律要求"实测 corr 永远跟零假设一起出、不出裸相关数字"：这两个病人的裸相关都在 −0.85 到 −0.93 之间，肉眼看很像强反向，但因为各自的零假设本身也偏负，最终没有打穿 5% 门槛。
