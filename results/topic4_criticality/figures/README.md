### trajectory_criticality_verdict.png
这张图诊断 M3A-v2.2 那条“抑制耗尽→跑飞”的真实轨迹是不是“临界慢化式软着陆”。左图把每个合格快照的主特征值 α₁ 画在失抑制轴上（红虚线是 α₁=0 临界线，灰点是不合格点仅作背景，颜色是mode-class）；右图把回弹时间 τ=−1/α₁ 沿时间画出来（对数轴），看它有没有在跑飞前拉长。当前判定：unresolved_operating_point。（unresolved 的具体原因：合格快照上 α₁ 仍为负，但分支延续补检发现低支 α₁ 在两个抽样点之间穿过 0——临界边界落在采样空隙里，属采样不足，非求解失败。）overlay 是否叠加见标题注记（未标定映射时 REFUSED，不画 atlas 背景）。
**关注点**：左图 α₁ 是平滑逼近 0（软着陆）还是一直离 0 有余量后直接跳（硬跳）；右图 τ 有没有临界式发散。
